# **A. МНОГОМЕРНЫЕ ФУНКЦИИ РАСПРЕДЕЛЕНИЯ**

## **1. Совместная функция распределения**

### **1.1. Определение**
* **Совместная ФР** для случайного вектора `(ξ₁, ..., ξₙ)`:
    * `F(x₁, ..., xₙ) = P(ξ₁ ≤ x₁, ..., ξₙ ≤ xₙ)`
* Обозначение: `F(x)` где `x = (x₁, ..., xₙ) ∈ ℝⁿ`

### **1.2. Свойства**
* **Монотонность:** `F` неубывает по каждому аргументу при фиксированных остальных
* **Правая непрерывность:** по каждому аргументу
* **Граничные условия:**
    * `F(+∞, ..., +∞) = 1`
    * `F(−∞, x₂, ..., xₙ) = 0` для любого аргумента, равного `−∞`
    * `F(x₁, ..., xₖ₋₁, −∞, xₖ₊₁, ..., xₙ) = 0`

### **1.3. Граничные распределения (маргинализация)**
* **Маргинальная ФР** `ξₖ`: `F_{ξₖ}(x) = F(+∞, ..., +∞, x, +∞, ..., +∞)` ( `x` на позиции `k` )

## **2. Совместная плотность вероятности**

### **2.1. Определение**
* Для абсолютно непрерывного случайного вектора:
    * `f(x₁, ..., xₙ) = ∂ⁿF / ∂x₁...∂xₙ`
* **Свойства:**
    * `f(x) ≥ 0` для всех `x`
    * `∫_{ℝⁿ} f(x₁, ..., xₙ) dx₁...dxₙ = 1`
    * `P((ξ₁,...,ξₙ) ∈ A) = ∫_A f(x₁,...,xₙ) dx₁...dxₙ`

### **2.2. Маргинальная плотность**
* `f_{ξₖ}(x) = ∫...∫ f(x₁,...,xₙ) dx₁...dx_{k₋₁} dx_{k₊₁}...dxₙ`
* Интегрирование совместной плотности по всем аргументам, кроме интересующего

## **3. Теорема о взаимно-однозначном соответствии в ℝⁿ**

* Между совместными ФР `F(x₁,...,xₙ)` и вероятными мерами на `(ℝⁿ, B(ℝⁿ))` существует взаимно-однозначное соответствие
* Каждой вероятной мере на `ℝⁿ` соответствует единственная совместная ФР
* Каждой такой ФР соответствует единственная вероятностная мера

# **B. НЕЗАВИСИМОСТЬ СЛУЧАЙНЫХ ВЕЛИЧИН**

## **1. Критерий независимости**

### **1.1. Определение**
* Случайные величины `ξ₁, ..., ξₙ` **независимы**, если:
    * `F(x₁,...,xₙ) = F_{ξ₁}(x₁) · ... · F_{ξₙ}(xₙ)` для всех `x₁,...,xₙ`
* Эквивалентно (при наличии плотности): `f(x₁,...,xₙ) = f_{ξ₁}(x₁) · ... · f_{ξₙ}(xₙ)`

### **1.2. Попарная vs совокупная независимость**
* **Попарная:** `ξᵢ` и `ξⱼ` независимы для всех `i ≠ j`
* **В совокупности:** joint F = произведение маргинальных F
* **Ключевой момент:** попарная независимость **не** эквивалентна независимости в совокупности!

### **1.3. Классический контрпример**
* `Ω = {1,2,3,4}`, `P({ω}) = 1/4` для каждого
* `A = {1,2}`, `B = {1,3}`, `C = {1,4}`
* `P(A) = P(B) = P(C) = 1/2`; `P(A∩B) = P(A∩C) = P(B∩C) = 1/4 = (1/2)(1/2)` — попарно независимы
* `P(A∩B∩C) = 1/4 ≠ (1/2)³ = 1/8` — **не** независимы в совокупности

## **2. Свойства независимости**

### **2.1. Лемма о независимости функций**
* Если `ξ₁, ..., ξₙ` независимы и `g₁, ..., gₙ` — измеримые функции, то `g₁(ξ₁), ..., gₙ(ξₙ)` независимы
* **Следствие:** `ξ²` и `η²` независимы при независимости `ξ` и `η`

### **2.2. E[произведения] = произведение E**
* Если `ξ₁, ..., ξₙ` независимы, то `E[∏ᵢ gᵢ(ξᵢ)] = ∏ᵢ E[gᵢ(ξᵢ)]`
* **Важно:** обратное неверно ( `E[XY] = E[X]·E[Y]` не означает независимость)

### **2.3. Дисперсия суммы**
* Если `ξ₁, ..., ξₙ` независимы: `D[Σᵢ ξᵢ] = Σᵢ D[ξᵢ]`
* **Без независимости:** `D[ξ + η] = D[ξ] + D[η] + 2·cov(ξ, η)`

## **3. Независимость бесконечного набора**

### **3.1. Определение**
* Система `{ξᵢ}_{i∈I}` независима, если для **любого конечного** подмножества `J ⊆ I` случайные величины `{ξⱼ}_{j∈J}` независимы

### **3.2. Критерий**
* `P(ξᵢ ∈ Bᵢ, i ∈ J) = ∏_{i∈J} P(ξᵢ ∈ Bᵢ)` для всех конечных `J ⊆ I` и борелевских `Bᵢ`

### **3.3. Следствие**
* Характеристическая функция: `φ(t) = ∏ᵢ φᵢ(tᵢ)` (при независимости)

# **C. СОВМЕСТНЫЕ РАСПРЕДЕЛЕНИЯ И СВЁРТКИ**

## **1. Совместная плотность при независимости**

* Если `ξ₁, ..., ξₙ` независимы: `f(x₁,...,xₙ) = f₁(x₁) · ... · fₙ(xₙ)`
* **Обратное:** если совместная плотность факторизуется, то СВ независимы

## **2. Формула для E[g(ξ₁,...,ξₙ)]**

### **2.1. Через совместную плотность**
* `E[g(ξ₁,...,ξₙ)] = ∫_{ℝⁿ} g(x₁,...,xₙ) · f(x₁,...,xₙ) dx₁...dxₙ`
* **При независимости:** `= ∫...∫ g(x₁,...,xₙ) · f₁(x₁)·...·fₙ(xₙ) dx₁...dxₙ`

### **2.2. Частные случаи**
* `E[ξ + η] = E[ξ] + E[η]` (линейность, без независимости)
* `E[ξη] = E[ξ]·E[η]` (только при независимости!)
* `E[ξ² + η²] = E[ξ²] + E[η²]` (линейность)

## **3. Свёртка плотностей**

### **3.1. Определение**
* Плотность суммы `ξ + η` при независимости `ξ, η`:
    * `f_{ξ+η}(x) = (f_ξ * f_η)(x) = ∫_{-∞}^{+∞} f_ξ(t) · f_η(x − t) dt`
* **Свёртка** — фундаментальная операция в теории вероятностей

### **3.2. Свойства свёртки**
* Ассоциативность: `(f * g) * h = f * (g * h)`
* Коммутативность: `f * g = g * f`
* Нейтральный элемент: `δ₀ * f = f` (дельта-функция в 0)

## **4. Известные формулы сложения**

| ξ | η | ξ + η |
|---|---|-------|
| `B(n, p)` | `B(m, p)` | `B(n + m, p)` |
| `Po(λ₁)` | `Po(λ₂)` | `Po(λ₁ + λ₂)` |
| `N(μ₁, σ₁²)` | `N(μ₂, σ₂²)` | `N(μ₁ + μ₂, σ₁² + σ₂²)` |
| `Exp(λ)` | `Exp(λ)` | `Gamma(2, λ)` (Эрланга) |
| `χ²(k₁)` | `χ²(k₂)` | `χ²(k₁ + k₂)` |
| `NB(r₁, p)` | `NB(r₂, p)` | `NB(r₁ + r₂, p)` |

### **4.1. Доказательство (напр., Пуассон)**
* `φ_{ξ+η}(t) = φ_ξ(t) · φ_η(t) = e^{λ₁(e^{it}-1)} · e^{λ₂(e^{it}-1)} = e^{(λ₁+λ₂)(e^{it}-1)}`
* Это характеристическая функция `Po(λ₁ + λ₂)` → единственность распределения

# **D. УСЛОВНЫЕ РАСПРЕДЕЛЕНИЯ**

## **1. Условная плотность**

### **1.1. Определение**
* `f(x|y) = f(x, y) / f_Y(y)` при `f_Y(y) > 0`
* Это плотность `X` при условии `Y = y` (непрерывный случай)

### **1.2. Свойства**
* `f(x|y) ≥ 0` для всех `x`
* `∫_{-∞}^{+∞} f(x|y) dx = 1` (интеграл по `x` равен 1)

## **2. Условное математическое ожидание**

### **2.1. Определение**
* `E[ξ|η = y] = ∫_{-∞}^{+∞} x · f(x|y) dx` (при абсолютно непрерывном `ξ`)
* `E[ξ|η]` — функция от `η` (само условное ожидание — случайная величина)

### **2.2. Формула полного математического ожидания**
* `E[ξ] = ∫_{-∞}^{+∞} E[ξ|η = y] · f_η(y) dy`
* Или в общей форме: `E[ξ] = E[E[ξ|η]]`

### **2.3. Интерпретация**
* Полное ожидание = «вложенное условное ожидание, усреднённое по распределению条件»

## **3. Марковские цепи**

### **3.1. Определение**
* Последовательность случайных величин `ξ₀, ξ₁, ξ₂, ...` с **свойством Маркова:**
    * `P(ξₙ₊₁ | ξ₀, ..., ξₙ) = P(ξₙ₊₁ | ξₙ)`
* «Прошлое не влияет на будущее при условии настоящего»

### **3.2. Матрица переходов**
* Для дискретного пространства состояний `S = {s₁, ..., sₘ}`:
    * `pᵢⱼ = P(ξₙ₊₁ = sⱼ | ξₙ = sᵢ)` — вероятность перехода из `sᵢ` в `sⱼ`
* **Матрица переходов** `P = [pᵢⱼ]`: строки нормированы (`Σⱼ pᵢⱼ = 1`)

### **3.3. Стационарное распределение**
* Распределение `π` такое, что `π = π · P` (собственный вектор `P` при собственном значении 1)
* **Существование:** если цепь эргодическая (неприводимая + апериодическая), то `π` единственна

### **3.4. Пример: цепь на графе**
* Вершины графа = состояния; `pᵢⱼ = 1/deg(i)` для смежных `i, j`
* Стационарное распределение: `πᵢ = deg(i) / (2|E|)` (степень вершины / суммарная степень)
* **Связь:** PageRank — обобщение на веб-граф с «затуханием» `d`

# **E. СВОДНАЯ ТАБЛИЦА**

## **1. Основные формулы сложения**

| Операция | Результат | Условие |
|----------|-----------|---------|
| Сумма independent `B(n,p) + B(m,p)` | `B(n+m, p)` | одинаковые `p` |
| Сумма independent `Po(λ₁) + Po(λ₂)` | `Po(λ₁ + λ₂)` | всегда |
| Сумма independent `N(μ₁,σ₁²) + N(μ₂,σ₂²)` | `N(μ₁+μ₂, σ₁²+σ₂²)` | всегда |
| Произведение independent `N(0,1) · N(0,1)` | χ²(1) | стандартные нормальные |
| Линейная комбинация `aX + b` | `N(aμ+b, a²σ²)` | `X ~ N(μ,σ²)` |

## **2. Ключевые неравенства и свойства**

* `E[XY] = E[X]·E[Y]` ⟹ не обязательно независимы (только первый момент)
* Попарная независимость ⟹⁄=> независимость в совокупности
* `D[X+Y] = D[X] + D[Y]` ⟹ `X, Y` некоррелированы (не обязательно независимы)
* `N(μ₁,σ₁²) + N(μ₂,σ₂²) ~ N(μ₁+μ₂,σ₁²+σ₂²)` — **единственное** стабильное распределение с конечной дисперсией
