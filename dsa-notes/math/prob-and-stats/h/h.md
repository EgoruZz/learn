# **A. ОПИСАТЕЛЬНАЯ СТАТИСТИКА**

## **1. Выборка и меры центра**

### **1.1. Выборка**
* `X₁, X₂, ..., Xₙ` — независимые одинаково распределённые (н.о.р.) случайные величины с распределением `F`
* **Выборка** — конкретные значения `x₁, ..., xₙ` (реализация)

### **1.2. Выборочное среднее**
* `X̄ = (1/n) Σᵢ₌₁ⁿ Xᵢ` — несмещённая оценка `E[X]`
* `E[X̄] = μ`, `D[X̄] = σ²/n`

### **1.3. Медиана**
* `Me = X_{(⌊(n+1)/2⌋)}` (при нечётном `n`) или среднее двух центральных
* Устойчива к выбросам (робастна)

### **1.4. Мода**
* Значение с максимальной частотой в выборке

## **2. Меры разброса**

### **2.1. Выборочная дисперсия**
* `S² = (1/(n−1)) Σᵢ₌₁ⁿ (Xᵢ − X̄)²` — **несмещённая** оценка `D[X]`
* Деление на `n−1` (поправка Бесселя): `E[S²] = σ²`

### **2.2. Стандартное отклонение**
* `S = √S²`

### **2.3. Межквартильный размах**
* `IQR = Q₃ − Q₁` — робастная мера разброса

### **2.4. Коэффициент вариации**
* `CV = S / X̄` — относительная изменчивость (безразмерная)
* Позволяет сравнивать изменчивость выборок с разными масштабами

### **2.5. Среднее абсолютное отклонение (MAD)**
* `MAD = (1/n) Σᵢ₌₁ⁿ |Xᵢ − X̄|` — более устойчива к выбросам, чем `S`
* Робастный вариант: `MAD = median(|Xᵢ − median(X)|)`

## **3. Другие средние**

### **3.1. Среднее геометрическое**
* `G = (∏ᵢ₌₁ⁿ Xᵢ)^{1/n}` (для `Xᵢ > 0`)
* Всегда `G ≤ X̄` (среднее арифметическое)
* `ln(G) = (1/n) Σᵢ ln(Xᵢ)` — среднее логарифмов

### **3.2. Среднее гармоническое**
* `H = n / Σᵢ₌₁ⁿ (1/Xᵢ)` (для `Xᵢ > 0`)
* Всегда `H ≤ G ≤ X̄` (цепочка неравенств)
* Естественно для скоростей и отношений

# **B. СТАТИСТИЧЕСКИЕ ОЦЕНКИ**

## **1. Свойства хороших оценок**

### **1.1. Несмещённость**
* `E[θ̂ₙ] = θ` для всех `θ ∈ Θ`
* **Пример:** `X̄` — несмещённая оценка `μ`; `S²` (с делением на `n−1`) — несмещённая для `σ²`

### **1.2. Эффективность**
* Среди несмещённых оценок выбирают ту, у которой минимальная дисперсия
* **Граница Крамера-Рао (CRB):** `D[θ̂] ≥ 1 / (n · I(θ))`, где `I(θ)` — информация Фишера
* Оценка, достижимая CRB, называется **эффективной**

### **1.3. Консистентность (согласованность)**
* `θ̂ₙ →^{P} θ` при `n → ∞`
* Выборочное среднее консистентно для `μ` (следствие ЗБЧ)

## **2. Метод моментов**

### **2.1. Идея**
* Равняем теоретические моменты `E[ξᵏ]` выборочным `(1/n) Σ Xᵢᵏ`
* Решаем систему уравнений относительно параметров

### **2.2. Пример: `N(μ, σ²)`**
* `E[ξ] = μ` → `μ̂ = X̄`
* `E[ξ²] = μ² + σ²` → `σ̂² = (1/n) Σ Xᵢ² − X̄²`

## **3. Метод максимального правдоподобия (MLE)**

### **3.1. Функция правдоподобия**
* `L(θ; x₁, ..., xₙ) = ∏ᵢ f(xᵢ; θ)` — «насколько вероятна выборка при параметре θ»
* Логарифмическая: `ℓ(θ) = Σᵢ ln f(Xᵢ; θ)` (монотонное преобразование)

### **3.2. Оценка MLE**
* `θ̂ = argmax_θ ℓ(θ)` — максимизируем логарифм правдоподобия
* Условие: `dℓ/dθ = 0` (при дифференцируемости)

### **3.3. Свойства MLE**
* **Согласованность:** `θ̂ₙ →^{P} θ`
* **Нормальная асимптотика:** `θ̂ₙ ~^{approx} N(θ, 1/I(θ))`
* **Инвариантность:** если `θ̂` — MLE для `θ`, то `g(θ̂)` — MLE для `g(θ)`

### **3.4. Пример: `Exp(λ)`**
* `f(x; λ) = λe^{−λx}`
* `ℓ(λ) = n·ln(λ) − λ·ΣXᵢ`
* `dℓ/dλ = n/λ − ΣXᵢ = 0` → `λ̂ = n / ΣXᵢ = 1/X̄`

# **C. ДОВЕРИТЕЛЬНЫЕ ИНТЕРВАЛЫ**

## **1. Идея**
* Интервал `[θ̂₁, θ̂₂]` такой, что `P(θ ∈ [θ̂₁, θ̂₂]) ≥ 1 − α`
* `1 − α` — доверительная вероятность (обычно 0.95, 0.99)

## **2. Для среднего**

### **2.1. При известной дисперсии (Z-интервал)**
* `X̄ ± z_{α/2} · σ/√n`
* `z_{α/2}` — квантиль N(0,1): `z_{0.025} = 1.96` для 95%

### **2.2. При неизвестной дисперсии (t-интервал)**
* `X̄ ± t_{α/2, n−1} · S/√n`
* `t_{α/2, n−1}` — квантиль распределения Стьюдента с `n−1` степенями свободы

## **3. Для дисперсии**

### **3.1. χ²-интервал**
* `(n−1)S² / χ²_{α/2, n−1} ≤ σ² ≤ (n−1)S² / χ²_{1−α/2, n−1}`
* Асимметричный из-за формы распределения χ²

## **4. Для пропорции**

### **4.1. Интервал для `p`**
* `p̂ ± z_{α/2} · √(p̂(1−p̂)/n)`
* Действителен при `np̂ ≥ 5` и `n(1−p̂) ≥ 5`

# **D. ПРОВЕРКА СТАТИСТИЧЕСКИХ ГИПОТЕЗ**

## **1. Основные понятия**

### **1.1. Гипотезы**
* `H₀` — нулевая гипотеза (предположение, которое проверяем)
* `H₁` — альтернативная гипотеза (противоположное `H₀`)

### **1.2. Ошибки**

| | `H₀` верна | `H₀` ложна |
|---|---|---|
| Отвергаем `H₀` | Ошибка I рода (`α`) | Верно (мощность `1−β`) |
| Принимаем `H₀` | Верно | Ошибка II рода (`β`) |

* **Уровень значимости:** `α = P(отвергнуть H₀ | H₀ верна)`
* **Мощность:** `1 − β = P(отвергнуть H₀ | H₁ верна)`

## **2. p-value**

### **2.1. Определение**
* Минимальный уровень значимости, при котором `H₀` отвергается
* `p = P(T ≥ t_{набл} | H₀)`, где `T` — статистика критерия

### **2.2. Правило**
* `p < α` → отвергаем `H₀`
* `p ≥ α` → не отвергаем `H₀` (не «принимаем»!)

## **3. Z-критерий (для среднего)**

### **3.1. Условия**
* Известна `σ` или `n` велико
* `H₀: μ = μ₀`

### **3.2. Формула**
* `Z = (X̄ − μ₀) / (σ/√n) ~ N(0, 1)` при `H₀`
* Двусторонний: отвергаем при `|Z| > z_{α/2}`

## **4. t-критерий Стьюдента**

### **4.1. Условия**
* `σ` неизвестна, `n` мало
* `H₀: μ = μ₀`

### **4.2. Формула**
* `T = (X̄ − μ₀) / (S/√n) ~ t(n−1)` при `H₀`
* Двусторонний: отвергаем при `|T| > t_{α/2, n−1}`

## **5. χ²-критерий согласия (Пирсон)**

### **5.1. Условия**
* Проверяем, принадлежит ли выборка заданному распределению
* `k` бинов, `m` оценённых параметров

### **5.2. Формула**
* `χ² = Σᵢ₌₁ᵏ (Oᵢ − Eᵢ)² / Eᵢ ~ χ²(k − m − 1)`
* `Oᵢ` — наблюдаемое число в бине `i`, `Eᵢ` — ожидаемое
* Отвергаем при `χ² > χ²_{α, k−m−1}`

## **6. χ²-критерий независимости**

### **6.1. Задача**
* Проверяем связь двух категориальных переменных

### **6.2. Формула**
* `χ² = Σ_{i,j} (Oᵢⱼ − Eᵢⱼ)² / Eᵢⱼ ~ χ²((r−1)(c−1))`
* `r` — число строк, `c` — число столбцов
* `Eᵢⱼ = (Σᵢ Oᵢⱼ · Σⱼ Oᵢⱼ) / N` (ожидаемое при независимости)

# **E. СТАТИСТИЧЕСКИЕ МЕРЫ СВЯЗИ**

## **1. Ранговая корреляция Спирмена**

### **1.1. Формула**
* `ρₛ = 1 − 6·Σdᵢ² / (n(n²−1))`
* `dᵢ` — разность рангов `i`-й пары
* Мера **монотонной** (не обязательно линейной) связи

### **1.2. Свойства**
* `|ρₛ| ≤ 1`; `ρₛ = ±1` при полной монотонной связи
* Не зависит от масштаба (инвариантна относительно монотонных преобразований)

## **2. Коэффициент Жаккара**

### **2.1. Формула**
* `J(A, B) = |A ∩ B| / |A ∪ B|`
* Мера схожести **множеств** (от 0 до 1)

## **3. Энтропия**

### **3.1. Формула Шеннона**
* `H(X) = −Σᵢ pᵢ · log₂ pᵢ` (в битах)
* Мера неопределённости/случайности

### **3.2. Свойства**
* `H(X) ≥ 0`; `H(X) = 0` ⟺ `X` детерминирована
* Максимум при равномерном распределении: `H = log₂(n)`

## **4. Взаимная информация**

### **4.1. Формула**
* `I(X; Y) = H(X) + H(Y) — H(X, Y)`
* Мера **общей информации** (не только линейной связи)

### **4.2. Свойства**
* `I(X; Y) ≥ 0`; `I(X; Y) = 0` ⟺ `X, Y` независимы
* `I(X; Y) = I(Y; X)` (симметрия)
* `I(X; X) = H(X)` (собственная информация = энтропия)

## **5. Условная энтропия**

### **5.1. Формула**
* `H(X|Y) = H(X, Y) — H(Y)`
* «Неопределённость `X` после наблюдения `Y`»

### **5.2. Связь**
* `I(X; Y) = H(X) − H(X|Y)` (сколько информации `Y` даёт о `X`)

# **F. СВОДНАЯ ТАБЛИЦА**

## **1. Типы оценок**

| Оценка | Формула | Несмещённая? |
|--------|---------|--------------|
| `X̄` | `(1/n) ΣXᵢ` | да |
| `S²` | `(1/(n-1)) Σ(Xᵢ-X̄)²` | да |
| `σ̂²_ML` | `(1/n) Σ(Xᵢ-X̄)²` | нет (смещённая) |
| `λ̂_ML` (Exp) | `1/X̄` | да |

## **2. Критерии проверки гипотез**

| Критерий | Статистика | Распределение | Применение |
|----------|------------|---------------|------------|
| Z | `(X̄−μ₀)/(σ/√n)` | N(0,1) | среднее, σ известна |
| t | `(X̄−μ₀)/(S/√n)` | t(n−1) | среднее, σ неизвестна |
| χ² согласия | `Σ(O−E)²/E` | χ²(k−m−1) | проверка распределения |
| χ² независимости | `Σ(O−E)²/E` | χ²((r-1)(c-1)) | связь категорий |
