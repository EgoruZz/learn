**C. СЛУЧАЙНЫЕ ВЕЛИЧИНЫ И ИХ РАСПРЕДЕЛЕНИЯ**

> **Архитектура:** `RandomVariables` (c.cpp) — наследует `MeasureTheoreticProb` (b.cpp). Вводит определение случайной величины через измеримые отображения, функцию распределения, классификацию вероятностных мер (дискретные, абсолютно непрерывные, сингулярные), основные дискретные распределения (Бернулли, биномиальное, Пуассон, геометрическое, гипергеометрическое), основные непрерывные распределения (равномерное, нормальное, экспоненциальное, хи-квадрат, Стьюдента) и метод преобразования случайных величин. Все последующие разделы (математическое ожидание, многомерные распределения и т.д.) строятся на этих распределениях как на базовых примерах.
>
> **Связи:** σ-алгебры и измеримость — `prob-and-stats/b` (B); функция распределения связана с вероятностной мерой через теорему о взаимно-однозначном соответствии; биномиальное распределение — продолжение схемы Бернулли из `prob-and-stats/a` (F); нормальное распределение — центральное в предельных теоремах (раздел G); экспоненциальное распределение связано с Пуассоновским процессом; метод преобразования используется в генерации случайных чисел (`math/number-theory/` — конгруэнентный генератор); характеристическая функция — инструмент доказательства предельных теорем (раздел G).

# **A. ОПРЕДЕЛЕНИЕ СЛУЧАЙНОЙ ВЕЛИЧИНЫ**

## **1. Формальное определение**

### **1.1. Случайная величина как измеримое отображение**
* **Определение:** случайная величина `ξ: (Ω, F, P) → (ℝ, B(ℝ))` — отображение, при котором прообраз любого борелевского множества является событием (принадлежит σ-алгебре `F`)
* **Измеримость:** для любого `B ∈ B(ℝ)`: `ξ⁻¹(B) = {ω ∈ Ω : ξ(ω) ∈ B} ∈ F`
* **Эквивалентный критерий:** `ξ` — случайная величина ⟺ `F_ξ(x) = P(ξ ≤ x) ∈ F` для всех `x ∈ ℝ` (измеримость функции распределения)

### **1.2. Интуиция**
* Случайная величина — это «число, которое станет известно после эксперимента»
* До эксперимента: `ξ` — функция на `Ω`; после: `ξ(ω)` — конкретное число
* Пример: `ξ(ω) = число орлов при броске n монет`; `Ω = {H,T}ⁿ`

### **1.3. Простые случайные величины**
* **Определение:** `ξ` называется простой, если принимает конечное число значений: `ξ = Σᵢ₌₁ⁿ aᵢ · 𝟙_{Aᵢ}`, где `Aᵢ` — несовместные события, `aᵢ` — числа
* **Теорема о приближении:** любая неотрицательная случайная величина `ξ ≥ 0` является пределом возрастающей последовательности простых случайных величин `ξₙ ↑ ξ`
* **Значение:** интеграл Лебега (и математическое ожидание) определяется через простые случайные величины

---

# **B. ДЕЙСТВИЯ НАД СЛУЧАЙНЫМИ ВЕЛИЧИНАМИ**

## **1. Борелевские функции**

### **1.1. Определение**
* **Борелевская функция:** непрерывная (или более общо — измеримая) функция `g: ℝ → ℝ`
* **Теорема:** если `ξ` — случайная величина и `g` — борелевская, то `g(ξ)` — тоже случайная величина
* **Доказательство:** для любого `B ∈ B(ℝ)`: `(g(ξ))⁻¹(B) = ξ⁻¹(g⁻¹(B)) ∈ F`, так как `g⁻¹(B) ∈ B(ℝ)` и `ξ` измерима

### **1.2. Примеры**
* Полиномы: `ξ²`, `3ξ + 1`, `ξ³ − 2ξ`
* Экспонента: `e^ξ`, логарифм `ln(ξ)` (при `ξ > 0`)
* Модуль: `|ξ|`, максимум `max(ξ, a)`, минимум `min(ξ, a)`
* Индикатор: `𝟙_{ξ > a}` — случайная величина Бернулли

## **2. Арифметические операции**

### **2.1. Линейная комбинация**
* Если `ξ, η` — случайные величины и `a, b` — константы, то `aξ + bη` — случайная величина
* **Следствие:** сумма `ξ + η`, разность `ξ − η`, произведение `ξ · η` — случайные величины

### **2.2. Частные случаи**
* `ξ/η` — случайная величина при `P(η = 0) = 0`
* `max(ξ, η)`, `min(ξ, η)`, `|ξ|` — случайные величины

## **3. Пределы и sup/inf**

### **3.1. Верхние и нижние пределы**
* `supₙ ξₙ`, `infₙ ξₙ` — случайные величины (если `ξₙ` — случайные)
* `lim supₙ ξₙ = infₙ sup_{k≥n} ξₖ`, `lim infₙ ξₙ = supₙ inf_{k≥n} ξₖ`

### **3.2. Сходимость по распределению**
* Если `Fₙ(x) → F(x)` во всех точках непрерывности `F`, то `ξₙ →^{d} ξ`
* **Критерий Перро:** `ξₙ →^{d} ξ` ⟺ `E[g(ξₙ)] → E[g(ξ)]` для всех непрерывных ограниченных `g`

# **C. ФУНКЦИЯ РАСПРЕДЕЛЕНИЯ**

## **1. Определение и свойства**

### **1.1. Функция распределения**
* **Определение:** `F_ξ(x) = P(ξ ≤ x)` — функция распределения случайной величины `ξ`
* **Свойства:**
    * Монотонно неубывающая: `x₁ ≤ x₂` ⟹ `F(x₁) ≤ F(x₂)`
    * Правая непрерывность: `F(x+) = F(x)` (предел справа равен значению)
    * Граничные условия: `F(−∞) = 0`, `F(+∞) = 1`
    * Вероятность интервала: `P(a < ξ ≤ b) = F(b) − F(a)`
    * Точечная вероятность: `P(ξ = a) = F(a) − F(a−)` (разрыв слева)

### **1.2. Теорема о взаимно-однозначном соответствии**
* Между функциями распределения и вероятными мерами на `(ℝ, B(ℝ))` существует взаимно-однозначное соответствие
* Каждой вероятной мере на `ℝ` соответствует единственная функция распределения (правая непрерывная, монотонная, с граничными условиями)
* Каждой такой функции распределения соответствует единственная вероятностная мера

---

# **D. КЛАССИФИКАЦИЯ ВЕРОЯТНОСТНЫХ МЕР**

## **1. Дискретные случайные величины**

### **1.1. Определение**
* `ξ` принимает счётное число значений `x₁, x₂, ...` с вероятностями `pᵢ = P(ξ = xᵢ)`
* **Функция распределения:** `F(x) = Σ_{xᵢ ≤ x} pᵢ` — ступенчатая функция (с разрывами в точках `xᵢ`)
* **Нормировка:** `Σᵢ pᵢ = 1`

### **1.2. Плотность вероятности (дискретный случай)**
* В терминах дельта-функции: `f(x) = Σᵢ pᵢ · δ(x − xᵢ)` (если нужна единая запись)

## **2. Абсолютно непрерывные случайные величины**

### **2.1. Определение**
* Существует функция `f(x) ≥ 0` (плотность вероятности) такая, что:
    * `F(x) = ∫₋∞ˣ f(t) dt` — функция распределения
    * `∫₋∞^∞ f(x) dx = 1` (нормировка)
* **Свойства:**
    * Вероятность одиночной точки: `P(ξ = a) = 0`
    * Вероятность интервала: `P(a < ξ < b) = P(a ≤ ξ < b) = P(a ≤ ξ ≤ b) = ∫ₐᵇ f(x) dx`
    * Непрерывность: `F(x)` непрерывна (для абсолютно непрерывных)

### **2.2. Связь с общей теорией**
* Абсолютно непрерывная мера: мера, Absolutely continuous относительно меры Лебега
* Теорема Радона-Никодима: `f(x) = dP/dx` — производная меры (плотность)

## **3. Сингулярные случайные величины**

### **3.1. Определение**
* Функция распределения непрерывна, но не абсолютно непрерывна (мера сингулярна относительно Лебега)
* **Пример:** распределение Кантора — непрерывная функция, растёт только на множестве Кантора (мера 0)

### **3.2. Разложение Лебега**
* Любая вероятностная мера唯一енно разлагается: `P = P_дискр + P_абс_непр + P_сингуляр`
* **Значение:** три типа исчерпывают все возможности

# **E. ДИСКРЕТНЫЕ РАСПРЕДЕЛЕНИЯ**

## **1. Распределение Бернулли `Ber(p)`**

### **1.1. Определение**
* `P(ξ = 1) = p`, `P(ξ = 0) = q = 1 − p`
* `E[ξ] = p`, `D[ξ] = pq`
* **Пример:** бросок одной монеты, исход «успех/неуспех»

## **2. Биномиальное распределение `B(n, p)`**

### **2.1. Определение**
* Число успехов в `n` независимых испытаниях Бернулли
* `P(ξ = k) = C(n, k) · pᵏ · qⁿ⁻ᵏ`, `k = 0, 1, ..., n`
* `E[ξ] = np`, `D[ξ] = npq`
* **Связь:** `B(1, p) = Ber(p)`; сумма `n` независимых `Ber(p)` даёт `B(n, p)`

### **2.2. Свойства**
* Мода: `⌊(n+1)p⌋`
* Асимметрия: `p < 0.5` — правый хвост; `p > 0.5` — левый; `p = 0.5` — симметричное
* Нормализация: `Σₖ₌₀ⁿ C(n,k) pᵏ qⁿ⁻ᵏ = (p + q)ⁿ = 1` (бином Ньютона)

## **3. Распределение Пуассона `Po(λ)`**

### **3.1. Определение**
* `P(ξ = k) = λᵏ e⁻λ / k!`, `k = 0, 1, 2, ...`
* `E[ξ] = λ`, `D[ξ] = λ` (среднее = дисперсия)
* **Предельный случай:** `B(n, p) → Po(λ)` при `n → ∞`, `p → 0`, `np = λ`

### **3.2. Свойства**
* Суперпозиция: `Po(λ₁) + Po(λ₂) ~ Po(λ₁ + λ₂)` (сумма независимых)
* Разделение: если `X ~ Po(λ₁ + λ₂)` и `Y ~ Po(λ₁)`, то `X − Y | X + Y = n ~ B(n, λ₁/(λ₁+λ₂))`
* Без последствий: время между событиями ~ `Exp(λ)`

## **4. Геометрическое распределение `Geom(p)`**

### **4.1. Определение**
* Число испытаний до первого успеха: `P(ξ = k) = (1−p)ᵏ⁻¹ · p`, `k = 1, 2, ...`
* `E[ξ] = 1/p`, `D[ξ] = (1−p)/p²`
* **Свойство без последствий:** `P(ξ > s+t | ξ > s) = P(ξ > t)` — «прошлое не влияет на будущее»

### **4.2. Связь с другими распределениями**
* `P(ξ > k) = (1−p)ᵏ` — функция выживания
* Сумма `n` независимых `Geom(p)` ~ `NB(n, p)` (отрицательное биномиальное)

## **5. Гипергеометрическое распределение `Hg(N, K, n)`**

### **5.1. Определение**
* Выборка **без возвращения** из `N` объектов, `K` из которых — «успехи»
* `P(ξ = k) = C(K, k) · C(N−K, n−k) / C(N, n)`
* `E[ξ] = nK/N`, `D[ξ] = n · (K/N) · (1 − K/N) · (N−n)/(N−1)`

### **5.2. Связь с биномиальным**
* При `n << N`: `Hg(N, K, n)` приближается `B(n, K/N)` (выборка с возвращением)

# **F. НЕПРЕРЫВНЫЕ РАСПРЕДЕЛЕНИЯ**

## **1. Равномерное распределение `U(a, b)`**

### **1.1. Определение**
* Плотность: `f(x) = 1/(b−a)` для `x ∈ [a, b]`, иначе `0`
* Функция распределения: `F(x) = (x−a)/(b−a)` для `x ∈ [a, b]`
* `E[ξ] = (a+b)/2`, `D[ξ] = (b−a)²/12`

### **1.2. Свойства**
* Максимальная энтропия среди распределений на `[a, b]` (наибольшая неопределённость)
* Метод квантилей: `Y = a + (b−a) · U` при `U ~ U(0,1)` → генерация `U(a, b)`

## **2. Нормальное (гауссово) распределение `N(μ, σ²)`**

### **2.1. Определение**
* Плотность: `f(x) = (1/(σ√(2π))) · exp{−(x−μ)²/(2σ²)}`
* Стандартное: `N(0, 1)`, `Φ(x)` — функция стандартного нормального распределения
* Стандартизация: `Z = (ξ − μ)/σ ~ N(0, 1)`

### **2.2. Свойства**
* Симметрия относительно `μ`: `f(μ + x) = f(μ − x)`
* `3σ`-правило: `P(|ξ − μ| < 3σ) ≈ 0.997`
* Линейная комбинация: `aξ + bη ~ N(aμ_ξ + bμ_η, a²σ²_ξ + b²σ²_η)` (при независимости)
* **Центральная роль:** предельное распределение для сумм многих малых воздействий (ЦПТ)

### **2.3. Стандартная нормальная `Φ(x)`**
* `Φ(x) = (1/√(2π)) ∫₋∞ˣ e^{−t²/2} dt`
* `Φ(0) = 0.5`, `Φ(1) ≈ 0.8413`, `Φ(2) ≈ 0.9772`, `Φ(3) ≈ 0.9987`
* Симметрия: `Φ(−x) = 1 − Φ(x)`
* Приближение: `Φ(x) ≈ 0.5 · (1 + erf(x/√2))`

## **3. Показательное (экспоненциальное) распределение `Exp(λ)`**

### **3.1. Определение**
* Плотность: `f(x) = λ e^{−λx}` для `x ≥ 0`, иначе `0`
* Функция распределения: `F(x) = 1 − e^{−λx}`
* `E[ξ] = 1/λ`, `D[ξ] = 1/λ²`

### **3.2. Свойство без последствий**
* `P(ξ > s+t | ξ > s) = P(ξ > t)` — «прошлое не влияет на будущее»
* **Единственное** непрерывное распределение с этим свойством
* Интерпретация: время ожидания следующего события в Пуассоновском процессе

### **3.3. Связь с Пуассоном**
* Число событий в интервале длины `t` ~ `Po(λt)`
* Время между событиями ~ `Exp(λ)`
* Сумма `n` независимых `Exp(λ)` ~ `Erlang(n, λ)` (гамма-распределение)

## **4. Распределение хи-квадрат `χ²(k)`**

### **4.1. Определение**
* Сумма квадратов `k` независимых стандартных нормальных: `ξ = Z₁² + ... + Zₖ²`
* `E[ξ] = k`, `D[ξ] = 2k`
* **Применение:** тесты согласия, доверительные интервалы для дисперсии

### **4.2. Свойства**
* Аддитивность: `χ²(k₁) + χ²(k₂) ~ χ²(k₁ + k₂)` (при независимости)
* Связь с гамма-распределением: `χ²(k) = Gamma(k/2, 1/2)`

## **5. Распределение Стьюдента `t(k)`**

### **5.1. Определение**
* `t = Z / √(χ²(k)/k)`, где `Z ~ N(0, 1)`, `χ²(k)` — хи-квадрат с `k` степенями свободы
* Плотность: `f(t) ∝ (1 + t²/k)^{−(k+1)/2}`

### **5.2. Свойства**
* Симметрично относительно 0
* При `k → ∞`: `t(k) → N(0, 1)` (нормальное распределение)
* **Применение:** малые выборки, проверка гипотез о среднем при неизвестной дисперсии

## **6. Распределение Фишера `F(k₁, k₂)`**

### **6.1. Определение**
* `F = (χ²(k₁)/k₁) / (χ²(k₂)/k₂)`, где числитель и знаменатель независимы
* **Применение:** ANOVA, сравнение дисперсий

# **G. МЕТОД ПРЕОБРАЗОВАНИЯ (ФУНКЦИИ РАСПРЕДЕЛЕНИЯ)**

## **1. Линейное преобразование**

### **1.1. Формула**
* `Y = aξ + b` при `a > 0`: `F_Y(y) = F_ξ((y−b)/a)`
* При `a < 0`: `F_Y(y) = 1 − F_ξ((y−b)/a)`

### **1.2. Стандартизация**
* `Z = (ξ − μ)/σ ~ N(0, 1)` при `ξ ~ N(μ, σ²)`
* **Применение:** приведение к стандартному виду для использования таблиц

## **2. Метод квантилей (инверсия)**

### **2.1. Формула**
* `Y = F⁻¹(U)`, `U ~ U(0,1)` → `Y` имеет распределение `F`
* **Требование:** `F` непрерывная и строго возрастающая (для единственности)

### **2.2. Применение**
* Генерация случайных величин с произвольным распределением
* Генерация `Exp(λ)`: `Y = −ln(U)/λ`
* Генерация `N(0,1)`: метод Бокса-Мюллера или обратная функция `Φ⁻¹`

## **3. Метод рёбер (acceptance-rejection)**

### **3.1. Идея**
* Генерируем `X` из «обёртывающего» распределения `g(x)` с плотностью `g(x)`
* Принимаем `X` с вероятностью `f(x)/(M·g(x))`, где `M = sup f(x)/g(x)`
* Принятое `X` имеет плотность `f(x)`

### **3.2. Эффективность**
* Вероятность принятия: `1/M`
* При `f ≈ g` (обёртка плотная): высокая эффективность

# **H. ДОПОЛНИТЕЛЬНЫЕ СВОЙСТВА И СВЯЗИ**

## **1. Моментная порождающая функция (MGF)**

### **1.1. Определение**
* `M_ξ(t) = E[e^{tξ}]` (существует в окрестности нуля)
* **Свойства:** `M(0) = 1`, `E[ξᵏ] = M⁽ᵏ⁾(0)` (производная в нуле)

### **1.2. Для основных распределений**
* `Ber(p)`: `M(t) = q + p·eᵗ`
* `B(n, p)`: `M(t) = (q + p·eᵗ)ⁿ`
* `Po(λ)`: `M(t) = exp{λ(eᵗ − 1)}`
* `N(μ, σ²)`: `M(t) = exp{μt + σ²t²/2}`
* `Exp(λ)`: `M(t) = λ/(λ − t)` при `t < λ`

### **1.3. Суммы независимых**
* `M_{ξ+η}(t) = M_ξ(t) · M_η(t)` (при независимости)
* **Применение:** доказательство вида распределения суммы (напр., `B(n,p) + B(m,p) = B(n+m,p)`)

## **2. Характеристическая функция**

### **2.1. Определение**
* `φ_ξ(t) = E[e^{itξ}]` — всегда существует (ограничена)
* **Уникальность:** двух распределений с одинаковой характеристикой совпадают

### **2.2. Для основных распределений**
* `N(μ, σ²)`: `φ(t) = exp{itμ − σ²t²/2}`
* `Po(λ)`: `φ(t) = exp{λ(e^{it} − 1)}`

## **3. Связь распределений (сводная таблица)**

| Сумма | Результат | При условиях |
|-------|-----------|--------------|
| `Ber(p) + Ber(p)` | `B(2, p)` | независимые |
| `B(n,p) + B(m,p)` | `B(n+m, p)` | одинаковые `p` |
| `Po(λ₁) + Po(λ₂)` | `Po(λ₁ + λ₂)` | независимые |
| `N(μ₁,σ₁²) + N(μ₂,σ₂²)` | `N(μ₁+μ₂, σ₁²+σ₂²)` | независимые |
| `Exp(λ₁) + Exp(λ₂)` | `Gamma(2, λ)` | одинаковые `λ` |
| `χ²(k₁) + χ²(k₂)` | `χ²(k₁ + k₂)` | независимые |

## **4. Связь с предельными теоремами**

* `B(n, p) → N(np, npq)` при `n → ∞` (ЦПТ для биномиального)
* `Po(λ) → N(λ, λ)` при `λ → ∞` (нормальная аппроксимация Пуассона)
* `t(k) → N(0, 1)` при `k → ∞` (нормальное при больших степенях свободы)
* `χ²(k) → N(k, 2k)` при `k → ∞` (ЦПТ для суммы квадратов)
