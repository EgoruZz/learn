**A. ОСНОВЫ ТЕОРИИ ВЕРОЯТНОСТЕЙ (КЛАССИЧЕСКАЯ ПАРАДИГМА)**

> **Архитектура:** `ProbabilityBasics` (a.cpp) — базовый класс всей ветки prob-and-stats. Вводит фундаментальные понятия: пространство элементарных исходов, события, вероятность, условная вероятность, формула Байеса, схему повторных испытаний (Бернулли, Лапласа, Пуассона). Все последующие разделы (аксиоматика, случайные величины, матожидание и т.д.) строятся на этих примитивах. Собственной сложной арифметики не имеет; переиспользует стандартные контейнеры STL и математические функции `<cmath>`.
>
> **Связи:** комбинаторные подсчёты ( C(n,k) для формулы Бернулли ) — `math/combinatorics/`;.factorials и биномиальные коэффициенты — `math/number-theory/`; вероятностные структуры данных (Bloom filter, Count-Min Sketch) — `hashing.md`; случайные графы — `graph.md` (K); вероятностные методы в ДП — `dynamic.md`; неравенства (Маркова, Чебышёва) — раздел F этой же ветки.

# **A. КЛАССИЧЕСКОЕ ОПРЕДЕЛЕНИЕ ВЕРОЯТНОСТИ**

## **1. Пространство элементарных исходов**

### **1.1. Эксперимент и исходы**
* **Эксперимент:** процесс, результат которого не может быть предсказан заранее (бросок `n` костей, выбор карты из колоды, измерение температуры)
* **Элементарный исход (outcome):** один конкретный результат эксперимента; обозначение `ω ∈ Ω`
* **Пространство элементарных исходов `Ω`:** множество **всех** неделимых результатов эксперимента
    * Конечное: `Ω = {ω₁, ω₂, ..., ωₙ}`, `|Ω| = n` — конечное число исходов
    * Счётное: `Ω = {ω₁, ω₂, ...}` — бесконечное, но счётное
    * Непрерывное: `Ω = [a, b]` или `ℝⁿ` — несчётное
* **Свойства `Ω`:**
    * `Ω ≠ ∅` (пустое пространство исходов невозможно)
    * Исходы **взаимно несовместны:** в результате эксперимента реализуется ровно один `ω`
    * Исходы **полны:** каждый возможный результат описан некоторым `ω ∈ Ω`

### **1.2. События**
* **Событие `A`:** подмножество `A ⊆ Ω` — «произошёл один из исходов, принадлежащих `A`»
* **Элементарное событие:** событие, содержащее ровно один исход: `A = {ωᵢ}`
* **Достоверное событие:** `Ω` — происходит всегда
* **Невозможное событие:** `∅` — никогда не происходит
* **Совместные события:** `A ∩ B ≠ ∅` — существуют исходы, принадлежащие обоим
* **Несовместные события:** `A ∩ B = ∅` — не могут произойти одновременно
* **Противоположные события:** `Ā = Ω \ A` — «`A` не произошло»

## **2. Аксиомы вероятности (Лаплас)**

### **2.1. Классическое определение**
* **Равновозможные исходы:** если нет оснований считать одни исходы более вероятными, чем другие, все `ω ∈ Ω` равновозможны
* **Формула Лапласа:** `P(A) = |A| / |Ω|` — отношение числа благоприятных исходов к общему числу
* **Условие применимости:** `Ω` конечно и все исходы равновозможны

### **2.2. Свойства вероятности**
* `0 ≤ P(A) ≤ 1` для любого события `A`
* `P(Ω) = 1` — достоверное событие
* `P(∅) = 0` — невозможное событие
* `P(Ā) = 1 − P(A)` — вероятность дополнения

## **3. Теоремы сложения вероятностей**

### **3.1. Для несовместных событий**
* **Формула:** если `A ∩ B = ∅`, то `P(A ∪ B) = P(A) + P(B)`
* **Обобщение на `n` несовместных событий:** `P(A₁ ∪ ... ∪ Aₙ) = Σᵢ₌₁ⁿ P(Aᵢ)`
* **Следствие:** `P(Ω) = 1` ⟹ `Σᵢ₌₁ⁿ P({ωᵢ}) = 1` (сумма вероятностей всех элементарных исходов)

### **3.2. Для совместных событий**
* **Формула включений-исключений (2 события):** `P(A ∪ B) = P(A) + P(B) − P(A ∩ B)`
* **Интерпретация:** при подсчёте `P(A) + P(B)` пересечение `A ∩ B` считается дважды — вычитаем один раз
* **Для `n` событий (общая формула):**

```
P(A₁ ∪ ... ∪ Aₙ) = Σᵢ P(Aᵢ) − Σᵢ<ⱼ P(Aᵢ ∩ Aⱼ) + Σᵢ<ⱼ<ₖ P(Aᵢ ∩ Aⱼ ∩ Aₖ) − ... + (−1)ⁿ⁺¹ P(A₁ ∩ ... ∩ Aₙ)
```

* **Применение:** подсчёт вероятности «хотя бы одного события»; задачи о рюкзаках, раскрасках, покрытиях

### **3.3. Формула для `n` несовместных событий, покрывающих `Ω`**
* Если `A₁, ..., Aₙ` попарно несовместны и `A₁ ∪ ... ∪ Aₙ = Ω`, то `Σᵢ₌₁ⁿ P(Aᵢ) = 1`
* **Пример:** `P(A) + P(Ā) = 1` (частный случай `n = 2`)

# **B. ЗАДАЧА О ДНЯХ РОЖДЕНИЯ**

## **1. Формулировка**

### **1.1. Задача**
* Из `n` людей вероятность того, что у **хотя бы двоих** совпадает день рождения (при `k` днях в году)
* Предположения: все `k` дней равновозможны; дни рождения людей **независимы**

### **1.2. Решение через дополнение**
* `P(совпадение) = 1 − P(все дни различны)`
* `P(все дни различны) = k/k · (k−1)/k · (k−2)/k · ... · (k−n+1)/k = k! / ((k−n)! · kⁿ)`
* **Формула:** `P(совпадение) = 1 − ∏ᵢ₌₀ⁿ⁻¹ (k − i)/k = 1 − k!/((k − n)! · kⁿ)`

### **1.3. Асимптотика при `n << k`**
* При `n << k`: `ln(P(все различны)) ≈ −n(n−1)/(2k)`
* **Приближение:** `P(совпадение) ≈ 1 − e^{−n(n−1)/(2k)}`
* **Парадокс:** при `k = 365` уже `n = 23` даёт `P > 0.5`; при `n = 50` — `P > 0.97`

## **2. Обобщения**

### **2.1. Обобщение на произвольные распределения**
* Пусть `X₁, ..., Xₙ` — н.о.р. с функциями распределения `F₁, ..., Fₙ`
* `P(есть совпадение) ≥ 1 − ∏ᵢ₌₂ⁿ (1 − Fᵢ(X₍₁₎))` (неравенство Чанга-Левина)
* **Следствие:** даже при неоднородном распределении дней вероятность совпадения быстро растёт

### **2.2. Применение в криптографии (коллизии хеш-функций)**
* **Парадокс дня рождения в хешировании:** при `n ≈ 2^{h/2}` случайных элементов вероятность коллизии `≈ 0.5` (для хеш-функции с `2ʰ` возможными значениями)
* **Атака дня рождения:** поиск коллизии за `O(2^{h/2})` вместо полного перебора `O(2ʰ)`
* **Связь:** эта же задача о днях рождения, но `k = 2ʰ`, `n` — число хешируемых элементов

# **C. ГЕОМЕТРИЧЕСКИЕ ВЕРОЯТНОСТИ**

## **1. Определение**

### **1.1. Геометрическая вероятность**
* **Идея:** если пространство исходов `Ω` — область в `ℝⁿ` с конечной мерой `μ(Ω)`, а событие `A ⊆ Ω` — подобласть, то `P(A) = μ(A) / μ(Ω)`
* **Мера `μ`:** длина (в `ℝ`), площадь (в `ℝ²`), объём (в `ℝ³`)
* **Условие:** все точки пространства равновозможны

### **1.2. Задача о встрече**
* **Условия:** два человека приходят в случайный момент времени в интервале `[0, T]`; каждый ждёт не дольше `t` минут
* **Решение:** `P(встреча) = 1 − (1 − t/T)²` при `t ≤ T`
* **Геометрическая интерпретация:** квадрат `[0, T]²` — возможные моменты прихода; «встреча» — область `|x − y| ≤ t`; площадь вычета = 2 треугольника со стороной `T − t`

## **2. Парадокс Бер特朗а**

### **2.1. Формулировка**
* **Задача:** какова вероятность, что случайная хорда круга длиннее стороны вписанного треугольника?
* **Три метода выбора хорды (три «разумных» ответа):**
    1. **Случайные концы на окружности:** два случайных угла `α, β ∈ [0, 2π)`; `P = 1/3`
    2. **Случайный радиус + случайная точка:** выбрать радиус, затем случайную точку на нём; `P = 1/2`
    3. **Случайная середина хорды:** случайная точка внутри круга; `P = 1/4`

### **2.2. Разбор парадокса**
* **Причина:** неоднозначность «случайной хорды» — разные методы генерации дают разные распределения
* **Вывод:** понятие «равновозможных исходов» в непрерывном случае зависит от выбора метода параметризации
* **Связь:** в классическом определении Лапласа `Ω` конечное и исходы **по определению** равновозможны; в геометрическом случае равновозможность определяется выбором меры

## **3. Задача Монти-Холла**

### **3.1. Формулировка**
* Три двери: за одной — приз, за двумя — козы
* Игрок выбирает дверь; ведущий (знающий, где приз) открывает **другую** пустую дверь
* **Вопрос:** стоит ли менять выбор?

### **3.2. Решение**
* **При смене:** `P(выигрыш) = 2/3` (выигрывает, если первоначально выбрал козу)
* **Без смены:** `P(выигрыш) = 1/3`
* **Формальное:** `P(приз за дверью A | ведущий открыл B) = ...` через формулу Байеса

### **3.3. Условная вероятность (подробно)**
* Пусть игрок выбрал дверь 1; ведущий открыл дверь 3
* `P(приз за 1 | открыл 3) = P(открыл 3 | приз за 1) · P(приз за 1) / P(открыл 3)`
* `P(открыл 3 | приз за 1) = 1/2` (равноверно между 2 и 3)
* `P(открыл 3 | приз за 2) = 1` (обязан открыть 3)
* `P(открыл 3 | приз за 3) = 0` (не может открыть дверь с призом)
* `P(открыл 3) = Σᵢ P(открыл 3 | приз за i) · P(приз за i) = 1/2 · 1/3 + 1 · 1/3 + 0 · 1/3 = 1/2`
* `P(приз за 1 | открыл 3) = (1/2 · 1/3) / (1/2) = 1/3`
* `P(приз за 2 | открыл 3) = (1 · 1/3) / (1/2) = 2/3`

# **D. ЗАДАЧА О МОНЕТАХ И СИММЕТРИЯ**

## **1. Вероятностное пространство для бросков**

### **1.1. Пространство исходов**
* `n` бросков честной монеты: `Ω = {H, T}ⁿ`, `|Ω| = 2ⁿ`
* Каждый элемент `ω = (ω₁, ..., ωₙ)`, `ωᵢ ∈ {H, T}`
* Вероятность конкретного исхода: `P({ω}) = 1/2ⁿ` (равновозможные исходы)

### **1.2. События как подмножества**
* «Ровно `k` орлов»: `Aₖ = {ω ∈ Ω : |{i : ωᵢ = H}| = k}`, `|Aₖ| = C(n, k)`
* `P(Aₖ) = C(n, k) / 2ⁿ` — биномиальное распределение `B(n, 1/2)`

## **2. Серии подряд орлов**

### **2.1. Задача**
* Вероятность появления серии из `r` подряд орлов в `n` бросках
* **Рекуррентное соотношение:** `p(n, r)` — вероятность серии длины `r` в первых `n` бросках
* `p(n, r) = p(n−1, r) + (1 − p(n−r−1, r)) · (1/2)^r` при `n > r`
* **Начальные условия:** `p(i, r) = 0` для `i < r`, `p(r, r) = 1/2^r`

### **2.2. Асимптотика**
* При `n >> r`: `E[число серий] ≈ (n − r + 1)/2^r`
* **Вероятность хотя бы одной серии:** `P ≥ 1 − e^{−(n−r+1)/2^r}` (неравенство Бонферрони)

# **E. УСЛОВНАЯ ВЕРОЯТНОСТЬ И ФОРМУЛА БАЙЕСА**

## **1. Условная вероятность**

### **1.1. Определение**
* **Условная вероятность события `A` при условии `B`:**
    ```
    P(A|B) = P(A ∩ B) / P(B),    при P(B) > 0
    ```
* **Интуиция:** «знаю, что `B` произошло» — сужаем пространство исходов до `B`; вероятность `A` пересчитывается относительно нового пространства
* **Альтернативное определение:** `P(A|B)` — единственная вероятность, удовлетворяющая аксиомам вероятности на `B`

### **1.2. Свойства**
* `P(A|B) ≥ 0`, `P(B|B) = 1`, `P(∅|B) = 0`
* `P(A₁ ∪ A₂ | B) = P(A₁|B) + P(A₂|B) − P(A₁ ∩ A₂ | B)` (формула включений-исключений для условных)
* `P(A|B) = 1 − P(Ā|B)` — дополнение

## **2. Теоремы умножения вероятностей**

### **2.1. Для зависимых событий**
* `P(A ∩ B) = P(A) · P(B|A) = P(B) · P(A|B)`
* **Общая формула для `n` событий:**
    ```
    P(A₁ ∩ A₂ ∩ ... ∩ Aₙ) = P(A₁) · P(A₂|A₁) · P(A₃|A₁ ∩ A₂) · ... · P(Aₙ|A₁ ∩ ... ∩ Aₙ₋₁)
    ```
* **Применение:** вычисление вероятности цепочки зависимых событий (последовательные броски, марковские цепи)

### **2.2. Для независимых событий**
* **Определение независимости:** `A` и `B` независимы ⟺ `P(A ∩ B) = P(A) · P(B)`
* **Эквивалентно:** `P(A|B) = P(A)` (при `P(B) > 0`) — «знание о `B` не влияет на `A`»
* **Попарная и совокупная независимость:** попарная независимость **не** эквивалентна независимости всех событий в совокупности

## **3. Формула полной вероятности**

### **3.1. Формулировка**
* Пусть `B₁, B₂, ..., Bₘ` — полная группа несовместных событий: `Bᵢ ∩ Bⱼ = ∅` при `i ≠ j`, `B₁ ∪ ... ∪ Bₘ = Ω`
* Тогда для **любого** события `A`:
    ```
    P(A) = Σⱼ₌₁ᵐ P(Bⱼ) · P(A|Bⱼ)
    ```
* **Интуиция:** разбиение события `A` по «причинам» `Bⱼ`; вероятность `A` — взвешенная сумма условных вероятностей

### **3.2. Применение**
* **Задача о двух фабриках:** фабрика 1 производит `α`% продукции с вероятностью брака `p₁`, фабрика 2 — `(1−α)`% с браком `p₂`; вероятность брака: `P(брак) = α·p₁ + (1−α)·p₂`
* **Рекурсивные схемы:** вероятность достижения состояния через промежуточные

## **4. Формула Байеса**

### **4.1. Формулировка**
* Из формулы умножения: `P(Bⱼ|A) = P(A|Bⱼ) · P(Bⱼ) / P(A)`
* Подставляя формулу полной вероятности:
    ```
    P(Bⱼ|A) = P(A|Bⱼ) · P(Bⱼ) / Σᵢ P(A|Bᵢ) · P(Bᵢ)
    ```
* **Терминология:**
    * `P(Bⱼ)` — **априорная вероятность** (до наблюдения `A`)
    * `P(A|Bⱼ)` — **правдоподобие** (likelihood)
    * `P(Bⱼ|A)` — **апостериорная вероятность** (после наблюдения `A`)

### **4.2. Интерпретация**
* Байесовская инверсия: из `P(причина|следствие)` → `P(следствие|причина)`
* Каждое новое наблюдение `A` обновляет наши знания о причине `Bⱼ`

### **4.3. Применения**
* **Медицинская диагностика:** `P(болезнь|симптом) = P(симптом|болезнь) · P(болезнь) / P(симптом)`
* **Спам-фильтры:** `P(спам|слово) ∝ P(слово|спам) · P(спам)` (Наивный Байесовский классификатор)
* **Байесовская классификация:** выбор класса `c* = argmax_c P(c) · ∏ᵢ P(xᵢ|c)`
* **Обновление убеждений:** последовательное применение формулы Байеса — основа байесовского вывода

### **4.4. Теорема о полной вероятности как частный случай Байеса**
* При `m = 2` и `B₂ = B̄₁`: `P(B₁|A) = P(A|B₁)P(B₁) / (P(A|B₁)P(B₁) + P(A|B̄₁)P(B̄₁))`

# **F. СХЕМА ПОВТОРНЫХ ИСПЫТАНИЙ**

## **1. Испытания Бернулли**

### **1.1. Определение**
* **Испытание Бернулли:** эксперимент с двумя исходами: «успех» (вероятность `p`) и «неуспех» (`q = 1 − p`, `0 < p < 1`)
* **Схема Бернулли:** `n` **независимых** испытаний Бернулли
* **Случайная величина `Sₙ`:** число успехов в `n` испытаниях; `Sₙ ~ B(n, p)` (биномиальное распределение)

### **1.2. Формула Бернулли**
* **Вероятность ровно `k` успехов:**
    ```
    P(Sₙ = k) = C(n, k) · pᵏ · qⁿ⁻ᵏ,    k = 0, 1, ..., n
    ```
* **Доказательство:** конкретная последовательность из `k` успехов и `n−k` неуспехов имеет вероятность `pᵏ · qⁿ⁻ᵏ`; таких последовательностей `C(n, k)` (выбор позиций успехов)

### **1.3. Свойства `B(n, p)`**
* `E[Sₙ] = np` — математическое ожидание
* `D[Sₙ] = npq` — дисперсия
* Мода: `⌊(n+1)p⌋` (или два значения при `(n+1)p` — целое)
* Нормализация: `Σₖ₌₀ⁿ C(n,k) pᵏ qⁿ⁻ᵏ = (p + q)ⁿ = 1` (бином Ньютона)

## **2. Локальная теорема Лапласа**

### **2.1. Формулировка**
* При `n → ∞`, `p` фиксировано, `0 < p < 1`:
    ```
    P(Sₙ = k) ≈ (1/√(2πnpq)) · exp{−(k − np)² / (2npq)}
    ```
* где `k` — целое число, `|k − np| = o(n^{2/3})` (в окрестности среднего)

### **2.2. Интерпретация**
* Биномиальное распределение приближается нормальным `N(np, npq)`
* **Стандартизация:** `x = (k − np)/√(npq)` → `P(Sₙ = k) ≈ (1/√(npq)) · φ(x)`, где `φ(x) = e^{−x²/2}/√(2π)`
* Биномиальные вероятности «подчиняются колоколообразной кривой» вокруг `np`

## **3. Интегральная теорема Лапласа**

### **3.1. Формулировка**
* При `n → ∞`:
    ```
    P(a ≤ Sₙ ≤ b) ≈ Φ((b − np)/√(npq)) − Φ((a − np)/√(npq))
    ```
    где `Φ(x) = (1/√(2π)) ∫₋∞ˣ e^{−t²/2} dt` — функция стандартного нормального распределения

### **3.2. Поправка Уisoftа (continuity correction)**
* При переходе от дискретного `Sₙ` к непрерывному `N(np, npq)`:
    ```
    P(Sₙ ≤ k) ≈ Φ((k + 0.5 − np)/√(npq))
    ```
* **Интуиция:** дискретная переменная `Sₙ = k` «занимает» интервал `[k − 0.5, k + 0.5]`

### **3.3. Вычисление `Φ(x)`**
* Приближение: `Φ(x) ≈ 0.5 · (1 + erf(x/√2))`, где `erf` — функция ошибок
* Табличные значения: `Φ(0) = 0.5`, `Φ(1) ≈ 0.8413`, `Φ(2) ≈ 0.9772`, `Φ(3) ≈ 0.9987`
* **Правило `3σ`:** `P(|Sₙ − np| < 3√(npq)) ≈ 0.997` — вероятность отклонения не более чем на 3 стандартных отклонения

## **4. Предельная теорема Пуассона**

### **4.1. Формулировка**
* При `n → ∞`, `p → 0`, `np = λ` (фиксировано):
    ```
    P(Sₙ = k) → λᵏ · e⁻λ / k!,    k = 0, 1, 2, ...
    ```
* **Распределение Пуассона `Po(λ)`:** дискретное распределение на `{0, 1, 2, ...}` с параметром `λ > 0`

### **4.2. Интерпретация**
* **Редкие события:** много испытаний (`n` велико), каждое с малой вероятностью (`p` мало), но число событий `λ = np` конечно
* **Примеры:** число звонков в час, число опечаток на странице, число аварий на перекрёстке

### **4.3. Свойства `Po(λ)`**
* `P(X = k) = λᵏ e⁻λ / k!`, `k = 0, 1, 2, ...`
* `E[X] = λ`, `D[X] = λ` (среднее = дисперсия)
* **Суперпозиция:** `Po(λ₁) + Po(λ₂) ~ Po(λ₁ + λ₂)` (сумма независимых Пуассоновых)
* **Связь с биномиальным:** `B(n, p) → Po(np)` при `n → ∞`, `p → 0`, `np = λ`
* **Связь с экспоненциальным:** время между событиями в Пуассоновском процессе ~ `Exp(λ)`

### **4.4. Приближение биномиального через Пуассон**
* При `n ≥ 20`, `p ≤ 0.05`, `np ≤ 10`: `P(Sₙ = k) ≈ e^{−np} · (np)^k / k!`
* **Вычислительное преимущество:** формула Пуассона не требует вычисления `C(n, k)` и больших степеней

## **5. Сравнение трёх подходов**

| Подход | Условия | Формула | Точность |
|--------|---------|---------|----------|
| Точный (Бернулли) | всегда | `C(n,k) p^k q^{n-k}` | точная |
| Лаплас (локальная) | `n` велико, `p` фиксировано | `(1/√(2πnpq)) e^{−x²/2}` | хорошая при `n ≥ 30` |
| Пуассон | `n` велико, `p` мало | `λ^k e^{-λ}/k!` | хорошая при `np ≤ 10` |
| Лаплас (интегральная) | `n` велико | `Φ(b) − Φ(a)` | хорошая для интервалов |
