# **A. МЕТОДЫ МОНТЕ-КАРЛО**

## **1. Общая схема**

### **1.1. Оценка интеграла**
* `I = integral g(x)f(x)dx = E_f[g(X)]` при `X ~ f`
* MC-оценка: `I_hat = (1/n) sum_i g(X_i)`, `X_i ~ f`
* Сходимость: `|I_hat - I| = O_p(1/sqrt(n))`

### **1.2. Оценка вероятностей**
* `P(A) = E[1_A]` -> `P_hat(A) = (1/n) sum 1_A(X_i)` = доля попаданий в A

## **2. Оценка числа pi**

### **2.1. Метод**
* Генерируем `n` случайных точек `(x, y)` в `[0,1]^2`
* `pi ~ 4 * (число точек с x^2 + y^2 <= 1) / n`
* **Сходимость:** ошибка `O(1/sqrt(n))`

## **3. Интегрирование Монте-Карло**

### **3.1. Простейшая оценка**
* `I = integral_a^b f(x) dx = (b-a) * E[f(X)]`, `X ~ U(a,b)`
* `I_hat = (b-a)/n * sum f(X_i)`

### **3.2. Методы ускорения**
* **Importance Sampling:** `I = E[f(X)/g(X)]` при плотности `g` вместо равномерной
* **Antithetic variables:** используем пары `(X, 1-X)` для уменьшения дисперсии
* **Control variates:** `I_hat_cv = I_hat - c*(J_hat - E[J])`, где `J` — известный интеграл
* **Stratified Sampling:** разбиение области на страты, MC внутри каждой

## **4. Демонстрация сходимости**
* Число бросков `n` -> оценка `pi_hat`
* График `|pi_hat - pi|` vs `n` показывает `1/sqrt(n)` спад

# **B. РАНДОМИЗИРОВАННЫЕ АЛГОРИТМЫ**

## **1. Три класса**

### **1.1. Las Vegas**
* Всегда даёт **правильный** ответ
* Время работы **случайное** (но `E[время]` конечна)
* Пример: QuickSelect с рандомизированным опорным -> `E[T] = O(n)`

### **1.2. Monte Carlo**
* Время работы **фиксированное**
* Ответ **правильный с вероятностью** `>= 1 - epsilon`
* Пример: тест Миллера-Рабина (проверка простоты, вероятность ложного `1/4^k`)

### **1.3. Sherwood**
* Правильный ответ с вероятностью `>= 1/2`
* Среди детерминированных алгоритмов есть "плохие" входы; Sherwood устраняет зависимость от входа

## **2. Сравнение**

| Класс | Ответ | Время |
|-------|-------|-------|
| Las Vegas | точный | случайное |
| Monte Carlo | прибл. | фиксированное |
| Sherwood | точный с p>=1/2 | случайное |

# **C. СЛУЧАЙНЫЕ БЛУЖДАНИЯ**

## **1. На Z**

### **1.1. Определение**
* `S_n = X_1 + ... + X_n`, где `X_i = +1` с вероятностью `p`, `-1` с `q = 1-p`

### **1.2. Возвратность**
* `p = 1/2` (симметричное): возвратно при `d = 1, 2` (возвращается в 0 almost surely)
* `d >= 3`: **не** возвратное (вероятность возврата < 1)

## **2. PageRank**

### **2.1. Формула**
* `PR(v) = (1-d)/n + d * sum_{u->v} PR(u)/deg(u)`
* `d ~ 0.85` — коэффициент затухания (дamping factor)
* **Интерпретация:** вероятность нахождения на странице v при случайном блуждании по ссылкам

### **2.2. Вычисление**
* Power method: итеративное умножение на матрицу переходов
* Сходимость: экспоненциальная при эргодичности графа

# **D. ЭВРИСТИЧЕСКИЕ МЕТОДЫ ОПТИМИЗАЦИИ**

## **1. Имитация отжига (Simulated Annealing)**

### **1.1. Алгоритм**
* Текущее решение `x`; температура `T(k)`
* Новое решение `x'`: если `E(x') < E(x)` -> принимаем; иначе с вероятностью `exp(-(E(x')-E(x))/T(k))`
* Температурный график: `T(k) -> 0` при `k -> infinity`

### **1.2. Свойства**
* Гарантия сходимости к глобальному оптимуму при `T -> 0` медленно
* На практике: быстрое "замораживание" -> хорошее, но не гарантированно оптимальное решение

# **E. ВЕРОЯТНОСТНЫЙ МЕТОД В КОМБИНАТОРИКЕ**

## **1. Метод ожидания**

### **1.1. Идея**
* `X` = число объектов с нужным свойством
* Если `E[X] > 0`, то существует хотя бы один объект (свойство `X > 0`)
* Даже `E[X] = epsilon > 0` достаточно!

### **1.2. Пример**
* Доказательство существования 2-раскраски с малым числом монochromatic клик

## **2. Лемма Ловаса (Lovász Local Lemma)**

### **2.1. Формулировка**
* События `A_1, ..., A_n`, каждое с `P(A_i) <= p`
* Каждое `A_i` независимо от всех `A_j`, кроме не более `d` других
* Если `ep(d+1) <= 1`, то `P(все A_i не произошли) > 0`

### **2.2. Применение**
* Раскраски графов (существование без коллизий)
* SAT (сatisfiability)
* Расстановки с ограничениями

# **F. ПРИЛОЖЕНИЯ В DATA SCIENCE**

## **1. Бутстрап (Bootstrap)**

### **1.1. Метод**
* Из выборки `x_1, ..., x_n` генерируем `B` бутстрап-выборок (с возвращением)
* Для каждой считаем статистику `theta*_b`
* Распределение `theta*` приближает распределение `theta`

### **1.2. Применение**
* Доверительные интервалы (без предположений о распределении)
* Оценка стандартной ошибки

## **2. A/B тестирование**

### **2.1. Постановка**
* `H_0: mu_A = mu_B` vs `H_1: mu_A != mu_B`
* Z-тест: `Z = (X_A - X_B) / sqrt(S_A^2/n_A + S_B^2/n_B)`

### **2.2. Размер выборки**
* `n = (z_{alpha/2} + z_beta)^2 * 2*sigma^2 / delta^2`
* `delta` = минимальный обнаруживаемый эффект

## **3. MLE в Machine Learning**

### **3.1. Логистическая регрессия**
* `P(y=1|x) = sigmoid(w . x) = 1 / (1 + exp(-w.x))`
* Loss: negative log-likelihood = `-sum [y_i * log(p_i) + (1-y_i) * log(1-p_i)]`

### **3.2. Нейронные сети**
* Функция потерь (cross-entropy) = оценка правдоподобия
* Backpropagation = градиентный спуск на负 log-likelihood
