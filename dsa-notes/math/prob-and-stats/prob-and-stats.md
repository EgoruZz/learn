## **A. ОСНОВЫ ТЕОРИИ ВЕРОЯТНОСТЕЙ (КЛАССИЧЕСКАЯ ПАРАДИГМА)**
> `a/a.md` · `a/a.cpp` · `struct ProbabilityBasics` — базовый класс всей ветки prob-and-stats

### **A. Классическое определение вероятности**
*   **Элементарные исходы и события:**
    *   Пространство элементарных исходов `Ω = {ω₁, ω₂, ..., ωₙ}` — множество всех неделимых результатов эксперимента
    *   Элементарное событие: `A = {ωᵢ}` — один конкретный исход
    *   Событие: `A ⊆ Ω` — произвольное подмножество пространства исходов
    *   Вероятность равновозможного события: `P(A) = |A| / |Ω|` (классическое определение Лапласа)
    *   Свойства: `0 ≤ P(A) ≤ 1`, `P(Ω) = 1`, `P(∅) = 0`
*   **Совместные и несовместные события:**
    *   Несовместные события: `A ∩ B = ∅` → `P(A ∪ B) = P(A) + P(B)`
    *   Совместные события: `P(A ∪ B) = P(A) + P(B) − P(A ∩ B)` (формула включений-исключений для двух событий)
    *   Формула для `n` событий: `P(A₁ ∪ ... ∪ Aₙ) = Σᵢ P(Aᵢ) − Σᵢ<ⱼ P(Aᵢ ∩ Aⱼ) + ... + (−1)ⁿ⁺¹ P(A₁ ∩ ... ∩ Aₙ)`
*   **Дополнение события:**
    *   `P(Ā) = 1 − P(A)` — вероятность события, противоположного `A`
    *   Полная группа событий: `A₁, A₂, ..., Aₙ` попарно несовместны и `A₁ ∪ ... ∪ Aₙ = Ω` → `Σᵢ P(Aᵢ) = 1`

### **B. Задача о днях рождения**
*   **Формулировка:** из `n` людей вероятность того, что у двоих совпадает день рождения (при `k` днях в году):
    *   `P(совпадение) = 1 − (1 − 1/k)(1 − 2/k)...(1 − (n−1)/k) = 1 − k!/((k−n)! · kⁿ)`
*   **Приближение:** при `n << k`: `P ≈ 1 − e^{−n(n−1)/(2k)}`
*   **Парадокс дней рождения:** при `n = 23` (k = 365) `P > 0.5`; при `n = 50` `P > 0.97`
*   **Обобщение на произвольные распределения:** неравенство для вероятности совпадения при неоднородном распределении дней

### **C. Геометрические вероятности**
*   **Определение:** вероятность определяется как отношение «благоприятной» меры (длины, площади, объёма) к общей мере пространства
*   **Задача о встрече:** два человека приходят в интервале `[0, T]`; каждый ждёт `t` минут. Вероятность встречи: `P = 1 − (1 − t/T)²`
*   **Задача о хорде:** вероятность, что случайная хорда длиннее стороны вписанного треугольника (парадокс Бер特朗а — три «разумных» ответа в зависимости от метода выбора)
*   **Задача Монти-Холла:** три двери, одна с призом; после открытия пустой двери — смена выбора увеличивает шанс до `2/3`

### **D. Задача о монетах и симметрия**
*   **Задание вероятностного пространства для бросков:** `Ω = {H, T}ⁿ`, `|Ω| = 2ⁿ`
*   **Последовательные броски:** вероятность серии из `k` подряд орлов в `n` бросках (рекуррентное соотношение или включение-исключение)

### **E. Условная вероятность и формула Байеса**
*   **Условная вероятность:**
    *   Определение: `P(A|B) = P(A ∩ B) / P(B)`, при `P(B) > 0`
    *   Интерпретация: «знаю, что `B` произошло» — сужение пространства исходов до `B`
*   **Теоремы умножения вероятностей:**
    *   Зависимые события: `P(A ∩ B) = P(A) · P(B|A) = P(B) · P(A|B)`
    *   Независимые события: `P(A ∩ B) = P(A) · P(B)` (частный случай, `P(B|A) = P(B)`)
    *   Общая формула для `n` событий: `P(A₁ ∩ ... ∩ Aₙ) = P(A₁) · P(A₂|A₁) · ... · P(Aₙ|A₁ ∩ ... ∩ Aₙ₋₁)`
*   **Формула полной вероятности:**
    *   Пусть `B₁, B₂, ..., Bₙ` — полная группа несовместных событий (`Σᵢ P(Bᵢ) = 1`, `Bᵢ ∩ Bⱼ = ∅`)
    *   Тогда для любого события `A`: `P(A) = Σᵢ P(Bᵢ) · P(A|Bᵢ)`
    *   Интерпретация: разбиение события `A` по «причинам» `Bᵢ`
*   **Формула Байеса (обратная вероятность):**
    *   `P(Bⱼ|A) = P(Bⱼ) · P(A|Bⱼ) / Σᵢ P(Bᵢ) · P(A|Bᵢ)` = `P(Bⱼ) · P(A|Bⱼ) / P(A)`
    *   Апостериорная вероятность = априорная × правдоподобие / нормировка
    *   Применение: медицинская диагностика, спам-фильтры, байесовская классификация

### **F. Схема повторных испытаний (испытания Бернулли)**
*   **Испытание Бернулли:** эксперимент с двумя исходами: «успех» (вероятность `p`) и «неуспех» (`q = 1 − p`)
*   **Формула Бернулли:** вероятность ровно `k` успехов в `n` независимых испытаниях:
    *   `P(Sₙ = k) = C(n, k) · pᵏ · qⁿ⁻ᵏ`, `k = 0, 1, ..., n`
    *   `Sₙ = X₁ + X₂ + ... + Xₙ`, где `Xᵢ ~ Bernoulli(p)`
*   **Локальная теорема Лапласа:**
    *   При `n → ∞`, `p` фиксировано: `P(Sₙ = k) ≈ (1/√(2πnpq)) · exp{−(k − np)² / (2npq)}`
    *   Интерпретация: биномиальное распределение приближается нормальным
*   **Интегральная теорема Лапласа:**
    *   `P(a ≤ Sₙ ≤ b) ≈ Φ((b − np)/√(npq)) − Φ((a − np)/√(npq))`
    *   Где `Φ(x)` — функция стандартного нормального распределения
    *   Поправка Уisoftа: `P(Sₙ ≤ k) ≈ Φ((k + 0.5 − np)/√(npq))`
*   **Предельная теорема Пуассона:**
    *   При `n → ∞`, `p → 0`, `np = λ` (фиксировано): `P(Sₙ = k) → λᵏ e⁻λ / k!`
    *   Интерпретация: редкие события в большом числе испытаний → распределение Пуассона

## **B. АКСИОМАТИЧЕСКОЕ ПОСТРОЕНИЕ ТЕОРИИ ВЕРОЯТНОСТЕЙ (КОЛМОГОРОВ)**
> `b/b.md` · `b/b.cpp` · `struct MeasureTheoreticProb : ProbabilityBasics`

### **A. Вероятностное пространство**
*   **Тройка Колмогорова `(Ω, F, P)`:**
    *   `Ω` — произвольное множество (пространство элементарных исходов)
    *   `F` — σ-алгебра (коллекция подмножеств `Ω`, замкнутая относительно дополнения и объединения счётного числа множеств)
    *   `P` — вероятностная мера: `P: F → [0, 1]`, `P(Ω) = 1`, σ-аддитивность
*   **Аksiомы Колмогорова:**
    1. `P(A) ≥ 0` для всех `A ∈ F`
    2. `P(Ω) = 1`
    3. Если `A₁, A₂, ...` попарно несовместны, то `P(∪ₙ Aₙ) = Σₙ P(Aₙ)` (σ-аддитивность)

### **B. σ-алгебры и алгебры множеств**
*   **Алгебра множеств:** замкнута относительно конечных объединений, пересечений, дополнений
*   **σ-алгебра:** замкнута относительно счётных объединений и пересечений
*   **Примеры:** `F` = все подмножества `Ω` (граничный случай); Borel-σ-алгебра `B(ℝ)`
*   **Порождённая σ-алгебра:** наименьшая σ-алгебра, содержащая заданную систему множеств; `σ({a, b}) = {∅, {a}, {b}, {a,b}}`

### **C. Вероятностная мера и её свойства**
*   **Свойства меры:**
    *   `P(∅) = 0`
    *   Монотонность: `A ⊆ B → P(A) ≤ P(B)`
    *   Субаддитивность: `P(A ∪ B) ≤ P(A) + P(B)` (неравенство Бонферрони)
    *   Непрерывность меры: `Aₙ ↑ A → P(Aₙ) → P(A)` и `Aₙ ↓ A → P(Aₙ) → P(A)`
*   **Последствие формулы включений-исключений:**
    *   Для счётного числа событий: `P(∪ₙ Aₙ) = Σₙ P(Aₙ) − Σₘ<ₙ P(Aₘ ∩ Aₙ) + ...`

### **E. Непрерывность вероятностной меры**
*   **Теорема о непрерывности меры:**
    *   Если `A₁ ⊆ A₂ ⊆ ...` (возрастающая последовательность), то `P(∪ₙ Aₙ) = lim_{n→∞} P(Aₙ)`
    *   Если `A₁ ⊇ A₂ ⊇ ...` (убывающая последовательность), то `P(∩ₙ Aₙ) = lim_{n→∞} P(Aₙ)`
    *   Следствие: вероятность предельного события определяется пределом вероятностей
*   **Связь с σ-аддитивностью:** непрерывность следствие σ-аддитивности (и обратно, при `P(Ω) < ∞`)

### **D. Системы множеств и продолжение меры**
*   **π-система:** замкнута относительно пересечений
*   **λ-система (dyadic):** содержит `Ω`, замкнута относительно дополнений и счётных несовместных объединений
*   **Теорема о π-λ:** если два вероятностных пространства совпадают на π-системе, порождающей σ-алгебру, то они совпадают на всей σ-алгебре
*   **Borel-σ-алгебра:** порождается отрезками `(a, b]` на `ℝ`; `B(ℝⁿ) = σ(промежутков)`
*   **Теорема Каратаодори:** продолжение предваренной меры на σ-алгебру — единственно

## **C. СЛУЧАЙНЫЕ ВЕЛИЧИНЫ И ИХ РАСПРЕДЕЛЕНИЯ** — complete
> `c/c.md` · `c/c.cpp` · `struct RandomVariables : MeasureTheoreticProb`

### **A. Определение случайной величины**
*   **Формальное определение:** случайная величина `ξ: (Ω, F, P) → (ℝ, B(ℝ))` — измеримое отображение пространства элементарных исходов в действительные числа
*   **Измеримость:** для любого `B ∈ B(ℝ)`: `ξ⁻¹(B) = {ω : ξ(ω) ∈ B} ∈ F`
*   **Эквивалентное определение:** `ξ` — случайная величина ⟺ `F(ξ) = {ω : ξ(ω) ≤ x} ∈ F` для всех `x ∈ ℝ`

### **B. Действия над случайными величинами**
*   **Борелевские функции:**
    *   Борелевская функция: непрерывная (или более общо — измеримая) функция `g: ℝ → ℝ`
    *   Если `ξ` — случайная величина и `g` — борелевская, то `g(ξ)` — тоже случайная величина
    *   Примеры: полиномы, экспонента, логарифм, максимум/минимум, модуль
*   **Арифметические операции:** если `ξ, η` — случайные величины, то `aξ + bη`, `ξ · η`, `ξ/η` (при `P(η=0)=0`), `max(ξ, η)`, `min(ξ, η)` — случайные величины
*   **Пределы и sup/inf:**
    *   `supₙ ξₙ`, `infₙ ξₙ` — случайные величины (если `ξₙ` — случайные)
    *   `lim supₙ ξₙ = infₙ sup_{k≥n} ξₙ`, `lim infₙ ξₙ = supₙ inf_{k≥n} ξₙ`
    *   Если `Fₙ(x) → F(x)` во всех точках непрерывности `F`, то `ξₙ →^{d} ξ`
*   **Теорема о приближении простыми случайными величинами:**
    *   Любая неотрицательная случайная величина `ξ ≥ 0` является пределом возрастающей последовательности простых случайных величин `ξₙ ↑ ξ`
    *   Любая случайная величина `ξ` является пределом последовательности простых случайных величин `|ξₙ| ↑ |ξ|`
    *   Следствие: интеграл Лебега определяется через простые случайные величины

### **B. Функция распределения**
*   **Определение:** `F_ξ(x) = P(ξ ≤ x)` — функция распределения случайной величины `ξ`
*   **Свойства:**
    *   Монотонно неубывающая
    *   Правая непрерывность: `F(x+) = F(x)`
    *   `F(−∞) = 0`, `F(+∞) = 1`
    *   `P(a < ξ ≤ b) = F(b) − F(a)`
    *   `P(ξ = a) = F(a) − F(a−)` — точечная вероятность
*   **Теорема:** между функциями распределения и вероятными мерами на `(ℝ, B(ℝ))` существует взаимно-однозначное соответствие

### **C. Классификация вероятностных мер**
*   **Дискретные случайные величины:**
    *   `ξ` принимает счётное число значений `x₁, x₂, ...` с вероятностями `pᵢ = P(ξ = xᵢ)`
    *   `F(x) = Σ_{xᵢ ≤ x} pᵢ` — ступенчатая функция
    *   Нормировка: `Σᵢ pᵢ = 1`
*   **Абсолютно непрерывные случайные величины:**
    *   Существует плотность `f(x) ≥ 0` такая, что `F(x) = ∫₋∞ˣ f(t) dt`
    *   `∫₋∞^∞ f(x) dx = 1` (нормировка)
    *   Вероятность одиночной точки: `P(ξ = a) = 0`
    *   `P(a < ξ < b) = P(a ≤ ξ < b) = P(a ≤ ξ ≤ b) = ∫ₐᵇ f(x) dx`
*   **Сингулярные случайные величины:**
    *   Функция распределения непрерывна, но не абсолютно непрерывна (фрактальное распределение Кантора)


### **D. Дискретные распределения**
*   **Биномиальное распределение `B(n, p)`:**
    *   `P(ξ = k) = C(n, k) · pᵏ · (1−p)ⁿ⁻ᵏ`, `k = 0, 1, ..., n`
    *   `E[ξ] = np`, `D[ξ] = np(1−p)`
    *   Применение: число успехов в `n` независимых испытаниях Бернулли
*   **Распределение Пуассона `Po(λ)`:**
    *   `P(ξ = k) = λᵏ e⁻λ / k!`, `k = 0, 1, 2, ...`
    *   `E[ξ] = λ`, `D[ξ] = λ`
    *   Предельный случай биномиального: `B(n, p)` при `n → ∞`, `p → 0`, `np = λ`
    *   Суперпозиция: сумма независимых `Po(λ₁) + Po(λ₂) ~ Po(λ₁ + λ₂)`
*   **Геометрическое распределение `Geom(p)`:**
    *   `P(ξ = k) = (1−p)ᵏ⁻¹ · p`, `k = 1, 2, ...` (число испытаний до первого успеха)
    *   `E[ξ] = 1/p`, `D[ξ] = (1−p)/p²`
    *   Свойство без последствий (memoryless): `P(ξ > s+t | ξ > s) = P(ξ > t)`
*   **Гипергеометрическое распределение `Hg(N, K, n)`:**
    *   `P(ξ = k) = C(K, k) · C(N−K, n−k) / C(N, n)`
    *   Выборка без возвращения из `N` объектов, `K` из которых — «успехи»
    *   Приближается биномиальному при `n << N`

### **E. Непрерывные распределения**
*   **Равномерное распределение `U(a, b)`:**
    *   Плотность: `f(x) = 1/(b−a)` для `x ∈ [a, b]`
    *   `F(x) = (x−a)/(b−a)`, `E[ξ] = (a+b)/2`, `D[ξ] = (b−a)²/12`
*   **Нормальное (гауссово) распределение `N(μ, σ²)`:**
    *   Плотность: `f(x) = (1/(σ√(2π))) · exp{−(x−μ)²/(2σ²)}`
    *   Стандартное: `N(0, 1)`, `Φ(x)` — функция Лапласа (нулевая)
    *   Стандартизация: `Z = (ξ − μ)/σ ~ N(0, 1)`
    *   `3σ`-правило: `P(|ξ − μ| < 3σ) ≈ 0.997`
    *   Свойство: линейная комбинация независимых нормальных — нормальная
*   **Показательное (экспоненциальное) распределение `Exp(λ)`:**
    *   Плотность: `f(x) = λ e^{−λx}` для `x ≥ 0`
    *   `E[ξ] = 1/λ`, `D[ξ] = 1/λ²`
    *   Свойство без последствий: `P(ξ > s+t | ξ > s) = P(ξ > t)`
    *   Связь с Пуассоном: время между событиями в Пуассоновском процессе ~ `Exp(λ)`
*   **Распределение хи-квадрат `χ²(k)`:**
    *   Сумма квадратов `k` независимых `N(0, 1)`: `ξ = Z₁² + ... + Zₖ²`
    *   `E[ξ] = k`, `D[ξ] = 2k`
    *   Применение: тесты согласия, доверительные интервалы для дисперсии
*   **Распределение Стьюдента `t(k)`:**
    *   `t = Z / √(χ²(k)/k)`, где `Z ~ N(0, 1)`, `χ²(k)` — хи-квадрат
    *   Применение: малые выборки, проверка гипотез о среднем

### **F. Метод преобразования (метод функции распределения)**
*   **Линейное преобразование:** `Y = aξ + b` → `F_Y(y) = F_ξ((y−b)/a)` (при `a > 0`)
*   **Метод квантилей:** `Y = F⁻¹(U)`, `U ~ U(0,1)` → генерация случайных величин с заданным распределением
*   **Метод рёбер (acceptance-rejection):** генерация из «обёртывающего» распределения с вероятностью принятия `f(x)/(M·g(x))`

## **D. МАТЕМАТИЧЕСКОЕ ОЖИДАНИЕ И СВОЙСТВА** — complete
> `d/d.md` · `d/d.cpp` · `struct Expectation : RandomVariables`

### **A. Построение математического ожидания**
*   **Для простых случайных величин:**
    *   `ξ = Σᵢ aᵢ · 𝟙_{Aᵢ}` (линейная комбинация индикаторных функций) → `E[ξ] = Σᵢ aᵢ · P(Aᵢ)`
    *   Дискретный случай: `E[ξ] = Σₖ xₖ · pₖ` (если ряд абсолютно сходится)
*   **Для неотрицательных случайных величин:**
    *   `E[ξ] = ∫₀^∞ P(ξ > t) dt` (формула через хвостовые вероятности)
    *   Приближение простыми: `ξₙ ↑ ξ` → `E[ξₙ] → E[ξ]` (теорема о монотонном пределе)
*   **Для произвольных случайных величин:**
    *   `E[ξ] = E[ξ⁺] − E[ξ⁻]`, где `ξ⁺ = max(ξ, 0)`, `ξ⁻ = max(−ξ, 0)` (разложение на положительную и отрицательную части)
    *   Сходство: `E[|ξ|] < ∞` (интегрируемость) → `E[ξ]` определено и конечно
*   **Интегральное определение (Лебега):** `E[ξ] = ∫_Ω ξ(ω) dP(ω)`

### **B. Свойства математического ожидания**
*   **Линейность:** `E[aξ + bη] = a·E[ξ] + b·E[η]` (всегда, даже для зависимых!)
*   **Вынос константы:** `E[c] = c` для любой константы `c`
*   **Сохранение порядка:** `ξ ≤ η` almost surely → `E[ξ] ≤ E[η]`
*   **Аддитивность:** для независимых `ξ, η`: `E[ξη] = E[ξ]·E[η]`
*   **Формула через индикаторы:** для события `A`: `E[𝟙_A] = P(A)`
*   **Итерированное математическое ожидание (формула полного математического ожидания):** `E[ξ] = E[E[ξ|η]]`
    *   Интерпретация: полное ожидание = вложенное условное ожидание, усреднённое по подраспределению
*   **Распределение неотрицательной случайной величины при нулевом среднем:**
    *   Если `ξ ≥ 0` и `E[ξ] = 0`, то `P(ξ = 0) = 1` (нетрицательная СВ с нулевым средним —initely concentrated в 0)
    *   Следствие: `E[|ξ|] = 0` ⟺ `P(ξ = 0) = 1`

### **C. Формулы подсчёта математических ожиданий**
*   **Для дискретных:** `E[g(ξ)] = Σₖ g(xₖ) · P(ξ = xₖ)`
*   **Для абсолютно непрерывных:** `E[g(ξ)] = ∫₋∞^∞ g(x) · f(x) dx`
*   **Подсчёт через функцию распределения:**
    *   Для неотрицательной `ξ`: `E[ξ] = ∫₀^∞ P(ξ > t) dt`
    *   Для `|ξ|`: `E[|ξ|] = ∫₀^∞ P(|ξ| > t) dt`
*   **Распределение случайной величины, порождённой σ-алгеброй:** `E[ξ|G]` —единственная `G`-измеримая случайная величина, интегрированная по условию `∫_A ξ dP = ∫_A E[ξ|G] dP` для всех `A ∈ G`

### **D. Медиана и квантили**
*   **Медиана:** `m` — число такое, что `P(ξ ≤ m) ≥ 1/2` и `P(ξ ≥ m) ≥ 1/2`
*   **Квантиль уровня `p`:** `q_p = inf{x : F(x) ≥ p}`
*   **Неравенство о медиане:** `P(|ξ − m| ≥ t) ≤ 1 − F(m + t) + F(m − t)` ≤ 2·min(P(ξ ≥ m + t), P(ξ ≤ m − t))

## **E. МНОГОМЕРНЫЕ РАСПРЕДЕЛЕНИЯ И НЕЗАВИСИМОСТЬ** — complete
> `e/e.md` · `e/e.cpp` · `struct MultivariateDistributions : Expectation`

### **A. Многомерные функции распределения**
*   **Совместная функция распределения:** `F(x₁, ..., xₙ) = P(ξ₁ ≤ x₁, ..., ξₙ ≤ xₙ)`
*   **Свойства:**
    *   Монотонность по каждому аргументу
    *   Правая непрерывность по каждому аргументу
    *   Граничные условия: `F(+∞, ..., +∞) = 1`, `F(−∞, x₂, ...) = 0`
*   **Совместная плотность:** `f(x₁, ..., xₙ) = ∂ⁿF/∂x₁...∂xₙ` (для абсолютно непрерывного случая)
    *   `P((ξ₁, ..., ξₙ) ∈ A) = ∫_A f(x₁, ..., xₙ) dx₁...dxₙ`
    *   `∫_{ℝⁿ} f(x₁, ..., xₙ) dx₁...dxₙ = 1`
*   **Теорема о взаимно-однозначном соответствии в `ℝⁿ`:**
    *   Между функциями распределения `F(x₁, ..., xₙ)` и вероятными мерами на `(ℝⁿ, B(ℝⁿ))` существует взаимно-однозначное соответствие
    *   Каждой мере на `ℝⁿ` соответствует единственная функция распределения (правая непрерывная, монотонная)
    *   Каждой такой функции распределения соответствует единственная вероятностная мера

### **B. Независимость случайных величин**
*   **Независимость событий:** `P(A ∩ B) = P(A) · P(B)`
*   **Независимость систем событий:** `σ(ξ₁, ..., ξₘ)` и `σ(ξₘ₊₁, ..., ξₙ)` — независимы
*   **Критерий независимости случайных величин:** `F(x₁, ..., xₙ) = F₁(x₁) · ... · Fₙ(xₙ)` для всех `x₁, ..., xₙ`
*   **Независимость = попарная + в совокупности:** попарная независимость **не** эквивалентна независимости в совокупности (пример: `A`, `B`, `A ∩ B` — попарно независимы, но не в совокупности)
*   **Лемма о независимости функций:** если `ξ₁, ..., ξₙ` независимы и `gᵢ` — измеримые, то `g₁(ξ₁), ..., gₙ(ξₙ)` независимы
*   **Формула для матожидания произведения:** `E[∏ᵢ gᵢ(ξᵢ)] = ∏ᵢ E[gᵢ(ξᵢ)]` при независимости
*   **Независимость бесконечного набора случайных величин:**
    *   Система случайных велиchin `{ξᵢ}_{i∈I}` независима, если для любого конечного подмножества `J ⊆ I` случайные величины `{ξⱼ}_{j∈J}` независимы
    *   Критерий: `P(ξᵢ ∈ Bᵢ, i ∈ J) = ∏_{i∈J} P(ξᵢ ∈ Bᵢ)` для всех конечных `J ⊆ I` и борелевских `Bᵢ`
    *   Следствие: характеристическая функция бесконечного набора — произведение характеристических функций

### **C. Совместные распределения и свёртки**
*   **Совместная плотность при независимости:** `f(x₁, ..., xₙ) = f₁(x₁) · ... · fₙ(xₙ)`
*   **Формула вычисления `E[g(ξ₁, ..., ξₙ)]`:**
    *   `E[g(ξ₁, ..., ξₙ)] = ∫ g(x₁, ..., xₙ) · f(x₁, ..., xₙ) dx₁...dxₙ`
*   **Формула свёртки плотности суммы независимых:** `(f₁ * f₂)(x) = ∫ f₁(t) · f₂(x − t) dt`
    *   `f_{ξ+η}(x) = ∫ f_ξ(t) · f_η(x − t) dt` для независимых `ξ, η`
*   **Сумма независимых распределений:**
    *   `B(n, p) + B(m, p) ~ B(n+m, p)`
    *   `Po(λ₁) + Po(λ₂) ~ Po(λ₁ + λ₂)`
    *   `N(μ₁, σ₁²) + N(μ₂, σ₂²) ~ N(μ₁+μ₂, σ₁²+σ₂²)`
    *   `Exp(λ₁) + Exp(λ₂)` — не экспоненциальное, но related (Erlang)

### **D. Условные распределения**
*   **Условная плотность:** `f(x|y) = f(x, y) / f_Y(y)` (при `f_Y(y) > 0`)
*   **Условное математическое ожидание:** `E[ξ|η = y] = ∫ x · f(x|y) dx`
*   **Формула полного математического ожидания:** `E[ξ] = ∫ E[ξ|η = y] · f_η(y) dy`
*   **Марковские цепи:** дискретные случайные величины с свойством `P(ξₙ₊₁|ξ₀, ..., ξₙ) = P(ξₙ₊₁|ξₙ)` (памяти нет предыдущего состояния)

## **F. ЧИСЛОВЫЕ ХАРАКТЕРИСТИКИ И НЕРАВЕНСТВА** — complete
> `f/f.md` · `f/f.cpp` · `struct NumericalCharacteristics : MultivariateDistributions`

### **A. Дисперсия и ковариация**
*   **Дисперсия:**
    *   `D[ξ] = E[(ξ − E[ξ])²] = E[ξ²] − (E[ξ])²`
    *   `D[c] = 0`, `D[aξ + b] = a² · D[ξ]`
    *   Для независимых: `D[ξ + η] = D[ξ] + D[η]`
    *   Для некоррелированных ( `ρ = 0` ): `D[ξ + η] = D[ξ] + D[η]`
    *   Стандартное отклонение: `σ = √D[ξ]`
*   **Ковариация:**
    *   `cov(ξ, η) = E[(ξ − E[ξ])(η − E[η])] = E[ξη] − E[ξ]·E[η]`
    *   `cov(ξ, ξ) = D[ξ]`
    *   Свойства: симметричность, линейность, `D[ξ + η] = D[ξ] + D[η] + 2·cov(ξ, η)`
*   **Корреляция:**
    *   `ρ(ξ, η) = cov(ξ, η) / (σ_ξ · σ_η)` — нормированная ковариация
    *   `|ρ| ≤ 1`; `ρ = 0` ↔ некоррелированные; `|ρ| = 1` ↔ линейная зависимость
*   **Матрица ковариаций (для случайного вектора `(ξ₁, ..., ξₙ)`):**
    *   `Σ[i][j] = cov(ξᵢ, ξⱼ)`
    *   Свойства: симметричность, неотрицательная определённость
    *   Собственные значения ковариационной матрицы → PCA (анализ главных компонент — `math/linear-algebra/`)

### **B. Моменты и центральные моменты**
*   **Момент `k`-го порядка:** `mₖ = E[ξᵏ]` (при существовании)
*   **Центральный момент `k`-го порядка:** `μₖ = E[(ξ − E[ξ])ᵏ]`
    *   `μ₁ = 0` (если существует)
    *   `μ₂ = D[ξ]` (дисперсия)
    *   `μ₃ / σ³` — коэффициент асимметрии (skewness)
    *   `μ₄ / σ⁴` — коэффициент эксцесса (excess kurtosis)
*   **Моментная порождающая функция (MGF):** `M(t) = E[e^{tξ}]`
    *   Свойства: `M(0) = 1`, `E[ξᵏ] = M⁽ᵏ⁾(0)` (производная в нуле)
    *   Сумма независимых: `M_{ξ+η}(t) = M_ξ(t) · M_η(t)`
*   **Характеристическая функция:** `φ(t) = E[e^{itξ}]` (существует всегда)
    *   Уникальность: двух распределений с одинаковой характеристической функцией совпадают

### **C. Неравенства**
*   **Неравенство Маркова:** `P(|ξ| ≥ ε) ≤ E[|ξ|ᵏ] / εᵏ` для любого `k ≥ 1`, `ε > 0`
*   **Неравенство Чебышева (случай `k = 2`):** `P(|ξ − E[ξ]| ≥ ε) ≤ D[ξ] / ε²`
*   **Неравенство Йенсена:** для выпуклой `φ`: `φ(E[ξ]) ≤ E[φ(ξ)]`
    *   Следствие: `(E[ξ])² ≤ E[ξ²]`, `|E[ξ]| ≤ E[|ξ|]`
*   **Неравенство Гёльдера:** `E[|XY|] ≤ (E[|X|ᵖ])^{1/p} · (E[|Y|ᵠ])^{1/ᵠ}`, `1/p + 1/ᵠ = 1`, `p ≥ 1`
*   **Неравенство Минковского:** `(E[|X+Y|ᵖ])^{1/p} ≤ (E[|X|ᵖ])^{1/p} + (E[|Y|ᵖ])^{1/p}` (аналог неравенства треугольника в `Lᵖ`)
*   **Неравенство Канторовича (для ковариационной матрицы):** связь собственных значений и среднего квадратичного отклонения

### **D. Корреляционные свойства**
*   **Некоррелированность ≠ независимость:** независимость → некоррелированность, но обратное неверно
*   **Некоррелированные + двумерно нормальные → независимые**
*   **Ранг корреляционной матрицы:** определяет размерность «ồnкого» подпространства

## **G. ПРЕДЕЛЬНЫЕ ТЕОРЕМЫ** — complete
> `g/g.md` · `g/g.cpp` · `struct LimitTheorems : NumericalCharacteristics`

### **A. Закон больших чисел (ЗБЧ)**
*   **Неравенство Чебышева (снова):** `P(|ξ̄ₙ − μ| ≥ ε) ≤ σ² / (nε²)` — слабое ЗБЧ
*   **Теорема Чебышева:** если `ξ₁, ξ₂, ...` попарно некоррелированы с одинаковым `μ` и `D[ξᵢ] ≤ C`, то `ξ̄ₙ → μ` по вероятности
*   **Теорема Бернулли (случай `D[ξᵢ] = p(1−p)`):** частота события `A` в `n` испытаниях сходится к `P(A)` по вероятности
*   **Формулировка:** `∀ε > 0: lim_{n→∞} P(|ξ̄ₙ − μ| < ε) = 1` (сходимость по вероятности)
*   **Сильное ЗБЧ (Колмогорова):** `P(lim_{n→∞} ξ̄ₙ = μ) = 1` (сходится почти наверное)

### **B. Центральная предельная теорема (ЦПТ)**
*   **Формулировка:** если `ξ₁, ξ₂, ...` — н.о.р. с `E[ξᵢ] = μ`, `D[ξᵢ] = σ²`, то
    *   `Sₙ = (Σᵢ₌₁ⁿ ξᵢ − nμ) / (σ√n) →^{d} N(0, 1)` (сходимость по распределению)
*   **Теорема Ляпунова:** обобщение на неодинаковые `ξᵢ` при выполнении условия Ляпунова: `Σ E[|ξᵢ − μᵢ|^{2+δ}] / (sₙ^{2+δ}) → 0`
*   **Приближение:** `P(Sₙ ≤ x) ≈ Φ(x)` при больших `n`
*   **Безусловная ЦПТ:** нетребование конечности дисперсии — строковая теорема Леви-Феллер

### **C. Нормальная аппроксимация**
*   **Биномиального распределения:** `B(n, p) → N(np, np(1−p))` при `np(1−p) ≥ 10`
*   **Поправка Уisoftа (continuity correction):** `P(ξ ≤ k) ≈ Φ((k + 0.5 − np) / √(np(1−p)))`
*   **Распределение Пуассона:** `Po(λ) → N(λ, λ)` при `λ ≥ 30`

### **D. Сходимость случайных величин**
*   **Сходимость по вероятности:** `∀ε > 0: P(|ξₙ − ξ| > ε) → 0`
*   **Сходимость почти наверное:** `P(lim_{n→∞} ξₙ = ξ) = 1`
*   **Сходимость по распределению:** `Fₙ(x) → F(x)` во всех точках непрерывности `F`
*   **Взаимосвязи:** almost sure → по вероятности → по распределению; обратное неверно
*   **Критерий Перро:** `ξₙ →^{d} ξ` ⟺ `E[g(ξₙ)] → E[g(ξ)]` для всех непрерывных ограниченных `g`

## **H. МАТЕМАТИЧЕСКАЯ СТАТИСТИКА** — complete
> `h/h.md` · `h/h.cpp` · `struct MathematicalStatistics : LimitTheorems`

### **A. Описательная статистика**
*   **Выборка:** `X₁, X₂, ..., Xₙ` — н.о.р. с распределением `F`
*   **Выборочное среднее:** `X̄ = (1/n) Σᵢ₌₁ⁿ Xᵢ` — оценка `E[X]`
*   **Выборочная дисперсия:** `S² = (1/(n−1)) Σᵢ₌₁ⁿ (Xᵢ − X̄)²` — несмещённая оценка `D[X]`
*   **Медиана:** `X_{(⌊(n+1)/2⌋)}` — устойчивая мера центра
*   **Мода:** значение с максимальной частотой
*   **Квантили:** выборочные квантили как оценки теоретических
*   **Межквартильный размах:** `IQR = Q₃ − Q₁`
*   **Коэффициент вариации:** `CV = S / X̄` (для сравнения изменчивости)
*   **Среднее геометрическое:** `G = (∏ᵢ₌₁ⁿ Xᵢ)^{1/n}` — всегда `G ≤ X̄` (среднее арифметическое); применим для положительных значений; логарифм геометрического среднего = среднее логарифмов
*   **Среднее гармоническое:** `H = n / Σᵢ₌₁ⁿ (1/Xᵢ)` — всегда `H ≤ G ≤ X̄`; применим для положительных значений; естественно для скоростей и отношений
*   **Среднее абсолютное отклонение:** `MAD = (1/n) Σᵢ₌₁ⁿ |Xᵢ − X̄|` — мера изменчивости, более устойчивая к выбросам, чем стандартное отклонение; связано с медианой: `MED = median(|Xᵢ − median(X)|)`

### **B. Статистические оценки**
*   **Свойства хороших оценок:**
    *   Несмещённость: `E[θ̂] = θ` для всех `θ`
    *   Эффективность: минимум дисперсии среди несмещённых (CRB — Cramér-Rao Bound)
    *   Консистентность: `θ̂ₙ →^{P} θ`
*   **Метод моментов:**
    *   Решаем систему: `E[ξᵏ] = (1/n) Σᵢ Xᵢᵏ` для `k = 1, ..., m` — выразить параметры
*   **Метод максимального правдоподобия (MLE):**
    *   Функция правдоподобия: `L(θ; x₁, ..., xₙ) = ∏ᵢ f(xᵢ; θ)`
    *   Логарифмическая функция правдоподобия: `ℓ(θ) = Σᵢ ln f(Xᵢ; θ)`
    *   Уравнение оценки: `dℓ/dθ = 0`
    *   Свойства MLE: согласованность, нормальная асимптотика `θ̂ ~ N(θ, 1/I(θ))`, где `I(θ)` — информация Фишера

### **C. Доверительные интервалы**
*   **Идея:** интервал `[θ̂₁, θ̂₂]` такой, что `P(θ ∈ [θ̂₁, θ̂₂]) ≥ 1 − α` (доверительная вероятность)
*   **Для среднего при известной дисперсии:** `X̄ ± z_{α/2} · σ/√n`
*   **Для среднего при неизвестной дисперсии:** `X̄ ± t_{α/2, n−1} · S/√n` (распределение Стьюдента)
*   **Для дисперсии:** `(n−1)S² / χ²_{α/2, n−1} ≤ σ² ≤ (n−1)S² / χ²_{1−α/2, n−1}`
*   **Для пропорции:** `p̂ ± z_{α/2} · √(p̂(1−p̂)/n)`

### **D. Проверка статистических гипотез**
*   **Нулевая и альтернативная гипотезы:** `H₀` vs `H₁`
*   **Критерий:** процедура принятия решения на основе выборки
*   **Ошибки:**
    *   Ошибка I рода (`α`): `P(отвергнуть H₀ | H₀ верна)` — ложное срабатывание
    *   Ошибка II рода (`β`): `P(принять H₀ | H₁ верна)` — пропуск цели
*   **Мощность критерия:** `1 − β = P(отвергнуть H₀ | H₁ верна)`
*   **p-value:** минимальный уровень значимости, при котором `H₀` отвергается
*   **Z-критерий (для среднего):** `Z = (X̄ − μ₀) / (σ/√n) ~ N(0, 1)`
*   **t-критерий Стьюдента:** `T = (X̄ − μ₀) / (S/√n) ~ t(n−1)`
*   **χ²-критерий согласия (Пирсон):** `χ² = Σᵢ (Oᵢ − Eᵢ)² / Eᵢ ~ χ²(k − m − 1)`
*   **χ²-критерий независимости:** проверка связи двух категориальных переменных

### **E. Статистические меры связи**
*   **Ранговая корреляция Спирмена:** `ρₛ = 1 − 6Σdᵢ² / (n(n²−1))` — монотонная связь
*   **Коэффициент Жаккара:** `J(A, B) = |A ∩ B| / |A ∪ B|` — схожесть множеств
*   **Энтропия:** `H(X) = −Σᵢ pᵢ · log₂ pᵢ` — мера неопределённости
*   **Взаимная информация:** `I(X; Y) = H(X) + H(Y) — H(X, Y)`
*   **Условная энтропия:** `H(X|Y) = H(X, Y) − H(Y)`

*   **Общая схема:** оценка интеграла `I = ∫g(x)f(x)dx` через среднее: `Î = (1/n) Σg(Xᵢ)`, `Xᵢ ~ f`

*   **Оценка числа `π`:** генерация `n` случайных точек в `[0,1]²`; `π ≈ 4 · (число точек внутри круга) / n`
*   **Интегрирование методом Монте-Карло:** оценка `I = ∫_a^b f(x) dx ≈ (b−a)/n · Σf(Xᵢ)`, `Xᵢ ~ U(a,b)`; сходимость `O(1/√n)`; ускорение через Important Sampling: `I = E[f(X)/g(X)]` при плотности `g`
*   **Тест Миллера-Рабина (проверка простоты)**
*   **Проверка равенства многочленов**
*   **Методы ускорения:**

### **B. Лас-Вегас алгоритмы**
*   **Лас-Вегас (Las Vegas):**
    *   Всегда даёт правильный ответ; время работы случайное
    *   Пример: случайный быстрый поиск медианы (QuickSelect с рандомизированным опорным)
    *   Ожидание: `O(n)` для поиска медианы через рандомизированный QuickSelect
*   **Шерри-Лас-Вегас (Sherwood):** правильный ответ с вероятностью `≥ 1/2`
*   **Сравнение:** LV ≥ MC ≥ Sherwood по «качеству» ответа

### **C. Вероятностные структуры данных**
* **A. Skip List**
    *   Определение: многоуровневые списки с вероятностными уровнями (монета `p = 1/2`)
    *   Операции: search/insert/delete, ожидаемая высота `O(log n)`
    *   Уровни: параметр вероятности `p` и максимальная высота (торговля память/скорость)
    *   Применение: упорядоченные множества в распределённых системах, конкурентные варианты (lock-free Skip List — ветка struct)
* **D. Reservoir Sampling**
    *   Равномерная выборка размера `k` из потока неизвестной длины (замена с вероятностью `k/i`)
    *   Обобщения: взвешенная выборка, выборка с приоритетами

### **D. Случайные блуждания (Random Walks)**
*   **На `ℤ`:** шаг `+1` или `−1` с вероятностью `p` и `q = 1−p`
    *   Возвратность: при `p = 1/2` — возвратное (возвращается в 0 almost surely при `d = 1, 2`)
    *   При `d ≥ 3` — не возвратное
*   **Марковские цепи:**
    *   Матрица переходов `P[i][j] = P(ξₙ₊₁ = j | ξₙ = i)`
    *   Стационарное распределение: `π = π·P` (собственный вектор матрицы `P`)
    *   Время смешивания: скорость сходимости к стационарному распределению
*   **PageRank:** `PR(v) = (1−d)/n + d · Σ_{u→v} PR(u)/deg(u)` — итеративный метод через power method

### **E. Эвристические методы оптимизации**
*   **Имитация отжига (Simulated Annealing):**
    *   Температурный график `T(k)`: принятие худшего решения с вероятностью `exp{−ΔE/T(k)}`
    *   Сходимость к глобальному оптимуму при `T → 0` ( «замораживание» )

### **F. Вероятностный метод в комбинаторике**
*   **Доказательство существования:**
    *   Если `E[число объектов] > 0`, то существует хотя бы один объект
    *   Пример: показать существование графа с `Δ ≤ k` через ожидание числа рёбер
*   **Лемма Ловаса (Lovász Local Lemma):**
    *   Если `P(Aᵢ) ≤ p` и `Σⱼ≠ᵢ P(Aᵢ ∩ Aⱼ) ≤ ep·(1−p)` (approximately), то события `Āᵢ`произойдут не произойдут
*   **Применение:** доказательство нижних границ, раскраски, паросочетания
*   **Ожидание и вероятность существования:**
    *   Метод: определить `X` — число объектов с нужным свойством → `P(X > 0) ≥ E[X] / max(X)`
    *   Если `E[X] > 0`, то существует хотя бы один объект
    *   Пример: вероятность существования регулярного графа, устойчивого паросочетания

### **G. Приложения в Data Science**
*   **Сэмплирование данных:** случайный выбор элементов из генеральной совокупности; простое случайное сэмплирование (SRS), стратифицированное, кластерное; сэмплирование с возвращением и без
*   **Бутстрап (Bootstrap):** повторная выборка из исходной выборки с возвращением → оценка распределения статистики
*   **A/B тестирование:**
    *   Гипотеза `H₀: μ_A = μ_B` vs `H₁: μ_A ≠ μ_B`
    *   Z-тест: `Z = (X̄_A − X̄_B) / √(S²_A/n_A + S²_B/n_B)`
    *   Размер выборки: `n = (z_{α/2} + z_β)² · 2σ² / δ²` (минимальный для заданной мощности)
*   **Метод максимального правдоподобия в Machine Learning:**
    *   Логистическая регрессия: `P(y=1|x) = σ(w·x)`, минимизация отрицательного логарифма правдоподобия
    *   Нейронные сети: функция потерь как оценка правдоподобия
