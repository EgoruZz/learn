# **A. ДИСПЕРСИЯ И КОВАРИАЦИЯ**

## **1. Дисперсия**

### **1.1. Определение**
* `D[ξ] = E[(ξ − E[ξ])²]` — дисперсия (второй центральный момент)
* Эквивалентная формула: `D[ξ] = E[ξ²] − (E[ξ])²`
* **Стандартное отклонение:** `σ = √D[ξ]` — имеет ту же размерность, что и `ξ`

### **1.2. Свойства**
* `D[c] = 0` для любой константы `c`
* `D[aξ + b] = a² · D[ξ]` (константа `b` не влияет на разброс)
* `D[ξ] ≥ 0` (неотрицательность, следствие невыпуклости квадрата)
* `D[ξ] = 0` ⟺ `P(ξ = E[ξ]) = 1` (детерминированная величина)

### **1.3. Дисперсия суммы**
* **Независимые:** `D[ξ + η] = D[ξ] + D[η]`
* **Некоррелированные (ρ=0):** `D[ξ + η] = D[ξ] + D[η]` (то же самое!)
* **Общий случай:** `D[ξ + η] = D[ξ] + D[η] + 2·cov(ξ, η)`
* **Обобщение:** `D[Σᵢ ξᵢ] = Σᵢ D[ξᵢ] + 2·Σᵢ<ⱼ cov(ξᵢ, ξⱼ)`

## **2. Ковариация**

### **2.1. Определение**
* `cov(ξ, η) = E[(ξ − E[ξ])(η − E[η])] = E[ξη] − E[ξ]·E[η]`
* `cov(ξ, ξ) = D[ξ]`

### **2.2. Свойства**
* Симметричность: `cov(ξ, η) = cov(η, ξ)`
* Линейность: `cov(aξ, bη) = ab · cov(ξ, η)`
* `cov(ξ + ζ, η) = cov(ξ, η) + cov(ζ, η)`
* `cov(ξ, c) = 0` для константы `c`
* `D[ξ + η] = D[ξ] + D[η] + 2·cov(ξ, η)` — ключевая связь

## **3. Корреляция**

### **3.1. Определение**
* `ρ(ξ, η) = cov(ξ, η) / (σ_ξ · σ_η)` — коэффициент корреляции Пирсона
* `|ρ| ≤ 1` (следствие неравенства Кёнига-Фишера)

### **3.2. Интерпретация**
* `ρ = 0` — **некоррелированные** (нет линейной связи)
* `|ρ| = 1` — **полная линейная зависимость:** `η = aξ + b`
* `0 < |ρ| < 1` — частичная линейная связь
* `ρ > 0` — прямая корреляция; `ρ < 0` — обратная

### **3.3. Важно**
* `ρ = 0` **не** означает независимость! (пример: `X ~ U(-1,1)`, `Y = X²`)
* `ρ = 0` означает только отсутствие **линейной** связи

## **4. Матрица ковариаций**

### **4.1. Определение**
* Для случайного вектора `X = (ξ₁, ..., ξₙ)`:
    * `Σ[i][j] = cov(ξᵢ, ξⱼ)`
    * `Σ[i][i] = D[ξᵢ]` — диагональные элементы
* **Свойства:**
    * Симметричность: `Σ = Σᵀ`
    * Неотрицательная определённость: `aᵀΣa ≥ 0` для любого `a ∈ ℝⁿ`

### **4.2. Ковариация линейных комбинаций**
* `cov(aᵀX, bᵀX) = aᵀΣb`

### **4.3. Связь с PCA**
* Собственные значения `Σ` → объяснённая дисперсия по каждой компоненте
* Собственные векторы → главные компоненты (направления максимального разброса)
* Связь: `math/linear-algebra/` (раздел «собственные значения»)

# **B. МОМЕНТЫ И ЦЕНТРАЛЬНЫЕ МОМЕНТЫ**

## **1. Моменты**

### **1.1. Момент k-го порядка**
* `mₖ = E[ξᵏ]` (при существовании)
* `m₁ = E[ξ]` — среднее

### **1.2. Центральный момент k-го порядка**
* `μₖ = E[(ξ − E[ξ])ᵏ]`
* `μ₁ = 0` (если существует)
* `μ₂ = D[ξ]` — дисперсия

### **1.3. Нормированные моменты**
* **Асимметрия (skewness):** `γ₁ = μ₃ / σ³`
    * `γ₁ = 0` — симметричное распределение
    * `γ₁ > 0` — правый хвост длиннее
    * `γ₁ < 0` — левый хвост длиннее
* **Эксцесс (excess kurtosis):** `γ₂ = μ₄ / σ⁴ − 3`
    * `γ₂ = 0` — как нормальное (мезокуртическое)
    * `γ₂ > 0` — более острый пик, тяжёлые хвосты (лептокуртическое)
    * `γ₂ < 0` — более плоский пик, лёгкие хвосты (платикуртическое)

## **2. Моментная порождающая функция (MGF)**

### **2.1. Определение**
* `M_ξ(t) = E[e^{tξ}]` — существует в окрестности `t = 0`
* **Свойства:**
    * `M(0) = 1`
    * `E[ξᵏ] = M⁽ᵏ⁾(0)` — k-й момент = k-я производная в нуле
    * Сумма независимых: `M_{ξ+η}(t) = M_ξ(t) · M_η(t)`

### **2.2. Для основных распределений**

| Распределение | MGF |
|---------------|-----|
| `Ber(p)` | `q + p·eᵗ` |
| `B(n, p)` | `(q + p·eᵗ)ⁿ` |
| `Po(λ)` | `exp{λ(eᵗ − 1)}` |
| `N(μ, σ²)` | `exp{μt + σ²t²/2}` |
| `Exp(λ)` | `λ/(λ − t)`, `t < λ` |
| `χ²(k)` | `(1 − 2t)^{-k/2}`, `t < 1/2` |

### **2.3. Применение**
* Доказательство вида распределения суммы (через произведение MGF)
* Вывод моментов через дифференцирование

## **3. Характеристическая функция**

### **3.1. Определение**
* `φ_ξ(t) = E[e^{itξ}]` — **всегда существует** (ограничена: `|φ(t)| ≤ 1`)
* Связь с MGF: `φ(t) = M(it)` (при существовании M)

### **3.2. Ключевые свойства**
* `φ(0) = 1`, `|φ(t)| ≤ 1`
* `φ(-t) = φ̄(t)` (конjugate)
* **Уникальность:** двух распределений с одинаковой φ совпадают
* `E[ξᵏ] = i⁻ᵏ · φ⁽ᵏ⁾(0)` (при существовании)

### **3.3. Для основных распределений**

| Распределение | φ(t) |
|---------------|------|
| `N(μ, σ²)` | `exp{itμ − σ²t²/2}` |
| `Po(λ)` | `exp{λ(e^{it} − 1)}` |
| `Exp(λ)` | `λ/(λ − it)` |

# **C. НЕРАВЕНСТВА**

## **1. Неравенство Маркова**

### **1.1. Формула**
* `P(|ξ| ≥ ε) ≤ E[|ξ|ᵏ] / εᵏ` для любого `k ≥ 1`, `ε > 0`
* **Доказательство:** `E[|ξ|ᵏ] = ∫|ξ|ᵏ dP ≥ ∫_{|ξ|≥ε} |ξ|ᵏ dP ≥ εᵏ · P(|ξ| ≥ ε)`

### **1.2. Применение**
* Грубая оценка вероятности отклонения без знания распределения
* Обобщение: `P(g(ξ) ≥ ε) ≤ E[g(ξ)] / ε` для неотрицательной `g`

## **2. Неравенство Чебышёва**

### **2.1. Формула (частный случай Маркова, k=2)**
* `P(|ξ − E[ξ]| ≥ ε) ≤ D[ξ] / ε²`
* Или: `P(|ξ − μ| < ε) ≥ 1 − σ²/ε²`

### **2.2. Интерпретация**
* Доля значений в интервале `[μ − kσ, μ + kσ]` ≥ `1 − 1/k²`
* `k = 2`: ≥ 75%; `k = 3`: ≥ 88.9%

## **3. Неравенство Йенсена**

### **3.1. Формула**
* Для выпуклой функции `φ`: `φ(E[ξ]) ≤ E[φ(ξ)]`
* Для выпуклой вниз (concave): `φ(E[ξ]) ≥ E[φ(ξ)]`

### **3.2. Следствия**
* `(E[ξ])² ≤ E[ξ²]` (выпуклость `x²`)
* `|E[ξ]| ≤ E[|ξ|]` (выпуклость `|x|`)
* `ln(E[ξ]) ≥ E[ln(ξ)]` для `ξ > 0` (выпуклость `ln x` вниз → неравенство в обратную сторону)

## **4. Неравенство Гёльдера**

### **4.1. Формула**
* `E[|XY|] ≤ (E[|X|ᵖ])^{1/p} · (E[|Y|ᵠ])^{1/ᵠ}`, где `1/p + 1/ᵠ = 1`, `p ≥ 1`
* **Частные случаи:**
    * `p = q = 2`: неравенство Коши-Буняковского: `|E[XY]| ≤ √(E[X²]·E[Y²])`
    * `p = 1, q = ∞`: `E[|XY|] ≤ E[|X|] · sup|Y|`

## **5. Неравенство Минковского**

### **5.1. Формула**
* `(E[|X+Y|ᵖ])^{1/p} ≤ (E[|X|ᵖ])^{1/p} + (E[|Y|ᵖ])^{1/p}`, `p ≥ 1`
* Аналог неравенства треугольника в пространстве `Lᵖ`

### **5.2. Связь с Гёльдером**
* Неравенство Минковского доказывается через Гёльдер

# **D. КОРРЕЛЯЦИОННЫЕ СВОЙСТВА**

## **1. Некоррелированность vs независимость**

### **1.1. Цепочка**
* `независимость` ⟹ `некоррелированность`
* Обратное **неверно** в общем случае

### **1.2. Контрпример**
* `X ~ U(-1, 1)`, `Y = X²`
* `E[X] = 0`, `E[XY] = E[X³] = 0` → `cov(X, Y) = 0` → `ρ = 0`
* Но `Y` полностью определяется `X` →极度 зависимы

## **2. Двумерно нормальное распределение**

### **2.1. Свойство**
* Для `(X, Y) ~ N(μ₁, μ₂, σ₁², σ₂², ρ)`:
    * `ρ = 0` ⟺ `X` и `Y` **независимы**
* **Единственный случай** когда некоррелированность ⟺ независимость (из классаulus распределений)

## **3. Ранг корреляционной матрицы**

### **3.1. Определение**
* `rank(Σ)` — ранг матрицы ковариаций
* Определяет **реальную размерность** данных (число «существенных» компонент)

### **3.2. Интерпретация**
* `rank = n` — все компоненты линейно независимы
* `rank < n` — есть линейные зависимости между компонентами
* **Связь:** собственные значения `Σ` → `rank` = число ненулевых собственных значений

# **E. СВОДНАЯ ТАБЛИЦА**

## **1. Основные формулы**

| Величина | Формула | Свойство |
|----------|---------|----------|
| Дисперсия | `D[ξ] = E[ξ²] − (E[ξ])²` | `≥ 0` |
| `D[aξ+b]` | `a²·D[ξ]` | константа `b` не влияет |
| `D[ξ+η]` | `D[ξ]+D[η]+2·cov(ξ,η)` | всегда |
| Ковариация | `cov(ξ,η) = E[ξη]−E[ξ]E[η]` | `= 0` для независимых |
| Корреляция | `ρ = cov/(σ_ξ·σ_η)` | `|ρ| ≤ 1` |

## **2. Неравенства**

| Неравенство | Формула | Когда |
|-------------|---------|-------|
| Марков | `P(\|ξ\|≥ε) ≤ E[\|ξ\|ᵏ]/εᵏ` | любое `k≥1` |
| Чебышёв | `P(\|ξ−μ\|≥ε) ≤ D[ξ]/ε²` | `k=2` |
| Йенсен | `φ(E[ξ]) ≤ E[φ(ξ)]` | `φ` выпуклая |
| Коши-Буняковский | `\|E[XY]\| ≤ √(E[X²]·E[Y²])` | `p=q=2` |
| Минковский | `\|X+Y\|_p ≤ \|X\|_p + \|Y\|_p` | `p ≥ 1` |
