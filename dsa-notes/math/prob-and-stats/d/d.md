**D. МАТЕМАТИЧЕСКОЕ ОЖИДАНИЕ И СВОЙСТВА**

> **Архитектура:** `Expectation` (d.cpp) — наследует `RandomVariables` (c.cpp). Построение математического ожидания для различных классов случайных величин (простых, неотрицательных, произвольных), интеграл Лебега, свойства (линейность, аддитивность, итерированное ожидание), формулы подсчёта через плотность, CDF и условные распределения, медиана и квантили. Все последующие разделы (многомерные распределения, числовые характеристики и т.д.) опираются на математическое ожидание как базовую операцию.
>
> **Связи:** случайные величины и распределения — `prob-and-stats/c`; условная вероятность и формула Байеса — `prob-and-stats/a` (E); σ-алгебры и условные ожидания — `prob-and-stats/b` (B); интеграл Лебега — `math/analysis/`; линейность ожидания используется повсюду (дисперсия, ковариация — раздел F; предельные теоремы — раздел G); формула через хвостовые вероятности связана с неравенствами Маркова и Чебышёва (раздел F).

# **A. ПОСТРОЕНИЕ МАТЕМАТИЧЕСКОГО ОЖИДАНИЯ**

## **1. Для простых случайных величин**

### **1.1. Определение**
* **Простая случайная величина:** `ξ = Σᵢ₌₁ⁿ aᵢ · 𝟙_{Aᵢ}`, где `Aᵢ` — попарно несовместные события, `∪ᵢ Aᵢ = Ω`
* **Математическое ожидание:** `E[ξ] = Σᵢ₌₁ⁿ aᵢ · P(Aᵢ)`
* **Свойство:** определение не зависит от выбора разбиения (если два представления дают разные разбиения — результат одинаков)

### **1.2. Дискретный случай**
* `ξ` принимает значения `x₁, x₂, ...` с вероятностями `pₖ = P(ξ = xₖ)`
* `E[ξ] = Σₖ₌₁^∞ xₖ · pₖ` (при абсолютной сходимости ряда: `Σₖ |xₖ| · pₖ < ∞`)
* **Почему absolute convergence:** без неё сумма может зависеть от порядка слагаемых

## **2. Для неотрицательных случайных величин**

### **2.1. Формула через хвостовые вероятности**
* `E[ξ] = ∫₀^∞ P(ξ > t) dt` (при `ξ ≥ 0`)
* **Доказательство (интуиция):** `∫₀^∞ P(ξ > t) dt = ∫₀^∞ ∫_{t<ξ} dP dt = ∫_Ω ∫₀^ξ dt dP = ∫_Ω ξ dP = E[ξ]`
* **Следствие:** `E[|ξ|] = ∫₀^∞ P(|ξ| > t) dt`

### **2.2. Теорема о монотонном пределе (для неотрицательных)**
* Если `ξₙ ≥ 0`, `ξₙ ↑ ξ` (возрастающая последовательность), то `E[ξₙ] → E[ξ]`
* **Применение:** построение интеграла Лебега через приближение простыми СВ

## **3. Для произвольных случайных величин**

### **3.1. Разложение на положительную и отрицательную части**
* `ξ⁺ = max(ξ, 0)` — положительная часть; `ξ⁻ = max(−ξ, 0)` — отрицательная часть
* `ξ = ξ⁺ − ξ⁻`, `|ξ| = ξ⁺ + ξ⁻`
* `E[ξ] = E[ξ⁺] − E[ξ⁻]` (при условии, что оба определены и конечно)

### **3.2. Условие существования**
* `E[ξ]` определено и конечно ⟺ `E[|ξ|] < ∞` (интегрируемость)
* Если `E[ξ⁺] = E[ξ⁻] = ∞` — ожидание не определено (не `∞`, а именно не существует)

### **3.3. Интеграл Лебега**
* `E[ξ] = ∫_Ω ξ(ω) dP(ω)` — интеграл случайной величины относительно вероятностной меры
* Обобщает дискретный случай: `Σₖ xₖ · P(ξ = xₖ) = ∫_Ω ξ dP`

# **B. СВОЙСТВА МАТЕМАТИЧЕСКОГО ОЖИДАНИЯ**

## **1. Линейность**

### **1.1. Формула**
* `E[aξ + bη] = a · E[ξ] + b · E[η]` для любых случайных величин `ξ, η` и констант `a, b`
* **Ключевой момент:** верно **всегда**, даже для зависимых случайных величин!
* **Обобщение:** `E[Σᵢ aᵢ ξᵢ] = Σᵢ aᵢ E[ξᵢ]` (линейная комбинация)

### **1.2. Доказательство (дискретный случай)**
* `E[aξ + bη] = Σ_{x,y} (ax + by) · P(ξ=x, η=y)`
* `= a · Σ_{x,y} x · P(ξ=x, η=y) + b · Σ_{x,y} y · P(ξ=x, η=y)`
* `= a · Σ_x x · P(ξ=x) + b · Σ_y y · P(η=y) = a·E[ξ] + b·E[η]`

### **1.3. Следствия**
* `E[c] = c` для любой константы `c` (линейность: `E[c·1] = c·E[1] = c`)
* `E[ξ − E[ξ]] = 0` (центральное отклонение имеет нулевое среднее)
* `E[Σᵢ ξᵢ] = Σᵢ E[ξᵢ]` (аддитивность для конечного числа слагаемых)

## **2. Сохранение порядка**

### **2.1. Формула**
* Если `ξ ≤ η` almost surely (с вероятностью 1), то `E[ξ] ≤ E[η]`
* **Следствие:** `|E[ξ]| ≤ E[|ξ|]` (неравенство для модуля)

## **3. Аддитивность для независимых**

### **3.1. Формула**
* Если `ξ, η` **независимы**, то `E[ξη] = E[ξ] · E[η]`
* **Обобщение:** `E[∏ᵢ ξᵢ] = ∏ᵢ E[ξᵢ]` для независимых `ξᵢ`

### **3.2. Важно: обратное неверно**
* `E[ξη] = E[ξ]·E[η]` **не** означает независимость (это лишь факторизация первого момента)

## **4. Формула через индикаторы**

### **4.1. Индикатор события**
* `𝟙_A(ω) = 1` если `ω ∈ A`, иначе `0`
* `E[𝟙_A] = P(A)` — ключевая связь между вероятностью и математическим ожиданием

### **4.2. Метод индикаторов**
* **Подсчёт числа объектов:** если `X = Σᵢ 𝟙_{Aᵢ}`, то `E[X] = Σᵢ P(Aᵢ)`
* **Пример:** математическое ожидание числа совпадений в задаче о днях рождения
* **Пример:** ожидание числа инверсий в перестановке

## **5. Итерированное математическое ожидание**

### **5.1. Формула полного математического ожидания**
* `E[ξ] = E[E[ξ|η]]`
* **Расшифровка:**
    1. Вычислить `E[ξ|η = y]` — условное ожидание при фиксированном `η = y`
    2. Усреднить по распределению `η`: `E[E[ξ|η]] = ∫ E[ξ|η = y] · f_η(y) dy`

### **5.2. Интерпретация**
* Полное ожидание = «вложенное условное ожидание, усреднённое по подраспределению»
* **Пример:** `E[сумма кубиков | число кубиков = n] = 3.5n`, `E[3.5N] = 3.5 · E[N]`

### **5.3. Связь с условной вероятностью**
* `E[𝟙_A | η] = P(A | η)` — условная вероятность как условное ожидание индикатора

## **6. Нулевое среднее у неотрицательных**

### **6.1. Теорема**
* Если `ξ ≥ 0` и `E[ξ] = 0`, то `P(ξ = 0) = 1`
* **Доказательство:** `0 = E[ξ] = ∫₀^∞ P(ξ > t) dt`; подынтегральная функция неотрицательна → `P(ξ > t) = 0` для всех `t > 0` → `P(ξ = 0) = 1`

### **6.2. Следствие**
* `E[|ξ|] = 0` ⟺ `P(ξ = 0) = 1` (не только для неотрицательных)

# **C. ФОРМУЛЫ ПОДСЧЁТА**

## **1. Для дискретных случайных величин**

### **1.1. Формула**
* `E[g(ξ)] = Σₖ g(xₖ) · P(ξ = xₖ)` для любой функции `g`
* **Частные случаи:**
    * `E[ξ] = Σₖ xₖ · pₖ` (где `g(x) = x`)
    * `E[ξ²] = Σₖ xₖ² · pₖ` (для дисперсии)
    * `E[ξ(ξ−1)] = Σₖ xₖ(xₖ−1) · pₖ` (моментное порождающее)

## **2. Для абсолютно непрерывных случайных величин**

### **2.1. Формула**
* `E[g(ξ)] = ∫₋∞^∞ g(x) · f(x) dx` при существовании интеграла
* **Частные случаи:**
    * `E[ξ] = ∫₋∞^∞ x · f(x) dx`
    * `E[ξ²] = ∫₋∞^∞ x² · f(x) dx`

## **3. Через функцию распределения**

### **3.1. Для неотрицательных**
* `E[ξ] = ∫₀^∞ P(ξ > t) dt = ∫₀^∞ (1 − F(t)) dt` при `ξ ≥ 0`
* **Преимущество:** не нужна плотность; достаточно CDF

### **3.2. Для модуля**
* `E[|ξ|] = ∫₀^∞ P(|ξ| > t) dt`

### **3.3. Двойное интегрирование**
* `E[ξ] = ∫₋∞^∞ x dF(x)` (интеграл Римана-Стьюлтесса по мере распределения)

## **4. Условное математическое ожидание**

### **4.1. Определение**
* `E[ξ|G]` —唯一ная `G`-измеримая случайная величина такая, что:
    * `∫_A ξ dP = ∫_A E[ξ|G] dP` для всех `A ∈ G`
* При `G = σ(η)`: `E[ξ|η]` — функция от `η`

### **4.2. Вычисление**
* Дискретный случай: `E[ξ|η = y] = Σₖ xₖ · P(ξ = xₖ | η = y)`
* Непрерывный: `E[ξ|η = y] = ∫ x · f(x|y) dx`

### **4.3. Свойства**
* `E[E[ξ|G]] = E[ξ]` (формула полного ожидания)
* `E[g(η) · ξ|η] = g(η) · E[ξ|η]` (вынос функции от `η`)
* `E[E[ξ|η] · η] = E[ξ · η]` при определённости

# **D. МЕДИАНА И КВАНТИЛИ**

## **1. Медиана**

### **1.1. Определение**
* **Медиана** `m` случайной величины `ξ`: число такое, что:
    * `P(ξ ≤ m) ≥ 1/2` и `P(ξ ≥ m) ≥ 1/2`
* Медиана **не唯一** в общем случае (любое число из отрезка `[q_{0.5-}, q_{0.5}]`)

### **1.2. Свойства**
* Медиана устойчива к выбросам (в отличие от среднего)
* Для симметричных распределений: медиана = среднее = мода

## **2. Квантили**

### **2.1. Определение**
* **Квантиль уровня `p`** (0 < p < 1): `q_p = inf{x : F(x) ≥ p}`
* Эквивалентно: `q_p` — наименьшее `x` такое, что `P(ξ ≤ x) ≥ p`

### **2.2. Особые случаи**
* `q_{0.5}` — медиана
* `q_{0.25} = Q₁` — первый квартиль
* `q_{0.75} = Q₃` — третий квартиль
* `q_{0.25}, q_{0.75}` — межквартильный размах `IQR = Q₃ − Q₁`

## **3. Неравенство о медиане**

### **3.1. Формула**
* `P(|ξ − m| ≥ t) ≤ 1 − F(m + t) + F(m − t)`
* **Следствие:** `P(|ξ − m| ≥ t) ≤ 2 · min(P(ξ ≥ m + t), P(ξ ≤ m − t))`

### **3.2. Интерпретация**
* Вероятность отклонения от медианы на `t` ограничена хвостами распределения
* Аналог неравенства Чебышёва, но для медианы (и без знания дисперсии)

# **E. СВОДНАЯ ТАБЛИЦА: СВОЙСТВА ОЖИДАНИЯ**

| Свойство | Формула | Условие |
|----------|---------|---------|
| Линейность | `E[aξ + bη] = aE[ξ] + bE[η]` | всегда |
| Вынос константы | `E[c] = c` | всегда |
| Сохранение порядка | `ξ ≤ η` ⟹ `E[ξ] ≤ E[η]` | всегда |
| Аддитивность | `E[ξη] = E[ξ]·E[η]` | `ξ, η` независимы |
| Индикатор | `E[𝟙_A] = P(A)` | всегда |
| Полное ожидание | `E[ξ] = E[E[ξ|η]]` | всегда |
| Нулевое среднее | `E[ξ] = 0, ξ ≥ 0` ⟹ `P(ξ=0) = 1` | `ξ ≥ 0` |
| Формула через CDF | `E[ξ] = ∫₀^∞ (1−F(t)) dt` | `ξ ≥ 0` |
