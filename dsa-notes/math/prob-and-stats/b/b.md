**B. АКСИОМАТИЧЕСКОЕ ПОСТРОЕНИЕ ТЕОРИИ ВЕРОЯТНОСТЕЙ (КОЛМОГОРОВ)**

> **Архитектура:** `MeasureTheoreticProb` (b.cpp) — наследует `ProbabilityBasics` (a.cpp). Расширяет классическое определение вероятности аксиоматическим подходом Колмогорова: вводит тройку `(Ω, F, P)`, σ-алгебры, аксиомы меры, свойства вероятностной меры, непрерывность меры, π-системы, λ-системы и теорему о продолжении меры (Каратаодори). Все последующие разделы (случайные величины, матожидание и т.д.) строятся на этом фундаменте.
>
> **Связи:** σ-алгебры и борелевские структуры — база для определения случайных величин (раздел C); теорема о продолжении меры — основа построения вероятностных мер на произвольных пространствах; π-λ-системы — инструмент доказательства единственности меры; непрерывность меры — связь с предельными теоремами (раздел G).

# **A. ВЕРОЯТНОСТНОЕ ПРОСТРАНСТВО**

## **1. Тройка Колмогорова**

### **1.1. Определение**
* **Вероятностное пространство** — упорядоченная тройка `(Ω, F, P)`, где:
    * `Ω` — произвольное множество (пространство элементарных исходов)
    * `F` — σ-алгебра подмножеств `Ω` (допустимые события)
    * `P` — вероятностная мера: отображение `P: F → [0, 1]`
* **Контекст:** тройка задаёт **всю** вероятностную модель; из неё выводятся все вероятности, распределения, матожидания

### **1.2. Пространство элементарных исходов `Ω`**
* **Свойства:**
    * `Ω ≠ ∅` (пустое пространство невозможно — эксперимент должен иметь хотя бы один исход)
    * Исходы **взаимно несовместны:** реализуется ровно один `ω ∈ Ω`
    * Исходы **полны:** каждый возможный результат описанsome `ω`
* **Примеры:**
    * Бросок монеты: `Ω = {H, T}`
    * Бросок `n` костей: `Ω = {1, ..., 6}ⁿ`
    * Случайное действительное на `[0, 1]`: `Ω = [0, 1]`

### **1.3. Сигма-алгебра `F`**
* **Зачем нужна:** не все подмножества `Ω` можно измерить (на непрерывных пространствах); `F` задаёт «допустимые» события
* **Аksiомы σ-алгебры:**
    1. `Ω ∈ F` (достоверное событие измеримо)
    2. Если `A ∈ F`, то `Ā = Ω \ A ∈ F` (дополнение измеримо)
    3. Если `A₁, A₂, ... ∈ F`, то `∪ₙ Aₙ ∈ F` (счётное объединение измеримо)
* **Следствия:**
    * `∅ ∈ F` (дополнение `Ω`)
    * `A ∩ B = Ω \ (Ā ∪ B̄)` — пересечение двух измеримых измеримо
    * Счётное пересечение: `∩ₙ Aₙ = Ω \ ∪ₙ(Ω \ Aₙ)` — измеримо

### **1.4. Вероятностная мера `P`**
* **Аksiомы Колмогорова:**
    1. **Неотрицательность:** `P(A) ≥ 0` для всех `A ∈ F`
    2. **Нормированность:** `P(Ω) = 1`
    3. **σ-аддитивность:** если `A₁, A₂, ... ∈ F` попарно несовместны (`Aᵢ ∩ Aⱼ = ∅` при `i ≠ j`), то `P(∪ₙ Aₙ) = Σₙ P(Aₙ)`
* **Интуиция:** мера — «обобщённая длина/площадь/объём»; аксиомы гарантируют, что вероятность ведёт себя «разумно»

## **2. Следствия аксиом**

### **2.1. Базовые свойства**
* `P(∅) = 0`: из σ-аддитивности ( `∅, ∅, ...` несовместны → `P(∅) = P(∅) + P(∅) + ...` → `P(∅) = 0` )
* `P(A) ≤ 1`: из `P(A) + P(Ā) = P(Ω) = 1` и неотрицательности
* `P(A) = 1 − P(Ā)`: дополнение

### **2.2. Монотонность**
* Если `A ⊆ B`, то `P(A) ≤ P(B)`
* **Доказательство:** `B = A ∪ (B \ A)`, несовместные → `P(B) = P(A) + P(B \ A) ≥ P(A)`

### **2.3. Субаддитивность (неравенство Бонферрони)**
* `P(A ∪ B) ≤ P(A) + P(B)`
* **Доказательство:** `P(A ∪ B) = P(A) + P(B) − P(A ∩ B) ≤ P(A) + P(B)`
* **Обобщение:** `P(∪ₙ Aₙ) ≤ Σₙ P(Aₙ)` (субаддитивность для счётного числа)

### **2.4. Формула включений-исключений (для мер)**
* Для счётного числа событий:
    ```
    P(∪ₙ Aₙ) = Σₙ P(Aₙ) − Σₘ<ₙ P(Aₘ ∩ Aₙ) + Σₘ<ₙ<ₖ P(Aₘ ∩ Aₙ ∩ Aₖ) − ...
    ```
* **Применение:** вычисление вероятности «хотя бы одного события» через попарные, тройные и т.д. пересечения

# **B. σ-АЛГЕБРЫ И АЛГЕБРЫ МНОЖЕСТВ**

## **1. Алгебра множеств**

### **1.1. Определение**
* Подколлекция `А ⊆ 2^Ω` называется **алгеброй**, если:
    1. `Ω ∈ А`
    2. Если `A ∈ А`, то `Ā ∈ А`
    3. Если `A, B ∈ А`, то `A ∪ B ∈ А` (и `A ∩ B ∈ А`, `A \ B ∈ А`)
* **Отличие от σ-алгебры:** замкнутость только для **конечных** операций (не счётных)

### **1.2. Примеры**
* `А = {∅, Ω}` — тривиальная алгебра (и σ-алгебра)
* `А = {A ⊆ Τ : A конечно или A̅ конечно}` — алгебра конечных/кофинальных множеств
* **Связь:** каждая σ-алгебра является алгеброй, но не каждая алгебра — σ-алгебра

## **2. σ-алгебра**

### **2.1. Определение**
* Подколлекция `F ⊆ 2^Ω` называется **σ-алгеброй**, если:
    1. `Ω ∈ F`
    2. Если `A ∈ F`, то `Ā ∈ F`
    3. Если `A₁, A₂, ... ∈ F`, то `∪ₙ Aₙ ∈ F`
* **Эквивалентные формулировки:** замкнутость относительно счётных пересечений, разностей, пределов

### **2.2. Граничные случаи**
* **Тривиальная σ-алгебра:** `F = {∅, Ω}` — нет информации о событиях
* **Сила множества:** `F = 2^Ω` (все подмножества) — максимум информации; на бесконечных `Ω` может быть слишком «густой»
* **Порождённая σ-алгебра:** для системы множеств `С ⊆ 2^Ω` наименьшая σ-алгебра, содержащая `С`; обозначение `σ(С)`

## **3. Borel-σ-алгебра**

### **3.1. Определение на `ℝ`**
* `B(ℝ) = σ({(a, b] : a < b})` — σ-алгебра, порождённая полуоткрытыми отрезками
* Содержит: все открытые, замкнутые, промежуточные множества, счётные объединения, пересечения
* **Ключевое свойство:** любая непрерывная функция `f: ℝ → ℝ` измерима относительно `B(ℝ)`

### **3.2. Обобщение на `ℝⁿ`**
* `B(ℝⁿ) = σ({(a₁, b₁] × ... × (aₙ, bₙ] : aᵢ < bᵢ})` — произведение Borel-σ-алгебр
* **Связь с вероятностями:** случайные величины `ξ₁, ..., ξₙ` определены на `(ℝⁿ, B(ℝⁿ))`

## **4. Свойства σ-алгебр**

### **4.1. Пересечение σ-алгебр**
* Пересечение любых σ-алгебр `∩ᵢ Fᵢ` является σ-алгеброй
* Объединение `∪ᵢ Fᵢ` **не** обязательно σ-алгебра; нужна порождённая `σ(∪ᵢ Fᵢ)`

### **4.2. Порождённая σ-алгебра**
* `σ(С)` — пересечение всех σ-алгебр, содержащих `С`
* Для конечного `Ω`: `σ(С)` конечна; для бесконечного — может быть бесконечной
* **Пример:** `σ({a, b})` на `Ω = {a, b, c}` = `{∅, {a}, {b,c}, Ω, {a,b,c}...}` (зависит от `c`)

# **C. ВЕРОЯТНОСТНАЯ МЕРА И ЕЁ СВОЙСТВА**

## **1. Свойства вероятностной меры**

### **1.1. Базовые следствия аксиом**
* `P(∅) = 0` — невозможное событие
* `P(A) ≤ 1` — вероятность не превышает 1
* `P(A) = 1 − P(Ā)` — дополнение
* **Монотонность:** `A ⊆ B` ⟹ `P(A) ≤ P(B)`
* **Субаддитивность:** `P(A ∪ B) ≤ P(A) + P(B)` (неравенство Бонферрони)

### **1.2. Формула включений-исключений (конечный случай)**
* Для `n` событий:
    ```
    P(A₁ ∪ ... ∪ Aₙ) = Σᵢ P(Aᵢ) − Σᵢ<ⱼ P(Aᵢ ∩ Aⱼ) + ... + (−1)ⁿ⁺¹ P(A₁ ∩ ... ∩ Aₙ)
    ```
* **Следствие для двух:** `P(A ∪ B) = P(A) + P(B) − P(A ∩ B)`

### **1.3. Формула для «не менее чем k из n»**
* Пусть события `A₁, ..., Aₙ` имеют одинаковую вероятность `p` и симметричны
* `P(минимум k событий произошли) = Σⱼ₌ₖⁿ (−1)ʲ⁻ᵏ C(j, k) · Sⱼ`, где `Sⱼ` — суммы вероятностей `j`-_intersection
* **Применение:** задачи о покрытиях, выборах, раскрасках

## **2. Непрерывность меры**

### **2.1. Теорема о непрерывности меры**
* **Возрастающие последовательности:** если `A₁ ⊆ A₂ ⊆ ...` и `A = ∪ₙ Aₙ`, то `P(A) = lim_{n→∞} P(Aₙ)`
* **Убывающие последовательности:** если `A₁ ⊇ A₂ ⊇ ...` и `A = ∩ₙ Aₙ`, то `P(A) = lim_{n→∞} P(Aₙ)` (при условии `P(A₁) < ∞`)
* **Интуиция:** мера «непрерывна» — предел последовательности событий = событие-предел

### **2.2. Доказательство (возрастающий случай)**
* Определим `B₁ = A₁`, `Bₙ = Aₙ \ Aₙ₋₁` для `n ≥ 2`
* `Bₙ` попарно несовместны, `∪ₙ Bₙ = A`
* `P(A) = Σₙ P(Bₙ) = lim_{N→∞} Σₙ₌₁ᴺ P(Bₙ) = lim_{N→∞} P(Aₙ)` ( `P(Aₙ) = Σₖ₌₁ⁿ P(Bₖ)` )

### **2.3. Связь с σ-аддитивностью**
* Непрерывность **следствие** σ-аддитивности (доказано выше)
* Обратно: если `P` конечна и непрерывна в нуле, то `P` σ-аддитивна

# **D. СИСТЕМЫ МНОЖЕСТВ И ПРОДОЛЖЕНИЕ МЕРЫ**

## **1. π-системы**

### **1.1. Определение**
* Система множеств `Π` называется **π-системой**, если замкнута относительно пересечений: `A, B ∈ Π` ⟹ `A ∩ B ∈ Π`
* **Примеры:** интервалы на `ℝ`, отрезки `[a, b]`, множества вида `(a, b]`
* **Связь:** каждая σ-алгебра является π-системой, но не наоборот

## **2. λ-системы (dyadic)**

### **2.1. Определение**
* Система `Л ⊆ 2^Ω` называется **λ-системой**, если:
    1. `Ω ∈ Л`
    2. Если `A ∈ Л`, то `Ā ∈ Л`
    3. Если `A₁, A₂, ... ∈ Л` попарно несовместны, то `∪ₙ Aₙ ∈ Л`
* **Эквивалентно (для полных пространств):** `Ω ∈ Л`, замкнутость относительно разностей `A \ B` при `A ⊆ B`, и замкнутость относительно возрастающих пределов

### **2.2. Связь с σ-алгебрами**
* Каждая σ-алгебра является λ-системой
* Каждая π-система, являющаяся одновременно λ-системой, является σ-алгеброй

## **3. Теорема о π-λ-системах (Дайесонфельд-Колмогоров)**

### **3.1. Формулировка**
* Пусть `Π` — π-система на `Ω`, `F = σ(Π)` — порождённая σ-алгебра
* Если два вероятностных пространства `(Ω, F, P₁)` и `(Ω, F, P₂)` совпадают на `Π` ( `P₁(A) = P₂(A)` для всех `A ∈ Π` ), то `P₁ = P₂` на всей `F`
* **Следствие:** вероятностная мера **единственна**, если задана на π-системе

### **3.2. Применение**
* Для доказательства равенства двух мер достаточно проверить их совпадение на «простой» системе (интервалах, отрезках)
* **Основа:** построение меры Лебега через продолжение с полуинтервалов

## **4. Теорема Каратаодори о продолжении меры**

### **4.1. Предварительная мера**
* Пусть `Π` — π-система на `Ω`, `μ₀: Π → [0, +∞]` — **предварительная мера** ( σ-аддитивная на `Π` )
* `μ₀` задаёт «длину/площадь» на простых множествах

### **4.2. Формулировка теоремы**
* Существует **продолжение** `μ` предваренной меры `μ₀` на σ-алгебру `σ(Π)`:
    * `μ(A) = inf{Σₙ μ₀(Bₙ) : A ⊆ ∪ₙ Bₙ, Bₙ ∈ Π}` (внешняя мера)
* Если `μ₀` σ-аддитивна на `Π`, то продолжение **единственно**
* **Применение:** построение меры Лебега на `ℝⁿ` через длину интервалов

## **5. Borel-σ-алгебра и продолжение**

### **5.1. Построение на `ℝ`**
* `Π = {(a, b] : a < b}` — π-система
* `μ₀((a, b]) = b − a` — длина интервала
* Продолжение Каратаодори → **мера Лебега** на `B(ℝ)`
* **Свойства:** σ-конечная, инвариантная относительно сдвигов, единственная (при этих свойствах)

### **5.2. Построение на `ℝⁿ`**
* `Π = {(a₁, b₁] × ... × (aₙ, bₙ]}` — π-система прямоугольников
* `μ₀ = произведение длин сторон`
* Продолжение → **мера Лебега** на `B(ℝⁿ)`

# **E. ДОПОЛНИТЕЛЬНЫЙ КОНТЕНТ**

## **1. Конечные вероятностные пространства**

### **1.1. Структура**
* `Ω = {ω₁, ..., ωₙ}` конечно; `F = 2^Ω` (все подмножества)
* Мера задаётся: `P({ωᵢ}) = pᵢ`, `Σᵢ pᵢ = 1`, `pᵢ ≥ 0`
* `P(A) = Σ_{ωᵢ ∈ A} pᵢ` для любого `A ⊆ Ω`
* **Связь с a.md:** равновозможные исходы — частный случай `pᵢ = 1/n`

### **1.2. Вероятностные пространства на `{0, 1}ⁿ`**
* `Ω = {0, 1}ⁿ`, `|Ω| = 2ⁿ`
* Бернуллиевские случайные величины: `Xᵢ(ω) = ωᵢ`
* Биномиальное распределение: `P(Σᵢ Xᵢ = k) = C(n, k) pᵏ (1−p)ⁿ⁻ᵏ` (переход к a.md.F)

## **2. Тривиальные σ-алгебры**

### **2.1. Грубая σ-алгебра**
* `F = {∅, Ω}` — «нет информации»; единственные измеримые события — невозможное и достоверное
* Единственная мера: `P(∅) = 0`, `P(Ω) = 1`

### **2.2. Сила множества**
* `F = 2^Ω` — максимум информации; все подмножества измеримы
* На бесконечном `Ω`: не все меры допускают продолжение на `2^Ω` ( парадокс Банаха-Тарского )

## **3. Сигма-алгебры, порождённые случайными величинами**

### **3.1. Определение**
* Для случайной величины `ξ: Ω → ℝ`: `σ(ξ) = σ({ξ⁻¹(B) : B ∈ B(ℝ)})` — наименьшая σ-алгебра, относительно которой `ξ` измерима
* **Интуиция:** `σ(ξ)` содержит всю информацию о `ξ`; события вида `{ξ ≤ x}` генерируют `σ(ξ)`

### **3.2. Независимость σ-алгебр**
* Случайные величины `ξ, η` независимы ⟺ `σ(ξ)` и `σ(η)` независимы как σ-алгебры
* **Определение:** `P(A ∩ B) = P(A) · P(B)` для всех `A ∈ σ(ξ)`, `B ∈ σ(η)`
