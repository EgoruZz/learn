# **A. ЗАКОН БОЛЬШИХ ЧИСЕЛ (ЗБЧ)**

## **1. Слабое ЗБЧ (по вероятности)**

### **1.1. Формулировка (Чебышёв)**
* Пусть `ξ₁, ξ₂, ...` — попарно некоррелированные СВ с `E[ξᵢ] = μ` и `D[ξᵢ] ≤ C` для всех `i`
* Тогда `ξ̄ₙ = (1/n) Σᵢ₌₁ⁿ ξᵢ →^{P} μ` (сходится по вероятности)
* **Формально:** `∀ε > 0: lim_{n→∞} P(|ξ̄ₙ − μ| ≥ ε) = 0`

### **1.2. Доказательство (через Чебышёва)**
* `P(|ξ̄ₙ − μ| ≥ ε) ≤ D[ξ̄ₙ] / ε² = D[Σξᵢ/n] / ε²`
* Попарная некоррелированность: `D[Σξᵢ] = ΣD[ξᵢ] ≤ nC`
* `D[ξ̄ₙ] ≤ C/n` → `P(|ξ̄ₙ − μ| ≥ ε) ≤ C/(nε²) → 0`

### **1.3. Теорема Бернулли (частный случай)**
* `ξᵢ ~ Bernoulli(p)`: `E[ξᵢ] = p`, `D[ξᵢ] = p(1−p)`
* Частота события `A` в `n` испытаниях: `νₙ/n →^{P} P(A)`
* Это **классическое** определение вероятности как предела частоты

## **2. Сильное ЗБЧ (почти наверное)**

### **2.1. Формулировка (Колмогоров)**
* Пусть `ξ₁, ξ₂, ...` — н.о.р. с `E[ξᵢ] = μ` (конечное)
* Тогда `P(lim_{n→∞} ξ̄ₙ = μ) = 1` (сходится **почти наверное**)

### **2.2. Разница со слабым**
* Слабое: сходимость по вероятности (вероятность отклонения мала)
* Сильное: сходимость几乎 наверное (отклонение происходит только на множестве меры 0)
* `сильное` ⟹ `слабое`, обратное неверно

### **2.3. Следствие**
* `P(lim_{n→∞} ξ̄ₙ = μ) = 1` означает: для «почти любой» реализации эксперимента среднее сходится к μ

# **B. ЦЕНТРАЛЬНАЯ ПРЕДЕЛЬНАЯ ТЕОРЕМА (ЦПТ)**

## **1. Классическая ЦПТ (Ляпунов-Феллер)**

### **1.1. Формулировка**
* Пусть `ξ₁, ξ₂, ...` — н.о.р. с `E[ξᵢ] = μ`, `D[ξᵢ] = σ² > 0`
* Тогда `Zₙ = (Σᵢ₌₁ⁿ ξᵢ − nμ) / (σ√n) →^{d} N(0, 1)`
* **Смысл:** сумма многих малых независимых воздействий → нормальное распределение

### **1.2. Интерпретация**
* Неважно, какое распределение у `ξᵢ` (при выполнении условий)
* `Σξᵢ` приближается `N(nμ, nσ²)`
* Стандартизация `Zₙ` → `N(0, 1)` при `n → ∞`

### **1.3. Теорема Ляпунова (обобщение)**
* Условие одинаковости `ξᵢ` **не** требуется
* Достаточное условие (условие Ляпунова): `Σ E[|ξᵢ − μᵢ|^{2+δ}] / sₙ^{2+δ} → 0` при `n → ∞`, где `sₙ² = Σ D[ξᵢ]`, `δ > 0`

## **2. Приближение ЦПТ**

### **2.1. Формула**
* `P(Σξᵢ ≤ x) ≈ Φ((x − nμ) / (σ√n))`
* Где `Φ` — функция стандартного нормального распределения
* **Поправка Уisoftа:** `P(Sₙ ≤ k) ≈ Φ((k + 0.5 − nμ) / (σ√n))` для дискретных `Sₙ`

# **C. НОРМАЛЬНАЯ АППРОКСИМАЦИЯ**

## **1. Биномиального распределения**

### **1.1. Условие**
* `Sₙ ~ B(n, p)`: `E[Sₙ] = np`, `D[Sₙ] = np(1−p)`
* ЦПТ: `Sₙ → N(np, np(1−p))` при `n → ∞`, `p` фиксировано

### **1.2. Критерий применимости**
* `np(1−p) ≥ 10` (иногда `np ≥ 5` и `nq ≥ 5`)
* При `p` близком к 0 или 1 — нужно большое `n`

### **1.3. Формулы**
* `P(Sₙ ≤ k) ≈ Φ((k + 0.5 − np) / √(np(1−p)))` (с поправкой)
* `P(Sₙ = k) ≈ φ((k − np) / √(np(1−p))) / √(np(1−p))` (локальная ЦПТ)

## **2. Распределения Пуассона**

### **2.1. Условие**
* `X ~ Po(λ)`: `E[X] = λ`, `D[X] = λ`
* ЦПТ: `X → N(λ, λ)` при `λ → ∞`

### **2.2. Критерий**
* `λ ≥ 30` (иногда `λ ≥ 20`)
* `P(X ≤ k) ≈ Φ((k + 0.5 − λ) / √λ)`

# **D. СХОДИМОСТЬ СЛУЧАЙНЫХ ВЕЛИЧИН**

## **1. Три типа сходимости**

### **1.1. Сходимость по вероятности**
* `∀ε > 0: P(|ξₙ − ξ| > ε) → 0`
* **Интуиция:** вероятность «далёкого» отклонения мала

### **1.2. Сходимость почти наверное (a.s.)**
* `P(lim_{n→∞} ξₙ = ξ) = 1`
* **Интуиция:** для «почти любой» реализации `ξₙ(ω) → ξ(ω)`

### **1.3. Сходимость по распределению**
* `Fₙ(x) → F(x)` во всех точках непрерывности `F`
* **Интуиция:** функции распределения сходятся (кроме точек разрыва)
* **Критерий Перро:** `ξₙ →^{d} ξ` ⟺ `E[g(ξₙ)] → E[g(ξ)]` для всех непрерывных ограниченных `g`

## **2. Взаимосвязи**

### **2.1. Цепочка**
* `a.s.` ⟹ `по вероятности` ⟹ `по распределению`
* Обратное **неверно**

### **2.2. Контрпримеры**
* `по вероятности` ⟹⁄=> `a.s.`: последовательность «блоков» growing length
* `по распределению` ⟹⁄=> `по вероятности`: `ξₙ = −ξ` (симметрия)

### **2.3. Сравнительная таблица**

| Тип | Формула | Сила |
|-----|---------|------|
| Почти наверное | `P(ξₙ → ξ) = 1` | сильнее всех |
| По вероятности | `P(\|ξₙ-ξ\|>ε) → 0` | средняя |
| По распределению | `Fₙ(x) → F(x)` | слабее всех |

# **E. ПРАКТИЧЕСКОЕ ПРИМЕНЕНИЕ ЦПТ**

## **1. Оценка вероятностей**

### **1.1. Алгоритм**
1. Определить `μ = E[ξᵢ]`, `σ² = D[ξᵢ]`
2. Вычислить `Z = (k − nμ) / (σ√n)` (или с поправкой)
3. `P(Σξᵢ ≤ k) ≈ Φ(Z)`

### **1.2. Пример**
* 100 бросков честной монеты: `P(40 ≤ орлов ≤ 60)`
* `μ = 0.5`, `σ² = 0.25`, `n = 100`, `σ√n = 5`
* `P(40 ≤ S ≤ 60) ≈ Φ(3) − Φ(−3) ≈ 0.997`

## **2. Определение размера выборки**

### **2.1. Формула**
* Для оценки `μ` с точностью `ε` и доверием `1−α`:
    * `n ≥ (z_{α/2} · σ / ε)²`
* Где `z_{α/2}` — квантиль нормального распределения

# **F. СВОДНАЯ ТАБЛИЦА**

## **1. Ключевые предельные теоремы**

| Теорема | Условия | Результат |
|---------|---------|-----------|
| Слабое ЗБЧ | попарно некорр., `D ≤ C` | `ξ̄ₙ →^{P} μ` |
| Сильное ЗБЧ | н.о.р., `E[ξ] = μ` | `P(ξ̄ₙ → μ) = 1` |
| ЦПТ | н.о.р., `E=μ, D=σ²` | `(Σ-nμ)/(σ√n) →^{d} N(0,1)` |
| Ляпунов | не necessarily одинаковые | условие Ляпунова → ЦПТ |

## **2. Типы сходимости**

| Тип | Определение | ЗБЧ |
|-----|-------------|-----|
| a.s. | `P(ξₙ → ξ)=1` | сильное |
| по вероятности | `P(\|ξₙ-ξ\|>ε)→0` | слабое |
| по распределению | `Fₙ(x)→F(x)` | — |
