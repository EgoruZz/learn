**H. ДИФФЕРЕНЦИАЛЬНЫЕ УРАВНЕНИЯ (ДУ)**

> **Архитектура:** `DifferentialEquations : ComplexAnalysis`. ДУ 1-го порядка (все типы), 2-го порядка (Вронского, ФСР, Абель), высшие (оператор, ФСР), системы (матричная экспонента), первые интегралы, ПДУ, краевые (Штурм–Лиувилль, Грин), устойчивость (Ляпунов), численные (Эйлер, RK, Адамс, Picard), приложения.
> **Связи:** производные → b; интегралы → c; линейная алгебра → linear-algebra; Лаплас → i.

---

# **A. ВВЕДЕНИЕ. ОСНОВНЫЕ ПОНЯТИЯ**

### **1.1. Определение:** dy/dx = f(x,y) — ДУ порядка m; решение — семейство кривых
### **1.2. Задача Коши:** dy/dx = f(x,y), y(x₀) = y₀; теорема существования и единственности (Липшиц)
### **1.3. Геометрическая интерпретация:** интегральные кривые, поле направлений
### **1.4. Линейные vs нелинейные:** линейные: y' + P(x)y = Q(x); нелинейные: сложнее решать
### **1.5. Системы:** приведение уравнения n-го порядка к системе 1-го

---

# **B. ДУ ПЕРВОГО ПОРЯДКА (ЧАСТЬ 1)**

### **1.1. Разделяющиеся:** dy/dx = f(x)g(y) → ∫dy/g(y) = ∫f(x)dx
### **1.2. Однородные:** dy/dx = F(y/x) → v = y/x → dv/dx = (F(v)−v)/x
### **1.3. Линейные 1-го порядка:** y' + P(x)y = Q(x)
* **Однородное (Q=0):** y = C·e^{-∫P dx}
* **Неоднородное:** y = e^{-∫P}(C + ∫Q·e^{∫P} dx) (метод вариации постоянных)
* **Дифференциальный оператор:** L[y] = y' + P(x)y; L[αy₁+βy₂] = αL[y₁]+βL[y₂]
* **Разрыв коэффициентов:** если P(x) имеет разрыв 1-го рода, решение на каждом промежутке своё; непрерывность в точке разрыва как условие

---

# **C. ДУ ПЕРВОГО ПОРЯДКА (ЧАСТЬ 2)**

### **1.1. Бернулли:** y' + P(x)y = Q(x)yⁿ → z = y^{1−n} → z' + (1−n)Pz = (1−n)Q
### **1.2. Точные:** M(x,y)dx + N(x,y)dy = 0, ∂M/∂y = ∂N/∂x → ∃F: dF = Mdx+Ndy → F(x,y)=C
### **1.3. Интегрирующий множитель:** μ(x,y)使得 ∂(μM)/∂y = ∂(μN)/∂x; для P(x)y'=Q(x,y): μ = e^{∫(P_y−Q_x)/Q dx}

---

# **D. ДУ ПЕРВОГО ПОРЯДКА (ЧАСТЬ 3)**

### **1.1. Особые решения:** не входят в общее семейство (касательная к кривым)
### **1.2. Уравнения F(x,y,y')=0:** не разрешенные относительно y'
* **Клеро:** y = xy' + f(y') → параметрическое: x = −f'(p)+..., y = p·x+f(p)
* **Лагранжа:** y = xg(y') + f(y') → дифференцирование → y''(g+pg')=0
### **1.3. Зависимость от параметров:** ∂y/∂p₀ = −φ(x,p₀)/∂Φ/∂p₀ (敏感度)
### **1.4. Огибающая:** касательная ко всем кривым семейства; ∂F/∂p = 0 + F = 0

---

# **E. ДУ ВТОРОГО ПОРЯДКА**

### **1.1. Линейное однородное:** y'' + p(x)y' + q(x)y = 0
### **1.2. Линейная зависимость/независимость:**
* **Определитель Вронского:** W(y₁,y₂) = |y₁ y₂; y₁' y₂'| = y₁y₂' − y₂y₁'
* **Свойство:** W ≠ 0 ⟺ y₁, y₂ линейно независимы
* **Теорема Абеля:** W(x) = W(x₀)·e^{-∫p(x)dx} (константность при p=0)
* **Формула Остроградского-Лиувилля:** обобщение на высшие порядки
### **1.3. Фундаментальная система решений (ФСР):** n линейно независимых решений для ДУ n-го порядка
### **1.4. Структура общего решения:**
* Однородное: y = C₁y₁ + ... + Cₙyₙ
* Неоднородное: y = y_общ + y_частное (любое частное решение)
### **1.5. С постоянными коэффициентами:** a₂y''+a₁y'+a₀y=0, характеристическое a₂r²+a₁r+a₀=0
* **Различные корни:** y = C₁e^{r₁x} + C₂e^{r₂x}
* **Кратные:** y = (C₁+C₂x)e^{rx}
* **Комплексные r=α±iβ:** y = e^{αx}(C₁cos βx + C₂sin βx)
### **1.6. Неоднородное:** метод неопределённых коэффициентов (подбор y_частное)

---

# **F. ЛИНЕЙНЫЕ ДУ ВЫСШИХ ПОРЯДКОВ**

### **1.1. Линейный оператор:** L = aₙ(x)Dⁿ + ... + a₁(x)D + a₀(x), D = d/dx
* **Свойства:** L[αy₁+βy₂] = αL[y₁]+βL[y₂] (суперпозиция)
### **1.2. ФСР для n-го порядка:** n линейно независимых решений y₁,...,yₙ
* **W(y₁,...,yₙ) ≠ 0** → ФСР
### **1.3. Общее решение:** y = C₁y₁+...+Cₙyₙ + y_частное
### **1.4. Восстановление ДУ по ФСР:** по y₁,...,yₙ → определитель Вронского → aₙ(x),...,a₀(x)
### **1.5. Метод вариации постоянных (Лагранжа):** yₚ = Σ uₖ(x)yₖ(x), где uₖ' = ...

---

# **G. ЛИНЕЙНЫЕ ДУ С ПОСТОЯННЫМИ КОЭФФИЦИЕНТАМИ**

### **1.1. Характеристическое уравнение:** aₙrⁿ + ... + a₁r + a₀ = 0
* **Различные корни r₁,...,rₙ:** y = Σ Cᵢe^{rᵢx}
* **Кратные корни (кратность m):** y = (C₁+C₂x+...+Cₘx^{m−1})e^{rx}
* **Комплексные:** e^{αx}(C₁cos βx + C₂sin βx)
### **1.2. Метод неопределённых коэффициентов:**
* r(x) = Pₙ(x)e^{αx}: yₚ = x^k·Qₙ(x)e^{αx} (k=кратность α в характеристичном)
* r(x) = e^{αx}(P(x)cos βx + Q(x)sin βx): аналогично с комплексными корнями
### **1.3. Уравнения Эйлера (степенные):** aₙxⁿy⁽ⁿ⁾ + ... + a₁xy' + a₀y = 0
* Замена x = eᵗ → ДУ с постоянными коэффициентами
### **1.4. Уравнения Лагранжа и Чебышёва:** специальные формы
### **1.5. Степенные ряды:** если коэффициенты не постоянные → решение через ∑aₙxⁿ
### **1.6. Понижение порядка:** если известно одно решение y₁ → z = y'/y₁ → ДУ 1-го порядка

---

# **H. МЕТОДЫ РЕШЕНИЯ ДУ**

### **1.1. Вариация постоянных (Лагранжа):** yₚ = u₁(x)y₁+...+uₙ(x)yₙ, решения системы L[uₖ'yₖ] = r(x)
### **1.2. Понижение порядка:** замена y' = p, y'' = p·dp/dy → ДУ 1-го порядка от p(y)
### **1.3. Интегрирующий множитель:** μ使得 d(μM)/dy = d(μN)/dx → точное уравнение

---

# **I. СИСТЕМЫ ДУ**

### **1.1. Нормальные системы:** dy/dt = f(t,y), y ∈ ℝⁿ
### **1.2. Задача Коши для систем:** y(t₀) = y₀; теорема существования/единственности
### **1.3. Приведение к системе:** y⁽ⁿ⁾ = F(t,y,y',...,y⁽ⁿ⁻¹⁾) → замена x₁=y, x₂=y',...
### **1.4. Линейные системы:** dy/dt = A(t)y + g(t)
### **1.5. С постоянными коэффициентами:** dy/dt = Ay, решение через собственные значения/векторы A
### **1.6. Матричная экспонента:** e^{At} = Σ(At)ᵏ/k!; dy/dt=Ay → y(t)=e^{At}y₀
### **1.7. Диагонализация:** A=PDP⁻¹ → e^{At}=Pe^{Dt}P⁻¹ (легко вычислять)
### **1.8. Кратные корни:** когда A не диагонализуема → жорданова форма
### **1.9. Неоднородная система:** y(t) = e^{At}y₀ + ∫₀ᵗ e^{A(t−τ)}g(τ)dτ

---

# **J. ПЕРВЫЕ ИНТЕГРАЛЫ**

### **1.1. Определение:** первый интеграл — функция I(t,y), постоянная вдоль решений
### **1.2. Функциональная зависимость:** если найдено n−1 независимых первых интегралов → полное решение
### **1.3. Теорема:** в окрестности regular точки существует система первых интегралов
### **1.4. Понижение порядка:** каждый первый интеграл понижает порядок на 1
### **1.5. Линейные системы с постоянными:** первый интеграл через левый собственный вектор

---

# **K. ДУ С ЧАСТНЫМИ ПРОИЗВОДНЫМИ (введение)**

### **1.1. ПДУ 1-го порядка:** методы характеристик
### **1.2. Квазилинейное:** a(x,y,u)uₓ + b(x,y,u)u_y = c(x,y,u) → характеристические кривые

---

# **L. КРАЕВЫЕ ЗАДАЧИ**

### **1.1. Постановка:** ДУ + граничные условия (Dirichlet, Neumann, смешанные)
### **1.2. Линейная краевая:**唯一ность/существование через функцию Грина
### **1.3. Самосопряженный вид:** (py')' + qy + λry = 0
### **1.4. Функция Грина:** G(x,ξ) — решение однородной задачи; решение неоднородной: y(x) = ∫G(x,ξ)f(ξ)dξ
### **1.5. Тождество Лагранжа:** ∫(uLv−vLu) = [pu'v−puv']ₐᵇ
### **1.6. Задача Штурма–Лиувилля:** собственные значения λₙ, собственные функции yₙ; ортогональность
### **1.7. Неоднородная ШЛ:** разложение по собственным функциям

---

# **M. УСТОЙЧИВОСТЬ**

### **1.1. По Ляпунову:** ∀ε ∃δ: ||y(t₀)−ȳ|| < δ ⟹ ||y(t)−ȳ|| < ε
### **1.2. Асимптотическая:** y(t) → ȳ при t→∞
### **1.3. Функция Ляпунова:** V(x) > 0, V̇(x) < 0 → устойчивость
### **1.4. Особые точки:** узел (реальные собственные одного знака), седло (разных знаков), фокус (комплексные), центр (чисто мнимые), вырожденный узел
### **1.5. Предельные циклы:** замкнутая орбита; теорема Пуанкаре–Бендиксона

---

# **N. ПРЕОБРАЗОВАНИЕ ЛАПЛАСА В ТЕОРИИ ДУ**

### **1.1. L{f(t)} = ∫₀^∞ e^{-st}f(t)dt; достаточные условия: экспоненциальный рост
### **1.2. Кусочно-непрерывные:** L существует для кусочно-непрерывных с экспоненциальным ограничением
### **1.3. Свойства:** линейность, сдвиг по t (e^{-as}F(s)), сдвиг по s (F(s−a)), дифференцирование (sF−f(0)), интегрирование (F/s)
### **1.4. Хевисайд:** H(t) = 0 при t < 0, H(t) = 1 при t ≥ 0; L{H(t−a)} = e^{-as}/s
### **1.5. Дирак:** δ(t) = 0 при t≠0, ∫δ=1; L{δ(t)} = 1; сifting: ∫f(t)δ(t−a)dt = f(a)
### **1.6. Решение ДУ:** преобразование → алгебра → обратное; обобщённое решение через δ

---

# **O. ЧИСЛЕННЫЕ МЕТОДЫ**

### **1.1. Эйлер:** yₙ₊₁ = yₙ + hf(tₙ,yₙ), O(h)
### **1.2. Эйлер-Коши (модифицированный):** yₙ₊₁ = yₙ + hf(tₙ+h/2, yₙ+hf/2), O(h²)
### **1.3. Рунге-Кутты:** RK4 (классический), O(h⁴)
### **1.4. RK-Fehlberg 4(5):** адаптивный шаг, оценка погрешности
### **1.5. RK-Gills:** минимизация вычислений
### **1.6. Адамс:** Adams-Bashforth (явный), Adams-Moulton (неявный), многошаговый
### **1.7. Пикар:** итерационная схема yₙ₊₁(t) = y₀ + ∫f(s,yₙ(s))ds
### **1.8. Изоклины:** построение кривых y' = const для визуализации
### **1.9. Метод прогонки:** для двухточечных краевых задач
### **1.10. Конечные разности:** дискретизация производных

---

# **P. ПРИМЕНЕНИЯ ДУ**

### **1.1. Механика:** F = ma → second-order ODE
### **1.2. Магнитное поле:** движение заряженной частицы (Lorentz force)
### **1.3. Натуральные уравнения кривой:** ds/dt = v
### **1.4. Инвариантные множества:** изоклины, нуль-клины автономных систем
### **1.5. Лотки–Вольтерры:** x' = ax−bxy, y' = −cy+dxy (хищник–жертва)
### **1.6. Чаша Тантала:** гидравлическая автоколебательная система
### **1.7. Барометрическая:** распределение давления с высотой
### **1.8. Химическая кинетика:** закон действия масс
### **1.9. Колебания:** гармонический осциллятор, RLC-контур
### **1.10. Энергия:** превращения кинетической и потенциальной в колебательном контуре
