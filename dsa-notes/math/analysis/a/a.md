**A. ВВЕДЕНИЕ В АНАЛИЗ: ПРЕДЕЛЫ И НЕПРЕРЫВНОСТЬ**

> **Архитектура:** `LimitsAndContinuity` (a.cpp) — базовый класс всей ветки analysis. Вводит фундамент математического анализа: аксиоматику вещественных чисел, теорию пределов последовательностей и функций, непрерывность, элементарные функции. Все последующие разделы (дифференцирование, интегрирование, ряды, ДУ) строятся на этих понятиях.
>
> **Связи:** пределы → B (производные: определение через предел); теоремы о непрерывных функциях (Вейерштрасс, Больцано–Коши) → C (интеграл: существование интегральной суммы); элементарные функции → E (ряды: разложение в ряд Тейлора); связь с `math/number-theory/` (последовательности), `math/combinatorics/` (суммы, прогрессии), `math/algebra/` (многочлены).

# **A. ВЕЩЕСТВЕННЫЕ ЧИСЛА И ТЕОРИЯ МНОЖЕСТВ**

## **1. Фундамент анализа**

### **1.1. Рациональные и действительные числа**
* **Определение:** ℚ = {p/q : p ∈ ℤ, q ∈ ℤ \ {0}} — рациональные числа; ℝ — действительные числа
* **Неполнота ℚ:** √2 ∉ ℚ (доказательство через нечётность: если 2 = p²/q², то p² = 2q² → p чётно → q чётно → бесконечный спуск); также π, e ∉ ℚ
* **Аксиома полноты (Кантор–Гейне):** любое ограниченное сверху непустое множество действительных чисел имеет точную верхнюю границу (supremum)
* **Архимедово свойство:** ∀x > 0 ∃n ∈ ℕ: n > x (нет бесконечно больших и бесконечно малых одновременно)
* **Плотность ℚ в ℝ:** для любых a < b ∈ ℝ существует q ∈ ℚ: a < q < b; между любыми двумя вещественными числами бесконечно много рациональных
* **Необходимость ℝ:** ℚ не обладает свойством полноты; например, {x ∈ ℚ : x² < 2} ограничено сверху в ℚ, но sup не существует в ℚ

### **1.2. Множество бесконечных десятичных дробей**
* **Представление:** любое x ∈ [0,1]唯一 представимо в виде x = 0.a₁a₂a₃... = Σ(k=1..∞) aₖ/10ᵏ (при не终止 десятичных дробях)
* **Исключение:** числа вида m/10ⁿ имеют два представления (0.5 = 0.5000... = 0.4999...)
* **Упорядочение:** x < y ⟺ ∃k: aₖ < bₖ и aᵢ = bᵢ для i < k (лексикографический порядок)
* **Ограниченные сверху множества:** A ⊂ ℝ ограничено сверху ⟺ ∃M: ∀x ∈ A x ≤ M; множество верхних границ образует промежуток [sup A, ∞)
* **Приближение:** ∀x ∈ ℝ ∀ε > 0 ∃p/q ∈ ℚ: |x − p/q| < ε (плотность)

### **1.3. Способы задания действительных чисел**
* **Десятичные разложения:** x = a₀.a₁a₂a₃... = a₀ + Σ(k=1..∞) aₖ/10ᵏ, где aₖ ∈ {0,1,...,9}
* **Отрезки (вложенные):** последовательность вложенных отрезков [aₙ, bₙ] с bₙ − aₙ → 0 определяет唯一 точку
* **Последовательности:** x = lim aₙ, где aₙ ∈ ℚ и |aₙ − x| → 0
* **Через sup:** x = sup{r ∈ ℚ : r < x} (через аксиому полноты)
* **Неравенства:** транзитивность (a < b ∧ b < c ⟹ a < c); аддитивность (a < b ⟹ a + c < b + c); мультипликативность (a < b ∧ c > 0 ⟹ a·c < b·c)

### **1.4. Построение вещественной прямой**
* **Аксиомы:** ℚ ⊂ ℝ, полнота, архимедово свойство (∀x > 0 ∃n ∈ ℕ: n > x)
* **Множества на прямой:** промежутки (a,b), [a,b], (a,b], [a,b), лучи, полуплоскости
* **Свойства:** connectedness (непрерывность), complete (полнота), плотность ℚ

### **1.5. Операции и свойства вещественных чисел**
* **Сложение:** ∀a,b ∈ ℝ ∃! c = a + b; коммутативность, ассоциативность, нейтральный элемент 0, обратный элемент −a
* **Умножение:** ∀a,b ∈ ℝ ∃! c = a · b; коммутативность, ассоциативность, нейтральный элемент 1, обратный элемент 1/a (a ≠ 0)
* **Дистрибутивность:** a · (b + c) = a · b + a · c
* **Порядок:** a < b ⟺ ∃c > 0: a + c = b; если a < b, то a + c < b + c; если a < b и c > 0, то a · c < b · c

### **1.6. Элементы теории множеств**
* **Операции:** A ∪ B (объединение), A ∩ B (пересечение), A \ B (разность), Aᶜ (дополнение)
* **Свойства:** коммутативность, ассоциативность, дистрибутивность, законы де Моргана: (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ
* **Произведение:** A × B = {(a,b) : a ∈ A, b ∈ B}; |A × B| = |A| · |B| (для конечных)
* **Биекции:** f: A → B биекция ⟺ f инъективна и съёмна ⟺ |A| = |B| (для конечных)
* **Счётability:** A счётно ⟺ ∃ биекция f: A → ℕ; ℚ счётно, ℝ несчётно (диагональный аргумент Кантора)
* **Мощность:** |ℕ| = ℵ₀, |ℝ| = 𝔠 = 2^{ℵ₀}; теорема Кантора: |A| < |P(A)| для любого A

### **1.7. Точная верхняя и нижняя грань**
* **Определение:** sup A = наименьшая верхняя граница A; inf A = наибольшая нижняя граница A
* **Свойства:** sup A ∈ closure(A) если A ограничено; sup A = max A если максимум достигается
* **Лемма о вложенных отрезках:** если [aₙ, bₙ] ⊃ [aₙ₊₁, bₙ₊₁] и bₙ − aₙ → 0, то ∃! x ∈ ∩[aₙ, bₙ]

# **B. ТЕОРИЯ ПЕДЕЛОВ (ЧАСТЬ 1)**

## **1. Основы пределов**

### **1.1. Функция и способы задания**
* **Определение:** f: A → B, A ⊂ ℝⁿ, B ⊂ ℝ; область определения dom(f) = A, область значений ran(f) ⊆ B
* **Способы задания:** формула (y = x²), таблица, график, неявное уравнение (x² + y² = r²), параметрическое (x = x(t), y = y(t))

### **1.2. Числовые последовательности**
* **Определение:** последовательность — функция f: ℕ → ℝ; aₙ = f(n)
* **Арифметическая прогрессия:** aₙ = a₁ + (n−1)d, сумма Sₙ = n(a₁ + aₙ)/2
* **Геометрическая прогрессия:** aₙ = a₁qⁿ⁻¹, сумма Sₙ = a₁(1−qⁿ)/(1−q) при q ≠ 1
* **Гармонический ряд:** Σ(k=1..n) 1/k ~ ln n + γ (расходится)
* **Гексагональные числа:** Hₙ = n(2n−1), последовательность 1, 6, 15, 28, ...
* **P-ряды:** Σ(k=1..∞) 1/kᵖ сходится при p > 1, расходится при p ≤ 1

### **1.3. Предел последовательности**
* **Определение (ε-N):** lim(n→∞) aₙ = L ⟺ ∀ε > 0 ∃N ∈ ℕ: ∀n > N |aₙ − L| < ε
* **Единственность:** предел唯一
* **Свойства:** lim(aₙ + bₙ) = lim aₙ + lim bₙ; lim(aₙ · bₙ) = lim aₙ · lim bₙ; lim(aₙ/bₙ) = lim aₙ / lim bₙ (при lim bₙ ≠ 0)
* **Сохранение неравенств:** если aₙ ≤ bₙ и оба предела существуют, то lim aₙ ≤ lim bₙ

### **1.4. Предел функции**
* **Определение (ε-δ):** lim(x→a) f(x) = L ⟺ ∀ε > 0 ∃δ > 0: 0 < |x−a| < δ ⟹ |f(x)−L| < ε
* **Односторонние пределы:** lim(x→a⁺) f(x) = L (правый); lim(x→a⁻) f(x) = L (левый)
* **Связь:** lim(x→a) f(x) = L ⟺ lim(x→a⁺) f(x) = lim(x→a⁻) f(x) = L

### **1.5. Определения по Коши и по Гейне**
* **По Коши:** lim(x→a) f(x) = L ⟺ ∀ε > 0 ∃δ > 0: ∀x₁, x₂ (0 < |x₁−a| < δ ∧ 0 < |x₂−a| < δ) ⟹ |f(x₁)−f(x₂)| < ε
* **По Гейне:** lim(x→a) f(x) = L ⟺ для любой последовательности xₙ → a (xₙ ≠ a): f(xₙ) → L
* **Эквивалентность:** определения по Коши и по Гейне эквивалентны

### **1.6. Свойства пределов**
* **Арифметика:** lim(f ± g) = lim f ± lim g; lim(f · g) = lim f · lim g; lim(f/g) = lim f / lim g
* **Композиция:** если lim(x→a) g(x) = b и lim(y→b) f(y) = L, и g(x) ≠ b в окрестности a, то lim(x→a) f(g(x)) = L
* **Замена переменной:** lim(x→a) f(g(x)) = lim(t→b) f(t), где b = lim(x→a) g(x)
* **Сохранение неравенств:** f ≤ g в окрестности a ⟹ lim f ≤ lim g

### **1.7. Свойства пределов последовательностей**
* **Монотонный критерий:** возрастающая ограниченная последовательность имеет предел
* **Сжимающая лемма:** если aₙ ≤ bₙ ≤ cₙ и lim aₙ = lim cₙ = L, то lim bₙ = L

# **C. ТЕОРИЯ ПЕДЕЛОВ (ЧАСТЬ 2)**

## **1. Продвинутая теория пределов**

### **1.1. Монотонные последовательности**
* **Возрастающая:** aₙ₊₁ ≥ aₙ для всех n; убывающая: aₙ₊₁ ≤ aₙ
* **Теорема:** монотонная ограниченная последовательность сходится
* **Следствие:** lim(n→∞) (1 + 1/n)ⁿ = e (возрастающая и ограниченная)

### **1.2. Теорема Вейерштрасса для последовательностей**
* **Формулировка:** любая ограниченная последовательность aₙ ∈ [m, M] имеет сходящуюся подпоследовательность
* **Доказательство:** через бинарный поиск: делим [m, M] пополам

### **1.3. Число e**
* **Определение:** e = lim(n→∞) (1 + 1/n)ⁿ = Σ(k=0..∞) 1/k! = 2.71828...
* **Свойства:** ln e = 1; d/dx eˣ = eˣ
* **Построение через ряд:** e = 1 + 1/1! + 1/2! + 1/3! + ... (остаток < 1/(n·n!))

### **1.4. Критерий Коши**
* **Последовательности:** {aₙ} сходится ⟺ ∀ε > 0 ∃N: ∀m,n > N |aₙ − aₘ| < ε
* **Функции:** lim(x→a) f(x) существует ⟺ ∀ε ∃δ: |f(x₁)−f(x₂)| < ε
* **Значение:** позволяет доказать сходимость без нахождения предела

### **1.5. Подпоследовательности**
* **Определение:** {aₙₖ} — подпоследовательность, если n₁ < n₂ < n₃ < ...
* **Свойство:** последовательность сходится ⟺ все подпоследовательности сходятся к одному пределу
* **Лемма Больцано–Вейерштрасса:** ограниченная последовательность имеет сходящуюся подпоследовательность

### **1.6. Предел по базе**
* **Определение:** lim_{x→a, x∈A} f(x) = L, где A — база (направленная система множеств)
* **Обобщение:** включает односторонние пределы, пределы на последовательностях, пределы в бесконечности
* **Критерий Коши по базе:** lim существует ⟺ ∀ε ∃B ∈ A: |f(x₁)−f(x₂)| < ε

### **1.7. Замечательные пределы**
* **Первый:** lim(x→0) sin(x)/x = 1 (геометрическое доказательство)
* **Второй:** lim(x→∞) (1 + 1/x)ˣ = e; lim(x→0) (1 + x)^{1/x} = e
* **Следствия:** lim(x→0) (sin x)/x = 1; lim(x→0) (tan x)/x = 1; lim(x→0) (1−cos x)/x² = 1/2
* **Вычисление сложных пределов:** замена переменной → приведение к замечательным пределам

# **D. ПРИЁМЫ РАСКРЫТИЯ НЕОПРЕДЕЛЁННОСТЕЙ**

## **1. Бесконечно малые и большие функции**

### **1.1. Бесконечно малые**
* **Определение:** α(x) — бесконечно малая при x→a, если lim(x→a) α(x) = 0
* **Сравнение:** α ≺ β если lim α/β = 0; α ~ β если lim α/β = 1; α ∼ β если 0 < lim α/β < ∞
* **Эквивалентные:** sin x ~ x, tan x ~ x, arcsin x ~ x, ln(1+x) ~ x, eˣ−1 ~ x, (1+x)ᵅ−1 ~ αx

### **1.2. Бесконечно большие**
* **Определение:** f → ∞ при x→a ⟺ ∀M ∃δ: 0 < |x−a| < δ ⟹ |f(x)| > M
* **Связь:** f → ∞ ⟺ 1/f → 0
* **Примеры:** eˣ → ∞ при x→∞; 1/x → ∞ при x→0⁺; ln x → −∞ при x→0⁺

### **1.3. O-символика**
* **О-нотация:** f = O(g) ⟺ ∃C,δ: |f(x)| ≤ C|g(x)|
* **Малая o-нотация:** f = o(g) ⟺ lim f/g = 0
* **Применение:** оценка остаточного члена Тейлора

## **2. Методы раскрытия**

### **2.1. Таблица эквивалентных (при x→0)**
* sin x ~ x; tan x ~ x; arcsin x ~ x; 1−cos x ~ x²/2
* ln(1+x) ~ x; eˣ−1 ~ x; (1+x)ᵅ−1 ~ αx; aˣ−1 ~ x ln a

### **2.2. Методы**
* **Замена на эквивалентные:** lim f/g через промежуточные
* **Вынесение главного члена:** f = aₖxᵏ(1 + o(1))
* **L'Hôpital:** lim f/g = lim f'/g' при 0/0 или ∞/∞
* **Ряд Тейлора:** подстановка f(x) = Σ aₖ(x−a)ᵏ + o((x−a)ⁿ)

### **2.3. Виды неопределённостей**
* **0/0:** L'Hôpital или эквивалентные
* **∞/∞:** L'Hôpital или вынесение главного
* **∞ − ∞:** общий знаменатель или замена
* **0·∞:** f·g = f/(1/g) → 0/0 или ∞/∞
* **1^∞:** exp(lim (f−1)·g)
* **0⁰, ∞⁰:** exp(lim g·ln f)

# **E. НЕПРЕРЫВНОСТЬ ФУНКЦИИ**

## **1. Основы непрерывности**

### **1.1. Непрерывность в точке**
* **Определение:** f непрерывна в a ⟺ lim(x→a) f(x) = f(a)
* **ε-δ:** ∀ε > 0 ∃δ > 0: |x−a| < δ ⟹ |f(x)−f(a)| < ε
* **Односторонняя:** справа: lim(x→a⁺) f(x) = f(a); слева: lim(x→a⁻) f(x) = f(a)
* **Эквиваленты:** f непрерывна в a ⟺ lim(x→a) f(x) = f(a) ⟺ f(xₙ) → f(a) при xₙ → a

### **1.2. Непрерывность на множестве**
* **Определение:** f непрерывна на A ⟺ f непрерывна в каждой точке a ∈ A
* **Виды:** на открытом, замкнутом, компакте, равномерная

### **1.3. Локальные свойства**
* **Сохранение знака:** f(a) > 0 ⟹ ∃δ > 0: f(x) > 0 при |x−a| < δ
* **Локальная ограниченность:** f непрерывна в a ⟹ ∃δ, M: |f(x)| < M при |x−a| < δ
* **Локальная монотонность:** непрерывная инъективная → монотонна в окрестности

### **1.4. Глобальные свойства**
* **Больцано–Коши:** f на [a,b], f(a) < c < f(b) ⟹ ∃x₀: f(x₀) = c
* **Вейерштрасс:** f на [a,b] ⟹ ∃min и ∃max (достигаются)
* **Равномерная (Гейне–Кантор):** f на [a,b] ⟹ равномерно непрерывна
* **Обратная функция:** f непрерывна + строго монотонна → f⁻¹ непрерывна
* **Свойства монотонных:** конечные односторонние пределы, не более enumerable разрывов
* **Композиция:** g∘f непрерывна если f и g непрерывны

## **2. Точки разрыва**

### **2.1. Классификация**
* **I род (скачки):** оба предела существуют, но различны; скачок = |B − A|
* **Устранимый:** пределы существуют и равны, но ≠ f(a)
* **II род:** хотя бы один предел не существует

### **2.2. Равномерная непрерывность**
* **Определение:** ∀ε ∃δ: |x₁−x₂| < δ ⟹ |f(x₁)−f(x₂)| < ε (δ не зависит от точки)
* **Контрпример:** f(x) = 1/x на (0,1] — не равномерно

## **3. Компактность**
* **Последовательная:** из любой последовательности → сходящаяся подпоследовательность с пределом в множестве
* **Эквивалент для ℝⁿ:** замкнутое + ограниченное
* **Открытые покрытия:** из каждого открытого покрытия → конечное подпокрытие

# **F. ЭЛЕМЕНТАРНЫЕ ФУНКЦИИ**

## **1. Каталог основных функций**

### **1.1–1.6. Основные классы**
* **Степенные:** xᵅ = e^{α ln x}, x > 0; xⁿ, √x, 1/x
* **Показательные:** aˣ = e^{x ln a}; eˣ
* **Логарифмические:** log_a x = ln x / ln a; ln x
* **Тригонометрические:** sin, cos, tan, cot
* **Обратные тригонометрические:** arcsin, arccos, arctan
* **Гиперболические:** sh x = (eˣ−e⁻ˣ)/2, ch x = (eˣ+e⁻ˣ)/2, th x

### **1.7. Свойства**
* **Чётность:** cos(−x) = cos x; sin(−x) = −sin x; ch(−x) = ch x; sh(−x) = −sh x
* **Периодичность:** sin(x+2π) = sin x; tg(x+π) = tg x
* **Монотонность:** eˣ, ln x, arcsin x, arctan x — возрастающие
* **Асимптоты:** arctan x → ±π/2; ln x → ∞ (медленно)
* **Связи:** sin²x + cos²x = 1; ch²x − sh²x = 1; cos(ix) = ch x

### **1.8. Построение элементарных функций**
* **Композиции:** f(g(x)) — вложение
* **Аффинные аргумента:** f(ax+b) — сжатие/растяжение и сдвиг
* **Аффинные значений:** a·f(x)+b — растяжение/сдвиг
* **Отражения:** −f(x) (Ox), f(−x) (Oy)

### **1.9. Графики и трансформации**
* **Стандартные:** y = x, x², x³, √x, |x|, 1/x
* **Показательные/логарифмические:** eˣ (быстро растёт), ln x (медленно)
* **Суперпозиция:** y = A·sin(ωx + φ) + B
