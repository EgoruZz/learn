# **A. ЭЛЕМЕНТЫ ОПЕРАЦИОННОГО ИСЧИСЛЕНИЯ (ЧАСТЬ 1)**

## **1. Преобразование Лапласа**

### **1.1. Определение:** F(s) = L{f(t)} = ∫₀^∞ e^{-st} f(t) dt
### **1.2. Достаточные условия существования:**
* f кусочно-непрерывна на [0,∞)
* |f(t)| ≤ Me^{αt} для некоторого M, α (экспоненциальный рост)
### **1.3. Взаимно однозначное соответствие:** f(t) ↔ F(s) (при выполнении условий)

## **2. Таблица основных пар**

| f(t) | F(s) = L{f(t)} |
|------|----------------|
| 1 | 1/s |
| tⁿ | n!/sⁿ⁺¹ |
| eᵃᵗ | 1/(s−a) |
| sin ωt | ω/(s²+ω²) |
| cos ωt | s/(s²+ω²) |
| sh ωt | ω/(s²−ω²) |
| ch ωt | s/(s²−ω²) |
| δ(t) | 1 |
| H(t) | 1/s |
| H(t−a) | e^{-as}/s |
| t·eᵃᵗ | 1/(s−a)² |
| e^{at} sin ωt | ω/((s−a)²+ω²) |
| e^{at} cos ωt | (s−a)/((s−a)²+ω²) |

# **B. ЭЛЕМЕНТЫ ОПЕРАЦИОННОГО ИСЧИСЛЕНИЯ (ЧАСТЬ 2)**

## **1. Свойства преобразования Лапласа**

### **1.1. Линейность:** L{αf(t) + βg(t)} = αF(s) + βG(s)
### **1.2. Сдвиг по аргументу (теорема запаздывания):** L{f(t−a)H(t−a)} = e^{-as}F(s)
### **1.3. Сдвиг по параметру:** L{e^{at}f(t)} = F(s−a)
### **1.4. Теорема подобия:** L{f(at)} = (1/a)F(s/a) при a > 0
### **1.5. Дифференцирование оригинала:** L{f'(t)} = sF(s) − f(0); L{f''(t)} = s²F(s) − sf(0) − f'(0)
### **1.6. Интегрирование:** L{∫₀ᵗ f(τ)dτ} = F(s)/s
### **1.7. Почленное дифференцирование:** F'(s) = −L{t·f(t)}
### **1.8. Почленное интегрирование:** ∫ₛ^∞ F(σ)dσ = L{f(t)/t}

## **2. Обратное преобразование**

### **2.1. Формула:** f(t) = L⁻¹{F(s)} = (1/2πi) ∫_{c−i∞}^{c+i∞} e^{st} F(s) ds
### **2.2. Метод разложения на простейшие:** F(s) = Σ Aᵢ/(s−pᵢ) → f(t) = Σ Aᵢe^{pᵢt}
### **2.3. Метод выделения полных квадратов:** F(s) = ω/((s−a)²+ω²) → e^{at}sin ωt

# **C. ЭЛЕМЕНТЫ ОПЕРАЦИОННОГО ИСЧИСЛЕНИЯ (ЧАСТЬ 3)**

## **1. Решение ДУ операционным методом**

### **1.1. Алгоритм:**
1. Записываем ДУ: y'' + ay' + by = r(t)
2. Применяем L: (s²Y−sy₀−y₀') + a(sY−y₀) + bY = R(s)
3. Решаем относительно Y: Y = (полином в s) / (характеристическое)
4. Применяем L⁻¹: y(t) = L⁻¹{Y(s)}
### **1.2. Преимущество:** превращает ДУ в алгебраическое уравнение

## **2. Системы ДУ через Лаплас**

### **2.1.** Применяем L к каждой компоненте системы
### **2.2.** Решаем алгебраическую систему в s-области
### **2.3.** Обратное преобразование каждой компоненты

## **3. Метод Дюамеля (свёртка)**

### **3.1.** Решение неоднородного: y(t) = ∫₀ᵗ g(τ)·h(t−τ) dτ
### **3.2.** h(t) — импульсная характеристика (решение однородного с нач. условией)
### **3.3.** g(t) — правая часть неоднородного уравнения

## **4. Специальные функции**

### **4.1. Функция Хевисайда:** H(t) = 0 при t < 0, H(t) = 1 при t ≥ 0
* L{H(t−a)} = e^{-as}/s
* Применение: моделирование скачков, включение/выключение
### **4.2. Функция Дирака (δ-функция):**
* δ(t) = 0 при t ≠ 0, ∫₀^∞ δ(t) dt = 1
* Свойство сдвига: ∫f(t)δ(t−a) dt = f(a)
* L{δ(t)} = 1; L{δ(t−a)} = e^{-as}
* Предел δ-последовательностей: δₑ(t) = (1/ε)·rect(t/ε) при ε→0
### **4.3. Обобщённые решения:** ДУ с δ → решение через несобственные функции
