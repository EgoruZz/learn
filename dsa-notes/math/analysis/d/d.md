**D. МЕТРИЧЕСКИЕ ПРОСТРАНСТВА И ФУНКЦИИ НЕСКОЛЬКИХ ПЕРЕМЕННЫХ**

> **Архитектура:** `MultivariableCalculus : IntegralCalculus`. Метрические/нормированные пространства, ФНП, частные производные, градиент, высшие производные, Тейлор, неявные функции, геометрические приложения, экстремумы (Лагранж).
> **Связи:** анализ → analysis/c; линейная алгебра (матрицы, градиенты) → math/linear-algebra; выпуклый анализ → combinatorics; оптимизация → dynamic/programming.

# **A. МЕТРИЧЕСКИЕ И НОРМИРОВАННЫЕ ПРОСТРАНСТВА**

## **1. Абстрактный анализ**

### **1.1. Метрические пространства**
* **Определение:** (X, d) — множество X + метрика d: X×X → [0,∞) с d(x,y)=0 ⟺ x=y, d(x,y)=d(y,x), d(x,z) ≤ d(x,y)+d(y,z)
* **Примеры:** ℝⁿ (метрика Евклида, Манхэттен, Чебышёва), C[a,b] (метрика равномерная), L² (метрика интегральная)
* **Шар:** B(x,r) = {y : d(x,y) < r}; открытый/замкнутый

### **1.2. Нормированные пространства**
* **Норма:** ||·||: X → [0,∞), ||x||=0 ⟺ x=0, ||αx||=|α|·||x||, ||x+y|| ≤ ||x||+||y||
* **Связанная метрика:** d(x,y) = ||x−y||
* **Банахово пространство:** полное нормированное

### **1.3. Полнота**
* **Последовательность Коши:** ∀ε ∃N: ||xₙ−xₘ|| < ε при m,n > N
* **Полнота:** все последовательности Коши сходятся
* **完备化 (completion):** X̄ — полное пространство, содержащее X как плотное подмножество

### **1.4. Компактность**
* **Последовательная:** из каждой последовательности → сходящаяся подпоследовательность с пределом в X
* **Открытые покрытия:** из каждого открытого покрытия → конечное подпокрытие
* **Лемма о вложенных шарах:** компакт ⟺ из каждого убывающего семейства замкнутых шаров → непустое пересечение

# **B. ФУНКЦИИ НЕСКОЛЬКИХ ПЕРЕМЕННЫХ (ЧАСТЬ 1)**

## **1. Основы ФНП**

### **1.1. Понятие и области**
* **Определение:** f: D → ℝ, D ⊂ ℝⁿ
* **Области:** открытая (∀x ∃r: B(x,r) ⊂ D), замкнутая (Dᶜ открыта), связная (любые две точки соединены путём)

### **1.2. График и линии уровня**
* **График:** множество {(x₁,...,xₙ, f(x₁,...,xₙ))} ⊂ ℝⁿ⁺¹
* **Линии уровня:** f(x₁,...,xₙ) = c — кривые/поверхности, на которых f постоянна

### **1.3. Предел и непрерывность**
* **Предел:** lim_{x→a} f(x) = L ⟺ ∀ε ∃δ: ||x−a|| < δ ⟹ |f(x)−L| < ε
* **Независимость от пути:** предел существует ⟺ одинаков по всем путям
* **Непрерывность:** f непрерывна в a ⟺ lim_{x→a} f(x) = f(a)

# **C. ДИФФЕРЕНЦИРОВАНИЕ ФНП (ЧАСТЬ 2)**

## **1. Частные производные и градиент**

### **1.1. Частные производные**
* **Определение:** ∂f/∂xᵢ = lim(h→0) (f(x+heᵢ) − f(x))/h
* **Геометрия:** наклон касательной вдоль оси xᵢ

### **1.2. Градиент**
* **Определение:** ∇f = (∂f/∂x₁, ..., ∂f/∂xₙ)
* **Свойство:** направление наибольшего роста; |∇f| — скорость роста

### **1.3. Производная по направлению**
* **Определение:** ∂f/∂v = ∇f · v/||v|| (v — вектор направления)
* **Свойство:** ∂f/∂v = ∇f · ŵ, где ŵ — единичный вектор

### **1.4. Дифференцируемость**
* **Определение:** f дифференцируема в a ⟺ ∃A: f(a+h) − f(a) = ∇f(a)·h + o(||h||)
* **Полный дифференциал:** df = ∇f · dx = Σ (∂f/∂xᵢ)dxᵢ
* **Инвариантность формы:** df не зависит от координат

### **1.5. Цепное правило**
* Если x = x(t), y = y(t), то df/dt = ∂f/∂x · dx/dt + ∂f/∂y · dy/dt
* Обобщение: df/dt = ∇f · dx/dt

# **D. ДИФФЕРЕНЦИРОВАНИЕ ФНП (ЧАСТЬ 3)**

## **1. Высшие производные и Тейлор**

### **1.1. Производные второго порядка**
* ∂²f/∂x², ∂²f/∂x∂y, ∂²f/∂y∂x, ∂²f/∂y²
* **Матрица Гессе:** H(f) = [[∂²f/∂xᵢ∂xⱼ]]

### **1.2. Смешанные производные**
* **Теорема:** если ∂²f/∂x∂y и ∂²f/∂y∂x непрерывны, то ∂²f/∂x∂y = ∂²f/∂y∂x

### **1.3. Формула Тейлора для ФНП**
* f(x+h) = f(x) + ∇f·h + (1/2)hᵀHh + ... + (1/n!) (h·∇)ⁿf + остаток

### **1.4. Неявные функции**
* **Теорема:** F(x,y) = 0, ∂F/∂y ≠ 0 ⟹ ∃唯一 y = f(x) в окрестности
* **Дифференцирование:** dy/dx = −Fₓ/F_y

### **1.5. Обратное отображение**
* **Теорема:** если jacobian ≠ 0, то отображение обратимо локально

# **E. ГЕОМЕТРИЧЕСКИЕ ПРИЛОЖЕНИЯ**

## **1. Градиент и касательные**

### **1.1. Касательная плоскость**
* z = f(a,b) + fₓ(a,b)(x−a) + f_y(a,b)(y−b)
* Нормаль: (−fₓ, −f_y, 1) или (fₓ, f_y, −1)

### **1.2. Градиент как нормаль**
* ∇f(a,b) ортогонален линии уровня f = c в точке (a,b)

# **F. ЭКСТРЕМУМЫ ФНП**

## **1. Необходимые и достаточные условия**

### **1.1. Необходимое условие:** ∇f(a) = 0 (градиент = 0)
### **1.2. Достаточное (второй признак):**
* Hesse положительно определён → минимум
* Hesse отрицательно определён → максимум
* Неопределён → нет экстремума

### **1.3. Метод множителей Лагранжа**
* Условный экстремум: ext f при g(x) = 0
* L(x,λ) = f(x) − λg(x); ∇L = 0

### **1.4. Численные методы**
* **Градиентный спуск:** xₙ₊₁ = xₙ − α∇f(xₙ)
* **Метод Ньютона:** xₙ₊₁ = xₙ − H⁻¹∇f(xₙ)
* **Сопряжённые градиенты:** для линейных систем
