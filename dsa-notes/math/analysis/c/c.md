**C. ИНТЕГРАЛЬНОЕ ИСЧИСЛЕНИЕ ФУНКЦИЙ ОДНОЙ ПЕРЕМЕННОЙ**

> **Архитектура:** `IntegralCalculus : DifferentialCalculus`. Первообразная, неопределённый интеграл (методы подстановки, по частям, рациональные, тригонометрические, иррациональные), определённый интеграл (Риман, Ньютон-Лейбница, численные методы), приложения, несобственные интегралы.
> **Связи:** производная → analysis/b (дифференцирование — обратная операция); интегральная сумма → analysis/a (предел); численные методы → analysis/b (интерполяция, аппроксимация).

---

# **A. ПЕРВООБРАЗНАЯ И НЕОПРЕДЕЛЁННЫЙ ИНТЕГРАЛ**

## **1. Основы интегрирования**

### **1.1. Определение**
* **Первообразная:** F'(x) = f(x) → ∫f(x)dx = F(x) + C
* **Неопределённый интеграл:** семейство всех первообразных, C — произвольная постоянная
* **Свойства:** ∫(f ± g)dx = ∫f dx ± ∫g dx; ∫kf dx = k∫f dx

### **1.2. Таблица основных интегралов**
* ∫xⁿdx = xⁿ⁺¹/(n+1) + C (n ≠ −1)
* ∫x⁻¹dx = ∫1/x dx = ln|x| + C
* ∫eˣdx = eˣ + C
* ∫aˣdx = aˣ/ln a + C
* ∫sin x dx = −cos x + C
* ∫cos x dx = sin x + C
* ∫tg x dx = −ln|cos x| + C
* ∫ctg x dx = ln|sin x| + C
* ∫1/(a²+x²)dx = (1/a) arctan(x/a) + C
* ∫1/√(a²−x²)dx = arcsin(x/a) + C
* ∫1/(a²−x²)dx = (1/(2a)) ln|(a+x)/(a−x)| + C

### **1.3. Основные методы интегрирования**
* **Непосредственное:** используем таблицу и свойства
* **Подстановка:** ∫f(g(x))g'(x)dx = ∫f(u)du, где u = g(x)
* **По частям:** ∫u dv = uv − ∫v du

# **B. НЕОПРЕДЕЛЁННЫЙ ИНТЕГРАЛ (ЧАСТЬ 1)**

## **1. Базовые методы**

### **1.1. Непосредственное интегрирование**
* Использование таблицы, линейность, разбиение на слагаемые

### **1.2. Метод подстановки (замена переменной)**
* ∫f(g(x))·g'(x)dx = ∫f(u)du при u = g(x)
* **Обратная подстановка:** u = g(x) → du = g'(x)dx
* **Тригонометрические подстановки:** x = a sin t, x = a tan t, x = a sec t

### **1.3. Интегрирование по частям**
* ∫u dv = uv − ∫v du
* **Правило выбора u (LIATE):** Logarithmic, Inverse trig, Algebraic, Trig, Exponential —优先级 u
* **Повторное применение:** если ∫v du проще исходного

# **C. НЕОПРЕДЕЛЁННЫЙ ИНТЕГРАЛ (ЧАСТЬ 2)**

## **1. Рациональные функции**

### **1.1. Разложение на простейшие дроби**
* **Линейные множители:** (x−a)ᵏ → Σ Aᵢ/(x−a)ⁱ
* **Неразложимые квадратные:** (x²+px+q)ᵏ → Σ (Aᵢx+Bᵢ)/(x²+px+q)ⁱ
* **Кратные корни:** разложение для каждой кратности

### **1.2. Алгоритм**
1. Если deg(числитель) ≥ deg(знаменателя) → деление
2. Факторизация знаменателя
3. Запись формы разложения
4. Определение коэффициентов (подстановка, сравнение коэффициентов)
5. Интегрирование каждой дроби

# **D. НЕОПРЕДЕЛЁННЫЙ ИНТЕГРАЛ (ЧАСТЬ 3)**

## **1. Тригонометрические функции**

### **1.1. Универсальная подстановка**
* t = tan(x/2) → sin x = 2t/(1+t²), cos x = (1−t²)/(1+t²), dx = 2dt/(1+t²)
* Превращает ∫R(sin x, cos x)dx в ∫R(t)dt (рациональная функция)

### **1.2. Тригонометрические积分ы**
* ∫sinᵐ x cosⁿ x dx: если m нечётно → sin x = u; если n нечётно → cos x = u
* ∫sin²x dx = (x − sin x cos x)/2 + C
* ∫cos²x dx = (x + sin x cos x)/2 + C

### **1.3. Подстановки для иррациональностей**
* √(a²−x²): x = a sin t
* √(a²+x²): x = a tan t
* √(x²−a²): x = a sec t

# **E. НЕОПРЕДЕЛЁННЫЙ ИНТЕГРАЛ (ЧАСТЬ 4)**

## **1. Иррациональные функции**

### **1.1. Замены корней**
* ∫R(x, √(ax+b))dx: t = √(ax+b)
* ∫R(x, √((ax+b)/(cx+d)))dx: t = √((ax+b)/(cx+d))

### **1.2. Дифференциальные биномы Чебышёва**
* ∫xᵐ(a+bxⁿ)ᵖ dx — интегрируется в элементарных функциях ⟺ хотя бы одно из:
    * p ∈ ℤ (целая степень)
    * (m+1)/n ∈ ℤ (чётное отношение)
    * (m+1)/n + p ∈ ℤ

### **1.3. Эллиптические интегралы**
* **Неполные:** F(φ,k) = ∫₀^φ dθ/√(1−k²sin²θ)
* **Полные:** K(k) = F(π/2,k), E(k) = ∫₀^{π/2} √(1−k²sin²θ) dθ
* **Связь:** длина эллипса, маятник, геодезические

# **F. ОПРЕДЕЛЁННЫЙ ИНТЕГРАЛ**

## **1. Теория интеграла Римана**

### **1.1. Интегральная сумма**
* ∫ₐᵇ f(x)dx = lim_{‖Δ‖→0} Σ f(ξᵢ)Δxᵢ
* Разбиение P = {a=x₀<x₁<...<xₙ=b}, ‖Δ‖ = max Δxᵢ

### **1.2. Суммы Дарбу**
* Верхняя: S(P) = Σ MᵢΔxᵢ, Mᵢ = sup f на [xᵢ₋₁, xᵢ]
* Нижняя: s(P) = Σ mᵢΔxᵢ, mᵢ = inf f на [xᵢ₋₁, xᵢ]
* **Критерий Римана:** sup s(P) = inf S(P)

### **1.3. Свойства**
* **Линейность:** ∫(αf+βg) = α∫f + β∫g
* **Аддитивность:** ∫ₐᵇ + ∫ᵇᶜ = ∫ₐᶜ
* **Монотонность:** f ≤ g ⟹ ∫f ≤ ∫g
* **Оценка:** m(b−a) ≤ ∫f ≤ M(b−a)
* **Среднее значение:** ∃c ∈ [a,b]: ∫f = f(c)(b−a)

### **1.4. Формула Ньютона-Лейбница**
* ∫ₐᵇ f(x)dx = F(b) − F(a), где F' = f
* **С переменным верхним:** Φ(x) = ∫ₐˣ f(t)dt → Φ'(x) = f(x)

## **2. Численное интегрирование**

### **2.1. Метод прямоугольников**
* ∫f ≈ Σ f(xᵢ)Δx; O(Δx) погрешность

### **2.2. Метод трапеций**
* ∫f ≈ Σ (f(xᵢ)+f(xᵢ₊₁))/2 · Δx; O(Δx²) погрешность

### **2.3. Метод Симпсона (Simpson's Rule)**
* ∫f ≈ (Δx/3)(f(x₀) + 4f(x₁) + 2f(x₂) + 4f(x₃) + ... + f(xₙ))
* O(Δx⁴) погрешность; требует чётного числа отрезков

# **G. ПРИЛОЖЕНИЯ ОПРЕДЕЛЁННОГО ИНТЕГРАЛА**

## **1. Геометрические приложения**

### **1.1. Площади**
* S = ∫ₐᵇ |f(x) − g(x)|dx
* В полярных: S = (1/2)∫ r² dθ

### **1.2. Объёмы**
* **По площадям сечений:** V = ∫ₐᵇ A(x)dx
* **Тел вращения:** V = π∫ₐᵇ f²(x)dx (disk), V = π∫(R²−r²)dx (washer)
* **Метод цилиндрических оболочек:** V = 2π∫ x·f(x)dx

### **1.3. Длина дуги**
* L = ∫ₐᵇ √(1 + (f'(x))²) dx
* Параметрическая: L = ∫ √(x'²+y'²) dt

### **1.4. Площадь поверхности вращения**
* S = 2π∫ₐᵇ f(x)√(1 + (f'(x))²) dx

# **H. НЕСОБСТВЕННЫЙ ИНТЕГРАЛ**

## **1. Бесконечные интегралы**

### **1.1. Интеграл I рода:** ∫ₐ^∞ f(x)dx = lim(b→∞) ∫ₐᵇ f(x)dx
### **1.2. Интеграл II рода:** ∫ₐᵇ f(x)dx, где f неограничена в c ∈ [a,b]

## **2. Признаки сходимости**

### **2.1. Сравнения:** 0 ≤ f ≤ g, ∫g < ∞ ⟹ ∫f < ∞
### **2.2. Даламбер:** lim f(x)/xᵖ = L; p > 1, L < ∞ ⟹ сходится
### **2.3. Коши:** ∫ₐ^∞ f(x)dx сходится ⟺ ∀ε ∃A: ∫ₐ^∞ |f| < ε

### **2.4. Абсолютная и условная сходимость**
* ∫|f| < ∞ →绝对收敛
* ∫f < ∞ но ∫|f| = ∞ → условная (например, ∫(sin x)/x dx)
