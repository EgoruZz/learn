## **B. ДИФФЕРЕНЦИАЛЬНОЕ ИСЧИСЛЕНИЕ ФУНКЦИЙ ОДНОЙ ПЕРЕМЕННОЙ**
> `b/b.md` · `b/b.cpp` · `struct DifferentialCalculus : LimitsAndContinuity`

### **A. Производные и дифференциалы функции (часть 1)**
*   **Основы дифференцирования:**
    *   Понятие производной: f'(x) = lim(h→0) (f(x+h) − f(x))/h, геометрический смысл (наклон касательной)
    *   Производная и дифференциал. Касательная к графику функции: y = f(a) + f'(a)(x−a)
    *   Пример недифференцируемой функции: |x| в точке 0, кусочно-линейные функции
    *   Производная функции: правила дифференцирования
    *   Правила вычисления производных: линейность, произведение (Лейбница), частное, цепное правило
    *   Дифференцирование суммы, разности, произведения и частного функции
    *   Производная сложной функции: (f(g(x)))' = f'(g(x))·g'(x)
    *   Дифференцирование сложной функции и обратной функции: (f⁻¹)'(y) = 1/f'(x)
    *   **Dual Number Automatic Differentiation**: точное дифференцирование через дуальные числа (ε²=0)

### **B. Производные и дифференциалы функции (часть 2)**
*   **Специальные виды дифференцирования:**
    *   Логарифмическая производная: (ln|f(x)|)' = f'(x)/f(x)
    *   Производная показательно-степенной функции: (xⁿ)' = nxⁿ⁻¹, (aˣ)' = aˣ ln a
    *   Производная неявной функции: если F(x,y)=0, то dy/dx = −Fₓ/F_y
    *   Дифференцирование функции, заданной параметрически: x=x(t), y=y(t) → dy/dx = (dy/dt)/(dx/dt)
    *   Производная векторной функции: r(t) = (x(t), y(t), z(t)) → r'(t) = (x'(t), y'(t), z'(t))
    *   Дифференциал функции, его геометрический смысл: dy = f'(x)dx
    *   Понятие дифференцируемости функции: линейное приближение, связь с существованием производной

### **C. Производные и дифференциалы функции (часть 3)**
*   **Производные высших порядков:**
    *   Производные высших порядков: f⁽ⁿ⁾(x), рекуррентные формулы
    *   Производные и дифференциалы высших порядков: dⁿy = f⁽ⁿ⁾(x)dxⁿ
    *   Формула Лейбница: (fg)⁽ⁿ⁾ = Σ(k=0..n) C(n,k) f⁽ᵏ⁾ g⁽ⁿ⁻ᵏ⁾
    *   Дифференциалы высших порядков: инвариантность формы для первого, потеря инвариантности для высших

### **D. Производные и дифференциалы функции (часть 4)**
*   **Ряд Тейлора и приложения:**
    *   Правило Лопиталя: раскрытие неопределённостей 0/0 и ∞/∞ через производные
    *   Раскрытие неопределенностей (правило Лопиталя): повторное применение, Conditions
    *   Формула Тейлора: f(x) = Σ(k=0..n) f⁽ᵏ⁾(a)/k! (x−a)ᵏ + Rₙ(x)
    *   Локальная формула Тейлора: приближение функции полиномом в окрестности точки
    *   Формула Тейлора с остаточным членом в форме Коши: Rₙ = f⁽ⁿ⁺¹⁾(ξ)/(n+1)! (x−a)ⁿ⁺¹
    *   Формула Тейлора с остаточным членом в форме Лагранжа
    *   Формула Тейлора с остаточным членом в форме Шлёмильха – Роша
    *   Различные формы остаточного члена. Формула Маклорена: при a=0
    *   Формула Тейлора с остаточным членом в интегральной форме
    *   Оценка остаточного члена. Разложение некоторых элементарных функций: eˣ, sin x, cos x, ln(1+x), (1+x)ᵅ
    *   Примеры приложений формулы Маклорена: вычисление значений, приближения
    *   Ряд Тейлора. Аналитические функции: равномерная сходимость, единственность разложения

### **E. Основные теоремы о дифференцируемых функциях**
*   **Фундаментальные теоремы:**
    *   Свойства дифференцируемых функций: связь дифференцируемости и непрерывности
    *   Основные теоремы дифференциального исчисления: Ролля, Лагранжа, Коши
    *   Возрастание (убывание) функции в точке. Локальный экстремум: f'(x₀) = 0 как необходимое условие
    *   Теорема о нуле производной: если f'(x) = 0 на (a,b), то f ≡ const
    *   Формула конечных приращений (формула Лагранжа): f(b)−f(a) = f'(ξ)(b−a), ξ ∈ (a,b)
    *   Некоторые следствия из формулы Лагранжа: монотонность, выпуклость
    *   Обобщённая формула конечных приращений (формула Коши): (f(b)−f(a))/(g(b)−g(a)) = f'(ξ)/g'(ξ)

### **F. Исследование функций с помощью производных**
*   **Практический анализ:**
    *   Экстремумы и интервалы монотонности функции: первый и второй признаки
    *   Отыскание стационарных точек: f'(x) = 0, f'(x) не существует
    *   **Решение уравнений:** метод бисекции (Bisection), метод Ньютона–Рафсона (Newton-Raphson), метод секущих (Secant Method)
    *   **Интерполяция:** формула Ньютона, формула Лагранжа, оценка погрешности
    *   Выпуклость, вогнутость, точки перегиба: f''(x) > 0 ↔ выпуклая, f''(x) < 0 ↔ вогнутая
    *   Выпуклость графика функции: критерий через вторую производную, связь с неравенством Йенсена
    *   Точки перегиба: f''(x₀) = 0 и смена знака
    *   Асимптоты графика функции: вертикальные (предел ≠ 0), горизонтальные (предел = const), наклонные
    *   Общая схема исследования функции и построения графика: область → асимптоты → экстремумы → перегибы → поведение на концах
    *   Построение графика функции
    *   Глобальные максимум и минимум функции на сегменте. Краевой экстремум
    *   Алгоритм отыскания экстремальных значений функции, использующий только значения этой функции: ternary search, golden section

## **C. ИНТЕГРАЛЬНОЕ ИСЧИСЛЕНИЕ ФУНКЦИЙ ОДНОЙ ПЕРЕМЕННОЙ**

*   **Основы интегрирования:**
    *   Первообразная и неопределённый интеграл: F'(x) = f(x) → ∫f(x)dx = F(x) + C
    *   Понятие первообразной функции и неопределенного интеграла
    *   Таблица интегралов и основные методы интегрирования
    *   Основные свойства неопределенного интеграла: линейность, интегрирование по частям
    *   Таблица основных интегралов: ∫xⁿdx, ∫eˣdx, ∫sin x dx, ∫1/x dx и т.д.
    *   Основные методы интегрирования: непосредственное, подстановка, по частям

### **B. Неопределённый интеграл (часть 1)**
*   **Базовые методы:**
    *   Непосредственное интегрирование: использование таблицы и свойств
    *   Метод подстановки (замена переменной): ∫f(g(x))g'(x)dx = ∫f(u)du
    *   Метод интегрирования по частям: ∫u dv = uv − ∫v du

### **C. Неопределённый интеграл (часть 2)**
*   **Рациональные функции:**
    *   Интегрирование рациональных дробей: разложение на простейшие дроби

    *   Разложение рациональной функции на простейшие дроби: линейные, квадратичные множители, кратные корни

### **D. Неопределённый интеграл (часть 3)**
*   **Тригонометрические функции:**
    *   Интегрирование тригонометрических функций: замены t = tan(x/2), разложение на сумму
    *   ∫sin^m(x) cos^n(x) dx: методы для различных m, n
    *   Тригонометрические подстановки для иррациональностей

### **E. Неопределённый интеграл (часть 4)**
*   **Иррациональные функции:**
    *   Интегрирование иррациональных функций: замены корней
    *   Интегрирование дифференциальных биномов: ∫xᵐ(a+bxⁿ)ᵖ dx — критерии Чебышёва
    *   Классы функций, интегрируемых в элементарных функциях
    *   Эллиптические интегралы: полные и неполные, связь с геометрией

### **F. Определённый интеграл**
*   **Теория интеграла Римана:**
    *   Задачи, приводящие к понятию определенного интеграла: площадь, работа, масса
    *   Определённый интеграл как предел интегральных сумм: ∫ₐᵇ f(x)dx = lim Σf(ξᵢ)Δxᵢ
    *   Суммы Дарбу и критерии интегрируемости: разность верхних и нижних сумм → 0
    *   Теорема об интегрируемости кусочно-непрерывных функций
    *   Основные свойства определенного интеграла: линейность, аддитивность, монотонность
    *   Теоремы об оценке и о среднем значении: если m ≤ f ≤ M, то m(b−a) ≤ ∫ ≤ M(b−a)
    *   Определённый интеграл с переменным верхним пределом: Φ(x) = ∫ₐˣ f(t)dt → Φ'(x) = f(x)
    *   Формула Ньютона-Лейбница: ∫ₐᵇ f(x)dx = F(b) − F(a)
    *   Вычисление определенных интегралов: подстановка, по частям
    *   **Численное интегрирование:** метод прямоугольников, трапеций, Симпсона ( Simpson's Rule )

### **G. Приложения определённого интеграла**
*   **Геометрические и физические приложения:**
    *   Вычисление площадей плоских фигур: S = ∫ₐᵇ |f(x)−g(x)|dx
    *   Вычисление объемов тел: по площадям сечений (method of slices), объём тел вращения (disk/washer/shell methods)
    *   Вычисление длины дуги кривой: L = ∫ₐᵇ √(1 + (f'(x))²) dx
    *   Вычисление площади поверхности вращения: S = 2π ∫ₐᵇ f(x)√(1 + (f'(x))²) dx
    *   Масса, центр масс, моменты инерции через интегралы

### **H. Несобственный интеграл**
*   **Сходимость бесконечных интегралов:**
    *   Несобственные интегралы I рода (по бесконечному промежутку): ∫ₐ^∞ f(x)dx
    *   Несобственные интегралы II рода (от неограниченных функций): разрыв в точке c
    *   Признаки сходимости несобственных интегралов: сравнения, Даламбера, Коши
    *   Абсолютная и условная сходимость: ∫|f| < ∞ → абсолютная сходимость; ∫f < ∞ но ∫|f| = ∞ → условная

## **E. РЯДЫ**
> `e/e.md` · `e/e.cpp` · `struct Series : MultivariableCalculus`

### **A. Числовые ряды (часть 1)**
*   **Основы рядов:**
    *   Основные понятия (сходимость, сумма): sₙ = Σ(k=1..n) aₖ, s = lim sₙ
    *   Начальные сведения о числовых рядах. Критерий Коши для ряда: сходимость ⟺ остаток → 0
    *   Необходимый признак сходимости: lim aₙ = 0
    *   Ряд геометрической прогрессии: Σqⁿ сходится при |q| < 1, сумма = 1/(1−q)
    *   Гармонический ряд: Σ1/n — расходимый, но Σ1/nᵖ — сходится при p > 1
    *   Суммы арифметической прогрессии, геометрической прогрессии, гармонического ряда

### **B. Числовые ряды (часть 2)**
*   **Признаки сходимости:**
    *   Признак сравнения: если 0 ≤ aₙ ≤ bₙ и Σbₙ < ∞, то Σaₙ < ∞
    *   Признак Даламбера (отношений): lim |aₙ₊₁/aₙ| = L < 1 → абсолютная сходимость
    *   Признак Коши (радикальный): lim √|aₙ| = L < 1 → абсолютная сходимость
    *   Интегральный признак: Σaₙ и ∫f(x)dx сходятся или расходятся одновременно

### **C. Числовые ряды (часть 3)**
*   **Знакопеременные ряды:**
    *   Знакопеременные ряды: знакопеременные, абсолютная и условная сходимость
    *   Признак Лейбница: aₙ монотонно убывает к 0 → сходимость знакопеременных рядов
    *   Ряд Лейбница: Σ(−1)ⁿ/n = ln 2
    *   Абсолютная сходимость: Σ|aₙ| < ∞ →Σaₙ < ∞
    *   Условная сходимость: Σaₙ < ∞ но Σ|aₙ| = ∞ (перестановка меняет сумму!)

### **D. Функциональные ряды (часть 4)**
*   **Равномерная сходимость:**
    *   Область сходимости: множество x, где Σfₙ(x) сходится
    *   Равномерная сходимость: sup|sₙ(x)−s(x)| → 0
    *   Признак Вейерштрасса: |fₙ(x)| ≤ Mₙ, ΣMₙ < ∞ → равномерная сходимость
    *   Теоремы о равномерной сходимости: сохранение непрерывности, интегрирование, дифференцирование

### **E. Степенные ряды (часть 5)**
*   **Ряды Тейлора:**
    *   Теорема Абеля: сходимость на границе интервала
    *   Радиус и интервал сходимости: R = 1/lim sup |aₙ|^{1/n}
    *   Почленное интегрирование и дифференцирование: внутри интервала сходимости

### **F. Разложение функций в ряды (часть 6)**
*   **Разложения:**
    *   Ряд Тейлора и Маклорена: f(x) = Σ aₙxⁿ
    *   Maclaurin Series, Continued Fraction: eˣ, sin x, cos x, ln(1+x), (1+x)ᵅ
    *   Разложение элементарных функций: стандартные разложения для олимпиад
    *   Методы вывода разложений сложных функций: замена, умножение, деление рядов

### **G. Ряды Фурье (часть 7)**
*   **Тригонометрические разложения:**
    *   Тригонометрический ряд Фурье: f(x) = a₀/2 + Σ(aₙcos nx + bₙsin nx)
    *   Разложение функции в ряд Фурье: формулы для коэффициентов, сходимость

### **H. Применение рядов**
*   **Численные методы:**
    *   Приближенное вычисление значений функций: разложение в ряд и обрезка
    *   Вычисление интегралов через ряды: разложение подынтегральной функции
    *   **Интерполяция:** формула Ньютона и Лагранжа, оценка погрешности (остаточный член ряда Тейлора)

## **G. КОМПЛЕКСНЫЕ ЧИСЛА И ФУНКЦИИ КОМПЛЕКСНОГО ПЕРЕМЕННОГО (ТФКП)**

### **A. Комплексные числа**
*   **Алгебра комплексных чисел:**
    *   Алгебраическая форма: z = a + bi, a = Re(z), b = Im(z)
    *   Тригонометрическая форма: z = r(cos φ + i sin φ) = r e^{iφ}
    *   Показательная форма: z = re^{iφ} (формула Эйлера: e^{iφ} = cos φ + i sin φ)
    *   Действия с комплексными числами: сложение, умножение, деление, степень, корень
    *   Формула Муавра: zⁿ = rⁿ(cos nφ + i sin nφ)
    *   Извлечение корней: n корней из z = r e^{iφ}: zₖ = r^{1/n} e^{i(φ+2πk)/n}

### **B. Элементы ТФКП (часть 1)**
*   **Функции комплексного переменного:**
    *   Функция комплексного переменного (ФКП): w = f(z), область определения в ℂ
    *   Предел и непрерывность ФКП: lim_{z→z₀} f(z) = w₀, независимость от направления
    *   Основные элементарные ФКП: степенные, показательные, логарифм, тригонометрические, обратные
    *   Много значений: Log z, zᵅ — множественные функции, ветви, главная ветвь

### **C. Элементы ТФКП (часть 2)**
*   **Дифференцирование и интегрирование:**
    *   Дифференцирование ФКП: f'(z) = lim_{Δz→0} (f(z+Δz)−f(z))/Δz
    *   Условия Коши-Римана: ∂u/∂x = ∂v/∂y, ∂u/∂y = −∂v/∂x (аналитичность)
    *   Аналитические функции: гармонические компоненты, связь с потенциальными полями
    *   Интегрирование ФКП: ∫_C f(z) dz, теорема Коши, формула Коши для интегралов
    *   Теорема Коши: интеграл по замкнутому контуру = 0 для аналитической функции
    *   Формула Коши: f(z₀) = 1/(2πi) ∮ f(z)/(z−z₀) dz
    *   Следствия: единственность, принцип максимума, теорема Лиувилля

    *   Линейное однородное дифференциальное уравнение второго порядка: структура общего решения
    *   Свойства решений однородного линейного дифференциального уравнения
    *   Ядро линейного оператора
