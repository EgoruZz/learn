**E. РЯДЫ**

> **Архитектура:** `Series : MultivariableCalculus`. Числовые ряды (сходимость, признаки), знакопеременные, функциональные (равномерная сходимость), степенные, разложения (Тейлор/Маклорен), Фурье, приложения.

# **A. ЧИСЛОВЫЕ РЯДЫ (ЧАСТЬ 1)**

## **1. Основы рядов**

### **1.1. Определение**
* **Ряд:** Σ(k=1..∞) aₖ = lim(n→∞) sₙ, где sₙ = Σ(k=1..n) aₖ (последовательность частичных сумм)
* **Сходимость:** ряд сходится ⟺ последовательность частичных сумм сходится

### **1.2. Критерий Коши для ряда**
* Σaₙ сходится ⟺ ∀ε ∃N: |Σ(k=m+1..n) aₖ| < ε при n > m > N
* **Следствие:** lim aₙ = 0 (необходимое условие, но не достаточное!)

### **1.3. Стандартные ряды**
* **Геометрический:** Σqⁿ сходится при |q| < 1, сумма = 1/(1−q)
* **P-ряды:** Σ1/nᵖ сходится при p > 1, расходится при p ≤ 1
* **Гармонический:** Σ1/n — расходится

# **B. ЧИСЛОВЫЕ РЯДЫ (ЧАСТЬ 2)**

## **1. Признаки сходимости**

### **1.1. Сравнения**
* **Прямое:** 0 ≤ aₙ ≤ bₙ, Σbₙ < ∞ ⟹ Σaₙ < ∞
* **Предел:** lim aₙ/bₙ = L, 0 < L < ∞ ⟹ оба сходятся/расходятся

### **1.2. Даламбер (отношений)**
* lim |aₙ₊₁/aₙ| = L: L < 1 →绝对收敛; L > 1 → расходимость; L = 1 → неопределённый

### **1.3. Коши (радикальный)**
* lim √|aₙ| = L: L < 1 →绝对收敛; L > 1 → расходимость

### **1.4. Интегральный признак**
* f монотонно убывает, aₙ = f(n) ⟹ Σaₙ и ∫₁^∞ f(x)dx сходятся одновременно

---

# **C. ЧИСЛОВЫЕ РЯДЫ (ЧАСТЬ 3)**

## **1. Знакопеременные ряды**

### **1.1. Признак Лейбница**
* aₙ ≥ 0, aₙ монотонно убывает, lim aₙ = 0 ⟹ Σ(−1)ⁿaₙ сходится

### **1.2. Абсолютная и условная сходимость**
* **Абсолютная:** Σ|aₙ| < ∞ ⟹ Σaₙ < ∞
* **Условная:** Σaₙ < ∞, но Σ|aₙ| = ∞ (например, Σ(−1)ⁿ/n)

---

# **D. ФУНКЦИОНАЛЬНЫЕ РЯДЫ**

## **1. Равномерная сходимость**

### **1.1. Определение**
* Σfₙ(x) равномерно сходится ⟺ sup|sₙ(x)−s(x)| → 0

### **1.2. Признак Вейерштрасса**
* |fₙ(x)| ≤ Mₙ для всех x, ΣMₙ < ∞ ⟹ равномерная сходимость

### **1.3. Свойства**
* Сумма непрерывных равномерно сходящихся функций — непрерывна
* Интегрирование и дифференцирование по членам ряда

---

# **E. СТЕПЕННЫЕ РЯДЫ**

## **1. Степенные ряды**

### **1.1. Форма:** Σ aₙ(x−a)ⁿ

### **1.2. Радиус и интервал сходимости**
* R = 1/lim sup |aₙ|^{1/n} (или через Даламбер: R = lim |aₙ/aₙ₊₁|)
* Интервал: (a−R, a+R) ± границы

### **1.3. Теорема Абеля**
* Если сходится на границе, то ряд непрерывен до этой границы

### **1.4. Почленные операции**
* Внутри интервала сходимости: интегрирование и дифференцирование по членам

# **F. РАЗЛОЖЕНИЕ ФУНКЦИЙ В РЯДЫ**

## **1. Разложения**

### **1.1. Стандартные разложения (Маклорен)**
* eˣ = Σ xᵏ/k!, sin x = Σ (−1)ᵏ x²ᵏ⁺¹/(2k+1)!, cos x = Σ (−1)ᵏ x²ᵏ/(2k)!
* ln(1+x) = Σ (−1)ᵏ⁺¹ xᵏ/k, (1+x)ᵅ = Σ C(α,k)xᵏ, arctan x = Σ (−1)ᵏ x²ᵏ⁺¹/(2k+1)

### **1.2. Методы вывода**
* Замена переменной: sin(x²) → подстановка в ряд для sin
* Умножение рядов: (Σaₙ)(Σbₙ) = Σcₙ, cₙ = Σ aₖbₙ₋ₖ
* Деление рядов: Σaₙ/Σbₙ
* Интегрирование/дифференцирование

# **G. РЯДЫ ФУРЬЕ**

## **1. Тригонометрические разложения**

### **1.1. Ряд Фурье**
* f(x) = a₀/2 + Σ(aₙcos nx + bₙsin nx)
* aₙ = (1/π)∫f(x)cos nx dx, bₙ = (1/π)∫f(x)sin nx dx

### **1.2. Сходимость**
* В точках непрерывности: ряд сходится к f(x)
* В точках разрыва: среднее от левого и правого пределов
