**B. ДИФФЕРЕНЦИАЛЬНОЕ ИСЧИСЛЕНИЕ ФУНКЦИЙ ОДНОЙ ПЕРЕМЕННОЙ**

> **Архитектура:** `DifferentialCalculus : LimitsAndContinuity`. Определение через предел, правила дифференцирования, производные высших порядков, ряд Тейлора, основные теоремы (Ролля, Лагранжа, Коши), исследование функций.
> **Связи:** пределы → analysis/a; выпуклость/Йенсен → combinatorics; многочлены (интерполяция) → algebra/a.

# **A. ПРОИЗВОДНЫЕ И ДИФФЕРЕНЦИАЛЫ (ЧАСТЬ 1)**

## **1. Основы дифференцирования**

### **1.1. Определение производной**
* f'(x₀) = lim(h→0) (f(x₀+h) − f(x₀))/h — наклон касательной
* Геометрический смысл: касательная к графику в (x₀, f(x₀))
* Физический смысл: скорость v(t₀) = s'(t₀)
* Производная существует ⟺ f'₋(x₀) = f'₊(x₀)

### **1.2. Касательная к графику**
* y = f(a) + f'(a)(x − a)
* Линейное приближение: f(x) ≈ f(a) + f'(a)(x − a)

### **1.3. Недифференцируемость**
* |x| в 0: f'₋ = −1, f'₊ = 1 → нет производной
* Причины: угол, вертикальная касательная, разрыв, осцилляции
* Дифференцируемость ⟹ непрерывность (обратное неверно!)

### **1.4. Правила дифференцирования**
* **Линейность:** (αf + βg)' = αf' + βg'
* **Лейбница:** (fg)' = f'g + fg'
* **Частное:** (f/g)' = (f'g − fg')/g²
* **Цепное правило:** (f∘g)' = f'(g)·g'
* **Обратная:** (f⁻¹)'(y) = 1/f'(x)

### **1.5. Dual Number Automatic Differentiation**
* z = a + bε, ε² = 0; f(x+ε) = f(x) + f'(x)ε — точное!
* Арифметика: (a+bε)(c+dε) = ac + (ad+bc)ε
* Преимущество: вычисляет производную точно за одно вычисление f

# **B. ПРОИЗВОДНЫЕ И ДИФФЕРЕНЦИАЛЫ (ЧАСТЬ 2)**

## **1. Специальные виды дифференцирования**

### **1.1. Логарифмическая производная**
* (ln|f(x)|)' = f'(x)/f(x)
* Удобна для произведений: f = Π gᵢ^{αᵢ} → f'/f = Σ αᵢ gᵢ'/gᵢ

### **1.2. Степенная и показательная**
* (xᵅ)' = αxᵅ⁻¹ для всех α ∈ ℝ, x > 0
* (aˣ)' = aˣ ln a; (eˣ)' = eˣ
* (log_a x)' = 1/(x ln a); (ln x)' = 1/x

### **1.3. Производная неявной функции**
* F(x,y) = 0, ∂F/∂y ≠ 0 → dy/dx = −Fₓ/F_y
* Дифференцируем обе части по x, y как функция x

### **1.4. Параметрическое дифференцирование**
* x = x(t), y = y(t) → dy/dx = y'(t)/x'(t)
* Вторая: d²y/dx² = (y''x' − y'x'')/(x')³

### **1.5. Производная векторной функции**
* r(t) = (x₁(t),...,xₙ(t)) → r'(t) = (x₁'(t),...,xₙ'(t))
* (r₁·r₂)' = r₁'·r₂ + r₁·r₂'

### **1.6. Дифференциал**
* dy = f'(x)dx — линейное приближение
* Инвариантность формы: dy не зависит от выбора переменной

### **1.7. Дифференцируемость**
* f дифференцируема ⟺ ∃A: f(a+h) − f(a) = Ah + o(h); A = f'(a)
* Дифференцируемость ⟹ непрерывность (обратное неверно!)

# **C. ПРОИЗВОДНЫЕ ВЫСШИХ ПОРЯДКОВ**

## **1. Высшие производные и дифференциалы**

### **1.1. Производные высших порядков**
* f⁽ⁿ⁾(x) = (f⁽ⁿ⁻¹⁾)'(x); (eˣ)⁽ⁿ⁾ = eˣ; (sin x)⁽ⁿ⁾ = sin(x + nπ/2)
* (xᵅ)⁽ⁿ⁾ = α(α−1)...(α−n+1)xᵅ⁻ⁿ

### **1.2. Дифференциалы высших порядков**
* dⁿy = f⁽ⁿ⁾(x)dxⁿ при фиксированном x
* Инвариантность: d¹y = f'dx инвариантна; d²y = f''dx² + f'd²x — НЕ инвариантна

### **1.3. Формула Лейбница**
* (fg)⁽ⁿ⁾ = Σ(k=0..n) C(n,k) f⁽ᵏ⁾ g⁽ⁿ⁻ᵏ⁾
* Доказательство: индукция по n

# **D. РЯД ТЕЙЛОРА И ПРИМЕНЕНИЯ**

## **1. Правило Лопиталя**

### **1.1. Неопределённость 0/0**
* Условия: lim f = lim g = 0; f, g дифференцируемы; lim f'/g' существует
* Результат: lim f/g = lim f'/g'

### **1.2. Неопределённость ∞/∞**
* Аналогично 0/0

### **1.3. Другие неопределённости**
* 0·∞ → f/(1/g); ∞−∞ → общий знаменатель; 1^∞ → exp(lim g·(f−1))

## **2. Формула Тейлора**

### **2.1. Полином Тейлора**
* f(x) = Σ(k=0..n) f⁽ᵏ⁾(a)/k! (x−a)ᵏ + Rₙ(x)
* Маклорен: a = 0

### **2.2. Остаточный член**
* Коши/Лагранж: Rₙ = f⁽ⁿ⁺¹⁾(ξ)/(n+1)! (x−a)ⁿ⁺¹
* Интегральная: Rₙ = ∫ₐˣ f⁽ⁿ⁺¹⁾(t)/n! (x−t)ⁿ dt

### **2.3. Стандартные разложения**
* eˣ = Σ xᵏ/k!, sin x = Σ (−1)ᵏ x²ᵏ⁺¹/(2k+1)!, cos x = Σ (−1)ᵏ x²ᵏ/(2k)!
* ln(1+x) = Σ (−1)ᵏ⁺¹ xᵏ/k, (1+x)ᵅ = Σ C(α,k) xᵏ, arctan x = Σ (−1)ᵏ x²ᵏ⁺¹/(2k+1)

### **2.4. Аналитические функции**
* f аналитична ⟺ f(x) = Σ aₖ(x−a)ᵏ сходится в окрестности
* Единственность разложения

# **E. ОСНОВНЫЕ ТЕОРЕМЫ**

## **1. Фундаментальные теоремы**

### **1.1. Связь дифференцируемости и непрерывности**
* f дифференцируема ⟹ непрерывна (обратное неверно!)

### **1.2. Теорема Ролля**
* f на [a,b], f(a) = f(b) ⟹ ∃c ∈ (a,b): f'(c) = 0

### **1.3. Формула Лагранжа**
* f на [a,b], дифференцируема на (a,b) ⟹ ∃ξ: f(b)−f(a) = f'(ξ)(b−a)
* Следствия: f' = 0 ⟹ const; f' > 0 ⟹ возрастает

### **1.4. Формула Коши**
* f, g на [a,b], g' ≠ 0 ⟹ ∃ξ: (f(b)−f(a))/(g(b)−g(a)) = f'(ξ)/g'(ξ)

---

# **F. ИССЛЕДОВАНИЕ ФУНКЦИЙ**

## **1. Экстремумы и монотонность**

### **1.1. Необходимое условие:** f'(a) = 0 или f'(a) не существует
### **1.2. Первый признак:** смена знака f' → экстремум
### **1.3. Второй признак:** f' = 0, f'' < 0 → макс; f'' > 0 → мин
### **1.4. Монотонность:** f' ≥ 0 → возрастает; f' ≤ 0 → убывает

## **2. Выпуклость и перегибы**

### **2.1. Выпуклость:** f'' ≥ 0 ↔ выпукла вниз; Йенсен: f(Σαᵢxᵢ) ≤ Σαᵢf(xᵢ)
### **2.2. Вогнутость:** f'' ≤ 0
### **2.3. Перегибы:** f'' = 0 и смена знака

## **3. Асимптоты**

### **3.1. Вертикальные:** x = a, lim f = ±∞
### **3.2. Горизонтальные:** lim(x→∞) f(x) = b
### **3.3. Наклонные:** k = lim f(x)/x, b = lim (f(x)−kx)

## **4. Алгоритм исследования**
1. Область определения → 2. Чётность → 3. Асимптоты → 4. f' (монотонность, экстремумы) → 5. f'' (выпуклость, перегибы) → 6. График

## **5. Методы решения уравнений**

### **5.1. Бисекция:** O(log((b−a)/ε)), гарантирована сходимость
### **5.2. Ньютон:** xₙ₊₁ = xₙ − f/f', квадратичная сходимость
### **5.3. Секущие:** без вычисления f', суперквадратичная

## **6. Интерполяция**

### **6.1. Лагранж:** P(x) = Σ yᵢ·Π(j≠i) (x−xⱼ)/(xᵢ−xⱼ)
### **6.2. Ньютон:** разделённые разности, O(n) на добавление точки

## **7. Краевой экстремум**
* Ternary search: O(log((b−a)/ε))
* Золотое сечение: деление в отношении φ = (1+√5)/2
