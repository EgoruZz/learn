# **A. ОСНОВНЫЕ ПРЕОБРАЗОВАНИЯ**

## **1. Яркость**

### **1.1. Формула**
* `I'(x,y) = I(x,y) + c` — сдвиг гистограммы на `c`
* `c > 0` → осветление, `c < 0` → затемнение

## **2. Контраст**

### **2.1. Формула**
* `I'(x,y) = (I(x,y) − 128) · c + 128` — масштабирование относительно среднего
* `c > 1` → увеличение контраста, `0 < c < 1` → уменьшение

## **3. Негатив**

### **3.1. Формула**
* `I'(x,y) = 255 − I(x,y)` — инвертирование значений яркости

## **4. Сепия**

### **4.1. Формула**
* `R' = 0.393R + 0.769G + 0.189B`
* `G' = 0.349R + 0.686G + 0.168B`
* `B' = 0.272R + 0.534G + 0.131B`

# **B. DITHERING**

## **1. Burkes Dithering**

### **1.1. Алгоритм**
* Улучшенный Floyd-Steinberg: распределение ошибки на 8 соседей (а не 3)
* **Веса:** текущий пиксель получает ошибку; распределяется на:
    * Вправо: 8/16
    * Вниз-влево: 4/16
    * Вниз: 5/16
    * Вниз-вправо: 3/16
    * + 4 дополнительных соседа второй строки

# **C. ОБНАРУЖЕНИЕ КРАЁВ (CANNY)**

## **1. Этапы алгоритма**

### **1.1. Гауссово сглаживание**
* Фильтр Гаусса: `G(x,y) = (1/2πσ²) · e^{−(x²+y²)/2σ²}`
* Ядро: матрица свёртки, нормализованная

### **1.2. Вычисление градиента**
* Фильтры Собеля: `Gx`, `Gy` — горизонтальный и вертикальный градиенты
* Амплитуда: `|G| = √(Gx² + Gy²)`
* Направление: `θ = atan2(Gy, Gx)`

### **1.3. Подавление немаксимумов**
* Для каждого пикселя: если `|G|` не является максимумом вдоль направления градиента → обнулить

### **1.4. Двойная пороговая фильтрация (hysteresis)**
* Сильные пиксели (`|G| > high`) → граница
* Слабые пиксели (`low < |G| < high`) → граница если сосед сильный
* Остальные → не граница

# **D. ФИЛЬТРЫ**

## **1. Гауссов фильтр**
* **Назначение:** размытие, сглаживание
* **Ядро:** `G(x,y) = e^{−(x²+y²)/2σ²}`, нормализованное

## **2. Фильтр Собеля**
* **Назначение:** вычисление градиента
* **Ядра:** `Gx = [[−1,0,1],[−2,0,2],[−1,0,1]]`, `Gy = [[−1,−2,−1],[0,0,0],[1,2,1]]`
* **Амплитуда:** `|G| = √(Gx² + Gy²)`

## **3. Лапласиан**
* **Назначение:** выделение границ (вторая производная)
* **Ядро:** `[[0,1,0],[1,−4,1],[0,1,0]]` или `[[1,1,1],[1,−8,1],[1,1,1]]`

## **4. Медианный фильтр**
* **Назначение:** устранение шума «соль и перец» без размытия границ
* **Метод:** замена центрального пикселя медианой окрестности

## **5. Билатеральный фильтр**
* **Назначение:** сглаживание с сохранением границ
* **Вес:** `w = G_spatial · G_range` — пространственное + по яркости
* **Результат:** размывает однородные области, сохраняет границы

## **6. Габор-фильтр**
* **Назначение:** выделение текстур в заданном направлении
* **Формула:** `K(x,y) = G(x,y) · sin(2π(ux + vy)/λ)`
* **Параметры:** `u,v` — направление, `λ` — длина волны, `σ` — ширинa

## **7. LBP (Local Binary Pattern)**
* **Назначение:** описание текстуры
* **Метод:** сравнение中心 пикселя с 8 соседями → 8-битный код
* **Применение:** классификация текстур, распознавание лиц

## **8. Свёртка**
* **Формула:** `I' = I * K` — свёртка изображения `I` с ядром `K`
* **Общая операция:** все линейные фильтры реализуются через свёртку

# **E. ГИСТОГРАММА**

## **1. Эквализация**
* `I'(x) = CDF(I(x))` — преобразование через кумулятивную функцию распределения
* Результат: равномерное распределение яркостей → улучшение контраста

## **2. Растяжение (Histogram Stretch)**
* Линейное масштабирование: `I'(x) = (I(x) − min) · 255 / (max − min)`
* Простая альтернатива эквализации

---

# **F. МОРФОЛОГИЧЕСКИЕ ОПЕРАЦИИ**

## **1. Дилатация**
* `I'(x) = max{I(y) : y ∈ N(x)}` — расширение белых областей
* **Ядро:** структурный элемент (прямоугольник, круг)

## **2. Эрозия**
* `I'(x) = min{I(y) : y ∈ N(x)}` — сужение белых областей

---

# **G. ГЕОМЕТРИЧЕСКИЕ ПРЕОБРАЗОВАНИЯ**

## **1. Resize**
* **Nearest Neighbor:** ближайший пиксель — быстро, но «զернистое»
* **Bilinear:** взвешенное среднее 4 соседей — гладкое
* **Bicubic:** взвешенное среднее 16 соседей — лучшее качество

## **2. Rotation**
* **Матрица поворота:** `R(θ) = [[cos θ, −sin θ], [sin θ, cos θ]]`
* **Обратная интерполяция:** для каждого пикселя выхода найти соответствующий во входе
