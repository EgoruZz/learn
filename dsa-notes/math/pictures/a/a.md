# **A. КРИВЫЕ БЕЗЬЕ**

## **1. Линейная кривая Безье**

### **1.1. Определение**
* Кривая первого порядка: `B(t) = (1−t)P₀ + tP₁`, `t ∈ [0, 1]`
* **Свойства:** отрезок `[P₀, P₁]`; касательная в `t=0`: направление `P₁ − P₀`

## **2. Квадратичная кривая Безье**

### **2.1. Определение**
* Кривая второго порядка: `B(t) = (1−t)²P₀ + 2(1−t)tP₁ + t²P₂`
* **Контрольные точки:** `P₀` (начало), `P₁` (управление), `P₂` (конец)
* **Свойства:** параболический сегмент; касательная в `t=0`: `2(P₁ − P₀)`, в `t=1`: `2(P₂ − P₁)`

## **3. Кубическая кривая Безье**

### **3.1. Определение**
* Кривая третьего порядка: `B(t) = (1−t)³P₀ + 3(1−t)²tP₁ + 3(1−t)t²P₂ + t³P₃`
* **Контрольные точки:** `P₀` (начало), `P₁`, `P₂` (управление), `P₃` (конец)
* **Свойства:** используется в векторной графике (SVG, PostScript); наибольшая гибкость

## **4. Алгоритм де Кастельжо**

### **4.1. Идея**
* Рекурсивное разбиение: на каждом шаге строим промежуточные точки
* Для n контрольных точек: `n−1` рекурсивных вызовов
* **Стабильность:** численно устойчив (в отличие от прямого вычисления полинома)

### **4.2. Сложность**
* O(n) на одну точку кривой (где n — порядок)
* Рисование k точек: O(k · n)

# **B. ЦИФРОВАЯ ДИФФЕРЕНЦИАЛЬНАЯ АНАЛИЗА (DDA)**

## **1. Алгоритм**

### **1.1. Идея**
* Пошаговая растеризация отрезка `[A, B]`
* Вычисляем `Δx = (B.x − A.x) / steps`, `Δy = (B.y − A.y) / steps`
* На каждом шаге: `x += Δx`, `y += Δy`, рисуем пиксель `(round(x), round(y))`

### **1.2. Число шагов**
* `steps = max(|Δx|, |Δy|)` где `Δx = B.x − A.x`, `Δy = B.y − A.y`
* Если `|Δx| > |Δy|`: шагаем по x (инкремент 1), вычисляем y
* Иначе: шагаем по y, вычисляем x

### **1.3. Сложность**
* O(max(|Δx|, |Δy|)) — линейная от длины отрезка в пикселях

# **C. VECTOR3 ДЛЯ 2D РЕНДЕРИНГА**

## **1. Структура и операции**

### **1.1. Определение**
* `(x, y, z)` — для 2D: `z = 0` (плоскость)
* **Сложение:** `A + B = (x₁+x₂, y₁+y₂, z₁+z₂)`
* **Умножение на скаляр:** `c·A = (c·x, c·y, c·z)`

### **1.2. Нормализация**
* **Длина:** `|A| = √(x² + y² + z²)`
* **Единичный вектор:** `Â = A / |A|`

### **1.3. Скалярное произведение**
* `A · B = x₁x₂ + y₁y₂ + z₁z₂ = |A|·|B|·cos(θ)`
* Применение: определение угла, проекция одного вектора на другой

### **1.4. Векторное произведение (2D)**
* `A × B = x₁y₂ − x₂y₁` — signed area параллелограмма
* Положительное → левый поворот, отрицательное → правый, 0 → коллинеарность
* **Предикат ориентации:** `orient(A, B, C) = sign((B−A) × (C−A))`

# **D. УЗОР «БАБОЧКА»**

## **1. Параметрические уравнения**

### **1.1. Lissajous-фигуры**
* `x(t) = A·sin(a·t + δ)`
* `y(t) = B·sin(b·t)`
* **Параметры:** `a`, `b` — частоты, `δ` — фазовый сдвиг, `A`, `B` — амплитуды

### **1.2. Свойства**
* При `a/b` рациональном: замкнутая кривая
* При `a/b` иррациональном: кривая плотно заполняет прямоугольник `[−A, A] × [−B, B]`
* **Симметрия:** при `δ = π/2` и `a = b` — эллипс
