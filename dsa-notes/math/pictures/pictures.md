## **A. ГРАФИКА**
> `a/a.md` · `a/a.cpp` · `struct GraphicsBasics` — базовый класс всей ветки pictures

### **A. Кривые Безье**
*   **Линейная:** `B(t) = (1−t)P₀ + tP₁`, `t ∈ [0, 1]`
*   **Квадратичная:** `B(t) = (1−t)²P₀ + 2(1−t)tP₁ + t²P₂`
*   **Кубическая:** `B(t) = (1−t)³P₀ + 3(1−t)²tP₁ + 3(1−t)t²P₂ + t³P₃
*   **Алгоритм де Кастельжо:** рекурсивное разбиение на отрезки ( numerically stable)
*   **Свойства:** касательная в начальной точке `P₁ − P₀`, в конечной `Pₙ − Pₙ₋₁`; выпуклая оболочка контрольных точек

### **B. Цифровая дифференциальная анализа (DDA)**
*   **Алгоритм:** пошаговая растеризация отрезка `[A, B]`
*   **Шаг:** `Δx = (B.x − A.x) / max(|Δx|, |Δy|)`, `Δy = ...`
*   **Сложность:** O(max(|Δx|, |Δy|))
*   **Применение:** рисование линий в растровой графике

### **C. Vector3 для 2D рендеринга**
*   **Структура:** `(x, y, z)` — для 2D: `z = 0` (плоскость)
*   **Операции:** сложение `A + B`, умножение на скаляр `c·A`
*   **Нормализация:** `Â = A / |A|` — единичный вектор направления
*   **Dot product:** `A · B = |A|·|B|·cos(θ)` — проекция одного на другой
*   **Cross product (2D):** `A × B = x₁y₂ − x₂y₁` —signed area

### **D. Узор «бабочка»**
*   **Параметрические уравнения:** Lissajous-фигуры
*   **Формулы:** `x = A·sin(a·t + δ)`, `y = B·sin(b·t)` — симметричные паттерны
*   **Применение:** тестирование графических примитивов, демонстрация параметрических кривых

## **B. ЦИФРОВАЯ ОБРАБОТКА ИЗОБРАЖЕНИЙ**
> `b/b.md` · `b/b.cpp` · `struct ImageProcessing : GraphicsBasics`

### **A. Основные преобразования яркости/контраста**
*   **Яркость:** `I'(x,y) = I(x,y) + c` — сдвиг гистограммы на `c`
*   **Контраст:** `I'(x,y) = (I(x,y) − 128) · c + 128` — масштабирование относительно среднего
*   **Негатив:** `I'(x,y) = 255 − I(x,y)` — инвертирование
*   **Сепия:** `R' = 0.393R + 0.769G + 0.189B`, `G' = 0.349R + 0.686G + 0.168B`, `B' = 0.272R + 0.534G + 0.131B`

### **B. Dithering**
*   **Burkes Dithering:** Floyd-Steinberg с расширенной областью ошибки (8 соседей вместо 3)
*   **Применение:** уменьшение цветового пространства (например, 24-bit → 8-bit) без потери субъективного качества

### **C. Обнаружение краёв (Canny Edge Detection)**
1.  **Гауссово сглаживание:** фильтр Гаусса `G(x,y) = e^{−(x²+y²)/2σ²}` — устранение шума
2.  **Вычисление градиента:** фильтры Собеля `Gx`, `Gy`; амплитуда `|G| = √(Gx² + Gy²)`
3.  **Подавление немаксимумов:** оставить только локальные максимумы градиента
4.  **Двойная пороговая фильтрация (hysteresis):** сильные → граница, слабые → граница если сосед сильный

### **D. Фильтры**
*   **Гауссов:** размытие/сглаживание; ядро `G(x,y) = e^{−(x²+y²)/2σ²}`, нормализованное
*   **Собеля:** вычисление градиента `Gx`, `Gy`; амплитуда `|G| = √(Gx² + Gy²)` — выделение границ
*   **Лапласиан:** `∇²I = ∂²I/∂x² + ∂²I/∂y²` — выделение границ (вторая производная)
*   **Медианный:** замена пикселя медианой окрестности — устранение шума «соль и перец» без размытия границ
*   **Билатеральный:** сглаживание с сохранением границ (взвешивание по расстоянию + разности яркостей)
*   **Габор:** `K(x,y) = G(x,y) · sin(2π(ux + vy)/λ)` — выделение текстур в заданном направлении
*   **LBP (Local Binary Pattern):** сравнение中心 пикселя с 8 соседями → 8-битный код текстуры
*   **Свёртка:** `I' = I * K` — общая операция для всех линейных фильтров

### **E. Гистограмма изображения**
*   **Эквализация:** `I'(x) = CDF(I(x))` → равномерное распределение яркостей → улучшение контраста
*   **Растяжение (Stretch):** линейное масштабирование `[min, max]` → `[0, 255]`

### **F. Морфологические операции**
*   **Дилатация:** `I'(x) = max{I(y) : y ∈ N(x)}` — расширение белых областей
*   **Эрозия:** `I'(x) = min{I(y) : y ∈ N(x)}` — сужение белых областей
*   **Применение:** устранение шума, соединение разрывов, извлечение компонент связности

### **G. Геометрические преобразования**
*   **Resize:** интерполяция (nearest neighbor, bilinear, bicubic)
*   **Rotation:** матрица поворота `R(θ) = [[cos θ, −sin θ], [sin θ, cos θ]]`; обратная интерполяция для точности
