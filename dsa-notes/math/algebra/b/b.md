**II. ДЕЛЕНИЕ С ОСТАТКОМ И ТЕОРЕМА БЕЗУ**

> **Архитектура:** `Division` (b.cpp) — класс ветки algebra, наследует `Polynomials` (a.cpp). Переиспользует: схему Горнера для деления на линейный двучлен (a.cpp, B.5), формальное дифференцирование для кратных корней (a.cpp, B.6), формальное обращение для быстрого деления (a.cpp, B.8). ## **A. ДЕЛЕНИЕ С ОСТАТКОМ**

### **1. Теорема о делении**
* **Формулировка:** для любых P, D ∈ K[x], D ≠ 0, существуют唯一 Q, R ∈ K[x] такие что P = QD + R и deg R < deg D
* **Единственность:** если P = Q₁D + R₁ = Q₂D + R₂, то (Q₁−Q₂)D = R₂−R₁; слева степень ≥ deg D, справа < deg D → Q₁ = Q₂, R₁ = R₂

### **2. Алгоритм деления «уголком»**
* **Наивный:** на каждом шаге вычитаем (lc(R)/lc(D)) · x^{deg R − deg D} · D из R
* **Число шагов:** deg P − deg D + 1
* **Сложность:** O(n · m) где n = deg P, m = deg D
* **Обобщение:** параметр — кольцо коэффициентов (для ℤ[x] — субрезультатный алгоритм, раздел III, c)

### **3. Деление через Горнера (на линейный двучлен)**
* **Формула:** P(x) = Q(x)·(x − a) + P(a)
* **Реализация:** `horner_extended` из a.cpp, B.5 — одновременно частное и остаток

### **4. Деление на (xᵐ − a) и (xᵐ + a)**
* **P(x) mod (xᵐ − a):** циклический сдвиг коэффициентов: cᵢ = ∑_{j≡i (mod m)} aⱼ · a^{⌊j/m⌋}
* **P(x) mod (xᵐ + a):** знакопеременный сдвиг: cᵢ = ∑_{j≡i (mod m)} aⱼ · (−a)^{⌊j/m⌋}

## **B. ТЕОРЕМА БЕЗУ И СЛЕДСТВИЯ**

### **5. Теорема Безу**
* **Формулировка:** P(a) = 0 ⟺ (x − a) | P(x)
* **Доказательство:** P(x) = Q(x)·(x − a) + R; deg R < 1 ⟹ R = const; P(a) = 0 ⟹ R = 0
* **Обобщение:** P(x) mod (x − a) = P(a) — остаток от деления

### **6. Кратность корня**
* **Определение:** (x − a)ᵏ | P(x) и (x − a)^{k+1} ∤ P(x) ⟹ a — корень кратности k
* **Критерий:** a — корень кратности ≥ k ⟺ P(a) = P'(a) = ... = P^{(k−1)}(a) = 0
* **Связь с производной:** P(x) = (x − a)ᵏ Q(x), Q(a) ≠ 0 ⟹ P'(x) = k(x − a)^{k−1} Q(x) + (x − a)ᵏ Q'(x) → P'(a) = 0 если k ≥ 2

### **7. Количество корней**
* **Теорема:** многочлен степени n имеет не более n корней (в целой области)
* **Следствие:** если P(x) = Q(x) для |K| > deg P, то P ≡ Q (принцип уникальности)
