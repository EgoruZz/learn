## **A. АЛГОРИТМЫ УМНОЖЕНИЯ**

### **1. Наивный алгоритм**
* **Сложность:** O(n·m) — умножение каждого на каждый
* **Когда использовать:** малые n, m (< 64)

### **2. Алгоритм Карацубы**
* **Идея:** P = P₁xᵏ + P₀, Q = Q₁xᵏ + Q₀; PQ = P₁Q₁x²ᵏ + ((P₁+P₀)(Q₁+Q₀) − P₁Q₁ − P₀Q₀)xᵏ + P₀Q₀
* **3 умножения вместо 4:** T(n) = 3T(n/2) + O(n) → O(n^{log₂3}) ≈ O(n^{1.585})
* **Рекурсия:** разбиение пополам на каждом шаге

### **3. Toom-Cook (Toom-3, Toom-k)**
* **Идея:** разбиение на k частей → 2k−1 умножений
* **Toom-3:** 5 умножений, O(n^{log₃5}) ≈ O(n^{1.465})
* **Обобщение Карацубы:** параметр k — число частей

### **4. Алгоритм Шёнхаге-Штрассена**
* **Сложность:** O(n log n log log n) — через FFT в ℤ/2^mℤ
* **Исторически:** первый полиномиальный алгоритм для длинного умножения

## **B. БЫСТРОЕ ПРЕОБРАЗОВАНИЕ ФУРЬЕ (FFT)**

### **5. Дискретное преобразование Фурье (DFT)**
* **Определение:** Aₖ = ∑_{j=0}^{n−1} aⱼ ωₙ^{jk} где ωₙ = e^{2πi/n}
* **Матрица:** F_{jk} = ωₙ^{jk} — ортогональная (с точностью до нормировки)

### **6. Алгоритм Кули-Тьюки (FFT)**
* **Разбиение:** A(x) = A_{чёт}(x²) + x A_{нечёт}(x²)
* **Рекурсия:** T(n) = 2T(n/2) + O(n) → O(n log n)
* **Итеративная реализация:** bit-reversal перестановка + бабочки

### **7. Обратное преобразование (IFFT)**
* **Формула:** aₖ = (1/n) ∑ Aⱼ ωₙ^{−jk}
* **Реализация:** то же FFT, но с ωₙ⁻¹ и нормировкой 1/n

### **8. Умножение многочленов через FFT**
* **Шаг 1:** интерполяция a → A, b → B через FFT — O(n log n)
* **Шаг 2:** покоординатное умножение Cₖ = Aₖ · Bₖ — O(n)
* **Шаг 3:** обратное преобразование C → c — O(n log n)
* **Итого:** O(n log n) с точностью до выбора «длинного» модуля

### **9. FFT в конечных полях (NTT)**
* **Замена:** комплексные корни → корни в 𝔽_p: g^{(p−1)/n}
* **Модули:** 998244353, 1004535809, 469762049
* **Китайская теорема об остатках (CRT):** объединение результатов по нескольким модулям

### **10. Свёртка через FFT**
* **Свёртка:** cₖ = ∑ aᵢbⱼ при i+j=k
* **Вычисление:** DFT(a), DFT(b), поэлементное умножение, IDFT — O(n log n)
