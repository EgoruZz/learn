**I. ОСНОВЫ МНОГОЧЛЕНОВ**

> **Архитектура:** `Polynomials` (a.cpp) — базовый класс ветки algebra. Вводит определение многочлена, кольцо K[x] (сложение, умножение, свёртку), подстановку (схему Горнера), формальное дифференцирование и композицию. Не зависит от других веток algebra, но используется всеми последующими разделами (b–k). Собственной арифметики не вводит (модулярная арифметика — `number-theory`).
>
> **Связи:** модулярная арифметика для вычислений по модулю p — `math/number-theory`; многочлены как основа FFT/NTT — раздел VII (g); интерполяция — раздел VI (f); симметрические многочлены — раздел XI (k); комбинаторные тождества через производящие функции — раздел X (j); символьные вычисления и AST — `struct` (раздел IX).

## **A. ОПРЕДЕЛЕНИЕ И КОЛЬЦО МНОГОЧЛЕНОВ**

### **1. Многочлен от одной переменной**
* **Определение:** P(x) = ∑_{i=0}^{n} aᵢ xⁱ — формальная сумма; aᵢ ∈ K (кольцо коэффициентов: ℤ, ℚ, ℝ, ℂ, 𝔽_p)
* **Степень:** deg P = max{i : aᵢ ≠ 0}; deg 0 = −∞
* **Старший коэффициент:** lc(P) = a_{deg P}; нормированный: lc(P) = 1
* **Каноническая форма:** упорядоченные степени с ненулевыми коэффициентами
* **Равенство:** P = Q ⟺ aᵢ = bᵢ для всех i

### **2. Кольцо многочленов K[x]**
* **Сложение:** (P + Q)(x) = ∑ (aᵢ + bᵢ) xⁱ
* **Умножение (свертка):** (PQ)(x) = ∑_k (∑_{i+j=k} aᵢ bⱼ) xᵏ
* **Свойства:** ассоциативность, коммутативность, дистрибутивность, единица 1
* **Степень произведения:** deg(PQ) = deg P + deg Q (для целых областей)
* **Степень суммы:** deg(P + Q) ≤ max(deg P, deg Q)
* **Делители нуля:** отсутствуют для ℤ, ℚ, ℝ, ℂ, 𝔽_p

### **3. Многочлены от нескольких переменных**
* **K[x₁, ..., xₙ]** = K[x₁, ..., x_{n-1}][xₙ] — рекурсивное определение
* **Степень по переменной:** deg_{xᵢ} P и общая степень
* **Лексикографический порядок мономов:** x₁^{a₁}...xₙ^{aₙ} > x₁^{b₁}...xₙ^{bₙ} если a₁ > b₁ или a₁ = b₁, a₂ > b₂, ...

### **4. Принцип уникальности многочлена**
* **Формулировка:** если P(x) = Q(x) для всех x ∈ K и |K| > deg P, то P ≡ Q
* **Следствие:** достаточно n+1 точки для唯一ного определения многочлена степени ≤ n

## **B. ОПЕРАЦИИ НАД МНОГОЧЛЕНАМИ**

### **5. Подстановка (вычисление значения)**
* **Формула Горнера:** P(x) = a₀ + x(a₁ + x(a₂ + ... + x·aₙ))
* **Рекуррентность:** bₙ = aₙ; bₖ = aₖ + a·b_{k+1} для k = n−1, ..., 0; P(a) = b₀
* **Сложность:** O(n) — одно умножение и одно сложение на шаг
* **Применение:** вычисление значений, деление на (x − a), оценка производных

### **6. Формальное дифференцирование**
* **Определение:** P'(x) = ∑_{i=1}^{n} i·aᵢ xⁱ⁻¹ — формальная производная
* **Свойства:** линейность, произведение (u·v)' = u'v + uv', цепное правило
* **Кратный корень:** P(x) = (x − α)ᵏ Q(x), Q(α) ≠ 0 ⟹ P'(x) имеет корень α с кратностью k−1
* **Наивное вычисление:** O(n); через Горнера: одновременно P(a) и P'(a)

### **7. Композиция**
* **Определение:** (P ∘ Q)(x) = P(Q(x))
* **Степень:** deg(P ∘ Q) = (deg P)(deg Q)
* **Наивный алгоритм:** O(n·m²) или O(n·m) через подстановку Горнера для каждого члена
* **Быстрый алгоритм:** O(n^{1+ε}) через разбиение (актуально для больших степеней)

### **8. Формальное обращение**
* **Задача:** найти Q(x) = 1/P(x) в K[[x]] при a₀ ≠ 0
* **Рекуррентность:** b₀ = 1/a₀; bₙ = −(1/a₀) ∑_{k=1}^{n} aₖ b_{n−k}
* **Сложность:** O(n²) наивно; O(n log n) через Ньютона
* **Применение:** деление многочленов (раздел VIII, h), экспонента/логарифм (раздел VIII, h)
