**XIII. ШИФРЫ**

> **Архитектура:** `Ciphers` (m.cpp) — раздел ветки algebra. Вводит классические подстановочные шифры (Caesar, Affine, Vigenère, Playfair, Hill), транспозиционные шифры (Rail Fence, Nihilist), кодировки (Base64, Morse), асимметричные шифры (RSA, Diffie-Hellman, ElGamal) и симметричные шифры (OTP, XOR). Опирается на модулярную арифметику (`math/number-theory`: обратные элементы, возведение в степень, простые числа), длинную арифметику (раздел XII, l) и линейную алгебру (`math/linear-algebra`: матрицы для Hill Cipher).
>
> **Связи с другими ветками:** модулярная арифметика — `math/number-theory` ( обратные элементы, CRT, простые); длинная арифметика — раздел XII (l) (RSA, большие числа); линейная алгебра — `math/linear-algebra` (обратная матрица для Hill Cipher); битовые операции — раздел XI (k) (XOR, OTP); комбинаторика — `math/combinatorics` (подсчёт ключей).

## **A. КЛАССИЧЕСКИЕ ПОДСТАНОВОЧНЫЕ ШИФРЫ**

### **1. Цезаря (Caesar Cipher)**
* **Шифрование:** `C = (P + k) mod m` — циклический сдвиг алфавита на k позиций
* **Дешифрование:** `P = (C − k) mod m`
* **Ключ:** одно число k ∈ [0, m−1]
* **Взлом:** полный перебор всех m−1 ключей; для m = 26 — всего 25 вариантов
* **Rot13:** частный случай Caesar с k = 13; самообратим: `rot13(rot13(x)) = x`

### **2. Аффинный шифр (Affine Cipher)**
* **Шифрование:** `C = (a·P + b) mod m`, требует `gcd(a, m) = 1`
* **Дешифрование:** `P = a⁻¹·(C − b) mod m`, где `a⁻¹` — обратный элемент по модулю m
* **Ключ:** пара (a, b), число ключей: `φ(m)·m`
* **Взлом:** частотный анализ + решение 2 уравнений с 2 неизвестными

### **3. Виженера (Vigenère Cipher)**
* **Шифрование:** `Cᵢ = (Pᵢ + Kᵢ) mod m` — для каждой позиции свой сдвиг из ключевого слова
* **Ключ:** слово длины t; `Kᵢ = key[i mod t]`
* **Дешифрование:** `Pᵢ = (Cᵢ − Kᵢ) mod m`
* **Взлом:** определение длины ключа (индекс совпадений Касинского), затем частотный анализ для каждого столбца

### **4. Плейфера (Playfair Cipher)**
* **Представление:** матрица 5×5 (I/J объединены), двумя буквами за раз
* **Правила шифрования:**
    * Одна строка → сдвиг вправо
    * Один столбец → сдвиг вниз
    * Прямоугольник → замена углов в строке
* **Ключ:** слово → заполнение матрицы

### **5. Хилла (Hill Cipher)**
* **Шифрование:** `C = K·P mod m` — умножение вектора открытого текста на матрицу-ключ
* **Дешифрование:** `P = K⁻¹·C mod m` — обратная матрица по модулю m
* **Ключ:** невырожденная матрица K размера n×n над ℤ/mℤ
* **Взлом:** known-plaintext атака: известные пары (P, C) → решение системы K·P = C

## **B. ТРАНСПОЗИЦИОННЫЕ ШИФРЫ**

### **6. Рельсовая ограда (Rail Fence Cipher)**
* **Алгоритм:** запись текста зигзагом по r строкам, чтение по строкам
* **Взлом:** перебор числа строк r

### **7. NIHILIST Cipher**
* **Шифрование:** таблица Полябия для букв, ключ — число; сумма: `C = P + K`
* **Расшифрование:** вычитание

---

## **C. КОДИРОВКИ**

### **8. Base64**
* **Преобразование:** 6 бит → один символ из набора A-Z, a-z, 0-9, +, /
* **Применение:** передача бинарных данных в текстовых протоколах

### **9. Код Морзе**
* **Представление:** точка/тире для каждой буквы, пробел между буквами, двойной пробел между словами

---

## **D. АСИММЕТРИЧНЫЕ ШИФРЫ**

### **10. RSA**
* **Генерация ключей:** p, q простые → n = pq, φ(n) = (p−1)(q−1), e·d ≡ 1 (mod φ(n))
* **Шифрование:** `C = Pᵉ mod n`
* **Расшифрование:** `P = Cᵈ mod n`
* **Безопасность:** трудность факторизации n

### **11. Diffie-Hellman**
* **Обмен ключами:** A = gᵃ mod p, B = gᵇ mod p; общий ключ K = gᵃᵇ mod p
* **Безопасность:** задача дискретного логарифма

### **12. ElGamal**
* **Генерация ключей:** h = gˣ mod p; открытый ключ (p, g, h), закрытый x
* **Шифрование:** c₁ = gᵏ mod p, c₂ = m·hᵏ mod p
* **Расшифрование:** m = c₂·(c₁ˣ)⁻¹ mod p

## **E. СИММЕТРИЧНЫЕ ШИФРЫ**

### **13. Одноразовый блокнот (OTP / Vernam Cipher)**
* **Шифрование:** C = P ⊕ K, |K| = |P| = длина сообщения
* **Ключ:** случайная последовательность той же длины, используется однократно
* **Безопасность:**資訊но-теоретическая безопасность (shannon secrecy)

### **14. XOR-шифр**
* **Шифрование:** `C = P ⊕ K` (ключ повторяется периодически)
* **Уязвимость:** повтор ключа → XOR двух шифротекстов = XOR двух открытых текстов
