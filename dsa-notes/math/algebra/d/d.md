**IV. РАЗЛОЖЕНИЕ НА МНОЖИТЕЛИ**

> **Архитектура:** `Factorization` (d.cpp) — класс ветки algebra, наследует `PolynomialGCD` (c.cpp). Переиспользует: НОД (c.cpp, B.4), деление (b.cpp, A.2), дифференцирование (a.cpp, B.6), формальное обращение (a.cpp, B.8). Вводит: определение неприводимости, критерий Эйзенштейна, методы разложения (неопределённые коэффициенты, группировка, выделение квадрата), разложение над 𝔽_p (алгоритм Берлекэмпа). Связан с `number-theory` (модулярная арифметика, решето) и `combinatorics` (комбинаторные методы).
>
> **Связи:** разложение → корни (раздел V, e); неприводимые → основная теорема алгебры; Эйзенштейн → дискриминант (раздел XI, k); разложение над 𝔽_p → Берлекэмп/Кантор-Зассенхауз; циклические многочлены → `number-theory` (первообразные корни).

## **A. НЕПРОВОДИМЫЕ МНОГОЧЛЕНЫ**

### **1. Определение неприводимости**
* **Определение:** P ∈ K[x] неприводим, если P = AB ⟹ A или B — константа
* **Над ℂ:** только линейные (x − a) — основная теорема алгебры
* **Над ℝ:** линейные и квадратные с D < 0
* **Над ℚ:** бесконечно много (критерий Эйзенштейна — ниже)
* **Над 𝔽_p:** конечное число (алгоритм Берлекэмпа — ниже)

### **2. Критерий Эйзенштейна**
* **Формулировка:** P(x) = aₙxⁿ + ... + a₀ ∈ ℤ[x]; если ∃ простое p:
    * p ∤ aₙ
    * p | aᵢ для всех i < n
    * p² ∤ a₀
    → P неприводим над ℚ
* **Обобщение:** замена x → x + c для сдвига; проверка для разных p
* **Ограничения:** не все неприводимые определяются Эйзенштейном (например, x⁴ + 1)

### **3. Уникальность разложения**
* **Теорема:** в K[x] (целая область) разложение на неприводимые唯一ственно с точностью до порядка и домножения на единицы

## **B. МЕТОДЫ РАЗЛОЖЕНИЯ**

### **4. Метод неопределённых коэффициентов**
* **Идея:** предполагаем P = (a₀ + a₁x + ...)(b₀ + b₁x + ...), решаем систему
* **Эффективен для:** малых степеней (n ≤ 10)
* **Сложность:** O(n³) наивно (система n уравнений)

### **5. Выделение полного квадрата/куба**
* **Разность квадратов:** A² − B² = (A−B)(A+B)
* **Полный квадрат:** x⁴ + ax² + b = (x² + a/2)² − (a²/4 − b)

### **6. Группировка слагаемых**
* **Пример:** x³ + x² + x + 1 = x²(x+1) + (x+1) = (x²+1)(x+1)

### **7. Замены и сдвиги**
* **Сдвиг x → x+c:** преобразует P(x) в P(x+c), затем обратная замена
* **Замена x → xᵏ:** для обнаружения структуры «многочлен от многочлена»

## **C. РАЗЛОЖЕНИЕ НАД 𝔽_p**

### **8. Алгоритм Берлекэмпа**
* **Идея:** ядро матрицы (I − M^p) определяет разбиение на неприводимые множители
* **Сложность:** O~(n^{ω/2}) где ω — стоимость умножения матриц

### **9. Алгоритм Кантора-Зассенхауз**
* **Идея:** случайный полином h(x) = x^{(p−1)/2} − 1; gcd(P, h) даёт нетривиальный делитель
* **Сложность:** O(n²) детерминированно или O(n² log n) вероятностно

### **10. Разложение Берлекэмпа-Ленстры**
* **Идея:** комбинация Берлекэмпа и Кантора-Зассенхауза
* **Сложность:** O~(n^{ω/2}) — детерминированный полиномиальный алгоритм
