**III. НОД МНОГОЧЛЕНОВ И АЛГОРИТМ ЕВКЛИДА**

> **Архитектура:** `PolynomialGCD` (c.cpp) — класс ветки algebra, наследует `Division` (b.cpp). Переиспользует: деление с остатком (b.cpp, A.2), формальное дифференцирование (a.cpp, B.6), теорему Безу (b.cpp, B.5). Вводит: определение НОД многочленов, классический и расширенный алгоритм Евклида, субрезультантный алгоритм для ℤ[x], вычисление Bezout-коэффициентов. Связан с модулярной арифметикой (`number-theory`) для вычислений по модулю.
>
> **Связи:** НОД → разложение на множители (раздел IV, d); расширенный Евклид → обратные элементы в кольцах многочленов; субрезультатный алгоритм → определители и результант (раздел XI, k); модулярный НОД → Берлекэмп/Кантор-Зассенхауз (раздел IV, d); НОД полиномиальных строк → `string.md`.

## **A. НАИБОЛЬШИЙ ОБЩИЙ ДЕЛИТЕЛЬ**

### **1. Определение НОД**
* **Определение:** gcd(P, Q) — нормированный многочлен максимальной степени, делящий и P, и Q
* **Свойства:**
    * gcd(P, Q) = gcd(Q, P mod Q) — основное соотношение
    * gcd(P, 0) = P / lc(P) (нормировка)
    * gcd(aP, bQ) = gcd(P, Q) для a, b ≠ 0
    * Существование и единственность (с точностью до домножения на единицу)

### **2. Линейная комбинация**
* **Теорема Bezout:** gcd(P, Q) = U·P + V·Q для некоторых U, V ∈ K[x]
* **Единственность:** не единственны; U, V определяются с точностью до Q/gcd и P/gcd

### **3. НОД нескольких многочленов**
* **Ассоциативность:** gcd(P₁, ..., Pₖ) = gcd(gcd(P₁, P₂), P₃, ..., Pₖ)
* **Свойства:** gcd(a₁P₁, ..., aₖPₖ) = gcd(P₁, ..., Pₖ) при aᵢ ≠ 0

## **B. АЛГОРИТМ ЕВКЛИДА ДЛЯ МНОГОЧЛЕНОВ**

### **4. Классический алгоритм**
* **Идея:** R₀ = P, R₁ = Q; Rᵢ₊₁ = Rᵢ₋₁ mod Rᵢ пока Rᵢ₊₁ ≠ 0
* **Нормировка:** на каждом шаге нормируем Rᵢ (делим на lc(Rᵢ)) для唯一ности
* **Число шагов:** O(m) где m = deg Q ≤ n = deg P
* **Сложность:** O(n·m) арифметических операций; через FFT: O~(n)

### **5. Расширенный алгоритм Евклида**
* **Находим U, V:** gcd(P, Q) = U·P + V·Q
* **Рекуррентность:** S₀ = 1, S₁ = 0, T₀ = 0, T₁ = 1
    * qᵢ = Rᵢ₋₁ div Rᵢ
    * Sᵢ₊₁ = Sᵢ₋₁ − qᵢ·Sᵢ
    * Tᵢ₊₁ = Tᵢ₋₁ − qᵢ·Tᵢ
* **Инвариант:** Rᵢ = Sᵢ·P + Tᵢ·Q на каждом шаге
* **Сложность:** O(n·m) — то же что классический

### **6. Субрезультантный алгоритм (subresultant GCD)**
* **Проблема:** при работе над ℤ[x] коэффициенты растут экспоненциально
* **Решение:** нормировка Rᵢ₊₁ = −(lc(Rᵢ₋₁))^{δᵢ+1} · (Rᵢ₋₁ mod Rᵢ) / lc(Rᵢ₋₁)^{δᵢ}
    * δᵢ = deg Rᵢ₋₁ − deg Rᵢ — понижение степени
* **Преимущество:** коэффициенты остаются в разумных пределах (детерминированный алгоритм)

### **7. Матрица Безу**
* **Матрица:** ∏_{i=1}^{k} [[0, 1], [1, −qᵢ]] связывает (P, Q) и (gcd, 0)
* **Определитель:** det = ±1 → U, V — корректная Bezout-комбинация
* **Применение:** проверка корректности, вычисление без рекурсии (итеративно)
