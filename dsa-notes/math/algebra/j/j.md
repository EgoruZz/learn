**X. СИММЕТРИЧЕСКИЕ МНОГОЧЛЕНЫ, РЕЗУЛЬТАНТ И ДИСКРИМИНАНТ**

> **Архитектура:** `SymmetricResultant` (j.cpp) — класс ветки algebra, наследует `Recurrences` (i.cpp). Переиспользует: горнер (a.cpp, B.5), деление (b.cpp, A.2), НОД (c.cpp, B.4), дифференцирование (a.cpp, B.6), умножение (g.cpp, B.8), возведение в степень (h.cpp, B.4). Вводит: элементарные симметрические многочлены, степенные суммы, основную теорему о симметрических многочленах, результант (определитель Сильвестра), дискриминант, специальные многочлены (ортогональные, Бернулли, Белла, Бернштейна). Связана с `number-theory` (простые числа, μ-функция), `combinatorics` (комбинаторные тождества), `linear-algebra` (определители).
>
> **Связи:** симметрические → теорема Виета (раздел V, e); результант → проверка общих корней (раздел IV, d); дискриминант → кратные корни (раздел V, e); ортогональные → `geometry.md` (ортогональные системы); специальные → комбинаторика, `number-theory`.

## **A. СИММЕТРИЧЕСКИЕ МНОГОЧЛЕНЫ**

### **1. Элементарные симметрические многочлены**
* **Определение:** eₖ(x₁,...,xₙ) = ∑_{1≤i₁<...<iₖ≤n} x_{i₁}...x_{iₖ}
* **Базовые:** e₀ = 1, e₁ = ∑xᵢ, eₙ = ∏xᵢ
* **Связь с корнями:** для P(x) = aₙ∏(x−xᵢ), eₖ = (−1)ᵏ aₙ₋ₖ/aₙ

### **2. Степенные суммы**
* **Определение:** pₖ = ∑xᵢᵏ
* **Связь с eₖ:** формулы Ньютона (раздел V, e)

### **3. Полные симметрические многочлены**
* **Определение:** hₖ = ∑_{1≤i₁≤...≤iₖ≤n} x_{i₁}...x_{iₖ} (с повторениями)
* **OGF:** H(x) = ∑ hₖ xᵏ = ∏_{i=1}^{n} 1/(1 − xᵢ)

### **4. Основная теорема**
* **Формулировка:** любой симметрический многочлен f(x₁,...,xₙ) единственным образом выражается как полиномиальная функция от e₁, ..., eₙ
* **Алгоритм:** лексикографическая замена мономов
* **Сложность:** O(n · deg f)

---

## **B. РЕЗУЛЬТАНТ**

### **5. Определение**
* **Определение:** Res(P, Q) — детерминант матрицы Сильвестра (степени n и m)
* **Свойства:**
    * Res(P, Q) = 0 ⟺ P и Q имеют общий корень
    * Res(P, Q) = (−1)^{nm} Res(Q, P)
    * Res(P, Q) = aₙᵐ ∏_{i} Q(αᵢ) — через корни P
    * Res(PQ, R) = Res(P, R) · Res(Q, R)

### **6. Вычисление**
* **Наивно:** O(n³ m³) через детерминант
* **Через Евклид:** O(n² m²) или O~((n+m)²)
* **Применения:** исключение переменных, проверка общих корней

### **7. Матрица Сильвестра**
* **Определение:** (n+m)×(n+m) матрица из коэффициентов P и Q
* **Структура:** каждая строка — сдвиг коэффициентов одного из многочленов

## **C. ДИСКРИМИНАНТ**

### **8. Определение и свойства**
* **Определение:** D(P) = aₙ^{2n−2} ∏_{i<j} (zᵢ − zⱼ)²
* **Связь с результантом:** D(P) = (−1)^{n(n−1)/2} aₙ⁻¹ Res(P, P')
* **D(P) = 0 ⟺ P имеет кратный корень**
* **Для квадратного:** D = b² − 4ac
* **Для кубического:** D = 18abcd − 4b³d + b²c² − 4ac³ − 27a²d²

## **D. СПЕЦИАЛЬНЫЕ МНОГОЧЛЕНЫ**

### **9. Ортогональные многочлены**
* **Лежандр:** Pₙ(x) = (1/(2ⁿn!)) dⁿ/dxⁿ (x²−1)ⁿ — на [−1,1]
  * Рекуррентность: (n+1)Pₙ₊₁ = (2n+1)xPₙ − nPₙ₋₁
* **Чебышёв 1-го рода:** Tₙ(x) = cos(n·arccos x), Tₙ = 2xTₙ₋₁ − Tₙ₋₂
* **Чебышёв 2-го рода:** Uₙ(x) = sin((n+1)arccos x)/sin(arccos x)
* **Лагерр:** Lₙ(x) = eˣ dⁿ/dxⁿ (xⁿ e⁻ˣ) — на [0,∞)
  * Рекуррентность: (n+1)Lₙ₊₁ = (2n+1−x)Lₙ − nLₙ₋₁
* **Эрмит:** Hₙ(x) = (−1)ⁿ e^{x²} dⁿ/dxⁿ e⁻ˣ² — на (−∞,∞)
  * Рекуррентность: Hₙ₊₁ = 2xHₙ − 2nHₙ₋₁
* **Реализация:** `legendre_P(n)`, `laguerre_L(n)`, `hermite_H(n)` — возвращают полиномы через рекуррентности

### **10. Многочлены Бернулли**
* **Определение:** B₀ = 1, ∑_{k=0}^{n} C(n+1,k)Bₖ = 0
* **Применение:** суммы степеней: ∑_{k=1}^{n} kᵖ = (1/(p+1)) ∑_{j=0}^{p} C(p+1,j) Bⱼ n^{p+1−j}
* **Реализация:** `bernoulli(n)` — вычисление B₀..Bₙ через рекуррентность

### **11. Многочлены Белла**
* **Определение:** Bₙ(x) = ∑_{k=0}^{n} S(n,k)xᵏ — полные симметрические для x₁=...=xₙ=x
* **Связь:** числа Белла Bₙ = Bₙ(1)
* **Рекуррентность:** B(n+1,k) = k·B(n,k) + B(n,k−1), B(0,0)=1
* **Реализация:** `bell_polynomial(n)` — матрица B(n,k) для всех k

### **12. Многочлены Бернштейна**
* **Определение:** Bᵢⁿ(x) = C(n,i)xⁱ(1−x)ⁿ⁻ⁱ
* **Применение:** базис для кривых Безье, приближение функций
* **Реализация:** `bernstein(i, n)` — один полином Bᵢⁿ
