> **Архитектура:** `Roots` (e.cpp) — класс ветки algebra, наследует `Factorization` (d.cpp). Переиспользует: НОД (c.cpp, B.4), деление (b.cpp, A.2), формальное дифференцирование (a.cpp, B.6), горнер (a.cpp, B.5), кратность корней (b.cpp, B.6), Эйзенштейн (d.cpp, A.2). >
> **Связи:** корни → интерполяция (раздел VI, f); основная теорема → разложение (раздел IV, d); Виета → симметрические многочлены (раздел XI, k); Штурм → вычислительная геометрия (пересечение кривых); границы → оценки в алгоритмах.

## **A. ОСНОВНАЯ ТЕОРЕМА АЛГЕБРЫ**

### **1. Формулировка и следствия**
* **Теорема:** ∀ P ∈ ℂ[x] степени n ≥ 1 ∃ ровно n корней с учётом кратности: P(x) = aₙ ∏_{i=1}^{n} (x − zᵢ)
* **Следствие для ℝ[x]:** комплексные корни идут парами: z = a+bi → z̄ = a−bi
* **Разложение над ℝ:** P(x) = aₙ ∏ (x − aⱼ)ᵏʲ ∏ (x² + bₖx + cₖ)^{mₖ} (D < 0)

### **2. Доказательство (обзор)**
* Через анализ: теорема Луиля (каждый многочлен имеет корень в ℂ)
* Через алгебраическую геометрию: ℂ алгебраически замкнуто
* Через комплексный анализ: лемма Луиля +maximum modulus

## **B. ТЕОРЕМА ВИЕТА И ФОРМУЛЫ НЬЮТОНА**

### **3. Формулы Виета**
* Для P(x) = aₙxⁿ + a_{n−1}xⁿ⁻¹ + ... + a₀ и корней z₁, ..., zₙ:
    * e₁ = ∑ zᵢ = −a_{n−1}/aₙ
    * e₂ = ∑_{i<j} zᵢzⱼ = a_{n−2}/aₙ
    * eₖ = ∑_{i₁<...<iₖ} z_{i₁}...z_{iₖ} = (−1)ᵏ a_{n−k}/aₙ
    * eₙ = ∏ zᵢ = (−1)ⁿ a₀/aₙ

### **4. Элементарные симметрические многочлены**
* **Определение:** eₖ(z₁,...,zₙ) = ∑_{1≤i₁<...<iₖ≤n} z_{i₁}...z_{iₖ}
* **Связь:** корни = «обратная задача Виета» — по eₖ восстановить корни

### **5. Степенные суммы и формулы Ньютона**
* **Степенные суммы:** pₖ = ∑ zᵢᵏ
* **Формулы Ньютона:** pₖ выражается через e₁, ..., eₖ:
    * p₁ = e₁
    * p₂ = e₁² − 2e₂
    * pₖ = e₁pₖ₋₁ − e₂pₖ₋₂ + ... + (−1)^{k−1} keₖ
* **Рекуррентность:** pₖ − e₁pₖ₋₁ + e₂pₖ₋₂ − ... + (−1)^k keₖ = 0 для k > 0

## **C. ГРАНИЦЫ И РАСПРЕДЕЛЕНИЕ КОРНЕЙ**

### **6. Границы модуля корней**
* **Граница Коши:** |zᵢ| ≤ 1 + max_{k<n} |aₖ/aₙ|
* **Уточнение Фуке:** |zᵢ| ≤ max(1, ∑_{k=0}^{n−1} |aₖ/aₙ|)

### **7. Правило знаков Декарта**
* **Формулировка:** число положительных корней ≤ число смен знаков в P(x)
* **Точность:** с точностью до чётности (разность — чётное число)

### **8. Теорема Штурма**
* **Построение цепочки:** P₀ = P, P₁ = P', Pᵢ₊₁ = −(Pᵢ₋₁ mod Pᵢ) (как в расширенном Евклиде)
* **Подсчёт:** W(a) = число смен знаков в P₀(a), P₁(a), ..., Pₖ(a)
* **Число корней на (a, b]:** W(a) − W(b)
* **Сложность:** O(n²) на один интервал (или O(n log n) через FFT)

### **9. Теорема Бюдана-Фурье**
* **Формулировка:** число корней на (a, b] ≤ число смен знаков в P, P', ..., P⁽ⁿ⁾
* **Ограничение:** хуже Штурма (нет точного подсчёта), но проще вычислительно
