**VIII. БЫСТРОЕ ДЕЛЕНИЕ И ВОЗВЕДЕНИЕ В СТЕПЕНЬ**

> **Архитектура:** `FastDivision` (h.cpp) — класс ветки algebra, наследует `FastMultiplication` (g.cpp). Переиспользует: деление (b.cpp, A.2), формальное обращение (a.cpp, B.8), горнер (a.cpp, B.5), FFT (g.cpp, B.8). Вводит: быстрое деление через обращение Ньютона, вычисление остатка, многоточечное вычисление, бинарное возведение многочлена в степень, экспоненту и логарифм. Связана с `number-theory` (быстрая арифметика), `technique.md` (метод Ньютона).
>
> **Связи:** быстрое деление → деление (раздел II, b); возведение → рекурренты (раздел IX, i); экспонента/логарифм → производящие функции (раздел X, j); многоточечное вычисление → интерполяция (раздел VI, f).

## **A. БЫСТРОЕ ДЕЛЕНИЕ**

### **1. Деление через обращение**
* **Идея:** найти Q(x) = 1/D(x) мод xᵏ (формальное обращение)
* **Итерация Ньютона:** Qₙ₊₁ = Qₙ(2 − D·Qₙ) мод x^{2ⁿ}
* **Сложность:** O(n log n) через FFT
* **Обоснование:** если D·Qₙ ≡ 1 mod xᵏ, то D·Qₙ₊₁ ≡ 1 mod x^{2k}

### **2. Вычисление остатка**
* **P(x) mod (xᵏ − a):** циклический сдвиг — O(n)
* **P(x) mod D(x):** через обращение — O(n log n)
* **Многоточечное вычисление:** вычислить P(xᵢ) для n точек за O(n log² n)

### **3. Многоточечное вычисление значений**
* **Задача:** вычислить P(xᵢ) для n точек за O(n log² n)
* **Рекурсия:** разбить точки пополам, вычислить ∏_{лев}(x − xⱼ) рекурсивно
* **Применение:** интерполяция, вычисление значений в корнях из единицы

## **B. БЫСТРОЕ ВОЗВЕДЕНИЕ В СТЕПЕНЬ**

### **4. Бинарное возведение**
* **Pᵏ:** k = ∑ bⱼ 2ʲ → Pᵏ = ∏_{bⱼ=1} P^{2ʲ}
* **Наивно:** O(M(n) log k) где M(n) — стоимость умножения
* **Через усечение:** Pᵏ mod xⁿ — отбрасываем старшие члены

### **5. Экспонента от многочлена**
* **exp(P) = ∑_{k≥0} Pᵏ/k!**
* **Через дифференцирование:** Q = exp(P) → Q' = Q·P' → рекуррентность
* **Сложность:** O(n log n) через FFT

### **6. Логарифм от многочлена**
* **log(1 + P) = ∑_{k≥1} (−1)^{k+1} Pᵏ/k** (при P₀ = 0)
* **Через дифференцирование:** (log Q)' = Q'/Q → log Q = ∫ Q'/Q
* **Сложность:** O(n log n) через деление + интегрирование

### **7. Формальные степенные ряды**
* **Синус:** sin(P) через рекуррентность: S[n] = (1/n)∑k·P[k]·C[n−k], C[n] = −(1/n)∑k·P[k]·S[n−k], P₀ = 0
* **Косинус:** cos(P) — та же рекуррентность, возвращаем только C
* **Арктангенс:** atan(P) = ∫ P'/(1+P²) dx через интегрирование + обращение
* **Композиция P(Q(x)):** O(n^{3/2}) или O(n^{1+ε}) — нет простого O(n log n)
