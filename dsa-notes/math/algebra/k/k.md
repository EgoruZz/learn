## **A. БАЗОВЫЕ ПОБИТОВЫЕ ОПЕРАЦИИ**

### **1. Логические операции**
* **Определения:**
    * AND (`a & b`): бит результата = 1 ⟺ оба бита = 1
    * OR (`a | b`): бит результата = 1 ⟺ хотя бы один бит = 1
    * XOR (`a ^ b`): бит результата = 1 ⟺ биты различаются
    * NOT (`~a`): инверсия каждого бита
* **Свойства:**
    * Коммутативность: `a & b = b & a`, `a | b = b | a`, `a ^ b = b ^ a`
    * Ассоциативность: `(a & b) & c = a & (b & c)` и т.д.
    * Дистрибутивность AND по OR: `a & (b | c) = (a & b) | (a & c)`
    * Двойственность: `~(a & b) = ~a | ~b`, `~(a | b) = ~a & ~b` (законы де Моргана для битов)
* **Свойства XOR:**
    * `a ^ a = 0` (самообратимость)
    * `a ^ 0 = a` (нейтральный элемент)
    * `a ^ b ^ b = a` (сокрытие/восстановление)
    * Ассоциативность: `a ^ (b ^ c) = (a ^ b) ^ c`
* **XOR как сложение без переноса:**
    * `a + b = (a ^ b) + ((a & b) << 1)` — рекурсивно, пока `a & b ≠ 0`
    * Суммарно O(log w) итераций, где w — разрядность слова

### **2. Манипуляции отдельными битами**
* **Операции:**
    * Установка k-го бита: `a | (1 << k)`
    * Сброс k-го бита: `a & ~(1 << k)`
    * Инверсия k-го бита: `a ^ (1 << k)`
    * Проверка k-го бита: `(a >> k) & 1`
    * Усечение младших k бит: `a & ((1 << k) - 1)`
* **Получение младшего установленного бита (lowbit):**
    * `a & (-a)` — в дополнительном коде `-a = ~a + 1`
    * Сброс младшего бита: `a & (a - 1)`
    * Проверка на степень двойки: `(a & (a - 1)) == 0` и `a > 0`

### **3. Битовые сдвиги**
* **Операции:**
    * Левый сдвиг: `a << k` = `a · 2ᵏ` (заполнение нулями справа)
    * Правый сдвиг: `a >> k` = `⌊a / 2ᵏ⌋`
        * Для unsigned: логический (заполнение нулями)
        * Для signed: арифметический (заполнение знаковым битом)
* **Циклический сдвиг (rotate):**
    * 32-бит: `(a << k) | (a >> (32 - k))`
    * 64-бит: `(a << k) | (a >> (64 - k))`
* **Опасность:** `a >> 32` для 32-битного типа — undefined behavior; всегда проверять границы

## **B. ПРЕДСТАВЛЕНИЯ ЧИСЕЛ**

### **4. Дополнительный код (Two's Complement)**
* **Формула:** `−a = ~a + 1`
* **Диапазон:** для n-бит: `[−2ⁿ⁻¹, 2ⁿ⁻¹ − 1]`
* **Проверка отрицательности:** `a < 0 ⟺ (a >> (w−1)) & 1 = 1` (где w — разрядность)
* **Быстрое отрицание:** `−a = (a ^ mask) + (1 & mask)`, где `mask = a >> (w−1)`
* **Среднее без переполнения:** `(a + b) >> 1` переполняется; `(a & b) + ((a ^ b) >> 1)` — безопасно

### **5. Системы счисления**
* **Позиционная система:** основание b, цифры `dᵢ ∈ [0, b)`, значение `n = Σᵢ dᵢ · bⁱ`
* **Перевод из десятичной в основание b:** деление на b, остатки (младшие цифры первые)
* **Перевод в десятичную:** схема Горнера: `result = result · b + dᵢ`
* **Поблочный перевод:** по 4 бита → hex, по 3 десятичных → octal

## **C. АНАЛИЗ И МАНИПУЛЯЦИЯ БИТАМИ**

### **6. Подсчёт битов**
* **Число единиц (popcount / Hamming weight):**
    * Наивно: O(w) — проверка каждого бита
    * Brian Kernighan: `while (a) { a &= a - 1; count++; }` — O(k), где k — число единиц
    * Табличный метод: разбиение на байты, предвычисленная таблица
    * Встроенные: `__builtin_popcountll(a)` (GCC/Clang), `std::popcount(a)` (C++20)
* **Число нулей:**
    * `__builtin_clzll(a)` — ведущие нули (count leading zeros); `__builtin_ctzll(a)` — хвостовые нули (count trailing zeros)
    * `w - __builtin_clzll(a)` — позиция старшего бита

### **7. Поиск позиций битов**
* **Старший установленный бит (highest set bit):**
    * `63 - __builtin_clzll(a)` (для 64-бит)
    * Через сдвиги: итеративно `a >>= 16`, потом `>>= 8`, ..., `>>= 1`
* **Младший установленный бит (lowest set bit):**
    * `a & (-a)` — значение, `__builtin_ctzll(a)` — позиция
* **Следующее число с тем же числом единиц:** алгоритм Госпера (Gosper's hack)

### **8. Реверс и перестановка битов**
* **Реверс битов (reverse bits):**
    * Пошаговый: swap попарно, потом попарно блоки по 2, потом по 4, ..., до блоков по w/2
    * Табличный: предвычисленные таблицы для байтов + сдвиги
* **Обмен чётных и нечётных позиций:**
    * `((a & 0xAAAA...AAAA) >> 1) | ((a & 0x5555...5555) << 1)`

## **D. БИТОВЫЕ ТРЮКИ И ОПТИМИЗАЦИИ**

### **9. Проверки свойств**
* **Чётность:** `a & 1` — 0 чётное, 1 нечётное
* **Степень двойки:** `(a & (a - 1)) == 0` и `a > 0`
* **Степень числа b:** проверка через логарифм или итеративное деление

### **10. Арифметические трюки**
* **Абсолютное значение:** `mask = a >> (w−1)`, `|a| = (a + mask) ^ mask`
* **Минимум/максимум без ветвления:** `min(a,b) = b ^ ((a ^ b) & -(a < b))`
* **Клонирование знака:** `sign = (a >> (w−1)) | ((unsigned)(-a) >> (w−1))` — 0/1/−1
* **Быстрое возведение в степень 2:** `1 << k`
* **Наибольшая степень двойки ≤ n:** `1 << (63 - __builtin_clzll(n))`
* **Поиск уникального элемента:** `a₁ ^ a₂ ^ ... ^ aₙ` при единственном уникальном
* **Поиск пропущенного числа:** `n(n+1)/2 XOR (сумма XOR всех элементов)`

### **11. Битовое сложение (рекурсивное)**
* `add(a, b)`:
    * Если `b == 0`: вернуть `a`
    * Иначе: `add(a ^ b, (a & b) << 1)`
* Сложность: O(log w) итераций

## **E. УПАКОВКА ДАННЫХ И БИТОВЫЕ МНОЖЕСТВА**

### **12. Битовые множества**
* **Представление:** подмножество универсума U = {0, 1, ..., w−1} — целое число: бит k = 1 ⟺ k ∈ множество
* **Операции:** `A | B` (объединение), `A & B` (пересечение), `A ^ B` (симметрическая разность), `~A & mask` (дополнение)
* **Перебор подмножеств:** `for (int s = mask; s; s = (s-1) & mask)` — O(2ᵏ) для подмножеств mask
* **Перебор подмасок:** `for (int s = submask; s; s = (submask - 1) & submask)` — суммарно O(3ⁿ) по всем подмножествам
* **Размер:** `|A| = __builtin_popcountll(A)` — мощность множества

### **13. Bit packing и сжатие**
* **Упаковка нескольких значений в одно слово:**
    * Каждое значение занимает b бит, общее число значений: `⌊w / b⌋`
    * Запись: `word = (word & ~(mask << (i*b))) | (val << (i*b))`
    * Чтение: `(word >> (i*b)) & ((1 << b) - 1)`
* **Эффективное хранение булевых массивов:** 64 bool в одном `long long`

## **F. ВСТРОЕННЫЕ ФУНКЦИИ И SIMD**

### **14. GCC/Clang builtins**
* `__builtin_popcountll(x)` — число единиц в 64-битном слове
* `__builtin_clzll(x)` — число ведущих нулей (undefined при x = 0)
* `__builtin_ctzll(x)` — число хвостовых нулей (undefined при x = 0)
* `__builtin_parityll(x)` — чётность числа единиц (XOR всех битов)
* `__builtin_ffsll(x)` — позиция младшего установленного бита + 1 (0 при x = 0)

### **15. SIMD-оптимизации (концепция)**
* Параллельная обработка: одно инструкция обрабатывает w/64 слов одновременно
* Применение: массовые popcount, поиск в битовых массивах, шифрование
