## **A. ИНТЕРПОЛЯЦИЯ МНОГОЧЛЕНАМИ**

### **1. Постановка задачи**
* **Задача:** по n+1 точкам (x₀,y₀), ..., (xₙ,yₙ) при xᵢ попарно различны — найти уникальный P степени ≤ n такой что P(xᵢ) = yᵢ
* **Существование и единственность:** следствие из линейной системы (определитель ≠ 0)

### **2. Интерполяционный многочлен Лагранжа**
* **Формула:** P(x) = ∑_{i=0}^{n} yᵢ Lᵢ(x) где Lᵢ(x) = ∏_{j≠i} (x − xⱼ)/(xᵢ − xⱼ)
* **Свойства:** Lᵢ(xⱼ) = δᵢⱼ (символ Кронекера)
* **Сложность вычисления:** O(n²) наивно; O(n log² n) через бинарное разбиение + FFT

### **3. Интерполяционный многочлен Ньютона**
* **Формула:** P(x) = f[x₀] + f[x₀,x₁](x−x₀) + f[x₀,x₁,x₂](x−x₀)(x−x₁) + ...
* **Разделённые разности:**
    * f[xᵢ] = yᵢ
    * f[xᵢ,...,xⱼ] = (f[x_{i+1},...,xⱼ] − f[xᵢ,...,x_{j−1}])/(xⱼ − xᵢ)
* **Достоинство:** добавление новой точки — O(n) дополнительных вычислений (против O(n²) у Лагранжа)
* **Свойства:** симметрична по аргументам; f[x₀,...,xₙ] = ∑ yᵢ/∏_{j≠i}(xᵢ − xⱼ)

---

## **B. ЭРМИТОВА ИНТЕРПОЛЯЦИЯ**

### **4. Интерполяция с кратными узлами**
* **Задача:** заданы P(xᵢ) = yᵢ, P'(xᵢ) = y'ᵢ, ..., P⁽ᵐⁱ⁾(xᵢ) = yᵢ⁽ᵐⁱ⁾
* **Обобщение разделённых разностей:** при совпадении xⱼ → xᵢ используем предел (производные)
* **Сложность:** O(n²) где n = ∑(mᵢ + 1)

---

## **C. БЫСТРАЯ ИНТЕРПОЛЯЦИЯ**

### **5. Интерполяция в корнях из единицы**
* Если xₖ = ωᵏ (ω — корень из единицы), то yₖ = P(ωᵏ) = DFT(a)
* Обратно: коэффициенты через IDFT за O(n log n)

### **6. Быстрая интерполяция O(n log² n)**
* Бинарное разбиение набора точек пополам
* Рекурсия: L(x) = L_{лев}(x) + L_{прав}(x) · ∏_{лев} (x − xᵢ)
* Каждый уровень: умножение через FFT — O(n log n), рекурсия O(log n) уровней
* **Реализация:** `multi_point_eval_mod` (дерево подотрезков), `interpolate_mod` (divide-and-conquer)
* **Сложность:** O(n log² n) через построение prod tree + mod tree

### **7. Интерполяция произвольных узлов**
* Алгоритм Бостана-Мохи: вычисление значений за O(n log² n)
* Через вычисление ∏(x − xᵢ) рекурсивно: O(n log² n)
