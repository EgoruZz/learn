## **I. ОСНОВЫ МНОГОЧЛЕНОВ**
> `a/a.md` · `a/a.cpp`

### **A. ОПРЕДЕЛЕНИЕ И КОЛЬЦО МНОГОЧЛЕНОВ**
*   **Многочлен от одной переменной:**
    *   Формальная сумма P(x) = ∑_{i=0}^{n} aᵢ xⁱ — коэффициенты aᵢ ∈ K (кольцо коэффициентов: ℤ, ℚ, ℝ, ℂ, 𝔽_p)
    *   Степень многочлена: deg P = max{i : aᵢ ≠ 0}; deg 0 = −∞
    *   Старший коэффициент: lc(P) = a_{deg P}
    *   Нормированный многочлен: lc(P) = 1
    *   Каноническая форма: упорядоченные степени с ненулевыми коэффициентами
*   **Кольцо многочленов K[x]:**
    *   Сложение: (P + Q)(x) = ∑ (aᵢ + bᵢ) xⁱ
    *   Умножение (свертка): (PQ)(x) = ∑_k (∑_{i+j=k} aᵢ bⱼ) xᵏ
    *   Свойства: ассоциативность, коммутативность, дистрибутивность, единица 1
    *   Степень произведения: deg(PQ) = deg P + deg P (для целых областей)
    *   Степень суммы: deg(P + Q) ≤ max(deg P, deg Q)
    *   Делители нуля отсутствуют для ℤ, ℚ, ℝ, ℂ, 𝔽_p (целые области)
*   **Многочлены от нескольких переменных:**
    *   K[x₁, ..., xₙ] = K[x₁, ..., x_{n-1}][xₙ] (рекурсивное определение)
    *   Степень по переменной deg_{xᵢ} P и общая степень
    *   Лексикографический, градуированный порядки мономов
*   **Тождественные равенства и их доказательство:**
    *   Два многочлена равны ⇔ равны все коэффициенты
    *   Если P(x) = Q(x) для всех x ∈ K бесконечного |K|, то P ≡ Q
    *   Принцип уникальности многочлена: достаточно |K| > deg P точек

### **B. ОПЕРАЦИИ НАД МНОГОЧЛЕНАМИ**
*   **Подстановка (вычисление значения):**
    *   P(a) — вычисление за O(n) через схему Горнера: P(x) = a₀ + x(a₁ + x(a₂ + ... + x·aₙ))
    *   Горнер: одна промежуточная переменная, n умножений и n сложений
*   **Дифференцирование:**
    *   P'(x) = ∑_{i=1}^{n} i·aᵢ xⁱ⁻¹ — формальная производная
    *   Свойства: линейность, произведение (u·v)' = u'v + uv', цепное правило для композиции
    *   Kратный корень: P(x) = (x − α)ᵏ Q(x), Q(α) ≠ 0 ⟹ P'(x) имеет корень α с кратностью k−1
*   **Композиция:**
    *   (P ∘ Q)(x) = P(Q(x)) — степень deg(P ∘ Q) = (deg P)(deg Q)
    *   Вычисление: наивно O(n² m), быстрее через разбиения
*   **Обратный многочлен (формально):**
    *   Для a₀ ≠ 0: P⁻¹(x) = 1/P(x) в K[[x]] (степенные ряды)
    *   Рекуррента: b₀ = 1/a₀, bₙ = −(1/a₀) ∑_{k=1}^{n} aₖ b_{n−k}

## **II. ДЕЛЕНИЕ С ОСТАТКОМ И ТЕОРЕМА БЕЗУ**
> `b/b.md` · `b/b.cpp`

### **A. ДЕЛЕНИЕ С ОСТАТКОМ**
*   **Теорема о делении:** для любых P, D ∈ K[x], D ≠ 0, существуют唯一 Q, R ∈ K[x] такие что P = QD + R и deg R < deg D
*   **Алгоритм деления (школьный «уголком»):**
    *   На каждом шаге: вычитаем (lc(R)/lc(D)) · x^{deg R − deg D} · D из R
    *   Число шагов: deg P − deg D + 1
    *   Сложность: O(n · m) где n = deg P, m = deg D
*   **Схема Горнера для деления:**
    *   Одновременно вычисляем P(a) и частное Q(x) от деления на (x − a)
    *   Рекуррентность: bₙ = aₙ; bₖ = aₖ + a·b_{k+1} для k = n−1, ..., 0
    *   Остаток R = b₀ = P(a); коэффициенты Q = b₁, ..., bₙ
*   **Деление на произвольный двучлен:**
    *   P(x) mod (xᵐ − a): циклический сдвиг коэффициентов по модулю m
    *   P(x) mod (xᵐ + a): знакопеременный сдвиг
*   **Деление на products of linear factors:**
    *   P(x) mod ∏_{i=1}^{n} (x − aᵢ): вычисление P(aᵢ) для каждого i (интерполяция остатков)

### **B. ТЕОРЕМА БЕЗУ И СЛЕДСТВИЯ**
*   **Теорема Безу:** P(a) = 0 ⟺ (x − a) | P(x)
*   **Обобщение:** P(x) mod (x − a) = P(a) — остаток от деления
*   **Кратность корня:** (x − a)ᵏ | P(x) и (x − a)^{k+1} ∤ P(x) ⟺ P(a) = P'(a) = ... = P^{(k−1)}(a) = 0 и P^{(k)}(a) ≠ 0
*   **Количество корней:** многочлен степени n имеет не более n корней (в целой области)
*   **Лагранжев интерполяционный многочлен:** P(x) = ∑_{i=0}^{n} yᵢ ∏_{j≠i} (x − xⱼ)/(xᵢ − xⱼ) — единственность следует из теоремы Безу

## **III. НОД МНОГОЧЛЕНОВ И АЛГОРИТМ ЕВКЛИДА**
> `c/c.md` · `c/c.cpp`

### **A. НАИБОЛЬШИЙ ОБЩИЙ ДЕЛИТЕЛЬ**
*   **Определение:** gcd(P, Q) — нормированный многочлен максимальной степени, делящий и P, и Q
*   **Свойства:**
    *   gcd(P, Q) = gcd(Q, P mod Q) — основное соотношение
    *   gcd(P, 0) = P / lc(P) (нормировка)
    *   gcd(aP, bQ) = gcd(P, Q) для a, b ≠ 0
    *   Существование и единственность (с точностью до домножения на единицу кольца)
    *   НОД нескольких: gcd(P₁, ..., Pₖ) = gcd(gcd(P₁, P₂), P₃, ..., Pₖ)
*   **Связь с линейной комбинацией:** gcd(P, Q) = U·P + V·Q для некоторых U, V ∈ K[x]

### **B. АЛГОРИТМ ЕВКЛИДА ДЛЯ МНОГОЧЛЕНОВ**
*   **Классический алгоритм:**
    *   R₀ = P, R₁ = Q
    *   Rᵢ₊₁ = Rᵢ₋₁ mod Rᵢ пока Rᵢ₊₁ ≠ 0
    *   gcd = Rᵢ / lc(Rᵢ) (нормированный последний ненулевой остаток)
    *   Число шагов: O(m) где m = deg Q ≤ n = deg P
    *   Сложность: O(n·m) арифметических операций (или O~(n) через FFT)
*   **Расширенный алгоритм Евклида:**
    *   Находим U, V такие что UP + VQ = gcd(P, Q)
    *   Рекуррентность: S₀ = 1, S₁ = 0, T₀ = 0, T₁ = 1
    *   Sᵢ₊₁ = Sᵢ₋₁ − qᵢ Sᵢ; Tᵢ₊₁ = Tᵢ₋₁ − qᵢ Tᵢ где qᵢ = Rᵢ₋₁ / Rᵢ
    *   Инвариант: Rᵢ = Sᵢ P + Tᵢ Q на каждом шаге
*   **Субрезультантный алгоритм (subresultant GCD):**
    *   Избегает роста коэффициентов при работе над ℤ[x]
    *   Нормировка: Rᵢ₊₁ = −(lc(Rᵢ₋₁))^{δᵢ+1} · (Rᵢ₋₁ mod Rᵢ) / lc(Rᵢ₋₁)^{δᵢ} где δᵢ = deg Rᵢ₋₁ − deg Rᵢ
*   **Вычисление НОД через матрицу:**
    *   Матрица Безу: ∏_{i=1}^{k} [[0, 1], [1, −qᵢ]] связывает (P, Q) и (gcd, 0)
    *   Определитель: det = ±1 → U, V — корректная Bezout-комбинация

## **IV. РАЗЛОЖЕНИЕ НА МНОЖИТЕЛИ**
> `d/d.md` · `d/d.cpp`

### **A. НЕПРОВОДИМЫЕ МНОГОЧЛЕНЫ**
*   **Определение:** P ∈ K[x] неприводим, если P = AB ⟹ A или B — константа
*   **Над ℂ:** только линейные (x − a) — основная теорема алгебры
*   **Над ℝ:** линейные (x − a) и квадратные (x² + bx + c) с D < 0
*   **Над ℚ:** критерий Эйзенштейна: P(x) = aₙxⁿ + ... + a₀ ∈ ℤ[x]
    *   Если ∃ простое p: p ∤ aₙ, p | aᵢ для i < n, p² ∤ a₀ → P неприводим над ℚ
    *   Обобщение: замена x → x + c для сдвига
*   **Над 𝔽_p (конечное поле):**
    *   Перебор: деление на все неприводимые степени ≤ n/2
    *   Алгоритм Берлекэмпа: разложение через ядро матрицы (I − M^p)
    *   Алгоритм Кантора-Зассенhaus: случайный полином + НОД
    *   Разложение Берлекэмпа-Ленстры: детерминированный O~(n^{ω/2}) где ω — стоимость умножения матриц
*   **Уникальность разложения:** в K[x] (целая область) разложение на неприводимые唯一ственно с точностью до порядка и домножения на единицы

### **B. МЕТОДЫ РАЗЛОЖЕНИЯ**
*   **Метод неопределённых коэффициентов:**
    *   Предполагаем P = (a₀ + a₁x + ...)(b₀ + b₁x + ...), решаем систему
    *   Эффективен для малых степеней (n ≤ 10)
*   **Выделение полного квадрата/куба:**
    *   x⁴ + ax² + b = (x² + a/2)² − (a²/4 − b)
    *   Разность квадратов: A² − B² = (A−B)(A+B)
*   **Группировка слагаемых:**
    *   x³ + x² + x + 1 = x²(x+1) + (x+1) = (x²+1)(x+1)
*   **Замены и сдвиги:**
    *   P(x+c) разложить, затем обратная замена
    *   x → x+1, x → −x, x → xᵏ для обнаружения скрытой структуры
*   **Дискретное логарифмирование (для циклических групп):**
    *   Если P(x) = ∏ Φₖ(x) (циклические многочлены), то разложение через дискретный логарифм в (ℤ/pℤ)*
*   **Берстроф-представление:**
    *   Для P(x,y) ∈ K[x][y]: P = ∏_{i=1}^{r} (y − fᵢ(x))^{eᵢ} + младшие члены
    *   Используется для разложения в 𝔽_p[x,y]

## **V. КОРНИ МНОГОЧЛЕНОВ**
> `e/e.md` · `e/e.cpp`

### **A. ОСНОВНАЯ ТЕОРЕМА АЛГЕБРЫ**
*   **Формулировка:** ∀ P ∈ ℂ[x] степени n ≥ 1 ∃ ровно n корней с учётом кратности: P(x) = aₙ ∏_{i=1}^{n} (x − zᵢ)
*   **Следствия для ℝ[x]:**
    *   Комплексные корни идут парами: если z = a+bi корень, то z̄ = a−bi тоже
    *   Разложение над ℝ: P(x) = aₙ ∏ (x − aⱼ)ᵏʲ ∏ (x² + bₖx + cₖ)^{mₖ} (D < 0)
*   **Связь с топологией:** доказательство через анализ (теорема Луиля), алгебраическую геометрию или комплексный анализ

### **B. ТЕОРЕМА ВИЕТА И ФОРМУЛЫ НЬЮТОНА**
*   **Формулы Виета:** для P(x) = aₙxⁿ + a_{n−1}xⁿ⁻¹ + ... + a₀ и корней z₁, ..., zₙ:
    *   ∑ zᵢ = −a_{n−1}/aₙ
    *   ∑_{i<j} zᵢzⱼ = a_{n−2}/aₙ
    *   ∑_{i<j<k} zᵢzⱼzₖ = −a_{n−3}/aₙ
    *   ∏ zᵢ = (−1)ⁿ a₀/aₙ
*   **Элементарные симметрические многочлены:** eₖ(z₁,...,zₙ) = ∑_{1≤i₁<...<iₖ≤n} z_{i₁}...z_{iₖ}
*   **Степенные суммы:** pₖ = ∑ zᵢᵏ
*   **Формулы Ньютона:** pₖ выражается через e₁, ..., eₖ:
    *   p₁ = e₁
    *   p₂ = e₁² − 2e₂
    *   pₖ = e₁pₖ₋₁ − e₂pₖ₋₂ + ... + (−1)^{k−1} keₖ
*   **Рекуррентность Ньютона:** pₖ − e₁pₖ₋₁ + e₂pₖ₋₂ − ... + (−1)^k keₖ = 0 для k > 0

### **C. ГРАНИЦЫ И РАСПРЕДЕЛЕНИЕ КОРНЕЙ**
*   **Граница модуля корней:** |zᵢ| ≤ 1 + max_{k<n} |aₖ/aₙ| (коши)
*   **Уточнение Фуке:** |zᵢ| ≤ max(1, ∑_{k=0}^{n−1} |aₖ/aₙ|)
*   **Правило знаков Декарта:** число положительных корней ≤ число смен знаков в P(x); с точностью до чётности
*   **Теорема Штурма:**
    *   Построить цепочку: P₀ = P, P₁ = P', Pᵢ₊₁ = −(Pᵢ₋₁ mod Pᵢ)
    *   Число вещественных корней на (a, b] = W(a) − W(b) где W — число смен знаков
*   **Теорема Бюдана-Фурье:** оценка через производные: число корней ≤ число смен знаков в P, P', ..., P⁽ⁿ⁾
*   **Распределение корней на окружности:**
    *   Циклические многочлены Φₙ(x): корни — n-е первообразные корни из единицы
    *   Связь с μ(n) (функция Мёбиуса): Φₙ(x) = ∏_{d|n} (xᵈ − 1)^{μ(n/d)}

## **VI. ИНТЕРПОЛЯЦИЯ**
> `f/f.md` · `f/f.cpp`

### **A. ИНТЕРПОЛЯЦИЯ МНОГОЧЛЕНАМИ**
*   **Задача:** по n+1 точкам (x₀,y₀), ..., (xₙ,yₙ) при xᵢ попарно различны — найти уникальный P степени ≤ n такой что P(xᵢ) = yᵢ
*   **Интерполяционный многочлен Лагранжа:**
    *   P(x) = ∑_{i=0}^{n} yᵢ Lᵢ(x) где Lᵢ(x) = ∏_{j≠i} (x − xⱼ)/(xᵢ − xⱼ)
    *   Сложность вычисления: O(n²) наивно; O(n log² n) через бинарное разбиение + FFT
    *   Достоинство: симметричная формула, наглядность
    *   Недостаток: добавление точки требует пересчёта всех Lᵢ
*   **Интерполяционный многочлен Ньютона:**
    *   P(x) = f[x₀] + f[x₀,x₁](x−x₀) + f[x₀,x₁,x₂](x−x₀)(x−x₁) + ...
    *   Разделённые разности: f[xᵢ] = yᵢ; f[xᵢ,...,xⱼ] = (f[x_{i+1},...,xⱼ] − f[xᵢ,...,x_{j−1}])/(xⱼ − xᵢ)
    *   Свойства: симметрична по аргументам; f[x₀,...,xₙ] = ∑ yᵢ/∏_{j≠i}(xᵢ − xⱼ)
    *   Достоинство: добавление новой точки — O(n) дополнительных вычислений
*   **Эрмитова интерполяция (с кратными узлами):**
    *   Заданы значения производных: P(xᵢ) = yᵢ, P'(xᵢ) = y'ᵢ, ..., P⁽ᵐⁱ⁾(xᵢ) = yᵢ⁽ᵐⁱ⁾
    *   Обобщение разделённых разностей: при совпадении xⱼ → xᵢ используем предел (производные)
    *   Сложность: O(n²) где n = ∑(mᵢ + 1)

### **B. БЫСТРАЯ ИНТЕРПОЛЯЦИЯ**
*   **Вычисление значений в корнях из единицы:**
    *   Если xₖ = ωᵏ (ω — корень из единицы), то yₖ = P(ωᵏ) = DFT(a)
    *   Обратно: коэффициенты через IDFT
*   **Быстрая интерполяция O(n log² n):**
    *   Бинарное разбиение набора точек пополам
    *   Рекурсия: L(x) = L_{лев}(x) + L_{прав}(x) · ∏_{лев} (x − xᵢ)
    *   Каждый уровень: умножение через FFT — O(n log n), рекурсия O(log n) уровней
*   **Интерполяция в корнях:**
    *   Если узлы — корни из единицы: интерполяция = DFT (за O(n log n))
    *   Произвольные узлы: алгоритм Бостана-Мохи или через вычисление ∏(x − xᵢ) рекурсивно

## **VII. БЫСТРОЕ УМНОЖЕНИЕ МНОГОЧЛЕНОВ**
> `g/g.md` · `g/g.cpp`

### **A. АЛГОРИТМЫ УМНОЖЕНИЯ**
*   **Наивный алгоритм:** O(n·m) — умножение каждого на каждый
*   **Алгоритм Карацубы:**
    *   P = P₁xᵏ + P₀, Q = Q₁xᵏ + Q₀ (k ≈ n/2)
    *   PQ = P₁Q₁x²ᵏ + ((P₁+P₀)(Q₁+Q₀) − P₁Q₁ − P₀Q₀)xᵏ + P₀Q₀
    *   3 умножения вместо 4 → T(n) = 3T(n/2) + O(n) → O(n^{log₂3}) ≈ O(n^{1.585})
*   **Toom-Cook (Toom-3, Toom-k):**
    *   Разбиение на k частей → 2k−1 умножений
    *   Toom-3: 5 умножений, O(n^{log₃5}) ≈ O(n^{1.465})
*   **Алгоритм Шёнхаге-Штрассена:** O(n log n log log n) — через FFT в ℤ/2^mℤ

### **B. БЫСТРОЕ ПРЕОБРАЗОВАНИЕ ФУРЬЕ (FFT)**
*   **Дискретное преобразование Фурье (DFT):**
    *   Aₖ = ∑_{j=0}^{n−1} aⱼ ωₙ^{jk} где ωₙ = e^{2πi/n} — первообразный корень
    *   Матрица DFT: F_{jk} = ωₙ^{jk} — ортогональная (с точностью до нормировки)
*   **Алгоритм Кули-Тьюки (FFT):**
    *   Разбиение на чётные/нечётные индексы: A(x) = A_{чёт}(x²) + x A_{нечёт}(x²)
    *   Рекурсия: T(n) = 2T(n/2) + O(n) → O(n log n)
    *   Итеративная реализация: bit-reversal перестановка + бабочки
*   **Обратное преобразование (IFFT):**
    *   aₖ = (1/n) ∑ Aⱼ ωₙ^{−jk} — то же FFT, но с ωₙ⁻¹ и нормировкой 1/n
*   **Умножение многочленов через FFT:**
    *   1) Интерполяция a → A, b → B через FFT — O(n log n)
    *   2) Покоординатное умножение: Cₖ = Aₖ · Bₖ — O(n)
    *   3) Обратное преобразование C → c — O(n log n)
    *   Итого: O(n log n) с точностью до выбора «длинного» модуля
*   **FFT в конечных полях (NTT — Number Theoretic Transform):**
    *   Замена комплексных корней на корни в 𝔽_p: g^{(p−1)/n}
    *   Требования: p — простое, p ≡ 1 (mod n), p ≡ 1 (mod 2^k) для итеративного FFT
    *   Модули: 998244353 (2³·7·17 + 1), 1004535809 (2²¹·479 + 1), 469762049 (2²⁶·7 + 1)
    *   Китайская теорема об остатках (CRT) для увеличения диапазона: объединение результатов по нескольким модулям
*   **FFT для свёртки и других операций:**
    *   Свёртка: cₖ = ∑ aᵢbⱼ при i+j=k → через DFT за O(n log n)
    *   Корреляция, умножение матриц, вычисление детерминанта

## **VIII. БЫСТРОЕ ДЕЛЕНИЕ И ВОЗВЕДЕНИЕ В СТЕПЕНЬ**
> `h/h.md` · `h/h.cpp`

### **A. БЫСТРОЕ ДЕЛЕНИЕ МНОГОЧЛЕНОВ**
*   **Деление через обращение:**
    *   Найти Q(x) = 1/D(x) мод xᵏ (формальное обращение)
    *   Итерация Ньютона: Qₙ₊₁ = Qₙ(2 − D·Qₙ) мод x^{2ⁿ}
    *   Сложность: O(n log n) через FFT
*   **Вычисление остатка:**
    *   P(x) mod D(x): наивно O(n·m), через обращение O(n log n)
    *   P(x) mod (xᵏ − a): циклический сдвиг коэффициентов — O(n)
*   **Многоточечное вычисление:**
    *   Вычислить P(xᵢ) для n точек: O(n log² n) через рекурсию + FFT
    *   Разделение на две половины + вычисление ∏_{лев}(x − xⱼ) рекурсивно
*   **Быстрое вычисление P(x) mod ∏(x − aᵢ):**
    *   Рекурсия: P mod (L·R) = (P mod L) + L · ((P/L) mod R) — O(n log² n)

### **B. БЫСТРОЕ ВОЗВЕДЕНИЕ МНОГОЧЛЕНОВ В СТЕПЕНЬ**
*   **Бинарное возведение:**
    *   Pᵏ: k = ∑ bⱼ 2ʲ → Pᵏ = ∏_{bⱼ=1} P^{2ʲ}
    *   Наивно: O(M(n) log k) где M(n) — стоимость умножения
    *   Через усечение: Pᵏ mod xⁿ — отбрасываем старшие члены — O(n log k)
*   **Экспонента от многочлена:**
    *   exp(P) = ∑_{k≥0} Pᵏ/k!
    *   Алгоритм: log(Q) = P → Q' = Q·P' → рекуррентность по коэффициентам
    *   Сложность: O(n log n) через FFT
*   **Логарифм от многочлена:**
    *   log(1 + P) = ∑_{k≥1} (−1)^{k+1} Pᵏ/k (при P₀ = 0)
    *   Через дифференцирование: (log Q)' = Q'/Q → log Q = ∫ Q'/Q
    *   Сложность: O(n log n) через деление + интегрирование
*   **Степенной ряд (формальные):**
    *   Разложение exp, log, sin, cos, (1−x)⁻ᵅ в формальные ряды
    *   Композиция P(Q(x)): O(n^{3/2}) или O(n^{1+ε}) — нет простого O(n log n)

## **IX. РЕКУРРЕНТНЫЕ ПОСЛЕДОВАТЕЛЬНОСТИ**
> `i/i.md` · `i/i.cpp`

### **A. ЛИНЕЙНЫЕ РЕКУРРЕНТЫ С ПОСТОЯННЫМИ КОЭФФИЦИЕНТАМИ**
*   **Определение:** aₙ = c₁aₙ₋₁ + c₂aₙ₋₂ + ... + cₖaₙ₋ₖ (k-я рекуррентность)
*   **Характеристический многочлен:** λᵏ − c₁λᵏ⁻¹ − c₂λᵏ⁻² − ... − cₖ = 0
*   **Общее решение (при различных корнях λ₁, ..., λₖ):**
    *   aₙ = α₁λ₁ⁿ + α₂λ₂ⁿ + ... + αₖλₖⁿ
    *   α₁, ..., αₖ определяются из начальных условий a₀, ..., aₖ₋₁
*   **При кратных корнях:** если λ — корень кратности m, то в решение входят λⁿ, nλⁿ, ..., n^{m−1}λⁿ
*   **Пример: числа Фибоначчи:**
    *   Fₙ = Fₙ₋₁ + Fₙ₋₂ → λ² − λ − 1 = 0 → λ₁,₂ = (1 ± √5)/2
    *   Fₙ = (φⁿ − ψⁿ)/√5 (формула Бине)

### **B. МАТРИЧНЫЙ МЕТОД**
*   **Приведение к матричной форме:**
    *   [aₙ, aₙ₋₁, ..., aₙ₋ₖ₊₁]ᵀ = M · [aₙ₋₁, aₙ₋₂, ..., aₙ₋ₖ]ᵀ
    *   M — матрица компаньонов: [[c₁, c₂, ..., cₖ], [1, 0, ..., 0], ..., [0, ..., 1, 0]]
*   **Быстрое возведение M в степень:**
    *   aₙ = M^{n−k+1} · [aₖ₋₁, ..., a₀]ᵀ
    *   Возведение за O(k³ log n) или O(k^{ω} log n) где ω — стоимость умножения матриц
*   **Пример:** Fₙ = [[1,1],[1,0]]ⁿ⁻¹ · [1,0]ᵀ → O(log n) через бинарное возведение матрицы
*   **Связь с特征值:** M = PDP⁻¹ где D = diag(λ₁, ..., λₖ) → Mⁿ = PDⁿP⁻¹

### **C. АЛГОРИТМ КИТАМАСЫ (KITAMASA)**
*   **Задача:** вычислить aₙ за O(k² log n) без матриц
*   **Идея:** выразить aₙ через начальные a₀, ..., aₖ₋₁: aₙ = ∑_{i=0}^{k−1} dᵢ aᵢ
*   **Рекуррентность для коэффициентов:**
    *   Многочлен T(x) = xᵏ − c₁xᵏ⁻¹ − ... − cₖ
    *   xⁿ mod T(x) = ∑ dᵢ xⁱ — коэффициенты искомого выражения
    *   Бинарное возведение полиномиального класса: O(k² log n)
*   **Оптимизация через FFT:** деление полиномов за O(k log k) → O(k log k log n)
*   **Применение:** вычисление N-го члена линейной рекуррентности (Фибоначчи, числа Каталана, ...) за O(k log k log n)

## **X. СИММЕТРИЧЕСКИЕ МНОГОЧЛЕНЫ, РЕЗУЛЬТАНТ И ДИСКРИМИНАНТ**
> `j/j.md` · `j/j.cpp`

### **A. СИММЕТРИЧЕСКИЕ МНОГОЧЛЕНЫ**
*   **Элементарные симметрические многочлены:**
    *   eₖ(x₁,...,xₙ) = ∑_{1≤i₁<...<iₖ≤n} x_{i₁}...x_{iₖ}
    *   e₀ = 1, e₁ = ∑xᵢ, eₙ = ∏xᵢ
    *   Связь с корнями: для P(x) = aₙ∏(x−xᵢ), eₖ = (−1)ᵏ aₙ₋ₖ/aₙ
*   **Степенные суммы:** pₖ = ∑xᵢᵏ
*   **Полные симметрические многочлены:** hₖ = ∑_{1≤i₁≤...≤iₖ≤n} x_{i₁}...x_{iₖ}
*   **Основная теорема о симметрических многочленах:**
    *   Любой симметрический многочлен f(x₁,...,xₙ) ∈ K[x₁,...,xₙ] единственным образом表达ается как полиномиальная функция от e₁, ..., eₙ
    *   Алгоритм: лексикографическая замена мономов — O(n·deg f)
*   **Суммы степеней корней:**
    *   pₖ = ∑zᵢᵏ — вычисляется через формулы Ньютона
    *   ζeta-функция Дедекинда: ζₖ(s) = ∑_{n≥1} 1/nˢ — связь с простыми числами

### **B. РЕЗУЛЬТАНТ**
*   **Определение:** Res(P, Q) — детерминант матрицы Сильвестра (степени n и m)
*   **Свойства:**
    *   Res(P, Q) = 0 ⟺ P и Q имеют общий корень
    *   Res(P, Q) = (−1)^{nm} Res(Q, P)
    *   Res(P, Q) = aₙᵐ ∏_{i} Q(αᵢ) = (−1)^{nm} bₘⁿ ∏_{j} P(βⱼ) — через корни
    *   Res(PQ, R) = Res(P, R) · Res(Q, R)
*   **Вычисление:**
    *   Наивно: O(n³ m³) через детерминант
    *   Через алгоритм Евклида: O(n² m²) или O~((n+m)²)
*   **Применения:**
    *   Исключение переменных: Res_x(P(x,y), Q(x,y)) — многочлен по y без x
    *   Проверка общих корней в системах уравнений
    *   Вычисление дискриминанта

### **C. ДИСКРИМИНАНТ**
*   **Определение:** D(P) = aₙ^{2n−2} ∏_{i<j} (zᵢ − zⱼ)² — квадрат разностей корней
*   **Связь с результантом:** D(P) = (−1)^{n(n−1)/2} aₙ⁻¹ Res(P, P')
*   **Свойства:**
    *   D(P) = 0 ⟺ P имеет кратный корень
    *   D(ax) = a^{n(n−1)} D(x) — однородность
    *   D(xⁿ + a₀) = (−1)^{n(n−1)/2} nⁿ a₀ⁿ⁻¹
*   **Дискриминанты малых степеней:**
    *   n=2: D = b² − 4ac
    *   n=3: D = 18abcd − 4b³d + b²c² − 4ac³ − 27a²d²
    *   n=4: дискриминант через результант с производной
*   **Применения:**
    *   Определение числа различных корней
    *   Критерий разложимости: D = квадрат ⟺ группа перестановок корней содержит только чётные
    *   Связь с галуа-группой: |Gal(P)| делит n! и связано с D

### **D. СПЕЦИАЛЬНЫЕ МНОГОЧЛЕНЫ**
*   **Ортогональные многочлены:**
    *   Лежандр: Pₙ(x) = (1/(2ⁿn!)) dⁿ/dxⁿ (x²−1)ⁿ — на [−1,1] с весом 1
    *   Чебышёв 1-го рода: Tₙ(x) = cos(n·arccos x) — рекуррентность Tₙ = 2xTₙ₋₁ − Tₙ₋₂
    *   Чебышёв 2-го рода: Uₙ(x) = sin((n+1)arccos x)/sin(arccos x)
    *   Лагерр: Lₙ(x) = eˣ dⁿ/dxⁿ (xⁿ e⁻ˣ) — на [0,∞) с весом e⁻ˣ
    *   Эрмит: Hₙ(x) = (−1)ⁿ e^{x²} dⁿ/dxⁿ e⁻ˣ² — на (−∞,∞) с весом e⁻ˣ²
*   **Многочлены Бернулли:** B₀ = 1, ∑_{k=0}^{n} C(n+1,k)Bₖ = 0 — связаны с суммами степеней
*   **Многочлены Эйлера:** Eₙ — связаны с секансом и тангенсом
*   **Многочлены Белла:** Bₙ(x) = ∑_{k=0}^{n} S(n,k)xᵏ — полные симметрические для x₁=...=xₙ=x
*   **Многочлены Бернштейна:** Bᵢⁿ(x) = C(n,i)xⁱ(1−x)ⁿ⁻ⁱ — базис для кривых Безье

## **ПРИЛОЖЕНИЕ: ШИФРЫ И БИТОВЫЕ ОПЕРАЦИИ**

> Этот раздел объединяет прикладные темы, использующие алгебраические структуры.
> Шифры связаны с `math/number-theory` (модулярная арифметика, первообразные, RSA).
> Битовые операции связаны с `struct/struct.md` (битовые множества, перебор подмножеств).

### **ШИФРЫ (шифры)**
*   **Классические подстановочные шифры:**
    *   Caesar, Vigenère, Affine, Playfair, Hill — линейные преобразования над алфавитом
    *   Метод частотного анализа, индекс совпадений (Coincidence Index)
*   **Шифры с открытым ключом:**
    *   RSA: безопасность = сложность факторизации N = pq
    *   Diffie-Hellman: обмен ключами через дискретный логарифм
    *   ElGamal: основа на проблеме дискретного логарифма
*   **Современная криптография:**
    *   AES (Rijndael): подстановки и линейные преобразования над GF(2⁸)
    *  椭圆ные кривые: ECDSA, ECDH — группа точек эллиптической кривой
    *  Хеш-функции: SHA-256, BLAKE3 — построение через Merkle-Damgård

### **БИТОВЫЕ ОПЕРАЦИИ (битовые операции)**
*   **Базовые операции:** AND, OR, XOR, NOT, сдвиги
*   **Арифметические трюки:**
    *   x & (−x) — младший установленный бит
    *   x & (x−1) — сброс младшего бита
    *   (x & (x−1)) == 0 — проверка на степень двойки
    *   popcount, clz, ctz — подсчёт битов, ведущие/хвостовые нули
*   **Битовые маски и перебор:**
    *   Перебор подмножеств: O(2ⁿ) через битовую маску
    *   Перебор k-подмножеств: O(C(n,k)) через следующую комбинацию
    *   DP по подмножествам: dp[mask] — обновление за O(n)
*   **Длинная арифметика:**
    *   Представление в базе B = 10⁹ или 2³²
    *   Сложение/вычитание: O(n), умножение: FFT за O(n log n)
    *   Деление: Ньютон за O(n log n)
