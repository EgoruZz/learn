## **I. ОСНОВНЫЕ ПОНЯТИЯ И ОПРЕДЕЛЕНИЯ**

### **1.1. Алгебраические основы**
* **Определение многочлена:** формальная сумма a₀ + a₁x + ... + aₙxⁿ
* **Степень многочлена (deg P)**
* **Коэффициенты, старший коэффициент**
* **Каноническая форма многочлена**
* **Равенство многочленов**
* **Нулевой многочлен и его степень**
* **Многочлены от нескольких переменных**

### **1.2. Кольцо многочленов**
* **Сложение и вычитание многочленов**
* **Умножение многочленов (свертка)**
* **Свойства кольца многочленов:**
  * Коммутативность, ассоциативность
  * Дистрибутивность
  * Существование единицы
* **Делимость многочленов**
* **Обратимые элементы (многочлены степени 0)**

## **II. ДЕЛЕНИЕ С ОСТАТКОМ И ТЕОРЕМА БЕЗУ**

### **2.1. Алгоритм деления**
* **Теорема о делении с остатком:** P(x) = Q(x)D(x) + R(x), deg R < deg D
* **Единственность частного и остатка**
* **Деление на линейный двучлен (x - a)**
* **Схема Горнера для вычисления значения и деления**

### **2.2. Теорема Безу и следствия**
* **Теорема Безу:** Остаток от деления P(x) на (x - a) равен P(a)
* **Корень многочлена (определение)**
* **Кратность корня**
* **Теорема:** x = a - корень ⇔ (x - a) делит P(x)
* **Многочлен, разложенный на линейные множители**

## **III. НОД И АЛГОРИТМ ЕВКЛИДА**

### **3.1. Наибольший общий делитель**
* **Определение НОД многочленов**
* **Существование и единственность (с точностью до умножения на константу)**
* **Свойства НОД:**
  * gcd(P, Q) = gcd(Q, P mod Q)
  * gcd(P, 0) = P/LC(P) (нормированный)
  * gcd(aP, bQ) = gcd(P, Q) для ненулевых a, b
* **Вычисление НОД нескольких многочленов**

### **3.2. Алгоритм Евклида для многочленов**
* **Классический алгоритм Евклида**
* **Расширенный алгоритм Евклида:** нахождение U, V таких что UP + VQ = gcd(P, Q)
* **Сложность алгоритма Евклида**
* **Субрезультантный алгоритм (subresultant GCD)**

## **V. КОРНИ МНОГОЧЛЕНОВ**

### **5.1. Основная теорема алгебры**
* **Формулировка:** всякий многочлен степени n с комплексными коэффициентами имеет ровно n корней с учетом кратности
* **Разложение над ℂ:** P(z) = aₙ∏(z - zᵢ)
* **Следствия для многочленов с вещественными коэффициентами:**
  * Комплексные корни идут парами (a±bi)
  * Разложение над ℝ: линейные и неприводимые квадратные множители

### **5.2. Теорема Виета**
* **Формулы Виета для корней:**
  * ∑xᵢ = -a_{n-1}/aₙ
  * ∑xᵢxⱼ = a_{n-2}/aₙ
  * ∏xᵢ = (-1)ⁿa₀/aₙ
* **Элементарные симметрические многочлены**
* **Выражение степенных сумм через элементарные симметрические многочлены**
* **Формулы Ньютона для степенных сумм**

### **5.3. Границы корней**
* **Теорема Лагерра:** оценки модуля корней
* **Правило знаков Декарта**
* **Теорема Штурма:** количество вещественных корней на интервале
* **Теорема Бюдана-Фурье**
* **Дискриминант многочлена и его связь с кратными корнями**

## **VII. БЫСТРОЕ УМНОЖЕНИЕ МНОГОЧЛЕНОВ**

### **7.1. Классические алгоритмы**
* **Наивный алгоритм:** O(n²)
* **Алгоритм Карацубы:** O(n^{log₂3}) ≈ O(n^{1.585})
  * Рекурсивное разбиение
  * Оптимизация через 3 умножения вместо 4
* **Алгоритм Тома-Кука (Toom-Cook):** O(n^{1+ε})
  * Обобщение Карацубы
  * Toom-3, Toom-4

### **7.2. Преобразование Фурье**
* **Дискретное преобразование Фурье (DFT):**
  * Определение: A(ωₖ) = ∑ aⱼ ωₖʲ, где ω = e^{2πi/n}
  * Свойства: линейность, свертка → произведение
* **Быстрое преобразование Фурье (FFT):**
  * Алгоритм Кули-Тьюки (Cooley-Tukey)
  * Рекурсивная и итеративная реализации
  * Bit-reversal permutation
* **Обратное преобразование Фурье (IFFT)**

### **7.3. Теоретико-числовое преобразование (NTT)**
* **Преобразование в конечных полях**
* **Требования к модулю:** существование примитивного корня степени 2^k
* **Модули для NTT:** 998244353, 1004535809, 469762049
* **Китайская теорема об остатках для больших коэффициентов**

### **7.4. Продвинутые алгоритмы**
* **Алгоритм Шёнхаге-Штрассена:** O(n log n log log n)
* **Алгоритм Фюрера:** O(n log n 2^{O(log* n)})
* **Алгоритмы для умножения разреженных многочленов**

## **VIII. БЫСТРОЕ ДЕЛЕНИЕ МНОГОЧЛЕНОВ**

## **VI. ИНТЕРПОЛЯЦИЯ**

### **6.1. Интерполяционный многочлен Лагранжа**
* **Постановка задачи:** найти P степени ≤ n такой что P(xᵢ) = yᵢ
* **Формула Лагранжа:** L(x) = ∑ yᵢ ∏_{j≠i} (x - xⱼ)/(xᵢ - xⱼ)
* **Существование и единственность**
* **Погрешность интерполяции (остаточный член)**

### **6.2. Интерполяционный многочлен Ньютона**
* **Разделенные разности (определение и свойства)**
* **Формула Ньютона:** N(x) = f[x₀] + f[x₀,x₁](x-x₀) + ... + f[x₀,...,xₙ]∏(x-xᵢ)
* **Связь с формулой Лагранжа**
* **Интерполяция с кратными узлами (эрмитова интерполяция)**

### **6.3. Быстрые алгоритмы интерполяции**
* **Вычисление значений в точках O(n log² n)**
* **Быстрая интерполяция O(n log² n)**
* **Интерполяция в корнях из единицы (использование FFT)**

* **Применения:** исключение переменных, решение систем уравнений

### **13.2. Дискриминант**

* **Связь с результантом:** D(P) = (-1)^{n(n-1)/2} aₙ^{-1} Res(P, P')
