## **A. ЛИНЕЙНЫЕ РЕКУРРЕНТЫ С ПОСТОЯННЫМИ КОЭФФИЦИЕНТАМИ**

### **1. Определение**
* **Рекуррентность:** aₙ = c₁aₙ₋₁ + c₂aₙ₋₂ + ... + cₖaₙ₋ₖ (k-я)
* **Начальные условия:** a₀, a₁, ..., aₖ₋₁ заданы

### **2. Характеристический многочлен**
* **Определение:** λᵏ − c₁λᵏ⁻¹ − c₂λᵏ⁻² − ... − cₖ = 0
* **Общее решение (при различных корнях):** aₙ = α₁λ₁ⁿ + α₂λ₂ⁿ + ... + αₖλₖⁿ
* **При кратных корнях:** если λ — корень кратности m, то в решение входят λⁿ, nλⁿ, ..., n^{m−1}λⁿ

### **3. Коэффициенты αᵢ**
* **Система линейных уравнений:** из начальных условий a₀, ..., aₖ₋₁
* **Через обратную матрицу Вандермонда:** (V⁻¹ · [a₀, ..., aₖ₋₁]ᵀ)ᵢ = αᵢ

### **4. Пример: числа Фибоначчи**
* **Рекуррентность:** Fₙ = Fₙ₋₁ + Fₙ₋₂, F₀ = 0, F₁ = 1
* **Характеристический:** λ² − λ − 1 = 0 → λ₁,₂ = (1 ± √5)/2
* **Формула Бине:** Fₙ = (φⁿ − ψⁿ)/√5 где φ = (1+√5)/2, ψ = (1−√5)/2

## **B. МАТРИЧНЫЙ МЕТОД**

### **5. Приведение к матричной форме**
* **Вектор состояния:** [aₙ, aₙ₋₁, ..., aₙ₋ₖ₊₁]ᵀ
* **Матрица компаньонов:** M = [[c₁, c₂, ..., cₖ], [1, 0, ..., 0], ..., [0, ..., 1, 0]]
* **Формула:** [aₙ, ..., aₙ₋ₖ₊₁]ᵀ = M · [aₙ₋₁, ..., aₙ₋ₖ]ᵀ

### **6. Быстрое возведение матрицы**
* **aₙ = M^{n−k+1} · [aₖ₋₁, ..., a₀]ᵀ**
* **Сложность:** O(k³ log n) или O(k^{ω} log n) где ω — стоимость умножения матриц
* **Пример:** Fₙ = [[1,1],[1,0]]ⁿ⁻¹ · [1,0]ᵀ → O(log n)

### **7. Связь с собственными значениями**
* **M = PDP⁻¹** где D = diag(λ₁, ..., λₖ) → Mⁿ = PDⁿP⁻¹
* **Это доказывает:** формула через корни характеристического многочлена

---

## **C. АЛГОРИТМ КИТАМАСЫ**

### **8. Постановка задачи**
* **Задача:** вычислить aₙ за O(k² log n) без матриц
* **Идея:** выразить aₙ через начальные a₀, ..., aₖ₋₁: aₙ = ∑_{i=0}^{k−1} dᵢ aᵢ

### **9. Рекуррентность для коэффициентов**
* **Многочлен:** T(x) = xᵏ − c₁xᵏ⁻¹ − ... − cₖ
* **Результат:** xⁿ mod T(x) = ∑ dᵢ xⁱ — коэффициенты выражения
* **Бинарное возведение:** полиномиальный класс, деление по модулю T(x)
* **Сложность:** O(k² log n)

### **10. Оптимизация через FFT**
* Деление полиномов за O(k log k) → O(k log k log n)
* Актуально при больших k (> 100)
