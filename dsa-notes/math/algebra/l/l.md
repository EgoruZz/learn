**XII. ДЛИННАЯ АРИФМЕТИКА**

> **Архитектура:** `BigInt` (l.cpp) — раздел ветки algebra. Вводит представление больших чисел, базовые операции (сложение, вычитание, умножение, деление), оптимизации (основание 10⁹, быстрое умножение через Карацубу). Опирается на базовые арифметические операции (раздел I) и битовые операции (раздел XI, k). Используется в `math/number-theory` (做大数运算), `math/combinatorics` (подсчёт больших чисел), `struct/struct.md` (сопоставление длинных строк).
>
> **Связи с другими ветками:** модулярная арифметика — `math/number-theory` (для вычислений по модулю p); быстрое умножение через FFT — раздел VII (f); шифры и криптография — раздел XIII (m); битовые операции — раздел XI (k); символьные вычисления — `struct/struct.md` (раздел IX AST).

## **A. ПРЕДСТАВЛЕНИЕ БОЛЬШИХ ЧИСЕЛ**

### **1. Структура данных**
* **Представление:** `vector<int64_t>` — массив «цифр» в системе счисления с основанием B
* **Основание B:**
    * `B = 10⁹`: каждый элемент хранит 9 десятичных цифр; `10⁹ < 2³¹` — умножение двух цифр не переполняет `int64_t`
    * `B = 2³²`: для битовых операций; умножение через `uint64_t`
* **Порядок хранения:** младшие разряды по индексу 0 (обратный порядок)
* **Нормализация:** после каждой операции пересчитать «заём/перенос», чтобы все элементы ∈ [0, B)
* **Знак:** хранить отдельно (bool `negative`); 0 — всегда положительный

### **2. Сравнение**
* **Длина:** если `|a| > |b|` (число цифр), то `|a| > |b|` по модулю
* **Лексикографическое:** при равных длинах — сравнение от старшего разряда к младшему
* **Сложность:** O(n) — один проход

---

## **B. БАЗОВЫЕ ОПЕРАЦИИ**

### **3. Сложение и вычитание**
* **Сложение (одинаковые знаки):** поэлементно + перенос; O(max(n, m))
* **Вычитание:** поэлементно + заём; O(max(n, m))
* **Разные знаки:** сводится к вычитанию модулей, знак результата определяется по модулям
* **Умножение «в столбик»:** каждый элемент `a[i]` умножается на каждый `b[j]`, результат в `res[i+j]`; O(n·m)

### **4. Умножение**
* **Наивное:** O(n·m) — для каждого разряда первого числа умножаем на все разряды второго
* **Карацуба:** O(n^{log₂3}) ≈ O(n^{1.585})
    * Разбиение: `a = a₁·Bᵏ + a₀`, `b = b₁·Bᵏ + b₀`
    * Три произведения: `a₁·b₁`, `a₀·b₀`, `(a₁+a₀)·(b₁+b₀)`
    * `ab = a₁b₁·B²ᵏ + ((a₁+a₀)(b₁+b₀) − a₁b₁ − a₀b₀)·Bᵏ + a₀b₀`
* **FFT/NTT:** O(n log n) — для очень больших чисел (n > 10⁴)

### **5. Деление**
* **Деление короткого на длинное:** O(n) — поэлементно с заёмом
* **Деление длинного на длинное:** бинарный поиск по частному или алгоритм Кнута (Knuth's Algorithm D); O(n·m) или O(n²)
* **Деление с остатком:** `a = q·b + r`, `0 ≤ r < |b|`

---

## **C. ОПТИМИЗАЦИИ**

### **6. Основание 10⁹**
* Хранение: `vector<int>` (каждый элемент < 10⁹)
* Сумма/разность: O(max(n, m))
* Произведение: `int64_t temp = (int64_t)a[i] * b[j] + res[i+j] + carry`
* Нормализация: `res[i+j+1] += temp / B`, `res[i+j] = temp % B`

### **7. Карацуба**
* Разбиение: `a = a₁·Bᵏ + a₀`, `b = b₁·Bᵏ + b₀`
* Три рекурсивных произведения: P₁ = a₁b₁, P₂ = a₀b₀, P₃ = (a₁+a₀)(b₁+b₀)
* Результат: `a₁b₁·B²ᵏ + (P₃ − P₁ − P₂)·Bᵏ + a₀b₀`
* Граница переключения: при n ≤ ~64 — наивное быстрее; при n > 64 — Карацуба

### **8. Ввод/вывод**
* Чтение строки → разбиение по 9 символов справа налево → `vector<int>`
* Запись: старший элемент без ведущих нулей, остальные с нулями до 9 цифр
