**B. МАТРИЦЫ И ОПЕРАЦИИ**

> **Архитектура:** `MatrixOperations` (b.cpp) — наследует `AlgebraicBasics` (a.cpp). Реализует: все базовые операции над матрицами (сложение, умножение, транспонирование, след), элементарные преобразования и метод Гаусса, блочные матрицы, Кронекеровское произведение. Все методы параметризованы размером `n × m` и работают с произвольными кольцами/полями через `long long` (для модулярных вычислений — через `mod`).
>
> **Связи:** `AlgebraicBasics` (a) — модулярная арифметика; определители — следующий раздел (C); обратные матрицы и ранг — раздел D; системы линейных уравнений — раздел E; линейные операторы — раздел G.

# **A. ОПРЕДЕЛЕНИЯ И ТИПЫ МАТРИЦ**

## **1. Основные определения**
*   **Матрица** `m × n`: прямоугольная таблица элементов `a[i][j]` где `i ∈ [1,m]`, `j ∈ [1,n]`; `a[i][j]` — элемент в строке `i`, столбце `j`
*   **Вектор-столбец:** матрица `n × 1`; **вектор-строка:** матрица `1 × n`
*   **Пространство `ℝⁿ`:** отождествление с матрицами-столбцами высоты `n`

## **2. Типы матриц**
*   **Квадратная:** `m = n`; **диагональная:** `a[i][j] = 0` при `i ≠ j`; **единичная:** `a[i][j] = δᵢⱼ`
*   **Верхнетреугольная:** `a[i][j] = 0` при `i > j`; **нижнетреугольная:** `a[i][j] = 0` при `i < j`
*   **Нулевая матрица:** все элементы `0`; **starter matrix:** `eᵢⱼ` — матрица с `1` на позиции `(i,j)`

# **B. ОПЕРАЦИИ НАД МАТРИЦАМИ**

## **1. Сумма и вычитание**
*   `(A ± B)[i][j] = A[i][j] ± B[i][j]`; условия: `A` и `B` одного размера
*   **Свойства:** коммутативность `A+B = B+A`, ассоциативность `(A+B)+C = A+(B+C)`

## **2. Умножение на скаляр**
*   `(αA)[i][j] = α · A[i][j]`; свойства: `α(A+B) = αA + αB`, `(αβ)A = α(βA)`

## **3. Произведение матриц**
*   `(AB)[i][j] = Σ_k A[i][k] · B[k][j]`; условия: число столбцов `A` = число строк `B`
*   **Некоммутативность:** `AB ≠ BA` (в общем случае); `AB = BA` для диагональных, единичной, вообще для специальных пар
*   **Свойства:** ассоциативность `(AB)C = A(BC)`, дистрибутивность `A(B+C) = AB+AC`

## **4. Степень матрицы**
*   `A⁰ = I`, `Aᵏ = A · Aᵏ⁻¹`; быстрое возведение в степень `O(n³ log k)` через square-and-multiply (уже в a.cpp)

## **5. Диагональные матрицы**
*   `diag(d₁,...,dₙ)`: умножение `D·A` — умножение строк `i` на `dᵢ`; `A·D` — столбцов `j` на `dⱼ`

## **6. Единичная матрица**
*   `Iₙ`: `I·A = A·I = A`; `IA = A`; нейтральный элемент матричного умножения

## **7. Транспонирование**
*   `(Aᵀ)[i][j] = A[j][i]`; `(Aᵀ)ᵀ = A`; `(A+B)ᵀ = Aᵀ+Bᵀ`; `(αA)ᵀ = αAᵀ`
*   **Двойственное:** `(AB)ᵀ = BᵀAᵀ` (порядок меняется!)

## **8. Сопряжение**
*   `A* = Āᵀ` (для комплексных матриц); для вещественных `A* = Aᵀ`

## **9. След**
*   `tr(A) = Σᵢ a[i][i]` — сумма диагональных элементов
*   **Свойства:** `tr(AB) = tr(BA)`, `tr(A) = Σ λᵢ`, `tr(Aᵀ) = tr(A)`, `tr(αA) = α·tr(A)`

# **C. БЛОЧНЫЕ МАТРИЦЫ И СПЕЦИАЛЬНЫЕ ФОРМЫ**

## **1. Блочные матрицы**
*   Разбиение матрицы на подматрицы: `A = [[A₁₁, A₁₂], [A₂₁, A₂₂]]`
*   **Умножение блоков:** если подматрицы compatible, умножаются как скаляры

## **2. Кронекеровское произведение**
*   `A ⊗ B`: блочная матрица `n₁n₂ × m₁m₂` где каждый блок `A[i][j] · B`
*   `dim(A ⊗ B) = dim(A) · dim(B)`

# **D. ЭЛЕМЕНТАРНЫЕ ПРЕОБРАЗОВАНИЯ И МЕТОД ГАУССА**

## **1. Элементарные преобразования**
*   Тип 1: перестановка двух строк (столбцов)
*   Тип 2: умножение строки (столбца) на скаляр `≠ 0`
*   Тип 3: прибавление к строке (столбцу) другой, умноженной на скаляр

## **2. Метод Гаусса**
*   **Приведение к ступенчатому виду:** последовательность элементарных преобразований строк
*   **Улучшенный ступенчатый вид:** каждый leading element `= 1`, и единственный ненулевой в столбце
*   **Сложность:** `O(n³)` для матрицы `n × n`
*   **Применение:** решение СЛУ (раздел E), вычисление ранга (раздел D), вычисление определителя (раздел C), нахождение обратной матрицы (раздел D)
