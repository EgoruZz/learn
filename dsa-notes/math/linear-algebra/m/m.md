**M. ПРИКЛАДНЫЕ АЛГОРИТМЫ ЛИНЕЙНОЙ АЛГЕБРЫ**

> **Архитектура:** `AppliedLinearAlgebra` (m.cpp) — наследует `NormedSpaces` (l.cpp). Реализует: QR-разложение, LU-разложение, Matrix Exponentiation, МНК, Sherman-Morrison, итерационные методы (Якоби, Зейдель), практику по базисам/подпространствам/отображениям. Все методы параметризованы размером `n` и работают через `double`.
>
> **Связи:** обратные матрицы — `d`; определители — `c`; СЛУ — `e`; собственные значения — `j` (для Якоби); нормы — `l` (для МНК).

---

# **A. МАТРИЧНЫЕ РАЗЛОЖЕНИЯ**

## **1. LU-разложение**
*   `A = LU` (L — нижнетреугольная с 1 на диагонали, U — верхнетреугольная)
*   **Разрешение `Ax = b`:** сначала `Ly = b` (прямой ход), затем `Ux = y` (обратный ход); `O(n²)`
*   **Построение:** `O(n³)` через приведение Гаусса

## **2. QR-разложение**
*   `A = QR` (Q — ортогональная, R — верхнетреугольная)
*   **Через Грам-Шмидт:** столбцы A → ортонормальный базис Q; `O(n²m)`
*   **Через вращения Гивенса:** `O(n³)`; более стабильно

---

# **B. MATRIX EXPONENTIATION**

*   `A^k` через square-and-multiply: `O(n³ log k)`
*   **Применение:** числа Фибоначчи `O(log n)`, линейные рекуррентности, shortest paths в DAG

---

# **C. МЕТОД НАИМЕНЬШИХ КВАДРАТОВ (МНК)**

*   **Задача:** `min ‖Ax − b‖₂` при `m > n` (переопределённая система)
*   **Нормальное уравнение:** `AᵀAx = Aᵀb`; решение через Гаусс `O(n³)`
*   **Через QR:** `Rx = Qᵀb` — численно стабильнее `O(n²)`

---

# **D. ШЕРМАН-МОРРИСОН**

*   Формула для обновления обратной матрицы: `(A + uvᵀ)⁻¹ = A⁻¹ − A⁻¹uvᵀA⁻¹ / (1 + vᵀA⁻¹u)`
*   **Применение:** обновление `A⁻¹` за `O(n²)` после изменения одной строки/столбца

---

# **E. ИТЕРАЦИОННЫЕ МЕТОДЫ**

## **1. Метод Якоби**
*   `x⁽ᵏ⁺¹⁾ᵢ = (bᵢ − Σ_{j≠i} aᵢⱼx⁽ᵏ⁾ⱼ) / aᵢᵢ`
*   **Сходимость:** если `A` диагонально доминирующая

## **2. Метод Зейделя**
*   Как Якоби, но с использованием уже обновлённых значений
*   Сходится быстрее Якоби

---

# **F. ПРАКТИКА**

## **1. Базисы**
*   `Extract Basis From Vectors` — выделение базиса через Гаусс
*   `Find Basis Of Span` — ненулевые строки ступенчатого вида
*   `Complete To Basis` — дополнение стандартными векторами
*   `Find Fundamental System Of Solutions` — ФСР однородной СЛУ

## **2. Подпространства**
*   Пересечение/сумма через ФСР и матричные уравнения

## **3. Проекции**
*   `proj_u(v) = (⟨v,u⟩/⟨u,u⟩) · u`; оператор проекции `P = B(AB)⁻¹A`
