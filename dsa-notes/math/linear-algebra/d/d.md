**D. ОБРАТНЫЕ МАТРИЦЫ И РАНГ**

> **Архитектура:** `InverseAndRank` (d.cpp) — наследует `Determinants` (c.cpp). Реализует: нахождение обратной матрицы (через присоединённую и через Гаусс), вычисление определителя, вычисление ранга, метод окаймляющих миноров. Все методы параметризованы размером `n × n`.
>
> **Связи:** определители — `c` (для `det(A)` и проверки обратимости); матричные операции — `b` (умножение, транспонирование); системы линейных уравнений — следующий раздел (E) (обратная матрица для `x = A⁻¹b`); линейные операторы — `g` (ядро/образ через ранг).

---

# **A. ОБРАТНАЯ МАТРИЦА**

## **1. Определение и существование**
*   **Обратная матрица:** `AA⁻¹ = A⁻¹A = I`; существует ⟺ `det(A) ≠ 0` (невырожденная)
*   **Единственность:** если `AB = I`, то `B = A⁻¹`
*   **Свойства:** `(AB)⁻¹ = B⁻¹A⁻¹`, `(Aᵀ)⁻¹ = (A⁻¹)ᵀ`, `det(A⁻¹) = 1/det(A)`, `(αA)⁻¹ = (1/α)A⁻¹`

## **2. Способы нахождения**

### **2.1. Через присоединённую матрицу**
*   **Присоединённая матрица:** `adj(A)[i][j] = A[j][i] = (−1)^{j+i} · M[j][i]` (алг. дополнение транспонированное)
*   **Формула:** `A⁻¹ = adj(A) / det(A)`
*   **Сложность:** `O(n³)` — вычисление `det` + вычисление `adj` через разложение по строке

### **2.2. Через метод Гаусса**
*   **Идея:** привести `[A | I]` к `[I | A⁻¹]` элементарными преобразованиями строк
*   На каждом шаге: деление строки на ведущий элемент + обнуление столбца
*   **Сложность:** `O(n³)`

## **3. Невырожденные матрицы**
*   `A` невырожденна ⟺ `det(A) ≠ 0` ⟺ `rank(A) = n` ⟺ существует `A⁻¹`
*   **Следствие:** `Ax = b` имеет единственное решение для любого `b`

---

# **B. ПОЛУОБРАТНАЯ И ПСЕВДООБРАТНАЯ МАТРИЦЫ**

## **1. Односторонние обратные**
*   **Левая обратная:** `BA = I` (но `AB ≠ I`); существует ⟺ `rank(A) = n` (столбцы линейно независимы)
*   **Правая обратная:** `AB = I` (но `BA ≠ I`); существует ⟺ `rank(A) = m` (строки линейно независимы)

## **2. Псевдообратная (Мура-Пенроуза)**
*   **Определение:**唯一 матрица `A⁺` такая, что `AA⁺A = A`, `A⁺AA⁺ = A⁺`, `(AA⁺)* = AA⁺`, `(A⁺A)* = A⁺A`
*   **Через SVD:** если `A = UΣVᵀ`, то `A⁺ = VΣ⁺Uᵀ` где `Σ⁺` — инвертированные ненулевые сингулярные числа
*   **Применение:** решение переопределённых систем `Ax ≈ b` → `x = A⁺b`

# **C. РАНГ МАТРИЦЫ**

## **1. Определение**
*   `rank(A)` = максимальное число линейно независимых строк (столбцов); `rank(A) = rank(Aᵀ)`
*   `rank(A) = r` ⟺ `A` содержит неsingular подматрицу `r × r`

## **2. Свойства**
*   `rank(A + B) ≤ rank(A) + rank(B)`
*   `rank(AB) ≤ min(rank(A), rank(B))`
*   `rank(A) + rank(B) ≤ rank(A + B) + rank(AB)` (неполное ранговое неравенство)
*   `rank(A) = r` ⟺ существует `r` линейно независимых строк/столбцов

## **3. Методы вычисления**
*   **Метод Гаусса:** приведение к ступенчатому виду; ранг = число ненулевых строк `O(n³)`
*   **Метод окаймляющих миноров:** ищем максимальный неsingular минор `O(n³)` через перебор
*   **Ранг произведения:** `rank(AB) ≥ rank(A) + rank(B) − n` (неполное ранговое неравенство)

## **4. Связь с другими характеристиками**
*   `rank(A) = n − dim(ker(A))` (теорема о размерности)
*   `rank(A) = n` ⟺ `det(A) ≠ 0` ⟺ `A` невырожденна
*   `rank(A) = 0` ⟺ `A = 0`
