**C. ОПРЕДЕЛИТЕЛИ И ОБЪЁМ СИСТЕМЫ ВЕКТОРОВ**

> **Архитектура:** `Determinants` (c.cpp) — наследует `MatrixOperations` (b.cpp). Реализует: вычисление определителей через Гаусс `O(n³)`, через разложение Лапласа `O(n!)`, свойства определителей, миноры/алгебраические дополнения, ориентированный объём системы векторов. Все методы параметризованы размером `n` и работают через `long long` (для модулярных вычислений — через `mod` из `AlgebraicBasics`).
>
> **Связи:** матричные операции — `b` (умножение, транспонирование, Гаусс); обратные матрицы — следующий раздел (D); определитель произведения `det(AB) = det(A)·det(B)` — связь с алгеброй матриц; объём — связь с `geometry.md` (для 2D/3D).

---

# **A. ОПРЕДЕЛЕНИЕ ОПРЕДЕЛИТЕЛЯ**

## **1. Через перестановки**
*   **Формула:** `det(A) = Σ_{σ ∈ Sₙ} sign(σ) · Π_{i=1}^{n} A[i][σ(i)]`
*   **Перестановка** σ: биекция `{1,...,n} → {1,...,n}`; `sign(σ) = (−1)^{инверсий}`
*   **Инверсия:** пара `(i,j)` где `i < j` но `σ(i) > σ(j)`
*   **Сложность:** `O(n!)` — экспоненциально

## **2. Лапласовское определение (рекурсия)**
*   `det(A) = Σ_{j=1}^{n} (−1)^{1+j} · a[1][j] · M[1][j]` где `M[i][j]` — минор (подматрица без строки `i` и столбца `j`)
*   **Сложность:** `O(n!)` — экспоненциально

## **3. Определители низших порядков**
*   `det([a]) = a`
*   `det([[a,b],[c,d]]) = ad − bc`
*   `det(3×3)`: правило Саррюса или полное разложение

---

# **B. СВОЙСТВА ОПРЕДЕЛИТЕЛЯ**

## **1. Основные свойства**
*   `det(Aᵀ) = det(A)`
*   `det(AB) = det(A) · det(B)`
*   `det(αA) = αⁿ det(A)` для `n × n` матрицы
*   `det(A⁻¹) = 1/det(A)`
*   Замена двух строк → изменение знака определителя
*   Прибавление к строке другой, умноженной на скаляр → определитель не меняется
*   Две одинаковые строки → `det = 0`

## **2. Верхнетреугольная матрица**
*   `det(U) = Π_{i=1}^{n} u[i][i]` — произведение диагональных элементов

---

# **C. ВЫЧИСЛЕНИЕ ОПРЕДЕЛИТЕЛЕЙ**

## **1. Через метод Гаусса**
*   Приведение к верхнетреугольному виду `O(n³)`; определитель = произведение диагонали × `(-1)^перестановок строк`
*   **Самый практичный метод** для вычислений

## **2. Через разложение Лапласа**
*   `det(A) = Σ_{j} (−1)^{i+j} · a[i][j] · M[i][j]` по строке `i`
*   **Сложность:** `O(n!)` — только для малых `n` или специальных матриц

## **3. Формула полного разложения**
*   `det(A) = Σ_{σ} sign(σ) · Π a[i][σ(i)]` — перебор всех перестановок

---

# **D. МИНОРЫ И АЛГЕБРАИЧЕСКИЕ ДОПОЛНЕНИЯ**

*   **Минор** `M[i][j]`: определитель подматрицы `A` без строки `i` и столбца `j`
*   **Алгебраическое дополнение:** `A[i][j] = (−1)^{i+j} · M[i][j]`
*   **Разложение по строке:** `det(A) = Σ_{j} a[i][j] · A[i][j]`
*   **Обратная матрица:** `A⁻¹[i][j] = A[j][i] / det(A)` — через алг. дополнения

---

# **E. ОБЪЁМ СИСТЕМЫ ВЕКТОРОВ**

## **1. Ориентированный объём**
*   **Определение:** `vol(v₁,...,vₙ) = det(v₁|...|vₙ)` где столбцы — векторы
*   **Геометрический смысл:** объём параллелепипеда = `|det(A)|`; знак — ориентация

## **2. Векторное произведение (ℝ³)**
*   `u × v` — вектор, перпендикулярный обоим; `|u × v|` = площадь параллелограмма
*   **Формула:** `(u × v)[k] = ε_{ijk} u[i] v[j]`

## **3. Смешанное произведение**
*   `(u × v) · w = det(u|v|w)` — объём трёхмерного параллелепипеда
*   **Связь с линейной зависимостью:** `det(v₁,...,vₙ) = 0` ⟺ векторы линейно зависимы

## **4. Определение объёма через определитель**
*   Для `n` векторов в `ℝⁿ`: объём параллелепипеда = `|det(v₁,...,vₙ)|`
*   Для `k` векторов в `ℝⁿ` (`k < n`): объём = `√det(G)` где `G` — матрица Грама `G[i][j] = ⟨vᵢ,vⱼ⟩`
