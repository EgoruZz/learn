**K. ФУНКЦИОНАЛЬНЫЕ МАТРИЦЫ И ВЕКТОРНЫЙ АНАЛИЗ**

> **Архитектура:** `FunctionalMatrices` (k.cpp) — наследует `JordanForm` (j.cpp). Реализует: дифференцирование матричных функций, градиент, якобиан, гессиан, правило цепочки. Все методы параметризованы и работают через `double`.
>
> **Связи:** матричные операции — `b` (умножение, транспонирование); собственные значения — `j` (для матричных экспонент); обратные матрицы — `d`; производные — связь с `math/analysis` (для функций нескольких переменных).

---

# **A. ФУНКЦИОНАЛЬНЫЕ МАТРИЦЫ СКАЛЯРНОГО АРГУМЕНТА**

## **1. Определение**
*   Матрица `A(t)` элементы которой — функции скалярного аргумента `t`
*   **Предел:** `lim_{t→t₀} A(t) = B` ⟺ `lim A[i][j](t) = B[i][j]` для всех `i,j`
*   **Непрерывность/дифференцируемость:** поэлементно

## **2. Производная матрицы**
*   `dA/dt` — матрица с элементами `(dA/dt)[i][j] = dA[i][j]/dt`
*   **Правило произведения:** `d(AB)/dt = (dA/dt)B + A(dB/dt)` — **порядок важен!**
*   **Матричная экспонента:** `d(e^{At})/dt = Ae^{At}`

---

# **B. ПРОИЗВОДНЫЕ ПО ВЕКТОРНОМУ АРГУМЕНТУ**

## **1. Градиент**
*   `∇f(x) = (∂f/∂x₁, ..., ∂f/∂xₙ)` — столбец-вектор; направление наибольшего возрастания

## **2. Якобиан**
*   `J[i][j] = ∂fᵢ/∂xⱼ` — матрица частных производных; `J ∈ ℝ^{m×n}` для `f: ℝⁿ → ℝᵐ`
*   **Связь с линейным отображением:** якобиан = матрица линейного приближения

## **3. Гессиан**
*   `H[i][j] = ∂²f/∂xᵢ∂xⱼ` — матрица вторых производных; симметрична
*   **Критерий экстремума:** `H` положительно определена → минимум; отрицательно определена → максимум

## **4. Правило цепочки**
*   `∇(f ∘ g)(x) = J_g(x)ᵀ · ∇f(g(x))` где `J_g` — якобиан `g`
*   Для `f: ℝᵐ → ℝ`, `g: ℝⁿ → ℝᵐ`: `∂(f∘g)/∂xⱼ = Σᵢ (∂f/∂yᵢ)·(∂gᵢ/∂xⱼ)`
