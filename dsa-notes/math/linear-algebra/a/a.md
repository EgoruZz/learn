**A. АЛГЕБРАИЧЕСКИЕ СТРУКТУРЫ И ОСНОВЫ**

> **Архитектура:** `AlgebraicBasics` (a.cpp) — базовый класс всей ветки linear-algebra. Вводит основные алгебраические структуры (группы, кольца, поля), арифметические операции над ними, конечные суммы и произведения. Все последующие разделы (B–M) строятся на этих примитивах. Собственной модулярной арифметики не вводит ( `math/number-theory`).
>
> **Связи:** модулярная арифметика (обратные элементы, быстрое возведение) — `math/number-theory`; комбинаторика (суммы, биномиальные коэффициенты) — `math/combinatorics`; ДП (суммы, рекуррентности) — `dynamic.md`; графы (циклы, компоненты) — `graph.md`; строки (хеширование по модулю) — `string/d`.

# **A. МНОЖЕСТВА И ОПЕРАЦИИ**

## **1. Множества**
*   **Определение:** множество — коллекция различных объектов (элементов); обозначение: `A = {a₁, ..., aₙ}` или `A = {x : P(x)}`
*   **Мощность:** `|A|` — число элементов; `|∅| = 0`
*   **Подмножество:** `A ⊆ B` ⟺ `∀x: x ∈ A ⟹ x ∈ B`; `A ⊂ B` — строгое
*   **Равенство:** `A = B` ⟺ `A ⊆ B ∧ B ⊆ A`

## **2. Операции над множествами**
*   **Объединение:** `A ∪ B = {x : x ∈ A ∨ x ∈ B}`
*   **Пересечение:** `A ∩ B = {x : x ∈ A ∧ x ∈ B}`
*   **Разность:** `A \ B = {x : x ∈ A ∧ x ∉ B}`
*   **Дополнение:** `Ā = U \ A` (относительно универсума `U`)
*   **Симметрическая разность:** `A △ B = (A \ B) ∪ (B \ A) = (A ∪ B) \ (A ∩ B)`
*   **Декартово произведение:** `A × B = {(a,b) : a ∈ A, b ∈ B}`; `|A × B| = |A| · |B|`
*   **Тождества:** коммутативность, ассоциативность, дистрибутивность, законы де Моргана, поглощение

## **3. Отношения на множествах**
*   **Бинарное отношение:** `R ⊆ A × A`; задаётся матрицей или списком пар
*   **Свойства:** рефлексивность (`∀a: aRa`), симметричность (`aRb ⟹ bRa`), транзитивность (`aRb ∧ bRc ⟹ aRc`)
*   **Отношение эквивалентности:** рефлексивное + симметричное + транзитивное; классы эквивалентности `A/∼`
*   **Отношение порядка:** рефлексивное + антисимметричное + транзитивное; частичный/линейный порядок
*   **Функция:** отношение, где каждому элементу домена соответствует ровно один образ; биекция — взаимно однозначное отображение

# **B. АЛГЕБРАИЧЕСКИЕ СТРУКТУРЫ**

## **1. Бинарные операции**
*   **Определение:** отображение `*: A × A → A`; запись: `a * b`
*   **Свойства:** ассоциативность (`(a*b)*c = a*(b*c)`), коммутативность (`a*b = b*a`), нейтральный элемент (`e*a = a*e = a`), обратный элемент (`a*a⁻¹ = e`)
*   **Замыкание:** `a * b ∈ A` для всех `a, b ∈ A`

## **2. Группы**
*   **Определение:** множество `G` с бинарной операцией `*`, где выполнены: ассоциативность, нейтральный элемент `e`, для каждого `a` существует `a⁻¹`
*   **Свойства:**唯一 нейтральный элемент;唯一 обратный элемент; `(a*b)⁻¹ = b⁻¹*a⁻¹`; `(aⁿ)⁻¹ = (a⁻¹)ⁿ`
*   **Абелева (коммутативная) группа:** `a*b = b*a` для всех `a,b`
*   **Примеры:** `ℤ` (сложение), `ℤₙ` (сложение по модулю `n`), `Sₙ` (композиция перестановок), `GL(n, K)` (умножение невырожденных матриц)
*   **Подгруппа:** замкнутое относительно операции подмножество, являющееся группой; теорема Лагранжа: `|H| | |G|`
*   **Порядок элемента:** `ord(a)` = наименьшее `k > 0` такое, что `aᵏ = e`; `ord(a) | |G|` (теорема Лагранжа)

## **3. Кольца**
*   **Определение:** множество `R` с двумя операциями `+` и `·`: `(R, +)` — абелева группа, `(R, ·)` — моноид, дистрибутивность
*   **Свойства:** нейтральный элемент сложения `0`; для каждого `a`: `−a`; `(a+b)·c = a·c + b·c`
*   **Коммутативное кольцо:** `a·b = b·a`
*   **Кольцо с единицей:** существует `1 ≠ 0` такое, что `1·a = a·1 = a`
*   **Делители нуля:** `a ≠ 0, b ≠ 0`, но `a·b = 0`; в области целостности делителей нуля нет
*   **Примеры:** `ℤ`, `ℤₙ`, `K[x]` (кольцо многочленов), `ℤ[i]` (Гауссовы целые)

## **4. Поля**
*   **Определение:** коммутативное кольцо с единицей, где каждый ненулевой элемент имеет обратный
*   **Свойства:** нет делителей нуля; `a ≠ 0, a·b = a·c ⟹ b = c`
*   **Примеры:** `ℚ`, `ℝ`, `ℂ`, `𝔽_p` (остатки по простому `p`), `𝔽_{pᵏ}` (конечные поля)
*   **Характеристика поля:** наименьшее `k > 0` такое, что `k · 1 = 0`; для `𝔽_p` характеристика `= p`

## **5. Группы преобразований**
*   **Симметрическая группа `Sₙ`:** множество всех биекций `{1,...,n} → {1,...,n}` с композицией; `|Sₙ| = n!`
*   **Общая линейная группа `GL(n, K)`:** множество невырожденных матриц `n × n` над полем `K` с умножением; `|GL(n, 𝔽_q)| = (qⁿ − 1)(qⁿ − q)...(qⁿ − qⁿ⁻¹)`
*   **Ортогональная группа `O(n)`:** `AᵀA = I`; сохраняет евклидову норму
*   **Унитарная группа `U(n)`:** `A*A = I` (сопряжение); сохраняет эрмитову норму

# **C. АРИФМЕТИЧЕСКИЕ ОПЕРАЦИИ И ИХ СВОЙСТВА**

## **1. Базовые операции**
*   Сложение: коммутативность, ассоциативность, нейтральный элемент `0`, обратный элемент `−a`
*   Умножение: коммутативность (в коммутативных кольцах), ассоциативность, нейтральный элемент `1`, обратный элемент `a⁻¹` (в полях)
*   Дистрибутивность: `a·(b + c) = a·b + a·c`

## **2. Модулярная арифметика**
*   **Определение:** `a ≡ b (mod n)` ⟺ `n | (a − b)`; классы вычетов `ℤₙ`
*   **Операции:** `(a + b) mod n`, `(a · b) mod n`, `(a − b) mod n`
*   **Обратный элемент:** `a⁻¹ mod n` существует ⟺ `gcd(a, n) = 1`; вычисление через расширенный алгоритм Евклида `O(log n)`
*   **Малая теорема Ферма:** `a^{p−1} ≡ 1 (mod p)` для простого `p` и `gcd(a,p) = 1`
*   **Теорема Эйлера:** `a^{φ(n)} ≡ 1 (mod n)` где `φ(n)` — функция Эйлера
*   **Быстрое возведение в степень:** `a^k mod n` за `O(log k)` умножений

## **3. Свойства вычетов**
*   **Китайская теорема об остатках:** система `x ≡ aᵢ (mod nᵢ)` при попарно взаимно простых `nᵢ` имеет единственное решение по модулю `N = Πnᵢ`
*   **Лемма Гаусса:** `p | a·b ∧ gcd(p,a) = 1 ⟹ p | b` (для простого `p`)
*   **Евклидовоouverность:** `gcd(a,b) = gcd(b, a mod b)`; расширенный: `ax + by = gcd(a,b)`

# **D. КОНЕЧНЫЕ СУММЫ И ПРОИЗВЕДЕНИЯ**

## **1. Символы суммы и произведения**
*   `Σ_{i=m}^{n} aᵢ = aₘ + aₘ₊₁ + ... + aₙ`; свойства: линейность, разбиение диапазона
*   `Π_{i=m}^{n} aᵢ = aₘ · aₘ₊₁ · ... · aₙ`; свойства: коммутативность, ассоциативность

## **2. Ключевые формулы**
*   Арифметическая прогрессия: `Σ_{i=0}^{n−1} (a + di) = n·a + d·n(n−1)/2`
*   Геометрическая прогрессия: `Σ_{i=0}^{n−1} a·rⁱ = a·(rⁿ − 1)/(r − 1)` при `r ≠ 1`
*   Сумма первых `n` натуральных: `n(n+1)/2`
*   Сумма квадратов: `n(n+1)(2n+1)/6`
*   Сумма кубов: `(n(n+1)/2)²`
*   **Бином Ньютона:** `(a+b)ⁿ = Σ_{k=0}^{n} C(n,k) · aᵏ · bⁿ⁻ᵏ`

## **3. Приближённые вычисления**
*   **Ошибка округления:** при вычислении `a ⊕ b` ошибка `≤ ε(a) + ε(b)`
*   **Замена сумм интегралами:** `Σ_{i=a}^{b} f(i) ≈ ∫_{a}^{b} f(x)dx ± O(max|f''|)` (формула Эйлера-Маклорена)
*   **Численное дифференцирование:** `f'(x) ≈ (f(x+h) − f(x−h))/(2h)` с ошибкой `O(h²)`

## **4. Олимпиадные применения**
*   **Принцип включения-исключений:** `|A₁ ∪ ... ∪ Aₙ| = Σ|Aᵢ| − Σ|Aᵢ∩Aⱼ| + ...`; подсчёт через свойства множеств
*   **Число дериваций:** подсчёт отображений с ограничениями через ДП + суммы
*   **Производящие функции:** формальное представление последовательностей через «степени»; `Σ aₙxⁿ`;卷积 ↔ произведение
