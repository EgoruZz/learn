## **B. МАТРИЦЫ И ОПЕРАЦИИ**
> `b/b.md` · `b/b.cpp` · `struct MatrixOperations`

### **1. Определения и типы матриц**
*   Матрица `m × n`; квадратная, диагональная `diag(d₁,...,dₙ)`, единичная `Iₙ`, нулевая, верхнетреугольная, нижнетреугольная
*   **Пространство `ℝⁿ`:** отождествление с матрицами-столбцами высоты `n`

### **2. Операции над матрицами**
*   Сумма: `(A+B)[i][j] = A[i][j] + B[i][j]`; свойства: коммутативность, ассоциативность
*   Умножение на скаляр: `(αA)[i][j] = α · A[i][j]`
*   **Произведение матриц:** `(AB)[i][j] = Σ_k A[i][k] · B[k][j]`; условия: число столбцов `A` = число строк `B`; **некоммутативно** в общем случае
*   **Степень матрицы:** `A⁰ = I`, `Aᵏ = A · Aᵏ⁻¹`; быстрое возведение в степень `O(n³ log k)` через square-and-multiply
*   **Транспонирование:** `(Aᵀ)[i][j] = A[j][i]`; свойства: `(A+B)ᵀ = Aᵀ+Bᵀ`, `(AB)ᵀ = BᵀAᵀ`, `(Aᵀ)ᵀ = A`
*   **След:** `tr(A) = Σᵢ A[i][i]`; свойства: `tr(AB) = tr(BA)`, `tr(A) = Σ λᵢ`
*   **Блочные матрицы:** разбиение на подматрицы; умножение блоков
*   **Кронекеровское произведение:** `A ⊗ B` — блочная матрица; `dim(A⊗B) = dim(A)·dim(B)`

### **3. Элементарные преобразования**
*   Типы: перестановка строк/столбцов, умножение на скаляр ≠ 0, прибавление строки/столбца
*   **Метод Гаусса:** приведение к ступенчатому виду `O(n³)`

## **C. ОПРЕДЕЛИТЕЛИ И ОБЪЁМ СИСТЕМЫ ВЕКТОРОВ**
> `c/c.md` · `c/c.cpp` · `struct Determinants`

### **1. Определение и свойства**
*   **Лапласовское определение:** рекурсивное через миноры; `O(n!)` — экспоненциально
*   **Через перестановки:** `det(A) = Σ_{σ ∈ Sₙ} sign(σ) · Πᵢ A[i][σ(i)]`; `O(n!)`
*   **Свойства:** `det(AB) = det(A)·det(B)`, `det(Aᵀ) = det(A)`, `det(A⁻¹) = 1/det(A)`, `det(αA) = αⁿ det(A)`
*   **Верхнетреугольная матрица:** `det(A) = Πᵢ A[i][i]`

### **2. Вычисление определителей**
*   **Гаусс:** приведение к верхнетреугольному виду `O(n³)`; определитель = произведение диагонали × `(-1)^перестановок`
*   **Рекуррентные соотношения:** для ленточных, циклических матриц — `O(n)` или `O(n²)`

### **3. Миноры и алгебраические дополнения**
*   Минор `M[i][j]` = определитель подматрицы без строки `i` и столбца `j`
*   Алгебраическое дополнение: `A[i][j] = (−1)^{i+j} · M[i][j]`
*   **Формула Лапласа:** `det(A) = Σⱼ A[i][j] · A[i][j]` по строке `i`

### **4. Объём системы векторов**
*   **Ориентированный объём:** `vol(v₁,...,vₙ) = det(v₁|...|vₙ)` (матрица из векторов-столбцов)
*   **Геометрический смысл:** объём параллелепипеда = `|det(A)|`; знак — ориентация
*   **Векторное произведение** (в `ℝ³`): `u × v` — вектор, перпендикулярный обоим; `|u × v|` = площадь параллелограмма
*   **Смешанное произведение:** `(u × v) · w = det(u|v|w)` — объём трёхмерного параллелепипеда
*   **Связь с линейной зависимостью:** `det(v₁,...,vₙ) = 0` ⟺ векторы линейно зависимы

## **D. ОБРАТНЫЕ МАТРИЦЫ И РАНГ**
> `d/d.md` · `d/d.cpp` · `struct InverseAndRank`

### **1. Обратная матрица**
*   `AA⁻¹ = A⁻¹A = I`; существует ⟺ `det(A) ≠ 0`
*   **Нахождение:** через присоединённую матрицу `A*`: `A⁻¹ = A*/det(A)` — `O(n³)`
*   **Метод Гаусса:** `[A | I]` → `[I | A⁻¹]` — `O(n³)`
*   **Свойства:** `(AB)⁻¹ = B⁻¹A⁻¹`, `(Aᵀ)⁻¹ = (A⁻¹)ᵀ`, `det(A⁻¹) = 1/det(A)`

### **2. Полуобратная и псевдообратная матрицы**
*   **Односторонние обратные:** `AA⁻¹ = I` но `A⁻¹A ≠ I` (или наоборот)
*   **Псевдообратная (Мура-Пенроуза):** `A⁺` —唯一的 матрица, решающая задачу МНК; через SVD: `A⁺ = VΣ⁺Uᵀ`

### **3. Ранг матрицы**
*   **Определение:** максимальное число линейно независимых строк (столбцов); `rank(A) = rank(Aᵀ)`
*   **Вычисление:** Гаусс `O(n³)`; ранг = число ненулевых строк ступенчатого вида
*   **Свойства:** `rank(AB) ≤ min(rank(A), rank(B))`; `rank(A) = r ⟺ A` содержит неsingular подматрицу `r × r`
*   **Ранг произведения:** `rank(AB) ≥ rank(A) + rank(B) − n` (неполное ранговое неравенство)

## **E. СИСТЕМЫ ЛИНЕЙНЫХ УРАВНЕНИЙ**
> `e/e.md` · `e/e.cpp` · `struct LinearSystems`

### **1. Матричная запись**
*   `Ax = b` где `A` — матрица `m × n`, `x` — вектор неизвестных, `b` — вектор правых частей
*   **Расширенная матрица:** `[A | b]`

### **2. Методы решения**
*   **Метод Гаусса:** приведение к ступенчатому виду `O(n³)` → параметрическое решение
*   **Правило Крамера:** `xᵢ = det(Aᵢ)/det(A)` при `det(A) ≠ 0`; `O(n³)` для каждого `xᵢ`
*   **Метод обратной матрицы:** `x = A⁻¹b` при невырожденной `A`

### **3. Теория совместности**
*   **Теорема Кронекера-Капелли:** система совместна ⟺ `rank(A) = rank(A|b)`
*   **Однородные системы `Ax = 0`:** всегда имеют тривиальное решение; число свободных переменных = `n − rank(A)`
*   **ФСР:** фундаментальная система решений — базис пространства решений однородной системы
*   **Неоднородные:** общее решение = частное решение + линейная комбинация ФСР

## **F. ЛИНЕЙНЫЕ ПРОСТРАНСТВА, КООРДИНАТЫ И ПРОСТРАНСТВА ПЛОСКОСТЕЙ**
> `f/f.md` · `f/f.cpp` · `struct VectorSpaces`

### **1. Основные понятия**
*   **Линейное пространство:** множество `V` с операциями сложения и умножения на скаляр; аксиомы
*   **Примеры:** `ℝⁿ`, `ℝⁿˣᵐ`, `Pₙ` (многочлены степени ≤ `n`), `C[a,b]`
*   **Подпространство:** замкнутое относительно сложения и умножения на скаляр

### **2. Линейная зависимость и базисы**
*   **Линейная комбинация:** `Σ αᵢvᵢ`; **линейная оболочка** `span(S)`
*   **Линейная зависимость:** `Σ αᵢvᵢ = 0` при не всех `αᵢ = 0`
*   **Базис:** максимальная линейно независимая система; **размерность** `dim(V)` = число элементов
*   **Координаты:**唯一 representation вектора через базис: `v = Σ xᵢeᵢ`
*   **Матрица перехода:** `P` — матрица, переводящая координаты из одного базиса в другой; `det(P) ≠ 0`

### **3. Подпространства**
*   Пересечение и сумма: `dim(U + W) = dim(U) + dim(W) − dim(U ∩ W)`
*   **Прямая сумма:** `U ⊕ W` если `U ∩ W = {0}`

### **4. Аффинные системы координат и пространства**
*   **Аффинное пространство:** сдвиг линейного: `a + V`; точки vs векторы
*   **Скалярное произведение:** `⟨u,v⟩ = Σ uᵢvᵢ`; свойства: симметричность, положительная определённость, неравенство Коши-Буняковского
*   **Евклидово пространство:** `ℝⁿ` со скалярным произведением; длина `|v| = √⟨v,v⟩`, угол `cos φ = ⟨u,v⟩/(|u|·|v|)`
*   **Ортогональность:** `⟨u,v⟩ = 0`; ортогональные системы, теорема о проекции

### **5. Прямая линия и плоскость**
*   **Уравнение прямой:** параметрическое `x = a + t·d` или нормальное `⟨n, x−a⟩ = 0`
*   **Уравнение плоскости:** `⟨n, x⟩ = d` (гиперплоскость в `ℝⁿ`: `Σ nᵢxᵢ = d`)
*   **Полупространство:** `{x : ⟨n, x⟩ ≥ d}`
*   **Совместное расположение:** параллельность, пересечение, совпадение прямых/плоскостей

## **G. ЛИНЕЙНЫЕ ОПЕРАТОРЫ И АЛГЕБРА ОПЕРАТОРОВ**
> `g/g.md` · `g/g.cpp` · `struct LinearOperators`

### **1. Линейные отображения**
*   `f: V → W` линейно: `f(αu + βv) = αf(u) + βf(v)`
*   **Ядро** `ker(f) = {v : f(v) = 0}`, **образ** `im(f) = f(V)`
*   **Теорема о размерности:** `dim(ker(f)) + dim(im(f)) = dim(V)`
*   **Матрица отображения:** `A[i][j] = f(eⱼ)` в координатах базисов

### **2. Линейные операторы**
*   `T: V → V`; матрица в фиксированном базисе
*   **Алгебра операторов:** `Hom(V,V)` — линейное пространство операторов; кольцо (композиция)
*   **Группа невырожденных операторов:** `GL(n)` — все обратимые матрицы

### **3. Связь с матрицами**
*   **Матрица композиции:** `[S∘T] = [S]·[T]`
*   **Замена базиса:** `A' = P⁻¹AP` где `P` — матрица перехода
*   **Эквивалентные матрицы:** `A ~ B` ⟺ `∃P: B = P⁻¹AP` (подобие)
*   **Подобие матриц:** сохраняет характеристический многочлен, след, определитель

## **H. БИЛИНЕЙНЫЕ, КВАДРАТИЧНЫЕ ФОРМЫ И БИЛИНЕЙНО-МЕТРИЧЕСКИЕ ПРОСТРАНСТВА**
> `h/h.md` · `h/h.cpp` · `struct BilinearForms`

### **1. Линейные функционалы и двойственное пространство**
*   Линейный функционал: `f: V → ℝ` линеен; `V*` — двойственное пространство; `dim(V*) = dim(V)`
*   **Двойственный базис:** `eⁱ(vⱼ) = δᵢⱼ`

### **2. Билинейные формы**
*   `B: V × V → ℝ` линейна по каждому аргументу; матрица `B[i][j] = B(eᵢ, eⱼ)`
*   **Симметричные:** `B(u,v) = B(v,u)`; **антисимметричные:** `B(u,v) = −B(v,u)`
*   **Ранг** = ранг матрицы; инвариантен при замене базиса

### **3. Квадратичные формы**
*   `Q(v) = B(v,v)` где `B` — симметричная билинейная форма
*   **Канонический вид:** через симметричные элементарные преобразования
*   **Индексы инерции:** число положительных/отрицательных/нулевых диагональных элементов
*   **Закон инерции (Сильвестр):** индексы инерции не зависят от базиса
*   **Положительно определённая:** `Q(v) > 0` для всех `v ≠ 0` ⟺ все угловые миноры > 0
*   **Критерий Сильвестра:** проверка через знаки ведущих миноров

### **4. Билинейно-метрические пространства**
*   **Матрица Грама:** `G[i][j] = ⟨eᵢ, eⱼ⟩` — матрица скалярных произведений базисных векторов
*   **Определитель Грама:** `det(G) = (объём параллелепипеда)²`; связан с ортогональностью
*   **Гиперповерхности второго порядка:** `xᵀAx + bᵀx + c = 0` — обобщение конических сечений
*   **Конгруэнтность матриц:** `B = PᵀAP` — связь с квадратичными формами

## **I. КОМПЛЕКСНЫЕ ЧИСЛА И МНОГОЧЛЕНЫ**
> `i/i.md` · `i/i.cpp` · `struct ComplexAndPolynomials`

### **1. Комплексные числа**
*   **Алгебраическая форма:** `z = a + bi`, `i² = −1`; `Re(z) = a`, `Im(z) = b`
*   **Сопряжение:** `z̄ = a − bi`; `|z|² = z·z̄ = a² + b²`
*   **Тригонометрическая форма:** `z = r(cos φ + i sin φ)` где `r = |z|`, `φ = arg(z)`
*   **Формула Муавра:** `zⁿ = rⁿ(cos nφ + i sin nφ)`
*   **Извлечение корней:** `ⁿ√z` даёт `n` корней на окружности радиуса `r^{1/n}`

### **2. Многочлены**
*   **Основная теорема алгебры:** многочлен степени `n` имеет ровно `n` корней в `ℂ` (с кратностями)
*   **Теорема Безу:** `(x − a) | P(x)` ⟺ `P(a) = 0`
*   **Деление с остатком:** `P = Q·D + R`, `deg(R) < deg(D)`
*   **Кратность корня:** `a` — корень кратности `k` ⟺ `(x−a)^k | P(x)` но `(x−a)^{k+1} ∤ P(x)`
*   **Интерполяция:** по `n+1` точкам существует唯一 многочлен степени ≤ `n−1`

## **J. ЖОРДАНОВА ФОРМА, ХАРАКТЕРИСТИЧЕСКИЙ МНОГОЧЛЕН И ФУНКЦИИ ОТ МАТРИЦ**
> `j/j.md` · `j/j.cpp` · `struct JordanForm`

### **1. Собственные значения и векторы**
*   `Av = λv` где `λ` — собственное значение, `v ≠ 0` — собственный вектор
*   **Характеристический многочлен:** `P_A(λ) = det(A − λI) = 0`; корни — собственные значения
*   **Собственное подпространство:** `E_λ = ker(A − λI)`; размерность = геометрическая кратность
*   **Теорема Гамильтона-Кэли:** `P_A(A) = 0` — матрица удовлетворяет своему характеристическому многочлену
*   **Минимальный многочлен:** наименьший многочлен `m_A(λ)` такой, что `m_A(A) = 0`; делит `P_A(λ)`

### **2. Диагонализуемость**
*   `A` диагонализуема ⟺ сумма геометрических кратностей = `n` ⟺ существует базис из собственных векторов
*   `A = PDP⁻¹` где `D` — диагональная матрица собственных значений

### **3. Жорданова нормальная форма (ЖНФ)**
*   **Жорданова клетка:** `J_k(λ)` — верхнетреугольная `k × k` с `λ` на диагонали и `1` выше; `J_k(λ) = λI + N` где `N` — нильпотентная матрица с единицами на супердиагонали
*   **ЖНФ:** блочная диагональная матрица из жордановых клеток; единственна с точностью до перестановки блоков
*   **Корневые подпространства:** `K_λ = ker((A − λI)^n)` — вектора `v`, для которых `(A − λI)^k v = 0` при некотором `k`
*   **Размеры жордановых клеток:** определяются через разности размерностей `dim ker(A − λI)^k`; число клеток размера `k` = `rk(A−λI)^{k+1} + rk(A−λI)^{k−1} − 2·rk(A−λI)^k`
*   **Конструкция ЖНФ (общий алгоритм для k×k):** для каждого `λ`: найти характеристический многочлен, корни с кратностями, вычислить `rk(A−λI)^j` для `j = 1..n`, определить размеры клеток; затем построить жорданов базис через фундаментальные цепочки

### **4. Функции от матриц**
*   **Через ЖНФ:** если `A = PJP⁻¹`, то `f(A) = Pf(J)P⁻¹`; `f(J_k(λ))` вычисляется через Taylor
*   **Через минимальный многочлен:** если `m_A(x)` известен — `f(A)` определяется значениями `f` и её производных в корнях
*   **Применение:** решение линейных рекуррентных уравнений: `xₖ₊₁ = Axₖ` → `xₖ = Aᵏx₀`

## **K. ФУНКЦИОНАЛЬНЫЕ МАТРИЦЫ И ВЕКТОРНЫЙ АНАЛИЗ**
> `k/k.md` · `k/k.cpp` · `struct FunctionalMatrices`

### **1. Функциональные матрицы скалярного аргумента**

### **2. Производные матричных функций**
*   `dA/dt` — матрица производных поэлементно
*   Правило произведения: `d(AB)/dt = (dA/dt)B + A(dB/dt)` (порядок важен!)
*   **Производная матричной экспоненты:** `d(e^{At})/dt = Ae^{At}`

### **3. Производные по векторному аргументу**
*   **Градиент:** `∇f(x) = (∂f/∂x₁, ..., ∂f/∂xₙ)`
*   **Якобиан:** `J[i][j] = ∂fᵢ/∂xⱼ` — матрица частных производных
*   **Гессиан:** `H[i][j] = ∂²f/∂xᵢ∂xⱼ` — симметричная матрица вторых производных
*   **Правило цепочки:** `∇(f ∘ g)(x) = J_g(x)ᵀ · ∇f(g(x))`

## **L. НОРМИРОВАННЫЕ ПРОСТРАНСТВА, ВЫЧИСЛИТЕЛЬНЫЕ ПРОЦЕССЫ И МЕТРИЧЕСКИЕ СВОЙСТВА ОПЕРАТОРА**
> `l/l.md` · `l/l.cpp` · `struct NormedSpaces`

### **1. Нормы**
*   **Аксиомы:** `‖x‖ ≥ 0`, `‖x‖ = 0 ⟺ x = 0`, `‖αx‖ = |α|·‖x‖`, `‖x+y‖ ≤ ‖x‖+‖y‖`
*   **Нормы в `ℝⁿ`:** `‖x‖₁ = Σ|xᵢ|`, `‖x‖₂ = √(Σxᵢ²)`, `‖x‖_∞ = max|xᵢ|`, `‖x‖ₚ = (Σ|xᵢ|^p)^{1/p}`
*   **Матричные нормы:** Фробениуса `‖A‖_F = √(Σ aᵢⱼ²)`, спектральная `‖A‖₂ = σ₁`, подчинённые `‖A‖_p`
*   **Эквивалентность норм:** `c‖x‖_a ≤ ‖x‖_b ≤ C‖x‖_a` для конечномерных пространств

### **2. Нормированные пространства и полнота**
*   **Метрика:** `d(x,y) = ‖x − y‖`; сходимость `xₙ → x ⟺ ‖xₙ − x‖ → 0`
*   **Полнота:** каждая фундаментальная последовательность сходится; `ℝⁿ` полно
*   **Сходимость по норме и координатная сходимость:** эквивалентны в конечномерных пространствах
*   **Предел и вычислительные процессы:** сходимость итерационных методов, оценка скорости сходимости

### **3. Метрические свойства операторов**
*   **Непрерывность и ограниченность:** линейный оператор непрерывен ⟺ ограничен ⟺ `‖T‖ < ∞`
*   **Норма оператора:** `‖T‖ = max_{‖x‖=1} ‖Tx‖` — минимальная константа неравенства `‖Tx‖ ≤ C‖x‖`
*   **Матричные нормы оператора:** подчинённая `‖A‖_p = max_{‖x‖_p=1} ‖Ax‖_p`; связь с сингулярными числами
*   **Спектральная норма:** `‖A‖₂ = σ₁` (максимальное сингулярное число); `‖A‖_∞ = max_i Σⱼ |aᵢⱼ|`
*   **Возмущение и невырожденность:** если `‖ΔA‖ < 1/‖A⁻¹‖` → `A + ΔA` невырожденна; оценка `‖(A+ΔA)⁻¹ − A⁻¹‖`
*   **Устойчивое решение уравнений:** относительная ошибка `‖Δx‖/‖x‖ ≤ κ(A) · ‖ΔA‖/‖A‖` где `κ(A) = ‖A‖·‖A⁻¹‖` (обусловленность)
*   **Возмущение и собственные значения:** для нормальных матриц: сдвиг собственных значений `≤ ‖ΔA‖`; для не нормальных — сложнее
*   **Операторные уравнения:** `Tx = b`; existence/uniqueness через `ker(T)` и `im(T)`; связь с полнотой пространств
*   **Псевдорешения и псевдообратный оператор:** `min ‖Tx − b‖` → решение через `A⁺b`; связь с SVD

### **4. Вычислительные процессы**
*   **Ортогонализация Грама-Шмидта:** из базиса → ортонормальный `O(n²m)`
*   **Ортогонализация степенной последовательности:** `1, x, x², ...` → ортогональные многочлены; для приближения функций
*   **Методы сопряжённых направлений:** итерационные для СЛАУ; сходимость за ≤ `n` итераций
*   **Псевдодвойственность:** связь между решениями СЛУ и оптимизационными задачами; сильная и слабая двойственность

## **M. ПРИКЛАДНЫЕ АЛГОРИТМЫ ЛИНЕЙНОЙ АЛГЕБРЫ**
> `m/m.md` · `m/m.cpp` · `struct AppliedLinearAlgebra`

### **1. Матричные разложения**
*   **QR-разложение:** через Грам-Шмидт `O(n³)` или вращения Гивенса
*   **LU-разложение:** приведение Гаусса `O(n³)`; LDLᵀ для симметричных

### **2. Matrix Exponentiation**
*   `A^k` через square-and-multiply `O(n³ log k)`; применение: Фибоначчи `O(log n)`, рекуррентности

### **3. Итерационные методы**
*   **Метод Якоби:** собственные значения через вращения; `O(n³)` на итерацию
*   **Метод простых итераций:** `x⁽ᵏ⁺¹⁾ = Bx⁽ᵏ⁾ + c`; сходимость при `ρ(B) < 1`
*   **Метод Зейделя:** улучшение — использование обновлённых компонент

### **4. Метод наименьших квадратов**
*   `min ‖Ax − b‖₂` при `m > n`; нормальное уравнение `AᵀAx = Aᵀb`; QR-подход стабильнее

### **5. Практические алгоритмы (из оригинала Y/Z)**
*   **Базисы:** `Extract Basis From Vectors`, `Find Any Basis Of Span`, `Complete To Basis With Standard Vectors`, `Find Fundamental System Of Solutions`
*   **Подпространства:** `Subspace Basis From Matrix Equation`, `Subspace Matrix Equation From Span`, `Sum Of Subspaces Given By Spans`, `Intersection Of Subspaces Given By Spans`, `Intersection Of Subspaces Given By Matrix Equations`, `Sum Of Subspaces Given By Matrix Equations`, `Intersection Of Subspaces Mixed Definitions` (2 варианта: базисом и системой), `Sum Of Subspaces Mixed Definitions` (2 варианта: системой и оболочкой)
*   **Отображения:** `Find Change Of Basis Matrix`, `Linear Map Matrix Under Basis Change`, `Check Linear Map Existence On Vectors`, `Find Image And Kernel Basis`, `Find Linear Map With Given Kernel And Image`, `Linear Operator Matrix Under Basis Change`
*   **Проекции:** `Vector Projection Onto Subspace`, `Projection Operator Onto Subspace`
*   **Ортогональные дополнения:** `Right Orthogonal Complement` (правое дополнение через билинейную форму), `Left Orthogonal Complement` (левое дополнение)
*   **Билинейные формы:** `Find Bilinear Form Matrix Under Basis Change`, `Symmetric Gauss` (симметричный алгоритм Гаусса для симметричных билинейных форм), `Jacobi Method For Bilinear Forms` (ортогональная диагонализация симметричных форм)
*   **Собственные значения/ЖНФ:** `Find Eigenvalues And Eigenvectors`, `Find Root Subspaces`, `Find Invariant Subspaces`, `Find Invariant Subspaces For Diagonalizable Operator`, `Check Diagonalizability`, `Check Diagonalizability Over C`, `Determine Jordan Normal Form` (общий алгоритм для k×k через `rk(A−λI)^j`), Jordan Form/Basis для 2×2, 3×3, 4×4 (с одним собственным значением)
*   **Ортогональные операторы:** `Diagonalization Of Unitary Operator` ( A = UDU* ), `Canonical Form Of Orthogonal Operator` (блоки {1, −1, вращение}), `Orthogonal Operator In R³` (ось + угол вращения)
*   **Разложения:** `Symmetric Matrix Decomposition` (A = CΛCᵀ ортогональное), `Singular Value Decomposition (SVD)` (A = UΣVᵀ), `Compact SVD` (усечённая версия SVD)
*   **Шерман-Моррисон:** `(A + uvᵀ)⁻¹ = A⁻¹ − A⁻¹uvᵀA⁻¹ / (1 + vᵀA⁻¹u)` — обновление обратной за `O(n²)`
*   **Работа с матрицами:** `Binary Search Matrix`, `Count Islands In Matrix`, `Spiral Print`, `Rotate Matrix`, `Pascal Triangle`, `Validate Sudoku Board`, `Sherman Morrison Formula`
*   **Машинное обучение:**
    *   **Linear Regression:** `min ‖Xw − y‖₂` → решение через `w = (XᵀX)⁻¹Xᵀy`; МНК для аппроксимации данных
    *   **Logistic Regression:** классификация через `σ(wᵀx) = 1/(1 + e^{-wᵀx})`; градиентный спуск для оптимизации
    *   **Gradient Descent:** итеративная оптимизация: `wₖ₊₁ = wₖ − α∇L(wₖ)`; mini-batch, stochastic variants
    *   **K Means Clustering:** разбиение на `k` кластеров: (1) назначение центров, (2) пересчёт центров; сходимость за `O(nki)` итераций
    *   **K Nearest Neighbours:** классификация по `k` ближайшим соседям; расстояние — Евклидово/Манхэттен/хэмминг
    *   **Principal Component Analysis (PCA):** снижение размерности через собственные значения ковариационной матрицы `C = (1/n)XᵀX`; `k` главных компонент — `k` largest eigenvalues
    *   **Support Vector Machines (SVM):** поиск разделяющей гиперплоскости с максимальным зазором; `min ½‖w‖²` при `yᵢ(wᵀxᵢ + b) ≥ 1`; kernel trick для нелинейных данных
    *   **Decision Tree:** рекурсивное разбиение пространства признаков; критерии: Gini impurity, entropy
    *   **Dimensionality Reduction:** PCA, t-SNE, UMAP — проекция данных в низкоразмерное пространство
    *   **Automatic Differentiation:** вычисление градиентов через цепочку производных (forward/backward mode)
