**L. НОРМИРОВАННЫЕ ПРОСТРАНСТВА, ВЫЧИСЛИТЕЛЬНЫЕ ПРОЦЕССЫ И МЕТРИЧЕСКИЕ СВОЙСТВА ОПЕРАТОРА**

> **Архитектура:** `NormedSpaces` (l.cpp) — наследует `FunctionalMatrices` (k.cpp). Реализует: нормы векторов и матриц, метрику, сходимость, норму оператора, вариационные свойства собственных значений, ортогонализацию Грама-Шмидта. Все методы параметризованы и работают через `double`.
>
> **Связи:** собственные значения — `j` (для вариационных свойств); матричные операции — `b` (умножение); нормы — связь с квадратичными формами (`h`); численные методы — следующий раздел (m).

---

# **A. НОРМЫ**

## **1. Определение и аксиомы**
*   **Норма:** отображение `‖·‖: V → ℝ` такое, что `‖x‖ ≥ 0`, `‖x‖ = 0 ⟺ x = 0`, `‖αx‖ = |α|·‖x‖`, `‖x+y‖ ≤ ‖x‖+‖y‖` (неравенство треугольника)

## **2. Нормы в ℝⁿ**
*   **L₁:** `‖x‖₁ = Σ|xᵢ|` — манхэттенская норма
*   **L₂:** `‖x‖₂ = √(Σxᵢ²)` — евклидова норма
*   **L∞:** `‖x‖_∞ = max|xᵢ|`
*   **Lₚ:** `‖x‖ₚ = (Σ|xᵢ|^p)^{1/p}`

## **3. Матричные нормы**
*   **Фробениуса:** `‖A‖_F = √(Σ aᵢⱼ²)`
*   **Спектральная:** `‖A‖₂ = σ₁` (максимальное сингулярное число)
*   **Подчинённая:** `‖A‖_p = max_{‖x‖_p=1} ‖Ax‖_p`

## **4. Эквивалентность норм**
*   В конечномерных пространствах: `c‖x‖_a ≤ ‖x‖_b ≤ C‖x‖_a` для некоторых `c, C > 0`

---

# **B. МЕТРИКА И СХОДИМОСТЬ**

## **1. Метрика**
*   `d(x,y) = ‖x − y‖`; свойства: неотрицательность, симметричность, неравенство треугольника

## **2. Сходимость**
*   `xₙ → x ⟺ ‖xₙ − x‖ → 0`
*   **Фундаментальная последовательность:** для всех `ε > 0` существует `N` такое, что `‖xₙ − xₘ‖ < ε` при `n,m > N`

## **3. Полнота**
*   Нормированное пространство, в котором каждая фундаментальная последовательность сходится; `ℝⁿ` полно

---

# **C. ЛИНЕЙНЫЕ ОПЕРАТОРЫ В НОРМИРОВАННЫХ ПРОСТРАНСТВАХ**

## **1. Норма оператора**
*   `‖T‖ = max_{‖x‖=1} ‖Tx‖`; связан с сингулярными числами

## **2. Спектральная норма**
*   `‖A‖₂ = σ₁` (максимальное сингулярное число)

## **3. Возмущение и устойчивость**
*   **Обусловленность:** `κ(A) = ‖A‖·‖A⁻¹‖`; большая обусловленность → чувствительность к возмущениям
*   **Оценка:** `‖Δx‖/‖x‖ ≤ κ(A)·‖ΔA‖/‖A‖`

---

# **D. ВЫЧИСЛИТЕЛЬНЫЕ ПРОЦЕССЫ**

## **1. Ортогонализация Грама-Шмидта**
*   Из базиса `v₁,...,vₙ` → ортонормальный `e₁,...,eₙ`
*   **Алгоритм:** `u₁ = v₁`; `uₖ = vₖ − Σ_{j=1}^{k−1} proj_{uⱼ}(vₖ)`; `eₖ = uₖ/‖uₖ‖`
*   **Сложность:** `O(n²m)` для `n` векторов размера `m`

## **2. Методы сопряжённых направлений**
*   Для СЛАУ `Ax = b` ( `A` симметричная положительно определённая)
*   Сходимость за ≤ `n` итераций (без округления); на практике быстрее
