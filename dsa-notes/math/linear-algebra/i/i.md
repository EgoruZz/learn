**I. КОМПЛЕКСНЫЕ ЧИСЛА И МНОГОЧЛЕНЫ**

> **Архитектура:** `ComplexAndPolynomials` (i.cpp) — наследует `BilinearForms` (h.cpp). Реализует: комплексные числа (алгебраическая/тригонометрическая форма, Муавра, корни), многочлены (деление, теорема Безу, интерполяция). Все методы параметризованы и работают через `double`.
>
> **Связи:** определители — `c` (для разложения многочленов); обратные матрицы — `d`; геометрия — `geometry.md` (для интерпретации комплексных чисел как поворотов/масштабирований).

# **A. КОМПЛЕКСНЫЕ ЧИСЛА**

## **1. Алгебраическая форма**
*   `z = a + bi`, `i² = −1`; `Re(z) = a`, `Im(z) = b`
*   **Сопряжение:** `z̄ = a − bi`; `|z|² = z·z̄ = a² + b²`
*   **Сложение:** `(a+bi) + (c+di) = (a+c) + (b+d)i`

## **2. Тригонометрическая форма**
*   `z = r(cos φ + i sin φ)` где `r = |z|`, `φ = arg(z)`
*   **Умножение:** `z₁z₂ = r₁r₂(cos(φ₁+φ₂) + i sin(φ₁+φ₂))` — умножение модулей, сложение аргументов

## **3. Формула Муавра**
*   `zⁿ = rⁿ(cos nφ + i sin nφ)`
*   **Извлечение корней:** `ⁿ√z` даёт `n` корней: `r^{1/n}(cos((φ+2πk)/n) + i sin((φ+2πk)/n))` для `k = 0,...,n−1`

# **B. МНОГОЧЛЕНЫ**

## **1. Основная теорема алгебры**
*   Многочлен степени `n` имеет ровно `n` корней в `ℂ` (с учётом кратностей)

## **2. Теорема Безу**
*   `(x − a) | P(x)` ⟺ `P(a) = 0`

## **3. Деление с остатком**
*   `P(x) = Q(x)·(x − a) + R` где `R = P(a)`
*   **Схема Горнера:** вычисление `P(a)` за `O(n)` через `bₙ = aₙ; bₖ = aₖ + a·bₖ₊₁`

## **4. Интерполяция**
*   По `n+1` точкам существует唯一 многочлен степени ≤ `n−1`
*   **Формула Лагранжа:** `P(x) = Σ yᵢ · Π_{j≠i} (x−xⱼ)/(xᵢ−xⱼ)` — `O(n²)`
