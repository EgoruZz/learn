**E. СИСТЕМЫ ЛИНЕЙНЫХ УРАВНЕНИЙ**

> **Архитектура:** `LinearSystems` (e.cpp) — наследует `InverseAndRank` (d.cpp). Реализует: решение СЛУ методом Гаусса, правило Крамера, метод обратной матрицы, проверку совместности (Кронекер-Капелли), ФСР однородных систем, параметрическое решение. Все методы параметризованы размером `n × n` и работают через `double` (для дробных решений).
>
> **Связи:** обратные матрицы — `d` (для `x = A⁻¹b`); ранг — `d` (для Кронекера-Капелли); определители — `c` (для Крамера); матричные операции — `b` (умножение); линейные пространства — `f` (ФСР как базис подпространства решений).

---

# **A. МАТРИЧНАЯ ЗАПИСЬ СИСТЕМ**

## **1. Основные понятия**
*   **Система:** `a₁₁x₁ + ... + a₁ₙxₙ = b₁`, ..., `aₘ₁x₁ + ... + aₘₙxₙ = bₘ`
*   **Матричная запись:** `Ax = b` где `A ∈ ℝ^{m×n}`, `x ∈ ℝⁿ`, `b ∈ ℝᵐ`
*   **Расширенная матрица:** `[A | b]` — матрица `m × (n+1)`

## **2. Совместные и несовместные системы**
*   **Совместная:** существует хотя бы одно решение
*   **Единственное решение:** `rank(A) = rank(A|b) = n`
*   **Бесконечно много решений:** `rank(A) = rank(A|b) < n`
*   **Несовместная:** `rank(A) ≠ rank(A|b)`

---

# **B. МЕТОДЫ РЕШЕНИЯ**

## **1. Метод Гаусса**
*   Приведение `[A|b]` к ступенчатому виду → параметрическое решение
*   **Сложность:** `O(mn²)` для `m × n` системы; `O(n³)` для квадратных

## **2. Правило Крамера**
*   При `det(A) ≠ 0`: `xᵢ = det(Aᵢ)/det(A)` где `Aᵢ` — матрица `A` с заменённым `i`-м столбцом на `b`
*   **Сложность:** `O(n³)` для каждого `xᵢ` (вычисление `det`); `O(n³)` суммарно через LU

## **3. Метод обратной матрицы**
*   `x = A⁻¹b` при невырожденной `A`
*   **Сложность:** `O(n³)` (обратная через Гаусс) + `O(n²)` (умножение)

---

# **C. ТЕОРИЯ СИСТЕМ**

## **1. Теорема Кронекера-Капелли**
*   Система совместна ⟺ `rank(A) = rank(A|b)`
*   **Единственное решение:** `rank(A) = rank(A|b) = n`
*   **Бесконечное число решений:** `rank(A) = rank(A|b) = r < n`; число свободных переменных = `n − r`

## **2. Однородные системы `Ax = 0`**
*   Всегда имеют тривиальное решение `x = 0`
*   **Нетривиальное решение** существует ⟺ `rank(A) < n`
*   **ФСР (фундаментальная система решений):** базис пространства решений; `dim(ker(A)) = n − rank(A)`
*   **Общее решение:** `x = α₁u₁ + ... + α_{n−r}uₙ₋ᵣ` где `uᵢ` — ФСР

## **3. Неоднородные системы `Ax = b`**
*   **Общее решение:** `x = x₀ + α₁u₁ + ... + α_{n−r}uₙ₋ᵣ` где `x₀` — частное решение, `uᵢ` — ФСР однородной системы
*   **Связь:** если `x₁` и `x₂` — два решения, то `x₁ − x₂` — решение однородной системы
