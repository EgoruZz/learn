**H. ЛИНЕЙНЫЕ, БИЛИНЕЙНЫЕ И КВАДРАТИЧНЫЕ ФОРМЫ**

> **Архитектура:** `BilinearForms` (h.cpp) — наследует `LinearOperators` (g.cpp). Реализует: билинейные формы (матрица, ранг, симметризация), квадратичные формы (канонический вид, индексы инерции, закон инерции Сильвестра, положительная определённость, критерий Сильвестра), двойственное пространство. Все методы параметризованы размером `n` и работают через `double`.
>
> **Связи:** определители — `c` (для критерия Сильвестра); обратные матрицы — `d` (для диагонализации); линейные операторы — `g` (связь форм и операторов); собственные значения — раздел J (спектральный анализ); нормы — раздел L (связь с квадратичными формами).

---

# **A. ЛИНЕЙНЫЕ ФУНКЦИОНАЛЫ И ДВОЙСТВЕННОЕ ПРОСТРАНСТВО**

## **1. Линейный функционал**
*   `f: V → ℝ` линеен: `f(αu + βv) = αf(u) + βf(v)`
*   **Двойственное пространство:** `V* = {все линейные функционалы на V}`; `dim(V*) = dim(V)`
*   **Двойственный базис:** `eⁱ(vⱼ) = δᵢⱼ` —唯一 определённый функционал

---

# **B. БИЛИНЕЙНЫЕ ФОРМЫ**

## **1. Определение**
*   `B: V × V → ℝ` линейна по каждому аргументу: `B(αu + βv, w) = αB(u,w) + βB(v,w)`
*   **Матрица:** `B[i][j] = B(eᵢ, eⱼ)` — матрица формы в базисе

## **2. Типы**
*   **Симметричная:** `B(u,v) = B(v,u)` ⟺ `B = Bᵀ`
*   **Антисимметричная:** `B(u,v) = −B(v,u)` ⟺ `B = −Bᵀ`
*   **Ранг:** ранг матрицы формы; инвариантен при замене базиса

## **3. Симметричная билинейная форма**
*   **Диагонализация:** через симметричные элементарные преобразования → канонический вид
*   **Угловые миноры:** `Δₖ = det(B[1..k, 1..k])` — знаки определяют индексы инерции

---

# **C. КВАДРАТИЧНЫЕ ФОРМЫ**

## **1. Определение**
*   `Q(v) = B(v,v)` где `B` — симметричная билинейная форма
*   **Матрица:** `Q(x) = xᵀAx` где `A` — симметричная матрица

## **2. Канонический вид**
*   Через симметричные элементарные преобразования → диагональная матрица
*   **Нормальный вид над ℝ:** `Q(x) = x₁² + ... + xₚ² − xₚ₊₁² − ... − xₚ₊ₖ²`
*   **Индексы инерции:** `p` (положительных), `k` (отрицательных), `n−p−k` (нулевых)
*   **Закон инерции (Сильвестр):** индексы инерции не зависят от базиса

## **3. Классификация**
*   **Положительно определённая:** `Q(v) > 0` для всех `v ≠ 0` ⟺ все `λᵢ > 0` ⟺ все угловые миноры `> 0`
*   **Неотрицательно определённая:** `Q(v) ≥ 0` для всех `v`
*   **Отрицательно определённая:** `Q(v) < 0` для всех `v ≠ 0`
*   **Иndefinitная:** принимает и положительные, и отрицательные значения

## **4. Критерий Сильвестра**
*   `Q` положительно определена ⟺ все ведущие миноры `> 0`
*   `Q` неотрицательно определена ⟺ все главные миноры `≥ 0`

---

# **D. ГРАММАТРИЦА И ОПРЕДЕЛИТЕЛЬ ГРАМА**

*   **Матрица Грама:** `G[i][j] = ⟨vᵢ, vⱼ⟩` для системы векторов `{v₁,...,vₖ}`
*   **Определитель Грама:** `det(G) = (объём параллелепипеда)²`
*   **Связь с линейной зависимостью:** `det(G) = 0` ⟺ векторы линейно зависимы
