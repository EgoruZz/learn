**C. КОМБИНАТОРИКА РАЦИОНАЛЬНЫХ ЧИСЕЛ**

> **Архитектура:** `RationalCombinatorics` (c.cpp) — базовый класс, наследует `Combinatorics` (a.cpp). Дроби — пары (числитель, знаменатель); все сравнения — перекрёстным умножением в `__int128` (в int64 переполняется уже при ~1e9). Из базы переиспользуем только include-механику; по наследству доступны `egcd`, `modinv`, `powmod` (number-theory b.cpp). Уровни дерева Штерна-Броко — `stern_brocot_level` (special-sequences, раздел M); здесь — поиск в дереве, приближения, ряд Фарея, цепные дроби.

# **A. ДЕРЕВО ШТЕРНА-БРОКО**

## **1. Построение и свойства**

### **1.1. Медианта**
* **Определение:** медианта дробей a/b и c/d — дробь (a + c)/(b + d)
* **Свойство:** при a/b < c/d и bc − ad = 1 медианта лежит строго между ними: (a+c)/(b+d) − a/b = (bc − ad)/(b·(b+d)) > 0; знаменатель медианты = сумма знаменателей
* **Почему важно:** из bc − ad = 1 (соседство) медианта несократима (НОД(a + c, b + d) = 1) — «первая» дробь между соседями (лемма Фарея, B.2.2)
* **Реализация:** `mediant`

### **1.2. Дерево Штерна-Броко**
* **Построение:** начинаем с интервала (0/1, 1/0); дробь в узле — медианта границ интервала; левый сын — медианта с левой границей, правый — с правой
* **Теорема:** каждая положительная рациональная дробь встречается в дереве ровно один раз
* **Почему единственность:** значение дроби всегда лежит между границами; спуск по сравнению с медиантой однозначно направляет к ней, и знаменатели при этом строго растут (алгоритм поиска, A.2.1)
* **Уровни:** уровень d содержит ровно 2^d дробей; 1/1 — корень; границы 0/1 и 1/0 — «маркеры», не узлы
* **Взаимная простота:** у любой дроби дерева НОД(числитель, знаменатель) = 1 (все узлы — медианты соседних пар)
* **Матрицы (продвинуто):** пара границ (a/b, c/d) — матрица [[a, c], [b, d]] с определителем ±1 (SL(2, Z)); шаг L/R — умножение на матрицу сдвига

### **1.3. Свойство соседства bc − ad = 1**
* **Теорема:** любые соседние дроби в дереве (и в ряде Фарея, раздел B) связаны равенством bc − ad = ±1
* **Следствия:** медианта соседей несократима; ни одна дробь между соседями не имеет знаменателя < b + d (лемма Фарея, B.2.2) — на этом построены все алгоритмы приближения (A.3.1)

## **2. Алгоритмы обхода и поиска**

### **2.1. Поиск дроби: путь L/R — sb_search**
* **Задача:** дана дробь a/b; найти её путь от корня (строка из L/R) — «позиция в дереве»
* **Алгоритм:** границы lo = 0/1, hi = 1/0; пока медианта m ≠ x: если x < m → шаг «L», hi = m; иначе шаг «R», lo = m
* **Корректность:** x всегда между границами (инвариант lo < x < hi), интервал сужается; знаменатель медианты строго растёт ⟹ конечность
* **Сложность:** O(глубина), глубина ≤ a + b; худший случай — дроби с цепной дробью из единиц (отношения чисел Фибоначчи, A.2.4): глубина ~ log_φ(a + b)
* **Вход:** дробь обязана быть несократимой (в дереве живут только взаимно простые) — в коде вход нормализуется
* **Пример:** 2/5 → «LLR»; 3/4 → «LRR»; 1/1 → «» (корень)
* **Реализация:** `sb_search`

### **2.2. Дробь по пути — sb_fraction**
* **Обратная операция:** по строке L/R восстанавливаем дробь: «L» → hi = медианта(lo, hi), «R» → lo = медианта(lo, hi); ответ — медианта границ
* **Пример:** «LLR» → 2/5
* **Реализация:** `sb_fraction`

### **2.3. Обход дерева — sb_bfs**
* **BFS по уровням:** `sb_bfs(d)` — все дроби глубины ≤ d в порядке уровней
* **Отдельные уровни:** `stern_brocot_level(d)` — ровно 2^d дробей уровня d; реализация здесь (A.2.3), special-sequences (раздел M) переиспользует её как факт
* **Инфиксный обход:** даёт все положительные дроби в порядке возрастания — связь с рядом Фарея (B.3)

### **2.4. Связь с цепными дробями**
* **Факт:** путь дроби — «кодировка» её цепной дроби: для x ∈ (0, 1), x = [0; a₁, a₂, ..., aₖ] ⟺ путь L^{a₁} R^{a₂} L^{a₃} ... (серии чередуются, последняя на 1 короче)
* **Пример:** 2/5 = [0; 2, 2] → L²R¹ = «LLR» ✓; 3/5 = [0; 1, 1, 2] → «LRL»; 1/3 = [0; 3] → «LL»
* **Глубина и Фибоначчи:** дроби F_{k+1}/F_k (1/1, 2/1, 3/2, 5/3, 8/5, ...) имеют максимальную глубину ≈ log_φ — худший случай поиска и цепных дробей

## **3. Рациональные приближения**

### **3.1. Ближайшая дробь с ограниченным знаменателем — best_rational_approx**
* **Задача:** дано x = p/q; найти a/b, b ≤ N, минимизирующее |x − a/b| — классика олимпиад и вычислений
* **Алгоритм:** та же прогулка по медиантам; останавливаемся, когда знаменатель медианты > N; ответ — ближайшая из двух границ
* **Корректность:** остановившись, границы — соседние дроби ряда Фарея F_N (B.2.1): между ними нет дробей со знаменателем ≤ N (лемма Фарея) ⟹ лучшая возможная дробь — одна из границ (не медианта — она уже вышла за N)
* **При равенстве расстояний** возвращаем дробь с меньшим знаменателем (обычно нижнюю)
* **Сложность:** шагов ≤ N (худший случай — x = 1/N), на практике O(log N) (знаменатели растут как Фибоначчи)
* **Пример:** π = 355/113: N = 100 → 311/99 (ошибка 1.8·10⁻⁴; 22/7 хуже в 7 раз!); N = 1000 → 355/113 (точно)
* **Реализация:** `best_rational_approx`

### **3.2. Цепные дроби и подходящие дроби — cf_expand, cf_convergents**
* **Определение:** x = [a₀; a₁, a₂, ...] — цепная дробь; подходящие дроби pₖ/qₖ по рекуррентности pₖ = aₖ·pₖ₋₁ + pₖ₋₂, qₖ = aₖ·qₖ₋₁ + qₖ₋₂ (p₋₁ = 1, q₋₁ = 0)
* **Алгоритм:** цепная дробь = расширенный Евклид — тот же инструмент, что `egcd` (number-theory b.cpp, F.1)
* **Теорема Лежандра:** если |x − a/b| < 1/(2b²), то a/b — подходящая дробь x; обратно: подходящие дроби — локально наилучшие приближения (ошибка < 1/qₖ²)
* **Представление не единственно:** [a₀; a₁, ..., aₖ] = [a₀; a₁, ..., aₖ − 1, 1] при aₖ > 1; `cf_expand` возвращает канонический вид (без хвоста из 1)
* **Пример:** 355/113 = [3; 7, 15, 1] = [3; 7, 16] → подходящие 3/1, 22/7, 355/113
* **Реализация:** `cf_expand`, `cf_convergents`

### **3.3. Дробь с минимальным знаменателем в интервале — min_denominator_in_interval**
* **Задача (классика олимпиад):** даны a/b < c/d; найти несократимую p/q ∈ (a/b, c/d) с минимальным q
* **Наивная медианта — не всегда ответ:** (1/5, 2/5): медианта 3/10, но 1/3 лучше (знаменатель 3)
* **Алгоритм:** медиантный спуск от (0/1, 1/0): m = медианта границ; если m строго внутри интервала — ответ; если m ≤ a/b → левая граница = m, иначе правая = m
* **Корректность:** спуск идёт по общим предкам всех дробей интервала (каждая дробь внутри — в поддереве текущей медианты), а вдоль пути знаменатели строго растут ⟹ первый узел, попавший внутрь, имеет минимальный знаменатель
* **Сложность:** O(шагов), шаги ≤ a + c, на практике логарифм
* **Примеры:** (1/3, 1/2) → 2/5; (1/5, 2/5) → 1/3; (2/5, 3/7) → 5/12; (3/10, 1/3) → 4/13
* **Реализация:** `min_denominator_in_interval`

# **B. РЯД ФАРЕЯ**

## **1. Определение и построение**

### **1.1. Определение**
* **Определение:** F_n — все несократимые дроби a/b ∈ [0, 1], 0 ≤ a ≤ b ≤ n, по возрастанию
* **Пример:** F₅ = 0/1, 1/5, 1/4, 1/3, 2/5, 1/2, 3/5, 2/3, 3/4, 4/5, 1/1
* **Свойство:** F_n ⊂ F_{n+1}; новые дроби всегда вставляются между соседями (2.2)

### **1.2. Длина ряда**
* **Формула:** |F_n| = 1 + Σ_{k=1..n} φ(k) — для каждого знаменателя k ровно φ(k) числителей (взаимно простые с k)
* **Сложность:** решето φ за O(n log log n); |F_n| ~ 3n²/π² — считать в long long
* **Олимпиадная задача:** «сколько несократимых дробей со знаменателем ≤ n» = farey_count(n) − 1 (без 0/1) или − 2 (без 0/1 и 1/1)
* **Связь:** φ-функция — `fi_single` (number-theory); решето удобнее для всего массива
* **Реализация:** `phi_sieve`, `farey_count`

### **1.3. Построение по соседям**
* **Формула:** если a/b < c/d соседние в F_n (bc − ad = 1), следующая дробь e/f = (k·c − a)/(k·d − b), k = ⌊(n + b)/d⌋
* **Почему:** из bc − ad = 1 и ограничения f ≤ n условие даёт ровно один k; k·c − a и k·d − b — целые (следствие определителя 1)
* **Сложность:** O(|F_n|) времени и памяти
* **Реализация:** `farey_build`, `farey_successor`

## **2. Свойства соседних дробей**

### **2.1. Соседи: bc − ad = 1**
* **Теорема:** у соседних дробей F_n определитель bc − ad = 1
* **Следствие:** проверка «соседи или нет» = проверка определителя; по паре соседей строится весь ряд (1.3)

### **2.2. Медианта и вставка (теорема Фарея)**
* **Теорема:** если a/b < c/d соседние в F_n, то любая дробь между ними имеет знаменатель ≥ b + d; медианта (a + c)/(b + d) — первая, появляющаяся между ними
* **Следствие:** F_{n+1} получается из F_n вставкой медиант всех пар соседей с b + d = n + 1
* **Пример:** F₄ → F₅: вставляются 1/5 (медианта 0/1 и 1/4), 2/5 (1/3 и 1/2), 3/5 (1/2 и 2/3), 4/5 (3/4 и 1/1)
* **Почему важно:** вставки — только медианты ⟹ формула построения (1.3) корректна

### **2.3. Следующая дробь — farey_successor**
* **Задача:** в F_n найти дробь, следующую за c/d (зная предыдущую a/b)
* **Формула:** та же, что в 1.3: k = ⌊(n + b)/d⌋; следующая = (k·c − a)/(k·d − b)
* **Пример:** в F₇ после 2/5 (за 1/3) идёт 3/7: k = ⌊(7 + 3)/5⌋ = 2 → (2·2 − 1)/(2·5 − 3) = 3/7

## **3. Связь с деревом Штерна-Броко**
* **Срез дерева:** F_n = все дроби дерева Штерна-Броко со знаменателем ≤ n, выписанные по возрастанию
* **Почему:** инфиксный обход дерева — все положительные дроби по возрастанию (A.2.3), а вдоль путей знаменатели растут
* **Единый механизм:** и дерево, и ряд построены на медиантах и свойстве bc − ad = 1; алгоритмы переносятся: best_rational_approx — это поиск соседей в F_N (A.3.1), min_denominator_in_interval — тот же спуск по дереву (A.3.3)
* **Практика:** Фарей удобен, когда нужен «массив» дробей (индексация, обход, задачи на соседство); дерево — когда нужен спуск без построения ряда

# **C. ПРИМЕНЕНИЯ**

## **1. Приближение иррациональных чисел**
* **Инструменты:** подходящие дроби цепной дроби (A.3.2) и спуск Штерна-Броко (A.3.1) — одно и то же: подходящие дроби = узлы на пути числа
* **Теорема Лежандра:** |x − a/b| < 1/(2b²) ⟹ a/b — подходящая дробь; ошибка подходящих < 1/qₖ² — «наилучшие» приближения
* **Алгоритм:** последняя подходящая дробь с q ≤ N; но для N между подходящими выигрывают полуподходящие дроби (их даёт best_rational_approx без цепной дроби)
* **Пример:** π = [3; 7, 15, 1, 292, ...]: 3/1, 22/7, 355/113 (ошибка ≈ 2.7·10⁻⁷ < 1/113²); √2 = [1; 2, 2, ...]: 3/2, 7/5, 17/12, 41/29, 99/70 (ошибка ≈ 7·10⁻⁵)
* **Полуподходящие:** при N = 100 для π лучшая дробь 311/99 — не подходящая, а полуподходящая между 22/7 и 333/106 — спуск Штерна-Броко находит её автоматически

## **2. Задачи оптимального поиска**
* **Задача 1:** ближайшая дробь к x со знаменателем ≤ N → `best_rational_approx` (A.3.1)
* **Задача 2:** дробь с минимальным знаменателем в (a/b, c/d) → `min_denominator_in_interval` (A.3.3)
* **Задача 3:** положение дроби в дереве, следующая дробь ряда → `sb_search` (A.2.1), `farey_successor` (B.2.3)
* **Задача 4:** число несократимых дробей со знаменателем ≤ n → `farey_count` (B.1.2)
* **Общая идея:** все задачи — «прогулка по медиантам» (двоичный поиск по бесконечной структуре): сложность пропорциональна сумме частичных знаменателей цепной дроби ответа — на практике логарифмическая
