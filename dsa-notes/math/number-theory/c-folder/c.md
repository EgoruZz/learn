# **A. ДЕЛИМОСТЬ ЧЕРЕЗ СУММУ ЦИФР**

## **1. Общее правило**
* **Фундаментальное наблюдение:** для произвольного основания b и произвольного делителя m:
  если `b ≡ r (mod m)`, то `b^k ≡ r^k (mod m)` для любого k ≥ 0
* **Доказательство:** b ≡ r (mod m) → b^k ≡ r^k (mod m) (по свойству степеней по модулю)
* **Следствие:** для числа n = aₖbᵏ + aₖ₋₁bᵏ⁻¹ + ... + a₁b + a₀:
  `n mod m = (a₀·r⁰ + a₁·r¹ + a₂·r² + ... + aₖ·rᵏ) mod m`
  = `(a₀ + a₁·r + a₂·r² + ... + aₖ·rᵏ) mod m`
* **Смысл:** чтобы найти n mod m, достаточно знать r = b mod m, и вычислить взвешенную сумму цифр с весами 1, r, r², r³, ...

## **2. Таблица: b mod m для m от 1 до 2b**
* **Формула:** b mod m = b - m·⌊b/m⌋
* **Таблица (все значения r = b mod m):**

| m | 1 | 2 | 3 | ... | b-2 | b-1 | b | b+1 | b+2 | b+3 | ... | 2b-1 | 2b |
|---|---|---|---|-----|-----|-----|---|-----|-----|-----|-----|------|-----|
| r = b mod m | 0 | b%2 | b%3 | ... | 2 | 1 | 0 | -1 | -2 | -3 | ... | b | 0 |

* **Ключевые случаи:**
  * r = 0 (m | b): n mod m = a₀ mod m (только последняя цифра)
  * r = 1 (m = b-1): n mod m = (a₀ + a₁ + a₂ + ...) mod m (сумма цифр)
  * r = -1 (m = b+1): n mod m = (a₀ - a₁ + a₂ - ...) mod m (чередующаяся сумма)
  * r = 2 (m = b-2): n mod m = (a₀ + 2a₁ + 4a₂ + 8a₃ + ...) mod m
  * r = -2 (m = b+2): n mod m = (a₀ - 2a₁ + 4a₂ - 8a₃ + ...) mod m
  * r = k (m = b-k): n mod m = (a₀ + k·a₁ + k²·a₂ + ...) mod m
  * r = -k (m = b+k): n mod m = (a₀ - k·a₁ + k²·a₂ - ...) mod m

## **3. Доказательство общего правила для m = b + k**
* **Утверждение:** если m = b + k, то b ≡ -k (mod b+k), поэтому:
  `n mod (b+k) = (a₀ - k·a₁ + k²·a₂ - k³·a₃ + ...) mod (b+k)`
* **Доказательство:**
  * b = (b+k) - k ≡ -k (mod b+k)
  * b^k ≡ (-k)^k = (-1)^k · k^k (mod b+k)
  * n = Σ aᵢb^i ≡ Σ aᵢ·(-k)^i = Σ aᵢ·(-1)^i·k^i (mod b+k)
  * Что и требовалось доказать
* **Частные случаи:**
  * k = 1 (m = b+1): b ≡ -1 → n mod (b+1) = (a₀ - a₁ + a₂ - ...) mod (b+1)
  * k = 2 (m = b+2): b ≡ -2 → n mod (b+2) = (a₀ - 2a₁ + 4a₂ - 8a₃ + ...) mod (b+2)
  * k = 3 (m = b+3): b ≡ -3 → n mod (b+3) = (a₀ - 3a₁ + 9a₂ - 27a₃ + ...) mod (b+3)

## **4. Доказательство общего правила для m = b - k**
* **Утверждение:** если m = b - k, то b ≡ k (mod b-k), поэтому:
  `n mod (b-k) = (a₀ + k·a₁ + k²·a₂ + k³·a₃ + ...) mod (b-k)`
* **Доказательство:**
  * b = (b-k) + k ≡ k (mod b-k)
  * b^k ≡ k^k (mod b-k)
  * n = Σ aᵢb^i ≡ Σ aᵢ·k^i (mod b-k)
  * Что и требовалось доказать
* **Частные случаи:**
  * k = 1 (m = b-1): b ≡ 1 → n mod (b-1) = (a₀ + a₁ + a₂ + ...) mod (b-1)
  * k = 2 (m = b-2): b ≡ 2 → n mod (b-2) = (a₀ + 2a₁ + 4a₂ + 8a₃ + ...) mod (b-2)
  * k = 3 (m = b-3): b ≡ 3 → n mod (b-3) = (a₀ + 3a₁ + 9a₂ + 27a₃ + ...) mod (b-3)

## **5. Обобщённая таблица правил**
| Делитель m | r = b mod m | Формула | Веса |
|------------|-------------|---------|------|
| m = b - k | k | n mod m = Σ aᵢ·k^i mod m | 1, k, k², k³, ... |
| m = b + k | -k | n mod m = Σ aᵢ·(-k)^i mod m | 1, -k, k², -k³, ... |
| m = b | 0 | n mod m = a₀ mod m | только a₀ |
| m = 1 | 0 | n mod m = 0 | всё делится на 1 |

## **6. Свойства суммы цифр**
* **S(a + b) ≤ S(a) + S(b):** при сложении перенос уменьшает сумму на (b-1)·(количество переносов)
  * Каждый перенос: сумма цифр уменьшается на (b-1)
  * В base 10: каждый перенос уменьшает сумму на 9
  * В base 2: каждый перенос уменьшает сумму на 1
* **S(a · b) ≤ S(a) · S(b):** слабая оценка, но полезная
* **S(n) ≡ n (mod b-1):** основное свойство (частный случай общего правила при r=1)
* **S(n) ≥ 1 для n ≥ 1:** сумма цифр всегда положительная
* **S(n) ≤ (b-1) · digits_b(n):** максимальная сумма для k-значного числа в base b

# **B. ЦЕЛОЧИСЛЕННЫЙ КОРЕНЬ**

## **1. Зачем нужен целочисленный корень**
* **Задача 1:** Является ли n квадратом? → isqrt(n)² == n
* **Задача 2:** Найти наибольший x: x² ≤ n → isqrt(n)
* **Задача 3:** Факторизация за O(√n) → перебираем делители до isqrt(n)
* **Задача 4:** Проверка на простоту за O(√n) → делители до isqrt(n)

## **2. Метод Ньютона для квадратного корня**
* **Идея:** итеративно приближаемся к √n через формулу:
  `x_{k+1} = (x_k + n / x_k) / 2`
* **Почему работает:** это метод Ньютона для f(x) = x² - n. Ищем корень f(x)=0.
  * f'(x) = 2x → x_{k+1} = x_k - f(x_k)/f'(x_k) = x_k - (x_k²-n)/(2x_k) = (x_k + n/x_k)/2
  * Геометрически: строим касательную к y=x² в точке x_k, она пересекает ось x в x_{k+1}
* **Почему сходится:** если x_k > √n, то n/x_k < √n, и среднее ближе к √n. Если x_k < √n, аналогично.
* **Сходность:** O(log log n) — квадратичная (число правильных цифр удваивается)

## **3. Алгоритм**
* **Псевдокод:**
  ```
  x = n
  пока x * x > n:
      x = (x + n / x) / 2
  return x
  ```
* **Важно:** используем целочисленное деление `n / x` (не вещественное!)
* **Почему `x * x > n` в условии:** чтобы избежать переполнения (x² может не влезть в long long)
* **Корректность:** после выхода из цикла x = ⌊√n⌋ (доказательство через индукцию)

## **4. Метод Ньютона для k-ого корня**
* **Формула:** x_{k+1} = ((k-1) * x_k + n / x_k^{k-1}) / k
* **Почему работает:** метод Ньютона для f(x) = x^k - n
  * f'(x) = k·x^{k-1} → x_{k+1} = x_k - (x_k^k - n)/(k·x_k^{k-1}) = ((k-1)x_k + n/x_k^{k-1})/k
* **Алгоритм:**
  ```
  x = n
  пока power(x, k) > n:
      x = ((k-1) * x + n / power(x, k-1)) / k
  return x
  ```
* **Аккуратность:** проверка power(x, k) ≤ n без переполнения (через последовательное умножение)
* **Сложность:** O(k · log log n)

## **5. Проверка: является ли n квадратом**
* **Способ:** return isqrt_newton(n) * isqrt_newton(n) == n
* **Сложность:** O(log log n)

## **6. Проверка: является ли n k-й степенью**
* **Способ:** return kth_root_newton(n, k)^k == n
* **Сложность:** O(k · log log n)

# **C. МАНИПУЛЯЦИИ С ЦИФРАМИ**

## **1. Извлечение цифры по позиции**
* **Формула:** digit_b(n, k, b) = (n / b^k) % b
  * k = 0 — единицы, k = 1 — "b-ицы", k = 2 — "b²-ки", ...
* **Сложность:** O(log_b n)

## **2. Удаление цифры по позиции**
* **Формула:** remove_digit_b(n, k, b) = (n / b^{k+1}) * b^k + (n % b^k)
* **Сложность:** O(log_b n)

## **3. Вставка цифры по позиции**
* **Формула:** insert_digit_b(n, d, k, b) = (n / b^k) * b^{k+1} + d * b^k + (n % b^k)
* **Сложность:** O(log_b n)

## **4. Реверс числа**
* **Алгоритм:**
  ```
  reverse_b(n, b):
      result = 0
      пока n > 0:
          result = result * b + n % b
          n /= b
      return result
  ```
* **Свойство:** reverse_b(reverse_b(n, b), b) = n (для чисел без ведущих нулей)
* **Сложность:** O(log_b n)

## **5. Количество цифр**
* **Формула:** digits_b(n) = ⌊log_b(n)⌋ + 1 = ⌊ln(n)/ln(b)⌋ + 1
* **Итеративно:** делим на b пока n > 0, считаем деления
* **Сложность:** O(log_b n)

# **D. ЦИФРОВОЙ КОРЕНЬ**

## **1. Определение**
* **Цифровой корень** dr(n) — результат итеративного сложения цифр до однозначного
* **Пример:** 12345 → 15 → 6, dr(12345) = 6

## **2. Формула (произвольная base b)**
* **dr_b(n) = 1 + (n-1) mod (b-1)** для n > 0, dr_b(0) = 0
* **Почему:** n mod (b-1) = sum_digits_b(n) mod (b-1), и dr_b(n) — это "нормализованный" остаток

## **3. Свойства цифрового корня**
* **dr(a + b) = dr(dr(a) + dr(b)):** сумма корней = корень суммы
* **dr(a · b) = dr(dr(a) · dr(b)):** произведение корней = корень произведения
* **dr(dr(n)) = dr(n)):** итеративный процесс сходится за один шаг
* **dr(n) ∈ {1, 2, ..., b-1}** для n > 0 в base b

# **E. ПЕРЕНОСЫ И ИХ ВЛИЯНИЕ НА СУММУ ЦИФР**

## **1. Как перенос уменьшает сумму цифр**
* **Ключевое наблюдение:** при сложении двух цифр a + b = c (с переносом):
  * Без переноса: a + b = c, сумма цифр = c
  * С переносом: a + b = c + b·1 (в base b), сумма цифр = c + 1 (вместо a+b)
  * Разница: (a+b) - (c+1) = (a+b) - (a+b-b+1) = b-1
* **Следствие:** каждый перенос уменьшает сумму цифр на (b-1)
  * В base 10: каждый перенос уменьшает сумму на 9
  * В base 2: каждый перенос уменьшает сумму на 1

## **2. Формула: S(a + b) = S(a) + S(b) - (b-1) · carry_count**
* **Где carry_count:** количество переносов при сложении a + b

## **3. Оценка S(a + b)**
* **Нижняя граница:** S(a + b) ≥ max(S(a), S(b)) (переносы не могут увеличить сумму)
* **Верхняя граница:** S(a + b) ≤ S(a) + S(b) (переносы уменьшают сумму)
