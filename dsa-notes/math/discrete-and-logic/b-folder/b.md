# **A. ЛОГИКА ВЫСКАЗЫВАНИЙ**

## **1. Понятие формальной логики**

### **1.1. Формальная логика**
* **Идея:** отделить форму рассуждения от его содержания: правильность вывода зависит только от формы (структуры), а не от того, о чём идёт речь
* **Определение:** формальная логика — наука о формах мышления — понятиях, суждениях, умозаключениях; изучает, при каких формах умозаключение из истинных посылок всегда даёт истинное заключение
* **Формы мышления:** понятие (объект мысли), суждение (утверждение об объектах), умозаключение (вывод нового суждения из имеющихся)
* **Правильность vs истинность:** правильное умозаключение может дать ложное заключение из ложных посылок; из истинных посылок правильное умозаключение всегда даёт истинное заключение

### **1.2. Логические парадоксы**
* **Определение:** парадокс — рассуждение, которое из, казалось бы, верных посылок по, казалось бы, верным правилам приводит к противоречию
* **Парадокс лжеца:** «это высказывание ложно» — если оно истинно, то оно ложно, и наоборот: самоссылка
* **Парадокс Рассела:** множество R = {x : x ∉ x} — «множество всех множеств, не содержащих себя»: R ∈ R ⟺ R ∉ R (связь с a.md 1.1: не всякое характеристическое свойство задаёт множество)
* **Значение парадоксов:** показывают границы наивных языков и вынуждают строить формальные системы с точными правилами (часть C) — из парадоксов вырастает формальная логика

## **2. Формализация утверждений**

### **2.1. Высказывание**
* **Определение:** высказывание — повествовательное предложение, о котором можно однозначно сказать, истинно оно или ложно
* **Не высказывания:** вопросы, приказы, а также предложения с переменными («x > 5» — истинность зависит от x; такие формы — предикаты, часть B)
* **Требование определённости:** «высказывание» имеет смысл только в рамках контекста (домена, момента времени и т.п.) — одно и то же предложение в разных контекстах — разные высказывания

### **2.2. Простые и составные высказывания**
* **Простые (атомарные):** далее обозначаются переменными высказываний p, q, r (в коде — числа 0, 1, 2, ...)
* **Составные:** строятся из простых связками:
  * ¬ — отрицание («не p»)
  * ∧ — конъюнкция («p и q»)
  * ∨ — дизъюнкция («p или q»)
  * → — импликация («если p, то q»; p — посылка, q — следствие)
  * ↔ — эквивалентность («p тогда и только тогда, когда q»)
* **Таблицы значений связок:** ¬p = 1 − p; p∧q = min(p, q); p∨q = max(p, q); p→q = 0 только при p = 1, q = 0 («из истины следует ложь»); p↔q = 1 при p = q
* **Функциональная полнота:** не все связки обязательны: {¬, ∧}, {¬, ∨}, {¬, →} — полные наборы; A→B ≡ ¬A∨B, A↔B ≡ (A→B)∧(B→A) — пригодится при приведении к нормальным формам (B.6)
* **В программировании:** ¬ = `!`, ∧ = `&&`, ∨ = `||`; → и ↔ в языках нет — выражаются через них

## **3. Язык логики высказываний**

### **3.1. Алфавит и индуктивное определение формулы**
* **Алфавит:** переменные высказываний p₀, p₁, ..., связки ¬, ∧, ∨, →, ↔, скобки ( )
* **Формула** — индуктивное определение:
  * база: переменная — формула;
  * шаги: если F, G — формулы, то ¬F, (F∧G), (F∨G), (F→G), (F↔G) — формулы;
  * ничего другого — не формула
* **Индукция по построению формулы:** главный метод доказательства в логике — утверждение доказывается для базы и для каждого шага (см. 4.2)
* **В коде:** формула — бинарное дерево `Form`: узел-операция с левым и правым поддеревьями, лист — переменная

### **3.2. Приоритеты операций и сокращение скобок**
* **Приоритет (сильнее → слабее):** ¬ > ∧ > ∨ > → > ↔
* **Ассоциативность:** ∧ и ∨ ассоциативны, скобки можно опускать: p∧q∧r
* **Соглашения:** ¬ связывает сильнее всего; p∧q→r читается как (p∧q)→r
* **Проверка корректности записи** — по индуктивному определению 3.1 (парсер формул в программировании)

## **4. Логическое значение высказывания**

### **4.1. Оценка переменных**
* **Оценка (присваивание):** функция val: {p₀, ..., pₙ₋₁} → {0, 1} — приписывает каждой переменной значение истинности
* **Интерпретация:** всего 2ⁿ оценок для n переменных — «все возможные ситуации»

### **4.2. Теорема о вычислении логического значения высказываний**
* **Теорема:** для любой формулы F и любой оценки val существует ровно одно логическое значение F(val) ∈ {0, 1}
* **Доказательство (индукция по построению):**
  * база: переменная — её значение задано оценкой;
  * шаги: ¬F, F∧G, F∨G, F→G, F↔G — значения вычисляются из значений F, G по таблицам связок (2.2) — однозначно
* **Следствие (алгоритмическое):** значение вычисляется за O(|F|) — `eval_form`: обход дерева формулы
* **Связь с a.md:** таблица истинности формулы — это её «вектор значений»; формула — булева функция от n переменных (подробнее в c.md)

### **4.3. Таблица истинности**
* **Определение:** таблица, в которой перечислены все 2ⁿ оценок и значения формулы на них
* **Сложность построения:** O(2ⁿ · |F|) — перебор оценок бинарным счётчиком
* **Классификация формул по таблице:**
  * тавтология (тождественно истинная) — все значения 1;
  * противоречие (тождественно ложная) — все значения 0;
  * выполнимая — есть хотя бы одна оценка со значением 1 (не противоречие)
* **Применение:** проверка тождеств, эквивалентности, следований (5, 6); при n ≤ 20 перебор таблицы практичен

## **5. Алгебра высказываний**
* **Идея:** множество формул с операциями ∧, ∨, ¬ — алгебраическая структура (как алгебра множеств a.md 3 — с той же аксиоматикой)
* **Основные тождества:**
  * двойное отрицание: ¬¬A ≡ A
  * идемпотентность: A∧A ≡ A, A∨A ≡ A
  * коммутативность: A∧B ≡ B∧A, A∨B ≡ B∨A
  * ассоциативность: (A∧B)∧C ≡ A∧(B∧C), (A∨B)∨C ≡ A∨(B∨C)
  * дистрибутивность: A∧(B∨C) ≡ (A∧B)∨(A∧C), A∨(B∧C) ≡ (A∨B)∧(A∨C)
  * законы поглощения: A∧(A∨B) ≡ A, A∨(A∧B) ≡ A
  * законы де Моргана: ¬(A∧B) ≡ ¬A∨¬B, ¬(A∨B) ≡ ¬A∧¬B
  * свойства импликации: A→B ≡ ¬A∨B ≡ ¬B→¬A (контрапозиция), A→(B→C) ≡ (A∧B)→C
  * свойства эквивалентности: A↔B ≡ (A→B)∧(B→A), A↔B ≡ ¬A↔¬B
* **Принцип двойственности:** если в тождестве заменить ∧ ↔ ∨ (и 1 ↔ 0, если есть константы), снова получится тождество — пары тождеств выше двойственны
* **Эквивалентные преобразования:** формулы эквивалентны ⟺ совпадают их таблицы истинности (проверка `forms_equivalent`); цепочки замен по тождествам — способ упрощения
* **Подстановка:** замена переменной формулой сохраняет эквивалентность (теорема о замене): если A ≡ B, то A[F/x] ≡ B[F/x]
* **В программировании:** упрощение логических условий — де Морган как правило трансформации if-условий

## **6. Понятие логического следования**

### **6.1. Определение**
* **Определение:** из множества формул Γ (посылок) логически следует α (Γ ⊨ α), если на всякой оценке, на которой истинны все формулы Γ, истинна и α
* **Пустое Γ:** ⊨ α ⟺ α — тавтология
* **Связь с импликацией:** Γ ⊨ α ⟺ тавтология (∧Γ) → α — при конечном Γ; семантический аналог теоремы о дедукции (см. C.4)
* **Отличие от выводимости:** ⊨ — семантическое (по оценкам), ⊢ — синтаксическое (по правилам, часть C); связь даёт теорема полноты

### **6.2. Проверка**
* Перебор всех 2ⁿ оценок: если найдена оценка, на которой все посылки истинны, а α ложна — следования нет; иначе есть. `logical_consequence`, O(2ⁿ · (|Γ| + |α|))

### **6.3. Классические правила (частные случаи следования)**
* modus ponens: p, p→q ⊨ q
* modus tollens: p→q, ¬q ⊨ ¬p
* гипотетический силлогизм: p→q, q→r ⊨ p→r
* приведение к противоречию: из p и ¬p следует любая формула (ex falso quodlibet — «из лжи следует всё»)

# **B. ЛОГИКА ПРЕДИКАТОВ**

## **1. Понятие предиката в логике**

### **1.1. Высказывательная форма**
* **Идея:** нужно говорить об утверждениях с переменными: «x > 5», «x делится на y» — истинность зависит от значений переменных
* **Определение:** предикат — утверждение (высказывательная форма), содержащее переменные; при подстановке конкретных значений вместо переменных превращается в высказывание
* **Арность:** одноместный P(x), двуместный P(x, y), ..., n-местный P(x₁, ..., xₙ)
* **Область определения:** декартово произведение доменов переменных A₁ × ... × Aₙ (a.md B.1)

### **1.2. Предикат как функция**
* **Определение (экстенсиональное):** n-местный предикат — функция P: A₁×...×Aₙ → {0, 1}, сопоставляющая каждому кортежу значений его истинность
* **Связь с a.md:** предикат — характеристическая функция отношения: R = {(x₁, ..., xₙ) : P(x₁, ..., xₙ) = 1} — отношение и предикат взаимно однозначно задают друг друга (a.md B.8.4: функция — частный случай соответствия)
* **В коде:** таблица истинности предиката — вектор из ∏|Aᵢ| битов; индекс кортежа — позиционный код (a.md B.1)

## **2. Множество истинности предиката**
* **Определение:** множество истинности IP = {(x₁, ..., xₙ) : P(x₁, ..., xₙ) = 1} ⊆ A₁×...×Aₙ
* **Взаимно однозначно:** предикат полностью определяется своим множеством истинности (и наоборот)
* **Связь операций (a.md A.2):** истинность ¬P ↔ дополнение, P∧Q ↔ пересечение, P∨Q ↔ объединение множеств истинности — поэтому свойства операций над множествами переносятся на предикаты
* **В коде:** `pred_truth_set` — перечисление кортежей, на которых таблица равна 1

## **3. Кванторные операции над предикатами**

### **3.1. Кванторы**
* **Квантор общности:** ∀x P(x) — «для всех x верно P(x)»; истина ⟺ IP = вся область определения
* **Квантор существования:** ∃x P(x) — «существует x, для которого верно P(x)»; истина ⟺ IP ≠ ∅
* **Многоместные предикаты:** ∀x P(x, y) — предикат от оставшихся свободных переменных (y): ∀ «пробегает» только по x
* **∀/∃ как обобщения ∧/∨:** для конечной области {a₁, ..., aₙ}: ∀xP(x) ≡ P(a₁)∧...∧P(aₙ), ∃xP(x) ≡ P(a₁)∨...∨P(aₙ)

### **3.2. Связь кванторов с операциями над множествами**
* ∀ — «пересечение по всем значениям», ∃ — «объединение»
* **В коде:** `pred_quantify` — квантор по координате: фиксируем остальные координаты, перебираем значения данной (для ∀ — все равны 1, для ∃ — хотя бы одно равно 1); результат — предикат меньшей арности

### **3.3. Выражение кванторов друг через друга**
* ¬∀x P(x) ≡ ∃x ¬P(x); ¬∃x P(x) ≡ ∀x ¬P(x) — «не для всех» = «существует, что не», «не существует» = «для всех не» (законы де Моргана для кванторов, ср. B.5)
* **Следствие:** любой квантор выражается через другой с отрицанием — базис {¬, ∀} полон

## **4. Формулы логики предикатов**

### **4.1. Алфавит**
* **Термы** — объекты рассмотрения: переменные x, y, z, константы, выражения функций (S(t) — «следующий», t₁+t₂, t₁·t₂)
* **Предикатные буквы** P, Q, ... (с фиксированной арностью), связки ¬, ∧, ∨, →, ↔, кванторы ∀, ∃, скобки
* **Равенство:** в языке часто есть специальный двуместный предикат =

### **4.2. Формулы: индуктивное определение**
* атомарная формула: P(t₁, ..., tₙ), где tᵢ — термы;
* если F, G — формулы, то ¬F, (F∧G), (F∨G), (F→G), (F↔G) — формулы;
* если F — формула, то ∀x F, ∃x F — формулы (x — переменная)
* **В коде:** предикатные буквы с термами представлены атомарными переменными (`Form`-листья); кванторы — узлы 'A'/'E'

### **4.3. Свободные и связанные переменные**
* **Область действия квантора:** подформула, к которой он применён
* **Связанная переменная:** входит в область действия квантора по ней; свободная — не входит ни в одну
* **Аналогия с программированием:** связанная переменная — локальная (параметр цикла), свободная — глобальная
* **Переименование:** связанную переменную можно переименовать, не меняя смысла (альфа-эквивалентность): ∀x P(x) ≡ ∀y P(y); свободную — нельзя
* **Замкнутая формула (предложение):** без свободных переменных — её истинность не зависит от значений переменных
* **В коде:** `free_vars` — маска свободных переменных формулы

### **4.4. Подстановка терма вместо переменной**
* **Подстановка** F[t/x] — замена всех свободных вхождений x в F на терм t
* **Захват переменных:** если в t есть переменная, связанная квантором в F, подстановка «испортит» смысл — например, (∀y P(x,y))[y/x] при наивной замене даёт ∀y P(y,y) — захват
* **Избегание захвата:** переименовать связанную переменную перед подстановкой (в коде — `substitute_free`, переименование в свежую)
* **Важность:** корректная подстановка — основа аксиом ФИП (C.6) и правил вывода

## **5. Законы логики предикатов**
* **Законы, сохраняющиеся:** перенос кванторов через связки одного типа:
  * ∀x(P∧Q) ≡ ∀xP ∧ ∀xQ
  * ∃x(P∨Q) ≡ ∃xP ∨ ∃xQ
* **Законы, НЕ сохраняющиеся:** кванторы не коммутируют с «чужими» связками:
  * ∀x(P∨Q) ≢ ∀xP ∨ ∀xQ (пример: домен {0, 1}, P(0) = Q(1) = 1, остальное 0 — левая часть истинна, правая ложна)
  * ∃x(P∧Q) ≢ ∃xP ∧ ∃xQ
* **Законы де Моргана для кванторов:** ¬∀xP ≡ ∃x¬P, ¬∃xP ≡ ∀x¬P (3.3)
* **Законы с «чужими» связками:** если x не свободна в Q:
  * ∀xP ∨ Q ≡ ∀x(P∨Q); ∃xP ∧ Q ≡ ∃x(P∧Q) — квантор «выносится» через связку
* **Переименование:** ∀xP(x) ≡ ∀yP(y), ∃xP(x) ≡ ∃yP(y) (4.3)
* **В коде:** проверка законов — вычисление таблиц обеих частей и сравнение (`pred_quantify`, `preds_equivalent`)

## **6. Теорема о приведённой форме**
* **Определение:** приведённая форма — формула, в которой из связок присутствуют только ¬, ∧, ∨, а отрицания стоят только непосредственно перед атомарными формулами (кванторы допустимы где угодно)
* **Теорема о приведённой форме:** для любой формулы логики предикатов существует эквивалентная приведённая формула
* **Алгоритм (алгебраический):**
  1. устранить → и ↔: A→B ≡ ¬A∨B, A↔B ≡ (A→B)∧(B→A);
  2. перенести отрицания вглубь: ¬¬A ≡ A, законы де Моргана ¬(A∧B) ≡ ¬A∨¬B, ¬(A∨B) ≡ ¬A∧¬B и ¬∀xP ≡ ∃x¬P, ¬∃xP ≡ ∀x¬P
* **Корректность:** каждый шаг — тождество (A.5, B.5), поэтому результат эквивалентен исходной формуле
* **В коде:** `eliminate_imp_iff`, `push_negations`, `reduced_form`

## **7. Теорема о предваренной нормальной форме**
* **Определение:** ПНФ — формула вида Q₁x₁ Q₂x₂ ... Qₖxₖ F, где Qᵢ — кванторы, F — бескванторная формула
* **Теорема о ПНФ:** для любой формулы существует эквивалентная ПНФ
* **Алгоритм:**
  1. привести к приведённой форме (6);
  2. выносить кванторы влево по законам B.5: если переменная квантора не свободна в соседней формуле — переносим; иначе переименовываем связанную переменную (4.4)
* **Корректность:** перенос обоснован законами B.5; переименование — альфа-эквивалентностью
* **В коде:** `to_pnf` (счётчик свежих переменных для переименования), `is_pnf` — проверка формы
* **Применение:** ПНФ — стандартный вид формул для дальнейших преобразований (сколемизация, резолюция — за рамками конспекта)

# **C. ФОРМАЛЬНЫЕ АКСИОМАТИЧЕСКИЕ ТЕОРИИ (ФАТ)**

## **1. Понятие формальной аксиоматической теории (ФАТ)**
* **Идея:** парадоксы (A.1.2) показывают, что «содержательные» рассуждения ненадёжны; ФАТ — способ доказательств без обращения к смыслу: только по форме
* **Определение:** ФАТ — тройка: (1) язык (алфавит + правила построения формул), (2) аксиомы — формулы, принимаемые без доказательства, (3) правила вывода — преобразования формул
* **Формальное доказательство:** конечная последовательность формул, каждая из которых — аксиома или получена из предыдущих по правилам вывода
* **Метатеория:** рассуждения о свойствах ФАТ ведутся вне неё

### **1.2. Основные свойства ФАТ**
* **Корректность (soundness):** всякая выводимая формула истинна (в выбранной интерпретации)
* **Непротиворечивость (consistency):** не существует формулы F, такой что выводимы и F, и ¬F (нельзя доказать противоречие)
* **Полнота (completeness):** всякая истинная формула выводима
* **Разрешимость (decidability):** существует алгоритм, который для любой формулы отвечает, выводима ли она (теория разрешима) — сильнее, чем полнота
* **Соотношения:** корректность + непротиворечивость — минимум для осмысленной теории; полнота желательна; разрешимость — редкий дар (см. 9 — вычислимость)

## **2. Формализованное исчисление высказываний (ФИВ)**
* **Язык:** формулы логики высказываний (часть A.3)
* **Аксиомы — три схемы** (в схему подставляются любые формулы A, B, C):
  * A1: A → (B → A)
  * A2: (A → (B → C)) → ((A → B) → (A → C))
  * A3: (¬B → ¬A) → (A → B)
* **Схема vs аксиома:** схема — бесконечное семейство формул; подстановка формул в схему даёт аксиому (самих аксиом бесконечно много)
* **Правило вывода:** modus ponens (MP): из A и A → B выводится B
* **В коде:** `is_axiom_scheme` — структурная проверка по трём схемам (согласованное сопоставление поддеревьев)

## **3. Понятие вывода (доказательства) формулы ФИВ**
* **Определение:** вывод формулы B из гипотез Γ — последовательность формул F₁, ..., Fₙ = B, где каждая Fᵢ — гипотеза из Γ, аксиома (по схемам 2) или результат MP из двух предыдущих формул
* **Обозначение:** Γ ⊢ B — «B выводимо из Γ»; ⊢ B — выводимо без гипотез (теорема)
* **Проверка вывода — алгоритмична:** каждая строка проверяется по списку гипотез, аксиомам и правилу; сложность O(k³) для вывода длины k (k шагов, поиск MP по парам)
* **Пример:** вывод A → A (без гипотез) — см. b.cpp `deduce_self_imp`: 5 формул из A1, A2 и MP
* **В коде:** `verify_derivation`

## **4. Теорема о дедукции**
* **Теорема о дедукции:** Γ, A ⊢ B ⟹ Γ ⊢ A → B; обратное тривиально: MP из Γ ⊢ A→B и гипотезы A даёт B
* **Значение:** позволяет доказывать импликации: переносим посылку в гипотезы, доказываем следствие, «возвращаем» импликацию
* **Алгоритмическая версия:** по выводу с гипотезой A строится вывод без неё: каждая формула Cᵢ заменяется выводом A → Cᵢ:
  * Cᵢ — аксиома или гипотеза Γ: Cᵢ, Cᵢ → (A → Cᵢ) [A1], A → Cᵢ [MP];
  * Cᵢ = A: стандартный вывод A → A;
  * Cᵢ = MP(Cⱼ, Cₖ), где Cₖ = Cⱼ → Cᵢ: аксиома A2 (A→(Cⱼ→Cᵢ)) → ((A→Cⱼ) → (A→Cᵢ)) и два MP
* **В коде:** `deduction_transform` — строит новый вывод и метки гипотез

## **5. Свойства ФИВ**
* **Корректность:** все аксиомы — тавтологии; MP сохраняет тавтологичность (из тавтологий A и A→B следует тавтология B) — значит, все выводимые формулы — тавтологии (в коде: `soundness_check`)
* **Непротиворечивость:** следствие корректности: если ⊢ F, то ¬F не выводима
* **Полнота:** теорема Гёделя о полноте для высказываний: всякая тавтология выводима в ФИВ
* **Разрешимость:** да — таблица истинности решает за O(2ⁿ·|F|) (A.4.3): формула выводима ⟺ она тавтология
* **Итог для ФИВ:** корректна, непротиворечива, полна и разрешима — идеальная система

## **6. Формализованное исчисление предикатов (ФИП)**
* **Язык:** формулы логики предикатов (B.4)
* **Аксиомы:** все схемы ФИВ (2) + кванторные схемы (t — терм, свободный для x в A(x)):
  * ∀x A(x) → A(t) (спецификация)
  * A(t) → ∃x A(x) (экзистенциальное введение)
* **Правила вывода:** MP + правило обобщения Gen: из A(x) выводится ∀x A(x), если x не свободна в гипотезах
* **В коде:** `is_axiom_scheme_pred` — проверка кванторных схем подстановкой; `verify_pred_derivation` — проверка выводов (MP и Gen)

### **6.3. Свойства ФИП**
* **Корректность:** выводимы только общезначимые формулы (истинные во всех интерпретациях)
* **Непротиворечивость:** следствие корректности
* **Полнота:** теорема Гёделя о полноте (1930): всякая общезначимая формула выводима в ФИП
* **Разрешимость:** НЕТ — теорема Чёрча (C.9): проверка вывода алгоритмична, поиск вывода — нет
* **Значение:** ФИП — формализация «обычной» математики; большинство математических теорий строятся как ФАТ на основе ФИП

## **7. Формальная арифметика (ФА)**
* **Язык:** константа 0, функция S («следующий»), операции +, ·, предикат =, переменные, кванторы, связки (в коде — строки схем)
* **Аксиомы Пеано:**
  * ¬S(x) = 0 — ноль не является следующим ни для какого числа
  * S(x) = S(y) → x = y — S взаимно однозначен
  * x + 0 = x; x + S(y) = S(x + y) — рекурсивное определение сложения
  * x · 0 = 0; x · S(y) = (x · y) + x — рекурсивное определение умножения
  * схема индукции: (F(0) ∧ ∀x(F(x) → F(S(x)))) → ∀x F(x)
* **Назначение:** ФА формализует арифметику натуральных чисел; все «школьные» факты доказуемы в ФА, однако (8) — не все истинные

## **8. Теоремы Гёделя о неполноте ФА**

### **8.1. Нумерация Гёделя (арифметизация синтаксиса)**
* **Идея:** сопоставить каждой формуле и каждому выводу натуральное число — тогда рассуждения о формулах становятся арифметическими
* **Кодирование:** символы алфавита нумеруются натуральными числами (коды); формула — последовательность символов — кодируется произведением первых простых в степенях кодов: g(s₁...sₖ) = 2^{c(s₁)+1} · 3^{c(s₂)+1} · ... · pₖ^{c(sₖ)+1}; вывод — кортеж номеров формул — аналогично
* **Однозначность:** по основной теореме арифметики разложение на простые единственно — декодирование однозначно (в коде: `godel_number` / `godel_decode`)
* **Самовысказывание:** свойства формул и выводов (быть аксиомой, быть выводом) — выражаются арифметическими предикатами; формула может «говорить» о своём собственном номере — парадокс лжеца (A.1.2) в законной форме
* **Внимание (в коде):** число растёт экспоненциально по длине формулы — для демонстрации годятся короткие формулы

### **8.2. Первая теорема Гёделя о неполноте (1931)**
* **Теорема:** если ФА непротиворечива, то существует замкнутая формула G, такая что ни G, ни ¬G не выводимы в ФА
* **Идея построения:** G «говорит»: «G не выводима» (аналог парадокса лжеца: вместо «я ложна» — «я недоказуема»): если G выводима — ФА не корректна; если ¬G выводима — ФА не непротиворечива
* **Следствие:** ФА неполна (и не может быть пополнена присоединением конечного числа аксиом — неполнота внутренняя)

### **8.3. Вторая теорема Гёделя**
* **Теорема:** непротиворечивость ФА не доказуема средствами самой ФА (если ФА непротиворечива)
* **Следствие:** нельзя обосновать арифметику внутри арифметики; программы «доказательства непротиворечивости» внутри системы заведомо невозможны

## **9. Вычислимость и теорема Чёрча о неразрешимости**

### **9.1. Понятие алгоритма и формализации**
* **Алгоритм:** конечное предписание, однозначно определяющее последовательность действий и выполнимое механически («без понимания») — интуитивное понятие, как и «высказывание» (A.2.1)
* **Вычислимая функция:** f: ℕᵏ → ℕ (или частичная), для которой существует алгоритм, вычисляющий f(x) по аргументам
* **Формализации (1930-е):** три независимых определения одного класса функций: машины Тьюринга (9.2), λ-исчисление Чёрча (9.3), рекурсивные функции Клина (9.4); совпадение классов — основание тезиса Чёрча (9.5)
* **Смысл:** формализация алгоритма — инструмент неразрешимости: «не существует алгоритма» становится доказуемым утверждением (9.5)
* **В коде:** три формализации представлены независимо и проверяются на одних и тех же примерах (9.2–9.4)

### **9.2. Машина Тьюринга**
* **Определение:** бесконечная лента (ячейки алфавита {0, 1} + пробел), конечное множество состояний Q (q₀ — начальное), программа — частичная функция δ: Q × Σ → Q × Σ × {−1, 0, +1} (новое состояние, новый символ, сдвиг головки)
* **Остановка:** машина останавливается, когда для пары (состояние, символ) перехода нет; «зацикливается», если переходы есть всегда
* **Конфигурация:** (состояние, позиция головки, лента) — полное описание момента работы (ср. вывод в ФАТ, 3); работа машины — последовательность конфигураций
* **Вычислимость по Тьюрингу:** f вычислима, если существует машина, которая по входу (x₁, ..., xₖ) останавливается с ответом на ленте
* **Универсальная машина:** программы кодируются числами (как формулы в нумерации Гёделя, 8.1), и существует машина U, моделирующая любую машину по её коду — «компьютер»: одна фиксированная машина выполняет любую программу
* **В коде:** `turing_step` — один шаг (false — машина встала), `turing_run` — выполнение с лимитом шагов (лимит — модель неразрешимости, 9.5)

### **9.3. Лямбда-исчисление Чёрча, вычислимость по Чёрчу**
* **Термы** (индуктивное определение, как формулы B.4.2): переменная x; λ-абстракция λx.M (функция от x); применение (M N) (вызов)
* **β-редукция:** (λx.M) N ⟶ M[x := N] — подстановка терма (ср. B.4.4); вычисление — последовательность β-редукций до нормальной формы
* **Числа Чёрча:** n = λf.λx. fⁿ(x) — «итератор»: n раз применить f к x; 0 = λf.λx. x; операции — термы: SUCC = λn.λf.λx. f (n f x), ADD = λm.λn.λf.λx. m f (n f x), MUL = λm.λn.λf. m (n f) — арифметика без чисел
* **Вычислимость по Чёрчу:** f вычислима по Чёрчу, если её представляет λ-терм, β-редуцирующийся к числу Чёрча f(x) для любого x (терм должен завершаться — не всякий терм имеет нормальную форму)
* **В коде:** числа Чёрча — функции C++: `church_numeral(n)` — итератор, применяющий функцию n раз; `church_succ`, `church_add`, `church_mul` — операции; `church_apply` — применение (модель β-редукции); `church_to_int` — проверка на «счётчике» (x → x+1)

### **9.4. Рекурсивные функции Клина**
* **Базисные функции:** O(x) = 0; S(x) = x + 1; проекции Iᵏᵢ(x₁, ..., xₖ) = xᵢ
* **Операторы:**
  * подстановка (суперпозиция): h(f₁(x), ..., fₘ(x)) из h и f₁, ..., fₘ;
  * примитивная рекурсия: f(x, 0) = g(x); f(x, y + 1) = h(x, y, f(x, y)) — итерация, всегда завершается;
  * минимизация (μ-оператор): f(x) = μy[g(x, y) = 0] — наименьший y с нулевым значением; не найден — функция не определена (частичная): единственный источник бесконечного поиска
* **Аксиоматическая теория вычислимых функций:** наименьший класс функций, содержащий базис и замкнутый операторами — пример ФАТ (1.1: базис — аксиомы, операторы — правила вывода, функции — «выводимые формулы»); свойства доказываются индукцией по построению
* **Теорема Клини:** класс частично-рекурсивных функций совпадает с классом вычислимых по Тьюрингу (9.2) — первое доказанное совпадение формализаций
* **В коде:** `basis_zero`, `basis_successor`, `basis_projection` (генерируют базис как std::function); `substitution`, `primitive_recursion`, `mu_minimize` (с ограничением поиска — неограниченный поиск не алгоритмичен, 9.5)

### **9.5. Тезис Чёрча, проблема остановки и неразрешимость**
* **Тезис Чёрча (1936):** всякая интуитивно вычислимая функция вычислима по Чёрчу (эквивалентно: по Тьюрингу); статус — тезис, не теорема (интуитивное понятие не формализовано); подтверждён совпадением трёх формализаций (9.2–9.4)
* **Проблема остановки:** по программе машины Тьюринга и входу определить, остановится ли машина; неразрешима (Тьюринг, 1936): допущение решающей машины H ведёт к машине D (по коду M: если H(M, M) отвечает «остановится» — зациклиться); D(D) останавливается ⟺ D(D) не останавливается — противоречие
* **Разрешимое приближение:** остановка «за не более чем K шагов» разрешима — выполнить K шагов (9.2: лимит `turing_run`); неразрешимость — отсутствие единого K для всех машин
* **Теорема Чёрча (1936):** не существует алгоритма, который по произвольной формуле логики предикатов отвечает, выводима ли она в ФИП
* **Следствия:**
  * ФИП неразрешима (а ФИВ разрешима — 5, таблицы истинности);
  * ФА неразрешима (в ФА кодируются выводы ФИП);
  * проверка вывода (3) — алгоритмична, а поиск вывода — нет: это разные задачи
* **Смысл:** неполнота (8.2) — свойство ФА, неразрешимость — свойство алгоритмов: никакая программа не «заменит» математиков; вычислимость — формальный смысл понятия «алгоритм» (9.1)

# **D. НЕЧЁТКАЯ ЛОГИКА**

## **1. Нечёткие множества**

### **1.1. Функция принадлежности**
* **Определение:** нечёткое множество A на универсуме U задаётся функцией принадлежности μ_A: U → [0, 1] — степень принадлежности элемента множеству
* **Частный случай:** классическое множество — μ_A: U → {0, 1} (характеристическая функция, a.md A.2); нечёткая логика «отпускает» 0 и 1 в отрезок [0, 1] — многозначность как развитие двузначной логики (части A, B)
* **Способы задания:** список пар ⟨x, μ_A(x)⟩; для конечного U — вектор степеней
* **Смысл:** формализация нечётких понятий («высокий», «тёплый») — степень истинности вместо 0/1
* **В коде:** нечёткое множество — вектор double (универсум — индексы): `FuzzySet`

### **1.2. Носитель, ядро, α-срезы**
* **Носитель:** supp A = {x ∈ U : μ_A(x) > 0} — элементы с ненулевой степенью
* **Ядро:** core A = {x ∈ U : μ_A(x) = 1} — полноправные элементы
* **α-срез:** A_α = {x ∈ U : μ_A(x) ≥ α} — «пороговое» классическое множество, α ∈ [0, 1] — уровень
* **Теорема о декомпозиции:** μ_A(x) = max{α : x ∈ A_α} — нечёткое множество однозначно восстанавливается по своим α-срезам: нечёткость «расслаивается» на семейство классических приближений
* **В коде:** `fuzzy_support`, `fuzzy_core`, `alpha_cut` — срез по уровню; `fuzzy_decompose` — восстановление по срезам (по сетке уровней)

## **2. Операции над нечётками множествами**
* **Дополнение:** μ_¬A(x) = 1 − μ_A(x) — обобщение дополнения (a.md A.2); двойное отрицание: μ_¬¬A(x) = μ_A(x)
* **Пересечение:** μ_(A∩B)(x) = min(μ_A(x), μ_B(x))
* **Объединение:** μ_(A∪B)(x) = max(μ_A(x), μ_B(x))
* **Включение:** A ⊆ B ⟺ μ_A(x) ≤ μ_B(x) для всех x
* **Проверка:** при μ ∈ {0, 1} операции совпадают с классическими (a.md A.2), а min/max — это ∧/∨ (A.2.2): нечёткая логика действительно обобщает двузначную
* **В коде:** `fuzzy_complement`, `fuzzy_intersection`, `fuzzy_union`, `fuzzy_subset` — поточечные операции над векторами

## **3. Нечёткая алгебраическая система (Fuzzy Operations)**

### **3.1. Алгебраическая система**
* **Определение:** алгебраическая система — множество (носитель) с операциями над ним (a.md); нечёткая алгебраическая система — носитель: нечёткие множества на U, операции: Fuzzy Operations
* **Поточечность:** результат на элементе x зависит только от значений операндов на x — операции «поднимаются» с отрезка [0, 1] на функции принадлежности

### **3.2. Fuzzy Operations**
* **Стандартная система:** пересечение — min степеней; объединение — max; дополнение — 1 − μ (2)
* **Обобщение:** выбор ∧/∨ не обязателен — любая пара «умножения и сложения степеней» с нужными свойствами задаёт другую нечёткую алгебраическую систему: это t-нормы и t-конормы (4)
* **В коде:** `fuzzy_intersection`/`fuzzy_union` — стандартная система (min/max); `fuzzy_binary_op` — произвольная поточечная операция над степенями; t-нормы и t-конормы — 4.3

## **4. t-нормы и t-конормы**

### **4.1. t-нормы**
* **Определение:** t-норма — функция T: [0, 1]² → [0, 1] с аксиомами: коммутативность T(a, b) = T(b, a); ассоциативность T(a, T(b, c)) = T(T(a, b), c); монотонность a ≤ c, b ≤ d ⟹ T(a, b) ≤ T(c, d); единица T(a, 1) = a
* **Стандартные t-нормы:** Гёдель T(a, b) = min(a, b); произведение T(a, b) = a·b; Лукасевич T(a, b) = max(0, a + b − 1)
* **Смысл:** аксиомы — «правила умножения степеней»: обобщение конъюнкции ∧ (для {0, 1} любая t-норма — это ∧)

### **4.2. t-конормы**
* **Определение:** t-конорма — двойственная операция (обобщение ∨): S(a, b) = 1 − T(1 − a, 1 − b) — двойственность де Моргана (A.5)
* **Стандартные t-конормы:** max; вероятностная S(a, b) = a + b − a·b; Лукасевич S(a, b) = min(1, a + b)
* **Свойства:** коммутативность, ассоциативность, монотонность, единица 0: S(a, 0) = a

### **4.3. Fuzzy Operations через t-нормы**
* **Определение:** (A ∩_T B)(x) = T(μ_A(x), μ_B(x)); (A ∪_S B)(x) = S(μ_A(x), μ_B(x)) — замена min/max на произвольные T/S (3.2)
* **Выбор системы:** min/max — обычная; произведение/вероятностная — «мягкая»; Лукасевич — «строгая» (вычитание степеней)
* **Де Морган:** двойственность T и S обеспечивает ¬(A ∩_T B) = ¬A ∪_S ¬B — тождества булевой алгебры (A.5) переносятся на нечёткий случай
* **В коде:** `t_norm`/`t_conorm` — операции по имени ("min"/"product"/"lukasiewicz" и "max"/"probabilistic"/"lukasiewicz"); `check_t_norm`/`check_t_conorm` — автоматическая проверка аксиом на сетке уровней; `fuzzy_intersection_t`/`fuzzy_union_t` — поточечное применение

## **5. Нечёткие отношения и композиция**

### **5.1. Нечёткое отношение**
* **Определение:** нечёткое отношение R на A × B — функция принадлежности μ_R: A × B → [0, 1] — степень связи пары (ср. бинарные отношения a.md B.2: матрица, только вместо 0/1 — степени)
* **Пример:** «x похож на y» — степень сходства, а не факт

### **5.2. Max-min композиция**
* **Определение:** (R ∘ S)(x, z) = max_y min(μ_R(x, y), μ_S(y, z)) — обобщение композиции отношений (a.md B.3): вместо ∃y (∧/∨) — max по y и min (t-конорма и t-норма, 4)
* **Смысл:** степень связи «через посредника» — максимум по всем путям x → y → z произведения степеней звеньев
* **Транзитивное замыкание:** наименьшее транзитивное нечёткое отношение, содержащее R (обобщение замыканий a.md B.7): итерации R ← R ∪ (R ∘ R) до стабилизации
* **В коде:** `fuzzy_relation_compose` — композиция матриц; `fuzzy_transitive_closure` — замыкание итерациями
