**C. БУЛЕВА АЛГЕБРА И ФУНКЦИИ**

# **A. БУЛЕВЫ ФУНКЦИИ**

## **1. Понятие булевой функции, способы задания**

### **1.1. Понятие**
* **Определение:** булева функция — функция f: {0, 1}ⁿ → {0, 1}, где n — арность (число переменных)
* **Число функций:** от n переменных ровно 2^(2ⁿ) — каждому из 2ⁿ наборов можно независимо сопоставить 0 или 1
* **Примеры:** константы 0 и 1, отрицание ¬x (n = 1), ∧, ∨, →, ↔, ⊕ (n = 2), ...
* **Связь с b.md:** каждая формула логики высказываний (b.md A.3) задаёт булеву функцию от своих переменных; таблица истинности формулы (b.md A.4.3) — это способ задания функции

### **1.2. Способы задания**
* **Таблица истинности:** наборы (в порядке бинарного счётчика) и значения функции на них
* **Вектор значений:** столбец значений — двоичная строка длины 2ⁿ; читается как двоичное число — номер функции (номера 0..2^(2ⁿ)−1)
* **Формула:** любая формула задаёт функцию; обратно — любая функция задаётся формулой (СДНФ, 4.2)
* **Полином Жегалкина:** (4.4)
* **В коде:** функция — вектор int размера 2ⁿ (таблица истинности, как предикат в b.cpp); `number_of_functions`, `function_number` / `function_from_number`

## **2. Существенные и фиктивные переменные**
* **Определение:** переменная xᵢ существенна для f, если существуют два набора, отличающиеся только значением xᵢ, на которых значения f различны; иначе xᵢ — фиктивная
* **Смысл:** от фиктивных переменных функция не зависит: f можно рассматривать как функцию меньшей арности
* **Смена роли:** добавление фиктивной переменной не меняет «содержание» функции, но формально меняет арность (СДНФ/СКНФ учитывают все n переменных)
* **В коде:** `is_essential`, `essential_variables`

## **3. Реализация булевых функций формулами**
* **Теорема (реализуемости):** каждая булева функция реализуется формулой — это следствие построения СДНФ (4.2); обратное очевидно: каждая формула задаёт функцию
* **Суперпозиция:** подстановка функций в функции и переименование переменных — способы строить новые функции из старых; формулы — синтаксическая форма суперпозиции
* **В коде:** значение функции на наборе — `eval_form` (b.cpp); таблица функции по формуле — `truth_table` (b.cpp); обратный переход — `sdnf_formula` (4.2)

## **4. Нормальные формы**

### **4.1. Литералы, элементарные конъюнкции и дизъюнкции**
* **Литерал:** переменная xᵢ или её отрицание ¬xᵢ
* **Элементарная конъюнкция (ЭК):** конъюнкция литералов (не обязательно всех переменных)
* **Элементарная дизъюнкция (ЭД):** дизъюнкция литералов
* **ДНФ/КНФ:** дизъюнкция ЭК / конъюнкция ЭД

### **4.2. Совершенная ДНФ (СДНФ)**
* **Определение:** ДНФ, в которой каждая ЭК содержит ровно по одному вхождению всех n переменных (полные ЭК — конституенты единицы)
* **Построение по таблице:** для каждого набора, где f = 1, берём ЭК: xᵢ при xᵢ = 1 и ¬xᵢ при xᵢ = 0; результат — дизъюнкция таких ЭК
* **Теорема:** СДНФ существует для любой функции (кроме тождественного нуля) и единственна — «формульный» способ задания функции
* **Пример:** f = x₀∨x₁ (вектор 0111): СДНФ = (¬x₀∧x₁) ∨ (x₀∧¬x₁) ∨ (x₀∧x₁)
* **В коде:** `sdnf_formula` — строит формулу (дерево Form, b.cpp)

### **4.3. Совершенная КНФ (СКНФ)**
* **Определение:** КНФ с полными ЭД (конституенты нуля): по наборам, где f = 0; литерал xᵢ при xᵢ = 0 и ¬xᵢ при xᵢ = 1 (литералы «перевёрнуты» относительно СДНФ)
* **Теорема:** СКНФ существует для любой функции (кроме тождественной единицы) и единственна
* **Пример:** f = x₀∨x₁: СКНФ = x₀∨x₁ (единственный набор с f = 0 — (0, 0))
* **В коде:** `sknf_formula`

### **4.4. Полином Жегалкина**
* **Определение:** представление функции полиномом по mod 2 в базисе {∧, ⊕}: f = ⊕Σ c_S · ∏_{i∈S} xᵢ (mod 2), c_S ∈ {0, 1} — коэффициенты
* **Базис Жегалкина:** {∧, ⊕, 1} — отрицание не нужно: ¬x ≡ x ⊕ 1
* **Теорема:** полином существует для любой функции и единственен; число полиномов 2^(2ⁿ)
* **Построение:** треугольник Паскаля по вектору значений; в коде — zeta-преобразование (a.cpp A.6) с XOR вместо сложения: c[mask] = ⊕_{sub ⊆ mask} a[sub], над GF(2) преобразование самодвойственно
* **Пример:** f = x₀∨x₁ = x₀ ⊕ x₁ ⊕ x₀x₁ (проверка: 0⊕0⊕0 = 0; 1⊕0⊕0 = 1; 0⊕1⊕0 = 1; 1⊕1⊕1 = 1 ✓)
* **Линейные функции:** полином степени ≤ 1 (часть A.8)
* **В коде:** `zhegalkin_coefficients`, `zhegalkin_to_string`

## **5. Булева алгебра, её тождества и стандартный базис**
* **Определение:** булева алгебра — множество B с операциями ∧, ∨, ¬ и константами 0, 1, удовлетворяющими аксиомам: коммутативность, ассоциативность, дистрибутивность (обе), идемпотентность, поглощение, законы дополнения (a ∨ ¬a = 1, a ∧ ¬a = 0)
* **Модели:** {0, 1} с обычными ∧, ∨, ¬; множества (a.md A.3); формулы высказываний (b.md A.5) — единая аксиоматика, разные модели
* **Тождества:** все тождества b.md A.5 (двойное отрицание, де Морган, поглощение, ...) — тождества булевой алгебры
* **Стандартный базис:** {¬, ∧, ∨} — полная система (b.md A.2: функциональная полнота)
* **Другие полные базисы:** {¬, ∧}, {¬, ∨}, {¬, →}, {∧, ⊕} (Жегалкин), {↓} (стрелка Пирса — одна функция), {|} (штрих Шеффера — одна функция)
* **В коде:** проверка тождеств — сравнение таблиц истинности (`forms_equivalent`, b.cpp)

## **6. Эквивалентные преобразования логических формул**
* **Определение:** эквивалентное преобразование — замена подформулы эквивалентной (b.md A.5: теорема о замене); цепочка преобразований не меняет функцию, задаваемую формулой
* **Проверка:** две формулы эквивалентны ⟺ совпадают их таблицы истинности (b.md A.5)
* **Канонический вид:** приведение к СДНФ — единый вид, по которому сравнивают и упрощают формулы (единственность, 4.2)
* **Применение:** упрощение схем (часть B): чем проще формула — тем меньше вентилей
* **В коде:** `forms_equivalent`, `truth_table` (b.cpp), `reduced_form` (b.md B.6), `sdnf_formula` (4.2)

## **7. Теорема Яблонского о полноте**
* **Замыкание:** [A] — множество всех функций, реализуемых формулами над системой A (суперпозиции)
* **Полная система:** [A] = P₂ — все булевы функции выражаются формулами над A
* **Замкнутые классы:** [A] = A — содержат все свои суперпозиции (например, {∧, ∨} порождает только монотонные функции)
* **Теорема Яблонского (критерий полноты):** система A полна ⟺ A не содержится целиком ни в одном из пяти предполных классов: T₀, T₁, S, M, L (см. 8)
* **В коде:** `is_complete_system`

## **8. Предполные классы булевых функций**
* **T₀ — сохраняющие 0:** f(0, ..., 0) = 0
* **T₁ — сохраняющие 1:** f(1, ..., 1) = 1
* **S — самодвойственные:** f(¬x₁, ..., ¬xₙ) = ¬f(x₁, ..., xₙ)
* **M — монотонные:** x ≤ y (покоординатно) ⟹ f(x) ≤ f(y)
* **L — линейные:** полином Жегалкина степени ≤ 1: c₀ ⊕ c₁x₁ ⊕ ... ⊕ cₙxₙ
* **Свойства:** каждый класс замкнут; каждый предполон — максимальный собственный замкнутый класс: добавление любой функции вне класса делает систему полной
* **Примеры:** ∧, ∨ ∈ T₀ ∩ T₁ ∩ M (но не S, не L); ¬ ∈ S ∩ L (но не T₀, не T₁, не M); константа 0 ∈ T₀ ∩ M ∩ L; константа 1 ∈ T₁ ∩ M ∩ L
* **В коде:** `in_T0`, `in_T1`, `is_self_dual`, `is_monotone`, `is_linear`

## **9. Критерий Поста**
* **Классификация:** каждая булева функция лежит в некотором подмножестве пяти классов T₀, T₁, S, M, L — «таблица Поста» функции (5 битов)
* **Критерий Поста:** система функций полна ⟺ для каждого из пяти классов найдётся функция системы, НЕ лежащая в этом классе (в таблице Поста системы нет класса, покрытого всеми функциями сразу)
* **Примеры:** {¬, ∧} полна; {∧, ∨} не полна (обе в T₀, T₁, M); {↓} полна (одна функция, но вне всех пяти классов)
* **Применение:** доказательство полноты/неполноты базисов (5), построение схем (часть B)
* **В коде:** `post_table`, `is_complete_system`

# **B. ЛОГИЧЕСКИЕ ЭЛЕМЕНТЫ И СХЕМЫ**

## **1. Базовые логические вентили**
* **Вентиль:** реализация булевой функции; комбинационная схема — сеть вентилей без памяти
* **Двухвходовые вентили** (x — первый вход, y — второй):
  * AND: x∧y; OR: x∨y; XOR: x⊕y
  * NAND: ¬(x∧y); NOR: ¬(x∨y); XNOR: ¬(x⊕y) (эквивалентность)
  * IMPLY: x→y; NIMPLY: ¬(x→y) = x∧¬y
* **Одновходовые:** NOT: ¬x
* **Замечания:** NAND и NOR полны сами по себе (базисы из одной функции, A.5); IMPLY/NIMPLY несимметричны
* **В коде:** `gate_table` — таблица вентиля (4 бита, индекс (x<<1)|y), `gate_apply` — применение к входам

## **2. Комбинационные схемы: мультиплексор**
* **Мультиплексор 2ᵏ → 1:** k адресных битов выбирают один из 2ᵏ входов: out = inputs[addr]
* **Реализация:** дизъюнкция «вход ∧ селектор»: out = ∨ᵢ (inputs[i] ∧ (addr = i)), где (addr = i) — конъюнкция литералов адресных битов (ср. СДНФ, A.4.2)
* **Демультиплексор:** обратная схема — один вход направляется в выбранный выход (значение в позиции addr, нули в остальных)
* **Применение:** коммутация сигналов; любая булева функция реализуется мультиплексором — вектор значений функции подаётся на входы, адрес — её аргументы (СДНФ «в железе»)
* **В коде:** `multiplexer`, `demultiplexer`

## **3. Методы минимизации**

### **3.1. Карты Карно**
* **Идея:** таблица истинности в виде клеток 2ⁿ, соседние клетки отличаются ровно одним битом (порядок Грея по строкам и столбцам)
* **Склейка:** прямоугольники из 2ᵏ соседних единиц (стороны — степени двойки, допускается «склейка через край» — тора) соответствуют ЭК из n−k переменных: переменные, меняющиеся внутри прямоугольника, выпадают
* **Минимизация:** покрыть все единицы минимальным числом максимальных прямоугольников
* **Связь с Квайном-МакКласки:** карты Карно — визуальный метод; QM (3.2) — его алгоритмическая автоматизация (склейка — та же идея)
* **В коде:** `karnaugh_order` — индексы клеток в порядке Грея, `karnaugh_map` — карта, `karnaugh_print` — вывод

### **3.2. Метод Квайна-МакКласки**
* **Идея:** алгоритмическая минимизация ДНФ — автоматизация карт Карно
* **Алгоритм:**
  1. минтермы: наборы, где f = 1 (строки из n битов, старший бит — первая позиция);
  2. склейка: пара строк, отличающихся ровно в одном бите, сливается в импликанту с '-' (безразличное значение) в этом бите; повторять, пока есть склейки;
  3. простые импликанты: строки, которые не удалось склеить (включая минтермы без пар на первом шаге);
  4. покрытие: минимальное подмножество простых импликант, накрывающих все минтермы (перебор подмножеств — импликант немного)
* **Сложность:** склейка O(m²·n) на раунд (m — число строк текущего уровня); покрытие — O(2ᵏ·m) при k импликантах; практично при n ≤ 6
* **Пример:** f = x₀∨x₁ (минтермы 01, 10, 11): склейки 01~11 → -1 и 10~11 → 1-; простые импликанты {-1, 1-}; минимальное покрытие — обе: x₀∨x₁
* **В коде:** `quine_mccluskey` — простые импликанты, `implicant_masks` — покрываемые минтермы, `minimal_cover` — минимальное покрытие, `implicant_to_string` — запись импликанты формулой
