# **A. ОСНОВЫ ТЕОРИИ МНОЖЕСТВ**

## **1. Основные понятия**

### **1.1. Множество и элемент**
* **Идея:** нужен способ говорить о «совокупности объектов как об одном целом» — без порядка, без повторов, только принадлежность
* **Определение:** множество — совокупность различных объектов (элементов), рассматриваемая как единый объект; x ∈ A — «x принадлежит A», x ∉ A — «x не принадлежит»
* **Способы задания:**
  * перечислением: A = {a₁, a₂, ..., aₙ}
  * характеристическим свойством: A = {x : P(x)} — все x, для которых истинно свойство P
  * порождающей функцией / рекурсивно: A = {n² : n ∈ ℤ}
* **Пустое множество** ∅ = {} — не содержит ни одного элемента
* **Универсум U** — множество, содержащее все рассматриваемые объекты (контекст задачи)
* **Терминология:** конечное/бесконечное множество, мощность |A| — число элементов
* **В программировании:** std::set / std::unordered_set (произвольные типы), битовая маска (универсум ≤ 64 элементов), бинарное дерево поиска, хеш-таблица

### **1.2. Подмножества и равенство**
* **Определение:** A ⊆ B (A — подмножество B) ⟺ ∀x: x ∈ A ⇒ x ∈ B
* **Собственное подмножество:** A ⊂ B ⟺ A ⊆ B и A ≠ B
* **Равенство:** A = B ⟺ A ⊆ B и B ⊆ A — единственный способ доказать равенство двух множеств: двумя включениями
* **Булеан:** 2^A = {X : X ⊆ A} — множество всех подмножеств A
* **Важно:** ∅ ⊆ A для любого A (пустое включено везде); ∅ ∈ 2^A всегда

### **1.3. Диаграммы Эйлера-Венна**
* **Идея:** множества — круги на плоскости; принадлежность — попадание точки в круг
* **Назначение:** визуально доказывать теоретико-множественные тождества и понимать операции; проверять «на глаз» справедливость равенств
* **Ограничение:** диаграмма — не доказательство: корректность тождества проверяется по элементам (x ∈ A ⇔ x ∈ B), для n ≥ 4 кругами не нарисовать
* **Применение в задачах:** классические задачи «сколько элементов в каждой зоне» (пересечения двух/трёх множеств) решаются именно в терминах диаграммы: рисуем зоны, заполняем с конца (изнутри наружу)

### **1.4. Представление битовой маской (программирование)**
* **Идея:** если универсум U = {0, 1, ..., n−1}, n ≤ 63, каждое множество — целое число: бит x = 1 ⟺ x ∈ A
* **Зачем:** все операции над множествами — одна инструкция процессора; перебор подмножеств — перебор чисел
* **Связь:** мощность = popcount (число единичных битов), пустое = 0, универсум = 2ⁿ−1

## **2. Операции над множествами**

### **2.1. Объединение, пересечение, разность**
* **Объединение:** A ∪ B = {x : x ∈ A ∨ x ∈ B}
* **Пересечение:** A ∩ B = {x : x ∈ A ∧ x ∈ B}
* **Разность:** A \ B = {x : x ∈ A ∧ x ∉ B}
* **Интуиция на диаграммах Венна:** ∪ — обе окружности целиком, ∩ — общая область, \ — левая окружность минус общая область
* **Пример:** A = {1, 2, 3}, B = {3, 4, 5}: A ∪ B = {1, 2, 3, 4, 5}, A ∩ B = {3}, A \ B = {1, 2}
* **Непересекающиеся:** A ∩ B = ∅ (обозначение A ⊔ B — дизъюнктное объединение)

### **2.2. Симметрическая разность**
* **Определение:** A △ B = (A \ B) ∪ (B \ A) = {x : ровно одно из x ∈ A, x ∈ B истинно}
* **Связь с XOR:** симметрическая разность = «исключающее ИЛИ» для принадлежности; в битовых масках A ^ B
* **Почему отдельная операция:** △ ассоциативна и коммутативна, A △ A = ∅, A △ ∅ = A — образует группу по структуре

### **2.3. Дополнение**
* **Определение:** A̅ = U \ A = {x : x ∉ A} — относительно универсума U (всегда уточнять, относительно какого U)
* **Правило:** A ∪ A̅ = U, A ∩ A̅ = ∅, (A̅)̅ = A

### **2.4. Формулы операций на масках**
* **∪** = `a | b`, **∩** = `a & b`, **\** = `a & ~b`, **△** = `a ^ b`, **A̅** = `~a & (2ⁿ−1)`
* **Почему работает разность через ~:** `a & ~b` оставляет в a только биты, которых нет в b

## **3. Алгебра множеств, её тождества**

* **Идемпотентность:** A ∪ A = A, A ∩ A = A
* **Коммутативность:** A ∪ B = B ∪ A, A ∩ B = B ∩ A
* **Ассоциативность:** (A ∪ B) ∪ C = A ∪ (B ∪ C), (A ∩ B) ∩ C = A ∩ (B ∩ C)
* **Дистрибутивность:** A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C), A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C) — «пересечение распределяется по объединению» и наоборот (в отличие от чисел, где работает только умножение по сложению)
* **Законы поглощения:** A ∪ (A ∩ B) = A, A ∩ (A ∪ B) = A
* **Нейтральные элементы:** A ∪ ∅ = A, A ∩ U = A
* **Поглощение:** A ∪ U = U, A ∩ ∅ = ∅
* **Законы де Моргана:** (A ∪ B)̅ = A̅ ∩ B̅, (A ∩ B)̅ = A̅ ∪ B̅ — «не (A или B)» = «не A и не B»
* **Двойное дополнение:** (A̅)̅ = A
* **Принцип двойственности:** если в тождестве заменить ∪ ↔ ∩ и ∅ ↔ U, получится снова верное тождество; пары выше — примеры двойственных тождеств
* **Доказательство тождеств:** по элементам: взять x ∈ левая часть и показать x ∈ правая часть, и наоборот; либо заменить каждую операцию её определением через ∈/∨/∧ и свести к алгебре логики (см. b.md — логика высказываний)
* **Применение:** упрощение выражений с множествами в задачах; де Морган — как отрицание условий в программировании

## **4. Мощность множества**

### **4.1. Конечные множества**
* **Определение:** |A| — число элементов; два множества равномощны ⟺ между ними существует биекция (взаимно-однозначное соответствие, см. B.8)
* **Правило суммы:** если A ∩ B = ∅, то |A ∪ B| = |A| + |B|; обобщение: |A₁ ⊔ A₂ ⊔ ... ⊔ Aₖ| = Σ|Aᵢ|
* **Правило суммы с пересечением:** |A ∪ B| = |A| + |B| − |A ∩ B| (частный случай включений-исключений, см. 1.7)
* **Правило произведения:** |A × B| = |A|·|B| — число пар; обобщение: |A₁ × A₂ × ... × Aₖ| = ∏|Aᵢ|
* **Мощность булеана:** |2^A| = 2^|A| — каждому подмножеству соответствует бинарный вектор длины |A|
* **Правило биекции:** если существует биекция A ↔ B, то |A| = |B| — главный инструмент пересчёта (см. combinatorics: биективный метод)

### **4.2. Бесконечные множества (дополнительно)**
* **Счётные множества:** |ℕ| = |ℤ| = |ℚ| = ℵ₀ — счётно бесконечные; ℚ счётно, хотя плотно в ℝ (диагональная нумерация Кантора)
* **Континуум:** |ℝ| = c > ℵ₀ — несчётно
* **Теорема Кантора:** |A| < |2^A| для любого A — не существует самой большой мощности
* **Диагональный аргумент:** предположим, что ℝ счётно; запишем числа в десятичной записи и построим число, отличающееся от k-го в k-м знаке — оно не попало в список; противоречие
* **Применение в олимпиадах:** задачи «сравните мощности» (например, множество конечных подмножеств ℕ счётно, множество всех подмножеств ℕ несчётно)

## **5. Формула включений-исключений**

### **5.1. Для двух и трёх множеств**
* **Два множества:** |A ∪ B| = |A| + |B| − |A ∩ B|
* **Три множества:** |A ∪ B ∪ C| = |A| + |B| + |C| − |A∩B| − |A∩C| − |B∩C| + |A∩B∩C|
* **Почему так:**
  * складываем одиночные мощности — элементы из пересечений посчитаны несколько раз;
  * вычитаем попарные пересечения — теперь элементы тройного пересечения не посчитаны вовсе;
  * добавляем тройное пересечение — оно было вычтено трижды
* **Интуиция на диаграмме Венна:** знак = (−1)^(число штриховок): 1 круг +, 2 круга −, 3 круга +; каждая точка в итоге посчитана ровно один раз

### **5.2. Общая формула**
* |∪ᵢ₌₁ⁿ Aᵢ| = Σ_{∅≠S⊆[n]} (−1)^(|S|+1) · |∩ᵢ∈ₛ Aᵢ|
* **Почему сходится:** элемент, лежащий ровно в k множествах, вносит Σ_{j=1..k} (−1)^{j+1} C(k,j) = 1 (по биному Ньютона: 1 − (1−1)^k = 1), значит считается ровно один раз
* **Количество элементов ровно в k множествах:** aₖ = Σ_{j≥k} (−1)^{j−k} · C(j,k) · gⱼ, где gⱼ = Σ_{|S|=j} |∩ᵢ∈ₛ Aᵢ| (биномиальная инверсия)
* **Сложность:** 2ⁿ−1 подмножеств, каждое |∩| за O(1) после предподсчёта — O(2ⁿ)

### **5.3. Алгоритм перебора подмножеств**
* Перебираем битовую маску S от 1 до 2ⁿ−1; знак по popcount(S); значение f(S) = |∩ᵢ∈ₛ Aᵢ| берём из предподсчёта
* **Границы:** n ≤ 20 перебор всех подмножеств; n ≤ 63 — если маски хранятся в unsigned long long
* **Применения в олимпиадах:** задача о беспорядках (!n = n!·Σ(−1)ᵏ/k!, см. combinatorics), перестановки с запрещёнными позициями, подсчёт чисел, делящихся хотя бы на одно из простых (решето + включения-исключения), задачи «сколько элементов обладают ровно k свойствами», задача о сюръекциях k!·S(n,k)

### **5.4. Пример**
* A = {0,1}, B = {0,2}, C = {1,2}: одиночные |A|=|B|=|C|=2; попарные |A∩B|=|A∩C|=|B∩C|=1; тройное = 0
* |A∪B∪C| = 2+2+2 −1−1−1 +0 = 3 ✓ (универсум {0,1,2} покрыт целиком)
* g₁ = 6, g₂ = 3, g₃ = 0: a₂ = g₂ − 3·g₃ = 3 — каждый элемент лежит ровно в двух множествах ✓

## **6. Булеан, перебор подмножеств и SOS DP (дополнительно для олимпиад)**

### **6.1. Перебор всех подмножеств**
* **Все подмножества универсума:** маска от 0 до 2ⁿ−1 — каждая маска ровно одно подмножество; сложность O(2ⁿ)
* **Все подмножества заданного множества mask:** классический цикл `for (s = mask; ; s = (s−1) & mask)` — перебирает подмаски в порядке убывания; остановка после s = 0
* **Сложность:** 3ⁿ суммарно по всем маскам (каждый элемент: не входит / входит в mask / входит в подмаску)

### **6.2. Zeta-преобразование (суммы по подмножествам, SOS DP)**
* **Задача:** для каждой маски mask посчитать f[mask] = Σ_{sub ⊆ mask} a[sub] — например, сумму весов всех подмножеств
* **Наивно:** O(3ⁿ); **умно:** O(n·2ⁿ)
* **Идея:** dp по битам: dp[mask] после обработки бита i = сумма по всем sub, отличающимся от mask только в битах 0..i−1 (может включать бит i, а может нет); переход: если бит i установлен — добавить значение без бита i
* **Реализация:** цикл по битам i, цикл по всем mask: если mask содержит i, f[mask] += f[mask ^ (1<<i)] — in-place
* **Обратное преобразование (Мёбиуса):** та же схема с вычитанием f[mask] −= f[mask ^ (1<<i)] — восстанавливает a из f
* **Применения:** задача «подсчитать пары (i, j): a[i] & a[j] = 0» (все маски → их дополнения, потом zeta и перемножить с самими собой), задачи на OR/AND по подмножествам, дирихлева свёртка на решётке подмножеств, максимум по подмножеству в задачах на битовые маски

### **6.3. Zeta по надмножествам**
* **Задача:** f[mask] = Σ_{sup ⊇ mask} a[sup] — симметричный вариант (например, «все надмножества маски»)
* **Реализация:** если бит i не установлен — f[mask] += f[mask | (1<<i)]; обратное — вычитание
* **Применение:** задачи «a[i] является подмножеством a[j]», подсчёт надмножеств заданного набора свойств

# **B. ОТНОШЕНИЯ НА МНОЖЕСТВАХ**

## **1. Декартово произведение множеств**

### **1.1. Определение**
* **Определение:** A × B = {(a, b) : a ∈ A, b ∈ B} — множество всех упорядоченных пар
* **Упорядоченность:** (a, b) ≠ (b, a) при a ≠ b — главное отличие от множества {a, b}
* **Мощность:** |A × B| = |A| · |B| (правило произведения)
* **Пример:** {1, 2} × {3, 4, 5} = {(1,3), (1,4), (1,5), (2,3), (2,4), (2,5)} — 6 пар

### **1.2. Декартова степень и обобщение**
* **A² = A × A, Aⁿ = A × ... × A (n раз)** — множество кортежей длины n
* **Обобщение:** A₁ × A₂ × ... × Aₖ = {(a₁, ..., aₖ) : aᵢ ∈ Aᵢ}
* **Мощность:** |A₁ × ... × Aₖ| = ∏|Aᵢ| — правило произведения (комбинаторика)
* **Связь с битовыми масками:** {0,1}ⁿ — в точности множество всех подмножеств n-элементного множества: |{0,1}ⁿ| = 2ⁿ = |2^A| — почему булеан имеет мощность 2ⁿ

## **2. Бинарные отношения**

### **2.1. Определение**
* **Определение:** бинарное отношение между A и B — произвольное подмножество R ⊆ A × B; если A = B — отношение на множестве A
* **Терминология:** (a, b) ∈ R читается «a находится в отношении R с b» (a R b); A — область отправления, B — область прибытия
* **Примеры:** отношение ≤ на ℤ, делимость | на ℕ, равенство =, «быть другом» на множестве людей

### **2.2. Способы задания**
* **Матричный:** булева матрица n×m: R[i][j] = 1 ⟺ (aᵢ, bⱼ) ∈ R — удобно для операций и проверки свойств
* **Графический:** ориентированный граф: вершины A ⊔ B, стрелка a → b для каждой пары (a, b) ∈ R; свойства отношения — свойства графа
* **Перечислением пар:** R = {(a₁, b₁), ..., (aₖ, bₖ)}
* **Характеристическим свойством:** R = {(x, y) : P(x, y)} (например, x < y)

### **2.3. Область определения и область значений**
* **Область определения:** dom R = {a ∈ A : ∃b, (a, b) ∈ R} — из каких элементов выходят стрелки
* **Область значений:** im R = {b ∈ B : ∃a, (a, b) ∈ R} — в какие элементы входят стрелки
* **Связь с матрицей:** dom R — строки с хотя бы одной единицей, im R — столбцы с хотя бы одной единицей

## **3. Операции над отношениями**

### **3.1. Теоретико-множественные операции**
* Отношение — множество пар, поэтому определены ∪, ∩, \: R ∪ S, R ∩ S, R \ S
* **Дополнение** R̅ = (A × B) \ R — все пары, которых нет в R
* **Включение:** R ⊆ S — «R вложено в S» (все пары R есть в S)

### **3.2. Обратное отношение**
* **Определение:** R⁻¹ = {(b, a) : (a, b) ∈ R} ⊆ B × A
* **Интуиция:** развернуть все стрелки; в матрице — транспонирование
* **Свойство:** (R⁻¹)⁻¹ = R; (R ∪ S)⁻¹ = R⁻¹ ∪ S⁻¹; (R ∘ S)⁻¹ = S⁻¹ ∘ R⁻¹ (порядок меняется!)
* **Пример:** R = «быть родителем» → R⁻¹ = «быть ребёнком»

### **3.3. Композиция отношений**
* **Определение:** R ∘ S = {(a, c) : ∃b, (a, b) ∈ R и (b, c) ∈ S} — отношение «сначала R, потом S»
* **Интуиция:** цепочка стрелок длины 2: a → b → c
* **Ассоциативность:** (R ∘ S) ∘ T = R ∘ (S ∘ T) — можно не ставить скобки
* **Дистрибутивность:** R ∘ (S ∪ T) = R ∘ S ∪ R ∘ T (композиция дистрибутивна по объединению)
* **Матрично:** булево умножение матриц: (R∘S)[i][j] = ∨ₖ (R[i][k] ∧ S[k][j]) — «есть путь длины 2 из i в j»
* **Степень:** R⁰ = id (диагональ), Rⁿ = R ∘ R ∘ ... ∘ R (n раз) — пути длины n

### **3.4. Булево умножение матриц**
* **Обычное умножение** заменяем на (∧, ∨): сумма → ИЛИ, произведение → И
* **Сложность:** O(n·m·p) наивно; битовое ускорение: если строки хранить масками — O(n·p·n/64)
* **Применение:** степени отношения, транзитивное замыкание, подсчёт путей длины ровно k (обычное умножение с целыми числами считает КОЛИЧЕСТВО путей, булево — только существование)

## **4. Свойства бинарных отношений**

### **4.1. Рефлексивность и антирефлексивность**
* **Рефлексивность:** ∀a ∈ A: (a, a) ∈ R — на диагонали матрицы все единицы; в графе — петля у каждой вершины
* **Антирефлексивность:** ∀a: (a, a) ∉ R — диагональ нулевая
* **Пример:** ≤ рефлексивно; < антирефлексивно; «перпендикулярно» на прямых антирефлексивно

### **4.2. Симметричность и антисимметричность**
* **Симметричность:** (a, b) ∈ R ⇒ (b, a) ∈ R — матрица симметрична; в графе стрелки парные
* **Антисимметричность:** (a, b) ∈ R и (b, a) ∈ R ⇒ a = b — нет «взаимных» стрелок между разными вершинами
* **Важно:** антисимметричность ≠ несимметричность: R = {(a,b)} антисимметрично; R = {(a,b),(b,a)} симметрично и НЕ антисимметрично
* **Пример:** ≤ антисимметрично (a ≤ b и b ≤ a ⇒ a = b); ≠ симметрично

### **4.3. Транзитивность**
* **Транзитивность:** (a, b) ∈ R и (b, c) ∈ R ⇒ (a, c) ∈ R — «из a в b, из b в c, значит из a в c»
* **Эквивалентно:** R ∘ R ⊆ R (композиция не выводит за пределы отношения)
* **Проверка по матрице:** для всех троек (i, j, k): R[i][j] = R[j][k] = 1 ⇒ R[i][k] = 1; сложность O(n³)
* **Пример:** делимость транзитивна (a|b, b|c ⇒ a|c — см. number-theory A.1), < транзитивно, ≠ НЕ транзитивно

## **5. Отношение эквивалентности**

### **5.1. Определение**
* **Определение:** R — отношение эквивалентности ⟺ рефлексивно, симметрично и транзитивно
* **Интуиция:** «быть равным по какому-то признаку»: равенство, сравнимость по модулю m, параллельность прямых, изоморфизм графов
* **Пример:** равенство по остатку: a ≡ b (mod m) — классы = остатки (см. number-theory B)

### **5.2. Классы эквивалентности и фактор-множество**
* **Класс эквивалентности элемента a:** [a] = {b : (a, b) ∈ R} — все элементы, эквивалентные a
* **Свойства классов:** любые два класса либо совпадают, либо не пересекаются; [a] = [b] ⟺ (a, b) ∈ R
* **Фактор-множество:** A/R = {[a] : a ∈ A} — множество классов
* **Связь с графом:** классы = компоненты связности графа отношения (с учётом петель)

### **5.3. Разбиения множества**
* **Теорема:** отношение эквивалентности ⟺ разбиение множества на классы: каждое разбиение задаёт отношение «лежать в одном блоке», и каждое отношение эквивалентности задаёт разбиение на классы — взаимно однозначно
* **Число разбиений n-элементного множества:** числа Белла B(n) (см. combinatorics/special-sequences)
* **Число разбиений на k блоков:** числа Стирлинга II рода S(n,k) — C(n, k)-подобная таблица (см. combinatorics)

### **5.4. Алгоритмы построения классов**
* **Через граф (BFS/DFS):** O(n²) на матрице отношений — обойти компоненты связности
* **Через DSU (система непересекающихся множеств):** O(n·α(n)) — если отношение задано списком пар
* **Применение в олимпиадах:** компоненты связности графа, группы в задачах «одинаковые по признаку», задачи на mod m классы вычетов

## **6. Отношения порядка**

### **6.1. Частичный порядок**
* **Определение:** R — частичный порядок ⟺ рефлексивно, антисимметрично, транзитивно
* **Примеры:** ≤ на ℤ, ⊆ на множествах, | (делимость) на ℕ, «быть предком»
* **Сравнимые элементы:** a и b сравнимы, если (a,b) ∈ R или (b,a) ∈ R
* **Линейный (полный) порядок:** любые два элемента сравнимы (≤ на ℤ — линейный; ⊆ — нет)

### **6.2. Строгий порядок**
* **Определение:** R строгий ⟺ антирефлексивно и транзитивно (<, ⊂, | на ℕ без равенства)
* **Связь:** из частичного порядка ≤ получаем строгий <, выбросив диагональ: (a,b) ∈ < ⟺ (a,b) ∈ ≤ и a ≠ b

### **6.3. Диаграммы Хассе**
* **Идея:** граф частичного порядка без «транзитивных» рёбер и без петель: рисуем только рёбра x → y, если x < y и нет z: x < z < y; ориентация снизу вверх
* **Зачем:** компактный рисунок структуры порядка; по диаграмме Хассе восстанавливается весь порядок транзитивным замыканием

### **6.4. Топологическая сортировка**
* **Задача:** расположить элементы так, чтобы (a,b) ∈ R ⇒ a стоит раньше b — возможна ⟺ в графе нет циклов (R — частичный порядок)
* **Алгоритм Кана:** повторно берём вершину без входящих рёбер (не помещённую), кладём в ответ, удаляем её исходящие рёбра; O(V + E); если остались вершины — есть цикл
* **Количество топологических сортировок:** DP по подмножествам: cnt[mask] — число корректных порядков элементов из mask; пересчёт добавлением вершины, у которой все предшественники уже в mask; O(n·2ⁿ) — допустимо при n ≤ 20
* **Применения:** планирование зависимостей (make, сборка пакетов), расписание курсов, задача о выполнении работ с условиями «раньше чем»

## **7. Замыкания отношений**

### **7.1. Рефлексивное и симметричное замыкания**
* **Рефлексивное замыкание:** R ∪ id (добавить все петли) — наименьшее рефлексивное отношение, содержащее R
* **Симметричное замыкание:** R ∪ R⁻¹ (добавить обратные стрелки) — наименьшее симметричное
* **Почему «наименьшее»:** замыкание = минимальное расширение R, обладающее свойством (пересечение всех расширений со свойством)

### **7.2. Транзитивное замыкание**
* **Определение:** R⁺ = R ∪ R² ∪ R³ ∪ ... — все пути положительной длины; R* = R⁺ ∪ id — включая пути нулевой длины
* **Интуиция:** «достижимость»: (a,b) ∈ R⁺ ⟺ из a в b идёт путь в графе отношения
* **Свойство:** R⁺ транзитивно; R транзитивно ⟺ R⁺ = R

### **7.3. Алгоритм Уоршалла (Флойда-Уоршалла)**
* **Идея:** пошаговое разрешение промежуточных вершин: после обработки k все пути используют только промежуточные вершины 0..k−1; если R[i][k] и R[k][j] достижимы — достижим R[i][j]
* **Реализация:** три вложенных цикла: for k for i for j: if (R[i][k] && R[k][j]) R[i][j] = 1
* **Сложность:** O(n³), память O(n²)
* **Битовое ускорение:** если строка k достижима из i — добавить целиком строку k в строку i: O(n³/64) на битовых масках
* **Применения:** достижимость в графе, подсчёт компонент сильной связности, проверка антисимметричности после замыкания, задачи «какие пары связаны транзитивно»

## **8. Соответствия, функции, отображения**

### **8.1. Соответствие**
* **Определение:** соответствие между A и B — произвольное подмножество q ⊆ A × B (то же, что бинарное отношение, — термин из классической теории): каждому a может соответствовать несколько b, а может ни одного
* **Терминология:** q(a) = {b : (a, b) ∈ q} — множество образов элемента a; dom q = {a : q(a) ≠ ∅} — область определения, im q = ∪ q(a) — область значений
* **Пример:** q = «быть делителем» на {1, 2, 3, 4, 6, 12}: q(12) = {1, 2, 3, 4, 6, 12} — у элемента несколько образов
* **Реализация:** соответствие — то же, что отношение: матрица n×m (`relation_from_pairs`), все операции над отношениями (B.3) применимы без изменений

### **8.2. Обратное соответствие**
* **Определение:** q⁻¹ ⊆ B × A = {(b, a) : (a, b) ∈ q} — «развернуть все стрелки»
* **Интуиция:** если q — «быть делителем» (12 делится на 2), то q⁻¹ — «быть кратным» (образ 2 в q⁻¹ — это 12)
* **Свойства:**
  * (q⁻¹)⁻¹ = q — двойное обращение возвращает исходное соответствие
  * dom q⁻¹ = im q, im q⁻¹ = dom q — область определения и значений меняются местами
  * (r ∘ q)⁻¹ = q⁻¹ ∘ r⁻¹ — обращение композиции меняет порядок сомножителей
  * q⁻¹(q(a)) ⊇ {a} — образ a в обратном соответствии может содержать и другие элементы (если q не взаимно-однозначно)
* **Когда является функцией:** q⁻¹ — функция ⟺ q — биекция (см. 8.5): только тогда у каждого b ровно один прообраз
* **Реализация:** `relation_inverse` (транспонирование матрицы), O(n·m)

### **8.3. Композиция (суперпозиция) соответствий**
* **Определение:** для q ⊆ A × B и r ⊆ B × C: r ∘ q = {(a, c) : ∃b ∈ B, (a, b) ∈ q и (b, c) ∈ r} — применить последовательно: сначала соответствие q, потом r
* **Образ элемента:** (r ∘ q)(a) = ∪_{b ∈ q(a)} r(b) = {c : ∃b ∈ q(a), (b, c) ∈ r} — объединение образов всех b, соответствующих a
* **Интуиция:** «пути длины 2»: a → b → c; композиция соответствий — то же, что композиция отношений (B.3.3), но в терминах образов
* **Ассоциативность:** (s ∘ r) ∘ q = s ∘ (r ∘ q) — можно опускать скобки
* **Дистрибутивность:** r ∘ (q₁ ∪ q₂) = (r ∘ q₁) ∪ (r ∘ q₂)
* **Пример:** q = {(1, a), (1, b), (2, b)}, r = {(a, x), (b, x), (b, y)}: (r ∘ q)(1) = r(a) ∪ r(b) = {x} ∪ {x, y} = {x, y}; (r ∘ q)(2) = r(b) = {x, y}
* **Реализация:** `relation_compose` (булево умножение матриц), O(n·m·p)

### **8.4. Функция (отображение)**
* **Определение:** f: A → B — функция, если каждому a ∈ A соответствует ровно один b ∈ B: ∀a ∈ A ∃!b: (a, b) ∈ f
* **Отличие от соответствия:** у функции каждый элемент a имеет образ (всюду определённость: dom f = A) и ровно один (однозначность); у соответствия это не требуется
* **В матрице:** в каждой строке ровно одна единица — проверка `is_function`
* **Терминология:** f(a) — образ a; dom f = A, im f ⊆ B; A — область определения, B — область значений (кодомен)
* **Способы задания:** таблица, формула, массив f[i] в программировании, граф (у каждой вершины ровно один исходящий переход — функциональный граф)

### **8.5. Инъекция, сюръекция, биекция**
* **Инъекция (взаимно-однозначное, 1–1):** f(a₁) = f(a₂) ⇒ a₁ = a₂ — разные элементы в разные образы; в графе в каждую вершину не более одной стрелки
* **Сюръекция (на):** ∀b ∈ B ∃a: f(a) = b — образы покрывают весь кодомен B; im f = B
* **Биекция:** инъекция + сюръекция = взаимно-однозначное соответствие между A и B — «пересчёт»: элементы A и B можно сопоставить попарно
* **Следствия для мощностей:** биекция A ↔ B ⟺ |A| = |B|; инъекция A → B ⟺ |A| ≤ |B|; сюръекция ⟺ |A| ≥ |B| (конечные множества)
* **Применения:** биективный метод в комбинаторике (см. combinatorics B), пересчёт объектов, задачи «докажите, что отображение биективно»

### **8.6. Обратная функция**
* **Определение:** обратная функция f⁻¹ — это обратное соответствие (8.2), которое само является функцией; существует ⟺ f биективна
* **Почему:** у не-инъективной f одному b отвечают несколько a (не однозначно); у не-сюръективной b остаются без прообраза (не всюду определена на B)
* **Свойство:** (f⁻¹ ∘ f) = id_A, (f ∘ f⁻¹) = id_B для биекции
* **Пример:** f(x) = 2x на ℤ: f⁻¹(y) = y/2; на ℕ та же f⁻¹ не функция (нечётные y без прообраза) — функция зависит от области определения
* **Реализация:** `function_inverse` — g[f[i]] = i, O(n)

### **8.7. Композиция функций**
* **Определение:** (g ∘ f)(x) = g(f(x)) — сначала f, потом g; частный случай композиции соответствий (8.3), когда оба соответствия — функции
* **Ассоциативность:** (h ∘ g) ∘ f = h ∘ (g ∘ f)
* **Свойства:** композиция инъекций — инъекция, сюръекций — сюръекция, биекций — биекция
* **Пример:** f = {0→1, 1→2, 2→0}, g = {0→0, 1→2, 2→1}: (g ∘ f)(0) = g(1) = 2, (g ∘ f)(1) = g(2) = 1, (g ∘ f)(2) = g(0) = 0 → g∘f = {0→2, 1→1, 2→0}
* **Реализация:** `function_compose` — h[i] = g[f[i]], O(n)

### **8.8. Функциональные графы (дополнительно для олимпиад)**
* **Определение:** граф функции f: A → A — ориентированный граф, у каждой вершины ровно один исходящий переход (стрелка x → f(x))
* **Структура:** каждая компонента связности = «хвост» (путь) + цикл: из любой вершины, идя по стрелкам, обязательно попадаем в цикл (единственный в компоненте)
* **Алгоритм анализа (снятие листьев):** индексы вершин; вершины с нулевой входящей степенью не в циклах — убираем их, понижая входящие степени следующих; оставшиеся — ровно вершины циклов; расстояние до цикла = порядок удаления; O(n)
* **Длина цикла (заяц и черепаха):** два указателя: медленный x → f(x), быстрый x → f(f(x)); когда встретились — идём по кругу, пока не вернёмся; O(длина цикла)
* **Применения:** задачи «идём по переходу, пока не зациклимся» (функция next, клеточный автомат, псевдослучайные последовательности), задачи про «вечность» процессов, определение момента попадания в цикл и его длины
