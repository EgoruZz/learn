## **A. ОСНОВНЫЕ ПРИНЦИПЫ И ФИЛОСОФИЯ ДП**
> `a/a.md` · `a/a.cpp` · `struct DPBasics` — базовый класс всей ветки

### Основные понятия и принципы
- 0. Основные понятия и принципы: ДП — парадигма, а не алгоритм: состояние / переход / база / порядок; критерии применимости — оптимальная подструктура и перекрытие подзадач; принцип Беллмана и его нарушение («память» → расширение состояния); границы — NP-трудные задачи (экспоненциальные состояния)

### A. Фундаментальные принципы
- A.1 Оптимальная подструктура (Optimal Substructure): оптимальное решение задачи строится из оптимальных решений подзадач; критерий применимости ДП
- A.2 Перекрывающиеся подзадачи (Overlapping Subproblems): подзадачи повторяются — иначе не ДП, а полный перебор
- A.3 Принцип оптимальности Беллмана: оптимальная политика независима от предыстории — только от текущего состояния; когда принцип нарушается (задачи с памятью, зависимостью от пути)
- A.4 ДП как функциональное уравнение: `f(s) = opt_{переходы} (g(f(s')) + цена(s, s'))` — единая форма для всех задач ДП
- A.5 Рекуррентные соотношения как математическая основа ДП: определение последовательностей через предыдущие члены; порядок вычисления
- A.6 Принцип индукции в ДП: база + шаг; доказательство корректности ДП индукцией по состоянию; обоснование оптимальности через обмен аргументов (exchange argument)
- A.7 Теория сложности для ДП: классы P, NP, #P; PSPACE-complete задачи; связь «решения в NP, подсчёта в #P»; где ДП делает задачи полиномиальными, а где NP-трудность остаётся (только псевдополиномиальность)

### B. Подходы к реализации
- B.1 Мемоизация (Top-Down): рекурсия + запоминание — `O(состояний · переходов)` времени, размер стека; перебор достижимых состояний
- B.2 Табуляция (Bottom-Up): заполнение таблицы в порядке зависимостей; контроль порядка циклов
- B.3 Сравнение подходов: скорость, восстановление ответа, обработка больших состояний, переполнение стека
- B.4 Восстановление ответа: хранение `prev`-массивов, обратный проход
- B.5 Поглощение констант: общий вид состояний и переходов без фиксированных границ (обобщение на произвольные `n`, `k`, `m`)

## **B. ОДНОМЕРНАЯ ДИНАМИКА**
> `b/b.md` · `b/b.cpp` · `struct LinearDP : DPBasics`

### Основные понятия и принципы
- 0. Основные понятия и принципы: почему одномерная ДП выделяется — состояние — одна координата (позиция префикса), «последний шаг» разбивает префикс на подзадачи, естественный порядок слева направо; распознавание (задача на последовательности) и границы (две координаты — C, «память» — расширение состояния)

### A. Классические задачи
- B.1 Climbing Stairs: `f(n) = f(n−1) + f(n−2)` — обобщение: шаги длиной от `1` до `k`: `f(n) = Σᵢ f(n−i)`; восхождение с ограничениями (не более `t` подряд по лестнице типа m)
- B.2 Fibonacci, Tribonacci: `T(n) = T(n−1) + T(n−2) + T(n−3)` — обобщение: линейная рекуррента порядка `k` через матрицу `k×k`
- B.3 House Robber / Max Non Adjacent Sum: `dp[i] = max(dp[i−1], dp[i−2] + a[i])`; кольцевой вариант (первый и последний связаны) — два прохода без одного из концов
- B.4 Max Subarray Sum (алгоритм Кадане): `best = max(best + a[i], a[i])`; обобщение: минимальный подотрезок (знаки), подотрезок с ограничением длины — скользящее окно с deque (см. J)
- B.5 Minimum Steps To One: `f(n) = 1 + min(f(n−1), f(n/2), f(n/3))` при делимости; обобщение на произвольные операции с ценой `cᵢ`
- B.6 Minimum Coin Change: `dp[s] = min(dp[s − cᵢ]) + 1` для всех монет `cᵢ ≤ s` — бесконечность для недостижимых сумм; восстановление набора монет
- B.7 Minimum Tickets Cost: ДП по дням `dp[d] = min(прошлый день, покупка билета на 1/7/30 дней назад)` — обобщение: произвольные длительности и цены билетов
- B.8 Задача Иосифа Флавия (Josephus): `J(n,k) = (J(n−1,k) + k) mod n`, `J(1,k) = 0` — рекуррентность по размеру круга; индексация с 1: `+1`; быстрый вариант для больших n: `O(k·log n)` прыжками по блокам (`josephus_fast`); обобщение: выбывание с `m` перешагиваний, первые `m` выживших

### B. Комбинаторная динамика
- B.9 Combination Sum IV: `dp[s] = Σᵢ dp[s − cᵢ]` — порядок важен; отличие от размена монет (порядок не важен)
- B.10 Размен монет (количество способов): `dp[s] += dp[s − cᵢ]` с внешним циклом по монетам — подсчёт способов без учёта порядка; обобщение: ограниченный запас монет
- B.11 Подсчёт путей в сетке: `f(i, j) = f(i−1, j) + f(i, j−1)` — одномерная формула `f(n) = C(n₁ + n₂, n₁)`; с запрещёнными клетками — см. C
- B.12 Catalan Numbers: различные интерпретации (скобочные последовательности, бинарные деревья, триангуляции, монотонные пути не выше диагонали)
- B.13 Беспорядки (Derangements): `D(n) = (n−1)·(D(n−1) + D(n−2))`, `D(1) = 0, D(2) = 1` — перестановки без неподвижных точек; альтернативная рекуррентность `D(n) = n·D(n−1) + (−1)ⁿ`; частичные беспорядки (ровно `k` неподвижных точек): `C(n,k)·D(n−k)`; через включения-исключения: `D(n) = n!·Σ(−1)ⁱ/i!`; асимптотика `⌊n!/e + 1/2⌋`

### C. Дополнительные олимпиадные задачи
- B.14 Decode Ways: `dp[i] = dp[i−1]·[aᵢ ≠ 0] + dp[i−2]·[10 ≤ aᵢ₋₁aᵢ ≤ 26]` — обобщение на алфавит из `m` цифр
- B.15 Best Time to Buy and Sell Stock (серия): 1 транзакция, `k` транзакций: `dp[t][d] = max(dp[t][d−1], price[d] + max(dp[t−1][d'] − price[d']))` — обобщение с комиссией и cooldown
- B.16 Jump Game: `dp[i] = ∃j < i: dp[j] и j + a[j] ≥ i` — достижимость; вариант с минимальным числом прыжков (жадный/ДП)
- B.17 Ugly Numbers: слияние последовательностей `×p₁, ×p₂, ..., ×pₖ` через указатели — обобщение на `k` простых множителей
- B.18 Perfect Squares: `dp[n] = min(dp[n − k²]) + 1` — минимальное число слагаемых-квадратов; обобщение на произвольные множества чисел
- B.19 Paint Fence: `same[i] = diff[i−1]`, `diff[i] = (same[i−1] + diff[i−1])·(k−1)` — обобщение: не более `t` одинаковых подряд — числа Фибоначчи порядка `t`
- B.20 Delete and Earn: сжатие по значениям → House Robber на массиве сумм по значениям
- B.21 Maximum Length of Pair Chain / Activity DP: сортировка + одномерная ДП по второму элементу
- B.22 Подотрезок с ограничением длины k (обобщение B.4): максимальная сумма подотрезка длины ≤ `k` — префиксные суммы + монотонная очередь (deque) `O(n)` времени, `O(k)` памяти (задел на J)

## **C. ДВУМЕРНАЯ И МНОГОМЕРНАЯ ДИНАМИКА**
> `c/c.md` · `c/c.cpp` · `struct MatrixDP : LinearDP`

### Основные понятия и принципы
- 0. Основные понятия и принципы: почему двумерная/многомерная ДП выделяется — состояние — кортеж независимых координат (две позиции, позиция + ограничение, клетка сетки); направление циклов семантическое (0/1- и неограниченный выбор); границы — k ограничений дают k-мерную таблицу

### A. Динамика на матрицах и путях
- C.1 Minimum Cost Path: `dp[i][j] = cost(i, j) + min(dp[i−1][j], dp[i][j−1])`; обобщение на 3 направления (8 соседей — уже граф), на веса `wᵢⱼ ≥ 0` произвольные
- C.2 Unique Paths: `C(m+n−2, m−1)` без препятствий; с препятствиями — `dp[i][j] = (dp[i−1][j] + dp[i][j−1])·[клетка свободна]`; подсчёт путей с ограничением на число поворотов/на собранные значения
- C.3 Maximum Path Sum в треугольнике/матрице: `dp[i][j] = a[i][j] + max(dp[i−1][j−1], dp[i−1][j])`; в матрице — `max(dp[i−1][j], dp[i][j−1])` с началами в любой клетке первого столбца
- C.4 Trapped Water (2D): симуляция подъёма воды с границ через приоритетную очередь (минимум среди «открытых» клеток) — `O(mn·log(mn))`; обобщение: высоты произвольные, уровень воды с учётом переливов
- C.5 Maximal Square: `dp[i][j] = 1 + min(dp[i−1][j], dp[i][j−1], dp[i−1][j−1])` при `a[i][j] = 1` — обобщение на прямоугольники (гистограмма + стек)
- C.6 Maximal Rectangle / Maximum Sum Submatrix: префиксные суммы по столбцам + Кадане по строкам — `O(m²n)`; обобщение: сумма ≥ K
- C.7 Dungeon Game: ДП от конца к началу: `need[i][j] = max(1, min(need[i+1][j], need[i][j+1]) − a[i][j])`
- C.8 Cherry Pickup: обратный путь эквивалентен второму пути — две «машины» идут одновременно; инвариант `i₁ + j₁ = i₂ + j₂ = t`, состояние `(t, i₁, i₂)`; `O(n³)` времени, `O(n²)` памяти
- C.9 Count Square Submatrices: `dp[i][j] = 1 + min(...)`; сумма всех `dp` — число всех квадратных подматриц с единицами
- C.10 Не бьющие слоны на доске n×n (из комбинаторики): диагонали цвета `(r+c) mod 2` независимы — два ДП по «лестнице Феррера»: длины диагоналей одного цвета `len(s) = min(s, 2n−2−s) + 1` (s = цвет, цвет+2, ...), сортировка по возрастанию; `dp[i][j] = dp[i−1][j] + dp[i−1][j−1]·(h_i − j + 1)` — O(n²); ответ для k слонов: `Σ_j dp_чётный[j]·dp_нечётный[k−j]`; обобщение: ладьи на ступенчатой доске (Феррера), максимальное число — `2n−2`

### B. Сравнительная динамика (Sequence Alignment)
- C.11 Edit Distance (Левенштейн): `dp[i][j] = min(dp[i−1][j]+1, dp[i][j−1]+1, dp[i−1][j−1] + [aᵢ ≠ bⱼ])`; обобщение: произвольные веса операций (insert/delete/substitute = `α, β, γ`); восстановление выравнивания; сжатие через ДП по более короткой строке
- C.12 Longest Common Subsequence (LCS): `dp[i][j] = dp[i−1][j−1] + 1` при равенстве, иначе `max(dp[i−1][j], dp[i][j−1])`; восстановление; сведение LIS для перестановок: LCS = LIS по индексам второй строки
- C.13 Longest Common Substring: совпадения — `dp[i][j] = dp[i−1][j−1] + 1`, иначе сброс в 0; максимум по всей таблице; суффиксный массив как альтернатива
- C.14 Wildcard Matching: `?` — одна буква, `*` — любая последовательность; `dp[i][j]` с поглощением `*` (`dp[i][j−1]` — `*` пуст, `dp[i−1][j]` — `*` съедает букву)
- C.15 Regex Match: `'.'` — одна буква, `x*` — ноль и более повторений предыдущего; два перехода для `*`: пропустить пару (`dp[i][j−2]`) или съесть букву при совпадении (`dp[i−1][j]`)
- C.16 Abbreviation: префикс можно удалять, заглавные должны совпадать — `dp[i][j]` с двумя ветками (удалить/проверить заглавную)
- C.17 Smith-Waterman (локальное выравнивание): `dp[i][j] = max(0, dp[i−1][j−1] + s(aᵢ,bⱼ), dp[i−1][j] − g, dp[i][j−1] − g)` — максимум по всей матрице
- C.18 Needleman-Wunsch (глобальное выравнивание): как Edit Distance с весами: `dp[i][j] = max(dp[i−1][j−1] + s(aᵢ,bⱼ), dp[i−1][j] − g, dp[i][j−1] − g)`; общая схема выравнивания — единая параметризация `(s, g)`, всё остальное — частные случаи

### C. Рюкзачные задачи (Knapsack DP)
- C.19 0-1 Knapsack: `dp[w] = max(dp[w], dp[w − cᵢ] + vᵢ)` — цикл по весам вниз; `O(nW)`; обобщение: огромные `W` — ДП по ценности `dp[v] = min вес`; восстановление набора
- C.20 Неограниченный рюкзак (Unbounded): тот же переход, цикл по весам вверх — один предмет сколько угодно раз; математика: `f(w) = maxᵢ (f(w − cᵢ) + vᵢ)`
- C.21 Рюкзак с повторениями (Bounded): ограниченный запас `kᵢ` каждого предмета; двоичное разбиение `kᵢ` на `1, 2, 4, ...` → 0-1 рюкзак; монотонная очередь для полного `O(nW)`
- C.22 Minimum Partition: `min|S₁ − S₂| = S − 2·dp[S/2]` — подмножество с суммой максимально близкой к половине
- C.23 Sum of Subset: `dp[s] |= dp[s − cᵢ]` — достижимость сумм; счёт вариантов; большие суммы — meet-in-the-middle (см. E)
- C.24 Target Sum: `±` операции: `dp[s ± cᵢ]`; сведение к Partition: `(S + target)/2`; обобщение на `aᵢ·xᵢ` с коэффициентами
- C.25 Largest Divisible Subset: сортировка + LIS-подобная ДП: `dp[i] = max(dp[j]) + 1` при `a[i] % a[j] == 0`
- C.26 Coin Change (минимум монет / количество способов): минимум — B.6, способы — B.10; обобщение: монеты с весами (стоимостью) — 2D-рюкзак: `dp[c][s]`
- C.27 2D-рюкзак (объём + вес): `dp[w][c] = max(dp[w][c], dp[w−cᵢ][c−pᵢ] + vᵢ)` — два измерения состояния
- C.28 Count of subsets with sum S: `dp[s] += dp[s − cᵢ]` по числу предметов — комбинаторная вариация C.23

## **D. ДИНАМИКА ПО ОТРЕЗКАМ И ПОДСТРОКАМ**
> `d/d.md` · `d/d.cpp` · `struct SegmentDP : MatrixDP`

### Основные понятия и принципы
- 0. Основные понятия и принципы: почему интервальная ДП выделяется — «последнее действие» происходит внутри отрезка и делит его на две независимые части; порядок вычисления — по длине (диагонали таблицы); распознавание (склейка/разрез отрезков) и границы (Knuth — J)

### A. Оптимизация разбиений (Interval DP)
- D.1 Matrix Chain Multiplication: `dp[i][j] = minₖ (dp[i][k] + dp[k+1][j] + p[i−1]·p[k]·p[j])` — порядок умножения матриц; восстановление расстановки скобок; Knuth-оптимизация (см. J)
- D.2 Matrix Chain Order: восстановление порядка; вариант с разными ценами скобок
- D.3 Palindrome Partitioning: минимальное число палиндромных частей — `dp[i] = 1 + min(dp[j])` по палиндромным `j+1..i`; предподсчёт палиндромов `pal[i][j]`; вариант — все разбиения (перебор)
- D.4 Optimal Binary Search Tree: `dp[i][j] = minₖ (dp[i][k−1] + dp[k+1][j]) + Σ p[i..j]` — дерево с минимальной взвешенной глубиной; префиксные суммы; Knuth-оптимизация
- D.5 Rod Cutting: `dp[n] = max(dp[n − i] + p[i])` — цена разрезания стержня; связь с неограниченным рюкзаком
- D.6 Burst Balloons: `dp[i][j] = maxₖ (dp[i][k−1] + dp[k+1][j] + a[i−1]·a[k]·a[j+1])` — «заполнение снаружи внутрь» — канонический пример интервальной ДП с убиранием последнего
- D.7 Scramble String: `dp[i][j][len]` — сравнение подстрок с рекурсивной свёрткой и обменом половинок
- D.8 Partition Array for Maximum Sum: `dp[i] = max(dp[i − l] + l·max(последние l))` — разбиение с ограничением длины куска
- D.9 Minimum Cost to Merge Stones: `dp[i][j] = minₖ dp[i][k] + dp[k+1][j] + prefix[j] − prefix[i−1]` при `(j−i) % (K−1) == 0` — слияние с ограничением на кучу
- D.10 Minimum Score Triangulation: триангуляция многоугольника: `dp[i][j] = minₖ (dp[i][k] + dp[k][j] + a[i]·a[k]·a[j])` — обобщение Catalan-структур

### B. Динамика на подстроках
- D.11 Longest Palindromic Subsequence (LPS): `dp[i][j] = dp[i+1][j−1] + 2` при равенстве, иначе `max(dp[i+1][j], dp[i][j−1])`; число палиндромных подпоследовательностей: `dp[i][j] = dp[i+1][j] + dp[i][j−1] − dp[i+1][j−1]` при неравенстве, `+1` иначе
- D.12 Longest Palindromic Substring: расширение от центров `O(n²)`; Manacher `O(n)`; подсчёт палиндромных подстрок `cnt`
- D.13 Minimum Insertions to Make Palindrome: `n − LPS`; обобщение: удаления и замены с весами — путь между строками (Edit Distance обобщение)
- D.14 Longest Increasing Subsequence: `dp[i] = max(dp[j]) + 1` для `j < i, a[j] < a[i]` — `O(n²)`; `O(n log n)`: `d[l]` — минимальный хвост LIS длины `l` (пасьянс/бинарный поиск); восстановление ответа через `prev`; счёт числа LIS; строгий/нестрогий (`lower_bound`/`upper_bound`)
- D.15 Max Product Subarray: `dpMin[i], dpMax[i]` — пара минимум/максимум (отрицательные числа меняют знак): `mx = max(a, mx·a, mn·a)`, `mn = min(a, mx_old·a, mn_old·a)`
- D.16 Longest Repeating Subsequence: LCS строки с самой собой, но `i ≠ j`
- D.17 Count Palindromic Substrings: расширение от центров с подсчётом; обобщение: подстроки с разными длинами и центрами (нечётные/чётные)
- D.18 Count Distinct Subsequences: `dp[i] = 2·dp[i−1] − dp[last[aᵢ] − 1]` — вычитание дублей по последнему вхождению; обобщение на алфавит произвольного размера
- D.19 Подотрезок с суммой ≤ K (1D-ядро C.6): максимальная сумма подотрезка с ограничением — формализация ядра из C.6
- D.20 Longest Bitonic Subsequence: LIS слева + LIS справа: `dp₁[i] + dp₂[i] − 1` — обобщение: число горных максимумов
- D.21 Maximum Sum Increasing Subsequence: `dp[i] = a[i] + max(dp[j])` при `a[j] < a[i]` — сумма вместо длины
- D.22 Count Subsequences with Sum S (двумерный вариант по позиции и сумме)

## **E. ДИНАМИКА ПО ПОДМНОЖЕСТВАМ (БИТОВЫЕ МАСКИ)**
> `e/e.md` · `e/e.cpp` · `struct SubsetDP : SegmentDP`

### Основные понятия и принципы
- 0. Основные понятия и принципы: почему ДП по подмножествам выделяется — состояние — битовая маска подмножества, пространство 2ⁿ (n ≤ 20–25); порядок обработки не фиксирован, порядок табуляции — по popcount; паттерн «маска + последний элемент»; границы (n > 25 — структура задачи, доски — F)

### A. Основные техники
- E.1 Bitmask: представление подмножества числом, `n ≤ 20–25`; `popcount`, проверка бита, `lowbit`
- E.2 Iterating Through Submasks: `for (sub = mask; ; sub = (sub−1) & mask)` (включая пустую подмаску) — суммарно `O(3ⁿ)` по всем маскам
- E.3 Subset Generation: все подмножества, подмаски с перечислением в порядке размера
- E.4 All Construct: перебор всех способов построения множества из частей — `dp[mask] = Σ dp[mask \ part]` для всех валидных `part ⊆ mask`

### B. Классические задачи
- E.5 Задача коммивояжера (TSP): `dp[mask][v] = min(dp[mask \ {v}][u] + w[u][v])` — `O(2ⁿn²)`; восстановление маршрута
- E.6 TSP с возвратом в старт: замкнутый цикл — база `dp[1][0] = 0`, ответ `min_v dp[full][v] + w[v][0]`
- E.7 TSP с метрикой/без метрики: неравенство треугольника — жадные эвристики; без метрики — только точное ДП
- E.8 Bitonic TSP: точки отсортированы по x, два монотонных пути от самой левой точки к самой правой: `dp[i][j]` (i > j — концы путей); при `j < i−1`: `dp[i][j] = dp[i−1][j] + d(i−1, i)`, при `j = i−1`: `dp[i][i−1] = minₖ (dp[i−1][k] + d(k, i))`; `O(n²)`
- E.9 Assignment Problem (назначение): `dp[mask] = min_{i ∈ mask} (dp[mask \ {i}] + cost[popcount(mask) − 1][i])` — рабочие добавляются по одному; Hungarian `O(n³)` как альтернатива
- E.10 Hamiltonian Path/Cycle: `dp[mask][v]` — существование; подсчёт числа путей/циклов
- E.11 Maximum Clique / Independent Set: через маски или перебор с брутфорсом `2ⁿ`; на графах малого размера
- E.12 Set Cover / Partition: `dp[mask] = 1 + min(dp[mask \ cover])` — покрытие подмножествами; минимум/счёт способов
- E.13 Перестановки с запрещёнными позициями (задача о ладьях, из комбинаторики): `R_r` — число способов расставить r не бьющих ладей на запрещённых клетках доски n×n; ДП по маскам `O(n·2ⁿ)` для малых n; ответ через включения-исключения: `Σ_{r=0}^{n} (−1)^r·R_r·(n−r)!`; частный случай `Sᵢ = {i}` — беспорядки (см. B.13)

### C. Оптимизации
- E.14 Meet-in-the-middle: разбиение на две половины, списки частичных сумм/масок, двоичный поиск — `O(2^(n/2))` памяти и времени; применение к Sum of Subset, TSP-подобным, задачам с `n ≈ 40`
- E.15 SOS DP (Sum over Subsets): `dp[mask][bit]` → `f[mask] = Σ_{sub ⊆ mask} a[sub]` за `O(n·2ⁿ)`; варианты: `sum`, `max`, `count`; обратное преобразование (супермножества)
- E.16 Number of Ways to Wear Different Hats: ДП по шляпам, маска — множество уже одетых людей: `ndp[mask | (1 << i)] += dp[mask]`; оптимизация по меньшей стороне (маска по людям или по шляпам)
- E.17 Partition to K Equal Sum Subsets: `dp[mask]` — достижимые суммы с максимумом ≤ target; жадная эвристика + ДП
- E.18 Matching: совершенное паросочетание в графе `n ≤ 20`: `dp[mask] = Σ dp[mask \ {i, j}]` для пар
- E.19 Travelling Salesman с восстановлением и оптимизацией порядка состояний (внешний цикл по popcount)

## **F. ДИНАМИКА ПО ПРОФИЛЮ**
> `f/f.md` · `f/f.cpp` · `struct ProfileDP : SubsetDP`

### Основные понятия и принципы
- 0. Основные понятия и принципы: почему профильная ДП выделяется — экспонента только по ширине доски m, полином по длине n; локальность перехода — будущее зависит от прошлого лишь через линию разлома; «клетка за клеткой» (Plug DP), метки компонент для связности; границы (большие m — экспонента неустранима)

### A. Основные понятия
- F.1 Профиль: состояние границы — битовая маска длины `m` (бит = клетка границы занята)
- F.2 Переходы между профилями: совместимость профилей соседних строк: `dp[row][mask] = Σ dp[row−1][prev]` по совместимым `prev`
- F.3 Подход «клетка за клеткой» (Plug DP): переход по каждой клетке с обработкой границы; профиль хранит состояние текущей линии разлома

### B. Задачи на замощение
- F.4 Домино 2×N: `F(n) = F(n−1) + F(n−2)` — числа Фибоначчи; обобщение: разные наборы фигур — матричный переход
- F.5 Домино M×N: `dp[row][mask] = Σ dp[row−1][prev]`; совместимость — перебор `3^m` или предподсчёт DFS-переходов; ответ при `mask = 0`; нечётное число клеток → 0
- F.6 Замощение с дефектами (дырками): запрещённые клетки помечаются занятыми в профиле
- F.7 Тримино (L-образные): замощение без дефектов; с одной дыркой — рекурсивное разбиение `2^k × 2^k` на четыре квадранта (классическая задача «игра с дыркой»); количество способов — ДП по профилю с L-образными переходами
- F.8 Полимино (тетримино и др.): фиксированные фигуры как наборы переходов профилей; перебор всех поворотов/отражений
- F.9 Обобщённое замощение: различными фигурами; с учётом симметрий (отождествление замощений с точностью до поворотов/отражений — счёт классов эквивалентности)
- F.10 Подсчёт числа способов покрытия: `dp` в модуле; варианты с запретами на клетки и фигуры
- F.11 Задачи на мосты и соединения: замощение «путями» (каждый ход связывает пары клеток), профиль с номерами компонент связности

### C. Другие задачи
- F.12 Minimum Squares To Represent A Number: `dp[n] = 1 + min(dp[n − k²])` — одномерная ДП (мост из профильной темы)
- F.13 Connected-компонентный профиль: профиль с номерами компонент связности; Plug DP — счёт гамильтоновых циклов на доске `m×n` (замыкание цикла — только в последней клетке); применение к задачам с требованиями связности
- F.14 Замощение с цветами/рисунками: профиль кодирует цвет клеток границы

## **G. ДИНАМИКА НА ДЕРЕВЬЯХ**
> `g/g.md` · `g/g.cpp` · `struct TreeDP : ProfileDP`

### Основные понятия и принципы
- 0. Основные понятия и принципы: почему ДП на деревьях выделяется — ацикличность и декомпозиция на непересекающиеся поддеревья (post-order); полином там, где на общих графах NP-трудность (MIS, MVC, паросочетание); rerooting (два прохода down/up) — ответ для всех корней; центроидное разложение — «все пути через центроид»

### A. Классификация задач
- G.1 Динамика на корневом дереве: фиксированный корень, поддеревья — `dp[v]` вычисляется от листьев к корню (post-order)
- G.2 Динамика на произвольном дереве (переподвешивание): rerooting — вычисление ответа для каждого корня за `O(n)` суммарно

### B. Типовые состояния
- G.3 `dp[v][0/1]` — вершина v не включена/включена в структуру; сумма по детям с независимыми вариантами
- G.4 DP на независимое множество: `dp[v][1] = 1 + Σ dp[c][0]`, `dp[v][0] = Σ max(dp[c][0], dp[c][1])` — максимум; счёт способов, восстановление
- G.5 DP на вершинное покрытие: `dp[v][1] = 1 + Σ min(dp[c][0], dp[c][1])`, `dp[v][0] = Σ dp[c][1]`; связь: покрытие = `n −` независимое множество
- G.6 DP на доминирующее множество: `dp[v][0/1/2]` (выбрана / не выбрана, но доминируется ребёнком / ждёт доминирования от родителя) — три состояния; состояние 2 недопустимо для корня
- G.7 Maximum Matching на дереве: `dp[v][0/1]` — ребро к родителю использовано или нет; `O(n)`

### C. Примеры задач
- G.8 Binary Tree Path Sum: суммы путей от корня к листу; максимальная сумма пути между любыми двумя вершинами (диаметр-обобщение через `max(left) + max(right)`)
- G.9 Maximum Sum BST: на поддеревьях — валидность BST и сумма: `(min, max, sum, valid)` снизу вверх
- G.10 Maximum Independent Set на дереве (см. G.4)
- G.11 Minimum Vertex Cover на дереве (см. G.5)
- G.12 Maximum Matching на дереве (см. G.7)
- G.13 Tree Diameter через DP: два прохода DFS от произвольной вершины (самая дальняя, затем от неё) или однопроходное ДП `max(child) + второй max(child)`; взвешенный вариант
- G.14 Подсчёт поддеревьев с определёнными свойствами: размер, диаметр ≤ k, число листьев — ДП по размерам (рюкзак на дереве `O(n²)`)
- G.15 Сумма расстояний до всех вершин: rerooting — перенос через ребро: `ans[to] = ans[v] + n − 2·sz[to]`
- G.16 Kth Ancestor / бинарный подъём: как основа для ДП на деревьях (задел, не ДП)
- G.17 Tree Knapsack: предметы на вершинах, рюкзак в поддереве: `dp[v][s] = max(dp[c][t] + dp[v][s−t])` — слияние детей `O(n²)` суммарно

### D. Специальные техники
- G.18 Rerooting DP (переподвешивание корня): общая схема — `down[v]` в поддереве, `up[v]` вне поддерева; перенос значений через ребро
- G.19 DP на centroid decomposition: центроидное дерево, ДП по уровням разложения; применение: задачи «все пути через центроид»
- G.20 Tree DP с ограничениями на размер компонент: `dp[v][s]` — размеры компонент после удаления рёбер; подсчёт разбиений на компоненты размера ≤ k / кратные k

## **H. ДИНАМИКА НА ГРАФАХ (DAG И НЕ ТОЛЬКО)**
> `h/h.md` · `h/h.cpp` · `struct GraphDP : TreeDP`

### Основные понятия и принципы
- 0. Основные понятия и принципы: почему ДП на графах выделяется — циклы ломают естественный порядок вычисления; на DAG порядок даёт топологическая сортировка; графы с циклами — свёртки к ДП-формам (по промежуточным вершинам, по числу шагов); сведения к двудольным паросочетаниям (Кёниг, покрытие путей)

### A. На Directed Acyclic Graph (DAG)
- H.1 Нахождение количества путей: `dp[v] = Σ_{(u,v)} dp[u]` в топологическом порядке; между парой вершин, модификации
- H.2 Нахождение самого длинного/короткого пути: `dp[v] = max/min_{(u,v)} dp[u] + w(u,v)` — ДП после топологической сортировки `O(V + E)`; восстановление пути
- H.3 Word Break: разбиение строки по словарю: `dp[i] = ∃j: dp[j] && s[j..i) ∈ dict` — `O(n²)` с хешами/trie; обобщение: подсчёт способов, ограничения
- H.4 Word Ladder: преобразование слов по одному шагу: BFS-уровни + ДП по графу переходов

### B. Алгоритмы на графах как DP
- H.5 Floyd Warshall: ДП по промежуточным вершинам: `dp[k][i][j] = min(dp[k−1][i][j], dp[k−1][i][k] + dp[k−1][k][j])` — все пары кратчайших; `O(V³)`; транзитивное замыкание
- H.6 Bellman-Ford: релаксация рёбер как ДП по числу шагов: `dp[k][v] = min(dp[k−1][v], min_u dp[k−1][u] + w(u,v))`; отрицательные циклы
- H.7 Min Distance Up Bottom: итеративный вариант Беллмана-Форда снизу вверх
- H.8 Число путей длины k: степень матрицы смежности `A^k` — ДП по слоям; `O(V³ log k)` возведением в степень

### C. Специальные задачи
- H.9 Maximum Clique в интервальном графе: свойство Хелли (попарное пересечение ⇔ общая точка) — sweep line: максимум одновременно активных интервалов, `O(n log n)`
- H.10 Maximum Independent Set в двудольном графе: теорема Кёнига: MIS = `n −` размер максимального паросочетания; ДП по рёбрам
- H.11 Динамика на пути/цикле: последовательности на цикле — два прохода (первая вершина зафиксирована/нет), как в House Robber II
- H.12 Игры на DAG: win/lose через реверс рёбер (задел на I.C)
- H.13 Minimum Path Cover в DAG: разбиение на минимум путей = `n − max matching` (Кёниг для DAG)
- H.14 Counting topologically distinct paths с ограничениями: путь с чередованием цветов и т.п.

## **I. СПЕЦИАЛЬНЫЕ ВИДЫ И ТЕХНИКИ ДП**
> `i/i.md` · `i/i.cpp` · `struct SpecialDP : GraphDP`

### Основные понятия и принципы
- 0. Основные понятия и принципы: почему выделяются специальные техники — классическая «таблица по индексам» не работает: цифры (разряды + флаги), вероятности (ожидания, цепи Маркова), игры (нимберы, XOR), параметры (количество/сумма как измерения), время (расписания, окна), лень (вычисление по требованию); у каждой семьи свой способ кодировать состояние и порядок вычисления

### A. Цифровая динамика (Digit DP)
- I.1 Основная идея: подсчёт чисел с ограничениями по цифрам — состояние `(pos, tight, leadingZero, ...)`
- I.2 Задачи: подсчёт чисел в диапазоне `[L, R]` с определёнными свойствами (через `f(R) − f(L−1)`)
- I.3 Range Sum Query для цифровых свойств: сумма значений свойства по всем числам диапазона
- I.4 Сумма цифр всех чисел в диапазоне: `dp[pos][sum][tight][leadingZero]`
- I.5 Числа без повторяющихся цифр: маска использованных цифр в состоянии
- I.6 Числа, делящиеся на K: `dp[pos][mod]` — остаток как состояние; обобщение: свойство-остаток для любых периодических функций
- I.7 Мемоизация со сложными состояниями: хранение в map/hash для произвольных параметров
- I.8 Обобщения: числа с ограничением на сумму цифр, цифровой корень, числа с `k` единицами, позиционные системы с основанием `b` (обобщение с 10 на произвольное `b`)
- I.9 Динамика по цифрам в комбинации с другими свойствами: палиндромность — строится половинка числа, зеркалится и сравнивается с границей; простота — проверка на листе

### B. Вероятностная динамика (Probability DP)
- I.10 Основы теории вероятностей в ДП: ожидаемое значение `E[X] = Σ pᵢ·xᵢ`, вероятности переходов между состояниями
- I.11 Игровые задачи с вероятностями (кости, карты): `dp[state] = Σ p(переход)·dp[next]`; ожидание числа шагов
- I.12 Random Walks: ожидание времени возврата/поглощения; формула для 1D-блуждания; связь с мартингалами
- I.13 Markov Chains: матрица переходов, стационарное распределение `π = π·P`, поглощающие состояния, фундаментальная матрица
- I.14 Viterbi Algorithm (скрытые марковские модели): `dp[t][s] = max(dp[t−1][s']·p(s'→s)·p(obs_t | s))` — самый вероятный путь
- I.15 Expected number of steps до поглощающего состояния: система линейных уравнений `E[i] = 1 + Σ p[i][j]·E[j]` — решение для не-DAG структур
- I.16 Ожидание с ДП по вероятностям (сетка): `dp[i][j] = p·dp[i][j+1] + (1−p)·dp[i+1][j]` — вероятность p шага вправо, граница — провал; обратный порядок от цели, `O(n·m)`
- I.17 Gambler's Ruin: вероятность разорения при серии игр с вероятностью победы `p`

### C. Комбинаторная игровая динамика (Combinatorial Game DP)
- I.18 Игры с impartial rules: `Grundy` числа (нимберы): `g(x) = mex{g(y) : x → y}`; рекуррентное вычисление позиций
- I.19 Определение P-позиций (проигрышных) и N-позиций (выигрышных): P — все переходы в N; N — есть переход в P
- I.20 Классические игры: Nim (разные варианты: `xor` всех кучек = 0 ⇔ P-позиция), Kayles (кегли), Dawson's Kayles, Wythoff's game (свойства через разность и золотое сечение)
- I.21 Теорема Шпрага-Гранди: разложение игры на независимые компоненты; XOR нимберов компонент; вычисление результата составной игры
- I.22 Partisan games (игры с разными правилами): hot games, cold games; сравнение игровых значений
- I.23 Применения: выигрывающий ход — из N-позиции в позицию с `g = 0`; в суммах игр — компонента с ведущим битом XOR (`gᵢ' = gᵢ ⊕ XOR`); стратегия «отдай P-позицию»
- I.24 Subtraction Games: множество допустимых ходов `S`; периодичность нимберов
- I.25 Игры с копками: Green Hackenbush — обобщение ним на деревья: `g(v) = [v — не корень] + XOR(g(детей))`; бамбук длины L = ним L; теорема колонизации

### D. Параметрическая динамика
- I.26 DP с ограничением на количество элементов: `dp[i][k]` — ровно/не более k элементов; переходы с фиксацией k
- I.27 DP с ограничением на сумму/разность: добавление измерения «сумма» к состоянию
- I.28 Integer Partition: `dp[n][k]` — разбиения числа на слагаемые: `p(n, k) = p(n−1, k−1) + p(n−k, k)`; производящая функция (см. комбинаторику)
- I.29 Minimum Size Subarray Sum: `dp[i]` — минимальная длина подотрезка с суммой ≥ S; двухуказательная/деque-оптимизация
- I.30 Техника «DP с K измерениями»: обобщение состояний на произвольное число параметров

### E. Временная динамика
- I.31 Scheduling problems (интервальные работы): сортировка по `end`; `dp[i] = max(dp[i−1], profit[i] + dp[p(i)])`, `p(i)` — последняя работа с `end ≤ start[i]` (бинарный поиск)
- I.32 Time-dependent стоимости: веса зависят от момента перехода: `dp[t][v]`
- I.33 Задачи с временными окнами (дедлайны): работы единичной длительности: `dp[t]` — максимум прибыли по моментам `1..t`; проход по дедлайнам сверху вниз — аналог 0/1-рюкзака
- I.34 Дискретизация временной оси (координатное сжатие): работа с конечными точками интервалов; классика — минимальное число интервалов для покрытия `[L, R]` (жадный по max r, недостижимость → −1)

### F. Ленивая динамика (Lazy DP)
- I.35 Отложенные вычисления: вычисление состояний по требованию (мемоизация с ленивой инициализацией)
- I.36 Динамика с кэшированием и мемоизацией по требованию: map-состояния, кэширование подзадач для больших разреженных пространств состояний
- I.37 Ленивое ДП на графах зависимостей: вычисление только достижимых состояний (top-down по списку зависимостей)

## **J. СЛОЖНЫЕ ОПТИМИЗАЦИИ ДП**
> `j/j.md` · `j/j.cpp` · `struct OptimizationDP : SpecialDP`

### Основные понятия и принципы
- 0. Основные понятия и принципы: почему выделяются оптимизации — ускорение уже построенных рекуррентностей (память и время пересчёта); каждому приёму — свой тип рекуррентности и своё структурное условие (четырёхугольное неравенство, Монжа, выпуклость, монотонные запросы) — проверка условия важнее техники; нарушение условий даёт неверные ответы

### A. Оптимизация пространства (Memory Optimization)
- J.1 Rolling DP: хранение только необходимых слоёв — `dp[2][...]`, `dp[k][...]`; для интервальных — по диагоналям
- J.2 Bit DP: сжатие состояний в биты (маски, bitset-ускорение: `dp |= dp << c` для сумм)
- J.3 DP на префиксах: O(N) памяти вместо O(N²) (LCS → две строки, Edit Distance → две строки)
- J.4 In-place DP: перезапись массивов с контролем направления цикла (0-1 рюкзак)

### B. Оптимизация времени пересчёта
- J.5 Divide & Conquer Optimization: применимость `dp[k][i] = min_{j<i} (dp[k−1][j] + C(j+1, i))`; условие: Quadrangle Inequality (четырёхугольное неравенство) на `C`; монотонность точки оптимума `opt[i−1] ≤ opt[i] ≤ opt[i+1]`; сложность: `O(K·n·log n)` (рекурсивный перебор j в коридоре `[optL, optR]`)
- J.6 Knuth Optimization: применимость `dp[i][j] = min_k (dp[i][k] + dp[k+1][j] + C[i][j])`; условия: Quadrangle Inequality + Monotonicity (монотонность по включению) на `C`; `opt[i][j−1] ≤ opt[i][j] ≤ opt[i+1][j]`; использование: Matrix Chain Multiplication, Optimal BST — `O(N²)` вместо `O(N³)`
- J.7 Monge Array Optimization: матрицы Монжа (полностью монотонные); LARSCH/SMAWK-класс
- J.8 Convex Hull Trick (CHT): `dp[i] = min_j (a[j]·x[i] + b[j])` — минимум линейных функций; монотонный CHT: наклоны добавляются по порядку, запросы с монотонным x — очередь с указателем, амортизированно `O(1)`; оболочка снизу/сверху (min/max)
- J.9 Li Chao Tree (динамический CHT): произвольный порядок добавления линий и запросов — `add_line`/`query` за `O(log C)`; целочисленные пересечения через `__int128`; координатное сжатие x
- J.10 Задачи CHT: Land Acquisition — сортировка по `w`, отбрасывание доминируемых (w', h' ≥ w, h); `dp[i] = min_j (dp[j−1] + h[j]·w[i])` — монотонный CHT; «коммандо» и доставка — параболические переходы
- J.11 Aliens Trick (Лагранжева релаксация): штраф `λ` за каждый сегмент — `solve(λ)` решается без ограничения; бинарный поиск `λ` так, чтобы использовалось ровно K сегментов (при равенстве стоимостей — максимум числа сегментов); `cost(K) = solve(λ*) − λ*·K`; задачи: K-сегментное разбиение, K-маршруты
- J.12 Оптимизация через очередь минимумов: Sliding Window минимум/максимум за `O(n)` (deque: монотонная очередь); Deque-based оптимизация; применение: Max Subarray Sum с ограничением длины `dp[i] = max_{j∈[i−k, i−1]} (dp[j] − prefix[j]) + prefix[i]`
- J.13 SMAWK Algorithm: Агарвала-Клаоса-Мортина-Принса-Шора; для полностью монотонных матриц; O(N) для нахождения минимумов в строках (при условии O(1) доступа к ячейке); применение к DP на конвейере

### C. Параллельные и распределённые реализации ДП
- J.14 GPU оптимизации: CUDA/OpenCL реализации (многомерные таблицы, перенос по диагоналям)
- J.15 Распределённое ДП: MapReduce подход (фазы map/reduce по слоям состояний)
- J.16 Потоковые алгоритмы: one-pass DP (скользящие структуры, инкрементальные обновления)
- J.17 Общая стратегия выбора оптимизации: диагностика структуры переходов (монотонность, неравенство четырёхугольника, линейность) → выбор между Knuth / D&C / CHT / deque / Aliens
