# **A. ТЕОРЕТИКО-ЧИСЛОВЫЕ ОСНОВЫ**

## **1. Модульная арифметика**

### **1.1. Основные понятия**
* **Модуль:** `a ≡ b (mod m)` ⟺ `m | (a − b)` — остатки при делении на `m`
* **Кольцо вычетов Z/mZ:** множество `{0, 1, ..., m−1}` с операциями `+` и `·` по модулю
* **Свойства:** коммутативность, ассоциативность, дистрибутивность; нейтральный элемент: `0` для `+`, `1` для `·`

### **1.2. Обратные элементы**
* **Обратный к `a` по модулю `m`:** число `a⁻¹` такое, что `a · a⁻¹ ≡ 1 (mod m)`
* **Существование:** `gcd(a, m) = 1` ⟹ обратный существует (алгоритм Евклида)
* **Применение в хешировании:** полиномиальное хеширование с обратными для подстрок

### **1.3. Китайская теорема об остатках (КТО)**
* **Формулировка:** если `m₁, m₂, ..., mₖ` попарно взаимно просты, то система `x ≡ aᵢ (mod mᵢ)` имеет единственное решение по модулю `M = m₁ · m₂ · ... · mₖ`
* **Применение:** large modulus через произведение малых модулей; хеширование с несколькими модулями для уменьшения коллизий

### **1.4. Быстрое возведение в степень**
* `aⁿ mod m` за `O(log n)`: последовательное возведение в квадрат
* Применение: вычисление полиномиального хеша, модулярное возведение в степень

## **2. Конечные поля (поля Галуа)**

### **2.1. Определение**
* **Поле:** множество `F` с операциями `+` и `·`, удовлетворяющее аксиомам (замкнутость, ассоциативность, коммутативность, нейтральные элементы, обратные элементы, дистрибутивность)
* **Конечное поле:** поле с конечным числом элементов; `|F| = pⁿ` (степень простого `p`)

### **2.2. Типы конечных полей**
* **GF(p) = Z/pZ:** поле вычетов по модулю простого `p`; сложение и умножение по модулю
* **GF(pⁿ):** расширение степени `n` над `GF(p)`; элементы — полиномы степени `< n` с коэффициентами из `GF(p)`, умножение по модулю неприводимого полинома

### **2.3. Применение в хешировании**
* **Полиномиальное хеширование:** `h(s) = Σ s[i] · pⁱ mod q`, где `q` — простое
* **Обратные элементы:** для подстрочных хешей (вычисление хеша подстроки без пересчёта)
* **Универсальные семейства:** `h_{a,b}(x) = ((ax + b) mod p) mod m` — случайный выбор `a, b`

## **3. Простые числа**

### **3.1. Распределение**
* **Теорема о распределении простых:** π(x) ~ x/ln(x) (теорема о простых числах)
* **Простые в хешировании:** модуль `m` простой → хорошее распределение хешей

### **3.2. Тесты простоты**
* **Детерминированные:** пробное деление до √n, тест Миллера-Рабина (детерминированный версия для малых `n`)
* **Вероятностные:** тест Миллера-Рабина (k раундов → вероятность ошибки `≤ 4⁻ᵏ`)

### **3.3. Генерация простых чисел**
* Генерация случайного `n`-битного числа → проверка на простоту → повторение
* Для хеш-таблиц: выбор простого размера таблицы → улучшение распределения

# **B. ТЕОРИЯ ВЕРОЯТНОСТЕЙ И СТАТИСТИКА**

## **1. Парадокс дней рождения**

### **1.1. Точная формула**
* `n` элементов, `M` возможных хешей:
    * `P(коллизия) = 1 − ∏ᵢ₌₀ⁿ⁻¹ (1 − i/M) = 1 − M!/((M−n)! · Mⁿ)`

### **1.2. Асимптотика**
* При `n << M`: `P ≈ 1 − e^{−n(n−1)/(2M)}`
* **Порог:** `P > 0.5` при `n ≈ 1.1774 · √M ≈ √(2 · ln 2 · M)`
* Для `M = 2^m`: `n ≈ 2^{m/2}` → атака дня рождения на криптографические хеш-функции

### **1.3. Применение**
* Оценка безопасности хеш-функции: `m`-битный хеш安全保障 = `2^{m/2}` вычислений
* Выбор размера хеш-таблицы: `n < √M` для малой вероятности коллизии

## **2. Статистические тесты**

### **2.1. χ²-тест равномерности**
* **Нулевая гипотеза:** хеш-функция распределяет значения равномерно
* **Статистика:** `χ² = Σᵢ (Oᵢ − Eᵢ)² / Eᵢ`, где `Oᵢ` — наблюдаемое число, `Eᵢ` — ожидаемое
* **Применение:** тестирование качества хеш-функции (количество коллизий в бакетах)

### **2.2. Тест на автокорреляцию**
* **Автокорреляция:** `r(k) = Σᵢ (xᵢ − x̄)(xᵢ₊ₖ − x̄) / Σᵢ (xᵢ − x̄)²`
* Для хорошей хеш-функции: `r(k) ≈ 0` при `k ≠ 0`

### **2.3. Тест на независимость**
* Проверка: последовательные хеш-значения независимы
* Критерий: `P(h(xᵢ) = v | h(xᵢ₋₁) = u) ≈ P(h(x) = v)` для всех `u, v`

## **3. Модели случайных процессов**

### **3.1. Марковские цепи**
* Состояния: бакеты хеш-таблицы; переходы: хеширование следующего элемента
* Стационарное распределение: равномерное распределение по бакетам (для хорошей хеш-функции)

### **3.2. Случайные блуждания**
* Случайное блуждание по таблице: каждый новый ключ — случайный шаг
* Связь с коллизиями:.expected расстояние между коллизиями

# **C. АЛГЕБРАИЧЕСКИЕ СТРУКТУРЫ**

## **1. Группы, кольца, поля**

### **1.1. Группа**
* Множество `G` с операцией `·`: замкнутость, ассоциативность, нейтральный элемент, обратные элементы
* **Абелева группа:** коммутативность (`a · b = b · a`)
* Пример: `(Z/mZ, +)` — абелева группа

### **1.2. Кольцо**
* Множество `R` с `+` и `·`: `(R, +)` — абелева группа, `(R, ·)` — моноид, дистрибутивность
* Пример: `(Z/mZ, +, ·)` — кольцо вычетов

### **1.3. Поле**
* Кольцо, в котором каждый ненулевой элемент имеет обратный: `(F\{0}, ·)` — группа
* Пример: `GF(p)` — поле вычетов по модулю простого `p`

## **2. Линейная алгебра**

### **2.1. Матричные представления хеш-функций**
* Хеш-функция как линейное преобразование: `h(x) = Ax mod m`
* **Полиномиальное хеширование:** `h(s) = Σ s[i] · pⁱ` — линейная комбинация символов
* **Horners's method:** `h = s[n] · p + s[n−1] · p + ... + s[0]` — efficient вычисление

### **2.2. Связь с кодированием**
* Линейные коды: проверка ошибок через матрицу проверки
* Связь с хеш-функциями: криптографические хеш-функции используют нелинейные преобразования

## **3. Булева алгебра**

### **3.1. Булевы функции**
* `f: {0,1}ⁿ → {0,1}` — функция из `n` переменных в одну
* **S-блоки:** нелинейные булевы функции в блочных шифрах и хеш-функциях

### **3.2. Критерии нелинейности**
* **Линейное приближение:** `P(f(x) = L(x)) ≤ 1/2 + ε` — чем меньше `ε`, тем лучше
* **Дифференциальная нелинейность:** máxima вероятность `P(f(x ⊕ Δ) ⊕ f(x) = Δ')` — чем ближе к `1/2`, тем лучше

### **3.3. Применение в хеш-функциях**
* **Аваланда-эффект:** изменение 1 бита → изменение ~50% битов (нелинейность)
* **Устойчивость к дифференциальному криптоанализу:** S-блоки с хорошей дифференциальной нелинейностью
