## **C. ХЭШ-ТАБЛИЦЫ: РЕАЛИЗАЦИИ И СТРАТЕГИИ РАЗРЕШЕНИЯ КОЛЛИЗИЙ**

### **A. Структура хэш-таблицы**
*   Hash Table, Hash Map `unordered_map`, `unordered_set`
*   **Массив бакетов (buckets)** — базовое хранение
*   **Фактор загрузки (load factor)** — оптимальные значения, автоматическое рехеширование
*   **Динамическое масштабирование** — увеличение/уменьшение размера таблицы

### **B. Методы разрешения коллизий**
*   **Separate Chaining (Цепочки)** — связные списки в каждом бакете
    *   *Hash Table With Linked List* — классическая реализация
    *   *Оптимизации* — переупорядочивание, объединение списков
*   **Open Addressing (Открытая адресация)** — поиск свободной ячейки

    *   *Double Hashing (Двойное хэширование)* — использование второй хэш-функции

### **C. Продвинутые реализации**
*   **Perfect Hashing** — хэширование без коллизий для статических множеств
*   **Universal Hashing** — случайный выбор из семейства хэш-функций
*   **Robin Hood Hashing** — "заимствование" у богатых для бедных пробирований
*   **Hopscotch Hashing** — локальность данных для кэш-эффективности

### **D. Тестирование и бенчмаркинг**

## **D. ВЕРОЯТНОСТНЫЕ СТРУКТУРЫ ДАННЫХ НА ОСНОВЕ ХЕШИРОВАНИЯ**
> `d/d.md` · `d/d.cpp` · `struct ProbabilisticStructures : HashTables`

### **A. Фильтр Блума и его варианты**
*   **Базовый Bloom Filter** — идея: `k` хешей, битовый вектор размера `m` — «возможно есть» / «точно нет»
*   Вероятность ложноположительного срабатывания: `(1 − e^(−kn/m))^k`, оптимум `k = (m/n)·ln 2`
*   **Counting Bloom Filter** — поддержка удалений (счётчики вместо битов), анализ ошибок
*   **Scalable Bloom Filter** — адаптация к растущим наборам данных
*   **Bloomier Filter** — ассоциативный фильтр Блума

### **B. Sketch-структуры**
*   **Count-Min Sketch** — частотная оценка по потоку: матрица счётчиков + `d` хешей
    *   Верхняя оценка ошибки `ε` с вероятностью `1−δ` (размеры `w = ⌈e/ε⌉`, `d = ⌈ln(1/δ)⌉`)
    *   Применения: тяжёлые ключи (heavy hitters), оценка квантилей и моментов
*   **Count-Sketch** — улучшенная версия с лучшими гарантиями
*   **HyperLogLog** — оценка кардинальности: максимум числа ведущих нулей по корзинам
    *   Оценка: `α·m·m / Σ 2^(−M[j])`, поправки на малые/большие значения
    *   Точность `1.04/√m` — параметр корзин `m`
*   **AMS Sketch** — оценка моментов распределения

### **C. Продвинутые вероятностные структуры**
*   **Quotient Filter** — эффективное использование памяти
*   **Cuckoo Filter** — лучшая производительность чем фильтр Блума
*   **Связи:** Randomized Treap и Randomized Heap — те же вероятностные приёмы (ветка struct, II.F, IV); локально-чувствительное хеширование (LSH) — см. раздел V (MinHash, SimHash)

## **E. АЛГОРИТМЫ И КОНСТРУКЦИИ ХЕШ-ФУНКЦИЙ**
> `e/e.md` · `e/e.cpp` · `struct HashFunctions : ProbabilisticStructures`

### **A. Универсальные семейства хеш-функций**
*   **Теорема Картера-Вегмана** — конструкция и доказательство
*   **Полиномиальное хеширование** — над конечными полями, свойства распределения
*   **Tabulation Hashing** — теоретические гарантии и практическая эффективность

### **B. Криптографические конструкции**
*   **Merkle-Damgård** — структура, свойства, уязвимости к атакам расширения
*   **Sponge Construction** — поглощение, сжатие, теоретическая емкость
*   **HAIFA** — улучшенная конструкция с счетчиком
*   **Криптографические хеш-функции**
    *   **MD5** — Message Digest 5, 128-битный, уязвим к коллизиям
    *   **SHA-1** — Secure Hash Algorithm 1, 160-битный, криптографически сломан
    *   **SHA-256** — Secure Hash Algorithm 256-битный, часть семейства SHA-2

### **C. Некриптографические хеш-функции**
*   **Djb2** — алгоритм Дэниела Бернстайна, умножение на 33
*   **Sdbm** — вариант используемый в SDBM database
*   **Elf** — хеш-функция из Executable and Linkable Format
*   **Adler32** — контрольная сумма, используется в zlib
*   **Fletcher16** — алгоритм контрольной суммы

### **D. Специализированные алгоритмы**
*   **Rolling Hashes** — полиномиальные, Rabin-Karp, циклические
*   **Locality-Sensitive Hashing (LSH)** — MinHash, SimHash, случайные проекции
    *   Принцип: семейство хеш-функций, где близкие объекты (по заданной метрике) с большой вероятностью попадают в один бакет, далёкие — с малой; поиск похожего — по бакетам, без попарного сравнения (линейный поиск — `O(n)`)
    *   «Вероятностная проекция» на малую сигнатуру: близость эквивалентна совпадению хеша с вероятностью, монотонной по расстоянию; объединение `L` бакетов: вероятность пропуска близкой пары `(1 − p^r)^L` — выбор `r` и `L` даёт компромисс точность/скорость
    *   Сложность: построение `O(L·n)` проекций; запрос — `O(L)` бакетов + верификация кандидатов
    *   **MinHash для множеств (Jaccard)** — Jaccard `|A ∩ B| / |A ∪ B|`; подпись — вектор из `r` минимумов хешей по `r` случайным универсальным хешам `h(x) = (a·x + b) mod P`; вероятность совпадения минимума `= |A∩B|/|A∪B|` — несмещённая оценка (минимум `A ∪ B` лежит в `A ∩ B`); построение `O(r·|S|)`, сравнение `O(r)`; приложения — приближённые дубликаты документов, сводный хэш для потоков
    *   **Hamming LSH (bit sampling)** — бинарные векторы длины `d`; проекция — выборка `r` позиций (бакет — значение на них); при расстоянии `t` вероятность совпадения `(1 − t/d)^r`; `L` независимых таблиц + верификация точным расстоянием (результат корректен, пропуски — вероятностные); память `O(L·n)`, запрос `O(L·r + кандидаты)`; приложения — дедупликация, поиск похожих изображений
    *   Обобщение: метрика — параметр схемы (Jaccard, Хемминг, косинус — случайные гиперплоскости SimHash); случайные проекции для вещественных векторов
*   **Perceptual Hashing** — pHash, dHash, wHash для изображений
*   **Luhn** — алгоритм проверки чисел (кредитные карты)
*   **Hamming Code** — код Хэмминга для обнаружения и исправления ошибок
*   **Chaos Machine** — теоретическая модель на основе хаотических систем
