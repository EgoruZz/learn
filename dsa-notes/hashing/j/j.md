# **A. ПОСТКВАНТОВАЯ КРИПТОГРАФИЯ**

## **1. Устойчивость к квантовым атакам**

### **1.1. Алгоритм Гровера**
* Квантовый алгоритм для поиска в неупорядоченной базе данных: `O(√N)` вместо `O(N)`
* **Влияние на хеш-функции:** атака на preimage: `O(2^{m/2})` квантовых шагов вместо `O(2^m)`

### **1.2. Алгоритм Шора**
* Факторизация больших чисел за полиномиальное время
* **Влияние:** RSA, ECC — сломаны; хеш-функции — **устойчивы** (не используют факторизацию)

### **1.3. Безопасность хеш-функций**
* Collision resistance: `O(2^{m/3})` квантовых шагов (алгоритм Брюсса-Лоу)
* Preimage resistance: `O(2^{m/2})` (алгоритм Гровера)
* **Рекомендация:** увеличить размер хеша до 256+ бит для постквантовой безопасности

## **2. Hash-based Signatures**

### **2.1. XMSS (eXtended Merkle Signature Scheme)**
* Подпись на основе Merkle tree
* **Свойства:** доказуемая безопасность (только collision resistance хеш-функции)
* **Ограничение:** одноразовые подписи (каждый ключ → фиксированное число подписей)

### **2.2. SPHINCS+ (Stateless Hash-based Signature)**
* Stateless: не требует хранения состояния
* **Основа:** Merkle tree + WOTS+ (Winternitz One-Time Signature)
* Стандарт NIST для постквантовых подписей

## **3. Lattice-based Хеши**

### **3.1. Связь с решётками**
* **Решётка:** дискретное подмножество `ℝⁿ`: `L = {Σᵢ aᵢbᵢ : aᵢ ∈ ℤ}` где `bᵢ` — базис
* **Хеш через решётку:** `h(x) = (A·x + e) mod q`, где `A` — случайная матрица, `e` — малый шум

### **3.2. Криптографические схемы**
* **NTRU:** шифрование/подпись на основе решёток
* **CRYSTALS-Dilithium:** постквантовая подпись (стандарт NIST)
* **FrodoKEM:** постквантовый обмен ключами

# **B. НОВЫЕ ПАРАДИГМЫ ХЕШИРОВАНИЯ**

## **1. Гомоморфное хеширование**

### **1.1. Определение**
* Хеш-функция, допускающая вычисление хеша **произведения** по хешам множителей
* `h(a · b) = f(h(a), h(b))` без знания `a` и `b`

### **1.2. Применение**
* Верификация вычислений на зашифрованных данных
* Защищённые облачные вычисления

## **2. Zero-knowledge Хеши**

### **2.1. Определение**
* Доказательство знания хеш-ключа без его раскрытия
* Протокол: prover убеждает verifier, что знает `x` с `H(x) = y`

### **2.2. Применение**
* Анонимная аутентификация
* Доказательства с нулевым разглашением (ZKP)

## **3. Биометрическое хеширование**

### **3.1. Определение**
* Преобразование биометрических данных (отпечаток пальца, лицо) в хеш
* **Свойство:** устойчивость к небольшим вариациям (шум измерений)

### **3.2. Применение**
* Аутентификация по биометрии
* Защита приватности биометрических данных

# **C. ЭКЗОТИЧЕСКИЕ ПРИМЕНЕНИЯ**

## **1. Квантовое хеширование**

### **1.1. Определение**
* Хеш-функция на основе квантовых вычислений
* **Свойство:** принцип неопределённости гарантирует collision resistance

## **2. Нейросетевые хеш-функции**

### **2.1. Определение**
* Обучение хеш-функции через нейронные сети
* **Цель:** perceptual hashing (похожие изображения → похожие хеши)

### **2.2. Архитектура**
* Encoder: изображение → вектор фичей → бинарный хеш
* Loss: triplet loss (похожие ближе, непохожие дальше)

## **3. Биологическое хеширование**

### **3.1. Определение**
* Хеш-функции на основе ДНК-последовательностей
* **Применение:** биоинформатика, геномная идентификация
