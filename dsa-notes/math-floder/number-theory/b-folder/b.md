# **B. МОДУЛЯРНАЯ АРИФМЕТИКА, ТЕОРИЯ СРАВНЕНИЙ И ДИОФАНТОВЫ УРАВНЕНИЯ**

---

# **A. МОДУЛЯРНАЯ АРИФМЕТИКА — ОСНОВЫ**

## **1. Действия по модулю**
* **Идея:** Вся арифметика работает как обычно, но результат — это остаток от деления на m. Мы "сворачиваем" бесконечную числовую прямую в кольцо {0, 1, ..., m-1}
* **Формулы:**
  * `(a + b) % m = (a % m + b % m) % m`
  * `(a - b + m) % m = (a % m - b % m + m) % m` — прибавляем m чтобы не уйти в минус
  * `(a * b) % m = (a % m * b % m) % m`
  * `(a / b) % m = (a % m * b⁻¹ % m) % m` — деление через обратный элемент
* **Почему при вычитании прибавляем m:** `a % m` может быть меньше `b % m`, тогда `a%m - b%m < 0`, а остаток должен быть в [0, m-1]
* **Ассоциативность:** (a+b)+c ≡ a+(b+c) (mod m), (a·b)·c ≡ a·(b·c) (mod m)
* **Коммутативность:** a+b ≡ b+a (mod m), a·b ≡ b·a (mod m)
* **Дистрибутивность:** a·(b+c) ≡ a·b + a·c (mod m)
* **Сокращение:** a·c ≡ b·c (mod m) ⟹ a ≡ b (mod m/gcd(c,m))
* **Количество чисел по модулю в интервале**
  * **Формула:** |{a ∈ [L, R] : a ≡ r (mod m)}| = ⌊(R-r)/m⌋ - ⌊(L-1-r)/m⌋
  * **Интуиция:** считаем сколько чисел вида r + km попадают в [L, R]
  * **Пример:** |{a ∈ [10, 30] : a ≡ 2 (mod 5)}| = ⌊28/5⌋ - ⌊7/5⌋ = 5 - 1 = 4 (числа: 12, 17, 22, 27)

## **2. Обратные элементы**

### **2.1. Когда обратный существует**
* **Интуиция:** В рациональных числах деление = умножение на обратное: `a/b = a × b⁻¹`. В целых числах по модулю `a⁻¹ (mod m)` существует ⟺ `gcd(a, m) = 1`
* **Аналогия с десятичными:** `13.45 / 17.2 = (1345 × 10) / (172 × 100)` — умножаем на степени 10 чтобы избавиться от запятой; аналогично в модулярной арифметике ищем число x такое что `a × x ≡ 1 (mod m)`
* **Почему gcd(a,m)=1:** если gcd(a,m)=d>1, то `a×x` всегда кратно d, а 1 не кратно d → решения нет

### **2.2. Вычисление через расширенный алгоритм Евклида**
* **Алгоритм:** Решаем `a×x + m×y = gcd(a,m) = 1` → x и есть a⁻¹ (mod m)
* **Сложность:** O(log m) — как обычный Евклид, но с дополнительными вычислениями коэффициентов
* **Свойство:** обратный единствен: если `a×x₁ ≡ 1` и `a×x₂ ≡ 1` (mod m), то `x₁ ≡ x₂` (mod m)

## **3. Китайская теорема об остатках (CRT)**

### **3.1. Стандартная версия (взаимно простые модули)**
* **Система:** x ≡ aᵢ (mod mᵢ), где gcd(mᵢ, mⱼ) = 1 для i ≠ j
* **Решение:** x = ∑ aᵢ · Mᵢ · Nᵢ (mod M), где:
  * M = ∏ mᵢ — произведение всех модулей
  * Mᵢ = M / mᵢ — произведение всех кроме i-го
  * Nᵢ ≡ Mᵢ⁻¹ (mod mᵢ) — обратный к Mᵢ по модулю mᵢ
* **Почему работает:** Mᵢ ≡ 0 (mod mⱼ) для j≠i, поэтому при подстановке в j-е сравнение остаётся только aⱼ · 1 · 1 = aⱼ
* **Сложность:** O(k log M) где k — количество уравнений

### **3.2. Обобщённая версия (произвольные модули)**
* **Система:** x ≡ aᵢ (mod mᵢ) без условия gcd(mᵢ,mⱼ)=1
* **Условие совместности:** aᵢ ≡ aⱼ (mod gcd(mᵢ, mⱼ)) ∀i,j
* **Решение:** последовательное слияние пар сравнений → одно итоговое сравнение
* **Алгоритм:** начиная с x ≡ a₁ (mod m₁), на каждой итерации объединяем с x ≡ aᵢ (mod mᵢ)

### **3.3. Алгоритм Гарнера**
* **Идея:** представляем x в смешанной системе счислений: x = v₁ + v₂·m₁ + v₃·m₁·m₂ + ...
* **Преимущество над CRT:** модульная арифметика не нужна на промежуточных шагах, числа не растут
* **Сложность:** O(k²) — на каждое новое число проверяем k предыдущих

### **3.4. Количество решений в [L,R]:**
* ⌊(R-x₀)/M⌋ - ⌊(L-1-x₀)/M⌋ где x₀ — наименьшее, M=lcm

# **B. ТЕОРЕМЫ МОДУЛЯРНОЙ АРИФМЕТИКИ**

## **1. Малая теорема Ферма**
* **Формула:** aᵖ⁻¹ ≡ 1 (mod p) для простого p и p ∤ a
* **Эквивалентно:** aᵖ ≡ a (mod p) для любого a (включая кратные p)
* **Почему верно:** множества {a, 2a, 3a, ..., (p-1)a} и {1, 2, 3, ..., p-1} совпадают по модулю p (перестановка), поэтому произведения равны: aᵖ⁻¹ · (p-1)! ≡ (p-1)! (mod p), сокращаем на (p-1)! который взаимно прост с p
* **Применение:** проверка простоты (тест Ферма), быстрое возведение в степень по модулю простого

## **2. Теорема Эйлера**
* **Формула:** a^φ(m) ≡ 1 (mod m) при gcd(a, m) = 1
* **Обобщение Ферма:** при m=p (простое) φ(p)=p-1 → получаем малую теорему Ферма
* **Почему верно:** группа units (ℤ/mℤ)* имеет порядок φ(m), по теореме Лагранжа порядок элемента делит порядок группы
* **Применение:** вычисление степеней по составным модулям, RSA

## **3. Теорема Лагранжа (полиномиальные сравнения)**
* **Формула:** полиномиальное сравнение степени n: `f(x) ≡ 0 (mod p)` имеет не более n решений по простому модулю
* **Почему верно:** если x₀ — корень, то f(x) = (x - x₀)·g(x) (mod p), induction
* **Применение:** проверка корней, тестирование

## **4. Теорема Дирихле о простых в арифметической прогрессии**
* **Формула:** в прогрессии a + nd при gcd(a, d) = 1 бесконечно много простых
* **Пример:** 3, 7, 11, 19, 23, ... (простые ≡ 3 mod 4) — бесконечно много
* **Применение:** доказательство существования простых с заданными свойствами

## **5. Дирихлева свёртка по модулю**
* **(f * g)(n) = Σ_{d|n} f(d)·g(n/d)** — свёртка по делителям
* **μ * 1 = ε:** Σ_{d|n} μ(d) = [n=1]
* **φ * 1 = id:** Σ_{d|n} φ(d) = n
* **d = 1 * 1:** d(n) = Σ_{d|n} 1
* **σ = id * 1:** σ(n) = Σ_{d|n} d
* **Обращение Мёбиуса:** если g = f * 1, то f = g * μ

# **C. ЛИНЕЙНЫЕ СРАВНЕНИЯ**

## **1. Линейные сравнения**
* **Формула:** ax ≡ b (mod m) имеет решение ⟺ gcd(a, m) | b
* **Количество решений:** gcd(a, m) при условии существования (все решения попарно различны по mod m)
* **Алгоритм:** приведение к диофантову уравнению: ax - my = b → расширенный Евклид → проверка gcd(a,m) | b

## **2. Системы сравнений**
* **Теорема:** система x ≡ aᵢ (mod mᵢ) совместна ⟺ aᵢ ≡ aⱼ (mod gcd(mᵢ, mⱼ)) ∀i,j
* **Алгоритм:** последовательное слияние сравнений:
  * Начинаем с x ≡ a₁ (mod m₁)
  * На каждой итерации: x ≡ aᵢ (mod mᵢ) объединяем с текущим
  * Результат — одно сравнение x ≡ a (mod lcm(m₁, ..., mᵢ))

## **3. Степенные сравнения**
* **Формула:** xᵏ ≡ a (mod m)
* **Проверка существования:** через дискретный логарифм и первообразные корни
* **Алгоритм:** подъем решений по степеням простых модулей, индексный криптосистема
* **Степень по модулю p:**
  * **Квадраты по модулю p:** a² mod p принимает ровно (p+1)/2 различных значений (включая 0)
  * **Кубы по модулю p:** если p ≢ 1 (mod 3), то x³ ≡ a (mod p) имеет ≤1 решение; если p ≡ 1 (mod 3) → до 3 решений
  * **k-ая степень по модулю p:** ...

# **D. ДИОФАНТОВЫ УРАВНЕНИЯ**

## **1. Линейные диофантовы уравнения**
* **Формула:** ax + by = c имеет целые решения ⟺ gcd(a, b) | c
* **Общее решение:** если (x₀, y₀) — частное решение, то:
  * x = x₀ + (b/d)·t
  * y = y₀ - (a/d)·t
  * где d = gcd(a, b), t ∈ ℤ
* **Нахождение частного:** через расширенный алгоритм Евклида: gcd(a,b)=d →ax₀+by₀=d → умножаем на c/d
* **Пример:** 6x + 15y = 9 → gcd(6,15)=3, 3|9 → x₀=2·3=6, y₀=-1·3=-3 (из Евклида: 6·(-2)+15·1=3 → ×3 → 6·(-6)+15·3=9)

## **2. Уравнение Пелля**
* **Формула:** x² - Dy² = 1, где D — не квадрат
* **Фундаментальное решение:** минимальное положительное (x₁, y₁)
* **Общее решение:** (x₁ + y₁√D)ⁿ = xₙ + yₙ√D для n = 1, 2, 3, ...
* **Алгоритм нахождения:** непрерывные дроби √D → период → конвергенты → фундаментальное решение в конце периода
* **Пример:** D=2 → √2 = [1;2,2,2,...] → x₁=3, y₁=2 → 3²-2·2²=1

## **3. Пифагоровы тройки**
* **Формула:** x² + y² = z²
* **Примитивные тройки (gcd(x,y,z)=1):**
  * x = m² - n², y = 2mn, z = m² + n²
  * где m > n > 0, gcd(m,n) = 1, m и n разной четности
* **Все тройки:** умножаем примитивные на k ≥ 1
* **Свойства:** z нечётное, ровно одно из x,y нечётное

# **E. БИНАРНОЕ ВОЗВЕДЕНИЕ В СТЕПЕНЬ ПО МОДУЛЮ**

## **1. Основная идея**
* **Идея:** Вместо умножать a саму на себя m-1 раз (O(m)), используем двоичное представление показателя: a^m = a^(b₀) · a^(b₁·2) · a^(b₂·4) · ... где m = b₀ + b₁·2 + b₂·4 + ...
* **Пример:** a¹³ = a^(1101₂) = a⁸ · a⁴ · a¹ — нужно 4 умножения вместо 12
* **Сложность:** O(log m) умножений по модулю

## **2. Алгоритм**
* result = 1, base = a % m
* пока показатель > 0:
  * если показатель нечётный → result = (result × base) % m
  * base = (base × base) % m
  * показатель >>= 1 (делим на 2)

# **F. РАСШИРЕННЫЙ АЛГОРИТМ ЕВКЛИДА**

## **1. Обычный Евклид**
* **Формула:** gcd(a, b) = gcd(b, a % b)
* **Сложность:** O(log(min(a,b))) — каждое деление уменьшает число хотя бы вдвое
* **Результат:** только gcd

## **2. Расширенный Евклид**
* **Формула:** находит x, y такие что ax + by = gcd(a, b)
* **Алгоритм:** начинаем с gcd(a,b) и "отматываем назад" коэффициенты
* **Сложность:** O(log(min(a,b))) — на каждой итерации O(1) арифметика
* **Результат:** (gcd, x, y) где ax + by = gcd

## **3. Использование для a⁻¹ mod m**
* **Формула:** gcd(a, m) = 1 → расширенный Евклид → ax + my = 1 → x ≡ a⁻¹ (mod m)
* **Отрицательные результаты:** если x < 0, прибавляем m: `x = (x % m + m) % m`

# **G. ТЕОРЕТИКО-ЧИСЛОВЫЕ ФУНКЦИИ**

## **1. Функция Кармайкла λ(n)**
* **Определение:** наименьшее m такое что aᵐ ≡ 1 (mod n) для всех a с gcd(a,n) = 1
* **Свойства:**
  * λ(pᵏ) = φ(pᵏ) = pᵏ⁻¹(p-1) для нечётных простых
  * λ(2) = 1, λ(4) = 2, λ(2ᵏ) = 2ᵏ⁻² при k ≥ 3
  * λ(lcm(m,n)) = lcm(λ(m), λ(n)) при gcd(m,n) = 1
* **Сравнение с Эйлером:** λ(n) | φ(n), поэтому a^λ(n) ≡ 1 (mod n) является "более сильным" утверждением
* **Применение:** оптимизация RSA (выбор открытой экспоненты)

## **2. Радикал числа rad(n)**
* **Формула:** rad(n) = ∏_{p|n} p (произведение различных простых делителей)
* **Примеры:** rad(12) = rad(2²·3) = 6, rad(1) = 1
* **ABC-гипотеза:** для каждого ε > 0 существует Cε такое что для a+b=c (gcd(a,b,c)=1): c < Cε · rad(abc)^(1+ε)
* **Применение:** ABC-гипотеза связывает аддитивную и мультипликативную структуру чисел

## **3. Функция Мангольдта Λ(n)**
* **Формула:** Λ(n) = ln p если n = pᵏ (степень простого), иначе 0
* **Свойство:** ∑_{d|n} Λ(d) = ln n
* **Связь с распределением простых:** сумма Λ(n) по n ≤ x ≈ x (по теореме о распределении простых)

# **H. КВАДРАТНЫЕ ВЫЧЕТЫ И СИМВОЛ ЛЕЖАНДРА**

## **1. Определения**
* **Квадратный вычет:** a — квадратный вычет по mod p если ∃x: x² ≡ a (mod p)
* **Невычет:** если такого x нет
* **Количество вычетов:** для нечётного простого p ровно (p-1)/2 квадратных вычетов и (p-1)/2 невычетов

## **2. Символ Лежандра (a/p)**
* **Определение:** (a/p) = a^((p-1)/2) mod p ∈ {0, 1, -1}
  * (a/p) = 1 если a — квадратный вычет
  * (a/p) = -1 если a — невычет
  * (a/p) = 0 если p | a
* **Критерий:** a — квадратный вычет ⟺ a^((p-1)/2) ≡ 1 (mod p)

## **3. Свойства символа Лежандра**
* **Мультипликативность:** (ab/p) = (a/p)·(b/p)
* **Периодичность:** (a/p) = (a mod p / p)
* **Формулы для специальных случаев:**
  * (-1/p) = (-1)^{(p-1)/2} = 1 если p≡1(mod4), -1 если p≡3(mod4)
  * (2/p) = (-1)^{(p²-1)/8} = 1 если p≡±1(mod8), -1 если p≡±3(mod8)

## **4. Закон взаимности Лежандра**
* **Формула:** для нечётных простых p,q: (p/q)·(q/p) = (-1)^{(p-1)/2 · (q-1)/2}
* **Смысл:** символ (p/q) определяется через (q/p), что позволяет вычислять символы за O(log p)

## **5. Символ Якоби (обобщение)**
* **Определение:** (a/n) = ∏ (a/pᵢ)^{eᵢ} где n = ∏ pᵢ^eᵢ
* **Свойства:** мультипликативность, (a/1)=1, (a/n)=0 если gcd(a,n)>1
* **Вычисление:** через закон взаимности за O(log²n)

## **6. Кубические вычеты**
* **Формула:** если p ≢ 1 (mod 3), то x³ ≡ a (mod p) имеет ≤1 решение
* **Если p ≡ 1 (mod 3):** до 3 решений (кубический вычет → проверка через a^((p-1)/3) mod p)

# **I. ПРОДВИНУТЫЕ ТЕОРЕТИЧЕСКИЕ ТЕМЫ**

## **1. p-адические числа**
* **p-адическая норма:** |n|_p = p^(-v_p(n)), где v_p(n) — показатель p в разложении n
* **Идея:** измеряем "делимость на p" вместо абсолютной величины
* **Лемма Гензеля:** подъем решений сравнений f(x) ≡ 0 (mod pᵏ) с одного уровня на следующий
  * Если f(x₀) ≡ 0 (mod pᵏ) и f'(x₀) ≢ 0 (mod p), то существует единственное решение x₁ ≡ x₀ (mod pᵏ) такое что f(x₁) ≡ 0 (mod pᵏ⁺¹)
* **Применение:** решение полиномиальных уравнений по модулям степеней простых

## **2. Кольца главных идеалов**
* **Определение:** целостное кольцо, в котором каждый идеал главный (порождён одним элементом)
* **Примеры:** ℤ, K[x] для поля K, ℤ[√(-1)] (gaussian integers)
* **Свойства:** факториальность, существование НОД, единственность разложения на непримоделимые
* **Связь с теорией чисел:** ℤ — главное кольцо идеалов, поэтому НОД существует для любых двух чисел

## **3. Теория дивизоров**
* **Дивизоры в кольцах:** обобщение понятия делителя на произвольные кольца
* **Факториальные кольца:** единственность разложения на непримоделимые (как в ℤ)
* **Дедекиндовы кольца:** единственность разложения на простые идеалы (даже когда единственное разложение на элементы не существует)

# **J. ПРИКЛАДНЫЕ ТЕМЫ**

## **1. Криптография**
* **RSA:**
  * Генерация: p, q простые → n=pq, φ(n)=(p-1)(q-1), e·d ≡ 1 (mod φ(n))
  * Открытый ключ: (n, e), закрытый: (n, d)
  * Шифрование: c = mᵉ mod n, расшифрование: m = cᵈ mod n
  * Безопасность: сложность факторизации n
* **Диффи-Хеллман:**
  * Публичные: p (простое), g (первообразный корень)
  * Алиса: a, отправляет A = gᵃ mod p; Боб: b, отправляет B = gᵇ mod p
  * Общий ключ: K = gᵃᵇ mod p = Aᵇ mod p = Bᵃ mod p
  * Безопасность: задача дискретного логарифмирования
* **Эллиптические кривые:**
  * Уравнение: y² = x³ + ax + b (mod p)
  * Сложение точек: P + Q = R через касательные/секущие
  * Умножение на скаляр: nP = P + P + ... + P
  * Безопасность: задача дискретного логарифмирования на эллиптических кривых (ECDLP)

## **2. Коды коррекции ошибок**
* **Коды Рида-Соломона:**
  * Кодирование: сообщение → полином → значения в n точках
  * Декодирование: интерполяция полинома по известным значениям (с учётом ошибок)
  * Корректирующая способность: t ошибок при 2t контрольных символах
* **Алгоритм Берлекэмпа-Велча:** декодирование кодов Рида-Соломона за O(n²) или быстрее через NTT

## **3. Геометрия чисел**
* **Теорема Минковского:** выпуклое симметричное тело в ℝⁿ с обёмом > 2ⁿ содержит ненулевую целочисленную точку
* **Целочисленные точки в кругах:** ∑_{n≤x} r(n) ∼ πx где r(n) — число представлений n как суммы двух квадратов
* **Применение:** оценки числа решений, латтичные методы
