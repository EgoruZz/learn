## **A. Делимость, НОД, НОК**
> `a-folder/a.md` · `a-folder/a.cpp` · `struct Divisibility`

### A. Деление и делимость
- A.1 Фундаментальные определения: `b | a`, частное, остаток
- A.2 Свойства делимости: транзитивность, линейные комбинации

### B. Разложение на множители
- B.1 Основная теорема арифметики: каноническое разложение `n = ∏ pᵢ^αᵢ`
- B.2 Решето Эратосфена O(N log log N)
- B.3 Линейное решето O(N): SPF (smallest prime factor), быстрая факторизация за O(log x)

### C. Функции делителей
- C.1 Перебор делителей: пары `(d, n/d)` до `√n`
- C.2 Количество делителей: `d(n) = ∏(αᵢ + 1)`
- C.3 Сумма делителей: `σ(n) = ∏(pᵢ^{αᵢ+1} - 1)/(pᵢ - 1)`
- C.4 Aliquot sum: `s(n) = σ(n) - n`, предподсчёт за O(N log N)

### D. НОК
- D.1 Определение: `lcm(a,b) = |ab| / gcd(a,b)`
- D.2 Свойства: ассоциативность, `lcm(a,b)·gcd(a,b) = |ab|`

### E. НОД
- E.1 Алгоритм Евклида: `gcd(a,b) = gcd(b, a%b)`, O(log min(a,b))
- E.2 Свойства: 14 ключевых свойств, БЕЗЗ: `ax + by = gcd(a,b)`

### F. Мультипликативные функции
- F.1 Определение: `f(mn) = f(m)f(n)` при `gcd(m,n)=1`
- F.2 Функция Мёбиуса `μ(n)`: определение, линейное решето, **формула обращения Мёбиуса**
- F.3 Функция Эйлера `φ(n)`: формула `n·∏(1-1/pᵢ)`, тождества, подсчёт сумм gcd/lcm
- F.4 Дирихлева свёртка: `(f*g)(n) = Σ f(d)·g(n/d)`, ключевые свёртки (`μ*1=ε`, `φ*1=id`, `d=1*1`, `σ=id*1`)
- F.5 Функции `dₖ(n)` и `σₖ(n)`: формулы через степени простых

## **B. Модулярная арифметика, сравнения, диофантовы уравнения**
> `b-folder/b.md` · `b-folder/b.cpp` · `struct ModArithmetic : Divisibility`

### A. Основы модулярной арифметики
- A.1 Действия по модулю: сложение, вычитание, умножение, деление
- A.2 Обратные элементы: `a⁻¹ mod m` через расширенный Евклид, O(log m)
- A.3 Китайская теорема об остатках (CRT): стандартная + обобщённая, алгоритм Гарнера O(k²)

### B. Теоремы
- B.1 Малая теорема Ферма: `a^{p-1} ≡ 1 (mod p)`
- B.2 Теорема Эйлера: `a^{φ(m)} ≡ 1 (mod m)` при `gcd(a,m)=1`
- B.3 Теорема Лагранжа: полиномиальное сравнение ≤ n корней
- B.4 Теорема Дирихле: бесконечно много простых в арифметической прогрессии

### C. Линейные сравнения
- C.1 `ax ≡ b (mod m)`: условие разрешимости `gcd(a,m)|b`
- C.2 Системы сравнений: совместимость, последовательное слияние

### D. Диофантовы уравнения
- D.1 Линейные: `ax + by = c` через расширенный Евклид
- D.2 Уравнение Пелля: `x² - Dy² = 1`, метод непрерывных дробей
- D.3 Пифагоровы тройки: `x² + y² = z²`, генерация примитивных

### E. Бинарное возведение в степень
- E.1 `powmod(a, exp, mod)`: O(log exp) умножений

### F. Расширенный алгоритм Евклида
- F.1 `egcd(a, b)`: находит gcd, x, y: `ax + by = gcd`
- F.2 `modinv(a, m)`: обратный элемент по модулю

### G. Теоретико-числовые функции
- G.1 Функция Кармайкла `λ(n)`: наименьшая экспонента
- G.2 Радикал `rad(n)`: произведение различных простых
- G.3 Функция Мангольдта `Λ(n)`: `ln p` если `n = pᵏ`

### H. Квадратные вычеты и символ Лежандра
- H.1 Символ Лежандра `(a/p)`: определение, свойства, закон взаимности
- H.2 Символ Якоби: обобщение на составные модули

### I. Продвинутые темы
- I.1 p-адические числа, лемма Гензеля
- I.2 Кольца главных идеалов

### J. Прикладные темы
- J.1 RSA, Диффи-Хеллман, эллиптические кривые
- J.2 Коды Рида-Соломона
- J.3 Геометрия чисел: теорема Минковского

## **C. Свойства чисел: цифровые операции**
> `c-folder/c.md` · `c-folder/c.cpp` · `struct DigitOps`

### A. Делимость через сумму цифр
- A.1 Общее правило: `b ≡ r (mod m)` → `n mod m = Σ aᵢ·rⁱ mod m`
- A.2 Таблица правил: m = b-k, m = b+k, m = b
- A.3 Свойства суммы цифр: `S(n) ≡ n (mod b-1)`

### B. Целочисленный корень
- B.1 Метод Ньютона для `√n`: O(log log n)
- B.2 Метод Ньютона для `ᵏ√n`: O(k·log log n)
- B.3 Проверка: является ли n квадратом / k-й степенью

### C. Манипуляции с цифрами
- C.1 Извлечение / удаление / вставка цифры по позиции
- C.2 Реверс числа: O(log_b n)
- C.3 Количество цифр: `⌊log_b(n)⌋ + 1`

### D. Цифровой корень
- D.1 Формула: `dr_b(n) = 1 + (n-1) mod (b-1)`
- D.2 Свойства: `dr(a+b) = dr(dr(a)+dr(b))`

### E. Переносы и влияние на сумму цифр
- E.1 `S(a+b) = S(a) + S(b) - (b-1)·carry_count`

## **D. Дискретный анализ и корни**
> `d-folder/d.md` · `d-folder/d.cpp` · `struct DiscreteLog : ModArithmetic`

### A. Первообразные корни
- A.1 Определение: `ord_p(g) = p-1`
- A.2 Нахождение: перебор с проверкой по простым делителям p-1
- A.3 Все ПК: `g^k` — ПК ⟺ `gcd(k, p-1)=1`, количество `φ(p-1)`

### B. Индексы (дискретные логарифмы)
- B.1 Определение: `ind_g(b) = x` где `g^x ≡ b (mod p)`
- B.2 Таблица индексов: построение за O(p)

### C. Baby-Step Giant-Step (BSGS)
- C.1 Задача: `a^x ≡ b (mod m)`
- C.2 Алгоритм: x = im + j, хеш-таблица, O(√m)
- C.3 Общий случай: обработка `gcd(a,m) ≠ 1`

### D. Pohlig-Hellman
- D.1 Идея: разложение p-1 = ∏qᵢ^eᵢ, BSGS по каждому, CRT
- D.2 Сложность: O(Σ eᵢ·√qᵢ)

### E. Извлечение корня по модулю (Tonelli-Shanks)
- E.1 Быстрый случай `p ≡ 3 (mod 4)`: `x = n^{(p+1)/4}`
- E.2 Общий случай: разложение `p-1 = Q·2ˢ`, O(log² p)

### F. Корень степени k по модулю
- F.1 Через первообразный корень и индексы
- F.2 `gcd(k, p-1)` решений

## **E. Простые числа**
> `f-folder/f.md` · `f-folder/f.cpp` · `struct PrimeNumbers : ModArithmetic`

### A. Тесты простоты
- A.1 Наивный O(√n): для n ≤ 10¹²
- A.2 Тест Миллера-Рабина: вероятностный O(k·log² n), детерминированный для n < 3·10¹⁸
- A.3 Тест Соловея-Штрассена: точность ≤ 1/2
- A.4 AKS: O(log⁶ n), первый полиномиальный
- A.5 BPSW: Миллер-Рабин + Люк, нет известных контрпримеров

### B. Факторизация
- B.1 Тривиальное деление O(√n)
- B.2 Метод Ферма: `n = a² - b²`
- B.3 Поллард p-1: O(B·log n)
- B.4 Rho-алгоритм Полларда: O(n^{1/4}) в среднем
- B.5 Метод Бента, Монте-Карло

### C. Решета
- C.1 Решето Эратосфена O(N log log N)
- C.2 Линейное решето O(N)
- C.3 Решето Сундарама
- C.4 Сегментированное решето: для больших [L, R]
- C.5 Нечётное решето: экономия памяти ×2
- C.6 Решето Аткина-Берлестайна: O(N / log log N)

### D. Распределение простых
- D.1 `π(x) ~ x/ln(x)`, `π(x) ~ Li(x)`
- D.2 Формула Римана, гипотеза Римана

### E. Специальные классы простых
- E.1 Софи Жермен: p и 2p+1 простые
- E.2 Близнецы: (p, p+2)
- E.3 Мерсенна: `M_p = 2^p - 1`, тест Люка-Лемера
