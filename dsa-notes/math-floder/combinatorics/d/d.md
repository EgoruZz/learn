**D. ТЕОРИЯ ПЕРЕЧИСЛЕНИЯ**

> **Архитектура:** `BurnsidePolya` (d.cpp) — базовый класс, наследует `Combinatorics` (a.cpp). Переиспользуем: `powmod`, `modinv` (ModArithmetic), готовые ожерелья/браслеты `necklace_count`, `bracelet_count` (a.cpp, раздел E.4) — здесь общий механизм Бернсайда-Пойа, воспроизводящий их результаты. Перестановки — 0-based массивы размера n; раскраски считаются по модулю (mod простой, |G| обратим по mod).

# **A. ДЕЙСТВИЯ ГРУПП И ЦИКЛЫ**

## **1. Цикловое разложение перестановок**

### **1.1. Циклы и цикловой тип**
* **Определение:** перестановка p разлагается на непересекающиеся циклы; пример: p = (0 1 2)(3 4) на множестве {0, 1, 2, 3, 4}
* **Цикловой тип:** cₖ — число циклов длины k; всего циклов c = Σ cₖ
* **Число перестановок с типом (c₁, ..., cₙ):** n! / ∏ₖ (k^{cₖ} · cₖ!) — расставить циклы по позициям, внутри цикла k! круговых порядков... (выбрать элементы циклов и намотать на круги)
* **Почему важно:** неподвижные раскраски перестановки зависят только от числа её циклов (B.1.3)
* **Реализация:** `cycle_type`, `cycles_count`, `perms_with_cycle_type`

### **1.2. Действие группы, орбиты и стабилизаторы**
* **Определение:** группа G действует на множестве X; орбита Orb(x) = {g·x : g ∈ G}, стабилизатор Stab(x) = {g : g·x = x}
* **Теорема орбит-стабилизаторов:** |Orb(x)|·|Stab(x)| = |G| — орбита точки и её симметрии связаны
* **Пример:** повороты квадрата на 4 вершинах: орбита любой вершины = все 4 позиции, |Stab| = 1
* **Задача перечисления:** посчитать орбиты («объекты с точностью до симметрии»), не перечисляя объекты — лемма Бернсайда (B)

# **B. ЛЕММА БЕРНСАЙДА**

## **1. Формулировка и применение**

### **1.1. Лемма**
* **Формулировка:** число орбит N = (1/|G|)·Σ_{g∈G} |Fix(g)|, где Fix(g) — элементы X, неподвижные под действием g
* **Вывод (двойной подсчёт):** Σ_g |Fix(g)| = число пар (g, x) с g·x = x = Σ_x |Stab(x)| = Σ_x |G|/|Orb(x)| = |G|·(число орбит) — по теореме орбит-стабилизаторов
* **Практическая ценность:** неподвижные точки считать легко (по циклам), орбиты — трудно: лемма сводит одно к другому

### **1.2. План**
1. Задать группу симметрий перестановками элементов (B.2, B.3)
2. Для каждой перестановки посчитать число неподвижных раскрасок (1.3)
3. Усреднить по группе: разделить сумму на |G| по модулю (`modinv`)

### **1.3. Неподвижные раскраски**
* **Лемма:** раскраска неподвижна под действием g ⟺ постоянна на каждом цикле g
* **Следствие:** при k цветах неподвижных раскрасок ровно k^{c(g)}, c(g) — число циклов
* **Итоговая формула:** N = (1/|G|)·Σ_{g∈G} k^{c(g)}
* **Сложность:** O(|G|·n) — посчитать циклы каждой перестановки
* **Реализация:** `burnside_orbits`

## **2. Ожерелья и браслеты**

### **2.1. Ожерелья (повороты C_n)**
* **Группа:** n поворотов бусин; поворот на s шагов имеет gcd(s, n) циклов длины n/gcd(s, n)
* **Формула:** N = (1/n)·Σ_{d|n} φ(d)·k^{n/d} — поворотов с главным циклом длины d ровно φ(d)
* **Пример:** 6 бусин, 2 цвета: (2⁶ + 2³ + 2·2² + 2·2)/6 = 84/6 = 14
* **Реализация:** `burnside_orbits(cyclic_group(n), n, k, mod)`; готовая формула — `necklace_count` (a.cpp, E.4) — значения совпадают
* **Применение:** кольцевые слова, циклические последовательности (a.md, E.4)

### **2.2. Браслеты (диэдральная группа D_n)**
* **Группа:** к поворотам добавляются n отражений; при нечётном n отражение фиксирует одну бусину, при чётном — две
* **Формула:** см. a.md E.4; пример: 6 бусин, 2 цвета → 13
* **Реализация:** `burnside_orbits(dihedral_group(n), n, k, mod)`; готовое — `bracelet_count`
* **Отличие:** ожерелье «нельзя снять с нити», браслет можно перевернуть — разные группы симметрий, разные ответы

## **3. Раскраски куба**

### **3.1. Группа поворотов куба (24 элемента)**
* **Классы поворотов:** тождество (1); 90°/270° вокруг осей граней (6); 180° вокруг осей граней (3); 120°/240° вокруг диагоналей вершин (8); 180° вокруг осей рёбер (6) — всего 24
* **Циклы на гранях:** e → 6·1; 90° (грани) → 1·1, 1·1, 1·4 (c = 3); 180° (грани) → 2·1, 2·2 (c = 4); 120° (вершины) → 2·3 (c = 2); 180° (рёбра) → 3·2 (c = 3)
* **Циклы на вершинах:** e → 8·1; 90° → 2·4 (c = 2); 180° → 4·2 (c = 4); 120° → 2·1, 2·3 (c = 4); 180° → 4·2 (c = 4)
* **Реализация:** `cube_rotations()` — генератор 24 поворотов (ортогональные матрицы 3×3 с det = +1), возвращает перестановки 6 граней и 8 вершин

### **3.2. Примеры**
* **Грани, 2 цвета:** (2⁶ + 6·2³ + 3·2⁴ + 8·2² + 6·2³)/24 = 240/24 = 10
* **Вершины, 2 цвета:** (2⁸ + 6·2² + 3·2⁴ + 8·2⁴ + 6·2⁴)/24 = 552/24 = 23
* **Грани, 3 цвета:** (3⁶ + 6·3³ + 3·3⁴ + 8·3² + 6·3³)/24 = 1368/24 = 57
* **Применение:** раскраски многогранников, «различные» конфигурации при сборке кубика

# **C. ТЕОРИЯ ПОЙА**

## **1. Цикловой индекс**
* **Определение:** Z(G) = (1/|G|)·Σ_g x₁^{c₁(g)}·x₂^{c₂(g)}·...·xₙ^{cₙ(g)} — многочлен, «суммирующий» цикловые типы всей группы
* **Примеры:** Z(C₆) = (x₁⁶ + x₂³ + 2x₃² + 2x₆)/6; Z(куб, грани) = (x₁⁶ + 6x₁²x₄ + 3x₁²x₂² + 8x₃² + 6x₂³)/24
* **Зачем:** цикловой индекс — «паспорт» группы: одна формула обслуживает все раскраски

## **2. Теорема Пойа**
* **Формулировка:** число орбит раскрасок m цветами с весами w₁, ..., wₘ равно Z(G)(x_k := Σ_{i=1..m} w_iᵏ) — в цикловой индекс подставляем суммы степеней весов
* **Частные случаи:** все веса = 1 → лемма Бернсайда; два цвета весов 1 и t → производящая функция по числу элементов первого цвета
* **Почему работает:** цикл длины k вносит в вес раскраски ровно k·w_i (все элементы цикла одного цвета), а подстановка x_k = Σ w_iᵏ аккуратно суммирует вклады циклов
* **Реализация:** `polya_two_color` — распределение орбит по числу «чёрных» элементов: a[j] = (1/|G|)·Σ_g [tʲ] ∏ₖ (1 + tᵏ)^{cₖ(g)}

## **3. Применения**

### **3.1. Ожерелья с фиксированным составом**
* **Пример (химия):** дихлорбензол C₆H₄Cl₂ — ожерелья из 6 бусин, 2 цвета, ровно 2 «чёрных»: a[2] = 3 — орто-, мета- и пара-изомеры
* **Распределение для C₆:** 1, 1, 3, 4, 3, 1, 1 (сумма 14 = все ожерелья 2 цветов)
* **Куб (грани):** 1, 1, 2, 2, 2, 1, 1 (сумма 10): две чёрные грани — 2 типа (смежные и противоположные)
* **Применение:** подсчёт изомеров по составу, раскраски с заданным числом цветов каждого типа

### **3.2. Химия и кристаллография (общая схема)**
* **Схема:** «структура + группа симметрий (точечная группа) + цикловой индекс + подстановка весов» — универсальный рецепт перечисления
* **Примеры:** бензольное кольцо — C₆, бифенил — D_n, кристаллическая решётка — её точечная группа; изомеры и классы позиций считаются одной техникой

### **3.3. Неизоморфные графы**
* **Задача:** число графов на n вершинах с точностью до перенумерации вершин
* **Модель:** группа S_n действует на рёбрах (их C(n,2)): перестановка вершин индуцирует перестановку рёбер; граф = 2-раскраска рёбер (есть/нет)
* **Алгоритм:** перебор всех n! перестановок, циклы на рёбрах, Бернсайд: N = (1/n!)·Σ_p 2^{c(p)}
* **Сложность:** O(n!·n²) — применимо для n ≤ 7 (далее — цикловые индексы Злата)
* **Значения:** n = 1..6: 1, 2, 4, 11, 34, 156
* **Реализация:** `graph_orbits`
