# **A. ФАКТОРИАЛЫ И БИНОМИАЛЬНЫЕ КОЭФФИЦИЕНТЫ**

## **1. Факториал**

### **1.1. Определение**
* **Факториал:** n! = 1·2·3·...·n, причём 0! = 1 (пустое произведение)
* **Интуиция:** n! — число способов упорядочить n различных предметов (рассадить n людей на n мест)
* **Рост:** n! ~ √(2πn)·(n/e)ⁿ (формула Стирлинга) — для оценки и сравнения с переполнением
* **Границы типа:** int64 вмещает 20!, поэтому в олимпиадах факториал почти всегда берут по модулю

### **1.2. Двойной факториал (Double Factorial)**
* **Определение:** n!! = n·(n-2)·(n-4)·...
  * Чётное n = 2k: n!! = 2k·(2k-2)·...·2 = 2^k·k!
  * Нечётное n = 2k+1: n!! = (2k+1)·(2k-1)·...·1 = (2k+1)! / (2^k·k!)
* **Применение:** число способов разбить 2n предметов на n неупорядоченных пар = (2n-1)!!
* **Пример:** 5!! = 5·3·1 = 15; 6!! = 6·4·2 = 48

### **1.3. Обобщённый факториал (мультифакториал)**
* **Определение:** n!⁽ᵐ⁾ = n·(n−m)·(n−2m)·... — произведение с шагом m
  * m = 1: обычный факториал n!
  * m = 2: двойной факториал n!!
  * m = 3: тройной факториал n!!!
* **Связь:** при n = m·k (n кратно m) все множители кратны m: n!⁽ᵐ⁾ = m^k·k!
* **Идея обобщения:** факториал — семейство: фиксируем шаг m, и «обычный» факториал — лишь шаг 1. Мультифакториалы возникают в разложениях функций и в подсчёте структур с периодом m

### **1.4. Степень простого в факториале**
* **Задача:** найти максимальное k: p^k | n! — обозначение v_p(n!) (p-адическая оценка n!)
* **Формула Лежандра:** v_p(n!) = ⌊n/p⌋ + ⌊n/p²⌋ + ⌊n/p³⌋ + ... = Σᵢ₌₁^∞ ⌊n/pⁱ⌋
  * **Почему работает:** ⌊n/p⌋ — числа, кратные p (дают хотя бы один множитель p); ⌊n/p²⌋ — кратные p² (дают ещё один); ⌊n/p³⌋ — ещё один; ... и так далее, пока pⁱ ≤ n
  * **Сложность:** O(log_p n)
  * **Пример:** v₅(100!) = ⌊100/5⌋ + ⌊100/25⌋ + ⌊100/125⌋ = 20 + 4 + 0 = 24
* **Аддитивность:** v_p(a₁·a₂·...·aₖ) = Σ v_p(aᵢ) — степень простого в произведении равна сумме степеней в сомножителях
  * **Следствие для бинома:** v_p(C(n,k)) = v_p(n!) − v_p(k!) − v_p((n−k)!)
* **Теорема Кюммера:** v_p(C(n,k)) = число переносов при сложении k + (n−k) в системе счисления по основанию p
  * **Почему работает:** перенос возникает, когда сумма цифр ≥ p — это и есть «захват» множителя p
  * **Пример:** C(10,3), p=2: 3 = 0011₂, 7 = 0111₂, при сложении 3+7 = 10 (1010₂) переносы на разрядах 0, 1, 2 → v₂(C(10,3)) = 3 (C(10,3) = 120 = 8·15) ✓ — см. также пример в 2.10
* **Хвостовые нули:** число нулей в конце n! в десятичной записи = v₅(n!)
* **Обратная задача:** наименьший n, при котором m | n!
  * Для каждого простого делителя p^e числа m ищем минимальное n_p: v_p(n_p!) ≥ e (бинарный поиск по n с проверкой через формулу Лежандра); ответ = max по всем n_p
  * **Сложность:** O(log² m) на простой делитель
  * **Пример:** m = 100 = 2²·5²: n₂ = 4 (v₂(4!) = 3 ≥ 2), n₅ = 10 (v₅(10!) = 2 ≥ 2) → ответ 10

### **1.5. Факториал по модулю простого p**
* **Наивный метод:** n! mod p = (1·2·...·n) mod p за O(n)
  * **Проблема:** при n ≥ p результат всегда 0 (в n! есть множитель p) — наивный цикл бесполезен
* **Структура (факториал без кратных p):** разбиваем n! на «чистые» множители:
  n! = p^{v_p(n!)} · F(n), где F(n) = ∏ i по i ∈ [1, n], p ∤ i — произведение чисел от 1 до n без кратных p
* **Рекурсия для F(n):** F(n) = F(⌊n/p⌋) · (−1)^{⌊n/p⌋} · (n mod p)! (mod p)
  * **Почему:** каждое число от 1 до n — либо p·t (его вклад уходит в F(⌊n/p⌋)), либо «голое»; «голые» множители повторяются с периодом p: ⌊n/p⌋ полных блоков по (p−1)! ≡ −1 (Вильсон), остаток — хвост (n mod p)!
  * **Рекурсивное вычисление n! mod p (без кратных p):** O(p log_p n), глубина рекурсии O(log_p n)
* **Теорема Вильсона:** (p−1)! ≡ −1 (mod p) для простого p
  * **Доказательство:** каждый a ∈ [2, p−2] имеет обратный a⁻¹ mod p, и a ≠ a⁻¹ (иначе a² ≡ 1 → a = ±1)
  * **Следствие:** произведение всех элементов от 2 до p−2 ≡ 1 (mod p); в рекурсии выше блок (∏ᵢ₌₁^{p−1} i)^{⌊n/p⌋} = (p−1)!^{⌊n/p⌋} = (−1)^{⌊n/p⌋}
  * **Применение:** тест простоты Вильсона (см. number-theory), ускорение вычисления факториала
* **Полное представление:** пара {v_p(n!), n!/p^{v_p(n!)} mod p} — степень p и «чистый» остаток
* **Обобщение:** тот же приём «вынести кратные p, посчитать чистое произведение» для степени простого p^e — см. 2.11 (fact_free) и 1.5.1 (факториал по составному модулю)
* **Сложность:** O(p log_p n) — быстрее наивного O(n), когда p много меньше n

#### **1.5.1. Факториал по составному модулю m (обобщение через CRT)**
* **Проблема:** при составном m приём Вильсона из 1.5 работает только для простого модуля; нужен другой путь
* **Идея:** разложить m = p₁^{e₁}·p₂^{e₂}·...·p_s^{e_s}, посчитать n! mod p_i^{e_i} отдельно и собрать китайской теоремой об остатках (CRT)
* **n! mod p^e (тот же приём «вынести кратные p»):**
  1. Степень p — формула Лежандра: v = v_p(n!). Если v ≥ e — ответ 0 (в n! «набралось» p^e)
  2. Иначе n! = p^v · f(n) mod p^e, где f(n) = n!/p^{v_p(n!)} mod p^e — p-свободная часть (см. fact_free, 2.11): f(n) = P^{⌊n/p^e⌋} · Q(n mod p^e) · f(⌊n/p⌋), где P — произведение чисел ≤ p^e, не делящихся на p (период), Q(t) — произведение чисел ≤ t, не делящихся на p
* **Сборка (CRT):** по остаткам r_i mod p_i^{e_i} восстанавливаем единственный остаток mod m (попарная взаимная простота модулей)
* **Сложность:** O(Σ p_i^{e_i}·log_{p_i} n) на запрос + O(s) на CRT — то же, что в 2.11
* **Связь с биномами:** C(n,k) mod m = n!·(k!)⁻¹·((n−k)!)⁻¹ mod m по составному модулю — см. 2.11; там дополнительно нужны обратные p-свободных частей (они взаимно просты с m), здесь — нет
* **Реализация:** fact_mod_ppow (n! mod p^e) + fact_mod_composite (n! mod m, разложение + CRT)
* **Пример:** 10! mod 100: v₂(10!) = 8 ≥ 2 и v₅(10!) = 2 ≥ 2 → 0 mod 4 и 0 mod 25 → ответ 0 (10! = 3628800 делится на 100); 4! mod 10: 0 mod 2 (v₂(4!) = 3 ≥ 1), 4 mod 5 (f(4) = 24 ≡ 4) → CRT даёт 4 (24 mod 10 = 4)

### **1.6. Циклические перестановки**
* **Определение:** число рассаживаний n людей за круглым столом = (n−1)!
* **Почему:** линейных расстановок n!, каждое круговое расположение считается n раз (n поворотов)
* **Обобщение:** если места за столом пронумерованы (с учётом поворотов) — снова n!; если разрешены отражения (стол переворачивается) — (n−1)!/2

### **1.7. Генерация перестановок (алгоритмы факториала)**
Почему этот раздел живёт в теории факториала: перестановок ровно n!, все алгоритмы их генерации опираются на факториал — вплоть до факториальной системы счисления, где факториал играет роль «веса» разряда.

#### **1.7.1. Алгоритм Нарайаны (лексикографический порядок)**
* **Идея:** от текущей перестановки к следующей лексикографически большей
* **Шаги:**
  1. Найти максимальный i: a[i] < a[i+1]
  2. Найти максимальный j: a[j] > a[i]
  3. Обменять a[i] и a[j]
  4. Развернуть суффикс a[i+1..n]
* **Применение:** перебор всех перестановок в лексикографическом порядке, начиная с отсортированной
* **Сложность:** O(n) на следующую перестановку, всего O(n!) перестановок (O(n·n!) суммарно)
* **Эквивалент в STL:** std::next_permutation
* **Обобщение:** тот же приём работает для любых последовательностей с линейным порядком (мультимножества, битовые маски) — «следующий объект» вместо перечисления с нуля

#### **1.7.2. Рекурсивный перебор (backtracking)**
* На каждой позиции пробуем все ещё не использованные элементы
* **Сложность:** O(n!) с памятью O(n)
* **Плюс:** можно на лету отсекать неперспективные ветви (например, по условию задачи)
* **С генерацией с повторениями:** не используем массив used, и/или пропускаем одинаковые соседние кандидаты

#### **1.7.3. K-я перестановка (факториальная система счисления, Lehmer code)**
* **Идея:** любое k ∈ [0, n!) однозначно записывается в факториальной системе счисления (см. 4.2):
  k = c₁·(n−1)! + c₂·(n−2)! + ... + c_n·0!, где 0 ≤ cᵢ ≤ n−i
* **Алгоритм:** на позиции i выбираем цифру cᵢ = k/(n−i−1)! — берём элемент с номером cᵢ среди оставшихся, остаток k %= (n−i−1)!
* **Обратно (rank):** считаем, сколько меньших неиспользованных элементов стоит правее каждого, и собираем число
* **Сложность:** O(n²) наивно, O(n log n) с деревом отрезков/Фенвиком
* **Пример:** n=4, k=5 (с 0): 5/3!=0 → берём 1-й элемент, k=5; 5/2!=2 → берём 3-й из оставшихся...
* **Обобщение:** та же техника «делим на размер блока» даёт k-е сочетание, k-е подмножество, k-ю скобочную последовательность — факториальная система счисления заменяется на свою для каждого семейства

## **2. Биномиальные коэффициенты**

### **2.1. Определение**
* **Определение:** C(n,k) = n! / (k!·(n−k)!) — число k-элементных подмножеств n-элементного множества
* **Терминология:** также «число сочетаний», обозначается C(n,k), ⁿCₖ, (n k), C^k_n
* **Асимметрия:** C(n,k) = C(n, n−k) — выбор k элементов = выбор n−k «выброшенных»
* **Крайние значения:** C(n,0) = C(n,n) = 1, C(n,1) = n, C(n,2) = n(n−1)/2

### **2.2. Способы вычисления**
* **Итеративный (без факториалов):** res = res·(n−i)/(i+1), i = 0..k−1
  * **Почему деление точное:** произведение k последовательных чисел всегда делится на k!
  * **Ограничение:** работает в int64 до n = 66 (C(67,33) ≈ 1.42·10¹⁹ уже переполняет int64)
* **Через факториалы по модулю p:** C(n,k) = fact[n]·inv_fact[k]·inv_fact[n−k] mod p
  * Предподсчёт fact и inv_fact за O(N), запрос за O(1)
  * **Ограничение:** нужен n < p (иначе знаменатель может быть 0 mod p)
* **Через треугольник Паскаля:** C(n,k) = C(n−1,k) + C(n−1,k−1)
  * Таблица до N за O(N²), каждый элемент без деления и переполнения (по модулю)
  * **Почему формула:** фиксируем один элемент — он либо входит в подмножество (C(n−1,k−1)), либо нет (C(n−1,k))

### **2.3. Генерация биномиальных коэффициентов (все сочетания)**
Почему здесь: C(n,k) — число сочетаний, значит генерация всех k-элементных подмножеств — это «генерация биномиальных коэффициентов».

#### **2.3.1. Рекурсивная**
* Перебираем позиции, на каждой выбираем следующий элемент больше предыдущего (start = prev+1)
* **Сложность:** O(C(n,k)) — каждое сочетание выводится ровно один раз

#### **2.3.2. На основе битовых масок**
* Для всех mask от 0 до 2ⁿ−1: если popcount(mask) == k — выводим элементы, где бит = 1
* **Сложность:** O(2ⁿ·n) — медленнее рекурсии, но проще в коде

#### **2.3.3. Gosper's Hack (следующая комбинация)**
* **Идея:** из текущей маски с k битами получаем следующую за O(1):
  c = x & −x; r = x + c; x = (((r ^ x) >> 2) / c) | r
* **Применение:** перебор всех C(n,k) подмножеств фиксированного размера за O(C(n,k)) — эффективнее битовых масок

### **2.4. Треугольник Паскаля**
* Строка n содержит C(n,0), C(n,1), ..., C(n,n)
* Каждая клетка = сумма двух родителей сверху
```
        1
      1   1
    1   2   1
  1   3   3   1
1   4   6   4   1
```
* **Ключевые тождества, читаемые из треугольника:**
  * Сумма строки: Σ C(n,k) = 2ⁿ (все подмножества)
  * Знакочередующаяся сумма: Σ (−1)^k·C(n,k) = 0 при n ≥ 1
  * Хоккейная клюшка: Σ_{i=k}^{n} C(i,k) = C(n+1, k+1)
  * Свёртка Вандермонда: Σ C(n,i)·C(m,k−i) = C(n+m,k)
  * Сумма квадратов: Σ C(n,k)² = C(2n,n)
  * Диагонали: Σ_{k=0}^{n} C(k+m,k) = C(n+m+1, m+1)

### **2.5. Мультиномиальные коэффициенты**
* **Определение:** число разбиений n элементов на группы размеров k₁, k₂, ..., k_m:
  n! / (k₁!·k₂!·...·k_m!), где k₁ + k₂ + ... + k_m = n
* **Связь с биномом:** мультиномиальный = произведение последовательных биномов:
  C(n; k₁, k₂, ..., k_m) = C(n, k₁)·C(n−k₁, k₂)·C(n−k₁−k₂, k₃)·...
* **Обобщение:** разбиение групп на подгруппы даёт произведение мультиномиальных коэффициентов (правило «делим поэтапно»)
* **Пример:** слово «МАМА» — перестановки с повторениями: 4!/(2!·2!) = 6

### **2.6. Биномиальная и мультиномиальная теоремы**
* **Бином Ньютона:** (x+y)ⁿ = Σ_{k=0}^{n} C(n,k)·x^k·y^(n−k)
  * **Частные случаи:** (1+1)ⁿ = 2ⁿ, (1−1)ⁿ = 0
* **Обобщение на m переменных (мультиномиальная теорема):**
  (a₁ + a₂ + ... + a_m)ⁿ = Σ_{k₁+k₂+...+k_m = n} C(n; k₁, k₂, ..., k_m)·a₁^{k₁}·a₂^{k₂}·...·a_m^{k_m},
  где C(n; k₁, k₂, ..., k_m) = n! / (k₁!·k₂!·...·k_m!) — мультиномиальный коэффициент
* **Почему формула:** коэффициент при a₁^{k₁}...a_m^{k_m} — число способов распределить n множителей по m группам
* **Бином Ньютона = частный случай** мультиномиальной теоремы при m = 2
* **Применения:** разложение степеней, производящие функции, извлечение тождеств, подсчёт в комбинаторике

### **2.7. Метод «Шаров и перегородок» (Stars and Bars)**
* **Определение:** C(n+k−1, k) — число способов выбрать k элементов из n видов с повторениями
* **Переформулировка:** число решений x₁ + x₂ + ... + x_n = k, xᵢ ≥ 0
* **Почему «звёзды и барьеры»:** рисуем k звёзд и n−1 барьер между n видами; всего перестановок с повторениями (k+n−1)!/(k!·(n−1)!) = C(n+k−1, k)
* **Обобщение с ограничениями:** если xᵢ ≥ aᵢ — замена yᵢ = xᵢ − aᵢ: C(n+k−Σaᵢ−1, n−1); если xᵢ ≤ bᵢ — включения-исключения
* **Пример:** число способов раздать k одинаковых конфет n детям (кому-то 0) = C(n+k−1, k)

### **2.8. Размещения (Accommodations / Placements)**
* **Без повторений**
  * **Определение:** A(n,k) = n·(n−1)·...·(n−k+1) = n!/(n−k)! — число упорядоченных k-наборов из n элементов
  * **Интуиция:** выбираем k человек из n И рассаживаем их на k пронумерованных мест
  * **Связь:** A(n,k) = C(n,k)·k! (сначала выбрать множество, потом упорядочить)
* **С повторениями**
  * **Определение:** A'(n,k) = n^k — число упорядоченных k-наборов, элементы могут повторяться
  * **Интуиция:** каждый из k выборов — n способов, правило произведения
  * **Пример:** число k-значных слов в алфавите из n букв = n^k
* **Схема «какие объекты, какое число»:** (здесь n — число предметов, k — число ящиков — в отличие от 2.7, где n — число видов, k — число выбираемых)
  * Различные предметы по различным ящикам: n^k (у каждого предмета k вариантов)
  * Различные предметы по одинаковым ящикам: S(n,k) (числа Стирлинга II рода, special-sequences.md, раздел G)
  * Одинаковые предметы по различным ящикам: C(n+k−1, n) (звёзды и барьеры, можно пустые)
  * Одинаковые предметы по одинаковым ящикам: p_k(n) (разбиения числа n на k частей, раздел B — производящие функции)
  * Если каждый ящик не пустой: замена xᵢ = yᵢ + 1 → C(n−1, k−1)

### **2.9. Обобщённые биномиальные коэффициенты**
* **Определение:** C(a,k) для произвольного числа a (не обязательно целого):
  C(a,k) = a·(a−1)·...·(a−k+1) / k!
* **Случай отрицательного целого:** C(−n,k) = (−1)^k·C(n+k−1, k)
* **Применение:** бином Ньютона с отрицательными/дробными степенями, производящие функции, ряд (1−x)^(−n) = Σ C(n+k−1, k)·x^k

### **2.10. Биномиальные коэффициенты по модулю простого**
* **Предподсчёт факториалов + обратных**
  * Обратный элемент: inv(x) = x^(p−2) mod p (малая теорема Ферма), p простое
  * inv_fact[n] = inv(fact[n]); обратные всех факториалов за O(N) или по формуле inv_fact[i] = inv_fact[i+1]·(i+1)
  * **Итог:** C(n,k) mod p за O(1) после предподсчёта O(N)
* **Теорема Люка (Lucas)**
  * **Проблема:** при n ≥ p обычный предподсчёт не работает (факториал обращается в 0 mod p)
  * **Теорема:** запишем n и k в системе по основанию p: n = n₁p + n₀, k = k₁p + k₀ → C(n,k) ≡ C(n₁,k₁)·C(n₀,k₀) (mod p)
  * **Рекурсивно:** Lucas(n,k) = Lucas(n/p, k/p)·C(n mod p, k mod p) mod p
  * **Сложность:** O(p + log_p n) на запрос (после предподсчёта факториалов до p−1)
  * **Следствие:** C(n,k) mod p ≠ 0 ⟺ каждый разряд k не превосходит разряда n (k «вписывается» в n по цифрам)
  * **Пример:** C(10,3) mod 2 — 10 = 1010₂, 3 = 0011₂. Сравниваем разряды: в разряде 0 цифра k больше цифры n (1 > 0) → C(10,3) чётно ✓. По Кюммеру: v₂(C(10,3)) = числу переносов при сложении 3 + 7 = 10 в двоичной системе — переносы на разрядах 0, 1, 2 → v₂ = 3 (C(10,3) = 120 = 8·15) ✓

### **2.11. Биномиальные коэффициенты по составному модулю (обобщение)**
* **Проблема:** при составном m у чисел, не взаимно простых с m, нет обратного по модулю m; факториал обращается в 0 — методы из 2.10 напрямую не работают
* **Идея:** разложить m на простые степени m = p₁^{e₁}·p₂^{e₂}·...·p_s^{e_s}, посчитать C(n,k) mod p_i^{e_i} отдельно, собрать китайской теоремой об остатках (CRT)
* **C(n,k) mod p^e (обобщение Люка на степень простого):**
  1. Считаем степень p через формулу Лежандра: v = v_p(n!) − v_p(k!) − v_p((n−k)!). Если v ≥ e — ответ 0
  2. Считаем p-свободную часть факториала f(n) = n! / p^{v_p(n!)} mod p^e рекурсивно:
     f(n) = P^{⌊n/p^e⌋} · Q(n mod p^e) · f(⌊n/p⌋) mod p^e,
     где P — произведение чисел от 1 до p^e, не делящихся на p (период), Q(t) — произведение чисел от 1 до t, не делящихся на p
  3. Ответ: C(n,k) = p^v · f(n) · f(k)⁻¹ · f(n−k)⁻¹ mod p^e. Обратные существуют: f-части взаимно просты с p^e (расширенный алгоритм Евклида)
* **Сборка (CRT):** по остаткам r_i mod p_i^{e_i} восстанавливаем единственный остаток r mod m (попарная взаимная простота модулей)
* **Сложность:** O(Σ p_i^{e_i}·log_{p_i} n) на запрос + O(s) на CRT (fact_free считает период P за O(p^e) на каждом уровне рекурсии)
* **Обобщение:** тот же приём — «разложить модуль, посчитать по степеням простых, собрать CRT» — работает для факториала по составному модулю и других арифметических функций

## **3. Правила суммы и произведения**

### **3.1. Правило суммы**
* Если объект можно выбрать способом A₁ или способом A₂ (не пересекающимися), то всего A₁ + A₂ способов
* **Ключевое слово:** «или» → сложение; множества обязаны не пересекаться
* **Обобщение:** для k попарно непересекающихся множеств — сумма |A₁| + |A₂| + ... + |A_k|; пересекающиеся — см. включения-исключения (B)

### **3.2. Правило произведения**
* Если первый выбор делается n₁ способами, второй — n₂ (независимо), то пара — n₁·n₂ способами
* **Ключевое слово:** «и» → умножение
* **Обобщение:** k независимых выборов из n₁, n₂, ..., n_k → n₁·n₂·...·n_k способов

### **3.3. Биективный метод**
* Если между двумя классами объектов есть биекция, их количество совпадает
* **Приём олимпиад:** не считаем сложный объект — находим простой, биективный ему

## **4. Специальные системы счисления**

### **4.1. Троичная сбалансированная система**
* **Определение:** основание 3, но цифры {−1, 0, 1} (обозначаются T, 0, 1): n = Σ dᵢ·3ⁱ, где dᵢ ∈ {−1, 0, 1}
* **Каноничность:** каждое целое число имеет единственное представление
* **Алгоритм перевода:** делим n на 3:
  * остаток 0 → цифра 0, n = n/3
  * остаток 1 → цифра 1, n = n/3
  * остаток 2 → цифра T (−1), n = (n+1)/3 (перенос 1)
  * Отрицательные числа: остаток −1 → цифра T, n = (n+1)/3; остаток −2 → цифра 1, n = (n−1)/3
* **Пример:** 5 → 5%3=2 → цифра T, n=(5+1)/3=2; 2%3=2 → цифра T, n=1; 1%3=1 → цифра 1 → 1TT₃ = 1·9 + (−1)·3 + (−1)·1 = 5 ✓
* **Свойства:**
  * **Бесконечная точность:** отрицательные числа представляются естественно — знак «встроен» в цифры, отдельного знакового разряда нет
  * **Арифметика:** сложение и умножение с переносами как в обычных позиционных системах
  * **Преимущество над дополнительным кодом:** нет проблемы «переполнения знакового бита» — при сложении двух представлений не нужна знаковая битность
* **Сложность перевода:** O(log₃ n)

### **4.2. Факториальная система счисления**
* **Определение:** позиции имеют вес i! (1!, 2!, 3!, 4!, ...); цифра dᵢ ∈ [0, i]:
  n = Σ dᵢ·i! = d₁·1! + d₂·2! + d₃·3! + ...
* **Каноничность:** каждое неотрицательное целое число имеет единственное представление
* **Количество цифр:** для числа n нужно до ~⌊log₂ n⌋ цифр (т.к. k! > 2^(k−1) при k ≥ 4)
* **Алгоритм перевода:** делим n на 2 → цифра d₁ (остаток), n /= 2; делим на 3 → цифра d₂, n /= 3; делим на 4 → цифра d₃, n /= 4; ... пока n > 0 (в коде к этой же процедуре добавлен деление на 1 первым шагом — оно всегда даёт цифру 0 и лишний разряд)
* **Пример:** 46 = 0·1! + 2·2! + 3·3! + 1·4! = 0·1 + 2·2 + 3·6 + 1·24 = 46 (в коде цифры печатаются от старшего разряда с весом (len−1)!, поэтому 46 выводится как `1!3!2!0!0` = 1·4! + 3·3! + 2·2! + 0·1! + 0·0!)
* **Ключевое применение — комбинаторика:** индекс перестановки ↔ перестановка (Lehmer code, см. 1.7.3); k-е сочетание, k-е подмножество — та же техника «делим на размер блока»
* **Свойства:**
  * Факториальные числа: 1, 2, 6, 24, 120, 720, ...
  * Количество цифр: O(log n / log log n) — меньше, чем в двоичной записи
* **Сложность перевода:** O(log n / log log n)

# **B. ПРИНЦИП ВКЛЮЧЕНИЙ-ИСКЛЮЧЕНИЙ**

## **1. Классическая формула**
* **Для двух множеств:** |A ∪ B| = |A| + |B| − |A ∩ B|
* **Для трёх:** |A∪B∪C| = |A|+|B|+|C| − |A∩B| − |A∩C| − |B∩C| + |A∩B∩C|
* **Общая формула:** |A₁ ∪ ... ∪ A_n| = Σ|Aᵢ| − Σ|Aᵢ∩Aⱼ| + Σ|Aᵢ∩Aⱼ∩A_k| − ... ± |A₁∩...∩A_n|
* **Почему работает:** элемент, попавший ровно в m множеств, посчитан Σ C(m,i)·(−1)^(i+1) = 1 раз (бином Ньютона)
* **Обобщение:** если нужно, чтобы объект попал ровно в t множеств — умножаем слагаемые на C(i,t) (обобщённые включения-исключения)

## **2. Применения к задачам на пересчёт**

### **2.1. Перестановки с запрещёнными позициями (задача о ладьях)**
* **Постановка:** сколько перестановок π ∈ S_n, у которых π(i) ∉ S_i (элемент i нельзя ставить на запрещённые позиции)?
* **Переформулировка (ладьи):** доска n×n, клетки (i, j) с j ∈ S_i запрещены; перестановка — расстановка n ладей, не бьющих друг друга; нужно расставить их, не трогая запрещённые клетки
* **Включения-исключения:** пусть R_r — число способов расставить r не бьющих друг друга ладей на запрещённых клетках (r независимых «нарушений»). Тогда:
  ответ = Σ_{r=0}^{n} (−1)^r · R_r · (n−r)!
* **Почему:** зафиксировали r нарушений — их можно выбрать R_r способами, остальные n−r элементов ставим произвольно на свободные места: (n−r)!
* **Частный случай:** S_i = {i} (только «свои» места) — R_r = C(n,r), получаем беспорядки D(n) = Σ_{r} (−1)^r·C(n,r)·(n−r)! = n!·Σ(−1)^r/r! (раздел 3)
* **Сложность:** R_r считается ДП по битовым маскам O(n·2ⁿ) для малых n; для структурированных запретов (клетки одной формы) — комбинаторно

### **2.2. Слова с обязательным использованием букв**
* **Постановка:** алфавит из k букв, слова длины n. Сколько слов используют каждую букву из заданного множества A (|A| = t) хотя бы один раз?
  ответ = Σ_{i=0}^{t} (−1)^i·C(t,i)·(k−i)ⁿ
* **Почему:** вычитаем слова без буквы a ∈ A (их (k−1)ⁿ), прибавляем без двух букв ((k−2)ⁿ), и т.д.
* **Пример:** слова длины n над {a,b,c} хотя бы с одной 'a' и одной 'b' (t = 2, k = 3): 3ⁿ − 2·2ⁿ + 1
* **Связь с сюръекциями:** t = k («использованы все k букв») — в точности сюръективные отображения из n позиций в k букв (см. 2.3)
* **Обобщение:** включения-исключения по свойствам «буква не используется» — «хотя бы одна из букв A», «все буквы A использованы», «хотя бы m из A»

### **2.3. Сюръективные отображения**
* Число сюръекций из n-элементного множества в k-элементное:
  Σ_{i=0}^{k} (−1)^i·C(k,i)·(k−i)ⁿ
* **Почему:** из всех отображений kⁿ выкидываем те, что не используют какие-то элементы
* **Обобщение:** те же включения-исключения дают отображения, использующие ровно заданное число элементов; на «раскраски» с использованием всех цветов

## **3. Задача о беспорядках (Derangements)**

### **3.1. Определение**
* **Беспорядок** — перестановка без неподвижных точек: π(i) ≠ i для всех i
* **Обозначение:** D(n) = !n — число беспорядков n элементов

### **3.2. Рекуррентные формулы**
* **Основная:** D(n) = (n−1)·(D(n−1) + D(n−2)), при D(1)=0, D(2)=1
  * **Почему:** элемент 1 отправляется в позицию i (n−1 способов). Если элемент i тоже на месте 1 — осталось D(n−2); иначе D(n−1)
* **Альтернативная:** D(n) = n·D(n−1) + (−1)ⁿ, D(1)=0
* **Формула включениями-исключениями:** D(n) = n!·Σ_{i=0}^{n} (−1)ⁱ/i!
  * **Почему:** из n! перестановок вычитаем с фиксированной точкой, прибавляем с двумя, ...
* **Асимптотика:** D(n) = ⌊n!/e + 1/2⌋ (ближайшее целое к n!/e)

### **3.3. Пример**
* D(3): беспорядки {2,3,1}, {3,1,2} → D(3)=2
* D(4) = 3·(D(3)+D(2)) = 3·(2+1) = 9
* **Олимпиадное применение:** задача «письма и конверты», задача о перепутанных шляпах, задача о встрече

# **D. ГЕНЕРАЦИЯ КОМБИНАТОРНЫХ ОБЪЕКТОВ**

## **1. Подмножества и подпоследовательности**

### **1.1. Все подмножества (All Subsequences / Subsets)**
* **Битовые маски:** mask = 0..2ⁿ−1, элемент i входит если (mask >> i) & 1
* **Суммарная сложность:** O(2ⁿ·n) — каждое подмножество обработать
* **Обобщение:** тот же перебор — все подпоследовательности (не важно, в каком порядке брать элементы) и все битовые раскраски

### **1.2. Перебор подмасок (подмножеств данной маски)**
* **Приём олимпиад:** for (int sub = mask; ; sub = (sub−1) & mask) — перебор всех подмножеств mask
* **Суммарно за O(3ⁿ):** Σ 2^popcount(mask) = 3ⁿ по всем mask
* **Применение:** ДП по подмножествам, покрытия, разбиения

## **2. Серый код (Gray Code)**
* **Определение:** последовательность всех 2ⁿ кодов, где соседние отличаются ровно в одном бите
* **Формула:** gray(k) = k ^ (k >> 1); обратно: k = gray; k ^= k>>1; k ^= k>>2; ... (или бинарный поиск)
* **Применение:** перебор подмножеств с пересчётом за O(1) (изменился ровно один элемент), задачи на повороты, Hamming distance
* **Пример:** n=3: 000, 001, 011, 010, 110, 111, 101, 100
* **Обобщение:** многомерный серый код (циклический сдвиг по каждой координате), коды с постоянным весом (все комбинации из k бит, отличающиеся на два переключения)

## **3. Правильные скобочные последовательности (Generate Parentheses)**
* **Определение:** последовательности из n открывающих и n закрывающих скобок, где в любом префиксе открывающих не меньше закрывающих
* **Рекурсивная генерация (backtracking):** добавляем '(' если open < n; добавляем ')' если close < open
* **Количество:** числа Каталана C_n = C(2n,n)/(n+1)
* **Итеративная генерация (Generate Parentheses Iterative):** начинаем с «(((...)))», применяем next_permutation и проверяем корректность (предикат-баланс)
* **С приоритетами (несколько типов скобок):** генерация по правилам вложенности разных типов, отслеживая стек типов
* **Проверка корректности строки:** баланс-счётчик: '(' → +1, ')' → −1, никогда не уходить в минус
* **Обобщение:** каталановские структуры (лестницы, двоичные деревья, триангуляции) — все считаются одним числом Каталана, биекции между ними

# **E. СПЕЦИАЛЬНЫЕ КОМБИНАТОРНЫЕ КОНФИГУРАЦИИ**

## **1. Задача Иосифа Флавия (Josephus Problem)**
* **Постановка:** n человек в круге, каждые k-го удаляют, начиная с 1-го (или k-го). Найти номер последнего оставшегося
* **Индексация с 0:** J(n,k) = (J(n−1,k) + k) mod n, J(1,k) = 0
  * **Почему:** после удаления позиции k−1 круг перенумеровывается, размер уменьшается на 1
* **С индексацией с 1:** ответ = J(n,k) + 1
* **Быстрый вариант (большие n):** когда n велико, а k мало, делаем k-кратные «прыжки» за O(k log n):
  while (n > 1) { если осталось мало — перейти к рекуррентности по одному; иначе перепрыгнуть блок }
* **Применение:** задачи на выбывание, карточные фокусы, шифры
* **Пример:** n=7, k=3, с 1: выбывают 3,6,2,7,5,1 → остаётся 4

## **2. Задачи на покрытие (Exact Cover)**

### **2.1. Точное покрытие — постановка**
* Дана 0-1 матрица: **столбцы** — ограничения, **строки** — варианты. Нужно выбрать подмножество строк так, чтобы каждый столбец был покрыт ровно один раз
* **Первичные столбцы** — обязаны быть покрыты ровно один раз; **вторичные** — не более одного раза (нет обязательности)
* **Почему это одна задача:** судоку, N-Queens, кроссворды, покрытия доски домино/полимино, латинские квадраты, расписания — всё сводится к точному покрытию

### **2.2. Судоку как точное покрытие**
* **Вариант:** клетка × цифра — 729 строк (9×9×9)
* **Ограничения (столбцы):**
  * (клетка, занята) — 81 столбец
  * (строка, цифра) — 81 столбец
  * (столбец, цифра) — 81 столбец
  * (блок, цифра) — 81 столбец
  * Итого 324 столбца, каждая строка покрывает ровно 4 столбца
* **Алгоритм (без DLX):** backtracking — нашли пустую клетку, пробуем цифры, проверяем строку/столбец/блок
* **Оптимизации:**
  * Проверка через битовые маски строк/столбцов/блоков (проверка за O(1))
  * Выбор клетки с минимальным количеством вариантов (MRV — most constrained variable)
  * Побитовое представление кандидатов

### **2.3. N-Queens как точное покрытие**
* **Вариант:** клетка (r,c) — n² строк
* **Ограничения:** столбец c (n столбцов, первичные) + две диагональные семьи r+c и r−c+n−1 (по 2n−1, вторичные — «не более одного ферзя»)
* **Алгоритм (без DLX):** бэктрекинг по строкам с битовыми масками занятых столбцов и диагоналей
* **Сложность:** полный перебор O(n!), отсечение масками делает его практически мгновенным до n ≈ 15

### **2.4. Кроссворды как задача на покрытие**
* **Постановка:** заполнить сетку словами из словаря по горизонтали и вертикали
* **Алгоритм:** backtracking по слотам; на каждом шаге выбираем слот и слово, совместимое с уже вписанными буквами
* **Оптимизации:** сортировка слотов по числу вариантов (MRV), сопоставление по пересечениям

### **2.5. Другие покрытия (обобщение)**
* **Домино/полимино:** клетки доски — первичные столбцы, фигуры — вторичные (каждая использована не более раза)
* **Латинские квадраты, раскраски, расписания** — те же схемы «объект → набор ограничений»

### **2.6. Алгоритм Кнута X (Dancing Links)**
* **Алгоритм X (рекурсия):**
  1. Если столбцов не осталось — решение найдено
  2. Выбрать столбец c с минимальным числом единиц (MRV)
  3. Для каждой строки r с единицей в c: включить r в ответ, удалить все столбцы строки r и все строки, пересекающие их; рекурсивно продолжить
  4. Откатить удаления и попробовать следующую строку
* **Dancing Links — приём реализации:** матрица хранится как сеть циклических двусвязных списков (по горизонтали и вертикали); удаление и восстановление узла — перезапись четырёх ссылок за O(1), без копирования матриц
* **Почему работает:** у каждого узла 4 ссылки (l/r/u/d); «вычёркивание» столбца — выключение из горизонтального списка, «вычёркивание» строк — выключение их узлов из вертикальных списков столбцов
* **Сложность:** экспоненциальная в худшем случае, на практике быстро из-за MRV
* **Применение:** все задачи 2.2–2.5 решаются им напрямую

## **3. Ход коня (Knight Tour)**
* **Постановка:** обойти конём все клетки доски n×n, посетив каждую ровно один раз
* **Алгоритм:** backtracking с эвристикой Варнсдорфа
  * **Эвристика Варнсдорфа:** на каждом шаге идти в клетку с минимальным числом доступных ходов дальше (degree heuristic)
  * **Почему работает:** сначала закрываем «трудные» клетки, пока они ещё доступны
* **Сложность:** без эвристики O(8^(n²)) — практически нереально; с эвристикой доска 8×8 решается мгновенно
* **Связанные:** число замкнутых маршрутов, задачи на обходы (см. эйлеровы пути в graph.md)

## **4. Ожерелья (циклические последовательности)**
* **Постановка:** n бусин нанизаны на нить, завязанную в кольцо, каждая окрашена в один из k цветов. Ожерелья равны, если одно получается из другого поворотом (циклическим сдвигом)
* **Модель:** раскраска — слово длины n в алфавите из k цветов (всего kⁿ); повороты образуют циклическую группу C_n, действующую на словах; ожерелья — орбиты этого действия
* **Формула (лемма Бернсайда):** N(k,n) = (1/n)·Σ_{i=1}^{n} k^{gcd(i,n)}
  * **Почему:** поворот на i позиций оставляет слово неизменным, только если оно периодично с периодом gcd(i,n) — таких слов k^{gcd(i,n)}; число орбит = среднее число неподвижных точек по всем поворотам
  * **Через делители:** N(k,n) = (1/n)·Σ_{d|n} φ(d)·k^{n/d} — поворотов с длиной цикла d ровно φ(d)
* **Браслеты (с переворотом):** если ожерелье можно снять и перевернуть, добавляются отражения — группа диэдра D_n:
  N_br(k,n) = (1/(2n))·(Σ_{d|n} φ(d)·k^{n/d} + R), где R = n·k^{(n+1)/2} при нечётном n, R = (n/2)·(k^{n/2+1} + k^{n/2}) при чётном
* **Пример:** двоичные ожерелья длины 4: (1/4)(φ(1)·2⁴ + φ(2)·2² + φ(4)·2¹) = (16+4+4)/4 = 6 — классы {0000}, {1111}, {0001,0010,0100,1000}, {0011,0110,1100,1001}, {0101,1010}, {0111,1110,1101,1011}
* **Сложность:** O(√n·log n) — перебор делителей n с функцией Эйлера; ответ растёт как kⁿ/n, при больших n — модулярная арифметика
* **Применение:** кольцевые последовательности, раскраски с циклической симметрией, подсчёт структур «с точностью до поворота»
* **Обобщение:** лемма Бернсайда — общий приём «число орбит = (1/|G|)·Σ|Fix(g)|» для любой группы симметрий (см. теорию перечисления)

## **5. Расстановки на шахматной доске**
* **Общая задача:** сколько способов расставить k не бьющих друг друга фигур; фигура задаёт набор «линий удара», и не бьющие фигуры занимают разные линии

### **5.1. Ладьи (Rooks)**
* Ладьи бьют по строкам и столбцам → не бьющие ладьи стоят в разных строках и разных столбцах
* **n ладей на доске n×n:** n! (биекция строк ↔ столбцов = перестановка)
* **k ладей на n×n:** C(n,k)²·k! (выбрать k строк, k столбцов и сопоставить их биекцией)
* **Прямоугольная доска m×n:** C(m,k)·C(n,k)·k!
* **Связь с включениями-исключениями:** ладьи на запрещённых клетках — числа R_r в B.2.1 (перестановки с запрещёнными позициями)
* **Пример:** 2 ладьи на 4×4: C(4,2)²·2! = 36·2 = 72

### **5.2. Слоны (Bishops)**
* Слоны бьют по диагоналям; цвет клетки (r+c) mod 2, слон бьёт только клетки своего цвета → задача распадается на два независимых подмножества по цвету
* **Сведение к ладьям:** клетки одного цвета образуют «лестницу» (доску Феррера): "/"-диагонали — столбцы, "\"-диагонали — строки; не бьющие слоны = не бьющие ладьи на этой ступенчатой доске
* **Высоты столбцов:** длины диагоналей одного цвета len(s) = min(s, 2n−2−s) + 1, s = цвет, цвет+2, ..., 2n−2; сортируем по возрастанию (лестница Феррера)
* **ДП по диагоналям (многочлены ладей):** dp[i][j] = dp[i−1][j] + dp[i−1][j−1]·(h_i − j + 1), где h_i — отсортированные длины
  * **Почему:** j-ю ладью можно поставить в столбец высоты h_i за h_i − (j−1) способов (j−1 уже стоящих ладей заняли свои строки); не ставить её вовсе — dp[i−1][j]
* **Ответ для k слонов:** Σ_{j=0}^{k} dp_чётный[j]·dp_нечётный[k−j]
* **Сложность:** O(n²) — ДП по ~n диагоналям каждого цвета
* **Максимум:** на n×n можно поставить не более 2n−2 не бьющих слонов
* **Пример:** 2 слона на 3×3: чётный цвет (длины 1,1,3) → [1,5,4], нечётный (2,2) → [1,4,2]; ответ = 4·1 + 5·4 + 1·2 = 26 (из 36 пар клеток бьют ровно 10 — общие диагонали)

### **5.3. Ферзи (N-Queens)**
* **Постановка:** n ферзей на доске n×n, никакие два не бьют друг друга (строки, столбцы и обе диагонали)
* **Математика:** каждая строка и каждый столбец заняты ровно один раз → расстановка = перестановка; у клетки (r,c) инварианты диагоналей r+c и r−c, и все они должны быть попарно различны
* **Существование:** решения есть при всех n ≥ 4 (при n=2,3 решений нет; n=1 тривиально)
* **Число решений:** N(8)=92, N(9)=352, N(10)=724; закрытой формулы нет, N(n) ~ n!/cⁿ при c ≈ 2.4 (Simkin, 2021); с учётом симметрий доски (до 8 эквивалентов: 4 поворота × отражение) фундаментальных решений для n=8 — 12
* **Алгоритмы:**
  * Бэктрекинг по строкам с битовыми масками занятых столбцов и диагоналей: O(n!) в худшем случае; подсчёт всех решений с масками практически мгновенен до n ≈ 15–17 (n_queens_count возвращает int — переполнение уже на N(19) ≈ 5·10⁹; поиск одного решения работает и при больших n)
  * N-Queens как точное покрытие — см. 2.3 (колонки — первичные столбцы, диагонали — вторичные)
* **Применение:** перестановки с ограничениями, классический пример точного покрытия, полигон для бэктрекинга и эвристики MRV
