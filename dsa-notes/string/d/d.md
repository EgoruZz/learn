**D. ХЕШИРОВАНИЕ СТРОК**

> **Архитектура:** `StringHashing` (d.cpp) — наследует `StringDistances` (c.cpp). Реализует: полиномиальное хеширование (single/double), rolling hash, сравнение подстрок за `O(1)`, поиск палиндромов через хеш, подсчёт различных подстрок, проверку изоморфизма. Все хеш-функции параметризованы основанием `p` и модулем `m`.
>
> **Связи:** Rabin-Karp (rolling hash) — `string/b` (4); KMP/Z-функция — `string/b` (2,3) (альтернативы хешированию); suffix array + LCP — `string/e` (для подсчёта различных подстрок через LCP); хеш-таблицы — `hashing.md`; модулярная арифметика (обратные элементы, быстрое возведение) — `math/number-theory`; ДП по подстрокам — `dynamic.md` (D).

# **1. Полиномиальное хеширование**

## **1.1. Базовый хеш**
* **Формула:** `h(s) = (Σ_{i=0}^{n−1} s[i] · p^i) mod m` где `p` — основание (обычно `257, 31, 37, 137, 91138233`), `m` — простое число (обычно `10⁹+7, 10⁹+9, 2^61−1`)
* **Префиксные хеши:** `pref[i+1] = pref[i] · p + s[i]`; хеш подстроки `s[l..r)`: `h = pref[r] − pref[l] · p^{r−l}` `O(1)`
* **Предвычисление:** `pref[0..n]` и `pow[0..n]` за `O(n)`

## **1.2. Rolling hash**
* Добавление символа: `h = h · p + ch`
* Удаление символа: `h = (h − ch · p^{k−1}) · p^{−1}` (или через.prefix)
* **Применение:** Rabin-Karp, поиск в потоке, скользящее окно

## **1.3. Выбор параметров**
* **Основание `p`:** нечётное простое `> |Σ|` (размер алфавита); типично `p = 31, 37, 91138233`
* **Модуль `m`:** большое простое; типично `10⁹+7, 10⁹+9`; `2^61−1` (Mersenne prime) для быстрого умножения
* **Двойное хеширование:** два хеша с `(p₁, m₁)` и `(p₂, m₂)` → вероятность коллизии `O(1/(m₁·m₂))`

---

# **2. Двойное хеширование**

* Два хеша: `h₁(s)` с `(p₁, m₁)` и `h₂(s)` с `(p₂, m₂)`
* Сравнение подстрок: `h₁(s₁) == h₁(s₂) ∧ h₂(s₁) == h₂(s₂)` → совпадение с вероятностью `1 − 1/(m₁·m₂)`
* **Применение:** детерминированный поиск подстроки `O(n + m)`

---

# **3. Применения**

## **3.1. Сравнение подстрок за O(1)**
* Предподсчёт `pref[0..n]` и `pow[0..n]`; хеш `s[l..r)` за `O(1)`

## **3.2. Поиск палиндромов через хеш**
* Прямой хеш `h(s[l..r))` + обратный хеш `h(s[l..r)reverse)`
* Палиндром ⟺ `h_direct == h_reverse`; `O(1)` на проверку

## **3.3. Подсчёт различных подстрок**
* Все хеши подстрок + set: `O(n² log n)` время, `O(n²)` память
* Через suffix array + LCP: `O(n log n)` время, `O(n)` память

## **3.4. Проверка изоморфизма**
* Две строки изоморфны ⟺ биекция символов; проверка через сопоставление позиций первого вхождения каждого символа

# **4. Коллизии и безопасность**

## **4.1. Birthday paradox**
* Для `k` хешей из `m` значений: вероятность коллизии ≈ `k²/(2m)`
* При `k = √m` → вероятность ≈ `0.5`

## **4.2. Universal hashing**
* `h_a(s) = (Σ s[i] · a^i) mod m` где `a` — случайный из `{1, ..., m−1}`
* Вероятность коллизии для любой пары строк `≤ 1/m`

## **4.3. Cryptographic hashes**
* SHA-256, MD5: детерминированные, стойкие; `O(n)` вычисление
* Не подходят для сравнения подстрок за `O(1)` (медленные)
