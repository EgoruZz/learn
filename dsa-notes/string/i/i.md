# **1. Фонетические алгоритмы**

## **1.1. Soundex**
* **Идея:** кодирование слова по звучанию; одинаковые коды → похоже звучащие слова
* **Правила:** первая буква сохраняется; далее: B,F,P,V → 1; C,G,J,K,Q,S,X,Z → 2; D,T → 3; L → 4; M,N → 5; R → 6; остальные (A,E,I,O,U,H,W,Y) → игнорируются;相邻ные одинаковые коды → один раз
* **Результат:** 4-символьный код (буква + 3 цифры)
* **Сложность:** `O(n)`

## **1.2. Metaphone**
* **Идея:** более точный фонетический алгоритм для английского
* **Правила:**組み合わせы букв (SH, TH, PH, GH и т.д.) → специальные коды; пропуск неакцентированных слогов
* **Применение:** spell checkers, поиск похожих слов

## **1.3. NYSIIS**
* **Идея:** улучшенный Soundex; сохраняет больше фонетической информации
* **Правила:** начальные буквы → специальные замены; двойные буквы → одна; окончания →标准化

# **2. Игры со строками**

## **2.1. Word Ladder (Лесенка слов)**
* **Задача:** преобразовать одно слово в другое, меняя по одной букве за шаг; каждый промежуточный шаг — слово из словаря
* **Алгоритм:** BFS на графе слов; расстояние Хэмминга = 1 между соседями
* **Сложность:** `O(n · m · Σ)` где `n` — число слов, `m` — длина слова, `Σ` — размер алфавита

## **2.2. Boggle (Поиск слов в матрице)**
* **Задача:** найти все слова в матрице символов; смежные клетки (по горизонтали, вертикали, диагоналям)
* **Алгоритм:** DFS из каждой клетки + проверка префикса через Trie
* **Сложность:** `O(n · m · 4^l)` где `l` — макс. длина слова

## **2.3. Scrabble (валидация слов)**
* **Задача:** проверить, является ли слово допустимым в словаре
* **Решение:** Trie или hash set; `O(m)` проверка
