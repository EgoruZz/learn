**J. БИТОВЫЕ И НИЗКОУРОВНЕВЫЕ ОПЕРАЦИИ**

> **Архитектура:** `BitStringOperations` (j.cpp) — наследует `PhoneticAlgorithms` (i.cpp). Реализует: битовые маски для множеств символов, Shift-Or/Shift-And (bit-parallel matching), определение кодировок (ASCII, UTF-8, UTF-16, UTF-32). Все алгоритмы параметризованы размером алфавита `Σ` и размером машинного слова `w`.
>
> **Связи:** KMP/Z-функция — `string/b` (2,3) (альтернативы bit-parallel); хеш-функции — `string/d` (для сравнения); битовые операции — `math/discrete-and-logic`; `__builtin_popcount` — machine-level primivite; ДП по маскам — `dynamic.md` (E — bitmask DP).

# **1. Битовые манипуляции**

## **1.1. Bitmask для строк**
* Множество символов через биты: `mask |= (1 << (c - 'a'))` — добавление; `mask & (1 << (c - 'a'))` — проверка
* **Сложность:** `O(1)` на операцию; `O(Σ)` на построение
* **Применение:** проверка уникальности символов `O(n)`, подсчёт различных символов

## **1.2. Bit-parallel string matching (Shift-Or/Shift-And)**
* **Идея:** битовое представление состояний; `mask` — бит `j` установлен если `j`-й символ паттерна совпал
* **Shift-And:** при совпадении `mask |= (1 << j)`; при несовпадении `mask = (mask << 1) | 1`
* **Shift-Or:** инвертированный вариант (отрицательное = совпадение)
* **Сложность:** `O(n · ⌈m/w⌉)` где `w` — размер машинного слова (обычно `64`)
* **Применение:** поиск с нечётким соответствием (до `k` ошибок); для `m ≤ w`

# **2. Кодировки**

## **2.1. ASCII**
* `1` байт/символ; `128` символов (0–127); прямая проекция `char → int`
* **Свойства:** фиксированный размер, простой доступ по индексу

## **2.2. UTF-8**
* **Формат:** variable-length (1–4 байта/символ)
    * `0xxxxxxx` — 1 байт (ASCII)
    * `110xxxxx 10xxxxxx` — 2 байта
    * `1110xxxx 10xxxxxx 10xxxxxx` — 3 байта (основной диапазон Unicode)
    * `11110xxx 10xxxxxx 10xxxxxx 10xxxxxx` — 4 байта
* **Обратно совместим с ASCII**
* **Определение длины символа:** по первому байту: `0xxx` → 1, `110x` → 2, `1110` → 3, `11110` → 4

## **2.3. UTF-16**
* `2` байта/символ для BMP (Basic Multilingual Plane); surrogate pairs для supplementary characters ( `2 × 2` байта)
* **Применение:** Java, Windows API

## **2.4. UTF-32**
* Фиксированные `4` байта/символ; простой доступ по индексу `O(1)`, но память

## **2.5. Unicode Normalization**
* **NFC:** composition (составные символы → одна глифа)
* **NFD:** decomposition (одна глифа → составные символы)
* **NFKC/NFKD:** compatibility normalization ( `ﬁ` → `fi`, `²` → `2`)
