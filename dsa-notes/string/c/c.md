**C. СТРОКОВЫЕ РАССТОЯНИЯ И РЕДАКТИРОВАНИЕ**

> **Архитектура:** `StringDistances` (c.cpp) — наследует `StringMatching` (b.cpp). Реализует: расстояние Левенштейна (с параметризованными стоимостями), Дамерау-Левенштейна, Хэмминга, LCS, Longest Common Substring, оптимизации (bit-parallel, rolling array). Все алгоритмы параметризованы размерами строк `n`, `m` и стоимостями операций.
>
> **Связи:** ДП по строкам — `dynamic.md` (C.11–C.18 — Edit Distance, LCS, Wildcard, Regex); суффиксный массив + LCP — `string/e` (для Longest Common Substring); хеш-функции — `string/d` (для проверки совпадений); префиксные суммы — `struct.md` (V.A); дерево отрезков — `struct.md` (V.D).

# **1. Расстояние Левенштейна (Edit Distance)**

* **Операции:** вставка `+c_i`, удаление `+c_d`, замена `+c_r` (параметризованные стоимости; по умолчанию `c_i = c_d = c_r = 1`)
* **ДП:** `dp[i][j]` = min cost `s[0..i) → t[0..j)`
    * `dp[i][j] = min(dp[i−1][j] + c_d, dp[i][j−1] + c_i, dp[i−1][j−1] + [s[i]≠t[j]]·c_r)`
* **Сложность:** `O(n·m)` время, `O(min(n,m))` память (rolling array — две строки)
* **Восстановление:** через `prev[i][j]` — обратный путь; или через two-pointer по таблице
* **Применение:** spell checking, DNA alignment, diff файлов

## **1.1. Min Cost String Conversion**
* Произвольные стоимости операций `c_i, c_d, c_r`; ДП аналогично
* **Применение:** выравнивание последовательностей в биоинформатике (match/mismatch/gap penalties)

---

# **2. Расстояние Дамерау-Левенштейна**

* Добавлена **транспозиция** (обмен соседних символов) за `+c_t`
* **ДП:** `dp[i][j]` + проверка `i > 1, j > 1: s[i−2] == t[j−1] ∧ s[i−1] == t[j−2]`
    * `dp[i][j] = min(..., dp[i−2][j−2] + c_t)`
* **Сложность:** `O(n·m)` время, `O(min(n,m))` память

---

# **3. Расстояние Хэмминга**

* Для строк одинаковой длины `n`: `d(s,t) = Σ_{i=0}^{n−1} [s[i] ≠ t[i]]`
* **Сложность:** `O(n)` время, `O(1)` память
* **Применение:** сравнение хешей, проверка кодовых слов, биоинформатика

---

# **4. LCS (Longest Common Subsequence)**

* **ДП:** `dp[i][j]` = длина LCS `s[0..i)` и `t[0..j)`
    * `dp[i][j] = dp[i−1][j−1] + 1` если `s[i] == t[j]`, иначе `max(dp[i−1][j], dp[i][j−1])`
* **Сложность:** `O(n·m)` время, `O(min(n,m))` память (rolling array)
* **Восстановление:** через `prev[i][j]` — обратный путь
* **Применение:** diff файлов, биоинформатика (выравнивание последовательностей)

---

# **5. Longest Common Substring**

* **Суффиксный массив + LCP:** конкатенация `s₁ + '#' + s₂`, построение SA + LCP, поиск максимума `lcp[i]` где `sa[i]` и `sa[i−1]` принадлежат разным строкам; `O(n log n)` или `O(n)`
* **ДП:** `dp[i][j]` = длина общего суффикса `s[i..)` и `t[j..)`: `dp[i][j] = dp[i+1][j+1] + 1` если `s[i] == t[j]`; `O(n·m)` время, `O(min(n,m))` память
* **Применение:** поиск повторяющихся паттернов, биоинформатика

---

# **6. Расстояние Джарро-Винклера**

* Для коротких строк/имён; учитывает префикс: `jw = jaro + prefix_bonus · (1 − jaro)`
* **Jaro:** `jaro(s,t) = (|s|/m + |t|/m + t_m/m) / 3` где `m` — число совпадений, `t_m` — число транспозиций
* **Применение:** fuzzy matching в базах данных, сравнение имён

---

# **7. Другие метрики сходства**

* **Cosine similarity:** `cos(s,t) = (s·t) / (‖s‖·‖t‖)` через N-gram векторы; `O(n + m)`
* **Jaccard similarity:** `|A ∩ B| / |A ∪ B|` для наборов N-грамм
* **Sørensen–Dice:** `2·|A ∩ B| / (|A| + |B|)`

---

# **8. Оптимизации**

## **8.1. Rolling array**
* `O(min(n,m))` память вместо `O(n·m)` — хранение двух строк (текущий и предыдущий ряд)

## **8.2. Ukkonen**
* Для малых расстояний `d`: `O(n·d)` время (вместо `O(n·m)`)
* Обрезка: если `dp[i][j] > d` — пропуск

## **8.3. Bit-parallel DP**
* Ускорение через битовые операции; `O(n·m/w)` где `w` — размер машинного слова
* Применяется для Hamming distance и приближённого поиска

## **8.4. Four Russians method**
* Блочное разбиение `O(n·m / log²(n·m))` — теоретическая оптимизация
