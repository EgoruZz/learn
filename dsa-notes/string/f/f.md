**F. АНАЛИЗ И ПРЕОБРАЗОВАНИЕ СТРОК**

> **Архитектура:** `StringAnalysis` (f.cpp) — наследует `StringAutomata` (e.cpp). Реализует: статистический анализ (частоты, top-K, N-gram), проверку свойств (уникальность, палиндромность, анаграммы, изограммы), трансформации (регистр, форматы, reverse, split/join), периодичность строки, минимальный циклический сдвиг (Booth), сортировка циклических сдвигов. Все алгоритмы параметризованы размером алфавита `Σ` и длиной строки `n`.
>
> **Связи:** KMP/префикс-функция — `string/b` (2) (период через `π`); Z-функция — `string/b` (3) (периодичность через Z); хеш-функции — `string/d` (палиндромы через хеш); suffix array — `string/e` (3) (сортировка циклических сдвигов); frequency counting — `struct.md` (IV — heap для top-K); сортировки — `technique.md` (I); ДП — `dynamic.md` (C — расстояния строк).

---

# **1. Статистический анализ**

## **1.1. Частотный анализ**
* Подсчёт символов: `O(n)` через массив `freq[Σ]`
* Top-K частых символов: heap `O(n log k)` или bucket sort `O(n + Σ)`
* **Применение:** шифры (частотный анализ), сжатие, генерация текстов

## **1.2. N-gram анализ**
* Подстроки длины `k`: `O(n·k)` генерация; подсчёт частот `O(n·k)` через map
* **Применение:** предсказание текста, определение языка, анализ стиля

---

# **2. Проверка свойств**

## **2.1. Уникальность символов**
* Bitmask `O(n)` для ASCII (маска битов); set `O(n log n)` для Unicode
* **Обобщение:** `O(n + Σ)` через boolean array размера `Σ`

## **2.2. Изограммы и панграммы**
* **Isogram:** слово без повторяющихся букв — `O(m)` через set
* **Pangram:** текст со всеми буквами алфавита — `O(n)` через bitmask

## **2.3. Палиндромность**
* Два указателя `O(n)` или хеш `O(n)` (прямой + обратный)
* **Обобщение:** проверка перестановки в палиндром: не более одной нечётной частоты

## **2.4. Анаграммы**
* Сортировка `O(m log m)` или frequency counting `O(m + Σ)`
* **Обобщение:** группировка анаграмм — `O(n·m log m)` или `O(n·m)` через хеш частот

# **3. Трансформации**

## **3.1. Регистр**
* `tolower`, `toupper`, `capitalize`, `title case`, `switch case` — `O(n)`

## **3.2. Форматы**
* CamelCase ↔ snake_case, kebab-case, dot case — `O(n)`

## **3.3. Перестановки**
* `reverse` `O(n)`, `reverse words` `O(n)`, `alternative string arrange` `O(n)`

## **3.4. Разделение и объединение**
* `split` по разделителю `O(n)`, `join` `O(n)`, `tokenization`, `strip`

---

# **4. Периодичность и повторы**

## **4.1. Период строки**
* Через префикс-функцию: `p = n − π[n−1]` если `n mod p == 0`; иначе период `= n`
* Через Z-функцию: `p = i` если `z[i] + i == n` (suffix совпадает с префиксом)

## **4.2. Тандемные повторы**
* Два вхождения подстроки подряд: `s[i..i+l) == s[i+l..i+2l)`
* **Main-Lorentz:** divide-and-conquer `O(n log n)` — разделение на половину + рекурсия
* **Crochemore:** `O(n log n)` через suffix array

## **4.3. Квадраты**
* Два вхождения одной подстроки (не обязательно подряд): `s[i..i+l) == s[j..j+l)` где `i < j`
* **Алгоритмы:** `O(n log n)` через suffix array + LCP; `O(n sqrt(n))` через border array

# **5. Минимальный циклический сдвиг и сортировка**

## **5.1. Booth's algorithm**
* **Задача:** найти лексикографически наименьший циклический сдвиг строки
* **Алгоритм:** `O(n)` через KMP-подобный подход; удвоение строки + поиск минимума
* **Применение:** каноническое представление циклической строки

## **5.2. Лексикографически наименьший/наибольший суффикс**
* Через суффиксный массив: `sa[0]` — наименьший, `sa[n−1]` — наибольший `O(n)`

## **5.3. Сортировка циклических сдвигов**
* Через SA-IS `O(n)` или через удвоение строки + сортировка `O(n log n)`

# **6. Текстовая обработка**

## **6.1. Text Justification**
* Выравнивание текста по ширине с переносом слов; `O(n·k)` где `k` — число слов

## **6.2. Удаление дубликатов**
* In-place через два указателя `O(n)` для отсортированного массива

## **6.3. Zigzag Conversion**
* Заполнение по строкам в зигзаге; `O(n)` время
