**E. СТРОКОВЫЕ АВТОМАТЫ И СТРУКТУРЫ**

> **Архитектура:** `StringAutomata` (e.cpp) — наследует `StringHashing` (d.cpp). Реализует: Trie, Radix Tree, Aho-Corasick, суффиксный массив + LCP (Kasai), суффиксный автомат, дерево палиндромов (Eertree). Все структуры параметризованы размером алфавита `Σ` и длиной строки `n`.
>
> **Связи:** KMP/префикс-функция — `string/b` (2) (связь с суффиксным массивом через LCP); хеш-функции — `string/d` (альтернатива суффиксным структурам); DFS/BFS — `graph/a` (обход trie); DSU — `graph/b` (A) (применение в Aho-Corasick); suffix link — `struct.md` (XI.F — Link-Cut Tree); приоритетные очереди — `struct.md` (IV).

# **1. Префиксное дерево (Trie)**

## **1.1. Базовый Trie**
* **Структура:** дерево, где каждое ребро — символ; путь от корня = префикс; в узлах — флаг окончания слова
* **Операции:** вставка `O(m)`, поиск `O(m)`, удаление `O(m)` где `m` — длина строки
* **Память:** `O(Σ·n·m)` худший (каждый символ — отдельный узел); оптимизация — radix tree

## **1.2. Radix Tree (Patricia Tree)**
* Сжатый trie: рёбра = строки (не один символ); `O(n)` памяти
* **Применение:** autocomplete, longest common prefix

## **1.3. Ternary Search Trie**
* Каждая вершина: 3 указателя (меньше, равно, больше); экономия памяти vs обычный trie

## **1.4. Применения Trie**
* Autocomplete, Word Break, Spell checker, IP routing tables

# **2. Алгоритм Ахо-Корасик**

* **Построение:** trie + failure links через BFS; `O(Σ·|P|)` где `|P|` — суммарная длина паттернов
* **Множественный поиск:** `O(n + Σ·|P| + k)` где `k` — число вхождений; один проход по тексту
* **Применение:** intrusion detection, bioinformatics, множественный поиск паттернов

---

# **3. Суффиксный массив (Suffix Array)**

## **3.1. Определение**
* Отсортированный массив индексов суффиксов строки

## **3.2. Построение**
* Naive `O(n² log n)`
* Prefix doubling `O(n log n)` — сортировка по префиксам длины `2^k`
* SA-IS `O(n)` — линейный (сложный)

## **3.3. LCP массив (Kasai)**
* `lcp[i]` = длина LCP `sa[i]` и `sa[i−1]`; `O(n)` построение
* **Применения:**
    * Поиск подстроки: бинарный поиск `O(m log n)`
    * Число различных подстрок: `n(n+1)/2 − Σ_{i=1}^{n−1} lcp[i]`
    * Longest repeating substring: `max(lcp[i])`
    * Longest common substring: через `lcp` на конкатенации `s₁ + '#' + s₂`

# **4. Суффиксный автомат (Suffix Automaton)**

* Минимальный DFA, accept все подстроки; `≤ 2n−1` вершин, `≤ 3n−4` рёбер
* **Построение:** online `O(n)` с терминальными ссылками
* **Применения:**
    * Число различных подстрок: `Σ_v (len[v] − len[link[v]])`
    * Кратчайшая строка, не входящая в текст
    * Количество вхождений подстроки (предподсчёт `occ`)

---

# **5. Дерево палиндромов (Palindromic Tree / Eertree)**

* Хранит все различные палиндромные подстроки; `≤ n` вершин; два корня (для нечётных и чётных)
* **Построение:** online `O(n)` с suffix links для палиндромов
* **Применения:** число различных палиндромов, longest palindromic prefix/suffix, подсчёт вхождений

---

# **6. Суффиксное дерево (Suffix Tree)**

* Компактное Trie всех суффиксов; `O(n)` вершин и рёбер
* **Построение:** Укконен `O(n)` (online, suffix links, active point)
* **Применения:** всё от суффиксного массива + поиск паттерна `O(m)`, LCS `k` строк
