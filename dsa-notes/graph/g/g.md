# **A. ДВУДОЛЬНЫЕ ПАРОСОЧЕТАНИЯ**

## **1. Основные понятия**

### **1.1. Определения**
* **Двудольный граф:** `G = (L ∪ R, E)`, `L ∩ R = ∅`; каждое ребро соединяет вершину из `L` с вершиной из `R`
* **Паросочетание (Matching):** множество рёбер `M ⊆ E`, где никакие два ребра не имеют общих вершин
* **Размер паросочетания:** `|M|`
* **Вершина покрыта:** если она — конец хотя бы одного ребра из `M`
* **Свободная вершина:** не покрыта `M`
* **Augmenting path (путь увеличения):** путь, начинающийся и заканчивающийся свободными вершинами, где рёбра чередуются: не в M, в M, не в M, ...
* **Свойство:** `M` максимальное ⟺ нет augmenting path (теорема БERGE)

### **1.2. Теорема Холла (Hall's Marriage Theorem)**
* **Утверждение:** в двудольном графе `G = (L ∪ R, E)` существует完美 паросочетание ( `|M| = |L|` ) ⟺ для любого `S ⊆ L`: `|N(S)| ≥ |S|`
* **Короткий случай:** `|L| = |R|` и `|N(S)| ≥ |S|` для всех `S ⊆ L` →完美 паросочетание
* **Некороткий случай:** maxSize matching = `min_{S ⊆ L} (|L| − |S| + |N(S)|)`

## **2. Алгоритм Куна (Kuhn's Algorithm)**

### **2.1. Идея**
* Для каждой свободной вершины `u ∈ L`: запустить DFS (BFS) для поиска augmenting path
* DFS возвращает `true`, если augmenting path найден → увеличение паросочетания
* **Паттерн:** `try_kuhn(u)`: для каждого соседа `v ∈ R`: если `v` свободна или `try_kuhn(matched[v])` → назначить `u ↔ v`

### **2.2. Сложность**
* `O(VE)` в худшем случае: `|V|` запусков DFS, каждый `O(E)`
* На практике значительно быстрее

## **3. Алгоритм Хопкрофта-Карпа (Hopcroft-Karp)**

### **3.1. Идея (BFS + DFS)**
1. **BFS построение уровней:** от всех свободных вершин `L`; уровни — расстояние до ближайшей свободной вершины `R`
2. **DFS поиск максимального набора augmenting paths:** используя только рёбра следующего уровня; за один проход находим максимум непересекающихся augmenting paths
3. Повторять until BFS не найдёт augmenting paths

### **3.2. Сложность**
* `O(E√V)` — количество фаз: `O(√V)`, на каждой фазе `O(E)` суммарно

### **3.3. Когда использовать**
* Максимальный размер двудольного паросочетания — оптимальный по асимптотике

## **4. Устойчивое паросочетание (Gale-Shapley)**

### **4.1. Постановка задачи**
* `n` мужчин и `n` женщин; у каждого — строгий рейтинг предпочтений
* **Стабильное паросочетание:** нет пары `(m, w)` таких, что `m` предпочитает `w` текущей партнёрше И `w` предпочитает `m` текущему партнёру

### **4.2. Алгоритм Гейла-Шепли (Proposal)**
* Свободные мужчины делают предложения по убыванию предпочтений; женщины принимают лучшее предложение
* **Сложность:** `O(n²)`
* **Гарантия:** stable matching существует всегда; алгоритм находит его

# **B. ПАРОСОЧЕТАНИЯ В ОБЩИХ ГРАФАХ**

## **1. Теорема Татта (Tutte)**

### **1.1. Формулировка**
* Граф `G` имеет完美 паросочетание ⟺ для любого `S ⊆ V`: `o(G − S) ≤ |S|`, где `o(H)` — число нечётных компонент связности графа `H`
* **Следствие:** для двудольных графов — эквивалентно теореме Холла

## **2. Алгоритм Эдмондса (Blossom Algorithm)**

### **2.1. Проблема: нечётные циклы**
* В общих графах augmenting path может содержать нечётный цикл («цветок»/blossom) — стандартный DFS не работает
* **Решение:** при обнаружении нечётного цикла — сжать его в одну «виртуальную» вершину (blossom contraction), продолжить поиск

### **2.2. Сложность**
* `O(V³)` — классическая реализация
* Практически: Vimple Blossom V — быстрее

## **3. Матрица Татта (Tutte Matrix)**
* **Определение:** `T[i][j] = x_{ij}` если `(i,j) ∈ E`, `0` иначе; `x_{ij} = −x_{ji}` (антисимметрия)
* **Свойство:** `det(T) ≠ 0` ⟺完美 паросочетание
* **Рандомизированный алгоритм:** замена `x_{ij}` на случайные числа; `det(T) ≠ 0` с высокой вероятностью; `O(V^ω)` (умножение матриц)

# **C. ВЗВЕШЕННЫЕ ПАРОСОЧЕТАНИЯ**

## **1. Венгерский алгоритм (Hungarian Algorithm)**

### **1.1. Задача: назначение (Assignment Problem)**
* Дана матрица стоимостей `cost[i][j]` ( `i ∈ L`, `j ∈ R`); найти паросочетание `M` с минимальной суммарной стоимостью: `Σ cost[i][M(i)]` → min

### **1.2. Идея (потенциалы)**
* **Потенциалы:** `u[i]` (для `L`) и `v[j]` (для `R`); `u[i] + v[j] ≤ cost[i][j]`
* **Равновесие:** если `(i,j)` в паросочетании → `u[i] + v[j] = cost[i][j]`
* **Алгоритм:** итеративно обновляем потенциалы, расширяя паросочетание

### **1.3. Сложность**
* `O(V³)` — классический匈牙利ский
* `O(V²E)` через shortest augmenting path

## **2. Min-Cost Max-Flow для паросочетаний**
* Сведение:.source → L (capacity 1), R → sink (capacity 1), рёбра L→R (capacity 1, cost = вес)
* Min-cost max-flow → оптимальное взвешенное паросочетание
* **Связь:** раздел H

# **D. СМЕЖНЫЕ ПОНЯТИЯ**

## **1. Вершинное покрытие (Vertex Cover)**

### **1.1. Определение**
* **Вершинное покрытие:** множество `C ⊆ V` такое, что каждое ребро имеет хотя бы один конец в `C`
* **Минимальное вершинное покрытие:** `|C|` → min

### **1.2. Теорема Кёнига (Kőnig's Theorem)**
* **Для двудольных графов:** макс. паросочетание = мин. вершинное покрытие: `|M*| = |VC*|`
* **Построение VC из M:** из свободных вершин в L — BFS в alternating graph; VC = (L \ Reachable) ∪ (R ∩ Reachable)

## **2. Покрытие путями в DAG (Dilworth)**

### **2.1. Теорема Дилуорта (Dilworth)**
* **Утверждение:** макс. число элементов антицепи = мин. число цепей, покрывающих всё множество
* **Связь:** антицепь = множество несравнимых элементков; цепь = упорядоченная последовательность

### **2.2. Minimum Path Cover в DAG**
* **Задача:** покрыть все вершины минимальным числом путей
* **Решение:** `n − max matching` через сведение к двудольному паросочетанию
* **Сведение:** каждая вершина `v` → два узла: `v_in` и `v_out`; ребро `(u_out, v_in)` если `(u,v) ∈ E`; max matching → min path cover

## **3. Maximum Independent Set**

### **3.1. Определение**
* **Независимое множество:** `I ⊆ V` где никакие две вершины не смежны
* **Максимальное:** `|I|` → max

### **3.2. Связь с другими задачами**
* `α(G) + |VC*| = n` (независимое множество + вершинное покрытие = все вершины)
* В двудольных графах: `α(G) = n − |M*|` (через теорему Кёнига)
* В общих графах: NP-hard
