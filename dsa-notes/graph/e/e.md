# **A. ЭЙЛЕРОВЫ ПУТИ И ЦИКЛЫ**

## **1. Определения**

### **1.1. Эйлеров цикл и путь**
* **Эйлеров цикл (Eulerian Circuit):** замкнутый путь, проходящий через каждое ребро ровно один раз; начало и конец в одной вершине
* **Эйлеров путь (Eulerian Path):** незамкнутый путь, проходящий через каждое ребро ровно один раз; начало и конец в разных вершинах
* **Эйлеров граф:** граф, содержащий эйлеров цикл
* **Полуэйлеров граф:** граф, содержащий эйлеров путь (но не цикл)

### **1.2. Связь с полным покрытием рёбер**
* Задача: пройти через каждое ребро ≥ 1 раз с минимальной стоимостью (Chinese Postman) или ровно 1 раз (Euler)
* Эйлеров цикл = идеальное решение (каждое ребро ровно 1 раз, замкнутый путь)

## **2. Критерии эйлеровости**

### **2.1. Неориентированные графы**
* **Эйлеров цикл:** граф связен И все степени `deg(v)` чётны
* **Эйлеров путь:** граф связен И ровно 2 вершины с нечётной степенью (начало и конец пути)
* **Почему работает:** при проходе через вершину используются 2 ребра (вход + выход); нечётная степень意味着 «свободное» ребро → конец пути

### **2.2. Ориентированные графы**
* **Эйлеров цикл:** граф слабо связен И для каждой вершины `in(v) = out(v)`
* **Эйлеров путь:** граф слабо связен И существуют ровно 2 вершины `a, b`: `out(a) − in(a) = 1`, `in(b) − out(b) = 1` (остальные `in = out`)
* **Свойство:** `Σ in(v) = Σ out(v) = m`

### **2.3. Проверка**
* `O(n + m)`: подсчёт степеней + проверка связности (DFS/BFS)

## **3. Алгоритм Флёри (Fleury)**

### **3.1. Идея**
* «Не пересекай мост, если есть альтернатива»
* На каждом шаге: выбрать ребро, не являющееся мостом (или единственное оставшееся ребро); удалить его

### **3.2. Сложность**
* `O(m²)`: проверка мостов через DFS за `O(n + m)` на каждом из `m` шагов
* На практике медленный; Hierholzer предпочтительнее

## **4. Алгоритм Хьерхольцера (Hierholzer)**

### **4.1. Идея (циклическое слияние)**
1. Начать с произвольной вершины `v`, идти по непройденным рёбрам, формируя цикл
2. Если в текущем цикле есть вершина `u` с непройденными рёбрами — начать новый цикл из `u`, встроить его в основной цикл
3. Повторять until все рёбра пройдены

### **4.2. Рекурсивная реализация**
* `dfs(v)`: пока `adj[v]` не пуст — извлечь ребро `(v, u)`, удалить его (и `(u, v)`), рекурсивно `dfs(u)`; добавить `v` в результат
* Результат — обратный эйлеров цикл/путь

### **4.3. Сложность**
* `O(m)`: каждое ребро обрабатывается один раз

### **4.4. Эйлеров путь (не цикл)**
* Начинаем из вершины с нечётной степенью (для неориент.) или `out(v) − in(v) = 1` (для ориент.)

## **5. Применения**

### **5.1. Задача китайского почтальона (Chinese Postman)**
* **Задача:** найти кратчайший замкнутый путь, проходящий через каждое ребро ≥ 1 раз
* **Решение (неориентированный граф):**
    1. Если граф эйлеров → эйлеров цикл (каждое ребро ровно 1 раз)
    2. Иначе: нечётные вершины `O = {v₁, ..., v₂ₖ}`; нужно удвоить минимальный набор рёбер, чтобы сделать все степени чётными
    3. Построить полный граф на `O` с весами `dist(vᵢ, vⱼ)` (Floyd-Warshall)
    4. Найти минимумальное совершенное паросочетание в этом полном графе (DP по маске `O(2^{2k} · k²)`)
    5. Удвоить рёбер на путях паросочетания → эйлеров цикл в расширенном графе
* **Сложность:** `O(n³ + 2^{2k} · k²)` где `2k` — число нечётных вершин

### **5.2. ДНК-секвенирование (Superstring)**
* Суперстрока: минимальная строка, содержащая все подстроки из заданного набора → через эйлеров путь в графе подстрок

# **B. ГАМИЛЬТОНОВЫ ПУТИ И ЦИКЛЫ**

## **1. Определения**

### **1.1. Гамильтонов цикл и путь**
* **Гамильтонов цикл (Hamiltonian Cycle):** цикл, проходящий через каждую вершину ровно один раз и возвращающийся в начало
* **Гамильтонов путь (Hamiltonian Path):** путь, проходящий через каждую вершину ровно один раз
* **Гамильтонов граф:** граф, содержащий гамильтонов цикл
* **Полугамильтонов граф:** содержит гамильтонов путь

### **1.2. Связь с TSP**
* TSP (Traveling Salesman Problem): найти гамильтонов цикл минимальной стоимости
* Для метрического TSP: неравенство треугольника → 3/2-приближение (Christofides)

## **2. Достаточные условия**

### **2.1. Теорема Дирака (Dirac)**
* **Условие:** если `deg(v) ≥ n/2` для всех `v ∈ V` → существует гамильтонов цикл
* **Доказательство:** через непротиворечие и максимальный путь; если длиннейший путь не цикл → добавление ребра создаёт «петлю» через соседей

### **2.2. Теорема Оре (Ore)**
* **Условие:** если `deg(u) + deg(v) ≥ n` для всех не смежных `u, v` → существует гамильтонов цикл
* **Обобщение:** теорема Дирака — частный случай ( `deg(u) ≥ n/2` и `deg(v) ≥ n/2` → сумма ≥ `n`)

### **2.3. Теорема Поша (Posa)**
* **Условие:** если при сортировке степеней `d₁ ≤ d₂ ≤ ... ≤ dₙ` выполнено: `d_i ≥ i/2` для `i < n/2` → гамильтонов цикл

### **2.4. Теорема Бонди-Хватала (Bondy-Chvatal)**
* **s-процедура:** если `deg(u) + deg(v) ≥ n` для не смежных `u, v` → добавить ребро `(u,v)`; повторять until невозможно
* **Теорема:** граф гамильтонов ⟺ его s-процедура даёт полный граф `K_n`
* **Связь:** обобщение всех вышеперечисленных

## **3. Алгоритмы поиска**

### **3.1. Backtracking (алгоритм Робертса-Флореса)**
* **Идея:** рекурсивно строим путь; на каждом шаге — перебираем соседей ещё не посещённых вершин
* **Обрезка:** если текущий путь невозможно продлить до гамильтонова (остались несмежные с концом вершины) — backtrack
* **Сложность:** `O(n!)` худший; на практике с обрезками значительно быстрее

### **3.2. Held-Karp (DP with bitmask)**
* **Состояние:** `dp[mask][v]` — существует ли путь, проходящий через все вершины из `mask` и заканчивающийся в `v`
* **Рекуррентность:** `dp[mask][v] = ∃u ∈ mask \ {v}: dp[mask \ {v}][u] ∧ (u,v) ∈ E`
* **База:** `dp[1 << v][v] = true` для всех `v`
* **Ответ:** `dp[(1 << n) − 1][v]` для любого `v` (+ ребро `(v, start)` для цикла)
* **Сложность:** `O(2^n · n²)` время, `O(2^n · n)` память
* **Связь:** полная реализация — `dynamic.md` (E)

### **3.3. Метод ветвей и границ**
* Lower bound: MST на непосещённых вершинах + рёбра к текущей вершине
* При lower bound > лучший найденный → отсечение ветки

## **4. NP-полнота**
* Проверка существования гамильтонова цикла — NP-полна (Кук 1971)
* Для специальных классов графов (деревья, планарные, с ограниченной treewidth) — полиномиально

# **C. ОБОБЩЁННЫЕ ЗАДАЧИ**

## **1. Longest Path Problem**
* **В произвольных графах:** NP-hard (сведение от Hamiltonian Path)
* **В DAG:** полиномиально через топологическую сортировку + DP: `dist[v] = max_{(u,v) ∈ E} (dist[u] + w(u,v))` — `O(n + m)` — `graph/c` (A.5)
* **В деревьях:** диаметр через два DFS или DP `O(n)` — `graph/f`

## **2. Traveling Salesman Problem (TSP)**

### **2.1. Классическая формулировка**
* **Задача:** найти гамильтонов цикл минимальной стоимости в полном взвешенном графе
* **Сложность:** NP-hard; точное решение — Held-Karp `O(2^n · n²)`

### **2.2. Метрический TSP**
* **Условие:** неравенство треугольника: `w(u,v) ≤ w(u,z) + w(z,v)` для всех троек
* **3/2-приближение (Christofides):**
    1. Построить MST
    2. Найти минимальное совершенное паросочетание на нечётных по степени вершинах
    3. Объединить MST + паросочетание → эйлеров мультиграф
    4. Эйлеров цикл → shortcuts (пропуск повторных вершин) → гамильтонов цикл
* **Сложность:** `O(n³)` (MST + Blossom + shortcuts)
* **Гарантия:** `≤ 3/2 · OPT`

### **2.3. Другие приближения**
* Nearest Neighbor: `O(n²)` — жадный, худшая оценка `O(log n)`
* 2-opt / 3-opt: локальный поиск, улучшение текущего решения
* Christofides: лучшая известная приближение для метрического TSP
