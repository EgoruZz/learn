# **A. ОСНОВНЫЕ СВОЙСТВА ПЛАНАРНЫХ ГРАФОВ**

## **1. Определение**
* **Планарный граф:** граф, который можно нарисовать на плоскости без пересечений рёбер
* **Planar embedding:** конкретная вкладка: порядок рёбер вокруг каждой вершины

## **2. Теорема Эйлера**
* **Формула:** `V − E + F = 2` для связного планарного графа (включая внешнюю грань)
* **Следствия:**
    * `E ≤ 3V − 6` для простых планарных графов ( `V ≥ 3` )
    * `E ≤ 2V − 4` для планарных графов без треугольников (двудольных планарных)
    * Минимальная грань имеет длину ≥ 3 (простой граф)
* **Почему работает:** каждая грань ≥ 3 рёбер, каждое ребро — на границе 2 граней → `2E ≥ 3F`; подстановка `F = 2 − V + E` → `E ≤ 3V − 6`

## **3. Теорема Куратовского (Kuratowski)**
* **Утверждение:** граф планарен ⟺ не содержит подграф, гомеоморфный `K₅` (полный граф на 5 вершинах) или `K₃,₃` (полный двудольный `3×3`)
* **Гомеоморфизм:** замена путей длины > 1 на одно ребро (подразделение рёбер)
* **Практика:** полная проверка — `O(V)` (Boyer-Myrvold); упрощённая проверка через必要 условия

## **4. Necessary conditions (упрощённая проверка)**
* Если `E > 3V − 6` → граф НЕ планарен
* Если граф двудолен и `E > 2V − 4` → НЕ планарен
* Обратное не всегда верно (недостаточное условие)

## **5. Planar Separator Theorem (Lipton-Tarjan)**
* **Утверждение:** для любого `n`-вершинного планарного графа существует разделитель `S` ( `|S| ≤ c·√n` ) такой, что после удаления `S` граф разбивается на две компоненты размера ≤ `2n/3`
* **Построение:** `O(n)` (Lipton-Tarjan), оптимизация `O(√n log n)` (Aleksandrov, Fomin)

# **B. ПРЕДСТАВЛЕНИЯ И АЛГОРИТМЫ**

## **1. Dual Graph (двойственный граф)**
* **Определение:** вершины `G*` — грани `G`; рёбра `G*` — между смежными гранями `G`
* **Свойства:** `V* = F`, `E* = E`, `F* = V`; двойственный двойственного — исходный граф
* **Применение:** min-cut в planar графах через shortest path в dual; max-flow = min-cut в dual

## **2. Fáry's Theorem**
* **Утверждение:** любой планарный граф можно нарисовать прямыми отрезками (без кривых)
* **Построение:** через DFS + встраивание граней; `O(n)` (de Fraysseix, Pach, Pollack)

## **3. Алгоритмы на планарных графах**
* **Shortest paths:** Dijkstra с specialized heap — `O(n log n)` (Fredwick, Tarjan)
* **Min-cut:** через dual graph — `O(n log n)`
* **Max-flow:** сведение к shortest path в dual graph

# **C. ГРАФЫ НА ПОВЕРХНОСТЯХ**

## **1. Обобщение формулы Эйлера**
* **Формула:** `V − E + F = 2 − 2g` где `g` — genus поверхности (число «дырок»)
* `g = 0` — сфера/плоскость (планарные); `g = 1` — тор; `g = 2` — двойной тор
* **Следствие:** `E ≤ 3(V + 2g − 1)` для простых графов на поверхности genus `g`

## **2. Приложения**
* Встроение в тор: `K₅` и `K₃,₃` планарны на торе
* Оптимизация макетов печатных плат (PCB routing)
