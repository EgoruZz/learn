# **A. ГРАФЫ С ОГРАНИЧЕННЫМИ ПАРАМЕТРАМИ**

## **1. Интервальные графы (Interval Graphs)**

### **1.1. Определение**
* **Интервальный граф:** граф пересечений интервалов на прямой; вершины — интервалы, ребро — пересечение
* **Каноническое свойство:** интервальный граф хордален (нет циклов длины ≥ 4 без хорды) И является comparability graph

### **1.2. Проверка интервальности**
* Граф интервален ⟺ хордален + не содержит «anti-hole» (дополнение цикла длины ≥ 5)
* **Практика:** через lexicographic BFS (Lex-BFS) → проверка ordering property

### **1.3. Maximum clique и independent set**
* **Maximum clique:** в интервальном графе = макс. число пересекающихся интервалов в одной точке; через sweep line `O(n log n)`
* **Maximum independent set:** в интервальном графе = макс. число непересекающихся интервалов; greedy `O(n log n)` (сортировка по правому концу)

### **1.4. Связь с другими задачами**
* Interval scheduling (жадный алгоритм) — частный случай maximum independent set
* Graph coloring интервального графа = chromatic number = maximum clique ( perfect graph)

## **2. Графы перестановок (Permutation Graphs)**

### **2.1. Определение**
* **Граф перестановок:** вершины — элементы перестановки `π`; ребро `(i, j)` если `i < j` и `π(i) > π(j)` (инверсия)
* **Свойство:** граф перестановок — intersection graph отрезков с особыми свойствами

### **2.2. Проверка**
* Граф является графом перестановок ⟺ он и его дополнение являются comparability graphs
* **Сложность:** `O(n + m)`

### **2.3. Инверсии**
* **Число инверсий:** `|{(i,j) : i < j, π(i) > π(j)}|`
* **Подсчёт:** merge sort `O(n log n)` или Fenwick tree `O(n log n)`
* **Связь:** инверсии — расстояние Кембридж-Эдвардса доidentity permutation

## **3. Графы с ограниченной treewidth**

### **3.1. Tree decomposition**
* **Определение:** дерево `T` с «мешками» (bags) `B_t ⊆ V` для каждой вершины `t` дерева; свойства: (1) каждое ребро `(u,v)` ∈ E принадлежит хотя бы одному bag; (2) для каждой вершины `v` — множество вершин `v` в bags образует связное поддерево
* **Ширина:** `tw = max_t |B_t| − 1`

### **3.2. DP на tree decomposition**
* Для фиксированной ширины `tw`: многие NP-трудные задачи решаются за `O(2^{tw} · poly(n))` или `O(3^{tw} · poly(n))`
* **Примеры:** Vertex Cover, Independent Set, Dominating Set, Hamiltonian Path

### **3.3. Courcelle's theorem**
* MSO₂-определяемые свойства решаются за `O(f(tw, φ) · n)` для фиксированной формулы `φ` и ширины `tw`

## **4. Графы с ограниченной clique-width**
* **Clique-width:** минимальное число «цветов» для построения графа через 4 операции
* Обобщение treewidth: деревья разбора с другой алгеброй

# **B. ГИПЕРГРАФЫ И МУЛЬТИГРАФЫ**

## **1. Гиперграфы**
* **Определение:** `H = (V, E)` где `E` — семейство подмножеств `V` (гиперрёбра могут содержать > 2 вершин)
* **Представления:** (1) инцидентная матрица; (2) bipartite incidence graph (вершины + гиперрёбра)
* **Transversal / Hitting Set:** минимальное подмножество вершин, пересекающее каждое гиперребро — NP-hard

## **2. Мультиграфы**
* **Определение:** граф с кратными рёбрами и/или петлями
* **Алгоритмы:** большинство алгоритмов адаптируется через схлопывание кратных рёбер или взвешивание
