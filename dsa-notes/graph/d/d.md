**D. ОСТОВНЫЕ ДЕРЕВЬЯ (SPANNING TREES)**

> **Архитектура:** `SpanningTrees` (d.cpp) — наследует `ShortestPaths` (c.cpp). Реализует три классических алгоритма MST (Kruskal, Prim, Boruvka), теоретические конструкции (матрица Кирхгофа, код Прюфера, формула Кэли) и второе по минимальности остовное дерево. Все алгоритмы параметризованы типом веса `W` и работают с произвольными связными взвешенными графами.
>
> **Связи:** DSU (Union-Find) — `graph/b` (A); приоритетные очереди — `struct.md` (IV); Dijkstra-подобный выбор — `graph/c` (A); LCA и Sparse Table — `struct.md` (VI.B, V.C); топологическая сортировка — `graph/a` (C.7); подсчёт определителя (Гаусс) — `math/linear-algebra`; ДП по подмножествам — `dynamic.md` (E) — для Steiner Tree.

# **A. МИНИМАЛЬНОЕ ОСТОВНОЕ ДЕРЕВО (MST)**

## **1. Основные понятия**

### **1.1. Определения**
* **Остовное дерево (Spanning Tree):** подграф, являющийся деревом и содержащий все `n` вершин графа; `n − 1` рёбер, связность, ацикличность
* **Минимальное остовное дерево (MST):** остовное дерево с минимальной суммой весов рёбер: `w(T) = Σ_{(u,v) ∈ T} w(u,v)` → min
* **Свойство:** для связного графа MST существует; если веса уникальны — MST единственна; при равных весах — множество MST

### **1.2. Cut Property (свойство разреза)**
* **Формулировка:** для любого разреза `(S, V\S)` самое лёгкее ребро, пересекающее разрез, принадлежит некоторому MST
* **Доказательство (обмен):** пусть ребро `e` — самое лёгкое в разрезе, но не в MST `T`; добавление `e` в `T` создаёт цикл; на этом цикле есть другое ребро `f` пересекающее разрез; `w(f) ≥ w(e)` ( `e` самое лёгкое); замена `f` на `e` не ухудшает дерево → `T − f + e` — MST
* **Применение:** обоснование корректности всех трёх алгоритмов

### **1.3. Cycle Property (свойство цикла)**
* **Формулировка:** для любого цикла самое тяжёлое ребро не принадлежит никакому MST
* **Доказательство:** если `e` — самое тяжёлое в цикле и в MST, удаление `e` разбивает дерево на две компоненты; добавление любого другого ребра цикла восстанавливает связность с меньшим/равным весом

## **2. Алгоритм Крускала (Kruskal)**

### **2.1. Алгоритм**
1. Сортировка всех `m` рёбер по весу: `O(m log m)`
2. Перебор рёбер в порядке возрастания веса: если `(u,v)` в разных компонентах — добавить в MST, объединить через DSU
3. Остановка when `n − 1` рёбер добавлено

### **2.2. Сложность**
* Сортировка: `O(m log m)` (или `O(m log n)` так как `m ≤ n²`)
* `m` операций DSU: `O(m α(n))` суммарно
* Итого: `O(m log m)` — определяет сортировка

### **2.3. Корректность**
* На каждом шаге: ребро `(u,v)` — минимальное среди рёбер, пересекающих разрез между компонентами → по Cut Property принадлежит MST

### **2.4. Применение**
* Естественный выбор для разреженных графов (`m << n²`)
* Второе по минимальности MST: Kruskal + LCA

## **3. Алгоритм Прима (Prim)**

### **3.1. Алгоритм**
* Аналог Дейкстры: начинаем с произвольной вершины `s`; на каждом шаге добавляем минимальное ребро, соединяющее посещённые и непосещённые вершины
* **Структура:** priority queue `(вес_рёбра, вершина)`, `visited[]`; при обработке `v`: для каждого непосещённого соседа `u` — potential релаксация через `w(v,u)`

### **3.2. Сложность**
* Binary heap: `O((n + m) log n)` — каждая вершина извлекается `O(log n)`, каждое ребро может вызвать вставку
* Fibonacci heap: `O(m + n log n)` — decrease-key `O(1)` амортизированно

### **3.3. Когда использовать**
* Густые графы (`m ≈ n²`) — Prim лучше Kruskal (без сортировки `m` рёбер)
* Когда граф задан матрицей смежности — Prim естественнее

## **4. Алгоритм Борувки (Boruvka)**

### **4.1. Алгоритм**
1. Каждая вершина — отдельная компонента
2. На каждом шаге: для каждой компоненты найти минимальное исходящее ребро (к другой компоненте)
3. Добавить все найденные рёбра в MST; объединить компоненты
4. Повторять until 1 компонента

### **4.2. Сложность**
* Каждый шаг: `O(m)` (перебор рёбер для каждой компоненты)
* Число шагов: `O(log n)` (каждый шаг сокращает число компонент вдвое минимум)
* Итого: `O(m log n)`

### **4.3. Параллелизм**
* Шаги параллелизуемы: для каждой компоненты — независимый поиск минимума
* Применение: распределённые вычисления, GPU

## **5. Сравнение алгоритмов**

| Алгоритм | Сложность | Когда лучше |
|---|---|---|
| Kruskal | O(m log m) | Разреженные графы, MST + доп. информация |
| Prim | O((n+m) log n) | Густые графы, начало с фиксированной вершины |
| Boruvka | O(m log n) | Параллельные вычисления, распределённые системы |

# **B. ВТОРОЕ ПО МИНИМАЛЬНОСТИ ОСТОВНОЕ ДЕРЕВО**

## **1. Second-best MST**

### **1.1. Задача**
* Найти остовное дерево с минимальной суммой весов, отличное от MST; т.е. минимизировать `w(T') − w(MST)`

### **1.2. Алгоритм**
1. Построить MST `T` (Kruskal/Prim)
2. Для каждого не-MST-ребра `(u,v)` с весом `w`:
    * Найти `max_edge_on_path(u,v)` в MST (максимальное ребро на уникальном пути в дереве)
    * Кандидат: `w(T) − max_edge + w`; минимизировать разницу
3. Ответ: минимум по всем кандидатам

### **1.3. Сложность**
* Построение MST: `O(m log n)`
* Для каждого из `m − (n−1)` не-MST-ребра: LCA + max на пути за `O(log n)` (binary lifting) или `O(1)` (Sparse Table после `O(n log n)` предподсчёта)
* Итого: `O(m log n)` или `O(m + n log n)`

### **1.4. Связь**
* LCA через binary lifting — `struct.md` (VI.B)
* Sparse Table — `struct.md` (V.C)

## **2. Minimum Bottleneck Spanning Tree (MBST)**

* **Определение:** дерево, минимизирующее максимальный вес ребра: `max_{e ∈ T} w(e)` → min
* **Свойство:** MBST совпадает с MST по bottleneck-свойству: `max_{e ∈ MST} w(e) = min_{T} max_{e ∈ T} w(e)`
* **Алгоритм:** найти MST → его максимальный ребро — ответ; или: сортировка рёбер + DSU до момента когда граф станет связным

## **3. Minimum Spanning Forest (MSF)**

* **Для несвязных графов:** MST на каждой компоненте связности
* **Алгоритм:** Kruskal/Prim/Boruvka без модификаций ( DSU автоматически обрабатывает компоненты)

# **C. ТЕОРЕТИЧЕСКИЕ ОСНОВЫ**

## **1. Матричная теорема Кирхгофа (Kirchhoff's Matrix Tree Theorem)**

### **1.1. Laplacian matrix**
* **Определение:** `L = D − A`, где `D` — диагональная матрица степеней (`D[i][i] = deg(i)`), `A` — матрица смежности
* **Свойства:** `L` симметрична; все строки/столбцы суммируются в 0; собственный вектор `(1,1,...,1)` с собственным значением 0

### **1.2. Теорема**
* **Утверждение:** число остовных деревьев связного графа = любой минор матрицы `L` порядка `n−1` (определитель матрицы, полученной удалением одной строки и одного столбца)
* **Доказательство:** через комбинаторную интерпретацию определителя (сумма по перестановкам)

### **1.3. Вычисление**
* Построение `L`: `O(n²)`
* Вычисление `det(L')` через Гаусс: `O(n³)`
* Для полных графов `K_n`: `det(L') = n^{n−2}` (формула Кэли — следствие)

## **2. Код Прюфера (Prufer Sequence)**

### **2.1. Биекция**
* **Утверждение:** взаимно однозначное соответствие: деревья на `n` маркированных вершинах ↔ последовательности Прюфера длины `n − 2` из чисел `{0, 1, ..., n−1}`
* **Формула Кэли:** число деревьев = `n^{n−2}` (все последовательности длины `n−2` из `n` символов)

### **2.2. Построение кода (дерево → последовательность)**
1. Найти лист с наименьшей маркировкой
2. Записать его соседа (единственный)
3. Удалить лист
4. Повторять until останется 2 вершины
* **Сложность:** `O(n log n)` через множество листьев (set); `O(n)` если использовать массивы

### **2.3. Восстановление дерева (последовательность → дерево)**
* Идея: на каждом шаге лист — наименьшая вершина, не出现在 в остатке кода
* **Сложность:** `O(n log n)` через priority queue; `O(n)` через массив степеней

### **2.4. Применение**
* Подсчёт числа деревьев: `n^{n−2}`
* Генерация случайных деревьев: случайная последовательность Прюфера
* Нумерация деревьев: биекция позволяет пронумеровать все `n^{n−2}` деревьев

## **3. Формула Кэли**

* **Утверждение:** число различных остовных деревьев полного графа `K_n` = `n^{n−2}`
* **Следствие:** теоремы Кирхгофа и Прюфера дают одно и то же число

# **D. ОБРАТНЫЕ ЗАДАЧИ И ОПТИМИЗАЦИИ**

## **1. Steiner Tree Problem**

### **1.1. Постановка**
* **Задача:** дан граф `G = (V, E)` и подмножество терминалов `T ⊆ V`; найти минимальное дерево, соединяющее все терминалы (вершины `V \ T` можно использовать как промежуточные)
* **Сложность:** NP-трудна (даже для `|T| = 4` в общих графах)

### **1.2. DP по подмножествам терминалов**
* **Идея:** `dp[S][v]` = стоимость минимального дерева, соединяющего терминалы из подмножества `S ⊆ T` и заканчивающегося в `v`
* **Рекуррентность:** `dp[S][v] = min_{T ⊂ S, u ∈ V} dp[T][u] + dist(u,v)` (разбиение `S` на две части) + `dp[S][v] = min_{(u,v) ∈ E} dp[S][u] + w(u,v)` ( extension)
* **Сложность:** `O(3^{|T|} · n + 2^{|T|} · (n + m) log n)` — DP по подмножествам + Dijkstra

### **1.3. Метрический случай**
* Если веса удовлетворяют неравенству треугольника: 2-приближение через MST на терминалах
* **Алгоритм:** построить полный граф на `T` с весами `dist(u,v)`, затем MST в этом полном графе → дерево в исходном графе через кратчайшие пути

## **2. Degree-constrained MST**
* **Задача:** MST с ограничением: `deg(v) ≤ b(v)` для каждой вершины
* **Сложность:** NP-трудна
* **Эвристики:** локальный поиск, жадные модификации

## **3. Capacitated MST**
* **Задача:** MST с ограничением на суммарный вес поддеревьев
* **Сложность:** NP-трудна
* **Применение:** логистика, маршрутизация с ограничениями на транспорт
