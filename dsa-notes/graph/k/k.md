# **A. ВЕРОЯТНОСТНЫЕ АЛГОРИТМЫ**

## **1. Random Walks**

### **1.1. Определение**
* **Случайное блуждание:** из текущей вершины `v` выбираем соседа `u` равновероятно; повторяем `k` шагов
* **Марковская цепь:** матрица переходов `P[v][u] = 1/deg(v)` для соседей; стационарное распределение `π = π·P`

### **1.2. Свойства**
* Для неориентированных связных графов: `π(v) = deg(v) / 2m` (степень нормирована на число рёбер)
* **Mixing time:** время сходимости к стационарному распределению; зависит от спектра лапласиана

### **1.3. Применение**
* Оценка размера графа (Metropolis-Hastings)
* Решение 2-SAT и других задач через Markov Chain Monte Carlo
* Генерация случайных деревьев (random spanning tree)

## **2. PageRank**

### **2.1. Формула**
* `PR(v) = (1 − d)/n + d · Σ_{u→v} PR(u)/deg(u)` где `d` — damping factor (обычно 0.85)
* **Интерпретация:** с вероятностью `d` пользователь идёт по ссылке, с вероятностью `1 − d` — случайно переходит на новую страницу
* **Матричная форма:** `PR = (1−d)/n · 1 + d · M · PR` где `M` — column-stochastic transition matrix

### **2.2. Итеративное вычисление (Power Method)**
1. Начать с `PR(v) = 1/n` для всех `v`
2. Итерировать: `PR_new(v) = (1−d)/n + d · Σ_{u→v} PR_old(u)/deg(u)`
3. Остановка: `||PR_new − PR_old||₁ < ε`
4. **Сложность:** `O(m · iterations)` где обычно `iterations ≤ 100`

## **3. Случайные графы (Erdős–Rényi)**

### **3.1. Модель G(n, p)**
* `n` вершин; каждое ребро существует с вероятностью `p` независимо
* **Ожидаемое число рёбер:** `E[|E|] = C(n,2) · p`

### **3.2. Фазовые переходы**
* `p < 1/n`: все компоненты размера O(log n)
* `p = 1/n`: появляется giant component размера Θ(n)
* `p > ln(n)/n`: граф связен с высокой вероятностью

# **B. МЕТАЭВРИСТИКИ**

## **1. Simulated Annealing**

### **1.1. Идея**
* Имитация отжига металла: на начальных этапах принимаем худшие решения с высокой вероятностью; постепенно «остываем»
* **Temperature schedule:** `T(t)` — монотонно убывает; вероятность принятия худшего решения `P = exp(−ΔE / T)`

### **1.2. Параметры**
* Начальная температура `T₀`: достаточно высокая (принимаем почти все переходы)
* Коэффициент охлаждения `α` (обычно 0.95–0.999): `T_{k+1} = α · T_k`
* Критерий остановки: `T < T_min` или количество итераций

## **2. Genetic Algorithm**

### **2.1. Идея**
* Популяция решений; эволюция через: отбор (selection), кроссовер (crossover), мутация (mutation)
* **Фитнес-функция:** оценка качества решения

### **2.2. Операторы**
* **Selection:** рулетка (proportional), турнир (tournament), rank-based
* **Crossover:** одноточечный, двухточечный, uniform
* **Mutation:** изменение случайного гена с вероятностью `p_m`

## **3. Ant Colony Optimization**
* Феромоны на рёбрах; каждый муравей строит решение; обновление феромонов: усиление лучших путей, испарение

## **4. Tabu Search**
* Запрет на возврат к недавним состояниям (tabu list); позволяет выходить из локальных оптимумов
