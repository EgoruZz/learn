# **ГЕОМЕТРИЯ**

> Разделы a–h: `geometry/a/` ... `geometry/h/` — каждый раздел — конспект `X.md` + реализация `X.cpp`. Класс `GeometryAlgorithms` объединяет все методы; каждый конспект использует материал предыдущих и переиспользует реализации из смежных веток. ## **A. МАТЕМАТИЧЕСКИЕ ОСНОВЫ И КООРДИНАТЫ**
> `a/a.md` · `a/a.cpp` · `struct GeometryBasics`

### **1. Аксиоматика**
*   Аксиомы Евклида; геометрия Лобачевского; обоснование метода координат

### **2. Системы координат**
*   **Декартова (прямоугольная):** `Oxy`, `Oxyz`; ортогональные оси, равный масштаб
*   **Полярная:** `(r, φ)` → `x = r cos φ`, `y = r sin φ`; обратное: `r = √(x²+y²)`, `φ = atan2(y,x)`
*   **Косоугольная:** оси не ортогональны; метрика `ds² = gᵢⱼdxᵢdxⱼ` (метрический тензор); при `⟨e₁,e₂⟩ ≠ 0`
*   **Треугольная (barycentric):** координаты `(λ₁, λ₂, λ₃)`, `λ₁+λ₂+λ₃ = 1`, `λᵢ ≥ 0`; точка `P = λ₁A + λ₂B + λ₃C`; удобна для растеризации, интерполяции, проверки принадлежности треугольнику
*   **Аффинная:** `x' = Ax + b`; инвариант — параллельность и отношение длин
*   **Цилиндрическая:** `(r, φ, z)` — для вращательно-симметричных задач
*   **Сферическая:** `(r, θ, φ)` — для задач на сфере (навигация, география); расстояние: great-circle distance
*   **Обобщённые криволинейные:** ковариантные/контравариантные компоненты; метрический тензор `gᵢⱼ`

### **3. Точность вычислений**
*   `double` IEEE 754: `ε ≈ 10⁻¹⁶`; сравнение через `fabs(a−b) < eps` (типично `10⁻⁹`)
*   **Предикаты ориентации:** `orient(a,b,c) = sign(det(...))` через compensated summation
*   **Kahan summation:** компенсация ошибки округления при длинных суммах

### **4. Основные вычисления**
*   Длина отрезка: `√(ΣΔxᵢ²)`; Манхэттен: `Σ|Δxᵢ|`; Чебышёв: `max|Δxᵢ|`
*   Площадь треугольника: `|det(...)|/2`; площадь многоугольника: шнуровка `O(n)`
*   Объём тетраэдра: `|det(p₁−p₀|p₂−p₀|p₃−p₀)|/6`; объём многогранника: Дивергентная теорема
*   **Дуговая длина:** `∫|r'(t)|dt`; **площадь поверхности:** `∬|rᵤ × rᵥ| dudv`
*   Предикаты: `on_segment`, `ccw`, `collinear`
*   **Комплексные числа:** поворот `z·e^{iθ}`, отражение `z̄`

## **B. ВЕКТОРНАЯ АЛГЕБРА ДЛЯ ГЕОМЕТРИИ**
> `b/b.md` · `b/b.cpp` · `struct VectorAlgebra`

### **1. Расстояния (уникально для геометрии)**
*   **Евклидово:** `√(Σ(xᵢ−yᵢ)²)` — стандартная метрика
*   **Манхэттен:** `Σ|xᵢ−yᵢ|` — для задач на решётках, такси
*   **Чебышёва:** `max|xᵢ−yᵢ|` — для задач с диагональными перемещениями
*   **Минковского:** `(Σ|xᵢ−yᵢ|^p)^{1/p}` — обобщение: `p=1` → Манхэттен, `p=2` → Евклидово, `p→∞` → Чебышёв
*   **Применение:** выбор метрики определяет алгоритм (BFS на решётке → Манхэттен; k-NN → Евклидово)

### **2. Геометрическое скалярное произведение**
*   Угол: `cos θ = ⟨u,v⟩ / (|u|·|v|)`; перпендикулярность: `⟨u,v⟩ = 0`
*   Проекция: `proj_u(v) = (⟨v,u⟩/⟨u,u⟩)·u`
*   **Связь с linear-algebra:** определение в `linear-algebra` (E)

### **3. Векторное произведение (ℝ³)**
*   `u × v` — перпендикуляр; `|u × v|` = площадь параллелограмма
*   **Связь с linear-algebra:** в `linear-algebra` (C)

### **4. Смешанное произведение (ℝ³)**
*   `(u × v) · w = det(...)` — объём; `= 0` ⟺ компланарны

### **5. Геометрические приложения**
*   Площадь треугольника через векторное произведение; объём тетраэдра через смешанное
*   Коллинеарность/компланарность через определители

## **C. АНАЛИТИЧЕСКАЯ ГЕОМЕТРИЯ 2D**
> `c/c.md` · `c/c.cpp` · `struct AnalyticGeometry2D`

### **1. Прямая на плоскости**
*   **Уравнения:** общее `Ax + By + C = 0`, параметрическое `r = r₀ + t·d`, нормальное `⟨n, x−p⟩ = 0`
*   **Расстояние:** `|Ax₀ + By₀ + C| / √(A² + B²)`
*   **Параллельность:** `A₁B₂ = A₂B₁`; перпендикулярность: `A₁A₂ + B₁B₂ = 0`
*   **Пересечение:** `det ≠ 0` → единственное; проверка отрезков `O(1)` через orient + on_segment
*   **Угол:** `tan θ = |(m₁−m₂)/(1+m₁m₂)|`

### **2. Окружность**
*   **Уравнение:** `(x−a)² + (y−b)² = r²`; через 3 точки, через касательные
*   **Описанная окружность:** центр = пересечение серединных перпендикуляров; `O(n)`
*   **Вписанная окружность:** `r = 2S/p`; центр = биссектрисы
*   **Касательная:** расстояние от центра до прямой = `r`
*   **Пересечение двух окружностей:** `d = |c₁c₂|`; `d > r₁+r₂` → нет; `d = r₁+r₂` → касание; `|r₁−r₂| < d < r₁+r₂` → 2 точки пересечения `O(1)`
*   **Общие касательные:** внутренние/внешние; зависит от взаимного расположения окружностей

### **3. Кривые второго порядка**
*   **Эллипс:** `x²/a² + y²/b² = 1`; фокусы `(±c, 0)` где `c = √(a²−b²)`; эксцентриситет `e = c/a`
*   **Гипербола:** `x²/a² − y²/b² = 1`; асимптоты `y = ±(b/a)x`; `e = c/a > 1`
*   **Парабола:** `y² = 2px`; фокус `(p/2, 0)`, директриса `x = −p/2`
*   **Общее уравнение:** `Ax² + Bxy + Cy² + Dx + Ey + F = 0`; `Δ = B² − 4AC`; классификация через `Δ`
*   **Приведение к каноническому виду:** метод вращений `θ = ½arctan(B/(A−C))`
*   **Конические сечения:** пересечение конуса плоскостью → эллипс/парабола/гипербола
*   **Спирали:** Архимедова `r = aφ`, логарифмическая `r = ae^{bφ}`, гиперболическая `rφ = a`
*   **Касательные к кривым второго порядка**

## **D. АНАЛИТИЧЕСКАЯ ГЕОМЕТРИЯ 3D**
> `d/d.md` · `d/d.cpp` · `struct AnalyticGeometry3D`

### **1. Плоскость**
*   **Уравнение:** `Ax + By + Cz + D = 0`; нормаль `n = (A,B,C)`; через 3 точки: `n = (p₂−p₁) × (p₃−p₁)`
*   **Расстояние:** `|Ax₀ + By₀ + Cz₀ + D| / |n|`
*   **Параллельность:** `n₁ ∥ n₂`; перпендикулярность: `n₁ ⟂ n₂`

### **2. Прямая в пространстве**
*   **Параметрическое:** `r = r₀ + t·d`
*   **Расстояние между скрещивающимися:** `|⟨(p₂−p₁), (d₁×d₂)⟩| / |d₁×d₂|`
*   **Линия пересечения двух плоскостей:** направление `n₁ × n₂`

### **3. Пространственные тела**
*   **Сфера:** `(x−a)² + (y−b)² + (z−c)² = R²`; объём `4πR³/3`; площадь `4πR²`
*   **Цилиндр:** `πR²h`; **Конус:** `πR²h/3`; **Эллипсоид:** `4πabc/3`
*   **Поверхности второго порядка:** параболоиды, гиперболоиды; канонические уравнения

## **E. ВЫПУКЛЫЕ МНОГОУГОЛЬНИКИ**
> `e/e.md` · `e/e.cpp` · `struct ConvexPolygons`

### **1. Свойства**
*   Все углы `< π`; треугольная разбиение без добавления вершин; ядро = пересечение полуплоскостей

### **2. Периметр и площадь**
*   Периметр `O(n)`; площадь шнуровкой `O(n)`; центр масс `O(n)`

### **3. Выпуклая оболочка**
*   **Джарвис:** `O(nh)`; **Грэхэм:** `O(n log n)`; **Эндрю:** `O(n log n)`; **Чан:**预期 `O(n log h)`
*   **Вращающиеся калиперы:** диаметр, ширина `O(n)` после оболочки

### **4. Проверка выпуклости**
*   Все повороты одного знака `O(n)` через `ccw`

### **5. Point-in-convex-polygon (быстрая проверка)**
*   **Бинарный поиск:** для выпуклого многоугольника `O(log n)` — разбиваем на треугольники (вершина + крайние рёбра), определяем через `ccw`
*   **Применение:** SAT (Separating Axis Theorem), проверка вхождения вершины в выпуклый многоугольник

### **6. Minkowski sum (сумма Минковского)**
*   `A ⊕ B = {a+b : a ∈ A, b ∈ B}` — сумма выпуклых многоугольников
*   **Алгоритм:** слияние рёбер по углам (как Merge Sort); `O(n + m)` для выпуклых `n` и `m` вершин
*   **Применение:** collision detection, SAT для выпуклых тел

### **7. Минимальный ограничивающий прямоугольник (MBR)**
*   **Ось-параллельный:** `min/max` координат; `O(n)`
*   **Произвольный:** через вращающиеся калиперы; `O(n)` после выпуклой оболочки
*   **Применение:** AABB (axis-aligned bounding box) для collision detection

## **F. ВЫЧИСЛИТЕЛЬНАЯ ГЕОМЕТРИЯ: ПОЛИГОНЫ**
> `f/f.md` · `f/f.cpp` · `struct ComputationalGeometry`

### **1. Алгоритмы на прямой**
*   **Объединение отрезков:** сортировка + merge `O(n log n)`
*   **Покрытие отрезков точками:** жадный `O(n log n)`

### **2. Решётчатая геометрия**
*   **Теорема Пика:** `S = i + b/2 − 1` (`i` — внутренние, `b` — граничные); обратная формула

### **3. Принадлежность точки многоугольнику**
*   **Ray casting:** `O(n)` — число пересечений луча с рёбрами
*   **Winding number:** `O(n)` — сумма углов поворота

### **4. Пересечение полуплоскостей**
*   Построение `O(n log n)` через сортировку по углам + deque
*   Применение: ядеро многоугольника

### **5. Оптимизация в многоугольниках**
*   **Максимальная вписанная окружность:** тернарный поиск `O(n log²C)`
*   **Минимальная охватывающая окружность:** Welzl `O(n)` randomized
*   **Минимальный ограничивающий прямоугольник:** `O(n)` через калиперы

## **G. ПРОСТРАНСТВЕННЫЕ СТРУКТУРЫ**
> `g/g.md` · `g/g.cpp` · `struct SpatialStructures`

### **1. KD-tree**
*   Двоичное дерево разбиения; построение `O(n log n)`
*   **k-ближайших соседей:** `O(√n)` среднее; **nearest neighbor:** `O(log n)` среднее

### **2. Quadtree / Octree**
*   Разбиение на 4/8 частей; для разреженных данных; range queries

### **3. Range Tree**
*   Ортогональные запросы: `O(log^(d−1) n + k)` для `d`-мерного пространства

### **4. Диаграмма Вороного**
*   Разбиение по ближайшему центру `O(n log n)`; двойственный граф Делоне
*   **Метрики:** классическая (Евклидова), **Voronoi L₁** (Манхэттен), **Voronoi L∞** (Чебышёв)

### **5. Ближайшая пара точек**
*   Divide & Conquer `O(n log n)` через разбиение по медиане

## **H. ТРИАНГУЛЯЦИИ**
> `h/h.md` · `h/h.cpp` · `struct Triangulations`

### **1. Триангуляция Делоне**
*   Ни одна окружность не содержит вершин внутри; уникальна; `O(n log n)`

### **2. Триангуляция монотонных многоугольников**
*   Монотонность по оси `y`; триангуляция через стек `O(n)`

### **3. Алгоритм Дугласа-Пекера**
*   Упрощение ломаных; `O(n log n)` через рекурсию

### **4. 3D триангуляция**
*   Тетраэдральная разбивка выпуклых многогранников `O(n log n)`
