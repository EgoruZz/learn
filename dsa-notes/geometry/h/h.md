**H. ТРИАНГУЛЯЦИИ**

> **Архитектура:** `Triangulations` (h.cpp) — наследует `SpatialStructures` (g.cpp). Реализует: триангуляцию Делоне (через выпуклую оболочку), триангуляцию монотонных многоугольников, алгоритм Дугласа-Пекера. Все методы параметризованы и работают через `Point` и `double`.
>
> **Связи:** `ConvexPolygons` (e) — выпуклые оболочки; `ComputationalGeometry` (f) — point_in_polygon; `VectorAlgebra` (b) — расстояния; `GeometryBasics` (a) — orient, ccw.

---

# **1. Триангуляция Делоне**
*   Ни одна окружность не содержит вершин внутри; уникальна для general position; `O(n log n)` через сортировку
*   Свойство: максимизирует min-angle среди всех триангуляций
*   `delaunay_triangulation(points)` → список рёбер `(i,j)` — через выпуклую оболочку + проверку `in_circle`

# **2. Триангуляция монотонных многоугольников**
*   Многоугольник монотонен по оси `y`: каждая горизонтальная прямая пересекает ≤ 2 ребра
*   `is_monotone_y(poly)` — проверка монотонности
*   `triangulate_monotone(poly)` — триангуляция через стек `O(n)`, возвращает список треугольников `(i,j,k)`

# **3. Алгоритм Дугласа-Пекера**
*   Упрощение ломаных: рекурсивное удаление вершин с расстоянием < порога `ε`
*   Сложность: `O(n log n)` или `O(n)` через предвычисление
