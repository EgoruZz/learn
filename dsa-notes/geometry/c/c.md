**C. АНАЛИТИЧЕСКАЯ ГЕОМЕТРИЯ 2D**

> **Архитектура:** `AnalyticGeometry2D` (c.cpp) — наследует `VectorAlgebra` (b.cpp). Реализует: прямые (уравнения, расстояния, пересечения), окружности (описанная, вписанная, пересечение, касательные), кривые второго порядка (эллипс, гипербола, парабола, общее уравнение). Все методы параметризованы и работают через `Point` и `double`.
>
> **Связи:** `VectorAlgebra` (b) — расстояния, скалярное/векторное произведение; `GeometryBasics` (a) — Point, orient; `math/linear-algebra` (I) — комплексные числа (для поворотов); `math/linear-algebra` (C) — определители (для пересечений).

# **1. Прямая на плоскости**

## **1.1. Уравнения**
*   **Общее:** `Ax + By + C = 0` ( `A² + B² ≠ 0` )
*   **Параметрическое:** `r = r₀ + t·d` где `d = (dx, dy)` — направляющий вектор
*   **Нормальное:** `⟨n, x−p⟩ = 0` где `n = (A,B)` — нормаль
*   **Через 2 точки:** `(y−y₁)(x₂−x₁) = (x−x₁)(y₂−y₁)`

## **1.2. Расстояние от точки до прямой**
*   `d = |Ax₀ + By₀ + C| / √(A² + B²)`; через векторное произведение: `d = |(p₂−p₁) × (p₁−p₀)| / |p₂−p₁|`

## **1.3. Условия расположения**
*   **Параллельность:** `A₁B₂ = A₂B₁`; **перпендикулярность:** `A₁A₂ + B₁B₂ = 0`
*   **Пересечение прямых:** `det([[A₁,B₁],[A₂,B₂]]) ≠ 0` → единственное; `= 0` → параллельны/совпадают
*   **Пересечение отрезков:** `O(1)` через `orient` + `on_segment` (из `a`)

## **1.4. Угол между прямыми**
*   `tan θ = |(m₁−m₂)/(1+m₁m₂)|`; через `atan2`
*   `angle_between_lines(A₁,B₁,A₂,B₂) = arccos(|A₁A₂+B₁B₂| / (|n₁|·|n₂|))`

# **2. Окружность**

## **2.1. Основные формулы**
*   **Уравнение:** `(x−a)² + (y−b)² = r²`
*   **Через 3 точки:** центр = пересечение серединных перпендикуляров; `O(1)`
*   **Описанная окружность:** центр = (a,b) через определители; `r = dist(center, vertex)`
*   **Вписанная окружность:** `r = 2S/p` (S — площадь, p — периметр); центр = `(aA + bB + cC) / P`; `inscribed_circle(a,b,c)`
*   **Касательная из точки:** `tangent_from_point_to_circle(p,c,r)` — 2 точки касания, через проекцию

## **2.2. Пересечение двух окружностей**
*   `d = dist(c₁, c₂)`; `r₁, r₂` — радиусы
*   `d > r₁ + r₂` → нет пересечений (0 точек)
*   `d = r₁ + r₂` → касание снаружи (1 точка)
*   `|r₁ − r₂| < d < r₁ + r₂` → 2 точки пересечения
*   `d = |r₁ − r₂|` → касание изнутри (1 точка)
*   `d < |r₁ − r₂|` → одна внутри другой (0 точек)
*   **Вычисление точек:** через треугольник `(c₁, c₂, intersection)` или через систему уравнений; `O(1)`

# **3. Кривые второго порядка**

## **3.1. Эллипс**
*   `x²/a² + y²/b² = 1`; фокусы `(±c, 0)` где `c = √(a²−b²)`; эксцентриситет `e = c/a < 1`

## **3.2. Гипербола**
*   `x²/a² − y²/b² = 1`; асимптоты `y = ±(b/a)x`; `e = c/a > 1`

## **3.3. Парабола**
*   `y² = 2px`; фокус `(p/2, 0)`, директриса `x = −p/2`

## **3.4. Общее уравнение**
*   `Ax² + Bxy + Cy² + Dx + Ey + F = 0`; дискриминант `Δ = B² − 4AC`
*   `Δ < 0` → эллипс; `Δ = 0` → парабола; `Δ > 0` → гипербола
*   **Приведение:** метод вращений `θ = ½arctan(B/(A−C))` → устранение `xy`-члена

## **3.5. Спирали**
*   Архимедова `r = aφ`, логарифмическая `r = ae^{bφ}`, гиперболическая `rφ = a`
