**E. ВЫПУКЛЫЕ МНОГОУГОЛЬНИКИ**

> **Архитектура:** `ConvexPolygons` (e.cpp) — наследует `AnalyticGeometry3D` (d.cpp). Реализует: выпуклую оболочку (Джарвис, Грэхэм, Эндрю, Чан), point-in-convex-polygon, Minkowski sum, вращающиеся калиперы, проверку выпуклости. Все методы параметризованы и работают через `Point` и `double`.
>
> **Связи:** `AnalyticGeometry2D` (c) — Point, orient, ccw; `VectorAlgebra` (b) — расстояния, angle_between; `technique.md` (I) — сортировка для Грэхэма/Чана; `struct.md` (IV) — priority queue для алгоритмов.

---

# **1. Свойства выпуклых многоугольников**
*   Все углы `< π`; треугольная разбиение без добавления вершин
*   **Ядро:** множество точек, из которых видны все вершины; построение `O(n)` через пересечение полуплоскостей

# **2. Периметр и площадь**
*   Периметр: `Σ |vᵢvᵢ₊₁|` `O(n)`; `perimeter(poly)`
*   Площадь: шнуровка `O(n)`; `area(poly)` — обёртка над `polygon_area`

# **3. Выпуклая оболочка**
*   **Джарвис (Gift Wrapping):** `O(nh)` — находим крайнюю точку, затем ищем следующую
*   **Грэхэм:** сортировка по полярному углу `O(n log n)` + стек `O(n)`
*   **Эндрю (Monotone Chain):** верхняя + нижняя огибающие `O(n log n)`
*   **Чан:**预期 `O(n log h)` — гибрид для малых `h`
*   **Вращающиеся калиперы:** диаметр, ширина `O(n)` после оболочки

# **4. Проверка выпуклости**
*   Все повороты одного знака `O(n)` через `ccw`

# **5. Point-in-convex-polygon**
*   **Бинарный поиск:** `O(log n)` для выпуклого многоугольника — проверяем треугольник через `ccw`

# **6. Minkowski sum (сумма Минковского)**
*   `A ⊕ B = {a+b : a ∈ A, b ∈ B}` — слияние рёбер по углам; `O(n + m)` для выпуклых

# **7. Минимальный ограничивающий прямоугольник**
*   Ось-параллельный: `O(n)` через min/max координат
*   Произвольный: через вращающиеся калиперы `O(n)` после оболочки
