**A. МАТЕМАТИЧЕСКИЕ ОСНОВЫ И КООРДИНАТЫ**

> **Архитектура:** `GeometryBasics` (a.cpp) — базовый класс всей ветки geometry. Вводит предикаты ориентации, расстояния, площади, объёмы, системы координат, основные вычислительные примитивы. Все последующие разделы (B–H) строятся на этих примитивах.
>
> **Связи:** линейная алгебра (векторы, определители) — `math/linear-algebra` (B, C, E); комплексные числа — `math/linear-algebra` (I); модулярная арифметика — `math/number-theory` (для решётчатой геометрии).

# **1. Предикаты ориентации**

## **1.1. Определение**
*   `orient(a,b,c)`: знак определителя `det([[ax,ay,1],[bx,by,1],[cx,cy,1]])`
*   **Значения:** `+1` (против часовой/CCW), `−1` (по часовой/CW), `0` (коллинеарны)

## **1.2. Реализация (с eps)**
*   `orient = sign((bx−ax)(cy−ay) − (by−ay)(cx−ax))`
*   **EPS:** `fabs(a−b) < eps` где `eps ≈ 10⁻⁹` (для double)

# **2. Системы координат**

## **2.1. Декартова (прямоугольная)**
*   `Oxy` для 2D, `Oxyz` для 3D; ортогональные оси, равный масштаб
*   **Преобразование координат:** параллельный перенос `x' = x + dx`; поворот `x' = x cos θ − y sin θ`, `y' = x sin θ + y cos θ`

## **2.2. Полярная**
*   `(r, φ)` → `x = r cos φ`, `y = r sin φ`; обратное: `r = √(x²+y²)`, `φ = atan2(y,x)`
*   **Преобразование:** декартовы → полярные и обратно; `O(1)`

## **2.3. Косоугольная**
*   Оси не ортогональны; координаты через базис `(e₁, e₂)` где `⟨e₁,e₂⟩ ≠ 0`
*   **Метрика:** `ds² = gᵢⱼdxᵢdxⱼ` (метрический тензор)

## **2.4. Треугольная (barycentric)**
*   Координаты `(λ₁, λ₂, λ₃)` относительно вершин треугольника; `λ₁+λ₂+λ₃ = 1`, `λᵢ ≥ 0`
*   Точка: `P = λ₁A + λ₂B + λ₃C`
*   **Применение:** растеризация треугольников, интерполяция, проверка принадлежности

## **2.5. Аффинная**
*   `x' = Ax + b`; инвариант — параллельность и отношение длин

## **2.6. Цилиндрическая и сферическая**
*   Цилиндрическая: `(r, φ, z)` — для вращательно-симметричных задач
*   Сферическая: `(r, θ, φ)` — для задач на сфере; расстояние: great-circle distance

# **3. Точность вычислений**

*   `double` IEEE 754: `ε ≈ 10⁻¹⁶`; сравнение через `fabs(a−b) < eps` (типично `10⁻⁹`)
*   **Предикаты ориентации:** `orient(a,b,c) = sign(det(...))` через compensated summation
*   **Kahan summation:** компенсация ошибки округления при длинных суммах
*   **sign(x):** `(x > eps) − (x < −eps)`

---

# **4. Основные вычисления**

## **4.1. Расстояния**
*   Евклидово: `√(ΣΔxᵢ²)`; Манхэттен: `Σ|Δxᵢ|`; Чебышёв: `max|Δxᵢ|`
*   От точки до прямой: `|Ax₀ + By₀ + C| / √(A² + B²)`
*   От точки до отрезка: проекция + проверка на отрезке

## **4.2. Площади и объёмы**
*   Треугольник: `|det(...)|/2`; многоугольник: шнуровка `O(n)`
*   Тетраэдр: `|det(p₁−p₀|p₂−p₀|p₃−p₀)|/6`
*   **Дуговая длина:** `∫|r'(t)|dt`

## **4.3. Тела вращения**
*   Сфера: `V = 4πR³/3`; цилиндр: `V = πR²h`; конус: `V = πR²h/3`; эллипсоид: `V = 4πabc/3`

## **4.4. Предикаты**
*   `on_segment(p, a, b)`: коллинеарность + bounds
*   `ccw(a,b,c)`: counter-clockwise — `orient > 0`
*   **Комплексные числа:** поворот `z·e^{iθ}`, отражение `z̄`; `rotate_complex(p, θ)`
