**D. АНАЛИТИЧЕСКАЯ ГЕОМЕТРИЯ 3D**

> **Архитектура:** `AnalyticGeometry3D` (d.cpp) — наследует `AnalyticGeometry2D` (c.cpp). Реализует: плоскости, прямые в пространстве, расстояния, пространственные тела. Все методы параметризованы и работают через `double`.
>
> **Связи:** `AnalyticGeometry2D` (c) — основные примитивы; `VectorAlgebra` (b) — векторное/смешанное произведения (ℝ³); `math/linear-algebra` (C) — определители (для объёмов).

---

# **1. Плоскость**
*   **Уравнение:** `Ax + By + Cz + D = 0`; нормаль `n = (A,B,C)`
*   **Расстояние:** `|Ax₀ + By₀ + Cz₀ + D| / |n|`
*   **Параллельность:** `n₁ ∥ n₂`; перпендикулярность: `n₁ ⟂ n₂`
*   **Через 3 точки:** `n = (p₂−p₁) × (p₃−p₁)`; `plane_through_3_points(a,b,c)` → `(A,B,C,D)`

# **2. Прямая в пространстве**
*   **Параметрическое:** `r = r₀ + t·d`
*   **Расстояние между скрещивающимися:** `|⟨(p₂−p₁), (d₁×d₂)⟩| / |d₁×d₂|`
*   **Линия пересечения:** направление `n₁ × n₂`; `line_intersection_direction(A₁,B₁,C₁,A₂,B₂,C₂)`

# **3. Пространственные тела**
*   **Сфера:** объём `4πR³/3`, площадь `4πR²`; `volume_sphere_3d(r)`
*   **Цилиндр:** `πR²h`; `volume_cylinder_3d(r,h)`
*   **Конус:** `πR²h/3`; `volume_cone_3d(r,h)`
*   **Эллипсоид:** `4πabc/3`; `volume_ellipsoid_3d(a,b,c)`
*   **Поверхности второго порядка:** параболоиды, гиперболоиды
