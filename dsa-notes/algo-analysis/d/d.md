# **A. РЕКУРРЕНТНЫЕ СООТНОШЕНИЯ**

## **1. Линейные рекуррентности**

### **1.1. Однородные**
* `T(n) = aT(n−1) + bT(n−2)` (Фибоначчи)
* Характеристическое уравнение: `x² = ax + b`
* Корни `r₁, r₂` → `T(n) = αr₁ⁿ + βr₂ⁿ`

### **1.2. Неоднородные**
* `T(n) = T(n−1) + f(n)` → `T(n) = T(0) + Σᵢ₌₁ⁿ f(i)`
* `T(n) = aT(n−1) + bn` → метод подстановки

## **2. Divide-and-conquer рекуррентности**

### **2.1. Общая форма**
* `T(n) = aT(n/b) + f(n)` — a подзадач размера n/b + работа f(n)
* **Примеры:**
    * Merge Sort: `T(n) = 2T(n/2) + O(n)`
    * Binary Search: `T(n) = T(n/2) + O(1)`
    * Strassen: `T(n) = 7T(n/2) + O(n²)`

### **2.2. Неоднородные подзадачи**
* `T(n) = T(n/3) + T(2n/3) + O(n)` — разные размеры подзадач
* Решение: дерево рекурсии + суммирование

## **3. Нестандартные рекуррентности**

### **3.1. Фибоначчи**
* `T(n) = T(n−1) + T(n−2) + O(1)`
* Корни: `φ = (1+√5)/2`, `ψ = (1−√5)/2`
* `T(n) = Θ(φⁿ)` — экспоненциальный рост

### **3.2. Аккерман**
* `A(m, n)`: не применима Мастер-теорема
* Растёт быстрее任何 экспоненциальной функции

# **B. МЕТОДЫ РЕШЕНИЯ**

## **1. Метод подстановки**

### **1.1. Алгоритм**
1. **Угадать** формулу: посмотрите на дерево рекурсии
2. **Доказать** по индукции: подставить и проверить

### **1.2. Пример: Merge Sort**
* Угадываем: `T(n) ≤ cn log n`
* Подставляем: `T(n) = 2T(n/2) + n ≤ 2(c(n/2) log(n/2)) + n = cn log n − cn + n`
* Условие: `−cn + n ≤ 0` → `c ≥ 1` ✓

## **2. Дерево рекурсии**

### **2.1. Идея**
* Визуализация: корень = T(n), дети = рекурсивные вызовы
* **Суммирование по уровням:** стоимость уровня + общее число уровней

### **2.2. Пример: Merge Sort**
```
            T(n)
           /    \
       T(n/2)  T(n/2)     ← уровень 0: n работы
       /  \    /  \
     T(n/4)...        T(n/4)  ← уровень 1: n работы (2 × n/2)
     ...
                        ← уровень log₂n: n работа
```
* **Итого:** n × log₂n → O(n log n)

## **3. Итерационный метод**

### **3.1. Алгоритм**
* Раскрытие рекуррентности: подставляем T(n−1) выражение для T(n−2)
* `T(n) = T(n−1) + n` → `T(n) = T(n−2) + (n−1) + n` → ... → `T(0) + Σ`

# **C. МАСТЕР-ТЕОРЕМА**

## **1. Стандартная форма**

### **1.1. Формулировка**
* `T(n) = aT(n/b) + Θ(nᵈ)`, где `a ≥ 1`, `b > 1`, `d ≥ 0`:
    * **Случай 1:** `a < bᵈ` → `T(n) = Θ(nᵈ)` (work主导)
    * **Случай 2:** `a = bᵈ` → `T(n) = Θ(nᵈ log n)` (balanced)
    * **Случай 3:** `a > bᵈ` → `T(n) = Θ(n^{log_b a})` (recursion主导)

### **1.2. Интуиция**
* Сравниваем «стоимость на верхнем уровне» `f(n)` с «стоимостью рекурсии» `a · f(n/b)`
* Если рекурсия «дороже» — она доминирует (случай 3)

## **2. Расширенная Мастер-теорема**

### **2.1. Формулировка**
* Для `f(n) = Θ(nᵈ logᵏ n)`:
    * Случай 1 (а < bᵈ): `T(n) = Θ(nᵈ)`
    * Случай 2 (a = bᵈ): `T(n) = Θ(nᵈ logᵏ⁺¹ n)`
    * Случай 3 (а > bᵈ): `T(n) = Θ(n^{log_b a})`

## **3. Akra-Bazzi**

### **3.1. Обобщение**
* `T(n) = Σᵢ₌₁ᵏ aᵢT(bᵢn) + f(n)` — разные `bᵢ`
* Находим `p` такое, что `Σ aᵢ · bᵢᵖ = 1`
* `T(n) = Θ(nᵖ (1 + ∫₁ⁿ f(u)/uᵖ⁺¹ du))`

# **D. ПРИМЕРЫ ДЛЯ ОЛИМПИАД**

## **1. Merge Sort**
* `T(n) = 2T(n/2) + O(n)` → случай 2 (a=2, b=2, d=1): `a = bᵈ` → `O(n log n)`

## **2. Quick Sort (средний)**
* `T(n) = 2T(n/2) + O(n)` → `O(n log n)` (аналогично Merge Sort)

## **3. Бинарный поиск**
* `T(n) = T(n/2) + O(1)` → случай 3 (a=1, b=2, d=0): `a = bᵈ` → `O(log n)`

## **4. Быстрое возведение в степень**
* `T(n) = T(n/2) + O(1)` → `O(log n)` (аналогично бинарному поиску)

## **5. Strassen**
* `T(n) = 7T(n/2) + O(n²)` → случай 3 (a=7, b=2, d=2): `a > bᵈ` → `O(n^{log₂7})` ≈ `O(n^{2.807})`

## **6. Karatsuba**
* `T(n) = 3T(n/2) + O(n)` → `O(n^{log₂3})` ≈ `O(n^{1.585})`
