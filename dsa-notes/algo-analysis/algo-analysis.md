## **A. ВВЕДЕНИЕ В ТЕОРИЮ СЛОЖНОСТИ**
> `a/a.md` · `a/a.cpp` · `struct ComplexityBasics` — базовый класс всей ветки

### **A. Основные понятия**
*   **Алгоритм** — формальное определение, свойства (корректность, завершаемость, определённость)
*   **Вычислительная задача** — классификация по типу (решение, оптимизация, поиск, decision)
*   **Размер входа (n)** — параметризация задачи, выбор параметра

### **B. Модели вычислений**
*   **Машина Тьюринга** — формальная модель, классы сложности определяются через неё
*   **RAM-модель** — реалистичная модель: арифметика за O(1), доступ к памяти за O(1)
*   **Word-RAM** — модель с машинным словом размера w = Θ(log n); влияет на битовую сложность

### **C. Метрики эффективности**
*   **Время выполнения** — число операций, реальное время
*   **Пространственная сложность** — используемая память
*   **Другие ресурсы** — число сравнений, обменов, вызовов рекурсии

## **B. АСИМПТОТИЧЕСКИЙ АНАЛИЗ**
> `b/b.md` · `b/b.cpp` · `struct AsymptoticAnalysis : ComplexityBasics`

### **A. Асимптотические обозначения**
*   **O-нотация** (верхняя граница): f(n) = O(g(n)) ⟺ ∃c, n₀: f(n) ≤ c·g(n) при n ≥ n₀
*   **Ω-нотация** (нижняя граница): f(n) = Ω(g(n)) ⟺ ∃c, n₀: f(n) ≥ c·g(n) при n ≥ n₀
*   **Θ-нотация** (точная оценка): f(n) = Θ(g(n)) ⟺ f = O(g) и f = Ω(g)
*   **o-нотация** (строгое верхнее): f(n) = o(g(n)) ⟺ lim f/g = 0
*   **ω-нотация** (строгое нижнее): f(n) = ω(g(n)) ⟺ lim f/g = ∞

### **B. Свойства асимптотических обозначений**
*   Транзитивность: f = O(g), g = O(h) ⟹ f = O(h)
*   Рефлексивность: f = O(f)
*   Симметричность: f = Θ(g) ⟺ g = Θ(f)
*   Суммирование: O(f + g) = O(max(f, g))
*   Умножение: O(f) · O(g) = O(f·g)

### **C. Типовые классы сложности**
*   O(1) — константное, O(log n) — логарифмическое
*   O(√n) — корневое, O(n) — линейное
*   O(n log n) — линейно-логарифмическое (сортировки)
*   O(n²) — квадратичное, O(n³) — кубическое
*   O(nᵏ) — полиномиальное, O(2ⁿ) — экспоненциальное
*   O(n!) — факториальное, O(nⁿ) — суперэкспоненциальное

### **D. Битовая сложность (для олимпиад)**
*   Word-RAM: слово = O(log n) бит; операция над словом = O(1)
*   Битовые операции: AND, OR, XOR, POPCOUNT за O(1)
*   Битовые маски: перебор подмножеств O(2ⁿ · n)

## **D. АНАЛИЗ РЕКУРСИВНЫХ АЛГОРИТМОВ**
> `d/d.md` · `d/d.cpp` · `struct RecursionAnalysis : AnalysisMethods`

### **A. Рекуррентные соотношения**
*   **Линейные:** T(n) = aT(n−1) + f(n) — однородные и неоднородные
*   **Разделяй и властвуй:** T(n) = aT(n/b) + f(n)
*   **Нестандартные:** T(n) = T(n−1) + T(n−2) + O(1) (Фибоначчи)

### **B. Методы решения**
*   **Метод подстановки:** угадывание + индуктивное доказательство
*   **Дерево рекурсии:** визуализация + суммирование по уровням
*   **Итерационный метод:** раскрытие рекуррентности
*   **Переход к сумме:** T(n) = Σ f(aⁱ) · bⁱ

### **C. Мастер-теорема**
*   **Стандартная:** T(n) = aT(n/b) + Θ(nᵈ):
    *   Если a < bᵈ: T(n) = Θ(nᵈ)
    *   Если a = bᵈ: T(n) = Θ(nᵈ log n)
    *   Если a > bᵈ: T(n) = Θ(n^{log_b a})
*   **Расширенная:** для f(n) = Θ(nᵈ logᵏ n)
*   **Akra-Bazzi:** обобщение на T(n) = ΣaᵢT(bᵢn) + f(n)

### **D. Примеры для олимпиад**
*   Merge Sort: T(n) = 2T(n/2) + O(n) → O(n log n)
*   Quick Sort (средний): T(n) = 2T(n/2) + O(n) → O(n log n)
*   Бинарный поиск: T(n) = T(n/2) + O(1) → O(log n)
*   Быстрое возведение в степень: T(n) = T(n/2) + O(1) → O(log n)

## **E. ПРАКТИЧЕСКИЙ АНАЛИЗ**
> `e/e.md` · `e/e.cpp` · `struct PracticalAnalysis : RecursionAnalysis`

### **A. Эмпирический анализ**
*   **Профилирование** — инструменты и методики
    *   gprof — статический профилировщик (GNU); компиляция с `-pg`; профилирует частоту вызовов функций
    *   perf — динамический профилировщик (Linux); опрос процессора (PMU); cache-misses, branch-misses, cycles
    *   Valgrind/Callgrind — эмуляция кэша; точный подсчёт инструкций, промахов кэша, предсказания ветвлений
    *   Intel VTune — аппаратное профилирование; NUMA, кэш, векторизация
    *   google-perf / CPU profiler — профилирование времени в строках кода
*   **Бенчмаркинг** — построение графиков зависимости времени от размера входа
    *   Генерация данных: случайные, отсортированные, обратно-отсортировные, частично отсортированные
    *   Многократный запуск: медиана/среднее из 5-10 прогонов (устойчивость к шуму ОС)
    *   Логарифмический масштаб: `log T(n)` vs `log n` → наклон = степень полинома
    *   Режимansion: нормирование на n, n log n, n² для визуального сравнения
*   **Кросс-алгоритмический анализ**
    *   Сравнение двух алгоритмов: построение `T₁(n)/T₂(n)` → точка перехода (crossover point)
    *   Ниже crossover — быстрее один, выше — другой (например: QuickSort vs MergeSort при малых n)

### **B. Статистические методы анализа**
*   **Регрессионный анализ** — построение модели T(n) = a·nᵇ + c по экспериментальным данным
    *   Логарифмирование: log T(n) = log a + b·log n → линейная регрессия; наклон = степень b
    *   Метод наименьших квадратов (МНК): минимизация Σ(Tᵢ − model(nᵢ))²
    *   Коэффициент детерминации R²: близость модели к данным (1 — идеально)
    *   Аппроксимация разными моделями: n, n log n, n², 2ⁿ — выбор лучшей по R²/AIC/BIC
*   **Доверительные интервалы** — оценка точности измерений времени
    *   Стандартное отклонение σ² = Σ(Tᵢ − T̄)²/(n−1)
    *   95% доверительный интервал: T̄ ± 1.96·σ/√N (при нормальности)
    *   Bootstrap: повторная выборка для оценки распределения медианы времени
*   **Устранение шума** — повышение воспроизводимости
    *   Изоляция: отключение других процессов, фиксация частоты CPU
    *   Прогрев: прогон k₁ итераций перед измерением (разогрев кэша, TLB)
    *   Многократные прогоны: минимум 10-20 запусков; медиана устойчивее среднего к выбросам
    *   Нормализация: деление на время базовой операции (clock cycle normalization)

## **F. ПРОСТРАНСТВЕННАЯ СЛОЖНОСТЬ**
> `f/f.md` · `f/f.cpp` · `struct SpaceComplexity : PracticalAnalysis`

### **A. Модели памяти**
*   **Иерархия:** регистры → L1 → L2 → L3 → RAM → SSD → HDD
*   **Кэш-линия:** 64 байта; промах L1 ~4 цикла, L3 ~40 циклов, RAM ~200 циклов
*   **Word-RAM:** слово = w = Θ(log n) бит

### **B. Анализ использования памяти**
*   **Статическая:** массивы фиксированного размера
*   **Динамическая:** куча, указатели, free
*   **Рекурсивная:** стек вызовов O(depth)
*   **In-place алгоритмы:** O(1) доп. памяти

### **C. Cache-Oblivious алгоритмы**
*   **Принцип:** алгоритм оптимален для всех размеров кэша
*   **Пример:** cache-oblivious сортировка (merge sort с блоками)
*   **Влияние:** ускорение в 2-10x на практике

## **G. NP-ТЕОРИЯ И КЛАССЫ СЛОЖНОСТИ**
> `g/g.md` · `g/g.cpp` · `struct NPTheory : SpaceComplexity`

### **A. Основные классы**
*   **P:** задачи, решаемые за полиномиальное время
*   **NP:** задачи, проверяемые за полиномиальное время
*   **co-NP:** дополнения задач из NP
*   **NP-полные:** hardest задачи в NP (Кук-Левин)
*   **NP-трудные:** сведение от NP-полных

### **B. Типичные NP-полные задачи**
*   **SAT:** 3-SAT — классическая NP-полная задача
*   **TSP:** коммивояжёрская задача (decision version)
*   **Vertex Cover:** вершинное покрытие
*   **Clique:** клика в графе
*   **Hamiltonian Path/Cycle:** гамильтонов путь/цикл
*   **Graph Coloring:** раскраска графа

### **C. Методы работы с NP-трудными задачами**
*   **Эвристики:** жадные, локальный поиск, имитация отжига
*   **Алгоритмы приближения:** гарантированное качество (2-approx, 3/2-approx)
*   **Малые параметры:** FPT (Fixed-Parameter Tractable)
*   **Экспоненциальные алгоритмы:** meet-in-the-middle, branch and bound

## **H. ПРОДВИНУТЫЕ ТЕМЫ**
> `h/h.md` · `h/h.cpp` · `struct AdvancedTopics : NPTheory`

### **A. Амортизированный анализ**
*   **Метод агрегирования:** T(n) = ΣT(i)/n
*   **Бухгалтерский метод:** присвоение «стоимости» операциям
*   **Метод потенциала:** ΔTᵢ + ΔΦᵢ — изменение реальной + потенциальной стоимости
*   **Примеры:** stack push/pop O(1), dynamic array resize O(1), Union-Find O(α(n))

### **B. Вероятностный анализ**
*   **Рандомизированные алгоритмы:** Las Vegas, Monte Carlo, Sherwood
*   **Среднее время:** E[T(n)] для рандомизированных структур
*   **Вероятностные ح력ные:** Skip List, Randomized Treap, QuickSort

### **C. Анализ онлайн-алгоритмов**
*   **Коэффициент конкурентоспособности:** C = T(алгоритм)/T(оптимальный)
*   **Competitive analysis:** lower bound для онлайн-задач
*   **Примеры:** кэширование (FIFO/LRU vs оптимум),Pagewise
