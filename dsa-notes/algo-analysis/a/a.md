# **A. ОСНОВНЫЕ ПОНЯТИЯ**

## **1. Алгоритм**

### **1.1. Формальное определение**
* **Алгоритм:** конечная последовательность точно определённых инструкций для решения задачи
* **Свойства:**
    * **Детерминированность:** одинаковый вход → одинаковый выход (детерминированные алгоритмы)
    * **Корректность:** для каждого допустимого входа выдаёт правильный результат
    * **Завершаемость:** завершается за конечное число шагов для любого входа
    * **Определённость:** каждая инструкция чётко определена

### **1.2. Классификация алгоритмов**
* **По назначению:** поиск, сортировка, оптимизация, вычисление, проверка
* **По методу:** жадные, динамическое программирование, разделяй и властвуй, backtracking
* **По детерминированности:** детерминированные, рандомизированные, вероятностные

## **2. Вычислительная задача**

### **2.1. Типы задач**
* **Decision (решаемая):** ответ «да/нет» (существует ли путь, является ли граф двудольным)
* **Search (поиск):** найти объект (найти путь, найти клику)
* **Optimization (оптимизация):** найти оптимальное решение (минимальный путь, максимальное паросочетание)
* **Function (вычисление функции):** вычислить значение (определитель матрицы, хеш строки)

### **2.2. Размер входа**
* **Параметр n:** обычно число элементов (длина строки, число вершин, размер массива)
* **Параметр (n, m):** когда два параметра ( граф: `n` вершин, `m` рёбер)
* **Битовый размер:** `|вход| = Σ log(aᵢ)` — сколько бит нужно для записи входа

# **B. МОДЕЛИ ВЫЧИСЛЕНИЙ**

## **1. Машина Тьюринга**

### **1.1. Определение**
* Абстрактная модель вычислений: бесконечная лента + головка + набор состояний
* Один шаг: чтение символа → запись нового символа → сдвиг головки → переход в новое состояние
* **Классы сложности определяются через MT:** P, NP, PSPACE и т.д.

### **1.2. Значение**
* Фундамент теории сложности (Тезис Чёрча-Тьюринга: всё вычислимое → вычислимо на MT)
* Для анализа алгоритмов: MT даёт формальную базу, но для практических оценок используют RAM

## **2. RAM-модель**

### **2.1. Определение**
* Random Access Machine: бесконечный массив ячеек + регистры + арифметические операции
* **Допущения:** доступ к ячейке за O(1), арифметика ( сложение, умножение) за O(1)
* **Реалистичность:** близко к поведению реальных компьютеров

### **2.2. Использование**
* Анализ большинства алгоритмов в алгоритмах и структурах данных
* Сложность = число «базовых операций» (сравнения, обмены, обращения к массиву)

## **3. Word-RAM модель**

### **3.1. Определение**
* RAM + слово фиксированного размера `w = Θ(log n)` бит
* Один шаг: операция над двумя словами (AND, OR, XOR, +, −, ×, ÷) за O(1)
* **Ограничение:** каждое слово содержит O(log n) бит

### **3.2. Влияние на сложность**
* Битовые операции: POPCOUNT, CTZ (count trailing zeros), CLZ (count leading zeros) за O(1)
* Битовые маски: перебор подмножеств `n` элементов за O(2ⁿ · n)
* Индексация: массив из `2ʷ` элементов → доступ за O(1)

# **C. МЕТРИКИ ЭФФЕКТИВНОСТИ**

## **1. Время выполнения**

### **1.1. Подходы к измерению**
* **Число операций:** подсчёт базовых операций (сравнения, обмены, арифметика)
* **Реальное время:** `clock()` или `chrono::high_resolution_clock` в C++
* **Число обращений к памяти:** для анализа cache-performance

### **1.2. Связь с асимптотикой**
* T(n) = число операций → O(T(n)) = асимптотическая оценка
* **Пример:** Bubble Sort: T(n) = n(n−1)/2 → O(n²)

## **2. Пространственная сложность**

### **2.1. Определение**
* S(n) = объём дополнительной памяти (не считая входа)
* **Дополнительная:** память поверх входных данных
* **Общая:** вход + доп. память

### **2.2. Примеры**
* Merge Sort: O(n) доп. памяти (для временного массива)
* Quick Sort: O(log n) доп. (стек рекурсии)
* In-place: O(1) доп. памяти

## **3. Другие ресурсы**

### **3.1. Число сравнений**
* Сортировки: нижняя граница Ω(n log n) для сортировок сравнениями
* Поиск: O(log n) для бинарного поиска

### **3.2. Число обменов**
* Selection Sort: O(n) обменов (минимум)
* Bubble Sort: O(n²) обменов (максимум)

### **3.3. Число вызовов рекурсии**
* Merge Sort: O(n) вызовов (по одному на каждый элемент)
* Fibonacci: O(2ⁿ) вызовов без мемоизации, O(n) с мемоизацией
