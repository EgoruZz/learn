# **A. АМОРТИЗИРОВАННЫЙ АНАЛИЗ**

## **1. Метод агрегирования**

### **1.1. Идея**
* Суммируем стоимость **всех** операций и делим на n
* `T_amortized = T_total / n`

### **1.2. Пример: Dynamic Array (vector)**
* Вставка в конец: амортизированно O(1)
* При переполнении: resize × 2 → копирование O(n)
* **Суммарная стоимость n вставок:** O(n) (каждый элемент копируется最多 O(log n) раз)
* **Амортизированная стоимость:** O(n)/n = O(1)

## **2. Бухгалтерский метод**

### **2.1. Идея**
* Присваиваем каждой операции «стоимость» (реальную + «на чёрный день»)
* При дешёвой операции: переплачиваем → копим «кредит»
* При дорогой: используем «кредит»

### **2.2. Пример: Stack push/pop**
* push: реальная стоимость 1, «заплачено» 2 → кредит 1
* pop: реальная стоимость 1, «заплачено» 0 → используем кредит
* **Амортизированная стоимость:** O(1) на операцию

## **3. Метод потенциала**

### **3.1. Идея**
* Функция потенциала `Φ: состояние → число`
* **Амортизированная стоимость:** `âᵢ = tᵢ + Φ(Dᵢ) − Φ(Dᵢ₋₁)`
* `Σâᵢ = Σtᵢ + Φ(Dₙ) − Φ(D₀)`

### **3.2. Пример: Dynamic Array**
* `Φ = 2·n − capacity` (n — число элементов)
* Вставка: `â = 1 + Φ(new) − Φ(old) = 1 + 2(n+1) − 2(n+1) = 1` (без resize)
* Resize: `â = n + 1 + 2(2n) − 2n = n + 1 + 2n = O(1)` амортизированно

## **4. Union-Find**

### **4.1. Свойства**
* `find`: амортизированно O(α(n)) — обратная функция Акермана
* `union`: амортизированно O(α(n))
* **Анализ через потенциал:** потенциал = ранг дерева

# **B. ВЕРОЯТНОСТНЫЙ АНАЛИЗ**

## **1. Рандомизированные алгоритмы**

### **1.1. Las Vegas**
* Всегда даёт **правильный** ответ
* Время работы **случайное** (но E[T] конечна)
* **Пример:** Randomized QuickSort — O(n log n) expected

### **1.2. Monte Carlo**
* Фиксированное время работы
* Ответ **правильный с вероятностью ≥ 1 − ε**
* **Пример:** Miller-Rabin primality test

### **1.3. Sherwood**
* Правильный ответ с вероятностью ≥ 1/2
* Устраняет зависимость от входа

## **2. Expected Time**

### **2.1. Формулировка**
* `E[T(n)]` — математическое ожидание времени работы
* Randomized QuickSort: `E[T(n)] = 2n ln n + O(n)` = O(n log n)

## **3. Skip List**

### **3.1. Анализ**
* Высота: O(log n) с вероятностью 1 − 1/n^c
* Поиск: O(log n) expected
* Вставка/удаление: O(log n) expected

# **C. АНАЛИЗ ОНЛАЙН-АЛГОРИТМОВ**

## **1. Конкурентный анализ**

### **1.1. Коэффициент конкурентоспособности**
* `C = T(алгоритм) / T(оптимальный offline)` для каждого входа
* **Competitive ratio:** `C* = sup_{входы} C`

### **1.2. Пример: Paging**
* **FIFO:** competitive ratio = k (размер кэша)
* **LRU:** competitive ratio = k
* **OPT (clairvoyant):** оптимальный offline (недостижим)

## **2. Детерминированные онлайн-алгоритмы**

### **2.1. Lower bound**
* Для paging: любой алгоритм имеет competitive ratio ≥ k
* **Доказательство:** adversary argument

## **3. Рандомизированные онлайн-алгоритмы**

### **3.1. Randomized Marking**
* Для paging: competitive ratio O(log k)
* Улучшение за счёт случайности
