# **A. АСИМПТОТИЧЕСКИЕ ОБОЗНАЧЕНИЯ**

## **1. O-нотация (верхняя граница)**

### **1.1. Формальное определение**
* `f(n) = O(g(n))` ⟺ ∃ константы `c > 0`, `n₀ > 0`: `f(n) ≤ c · g(n)` для всех `n ≥ n₀`
* **Интуиция:** `f` растёт **не быстрее** `g` (с точностью до константы)
* **Пример:** `2n² + 3n + 1 = O(n²)` (при `c = 3`, `n₀ = 4`)

## **2. Ω-нотация (нижняя граница)**

### **2.1. Формальное определение**
* `f(n) = Ω(g(n))` ⟺ ∃ константы `c > 0`, `n₀ > 0`: `f(n) ≥ c · g(n)` для всех `n ≥ n₀`
* **Интуиция:** `f` растёт **не медленнее** `g`
* **Пример:** `2n² + 3n + 1 = Ω(n²)` (при `c = 2`, `n₀ = 1`)

## **3. Θ-нотация (точная оценка)**

### **3.1. Формальное определение**
* `f(n) = Θ(g(n))` ⟺ `f(n) = O(g(n))` и `f(n) = Ω(g(n))`
* Эквивалентно: ∃ `c₁, c₂, n₀`: `c₁·g(n) ≤ f(n) ≤ c₂·g(n)` при `n ≥ n₀`
* **Интуиция:** `f` растёт **с той же скоростью** что `g` (с точностью до константы)

## **4. o-нотация (строгое верхнее)**

### **4.1. Формальное определение**
* `f(n) = o(g(n))` ⟺ `∀c > 0` ∃ `n₀`: `f(n) < c · g(n)` при `n ≥ n₀`
* Эквивалентно: `lim_{n→∞} f(n)/g(n) = 0`
* **Интуиция:** `f` растёт **строго медленнее** `g`
* **Пример:** `n = o(n²)`, `log n = o(n)`

## **5. ω-нотация (строгое нижнее)**

### **5.1. Формальное определение**
* `f(n) = ω(g(n))` ⟺ `∀c > 0` ∃ `n₀`: `f(n) > c · g(n)` при `n ≥ n₀`
* Эквивалентно: `lim_{n→∞} f(n)/g(n) = ∞`
* **Интуиция:** `f` растёт **строго быстрее** `g`

# **B. СВОЙСТВА АСИМПТОТИЧЕСКИХ ОБОЗНАЧЕНИЙ**

## **1. Рефлексивность**
* `f = O(f)`, `f = Ω(f)`, `f = Θ(f)` — всегда верно

## **2. Транзитивность**
* `f = O(g)` и `g = O(h)` ⟹ `f = O(h)`
* Аналогично для Ω, Θ, o, ω

## **3. Симметричность**
* `f = Θ(g)` ⟺ `g = Θ(f)` (но O и Ω не симметричны!)

## **4. Арифметика**
* `O(f) + O(g) = O(max(f, g))`
* `O(f) · O(g) = O(f · g)`
* `O(f^k) = O(f)^k` (степень константы)
* Полиномиальная сложность: `O(aₖnᵏ + ... + a₁n + a₀) = O(nᵏ)`

## **5. Сравнение**
* Если `f = o(g)`, то `f = O(g)` (но не наоборот)
* `f = Θ(g)` ⟺ `f = O(g)` и `f = Ω(g)` (одновременно)

# **C. ТИПОВЫЕ КЛАССЫ СЛОЖНОСТИ**

## **1. Константное время O(1)**
* Доступ к элементу массива по индексу
* Арифметическая операция

## **2. Логарифмическое O(log n)**
* Бинарный поиск
* Быстрое возведение в степень
* Операции с деревьями высоты O(log n)

## **3. Корневое O(√n)**
* Перебор делителей числа n
* Декомпозиция на блоки √n

## **4. Линейное O(n)**
* Обход массива/графа
* Один проход данных

## **5. Линейно-логарифмическое O(n log n)**
* Сортировки: Merge Sort, Heap Sort, Quick Sort (средний)
* Строительство суффиксного массива

## **6. Квадратичное O(n²)**
* Вложенные циклы по n
* Базовые сортировки: Bubble, Selection, Insertion
* Умножение матриц (наивное)

## **7. Кубическое O(n³)**
* Floyd-Warshall
* Умножение трёх матриц

## **8. Экспоненциальное O(2ⁿ)**
* Перебор всех подмножеств
* Наивный backtracking (N-Queens без оптимизаций)

## **9. Факториальное O(n!)**
* Перебор всех перестановок
* Наивное решение Traveling Salesman

# **D. БИТОВАЯ СЛОЖНОСТЬ (ДЛЯ ОЛИМПИАД)**

## **1. Word-RAM модель**

### **1.1. Определение**
* Слово = `w = Θ(log n)` бит; операция над словом = O(1)
* Массив `a[0..2ʷ−1]` доступен за O(1)

### **1.2. Битовые операции за O(1)**
* AND, OR, XOR, NOT
* POPCOUNT (число единиц)
* CTZ (count trailing zeros)
* CLZ (count leading zeros)
* shifts

## **2. Битовые маски**

### **2.1. Представление подмножества**
* Подмножество `n` элементов → битовая маска длины `n`
* i-й элемент в подмножестве ⟺ i-й бит равен 1

### **2.2. Перебор всех подмножеств**
```cpp
for (int mask = 0; mask < (1 << n); mask++) {
    // mask — подмножество
}
```
* Сложность: O(2ⁿ) — перебор всех подмножеств
* Суммарный размер: Σ|подмножество| = n · 2ⁿ⁻¹

### **2.3. Перебор пар подмножеств**
```cpp
for (int A = 0; A < (1 << n); A++) {
    for (int B = A; B < (1 << n); B++) {
        // (A, B) — пара подмножеств
    }
}
```
* Сложность: O(3ⁿ) — для каждой вершины 3 варианта (только A, только B, оба, ни A ни B)
