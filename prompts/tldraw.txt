tldraw
- open-source infinite canvas SDK на React (npm-пакет `tldraw`).
- GitHub: tldraw/tldraw (~49.8K★), ~74K подписчиков X, ~314K npm-загрузок/неделю.
- Актуальный npm: tldraw@5.3.1 (проверка: registry.npmjs.org/tldraw/latest).
- В проде: Google, Shopify, ClickUp, Autodesk, Runway, Replit, BlackRock, Luma,
  SchoolAI, Padlet, CADChat, Honeycomb и др.
- Продукты/вехи: tldraw Sync (мультиплеер), Make Real, fairies, Agent Draw,
  tldraw MCP App, tldraw offline (июл 2026), SDK 4.x–5.x.
- Финансы (исторически): seed $2.7M (2022), +$2M (2023), $10M (апр 2025).

tldraw offline
- Десктоп-приложение (Electron) для локальных файлов.
  Анонс: 16 июля 2026 (Steve Ruiz). Слоган: «A local whiteboard for you and your agents».
- Без аккаунтов и cloud-хранилища; работает без интернета. Всё локально и приватно.
- Файл: формат `.tldraw` — canvas + страницы + медиа + document script в одном архиве.
  Legacy `.tldr` открывается как новый unsaved document (оригинал не трогается);
  экспорт в `.tldr` — File → Export (скрипты при экспорте снимаются — для tldraw.com /
  VS Code / Obsidian).
- GitHub: tldraw/tldraw-offline (~543★). НЕ open source: «All rights reserved».
- Скачать: offline.tldraw.com; релизы: github.com/tldraw/tldraw-offline/releases/latest.
- Платформы:
  macOS — Universal DMG (+ arm64 DMG/ZIP);
  Windows — x64 / Arm64 installer;
  Linux — AppImage x64/Arm64, .deb x64.
- Автообновления: File → Preferences → Check for Updates Automatically;
  ручная проверка: macOS «tldraw offline → Check for Updates…», Win/Linux «Help → …».
- Версия: About (macOS: tldraw offline → About; Win/Linux: Help → About).
- Приложение НЕ мержит внешние правки открытого файла (Git, другой процесс, sync).
  Перед заменой файла извне — закрой документ, потом открой снова.
- Working copies: после краша восстанавливает open docs; это safety net, не замена Save.

4. LOCAL CANVAS API (как агент управляет холстом)
⸻

При запуске app пишет server.json в конфиг-каталог:
  macOS   ~/Library/Application Support/tldraw/server.json
  Linux   ~/.config/tldraw/server.json
  Windows %APPDATA%\tldraw\server.json

Содержит: port (часто 7236), token (bearer), pid, startedAt.
Чистый выход удаляет server.json. Файл есть, порт молчит → stale (crash/unclean quit).

Авторизация:
- GET / и GET /readme — без токена.
- Все остальные запросы: Authorization: Bearer <token>.

ПРАВИЛО: port и token перечитывать из server.json ПРИ КАЖДОМ shell-вызове.
Не хардкодить 7236, не кэшировать token между вызовами (каждый Bash = fresh shell).

```bash
PORT=$(jq -r .port "$HOME/Library/Application Support/tldraw/server.json")
TOKEN=$(jq -r .token "$HOME/Library/Application Support/tldraw/server.json")
# http://localhost:$PORT/...  -H "Authorization: Bearer $TOKEN"
```

Основные эндпоинты:
- POST /api/docs/create  body: {"name":"…"[, "directory": абс-путь]}
  → новый .tldraw, открывается в окне, сразу Save на диск.
  409 если имя уже существует. `.tldr` имена — 400.
- POST /api/search  body: raw JS или {"code":"..."}
  scope: объект `api` (не `spec`).
  Типичное: api.getFocusedDoc(), api.getDocs(), api.getDocs({ name }),
  api.getShapes(docId), api.getBindings(docId),
  api.getScreenshot(docId, opts?), api.recipes, api.imports, api.members.
- POST /api/doc/:id/exec  — разовый JS с live `editor` (+ helpers).
  body: text/plain JS или {"code":"..."}; top-level await ок.
- POST /api/doc/:id/script-workspace → { mainJsPath, isDefaultScript, ... }
  пути к script/** для durable behavior.
- GET  /api/doc/:id/script-status
  state: "applied" | "pending" | "error" | "not-watching"
  при error — lastApplyError / errorLogPath (.script-workspace/error.log).
- Shared boards (v1.13+): listings включают ownership: 'remote' для joined boards;
  reads / screenshots /exec идут на них; правки синкаются к host.
  Также видно, shared ли локальная доска и от какого host пришёл join.

Скриншоты: api.getScreenshot → { filePath, width, height, ... } (JPEG path, не bytes).
  opts.size: 'small'|'medium'|'large'|'full' (default small)
  opts.mode: 'canvas' (shapes) | 'window' (весь UI chrome)
  opts.bounds: {x,y,w,h} page coords (только canvas mode).
  Открой filePath глазами (Read tool).

Запрещено редактировать напрямую, пока документ открыт:
  .tldraw archive, db.sqlite*, metadata.json, .lock, .script-workspace/**

Persistence (v1.13.x, из /readme):
- Правки через /exec живут в working copy; завершать mutating-сниппет
  `await helpers.saveDoc()` (только для local docs) — пишет в .tldraw архив.
- Remote (joined) board: saveDoc НЕ звать; синк к host, host сам Save'ит.
- helpers.saveDoc() — только из /exec; НИКОГДА из document script.
- Shared board: скрипт исполняется у ВСЕХ участников; guard записи
  `if (!app?.board.isHost) return` после локальных подписок.
- runtime-слушатели из /exec исчезают при закрытии — durable = script/main.js.

5. ДВА ПОДХОДА К РАБОТЕ
⸻

A. One-off edits (/exec) — генерация, раскладка, чистка. Не «скрипт файла».
   Пример:
   const { createShapeId, toRichText } = await import("tldraw");
   editor.createShape({
     id: createShapeId("box1"), type: "geo", x: 0, y: 0,
     props: { geo: "rectangle", w: 200, h: 100, color: "blue", fill: "solid",
              richText: toRichText("hello") }
   });
   return editor.getCurrentPageShapes().length;

B. Durable behavior (document script) — переживает reload, грузится при открытии.
   Живёт в script/main.js (путь из /script-workspace); app watcher применяет changes.
   Контракт (см. .script-workspace/script-context.d.ts):
     import { createShapeId, toRichText } from 'tldraw'  // примитивы: import
     export default function ({ editor, helpers, signal }) {
       editor.run(() => {
         helpers.createShapeIfMissing({
           id: createShapeId('node-1'), type: 'geo', x: 0, y: 0,
           props: { geo: 'rectangle', w: 200, h: 100, richText: toRichText('hi') },
         })
       })
       const stop = editor.store.listen(() => { /* ... */ })
       signal.addEventListener('abort', () => stop())  // ОБЯЗАТЕЛЬНАЯ очистка
     }
   - Импорты только из 'tldraw' / 'react' / 'react-dom'. Это не Node-проект.
   - Идемпотентность: createShapeIfMissing + стабильные createShapeId('name').
   - isDefaultScript === true → starter template; false → НЕ затирай чужой script.
   - Script writes вне undo: editor.run(fn, { history: 'ignore' }).
   - helpers.onShapeTranslate / helpers.translateShapes — для «мебели» с якорем.
   - editor.on('tick') — RAF; setInterval в фоне ~1/с.
   - Consent UI: «Run Script» / «Open Without Script».
     Trust привязан к digest содержимого; смена script → новый prompt.
     metadata.json script-manifest + ~/.tldraw/script-trust.json / $TLDRAW_SCRIPT_TRUST
     (детали — /readme и manual; mismatch digest = reject).
   - Develop → Reveal Script… / Reload Script; ошибка → .script-workspace/error.log.
   - Правка script помечает document unsaved → File → Save вшивает в .tldraw.

C. config.js (рядом с main.js) — custom shapes / tools / overlays / components.
   default export runs BEFORE editor mount: ({ config }) => mutated TldrawConfig.
   Saving config.js remounts editor (history reset; doc/camera/selection keep).
   main.js-only НЕ регистрирует ShapeUtil. Recipes: custom-shape-config-js,
   custom-overlay-config-js через api.recipes.

Связи на диаграммах:
- Meaningful arrows: helpers.createArrowBetweenShapes(fromId, toId, options)
  (реальные bindings). Не raw unbound arrow для смысловых связей.
- Перед «готово»: helpers.getLints() и починить actionable.

Recipes (api.recipes['id'] через /api/search):

6. ПРИНЦИПЫ РАБОТЫ АГЕНТА (критично)
⸻

- НЕ «рисуй» фигуры мышью. Пиши код, который их генерирует (/exec или script).
- НЕ computer-use клики; НЕ правь .tldraw руками. Только Local HTTP API.
- Держи tldraw offline открытым + нужный документ в фокусе/известен по имени.
- Верификация: api.getShapes / getBindings; при сомнении — getScreenshot + Read image.
  UI: симулируй pointer через /exec (editor.dispatch), не реальной мышью.
- script-status: не рапортуй успех при "pending"; при "error" читай error.log.
- Linux watcher = inotify; нехватка max_user_instances → "not-watching".
- Безопасность: scripts = executable. Только доверенные файлы и агенты.
- Несколько окон: явно выбирай doc (getFocusedDoc / getDocs({name})).
- После agent-правок: пользователь Save’ит сам; агент может напомнить Save.
- Share (v1.13+): LAN unencrypted; link = secret; scripts едут с host-файлом.

10. ТРЕНДЫ И НАПРАВЛЕНИЕ
⸻

- Главный вектор: canvas + local AI agents. Offline снимает guardrails online
  (сырой JS на порту — фича, не дыра).
- Файл = приложение: каждый .tldraw несёт script (+ optional config.js).
- v1.13.0 (12 авг 2026): Share over network (LAN, no account/cloud);
  guests Editor|Viewer; presence; scripts с host; permissions camera/mic/clipboard
  per-document; Canvas API видит shared/remote boards.
  v1.13.1 / v1.13.2 — patch releases (14 авг 2026 latest = v1.13.2).
- Backward compat: files from newer app open in older builds (заявлено в 1.13 notes);
  scripts may warn on major SDK mismatch.
- Следить: @tldraw, changelog Notion, GitHub releases.
