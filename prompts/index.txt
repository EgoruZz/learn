prompts — оглавление папки (index)
=================================

Этот файл — точка входа. Он описывает назначение каждого промта в папке prompts
и правила их совместного использования.

⸻

1. СОСТАВ И НАЗНАЧЕНИЕ
⸻

warm_up.txt — составление списка тем
- Промт для наставника: формирует и ведёт список тем для изучения.
- Темы заключают в себе универсальность: список тем — это карта всей будущей базы знаний.
- Читать первым при планировании: что учим и в каком порядке.

websites.txt — источники с алгоритмами
- Список полезных ресурсов по алгоритмам и структурам данных.
- Включает как материалы, которые уже есть в learn/dsa-notes, так и те, которых ещё нет.
- Необязательно ограничиваться только этими ссылками — агент может искать источники свободно, по своему усмотрению.
- Читать при поиске дополнительных объяснений, задач и примеров.

workflow.txt — контроль версий написанного материала
- Правила git-процесса: ветки, коммиты, rebase, Pull Request, merge.
- Читать при фиксации результата: конспект → коммит → PR.

⸻

2. КОНВЕЙЕР И ПОРЯДОК РАБОТЫ
⸻

1. warm_up.txt — определить/проверить список тем.
2. websites.txt — при необходимости найти дополнительные источники по теме.
3. workflow.txt — зафиксировать результат в git (ветка → коммит → PR).

⸻

3. ПРАВИЛА САМОГО index.txt
⸻

- Если добавляется новый промт в папку prompts — сначала описать его здесь,
  потом создавать файл.
- Если меняется назначение промта — обновлять описание здесь.
- Этот файл читается первым, поэтому описания должны оставаться краткими.
