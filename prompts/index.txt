prompts — оглавление папки (index)
=================================

Этот файл — точка входа. Он описывает назначение каждого промта в папке prompts
и правила их совместного использования. Все файлы образуют единый конвейер:
ТЕМЫ → КОНСПЕКТ → ДОСКА → GIT.

⸻

1. СОСТАВ И НАЗНАЧЕНИЕ
⸻

warm_up.txt — составление списка тем
- Промт для наставника: формирует и ведёт список тем для изучения.
- Темы заключают в себе универсальность: список тем — это карта всей будущей базы знаний.
- Читать первым при планировании: что учим и в каком порядке.

whiteboard.txt — правила написания конспектов
- Промт AI Professor: как превращать тему из списка (warm_up) в полноценный урок.
- Задаёт методику: мотивация → интуиция → визуализация → примеры → определение →
  алгоритм/доказательство → сложность → применение → ошибки → связи.
- Читать при подготовке конспекта по конкретной теме.

tldraw.txt — инструмент создания конспекта
- Технический самобриф агента по tldraw / tldraw offline и локальному API (порт 7236).
- С помощью этого инструмента создаётся конспект по теме, набору тем или решению задачи:
  уроки из whiteboard.txt материализуются на холсте.
- ВАЖНО: всегда после прочтения tldraw.txt обновляй в нём информацию и фокусируй её
  на современности (разделы «Актуальные источники правды» и «Дата актуальности»).
  Технология быстро меняется: каждый раз сверяйся с changelog, релизами и user manual,
  правь самобриф, и только потом работай с холстом.
- Читать при каждой задаче, которая касается холста.

workflow.txt — контроль версий написанного материала
- Правила git-процесса: ветки, коммиты, rebase, Pull Request, merge.
- Читать при фиксации результата: конспект → доска → коммит → PR.

⸻

2. OPENCODE SKILLS (автозагрузка агентом)
⸻

Два skill'а подхватываются OpenCode (tool `skill`). Они не заменяют файлы выше —
оркестрируют их чтение и работу с API. Активация — словами в запросе
(«нарисуй конспект по X», «разбери задачу Y»); отдельных команд/кнопок нет.

cs-whiteboard
- Когда: конспект, урок, разбор задачи на доске, «AI Professor».
- Делает: pipeline warm_up → tldraw → whiteboard → canvas; методика + verify.
- Пути:
  ~/.config/opencode/skills/cs-whiteboard/SKILL.md
  .opencode/skills/cs-whiteboard/SKILL.md  (в этом репо)
  ~/.claude/skills/cs-whiteboard/SKILL.md

tldraw-offline
- Когда: любой inspect/edit/script живого tldraw offline холста.
- Делает: Local Canvas API, tq helper, exec/scripts/recipes.
- Пути:
  ~/skills/tldraw-offline/          (канон: SKILL.md + tq)
  ~/.config/opencode/skills/tldraw-offline/
  .opencode/skills/tldraw-offline/
  ~/.claude/skills/tldraw-offline/

Агент при уроке: skill(cs-whiteboard) → skill(tldraw-offline) → читать prompts/* → рисовать.

⸻

3. КОНВЕЙЕР И ПОРЯДОК РАБОТЫ
⸻

1. warm_up.txt — определить/проверить список тем.
2. tldraw.txt — прочитать про инструмент, при необходимости обновить его актуальность.
3. whiteboard.txt — построить урок по выбранной теме по правилам этого промта
   (содержание конспекта).
4. workflow.txt — зафиксировать результат в git (ветка → коммит → PR).

Любая задача может начинаться с любого этапа, но при касании холста
порядок «прочитать tldraw.txt → обновить → работать» не нарушается.
Для OpenCode предпочтительно стартовать через skill `cs-whiteboard`.

⸻
