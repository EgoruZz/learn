# **A. Что составляет действие "деление"?**

## **1. Фундаментальные определения**

### **1.1. Делимость - произошло деление без остатка**
* **Идея:** Есть сложение и вычитание (вычитание тоже сложение) - надо придумать деление
* **Интуиция:** Число a можно представить как сумму c слагаемых равных b:
a = b + b + ... + b
    \_____________/
         c раз
* **Определение "a делит b":** `b | a` ⇔ ∃c ∈ ℤ: `a = b·c`
* **Теорема:** Для любых целых в паре (a, b), b ≠ 0 ∃ !c:

### **1.2. Неделимость - произошло деление с остатком**
* **Теорема:** Для любых целых в паре (a, b), b ≠ 0 ∃ !(c, r):
  Представляем одну букву с помощью трех:
  `a = b·c + r`, где `0 ≤ r < |b|`
* **Терминология:**
  - `a` — делимое (число, которое делим)
  - `b` — делитель (на что делим)
  - `c` — неполное частное (`c = ⌊a/b⌋` = `a div b`)
  - `r` — остаток (`r = a mod b = a % b`)
  - a = b * ⌊a/b⌋ + a % b (дана буква а, выходит b - любая)
* **Интуиция:**
a = b + b + ... + b + 0,1,2,...,b-1
    \_____________/
         c раз

### **1.3. Свойства остатков**
* **Остаток всегда меньше делителя:** `0 ≤ r < |n|`
* **Если остаток 0:** `n | m` (делится нацело)
* **Отрицательные числа:** Остаток всегда неотрицательный!  
  `-7 ÷ 3 = -3` с остатком `2`, потому что `-7 = 3×(-3) + 2`
* Лжеостаток 17 / 3
* **Остатка всегда 2 шт - так как можно недобрать, а можно перебрать**:
  * **Пример, представим -17 с помощью 5:** -17 = -4 * 5 +3 = -3 * 5 -2, но правильно выбирать случай по определению, то есть -17 div 5

### **1.3. Ключевые свойства**
- a | b и b | c ⇒ a | c
- a | b и a | c ⇒ a | (bx + cy) ∀x,y
- *Следствие:* a | (b + c), a | (b - c), a | kb, a | kc, a | k(b +- c)
- a | b и b | a ⇒ a = ±b

# **B. РАЗЛОЖЕНИЕ НА МНОЖИТЕЛИ**

## **1. Основная теорема арифметики**
* n = p₁^α₁ p₂^α₂ ⋯ pₖ^αₖ, где pᵢ — простые, αᵢ ≥ 1
* 2^k <= p1 * p2 * ... * pk <= n;
* **Метод факторизации:** проверка делителей до √n 
* **Предподсчет простых через решето**
  * **Идея:** Если p простое, то все кратные p (от p² до N) — составные
  * **Сложность:** O(N log log N), память O(N)
  * **Ключ:** начинаем с i², потому что все меньшие кратные уже помечены

## **2. Предподсчёт делителей:**
* **Основа всех вычислений:** без факторизации нет эффективных алгоритмов 
* **Хранение всех делителей до N:** O(N log N) памяти, O(1) доступ 
* **Хранение только простых делителей:** O(N) памяти, O(количество делителей) доступ модификация для 
* **Минимальные простые делители:** ключ к линейному решету
  * **SPF[i]** — smallest prime factor, минимальный простой делитель i
  * **Сложность:** O(N) — каждое число помечается ровно один раз
  * **Условие p ≤ spf[i]:** гарантирует, что i·p помечается минимальным делителем p
* **Быстрая факторизация:** через LPF (минимальный простой делитель)
  * **Для любого x ≤ N:** за O(log x) — делим на spf[x] пока x > 1
  * **Пример:** x=60, spf={2,2,3,5} → 60 = 2²·3·5

# **C. ФУНКЦИИ ДЕЛИТЕЛЕЙ**

## **1. Что такое делитель**
* Делитель это p₁^b₁ p₂^b₂ ⋯ pₖ^bₖ где pᵢ — простые, 0 <= bᵢ <= αᵢ
* при deg(pᵢ) ≥ 0 набор простых p1,p2,...,pk становится бесконечный
* **Все делители через разложение** # факторизация 
* **Быстрый перебор пар (d, n/d)** # алгоритм до √n 

## **2. Количество делителей**
* d(n) = ∏ᵢ (αᵢ + 1) где n = ∏ pᵢ^αᵢ # комба 
* **Свойства:** мультипликативная функция
* **Алгоритмы:** через разложение на множители

## **3. Сумма делителей**
* σ(n) = ∏ᵢ (pᵢ^{αᵢ+1} - 1)/(pᵢ - 1) = Пi (pi^ai + pi*(ai-1) + ... + 1) # комба 
* **Классификация:**
  - Совершенные: s(n) = n <==> σ(n) = 2n
  - Избыточные: s(n) > n <==> σ(n) > 2n
  - Недостаточные: s(n) < n <==> σ(n) < 2n

## **4. Aliquot Sum = Сумма собственных делителей (теория)**
* **Аликвота числа** это делитель числа, не равный самому числу
* **Определение:** s(n) = σ(n) - n # поэтому само число не учитываем в сумму аликвот
* **Совершенные числа, k = 1:** s(a₁) = a₂
* **Дружественные числа, k = 2:** s(a₁) = a₂ и s(a₂) = a₁
* **Социабельные числа, k >= 3:** s(a₁) = a₂ и s(a₂) = a₃ и ... и s(aₖ) = a₁
* **Алгоритмы:** поиск через предподсчет
  * **Предподсчёт s[1..N]:** O(N log N) — для каждого i добавляем i ко всем кратным 2i, 3i, ...
  * **Совершенные:** s(n) == n (6, 28, 496, 8128)
  * **Дружественные:** s(a) == b && s(b) == a (220, 284)
  * **Социабельные:** s(a₁)=a₂, s(a₂)=a₃, ..., s(aₖ)=a₁

# **D. НАИМЕНЬШЕЕ ОБЩЕЕ КРАТНОЕ (НОК)**

## **1. Определения**
* lcm(a,b) = min{m > 0: a | m и b | m}
* lcm(a,b) = p1^max(a1,b1) * p2^max(a2,b2) * ... * pk^max(ak, bk)
* l = lcm(a,b) = lcm(x, y), пар (x, y) П(2ki+1) и (П(2ki+1)+1)/2 # факторизация

## **2. Свойства НОК**
* lcm(a,b) * gcd(a,b) = |ab| # факторизация
* lcm(a₁,...,aₙ) = lcm(a₁, lcm(a₂, ..., aₙ)) # факторизация
* ОК: a | c и b | c ⇒ lcm(a,b) | c  # факторизация
* lcm(ka, kb) = k ⋅ lcm(a,b)  # факторизация

# **E. НАИБОЛЬШИЙ ОБЩИЙ ДЕЛИТЕЛЬ (НОД)**

## **1. Определения**
* gcd(a,b) = max{d: d | a и d | b}
* gcd(a,b) = p1^min(a1,b1) * p2^min(a2,b2) * ... * pk^min(ak,bk)
* **Взаимно простые:** gcd(a,b) = 1
* g = gcd(a, b) = gcd(x, y) пар (x, y) бесконечно много # делим на gcd(a, b)

## **2. Свойства НОД**
* 0. gcd(a,b) = gcd(b, a)
* 1. gcd(a,b) = gcd(a, -b)
* 2. gcd(a,b) = gcd(-a, -b)
* 3. gcd(a,b) = gcd(a, b-a) # выделение ОД
* 4. gcd(a,b) = gcd(a, b-k*a), где k в No # выделение ОД
* 5. gcd(a,b) = gcd(a, b mod a) # определение остатка, жадный выбор k
* 6. gcd(a,b) = gcd(a, b + k*a) где k в Z # выделение ОД
* 7. ОД: c | a и c | b => c | gcd(a, b) # факторизация
* 8. gcd(a,b) ⋅ lcm(a,b) = |ab| # факторизация
* 9. gcd(a₁,...,aₙ) = gcd(a₁, gcd(a₂, ..., aₙ)) # факторизация
* 10. gcd(ab, ac) = a ⋅ gcd(b,c)  # факторизация
* 11. gcd(a/g, b/g) = 1, если g = gcd(a, b); # вынести множитель
* 12. gcd(a,b) = 1 = gcd(1, b) => gcd(ak,b) = gcd(k,b) # факторизация
* 13. gcd(a,b) = gcd((a-b)/n, b) если a == b (mod n) и gcd(n,b)==1 # 6 и 11
* 14. ∃x,y: ax + by = gcd(a,b) # через множество S

# **F. МУЛЬТИПЛИКАТИВНЫЕ ФУНКЦИИ**

## **1. Определение и основная идея**
* **Формальное определение:** f(mn) = f(m)f(n) при gcd(m,n) = 1, а также f(1) = 1
* **Простая аналогия:** Если m и n "независимы" (взаимно просты), то f(mn) = f(m) × f(n)
* **Ключевое следствие:** Чтобы вычислить f(n) для любого n, достаточно знать f(pᵏ) для степеней простых
n = p₁ᵃ¹ × p₂ᵃ² × ... × pₖᵃᵏ
f(n) = f(p₁ᵃ¹) × f(p₂ᵃ²) × ... × f(pₖᵃᵏ)
* Мультипликативные функции — это мощный инструмент для сведения задач на подсчёт к эффективным алгоритмам

### **1.1. Примеры мультипликативных функций:**
* **d(n) = σ₀(n)** — количество делителей
* **σ(n) = σ₁(n)** — сумма делителей
* **φ(n)** — функция Эйлера
* **μ(n)** — функция Мёбиуса
* **λ(n)** — функция Лиувилля
* **1(n)** = 1 для всех n (единичная функция)
* **id(n)** = n (тождественная функция)
* **idₖ(n)** = nᵏ
* **dₖ(n)** — функция делителей, остальные функции на делителях
* **σₖ(n)** — функция "сумма делителей в степенях"

#### **Кэширование результатов:**
* **Мемоизация для единичных вычислений:** если n имеет много запросов
* **Предподсчет часто используемых значений:** φ(n), d(n), σ(n) для часто встречающихся n

### **Почему это важно в спортивном программировании?**
* **Оптимизация вычислений:** Вместо O(n) можно за O(√n) через разложение на простые
* **Предподсчет для всех чисел до N:** Используя линейное решето, можно вычислить f(n) для всех n ≤ N за O(N)
* **Сведение сложных задач к независимым подсчетам по простым множителям**

## **2. Важные мультипликативные функции**

### **2.1. Функция Мёбиуса μ(n)**
#### **Определение (развернуто):**
* **μ(1) = 1** — базовый случай
* **μ(n) = 0** если в разложении n есть квадрат простого (p² | n для некоторого p)
* **μ(n) = (-1)ᵏ** если n = p₁·p₂·...·pₖ (различные простые множители)
* **μ(n) ≠ 0** только для бесквадратных чисел
* **Σ μ(d) = 1** если n=1, иначе 0 (сумма по делителям)

#### **Геометрический смысл μ(n):**
* **0** — если число делится на квадрат простого
* **+1** — если число имеет чётное количество различных простых множителей
* **-1** — если число имеет нечётное количество различных простых множителей

#### **Способы вычисления μ(n):**
* **Для одного числа:** через разложение на простые 
* **Для всех чисел до N:** модификация линейного решета
  * mu[1]=1, для простых p: mu[p]=-1
  * Если spf[i*p]==p → mu[i*p]=0 (квадрат простого), иначе → mu[i*p]=-mu[i]
* **Использование предподсчитанных значений:** если N ≤ 10⁶-10⁷

#### **Работа с μ(n):**
* **Предподсчет μ(n) до 10⁷:** линейное решето за O(N)
* **Быстрое вычисление Σ μ(d):** через формулу Мертенса
  * M(N) = Σ_{n≤N} μ(n) = Σ_{d=1}^{N} μ(d)·⌊N/d⌋
  * Используется для быстрого подсчёта через деления на ⌊N/d⌋ за O(√N)
* **Использование свойств μ(n):** μ(ab)=μ(a)μ(b) при gcd(a,b)=1
* **Пар с gcd=1:** Σ μ(d)·cnt(d)²
* **Пар с gcd=k:** Σ μ(t)·cnt(k·t)²
* **Троек (a,b,c) с gcd(a,b,c)=1:** Σ μ(d)·⌊n/d⌋³
* **Наборок (a1, a2, ..., ak) с gcd((a1, a2, ..., ak))=k:**
  * Ответ: Σ_{t=1}^{⌊N/k⌋} μ(t)·⌊N/(k·t)⌋ᵏ
  * Логика: gcd(a₁,...,aₖ)=k ⟺ gcd(a₁/k,...,aₖ/k)=1

#### **Подсчёт по условиям делимости**
* **Числа, взаимно простые со всеми из множества**
  * **Формула:** |{a ≤ N : gcd(a, mᵢ)=1 ∀i}| = Σ_{d|M} μ(d) · ⌊N/d⌋
  * **Где:** M = lcm(m₁, ..., mₖ), μ — функция Мёбиуса
  * **Связь:** принцип включения-исключения через μ
* **Чисел, делящихся хотя бы на одно из множества:** принцип включения-исключения
  * |A₁ ∪ ... ∪ Aₖ| = Σ|Aᵢ| - Σ|Aᵢ∩Aⱼ| + ... где |Aᵢ| = ⌊N/mᵢ⌋
  * |Aᵢ ∩ Aⱼ| = ⌊N/lcm(mᵢ,mⱼ)⌋

### **Формула обращения Мёбиуса**
#### **Теорема (две эквивалентные формы):**
* **Прямая форма:** Если g(n) = Σ f(d) (сумма по всем делителям d числа n),  
  то f(n) = Σ μ(d)·g(n/d) (d | n)
* **Двойственная форма:** Если g(n) = Σ f(d) (сумма по всем числам d, кратным n),  
  то f(n) = Σ μ(d/n)·g(d) (n | d)

### **2.2. ФУНКЦИЯ ЭЙЛЕРА φ(n)**

#### **Определение и основные свойства**
* **Определение:** φ(n) = количество чисел от 1 до n, взаимно простых с n
* **φ(1) = 1** — по определению
* **Для простого p:** φ(p) = p - 1
* **Для степени простого:** φ(pᵏ) = pᵏ - p^{k-1} = p^{k-1}(p - 1) для k ≥ 1
* **Мультипликативность:** φ(mn) = φ(m)·φ(n) при gcd(m, n) = 1

#### **Формула вычисления**
* **Через разложение на простые:**
  φ(n) = n × ∏ (1 - 1/pᵢ) где произведение по всем различным простым делителям pᵢ числа n

#### **Важные тождества и формулы**
* **Сумма по делителям:** Σ φ(d) = n (сумма по всем делителям d числа n)
* **Связь с функцией Мёбиуса:** φ(n) = Σ μ(d)·(n/d) (сумма по всем делителям d числа n)
* **Для чётных n > 2:** φ(n) ≤ n/2
* **Неравенство:** φ(n) ≥ √(n/2) для n ≥ 2
* **Сумма gcd всех пар:** Σ φ(d)·⌊N/d⌋²
  * Вывод: Σ_{g=1}^{N} g·Σ μ(k)·⌊N/(g·k)⌋² → подстановка t=g·k → Σ φ(t)·⌊N/t⌋²
  * Сложность: O(N log N) через предподсчёт φ
* **Сумма gcd всех чисел с фиксированным**
  * **Формула:** Σ_{a=1}^{N} gcd(a, n) = Σ_{d|n} d · φ(n/d)
  * **Вывод:** gcd(a,n)=d ⟺ d|n, gcd(a/d, n/d)=1 → для каждого делителя d числа n считаем φ(n/d)
  * **Сложность:** O(√n) через факторизацию n
* **Сумма gcd всех наборов (a1, a2, ..., ak):**
  * Обобщение: Σ_{t=1}^{N} φ(t)·⌊N/t⌋ᵏ
  * Доказательство: gcd(a₁,...,aₖ)=g ⟺ gcd(a₁/g,...,aₖ/g)=1
* **Сумма lcm всех пар:** через предподсчет σ(n) и других функций
  * Σ lcm(i,j) = Σ (i·j)/gcd(i,j) = Σ_{g=1}^{N} g·Σ_{a,b≤⌊N/g⌋, gcd(a,b)=1} a·b
  * Σ_{gcd(a,b)=1} a·b = Σ_{d=1}^{M} μ(d)·d²·(Σ_{k≤M/d} k)²
  * Сложность: O(N log N) через предподсчёт μ, σ₁
* **Сумма lcm всех наборов (a1, a2, ..., ak):**
  * lcm(a₁,...,aₖ) = Π_{p} p^{max(eₚ(aᵢ))} — мультипликативно
  * Вклад p^e = p^e · (кол-во наборов, где max(eₚ) = e) — считаем по простым
* **Подсчёт gcd всех пар**
  * **Формула:** Σ_{a=1}^{N} Σ_{b=1}^{N} gcd(a,b) = Σ_{d=1}^{N} φ(d) · ⌊N/d⌋²
  * **Вывод:** gcd(a,b)=g ⟺ g|a, g|b, gcd(a/g, b/g)=1 → суммируем по g, внутри считаем взаимно простые
  * **Сложность:** O(N log N) через предподсчёт φ
* **Подсчёт gcd всех наборов (a₁, ..., aₖ)**
  * **Формула:** Σ_{a₁,...,aₖ=1}^{N} gcd(a₁,...,aₖ) = Σ_{d=1}^{N} φ(d) · ⌊N/d⌋ᵏ
  * **Обобщение:** gcd(a₁,...,aₖ)=g ⟺ gcd(a₁/g,...,aₖ/g)=1

#### **Частные случаи и свойства**
* **φ(p) = p-1** для простого p
* **φ(pᵏ) = pᵏ - p^{k-1}**
* **φ(2p) = p-1** если p — нечётное простое
* **φ(ab) = φ(a)·φ(b)·d/φ(d)** где d = gcd(a,b) (обобщение мультипликативности)
* **n/φ(n) = Σ 1/p** (приближённо) для больших n

### **2.3. Функция Лиувилля λ(n)**
#### **Определение:**
* **λ(n) = (-1)^Ω(n)** где Ω(n) — сумма степеней простых делителей (с учётом кратности)
* **Эквивалентно:** λ(p₁^α₁ · p₂^α₂ · ... · pₖ^αₖ) = (-1)^(α₁ + α₂ + ... + αₖ)
* **Отличие от μ:** λ работает с кратными делителями, μ только с различными

#### **Свойства:**
* **Полная мультипликативность:** λ(ab) = λ(a)λ(b) для любых a, b (без условия взаимной простоты)
* **λ(n) = 1** если n — полный квадрат (все степени чётные)
* **λ(n) = -1** если n — не полный квадрат, но свободно от квадратов (все степени равны 1)
* **λ(n) = 0** если n не свободно от квадратов (хотя бы одна степень ≥ 2)

#### **Связь с другими функциями:**
* **|λ(n)| = μ²(n)** — абсолютное значение равно индикатору квадратно-свободных
* **Σ_{d|n} λ(d) = 1** если n — полный квадрат, иначе 0
* **λ(n) = μ(n)·μ(n)/μ(n)** — не совсем, но связь через количество простых делителей

#### **Примеры вычисления:**
| n | Разложение | Ω(n) | λ(n) |
|---|-----------|-------|-------|
| 1 | — | 0 | 1 |
| 2 | 2¹ | 1 | -1 |
| 6 | 2¹·3¹ | 2 | 1 |
| 12 | 2²·3¹ | 3 | -1 |
| 36 | 2²·3² | 4 | 1 |

#### **Применение:**
* **Подсчёт полных квадратов:** Σ_{d|n} λ(d) = [n — полный квадрат]
* **Связь с делителями:** λ(d) = (-1)^{разность степеней} при переходе между делителями

### **2.4. Дирихлева свёртка**
#### **Определение:**
* (f * g)(n) = Σ f(d)·g(n/d) (сумма по всем делителям d числа n)
* **Свойства:** Коммутативность, ассоциативность, дистрибутивность относительно сложения

#### **Важные свёртки:**
* **μ * 1 = ε** где ε(1)=1 и ε(n)=0 при n>1 (единичная функция)
* **φ * 1 = id** где id(n)=n (тождественная функция)
* **d = 1 * 1** где d(n) — количество делителей
* **σ = id * 1** где σ(n) — сумма делителей

### **2.5. Функция делителей dₖ(n)**
#### **Определение:**
`dₖ(n)` = количество упорядоченных наборов (a₁, a₂, ..., aₖ) таких, что a₁·a₂·...·aₖ = n

#### **Связь с комбинаторикой:**
* **d₂(n) = d(n)** — количество делителей
* **dₖ(n) = (1 * 1 * ... * 1)(n)** (k раз) — k-кратная свёртка единичной функции
* **Формула через разложение на простые:** dₖ(n) = ∏ C(aᵢ + k - 1, k - 1)
  * Почему: для каждого pᵢ выбираем, сколько раз pᵢ входит в каждый из k множителей — разбиение aᵢ на k неотрицательных слагаемых: «звёзды и барьеры»
  * Пример: n=12=2²·3, k=3 → C(4,2)·C(3,2) = 6·3 = 18

#### **Вычисление dₖ(n):**
* **Для одного n:** через разложение на простые + комбинаторная формула
* **Для всех n до N:** через k-кратную свёртку за O(N log N) d(n, k)

### **2.6. Сумма степеней делителей σₖ(n)**
#### **Определение:**
`σₖ(n) = Σ dᵏ` где сумма берется по всем делителям d числа n

#### **Частные случаи σₖ(n):**
* **σ₀(n) = d(n) = d₂(n)** — количество делителей
* **σ₁(n) = σ(n)** — сумма делителей
* **σ₋₁(n) = Σ 1/d** — сумма обратных делителей

#### **Способы вычисления:**
* **Формула через разложение:** σₖ(n) = ∏ (pᵢ^{k(aᵢ+1)} - 1)/(pᵢᵏ - 1) при k ≠ 0 
* **Через свёртку:** σₖ = idₖ * 1
* **Предподсчет:** модификация линейного решета
  * Доп. массивы: pe[i]=spf[i]^e, rest[i]=σₖ(m) где m=i/pe[i]
  * Для простых p: sigma[p] = 1 + p^k
  * Для i*p (p ∤ i): sigma[i*p] = sigma[i] · sigma[p] (мультипликативность)
  * Для i*p (p | i): sigma[i*p] = rest[i] · (pe[i*p]^k · p^k - 1)/(p^k - 1)
  * Важно: ratio σₖ(p^{e+1})/σₖ(p^e) не целочисленный, поэтому нужен rest[i]
