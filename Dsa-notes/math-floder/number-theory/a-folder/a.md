# **A. ДЕЛИМОСТЬ, НОК, НОД, МУЛЬТИПЛИКАЦИЯ**

# **I. ДЕЛИМОСТЬ**

## **1. Фундаментальные определения**

### **1.1. Делимость - произошло деление без остатка**
* **Определение:** `b | a` (a делит b) ⇔ ∃c ∈ ℤ: `a = b·c`
* **Теорема:** Для любых целых в паре (a, b), b ≠ 0 ∃ !c: `a = b·c`
* **a через b:** Число a можно представить как сумму c слагаемых равных b:
a = b + b + ... + b
    \_____________/
         c раз

### **1.2. Неделимость - произошло деление с остатком**
* **Теорема:** Для любых целых в паре (a, b), b ≠ 0 ∃ !(c, r):
  Представляем одну букву с помощью трех:
  `a = b·c + r`, где `0 ≤ r < |b|`
* **Терминология:**
  - Делимое: `a`
  - Делитель: `b`
  - Неполное частное: `c = ⌊a/b⌋` = `a div b`
  - Остаток: `r = a mod b = a % b`
* Получаем: a = b * ⌊a/b⌋ + a % b (дана буква а, b подставляем любую)
* **a через b:**
a = b + b + ... + b + 0,1,2,...,b-1
    \_____________/
         c раз

### **1.3. Заметка**
* Все деление происходит всегда **в целых числах**
* **В рациональных числах:** Деление = умножение на обратное: `a/b = a × b⁻¹`
* **Трюк для работы с десятичными:** `13.45 / 17.2 = (1345 × 10) / (172 × 100)`  
  Умножаем на степени 10, чтобы избавиться от запятой
* Вспомнить деление в столбик - как создается число с запятой

## **2. Ключевые свойства**
- a | b и b | c ⇒ a | c
- a | b и a | c ⇒ a | (bx + cy) ∀x,y
- *Следствие:* a | (b + c), a | (b - c), a | kb, a | kc, a | k(b +- c)
- a | b и b | a ⇒ a = ±b

# **II. РАЗЛОЖЕНИЕ НА МНОЖИТЕЛИ**

## **1. Основная теорема арифметики**
* n = p₁^α₁ p₂^α₂ ⋯ pₖ^αₖ, где pᵢ — простые, αᵢ ≥ 1
* 2^k <= p1 * p2 * ... * pk <= n;
* **Метод факторизации: fact()** проверка делителей до √n
```cpp
pair<vector<int>, vector<int> > fact(int a) {
    vector<int> primes((int) log2(a), 0), powers((int) log2(a), 0);
    int x = 2, i = 0;
    while (a > 1) {
        for (; a % x == 0; a /= x, powers[i]++);
        (powers[i] == 0) ? x++ : primes[i++] = x++;
    }
    return make_pair((primes.resize(i), std::move(primes)), (powers.resize(i), std::move(powers)));
}
```
* **Предподсчет простых через решето**

# **III. НАИМЕНЬШЕЕ ОБЩЕЕ КРАТНОЕ (НОК)**

## **1. Определения**
* lcm(a,b) = min{m > 0: a | m и b | m}
* lcm(a,b) = p1^max(a1,b1) * p2^max(a2,b2) * ... * pk^max(ak, bk)
* l = lcm(a, b) = lcm(x, y) пар (x, y) не бесконечно много # x и y | l

## **2. Свойства НОК**
* lcm(a,b) * gcd(a,b) = |ab| # факторизация 🟢
* lcm(a₁,...,aₙ) = lcm(a₁, lcm(a₂, ..., aₙ)) # факторизация
* ОК: a | c и b | c ⇒ lcm(a,b) | c  # факторизация
* lcm(ka, kb) = k ⋅ lcm(a,b)  # факторизация

* **Нахождение НОК: lcm()** нахождение через НОД
```cpp
int lcm(int a, int b) {
    return a / gcd_mod(a, b) * b;
}
```

# **IV. НАИБОЛЬШИЙ ОБЩИЙ ДЕЛИТЕЛЬ (НОД)**

## **1. Определения**
* gcd(a,b) = max{d: d | a и d | b}
* gcd(a,b) = p1^min(a1,b1) * p2^min(a2,b2) * ... * pk^min(ak,bk)
* **Взаимно простые:** gcd(a,b) = 1
* g = gcd(a, b) = gcd(x, y) пар (x, y) бесконечно много # делим на gcd(a, b)

## **2. Свойства НОД**
* 0. gcd(a,b) = gcd(b, a)
* 1. gcd(a,b) = gcd(a, -b)
* 2. gcd(a,b) = gcd(-a, -b)
* 3. gcd(a,b) = gcd(a, b-a) 🟢 # выделение ОД
* 4. gcd(a,b) = gcd(a, b-k*a), где k в N0 # выделение ОД
* 5. gcd(a,b) = gcd(a, b mod a) 🟢 # определение остатка, жадный выбор k
* 6. gcd(a,b) = gcd(a, b + k*a) где k в Z # выделение ОД
* 7. ОД: c | a и c | b => c | gcd(a, b) # факторизация
* 8. gcd(a,b) ⋅ lcm(a,b) = |ab| # факторизация
* 9. gcd(a₁,...,aₙ) = gcd(a₁, gcd(a₂, ..., aₙ)) # факторизация
* 10. gcd(ab, ac) = a ⋅ gcd(b,c)  # факторизация
* 11. gcd(a/g, b/g) = 1, если g = gcd(a, b); # вынести множитель
* 12. gcd(a,b) = 1 = gcd(1, b) => gcd(ak,b) = gcd(k,b) # факторизация
* 13. gcd(a,b) = gcd((a-b)/n, b) если a == b (mod n) и gcd(n,b)==1 🟢 # 6 и 11
* 14. ∃x,y: ax + by = gcd(a,b) # через множество S

* **Нахождение НОД: gcd_diff()** нахождение через свойство 3
```cpp
int gcd_diff(int a, int b) {
    if (a > b) swap(a, b);
    while (b > 0) (a > b) ? a -= b : b -= a;
    return a;
}
```
* **Нахождение НОД: gcd_mod()** нахождение через свойство 5
```cpp
int gcd_mod(int a, int b) {
    while (b) swap(a %= b, b);
    return a;
}
int gcd_mod(int a, int b) {
    return (b == 0) ? gcd_mod_rec(b, a % b) : a;
}
```
* **Нахождение НОД: gcd_stein()** нахождение через свойства 3, 10, 12
```cpp
// Используйте эту версию, если компилятор GCC/Clang:
unsigned int gcd_stein(unsigned int a, unsigned int b) {
    if (a == 0) return b;
    if (b == 0) return a;

    int shift = __builtin_ctz(a | b);
    a >>= __builtin_ctz(a);

    do {
        b >>= __builtin_ctz(b);
        if (a > b) std::swap(a, b);
        b -= a;
    } while (b);

    return a << shift;
}
```

# **V. ФУНКЦИИ ДЕЛИТЕЛЕЙ**

## **1. Что такое делитель**
* Делитель это p₁^b₁ p₂^b₂ ⋯ pₖ^bₖ где pᵢ — простые, 0 < bᵢ <= αᵢ
* при deg(pᵢ) ≥ 0 набор простых p1,p2,...,pk становится бесконечный
* **Все делители через разложение** # факторизация
* **Быстрый перебор пар (d, n/d)** # алгоритм до √n
```cpp
vector<int> divide(int a) {
    vector<int> divs;
    for (int x = 1; x * x <= a; x++) {
        if (a % x == 0) {
            divs.push_back(x);
            if (a / x != x) divs.push_back(a / x);
        }
    }
    return divs;
}
```

## **2. Количество делителей**
* d(n) = ∏ᵢ (αᵢ + 1) где n = ∏ pᵢ^αᵢ # комба

## **5.2. Сумма делителей**
* σ(n) = ∏ᵢ (pᵢ^{αᵢ+1} - 1)/(pᵢ - 1) = Пi (pi^ai + pi*(ai-1) + ... + 1) # комба

## **5.3. Aliquot Sum = Сумма собственных делителей (теория)**
* **Собственный делитель числа = Аликвота числа** - это делитель числа, не равный самому числу
* **Определение:** s(n) = σ(n) - n cумма собственных делителей числа n # поэтому само число не учитываем в сумму аликвот

#### **Классификация:**
* **Совершенные:** $s(n) = n \Leftrightarrow \sigma(n) = 2n$
* **Избыточные:** $s(n) > n \Leftrightarrow \sigma(n) > 2n$
* **Недостаточные:** $s(n) < n \Leftrightarrow \sigma(n) < 2n$

#### **Цепочки:**
* **Совершенные ($k=1$):** $s(a_1) = a_2$
* **Дружественные ($k=2$):** $s(a_1) = a_2$ и $s(a_2) = a_1$
* **Социабельные ($k \ge 3$):** $s(a_1) = a_2$, $s(a_2) = a_3$, $\dots$, $s(a_k) = a_1$

#### **Алгоритмы:** по формуле - через нахождение σ(n)

# **VI. МУЛЬТИПЛИКАТИВНЫЕ ФУНКЦИИ**

## **1. Определение и основная идея**
* **Формальное определение:** f(mn) = f(m)f(n) при gcd(m,n) = 1, а также f(1) = 1
* **Простая аналогия:** Если m и n "независимы" (взаимно просты), то f(mn) = f(m) × f(n)
* **Ключевое следствие:** Чтобы вычислить f(n) для любого n, достаточно знать f(pᵏ) для степеней простых
n = p₁ᵃ¹ × p₂ᵃ² × ... × pₖᵃᵏ
f(n) = f(p₁ᵃ¹) × f(p₂ᵃ²) × ... × f(pₖᵃᵏ)
* Мультипликативные функции — это мощный инструмент для сведения задач на подсчёт к эффективным алгоритмам

## **2. Примеры мультипликативных функций:**
* **d(n)** — количество делителей (из раздела V.5.1)
* **σ(n)** — сумма делителей (из раздела V.5.2)
* **φ(n)** — функция Эйлера
* **μ(n)** — функция Мёбиуса
* **1(n)** = 1 для всех n (единичная функция)
* **id(n)** = n (тождественная функция)
* **idₖ(n)** = nᵏ
* **dₖ(n)** — функция делителей, остальные функции на делителях
* **σₖ(n)** — функция "сумма делителей в степенях"

## **3. Важные мультипликативные функции**

### **3.1. Функция Мёбиуса μ(n)**
* **μ(1) = 1** — базовый случай
* **μ(n) = 0** если в разложении n есть pi: deg(pi) >= 2
* **μ(n) = (-1)ᵏ** если n = p₁·p₂·...·pₖ (различные простые множители)
* **Σ μ(d) = 1** если n=1, иначе 0 (сумма по делителям)
* **Нахождение : mu()** через разложение на простые
```cpp
int mu(int n) {
    auto [primes, powers] = fact(n);
    for (auto ai : powers) if (ai >= 2) return 0;
    return (primes.size() % 2 == 0) ? 1 : -1;
}
```

#### **3.1.1 Формула обращения Мёбиуса - Теорема (две эквивалентные формы)**
* **Прямая форма:** Если g(n) = Σ f(d) (сумма по всем делителям d числа n),  
  то f(n) = Σ μ(d)·g(n/d) (d | n)
* **Двойственная форма:** Если g(n) = Σ f(d) (сумма по всем числам d, кратным n),  
  то f(n) = Σ μ(d/n)·g(d) (n | d)

### **3.2. Функция Эйлера φ(n)**
* **Определение:** φ(n) = количество чисел от 1 до n, взаимно простых с n
* **φ(1) = 1** — по определению
* **Для простого p:** φ(p) = p - 1
* **Для степени простого:** φ(pᵏ) = pᵏ - p^{k-1} = p^{k-1}(p - 1) для k ≥ 1
* **Мультипликативность:** φ(mn) = φ(m)·φ(n) при gcd(m, n) = 1
* **Обобщение мультипликативности:** φ(ab) = φ(a)·φ(b)·d/φ(d), где d = gcd(a,b)
* **n/φ(n) = Σ 1/p** (приближённо) для больших n

#### **3.2.2. Формула обращения для φ(n)**
* **Сумма по делителям:** Σ φ(d) = n (сумма по всем делителям d числа n)
* **Связь с функцией Мёбиуса:** φ(n) = Σ μ(d)·(n/d) (сумма по всем делителям d числа n)
* **Для чётных n > 2:** φ(n) ≤ n/2
* **Неравенство:** φ(n) ≥ √(n/2) для n ≥ 2

#### **3.2.1. Формула вычисления**
* **Через разложение на простые:**
  φ(n) = n × ∏ (1 - 1/pᵢ) где произведение по всем различным простым делителям pᵢ числа n
* **Нахождение φ(n): fi()** по связи с функцией Мёбиуса
```cpp
int fi(int n) {
    int result = 0;
    for (auto d : divide(n)) result += mu(d) * (n / d);
    return result;
}
```

### **3.3. Дирихлева свёртка**
* (f * g)(n) = Σ f(d)·g(n/d) (сумма по всем делителям d числа n)
#### **Свойства:**
* **Коммутативность:** $f * g = g * f$
* **Ассоциативность:** $(f * g) * h = f * (g * h)$
* **Дистрибутивность:** $f * (g + h) = f*g + f*h$

#### **3.3.1. Важные свёртки:**
* **μ * 1 = ε** где ε(1)=1 и ε(n)=0 при n>1 (единичная функция)
* **φ * 1 = id** где id(n)=n (тождественная функция)
* **d = 1 * 1** где d(n) — количество делителей
* **σ = id * 1** где σ(n) — сумма делителей

### **3.4. Функция делителей dₖ(n)**
* **Определение:**
`dₖ(n)` = количество упорядоченных наборов (a₁, a₂, ..., aₖ) таких, что a₁·a₂·...·aₖ = n

#### **3.4.1. Связь с комбинаторикой:**
* **d₀(1) = 1, d₀(n) = 0 когда n != 1**
* **d₂(n) = d(n)** — количество делителей
* **dₖ(n) = (1 * 1 * ... * 1)(n)** (k раз) — k-кратная свёртка единичной функции
* **Формула через разложение на простые:** dₖ(n) = ∏ C(aᵢ + k - 1, k - 1)
* **Нахождение dₖ(n): d()** через k-кратную свертку Дирихле
```cpp
int d(int n, int k) {
    if (k == 0) return n == 1;
    vector<int> keys = divide(n);
    unordered_map<int, vector<int> > info;
    for (auto key : keys) info[key] = divide(key);

    unordered_map<int, int> di;
    for (auto key : keys) di[key] = 1;

    while (--k) {
        unordered_map<int, int> dj;
        for (auto key : keys) for (auto div : info[key]) dj[key] += di[div];
        di = dj;
    }

    return di[n];
}
```

### **3.5. Сумма степеней делителей σₖ(n)**
* ***Определение:**
`σₖ(n) = Σ dᵏ` где сумма берется по всем делителям d числа n

#### **Частные случаи σₖ(n):**
* **σ₀(n) = d(n) = d₂(n)** — количество делителей
* **σ₁(n) = σ(n)** — сумма делителей
* **σ₋₁(n) = Σ 1/d** — сумма обратных делителей

#### **Способы вычисления:**
* **Формула через разложение:** σₖ(n) = ∏ (pᵢ^{k(aᵢ+1)} - 1)/(pᵢᵏ - 1) при k ≠ 0
* **Через свёртку:** σₖ = idₖ * 1 - дает определение
* **Нахождение σₖ(n): delta()** через свертку
```cpp
int delta(int n, int k) {
    vector<int> keys = divide(n);
    int sum = 0;
    for (auto key : keys) sum += pow(key, k);
    return sum;
}
```

## **4. Типичные задачи**
### **Категория 1: Подсчёт пар/троек**
* **Нахождение упорядоченных m-наборов (a1, a2, ..., am) с gcd=g: category1()**
* ответ = Σ μ(t)·⌊N/g·t⌋^m, где 1 <= ai <= N
```cpp
int category1(int N, int m, int g) {
    int sum = 0;
    for (int t = 1; g * t <= N; t++) {
        int cnt = N / (g * t);
        sum += mu(t) * pow(cnt, m);
    }
    return sum;
}
```

#### **Категория 2: Суммы gcd/lcm**
* **Сумма gcd всех пар:** Σ φ(d)·cnt(d)²·d
* **Сумма lcm всех пар:** через предподсчет σ(n) и других функций
* **Сумма gcd(i,n) для i=1..n:** Σ d·φ(n/d)

#### **Категория 3: Подсчёт по условиям делимости**
* **Чисел, взаимно простых со всеми из множества:** включение-исключение через μ
* **Чисел, делящихся хотя бы на одно из множества:** принцип включения-исключения

### **8.3.3. Оптимизации и хитрости**
#### **Предподсчёт делителей:**
* **Хранение всех делителей до N:** O(N log N) памяти, O(1) доступ
* **Хранение только простых делителей:** O(N) памяти, O(количество делителей) доступ
