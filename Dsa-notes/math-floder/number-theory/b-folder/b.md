# **B. МОДУЛЯРНАЯ АРИФМЕТИКА И ДИОФАНТОВЫ УРАВНЕНИЯ**

## **1. МОДУЛЯРНАЯ АРИФМЕТИКА**

### **1.0. Свойства остатков**
* **a mod n = остаток от деления a на n**
* **a (mod n) = r <==> a = n * q + r, q = floor(a / n)**
* **Остаток всегда меньше делителя:** `0 ≤ r < |n|` явно `-|n| < r < |n|`
* **Если остаток 0:** `n | a` (делится нацело)
* **Отрицательные числа:** остатка всегда два (кроме случая что остаток = 0)
  - потому что можно округлить 1. вверх или 2. вниз
  - неполное частное всегда является округлением вниз
  - Пример: 17 mod 3 --> 17 = 3 * 6 - 1 ceil(17 / 3), либо 17 = 3 * 5 + 2 floor(17 / 3)
* Памятка: a mod n = m <==> -(n-m)
    0       1       2       3       ...     n-2      n-1      n
 -(n-0)  -(n-1)  -(n-2)  -(n-3)     ...     -2       -1       0

    32 % 7 = 4 --> -3
    32 % -7 = -3 --> 4
    -32 % 7 = 3 --> -4
    -32 % -7 = -4 --> 3

### **1.1. Сравнения по модулю**
* **Определение:** `a ≡ b (mod n)` ⇔ `n | (a - b)`
* **Эквивалентные формулировки:**
  - `a ≡ b (mod n)` ⇔ `a mod n = b mod n`
  - `a ≡ b (mod n)` ⇔ `∃k ∈ ℤ: a = k·n + b`
* **Модуль:** число n в выражении `mod n`

### **1.2. Основные свойства сравнений**
* **Рефлексивность:** `a ≡ a (mod n)`
* **Симметричность:** `a ≡ b (mod n)` ⇒ `b ≡ a (mod n)`
* **Транзитивность:** `a ≡ b (mod n)` и `b ≡ c (mod n)` ⇒ `a ≡ c (mod n)`
* **Сложение:** `a ≡ b (mod n)` и `c ≡ d (mod n)` ⇒ `a+c ≡ b+d (mod n)`
* **Вычитание:** `a ≡ b (mod n)` и `c ≡ d (mod n)` ⇒ `a-c ≡ b-d (mod n)`
* **Умножение:** `a ≡ b (mod n)` и `c ≡ d (mod n)` ⇒ `a·c ≡ b·d (mod n)`
* **Возведение в степень:** `a ≡ b (mod n)` ⇒ `aᵏ ≡ bᵏ (mod n)`

### **1.3. Деление в сравнениях (осторожно!)**
* **Общее правило:** `ac ≡ bc (mod n)` ⇔ `a ≡ b (mod n/gcd(c,n))`
* **Следствие 1:** Если `gcd(c,n) = 1`, то можно сократить:  
  `ac ≡ bc (mod n)` ⇒ `a ≡ b (mod n)`
* **Следствие 2:** Если `d = gcd(c,n)`, то:  
  `ac ≡ bc (mod n)` ⇔ `a ≡ b (mod n/d)`
* **Пример:** `8 ≡ 2 (mod 6)`  
  Делим обе части на 2: `4 ≡ 1 (mod 3)` (так как `gcd(2,6) = 2`, новый модуль `6/2 = 3`)

## **2. КЛАССЫ ВЫЧЕТОВ И ПОЛНАЯ СИСТЕМА ВЫЧЕТОВ**

### **2.1. Классы вычетов**
* **Количество классов:** Ровно n различных классов: `[0], [1], ..., [n-1]`
* **Определение:** Класс вычетов по модулю n: `[a]ₙ = {x ∈ ℤ: x ≡ a (mod n)}`
* **Пример:** `[2]₅ = {..., -8, -3, 2, 7, 12, ...}`

### **2.2. Полная система вычетов (ПСВ)**
* **Определение:** Набор из n чисел, дающих все различные остатки при делении на n
* **Стандартная ПСВ:** `{0, 1, 2, ..., n-1}`
* **Другие ПСВ:** `{1, 2, 3, ..., n}`, `{-⌊n/2⌋, ..., 0, ..., ⌈n/2⌉-1}`

### **2.3. Приведенная система вычетов (ПрСВ)**
* **Определение:** Набор чисел из ПСВ, взаимно простых с модулем n
* **Количество чисел в ПрСВ:** `φ(n)` (функция Эйлера)
* **Пример для n=8:** `{1, 3, 5, 7}` (всего `φ(8)=4` числа)

## **3. ОБРАТИМЫЕ ЭЛЕМЕНТЫ И МУЛЬТИПЛИКАТИВНЫЕ ОБРАТНЫЕ**

### **3.1. Обратимые элементы по модулю n**
* **Определение:** `a` обратим по модулю n ⇔ `∃b: a·b ≡ 1 (mod n)`
* **Критерий обратимости:** `a` обратим ⇔ `gcd(a,n) = 1`
* **Обозначение:** `a⁻¹ (mod n)` или `inv(a, n)`

### **3.2. Нахождение обратного элемента**
#### **3.2.1. Метод 1: Расширенный алгоритм Евклида**
* Находим `x,y` такие, что `a·x + n·y = gcd(a,n) = 1`
* Тогда `x mod n` — искомый обратный к `a` по модулю `n`

```cpp
int mod_inv(int a, int n) {
    int x, y;
    int g = extended_gcd(a, n, x, y);
    if (g != 1) return -1; // обратного не существует
    return (x % n + n) % n; // нормализуем в [0, n-1]
}
```

#### **3.2.2. Метод 2: Малая теорема Ферма (для простых модулей)**

* Если `p` — простое и `gcd(a,p) = 1`, то:  
  `a^{p-1} ≡ 1 (mod p)`
* **Следствие:** `aᵖ ≡ a (mod p)` для любого `a`

* Если `n` — простое и `a` не делится на `n`, то:  
  `a⁻¹ ≡ a^{n-2} (mod n)`

```cpp
int mod_inv_fermat(int a, int n) {
    // n должно быть простым
    return pow_mod(a, n-2, n);
}
```

#### **3.2.3. Метод 3: Теорема Эйлера**

* Если `gcd(a,n) = 1`, то:  
  `a^{φ(n)} ≡ 1 (mod n)`
* **Обобщение малой теоремы Ферма**

* Если `gcd(a,n) = 1`, то:  
  `a⁻¹ ≡ a^{φ(n)-1} (mod n)`

### **3.3. Группа обратимых элементов**
* **Обозначение:** `(ℤ/nℤ)*` — группа обратимых элементов по модулю n
* **Порядок группы:** `|(ℤ/nℤ)*| = φ(n)`
* **Свойство:** `a^{φ(n)} ≡ 1 (mod n)` если `gcd(a,n) = 1`

### **3.3.1. Теорема Лагранжа (о порядке элемента)**
* В группе `(ℤ/nℤ)*` порядок любого элемента делит `φ(n)`
* **Порядок элемента:** Наименьшее `k > 0` такое, что `aᵏ ≡ 1 (mod n)`

## **4. ЛИНЕЙНЫЕ СРАВНЕНИЯ**

### **4.1. Общий вид**
* `a·x ≡ b (mod n)` — линейное сравнение
* **Пример:** `3x ≡ 2 (mod 7)`

### **4.2. Критерий разрешимости**
* Сравнение `a·x ≡ b (mod n)` имеет решение ⇔ `gcd(a,n) | b`

### **4.3. Алгоритм решения**
1. Находим `d = gcd(a,n)`
2. Если `d ∤ b`, решений нет
3. Если `d | b`, делим всё на `d`:  
   `(a/d)·x ≡ (b/d) (mod n/d)`
4. Теперь `gcd(a/d, n/d) = 1`, находим обратный к `(a/d)` по модулю `n/d`
5. Умножаем обе части на обратный: `x ≡ (b/d)·(a/d)⁻¹ (mod n/d)`
6. Получаем `d` решений по модулю `n`:  
   `x ≡ x₀ + k·(n/d) (mod n)`, где `k = 0,1,...,d-1`

```cpp
vector<int> solve_linear_congruence(int a, int b, int n) {
    int d = gcd(a, n);
    vector<int> solutions;
    
    if (b % d != 0) return solutions; // нет решений
    
    int a1 = a / d, b1 = b / d, n1 = n / d;
    int inv = mod_inv(a1, n1);
    int x0 = (b1 * inv) % n1;
    
    for (int k = 0; k < d; k++) {
        solutions.push_back((x0 + k * n1) % n);
    }
    
    return solutions;
}
```

## **5. СИСТЕМЫ СРАВНЕНИЙ (КИТАЙСКАЯ ТЕОРЕМА ОБ ОСТАТКАХ)**

### **5.1. Китайская теорема об остатках (КТО)**
* **Дано:** Система сравнений:  
  ```
  x ≡ a₁ (mod n₁)
  x ≡ a₂ (mod n₂)
  ...
  x ≡ aₖ (mod nₖ)
  ```
* **Условие разрешимости:** `gcd(nᵢ, nⱼ) = 1` для всех `i ≠ j`
* **Решение:** Существует единственное решение по модулю `N = n₁·n₂·...·nₖ`

### **5.2. Алгоритм решения**
1. Вычисляем `N = n₁·n₂·...·nₖ`
2. Для каждого `i` вычисляем:
   - `Nᵢ = N / nᵢ`
   - `Mᵢ = обратный к Nᵢ по модулю nᵢ` (т.е. `Nᵢ·Mᵢ ≡ 1 (mod nᵢ)`)
3. Решение: `x ≡ Σ (aᵢ·Nᵢ·Mᵢ) (mod N)`

```cpp
int crt(vector<int> a, vector<int> n) {
    int k = a.size();
    int N = 1;
    for (int i = 0; i < k; i++) N *= n[i];
    
    int x = 0;
    for (int i = 0; i < k; i++) {
        int Ni = N / n[i];
        int Mi = mod_inv(Ni, n[i]);
        x = (x + a[i] * Ni % N * Mi % N) % N;
    }
    
    return x;
}
```

### **5.3. Обобщенная КТО**
* Если модули не взаимно просты, система может иметь:
  - Ни одного решения
  - Одно решение по модулю `lcm(n₁, n₂, ..., nₖ)`
* **Критерий разрешимости:** Для всех `i,j` должно выполняться:  
  `aᵢ ≡ aⱼ (mod gcd(nᵢ, nⱼ))`

## **6. ДИОФАНТОВЫ УРАВНЕНИЯ**

### **6.1. Линейные диофантовы уравнения**
* **Общий вид:** `a·x + b·y = c`, где `a,b,c ∈ ℤ`
* **Критерий разрешимости:** Уравнение имеет целые решения ⇔ `gcd(a,b) | c`

### **6.2. Алгоритм решения**
1. Находим `d = gcd(a,b)`
2. Если `d ∤ c`, решений нет
3. Если `d | c`, делим всё на `d`: `a₁·x + b₁·y = c₁`
4. Находим частное решение `(x₀, y₀)` с помощью расширенного алгоритма Евклида
5. Общее решение:
   ```
   x = x₀ + k·(b₁)
   y = y₀ - k·(a₁)
   где k ∈ ℤ
   ```

```cpp
struct DioSolution {
    bool exists;
    int x0, y0;  // частное решение
    int dx, dy;  // шаги для общего решения
};

DioSolution solve_diophantine(int a, int b, int c) {
    int d = gcd(abs(a), abs(b));
    DioSolution sol;
    
    if (c % d != 0) {
        sol.exists = false;
        return sol;
    }
    
    sol.exists = true;
    int a1 = a / d, b1 = b / d, c1 = c / d;
    
    // Находим решение a1*x + b1*y = 1
    int x1, y1;
    extended_gcd(a1, b1, x1, y1);
    
    // Частное решение
    sol.x0 = x1 * c1;
    sol.y0 = y1 * c1;
    
    // Шаги для общего решения
    sol.dx = b1;
    sol.dy = -a1;
    
    return sol;
}
```

### **6.3. Связь с модулярной арифметикой**
* Уравнение `a·x + b·y = c` эквивалентно `a·x ≡ c (mod b)` при поиске `x`
* Уравнение `a·x + b·y = c` эквивалентно `b·y ≡ c (mod a)` при поиске `y`
