# **A. СТЕПЕНЬ ДЕЛИТЕЛЯ В ФАКТОРИАЛЕ**

## **1. Задача**
* Найти старшую степень p, в которую делится n! (т.е. максимальное k: p^k | n!)
* Обозначение: v_p(n!) — p-адическая оценка n!

## **2. Формула Лежандра**
* **Формула:** v_p(n!) = ⌊n/p⌋ + ⌊n/p²⌋ + ⌊n/p³⌋ + ... = Σᵢ₌₁^∞ ⌊n/pⁱ⌋
* **Почему работает:** каждое число от 1 до n содержит определённое количество множителей p
  * ⌊n/p⌋ — числа кратные p (дают хотя бы один множитель p)
  * ⌊n/p²⌋ — числа кратные p² (дают ещё один множитель p)
  * ⌊n/p³⌋ — числа кратные p³ (дают ещё один)
  * ...и так далее, пока pⁱ > n
* **Пример:** v₅(100!) = ⌊100/5⌋ + ⌊100/25⌋ + ⌊100/125⌋ = 20 + 4 + 0 = 24
* **Сложность:** O(log_p n)

## **3. Формула для произведения**
* v_p(a₁ · a₂ · ... · aₖ) = Σ v_p(aᵢ)
* v_p(C(n,k)) = v_p(n!) - v_p(k!) - v_p((n-k)!) — для биномиальных коэффициентов

## **4. Теорема Кюммера**
* **Формула:** v_p(C(n,k)) = количество переносов при сложении k + (n-k) в системе счисления по основанию p
* **Почему работает:** перенос возникает когда сумма цифр ≥ p, что соответствует "захвату" множителя p
* **Пример:** C(10,3), p=2: 3=0011₂, 7=0111₂, сумма=10110₂ — перенос на позициях 1 и 2 → v₂(C(10,3))=2
* **Сложность:** O(log_p n)
* **Применение:** быстрая проверка делимости биномиальных коэффициентов, задачи на подсчёт нулей

## **5. Обратная задача: наименьший n: m | n!**
* **Задача:** найти минимальное n такое что m делит n!
* **Алгоритм:** для каждого простого делителя p^e числа m найти最小ое n_p: v_p(n_p!) ≥ e
  * Бинарный поиск по n: проверять v_p(n!) ≥ e через формулу Лежандра
  * Ответ: max(n_p) по всем простым делителям m
* **Сложность:** O(log²m) на простой делитель
* **Пример:** m=100=2²·5²: n₂=4 (v₂(4!)=3≥2), n₅=10 (v₅(10!)=2≥2) → ответ 10

# **B. ВЫЧИСЛЕНИЕ ФАКТОРИАЛА ПО МОДУЛЮ**

## **1. Наивный метод**
* n! mod p = (1 · 2 · ... · n) mod p за O(n)
* Проблема: при n > p результат всегда 0 (потому что n! содержит p)

## **2. Факториал без кратных p (структура)**
* **Идея:** разбить n! на произведение "чистых" элементов
* n! = p^(v_p(n!)) · (произведение чисел от 1 до n без кратных p)
* **Чистое произведение:** F(n) = ∏ᵢ₌₁^ⁿ (i, если p ∤ i)
* **Свойство:** F(n) = F(⌊n/p⌋) · (∏ᵢ₌₁^{p-1} i)^{⌊n/p⌋} · (∏ᵢ₌₁^{n mod p} i) (mod p)
* **Разложение:** каждое число от 1 до n разбивается на "голые" части и кратные p

## **3. Рекурсивное вычисление n! mod p (без кратных p)**
* **Алгоритм:** O(p log n) — рекурсия с глубиной O(log_p n)
* На каждом уровне: вычисляем произведение "чистых" элементов за O(p)
* **Итого:** O(p log_p n) = O(p · log n / log p)

## **4. Теорема Вильсона**
* **Формула:** (p-1)! ≡ -1 (mod p) для простого p
* **Доказательство:** каждое число a ∈ [2, p-2] имеет обратный a⁻¹ mod p, и a ≠ a⁻¹ (кроме 1 и p-1)
* **Следствие:** произведение всех элементов от 2 до p-2 ≡ 1 (mod p)
* **Применение:** проверка простоты, вычисление факториалов

# **C. ТРОИЧНАЯ СБАЛАНСИРОВАННАЯ СИСТЕМА СЧИСЛЕНИЯ**

## **1. Определение**
* **Основание:** 3, но цифры: -1, 0, 1 (обозначаются как T, 0, 1)
* **Представление:** n = Σ dᵢ · 3ⁱ, где dᵢ ∈ {-1, 0, 1}
* **Каноничность:** каждое целое число имеет唯一ное представление

## **2. Алгоритм перевода**
* Делим n на 3:
  * Если остаток 0 → цифра 0, n = n/3
  * Если остаток 1 → цифра 1, n = n/3
  * Если остаток 2 → цифра T (-1), n = (n+1)/3 (перенос 1)
* **Пример:** 5 → 5/3 = 1 ост. 2 (T), 1/3 = 0 ост. 1 → 1T₃ = 1·3 + (-1)·1 = 2... нет
* **Правильный пример:** 5 → 5%3=2 → цифра T, n=(5+1)/3=2; 2%3=2 → цифра T, n=(2+1)/3=1; 1%3=1 → цифра 1 → 1TT₃ = 1·9 + (-1)·3 + (-1)·1 = 5 ✓

## **3. Свойства**
* **Бесконечная точность:** отрицательные числа представляются естественно
* **Арифметика:** сложение и умножение с переносами как в обычных системах
* **Преимущество над дополнительным кодом:** нет проблемы "переполнения знакового бита"

# **D. ФАКТОРИАЛЬНАЯ СИСТЕМА СЧИСЛЕНИЯ**

## **1. Определение**
* **Основания:** 1!, 2!, 3!, 4!, ...
* **Цифры:** dᵢ ∈ [0, i] (для позиции i! цифра от 0 до i)
* **Представление:** n = Σ dᵢ · i! = d₁·1! + d₂·2! + d₃·3! + ...
* **Каноничность:** каждое неотрицательное целое число имеет唯一ное представление
* **Ограничение:** для числа n нужны цифры до ⌊log₂(n)⌋! (потому что k! > 2^(k-1) для k ≥ 4)

## **2. Алгоритм перевода**
* Делим n на 1 → цифра d₁ (остаток), n = n/1
* Делим n на 2 → цифра d₂ (остаток), n = n/2
* Делим n на 3 → цифра d₃ (остаток), n = n/3
* ...продолжаем пока n > 0
* **Пример:** 46 = 0·1! + 1·2! + 0·3! + 1·4! + 1·5! = 0·1 + 1·2 + 0·6 + 1·24 + 1·120 = 46

## **3. Свойства**
* **Факториальные числа:** 1, 2, 6, 24, 120, 720, 5040, ...
* **Количество цифр:** O(log n / log log n) — меньше чем в двоичной системе
* **Применение:**
  * Перестановки: индекс перестановки ↔ перестановка ( Lehmer code )
  * Подсчёт: количество чисел с заданными свойствами
  * Хеширование: уникальное представление для комбинаторных объектов
