**D. ДИСКРЕТНЫЙ АНАЛИЗ И КОРНИ**

> **Архитектура:** `ModArithmetic` (b.cpp) — базовый класс. `DiscreteLog` (d.cpp) — наследник. Все D-алгоритмы — методы `DiscreteLog`.

---

# **A. ПЕРВООБРАЗНЫЕ КОРНИ**

## **1. Определение**
* **Порядок элемента:** ord_p(g) = наименьшее k > 0: g^k ≡ 1 (mod p)
* **Первообразный корень:** g такое что ord_p(g) = p-1 (т.е. g, g², ..., g^(p-1) дают все 1..p-1)
* **Существование:** g существует ⟺ p = 2, 4, pᵏ, 2pᵏ (p — нечётное простое)
* **Формула:** g — ПК ⟺ g^((p-1)/q) ≢ 1 (mod p) для всех простых делителей q числа p-1

## **2. Нахождение**
* Разложить p-1 = q₁^α₁ · q₂^α₂ · ... · qₖ^αₖ
* Перебирать g = 2, 3, 4, ... и проверять g^((p-1)/qᵢ) ≢ 1 (mod p) для всех i
* Первый подходящий — первообразный корень
* **Сложность:** O(p^(1/2) · log p) в среднем

## **3. Все первообразные корни**
* Если g — ПК, то g^k тоже ПК ⟺ gcd(k, p-1) = 1
* Количество: φ(p-1) штук

## **4. Пример**
* p=7: p-1=6=2·3
* g=2: 2^(6/2) = 8 ≡ 1 (mod 7) → не подходит
* g=3: 3^(6/2) = 27 ≡ 6 ≡ -1 (mod 7) ✓, 3^(6/3) = 9 ≡ 2 (mod 7) ✓ → g=3

# **B. ИНДЕКСЫ (ДИСКРЕТНЫЕ ЛОГАРИФМЫ)**

## **1. Определение**
* **Индекс:** ind_g(b) = x такое что g^x ≡ b (mod p), g — фиксированный ПК
* **Аналогия:** ind_g — это "дискретный логарифм" по основанию g

## **2. Свойства**
* ind_g(1) = 0
* ind_g(g) = 1
* ind_g(b₁·b₂) = ind_g(b₁) + ind_g(b₂) (mod p-1)
* ind_g(bᵏ) = k·ind_g(b) (mod p-1)
* ind_g(b) ∈ [0, p-2]

## **3. Таблица индексов**
* **Построение:** O(p) — вычислить g^i для i=0..p-2, заполнить table[g^i] = i
* **Запрос:** O(1) — table[b]

## **4. Применение**
* Превращает умножение в сложение: a·b ≡ g^(ind(a)+ind(b)) (mod p)
* Решает a^x ≡ b → x·ind(a) ≡ ind(b) (mod p-1)

# **C. ДИСКРЕТНОЕ ЛОГАРИФМИРОВАНИЕ (BSGS)**

## **1. Задача**
* Найти x: a^x ≡ b (mod m)
* Решение: x = ind_g(b) · (ind_g(a))⁻¹ (mod p-1) — но это требует знания ПК и построения таблицы за O(p)

## **2. Baby-Step Giant-Step**
* **Идея:** x = im + j, где m = ⌈√m⌉, i ∈ [0,m), j ∈ [0,m)
* **Уравнение:** aʲ ≡ b·(a⁻ᵐ)ⁱ (mod m)
* **Алгоритм:**
  1. Baby step: aʲ в хеш-таблице для j=0..m-1
  2. Giant step: для i=0..m-1 проверить b·(a⁻ᵐ)ⁱ в хеш-таблице
  3. Результат: x = im + j
* **Сложность:** O(√m) время и память

## **3. BSGS для общего случая (gcd(a,m) ≠ 1)**
* Выносим g = gcd(a,m) пока b не станет взаимно простым с m
* Считаем количество вынесенных делителей cnt
* Итог: x = result + cnt

## **4. Пример**
* 2^x ≡ 5 (mod 11): m = ⌈√10⌉ = 4
* Baby: 2⁰=1, 2¹=2, 2²=4, 2³=8 → {1:0, 2:1, 4:2, 8:3}
* a⁻ᵐ = 2⁻⁴ = 16⁻¹ ≡ 5⁻¹ ≡ 9 (mod 11)
* Giant: i=1: 5·9¹=45≡1 → x=1·4+0=4. Проверка: 2⁴=16≡5 ✓

# **D. POHLIG-HELLMAN (ОПТИМИЗАЦИЯ BSGS)**

## **1. Идея**
* Разложить p-1 = ∏ qᵢ^eᵢ
* Для каждого qᵢ: извлечь x по цифрам в системе счисления по qᵢ
* Собрать ответ через КРТ (Китайская теорема об остатках)

## **2. Алгоритм**
* Для каждого простого q с показателем e в разложении p-1:
  1. gamma = a^((p-1)/q) (mod p)
  2. Извлекаем j-ю цифру x по модулю q через BSGS с основанием gamma
  3. Собираем x_mod = Σ d_j · q^j
  4. Запоминаем (x_mod, q^e) для КРТ
* Ответ = CRT(residues, moduli)

## **3. Сложность**
* O(∑ eᵢ · √qᵢ) — гораздо быстрее BSGS если p-1 "гладкое" (малые простые делители)

# **E. ИЗВЛЕЧЕНИЕ КОРНЯ ПО МОДУЛЮ (TONELLI-SHANKS)**

## **1. Задача**
* Найти x: x² ≡ n (mod p), p — простое
* **Условие решения:** n^((p-1)/2) ≡ 1 (mod p) (критерий Эйлера)

## **2. Быстрый случай: p ≡ 3 (mod 4)**
* x ≡ n^((p+1)/4) (mod p)
* **Сложность:** O(log p)

## **3. Общий случай: Tonelli-Shanks**
* Разложить p-1 = Q·2ˢ (Q нечётное)
* Найти z — невычет: z^((p-1)/2) ≡ -1 (mod p)
* M = s, c = z^Q, t = n^Q, R = n^((Q+1)/2)
* Пока t ≠ 1:
  * Найти i > 0: t^(2ⁱ) ≡ 1 (mod p)
  * b = c^(2^(M-i-1))
  * M = i, c = b², t = t·b², R = R·b
* Ответ: x = R
* **Сложность:** O(log² p) в среднем

## **4. Все корни**
* Если x₀ — корень, то второй корень: p - x₀
* Если x₀ = p - x₀ → один корень (n = 0), иначе два

# **F. ДИСКРЕТНЫЙ КОРЕНЬ СТЕПЕНИ K**

## **1. Задача**
* Найти x: xᵏ ≡ a (mod p), p — простое

## **2. Алгоритм**
* Найти g — первообразный корень
* Найти ind_a = ind_g(a) через BSGS
* Решить k·x ≡ ind_a (mod p-1) → x = ind_a · (k/gcd(k,p-1))⁻¹ (mod (p-1)/gcd(k,p-1))
* Ответ: g^x (mod p)

## **3. Все решения**
* Если x₀ — решение, то все: x₀ · (g^((p-1)/gcd(k,p-1)))^i для i=0..gcd(k,p-1)-1
* Количество: gcd(k, p-1)

## **4. Пример**
* x² ≡ 3 (mod 11): g=2, ind₂(3)=8 (потому что 2⁸=256≡3)
* 2·x ≡ 8 (mod 10) → x ≡ 4 (mod 5) → x=4
* Ответ: 2⁴=16≡5 (mod 11). Проверка: 5²=25≡3 ✓
