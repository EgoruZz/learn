# learn

Личная инженерная база знаний по Computer Science: конспекты по алгоритмам,
структурам данных и математике, спроектированные для долгосрочной поддержки
и интеграции знаний.

## Структура

- **`dsa-notes/`** — ядро репозитория: 18 тем, 164 юнита, каждый со своей
  цепочкой наследования (A→B→C…). Формат — Markdown-конспекты + C++-код.
  - `struct/`, `technique/`, `graph/`, `dynamic/`, `string/`, `hashing/` — алгоритмы и структуры данных
  - `math/` — дискретка, теория чисел, комбинаторика, алгебра, линал, анализ, вероятность
  - `geometry/`, `special-numbers/`, `special-sequences/` — геометрия и специализированные темы
  - `algo-analysis/` — капстоун: анализ сложности и алгоритмов
- **`prompts/`** — инструкции для AI-агента (наставника): `index.txt` — точка входа,
  `warm_up.txt` — роль и методика, `websites.txt` — источники, `workflow.txt` — git-процесс.
- **`.vscode/`**, **`opencode.json`** — конфигурация рабочей среды и MCP.

## Принципы

1. Фундаментальность: интуиция → строгое определение → почему работает → применение → ограничения.
2. Последовательность внутри темы фиксирована цепочкой наследования.
3. Репозиторий — долгосрочная инженерная библиотека: структура важнее объёма.
